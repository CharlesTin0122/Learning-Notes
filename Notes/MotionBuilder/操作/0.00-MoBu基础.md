# 快捷键
- 这里的快捷键基于maya模式
- ![](attachments/50b797983d77c18665297751df818f86_MD5.jpg)
- TRS分别对应位移旋转和缩放
- F5和F6对应局部旋转和世界选转
- 空格+鼠标右键点击骨骼=选择骨骼链
- K键打帧
- X+LMB + 视图内拖拽菜单：用于实现两个对象父子关系或对齐（MB模式快捷键为Alt+LMB)。先选中要操作的对象，然后执行X+LMB + 视图内拖拽菜单，拖拽最终指向驱动对象，弹出菜单。此操作在示意图中也可以使用。
- ![](attachments/845768c8238b289cc2393b494287ddd0_MD5.jpg)

- Ctrl+W：示意图
- Ctrl +E：透视图
- Ctrl+F：前视图，再次执行为后视图
- Ctrl+R：右视图，再次执行为左视图
- Ctrl+T：顶视图，再次执行为底视图
- Ctrl+2、3、4：多视图显示
- Alt+Z：摄影机撤销
- Alt+Y：摄影机重做

- 故事板模式操作：点右键Insert-Character Animation Track,选择角色，点右键Insert Current Take.两个片段整合过度，点眼睛，然后点match,并选择match部位。片段修改完成后，Plot Whole Scene To Current Take.

# 属性
## 添加属性
- 选中要添加属性的对象，点击Property中的Editor
- ![](attachments/03c465d90df1d8007cd90b9e5fd9df90_MD5.jpg)
- 在propertyEditor中选择CustomProperties选项，为其添加属性
- ![](attachments/9c2e91c58b5716286317a73f07d2e18e_MD5.jpg)
- 在属性栏中，将其设为Animatable，这样便可以链接该属性
- ![](attachments/3d88d9241958394d11bd73fb4abafa90_MD5.jpg)
- 创建RelationConstraint，用来连接属性
- ![](attachments/85c0005faab835a15cd4614c0380d4ee_MD5.jpg)
## 传递属性
- 选中要传递属性的控制器们，然后打开PropertyEditor，进入PropertyEditor选项卡
- ![](attachments/cc09fcd215c678006c3c2d71636e10e2_MD5.jpg)
- 可以将选中对象的任一控制器的属性传递给其他控制器
