从 Python 3 回到 MotionBuilder 2019（Python 2.7），确实会有一些“反直觉”的坑，主要集中在 **字符串、除法、迭代器、编码、API行为** 这些地方。我给你挑最容易踩坑、而且在 pyfbsdk 里特别常见的点。

---

# 1. 字符串 / Unicode（最容易出问题）

Python 2：

- `str` = 字节串
- `unicode` = 文本

### 常见坑

```python
name = model.Name  # 有时返回 str，有时是 unicode
```

如果你拼接中文或非 ASCII：

```python
"角色_" + name   # 可能直接炸
```

### 建议写法

```python
u"角色_" + unicode(name)
```

或者统一：

```python
name = unicode(name)
```

👉 在 MotionBuilder 里，**FBProperty / Name 字段经常混用 str/unicode**

---

# 2. print 不是函数

```python
print "hello"   # ✅
print("hello")  # 也能用，但要注意 tuple 行为
```

坑：

```python
print("a", "b")  
# Python2 输出: ('a', 'b')
```

---

# 3. 整数除法（非常隐蔽）

```python
3 / 2   # Python2 = 1
3 / 2.0 # = 1.5
```

建议强制：

```python
from __future__ import division
```

否则你在：

- 时间计算
- 权重
- 插值

都会出错

---

# 4. range vs xrange

```python
range(1000000)   # 直接生成大列表（慢+占内存）
xrange(1000000)  # 推荐
```

👉 在遍历大量 FBModel / FBComponent 时很重要

---

# 5. dict / 迭代行为不同

Python 3：

```python
d.keys()  # view
```

Python 2：

```python
d.keys()  # list
```

影响：

- 性能
- 内存
- 某些 for 循环逻辑

---

# 6. 异常语法不同

```python
except Exception as e:   # ✅ Python2.7支持
```

但不要写太新式的写法（比如多异常 unpack）

---

# 7. 编码声明必须写（很关键）

文件头必须：

```python
# -*- coding: utf-8 -*-
```

否则：

- 中文注释
- 字符串

都会炸

---

# 8. pyfbsdk 特有坑（重点）

## 8.1 FBString / Name 类型

```python
model.Name
```

可能：

- 是 str
- 也可能是 unicode

👉 建议统一：

```python
name = unicode(model.Name)
```

---

## 8.2 属性比较

```python
if prop.Data == "something":
```

在 Py2 可能因为编码问题失败

👉 安全写法：

```python
if unicode(prop.Data) == u"something":
```

---

## 8.3 列表 API（FBList）

```python
models = FBModelList()
FBGetSelectedModels(models)
```

遍历没问题，但注意：

- 不是标准 Python list
- 不支持某些切片/高级操作

---

## 8.4 None 判断

```python
if obj is None:   # ✅
```

不要用：

```python
if not obj:
```

因为 FBComponent 有时会“假值但不为空”

---

# 9. 类 / 新式类问题

一定要写：

```python
class MyTool(object):
```

否则：

- MRO
- property
- super()

都会有问题

---

# 10. 模块差异

Python 2：

- `urllib` 结构不同
- `reload()` 直接可用
- 没有 `pathlib`

---

# 11. MotionBuilder 特有执行环境

## 11.1 不要依赖标准 Python 行为完全一致

- MB 内嵌解释器有差异
- 某些模块缺失

## 11.2 UI 和主线程

- UI 操作必须在主线程
- 否则会 crash（不是异常）

---

# 12. 强烈建议的写法（兼容思路）

如果你要同时支持 Py2 + Py3，可以这样：

```python
try:
    unicode
except NameError:
    unicode = str
```

```python
try:
    xrange
except NameError:
    xrange = range
```

---

# 一句话总结

👉 你需要特别警惕三件事：

1. **字符串（str vs unicode）**
2. **除法（整数除法）**
3. **pyfbsdk 返回值类型不稳定**

---

# # ✅ MotionBuilder 2019 Python 工具模板（安全版）

```python
# -*- coding: utf-8 -*-

"""
MotionBuilder 2019 Python 2.7 安全模板
- 兼容 Python3 写法习惯
- 避免 unicode / 除法 / xrange 等问题
"""

from __future__ import division, print_function

from pyfbsdk import *
from pyfbsdk_additions import *

# ---------------------------
# ✅ Py2 / Py3 兼容层
# ---------------------------

try:
    unicode
except NameError:
    unicode = str

try:
    xrange
except NameError:
    xrange = range


def to_unicode(s):
    """安全转换字符串"""
    if isinstance(s, unicode):
        return s
    try:
        return unicode(s)
    except:
        return unicode(str(s))


# ---------------------------
# ✅ 通用工具函数
# ---------------------------

def safe_name(obj):
    """安全获取 Name"""
    try:
        return to_unicode(obj.Name)
    except:
        return u""


def get_selected_models():
    """获取选择对象（安全版）"""
    models = FBModelList()
    FBGetSelectedModels(models)
    return [m for m in models if m is not None]


def safe_iter(iterable):
    """防御式遍历"""
    if iterable is None:
        return []
    return iterable


# ---------------------------
# ✅ 示例逻辑
# ---------------------------

def rename_selected(prefix=u"OBJ_"):
    models = get_selected_models()

    for i, model in enumerate(models):
        if model is None:
            continue

        name = safe_name(model)

        new_name = u"{0}{1}_{2}".format(prefix, name, i)

        try:
            model.Name = new_name
        except Exception as e:
            print(u"[Rename Error]", to_unicode(e))


# ---------------------------
# ✅ UI 示例（安全版）
# ---------------------------

class SimpleTool(object):

    def __init__(self):
        self.tool = None

    def build(self):
        self.tool = FBCreateUniqueTool("MyTool")

        self.tool.StartSizeX = 300
        self.tool.StartSizeY = 100

        # 按钮
        btn = FBButton()
        btn.Caption = "Rename Selected"
        btn.OnClick.Add(self.on_click)

        # 布局
        x = FBAddRegionParam(10, FBAttachType.kFBAttachLeft, "")
        y = FBAddRegionParam(10, FBAttachType.kFBAttachTop, "")
        w = FBAddRegionParam(-10, FBAttachType.kFBAttachRight, "")
        h = FBAddRegionParam(40, FBAttachType.kFBAttachNone, "")

        self.tool.AddRegion("btn", "btn", x, y, w, h)
        self.tool.SetControl("btn", btn)

        ShowTool(self.tool)

    def on_click(self, control, event):
        rename_selected()


# ---------------------------
# ✅ 入口
# ---------------------------

def main():
    tool = SimpleTool()
    tool.build()


if __name__ == "__main__":
    main()
```
