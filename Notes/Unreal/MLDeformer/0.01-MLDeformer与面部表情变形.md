**MetaHuman的面部表情变形完全可以使用 ML Deformer！**

它特别适合**自定义或增强面部表情**，比如用 4D 扫描数据训练出更真实的肌肉滑动、皮肤褶皱、FACS（Facial Action Coding System）变形，超越标准 blendshapes 的局限。

### 为什么适合面部？
| 优势 | 细节 |
|------|------|
| **真实度提升** | 标准 MetaHuman 用骨骼 + blendshapes，容易有 artifacts（如嘴角拉伸不自然）。ML Deformer 学习离线模拟/扫描数据，实现体积保持、动态褶皱。 |
| **性能优秀** | 面部网格小，模型 ~1-5MB，推理 <50μs/帧（GPU），多角色无压力。 |
| **实时驱动** | 完美接 Live Link Face、MetaHuman Animator 或 Control Rig。 |
| **自定义 FACS** | 用工具如 Mesh Morpher 快速生成 30+ 自定义表情，实时播放。 |

### 典型工作流（UE 5.4+ 推荐）
1. **准备训练数据**：
   - 用 Maya/Houdini/Blender 模拟或导入 4D 扫描（.abc 序列，包含多种表情）。
   - 只导出 **head 网格**（排除 eyes/teeth/lashes，避免影响其他组件）。

2. **UE 内训练**：
   - 启用 **ML Deformer Framework** 插件。
   - 创建 **ML Deformer Asset**，导入源 Skeletal Mesh + .abc 序列。
   - 选 **Neural Morph Model (NMM)**（Vertex Delta 有 bug，5.5+ NMM 稳定）。
   - 训练（RTX 显卡几小时）。

3. **运行时绑定**：
   - 在 MetaHuman 的 **Head Skeletal Mesh Component** 加 **ML Deformer Component**。
   - 接骨骼/表情驱动，LOD 支持自动切换。

### 注意事项 & 常见坑
- **组件隔离**：早期版本（如 5.4 Vertex Delta）会“泄漏”变形到 eyes/teeth。用 NMM + 压缩阈值=0 解决。
- **数据质量**：用高保真 4D 数据（如 Pixel Light Effects）效果最佳，否则泛化差。
- **版本**：UE 5.5+ 最稳，结合 Chaos Flesh 可做全脸软体。
- **官方支持**：MetaHuman rig 明确兼容 ML Deformer。
