# **事件节点**

- Event BeginPlay：开始游戏立即触发，游戏开始之后新诞生Actor，诞生时执行一次。

- Event End Play：Actor结束（销毁）时触发（角色死亡时触发）

- Event Tick：事件Tick，当项目开始运行的时候，实时执行（游戏进程中每帧调用的简单事件。按照间隔时间Delta Second不断执行）

- Event Actor Begin Overlap：Actor开始重叠事件（发生重叠的Actor双方必须打开Generate Overlap Event选项）

- Event Actor Begin Overlap：Actor结束重叠事件（发生重叠的Actor双方必须打开Generate Overlap Event选项）

- Event Hit：发生碰撞一瞬间（发生碰撞的Actor之一打开了Generate Hit Event即可）

# **函数**

- 函数，传入参数经过处理，输出返回值，

- 函数可以为 纯（Pure） 类型，也可以为 非纯（Impure） 类型。主要区别在于，纯函数承诺不以任何方式修改状态 或类的成员，而非纯函数可以自由修改状态。纯函数通常用于只输出数据值的 getter函数或运算符。纯函数没有执行线。

- 局部变量只能在函数内使用。

| 设置（Setting） | 说明（Description） | 
| -- | -- |
| 公开（Public） | 公开（Public）设置意味着任何其他对象都可以调用此函数。这是默认设置。 | 
| 受保护（Protected） | 受保护（Protected）设置意味着只能由当前蓝图以及从当前蓝图派生的任何蓝图调用此函数。 | 
| 私有（Private） | 私有（Private）设置意味着只能从当前蓝图中调用此函数。 |

# **宏**

- 蓝图宏（Blueprint Macros） 或 宏（Macros） 本质上与节点的折叠图相同。它们有一个由隧道节点 指定的入口点和出口点。每个隧道都可以有任意数量的执行或数据引脚，当在其他蓝图和图表中使用时， 这些引脚在宏节点上可见。

- 函数只有一个引脚，宏可以有多个输入输出引脚（多指令，根据条件修改指令流分支）

- 可以调用延迟类指令

- 其他蓝图可以调用函数，不能调用宏

- 将多个宏文件组成宏库，可以在其他蓝图中调用。

# Unreal引擎中函数，事件，宏的区别

## 语法上的区别

- **执行引脚:** 调用函数和发射事件只能有一个执行引脚，而宏在调用的时候可以有很多执行引脚进入或者输出。
- **返回值:** 事件被触发了在执行触发事件的逻辑之后，没有返回值，函数和宏有返回值。
- **延迟节点:** 函数和宏可以直接使用延迟节点，而事件需要通过自定义事件来实现延迟。
- **允许访问范围:** 函数和宏可以在任何地方调用，而事件只能在声明事件的类或子类中调用。

## 逻辑区别

- **函数:** 函数是一种代码块，它可以执行一系列操作并返回一个值。函数通常用于封装代码，以便可以重复使用。
- **事件:** 事件是一种通知机制，它允许一个对象通知其他对象发生了某些事情。事件通常用于在对象之间进行通信。
- **宏:** 宏是一种代码替换机制，它允许将一段代码替换为另一个代码。宏通常用于简化代码或提高代码效率。

## 总结

- 函数和宏都用于封装代码，但函数的执行顺序是有保证的，而宏的执行顺序是不确定的。
- 事件用于在对象之间进行通信，它没有返回值，并且只能在声明事件的类或子类中调用。
- 在需要保证执行顺序的情况下，应该使用函数。
- 在需要在对象之间进行通信的情况下，应该使用事件。
- 在需要简化代码或提高代码效率的情况下，可以使用宏。

# **蓝图类和关卡蓝图交互**
