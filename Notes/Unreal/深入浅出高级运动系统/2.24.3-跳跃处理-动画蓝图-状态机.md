### 过渡规则

- 进入Grounded状态
	- 如果MovementState 不为地面状态，则切换到<- Movement State ->导管
	- ![](attachments/2.24.3-跳跃处理-动画蓝图-状态机-1.png)

- <- Movement State ->导管中
	- 如果MovementState 为地面状态，则切换回地面状态Grounded 
	- ![](attachments/2.24.3-跳跃处理-动画蓝图-状态机-4.png)
	- 如果MovementState 为InAir，则过渡到-> InAir导管
	- ![](attachments/2.24.3-跳跃处理-动画蓝图-状态机-5.png)

- InAir导管
	- 如果MovementState 不为InAir，则回到<- Movement State ->导管
	- ![](attachments/2.24.3-跳跃处理-动画蓝图-状态机-7.png)
	-  如果Jumped为真，进入Jumped状态
	- ![](attachments/2.24.3-跳跃处理-动画蓝图-状态机-14.png)
	- 如果MovementState为InAir，进入Fall状态，这一条优先级为2
	- ![](attachments/2.24.3-跳跃处理-动画蓝图-状态机-15.png)
- Jump状态
	- 如果MovementState不为InAir，则回到-> InAir导管
	- ![](attachments/2.24.3-跳跃处理-动画蓝图-状态机-16.png)
	- 直接过渡到-> Land导管
	- ![](attachments/2.24.3-跳跃处理-动画蓝图-状态机-27.png)
- Fall状态
	- 如果MovementState不为InAir，则回到-> InAir导管
	- ![](attachments/2.24.3-跳跃处理-动画蓝图-状态机-28.png)
	- 直接过渡到-> Land导管
	- ![](attachments/2.24.3-跳跃处理-动画蓝图-状态机-29.png)
- -> Land 导管
	- 直接过渡到Land状态
	- ![](attachments/2.24.3-跳跃处理-动画蓝图-状态机-29.png)
	- 如果有位移的旋转输入，则过渡到Land Movement状态
	- ![](attachments/2.24.3-跳跃处理-动画蓝图-状态机-30.png)
- Land状态
	- 如果有位移的旋转输入，或移动速度大于650，进入Land Movement状态
	- ![](attachments/2.24.3-跳跃处理-动画蓝图-状态机-31.png)
	- 如果动画播放完毕，进入Grounded状态
	- ![](attachments/2.24.3-跳跃处理-动画蓝图-状态机-32.png)
	- 如果movement state 不为Grounded或者Stance不为Stand，强制进入进入Grounded状态
	- ![](attachments/2.24.3-跳跃处理-动画蓝图-状态机-33.png)
- LandMovement状态
	- 采用自动过渡到Grounded状态
	- ![](attachments/2.24.3-跳跃处理-动画蓝图-状态机-34.png)
	- 如果movement state 不为Grounded或者Stance不为Stand，强制进入进入Grounded状态
	- ![](attachments/2.24.3-跳跃处理-动画蓝图-状态机-35.png)
