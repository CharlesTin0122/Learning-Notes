下面给出**FACS（Action Units）与 ARKit 52 BlendShapes（Face Tracking）**之间的**逐项对应关系表（业内通用映射）**。  
这是绑定、面捕数据清洗、MetaHuman/UE 面部驱动时最常用的参考表。

> ⚠ 注：ARKit 52 并不是纯 FACS 体系，而是“Apple 定义的表情形变集”。  
> 因此对应关系是 **基于功能 + 活动区域** 的行业通用映射，而非 1:1 生物学严格对应。

---

# ✅ **FACS → ARKit 52 BlendShapes 对照表（完整版）**

格式：

```
[ARKit blendShape]  ←  FACS AU（典型动作）
```

---

# 🎯 **1. 眉部（Brows）**

|**ARKit 名称**|**对应 FACS**|说明|
|---|---|---|
|browInnerUp|**AU01 内眉上抬**|非常典型|
|browOuterUpLeft / Right|**AU02 外眉上抬**|左右独立|
|browDownLeft / Right|**AU04 眉下压**|等价于 AU04|
|eyeSquintLeft / Right|**AU06 颧肌提升（眯眼）**|ARKit 将 AU06 拆成 squint 与 cheek|

---

# 🎯 **2. 眼睛（Eyes）**

|ARKit|FACS|说明|
|---|---|---|
|eyeWideLeft / Right|**AU05 上眼睑提升**|惊讶|
|eyeBlinkLeft / Right|**AU45 眨眼**||
|eyeLookUp / Down / Left / Right|**非 FACS**|这是眼球旋转控制，不属于 FACS|
|eyeSquintLeft / Right|**AU06**|与上面重复|

# 🎯 **3. 鼻部（Nose）**

# 🎯 **4. 嘴部（Mouth / Lips）**

|mouthDimpleLeft / Right|**AU14 酒窝肌**||

# 🎯 **5. 颚（Jaw）**

|ARKit|FACS|说明|

FACS 对下颌只有 AU26/27/29，而 ARKit 划分更机械化。

AU09 → noseSneer
AU10 → mouthUpperUpLeft/Right
AU12 → mouthSmileLeft/Right
AU14 → mouthDimple
AU15 → mouthFrownLeft/Right
AU16 → mouthLowerDownLeft/Right
AU17 → chinRaise
AU18 → mouthPucker
AU20 → mouthStretchLeft/Right
AU22 → mouthFunnel / mouthRollUpper
AU23 → mouthFunnel / mouthRollUpper
AU24 → mouthPress / mouthClose（不完全对应）
AU26 → jawOpen
AU27 → jawOpen（大幅度）
AU34 → cheekPuff
AU45 → eyeBlinkLeft/Right
```

```
