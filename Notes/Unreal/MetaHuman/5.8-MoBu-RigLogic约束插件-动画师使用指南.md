# 5.8 MoBu RigLogic 约束插件 · 动画师使用指南

> 面向**动画师**的操作手册——如何在 MotionBuilder 2024 中安装和使用 RigLogic 约束插件，
> 让 MetaHuman 角色的**身体修形**与**面部表情**在摆姿势、播放、导出时全自动工作。
> 技术原理与开发细节见 [5.7 C++RigLogic约束插件](5.7-MoBu-C%2B%2BRigLogic%E7%BA%A6%E6%9D%9F%E6%8F%92%E4%BB%B6-OpenReality.md)；
> 插件与 OpenRigLogic 库的关系见 [5.9 原理解析](5.9-MoBu插件如何使用OpenRigLogic-原理解析.md)。

## 一、插件是什么

一个 MoBu 原生插件（`moburiglogic.dll`），提供两个约束：

| 约束                           | 作用                                   | 通俗理解                                    |
| ---------------------------- | ------------------------------------ | --------------------------------------- |
| **RigLogic Body Corrective** | 身体修形：肘/膝/肩/腕等 258 个修形骨骼跟随姿势自动变形      | 相当于 Maya 官方 MetaHuman 绑定里的身体修形，弯胳膊肘不再穿插 |
| **RigLogic Head Expression** | 面部表情：840 个面部骨骼 + BlendShape，支持表情面板驱动 | 拖 FaceBoard 面板控制器，脸会动；K 面板动画，播放出表情      |

特点（相比脚本方案）：
- **播放、拖时间线、Plot 烘焙、渲染导出全程有效**——不是"只在停下来时才对"
- 修形骨骼被约束接管（属性变灰），**不会被误移动/误 K 帧**
- 性能极高（双约束合计约 0.45ms/帧），几十个角色也不卡
- 支持**多角色**：不同 namespace 的角色各建各的约束，互不干扰

## 二、安装

### 需要的文件

| 文件 | 说明 |
|---|---|
| `moburiglogic_2024.dll` | 插件本体（构建产物在 `D:\Code\MoBuRigLogic\build\Release\`） |
| `body.dna` | 身体 DNA（角色资产，如 `D:\Code\MoBuMetaHuman\assets\body.dna`） |
| `head.dna` | 头部 DNA（同上目录） |

### 安装步骤

1. **关闭 MotionBuilder**（插件文件被占用时无法替换）
2. 把 `moburiglogic_2024.dll` 复制到：
   ```
   C:\Program Files\Autodesk\MotionBuilder 2024\bin\x64\plugins\
   ```
   （需要管理员权限；也可用 `MOTIONBUILDER_PLUGIN_PATH` 环境变量指向自定义目录）
3. 启动 MotionBuilder 2024
4. 验证：打开 **Asset Browser → Templates → Constraints**，能看到
   **RigLogic Body Corrective** 和 **RigLogic Head Expression** 即安装成功
   （或在 Navigator 里 Constraints 右键 → 新建列表中查看）

> ⚠️ 仅支持 **MotionBuilder 2024**（Windows x64）。插件与 MoBu 版本严格一对一
> （版本命名空间隔离），其他版本装了不会报错但约束不出现。

## 三、快速上手：给角色挂上修形和表情

前提：场景里有 MetaHuman 角色（骨架命名与 DNA 一致，如 H10100 的 AllMesh 场景）。

### 3.1 身体修形（Body Corrective）

1. Navigator → Constraints → 右键 **Create → RigLogic Body Corrective**
2. 选中新约束，打开 **Setup 页签**（自定义面板）：
   - 点 **Browse...** 选择 `body.dna`（或直接在编辑框填路径后点 Rebuild Bindings）
   - **LOD Level** 在 Properties 页签，保持 0（最高质量）
3. 把角色的 **pelvis** 骨骼（骨架里任意一根都行，习惯用根）拖进约束的
   **Skeleton Root** 引用组
4. 勾选 **Active** ✔ → Setup 面板状态区变为 **Bindings OK** + 绑定统计
5. 完成——弯膝盖试试：`calf_l` 绕 Z 转 90°，膝盖后侧的修形骨骼会自动缩放平移

### 3.2 面部表情（Head Expression）——FaceBoard 面板驱动（推荐）

1. **Merge 表情面板**：File → Merge 你的 FaceBoard 资产
   （如 `SK_MH_FaceBoard.fbx`，里面是 CTRL_C_jaw、CTRL_L_eye_blink 等控制器）
2. Navigator → Constraints → **Create → RigLogic Head Expression**
3. **Setup 页签**（自定义面板）：
   - 点 **Browse...** 选择 `head.dna`
   - **Input Mode** 下拉选 **FaceBoard Panel**（切换会自动重建绑定）
4. 把 **head** 骨骼拖进 **Skeleton Root** 引用组
5. 勾选 **Active** ✔ → 状态区显示 "Bindings OK (FaceBoard mode)" + 174 panel controls
6. 完成——拖 `CTRL_C_jaw` 往下（ty=1），嘴张开；拖 `CTRL_L_eye.tx`，眼球转动

> Setup 面板的状态区会自动刷新（约每秒），排查问题先看它：三种状态分别给出下一步操作指引。

### 3.3 表情的另一种玩法：属性直驱模式

**Input Mode 保持 0**（默认）时，约束自己身上会出现 **252 个表情属性**
（jawOpen、mouthCornerPullL、eyeBlinkL……）：

- 在属性面板直接拖数值 → 脸实时变
- 右键属性 → **Animated** → 可以直接给表情 K 帧
- 可以被 Relation Constraint / 脚本 / Story 驱动

适合：没有面板资产的场景、程序化批量做表情、捕捉数据直灌。

> Input Mode 切换后需要 **Active 关→开** 一次让绑定重建。

## 四、日常工作流

### K 面板表情动画

面板控制器就是普通物体——**直接对控制器 K 位移**即可：

1. 选中 `CTRL_C_jaw`，在 ty 上 K 帧（0 帧 =0，30 帧 =1，60 帧 =0）
2. 播放：嘴 40°→62°→40° 平滑开合，BlendShape 同步
3. 从 Maya 导出的面板动画 FBX，merge 进来**直接就能播**——三端（Maya/UE/MoBu）共用同一套面板动画

### 身体动画

正常 K 骨骼/用 Character 系统/导入动捕——修形骨骼全自动跟随，**不需要**也**不应该**手动碰修形骨骼（它们已被约束占用）。

### Plot / 烘焙导出

约束在求值图内，Plot 时修形和表情会一起烘进曲线。导出给引擎前照常 Plot 到骨骼即可。

### 保存场景

约束随 `.fbx` 场景保存：DNA 路径、Active 状态、骨架引用都会恢复，重开场景不用重新设置。
（前提：DNA 文件路径没变——换机器时保持 DNA 相对位置一致或重填路径。）

## 五、多角色场景

每个角色**各建一套约束**，按 namespace 自动隔离：

1. Merge 角色时给每个角色设置不同 **namespace**（如 CharA、CharB）
2. 给 CharA 建约束时，把 **CharA:head / CharA:pelvis** 拖进引用组
3. 约束只认自己 namespace 下的骨骼、网格、面板——A 的面板只动 A 的脸

实测：双角色双约束同开，各自面板独立驱动，无跨角色串扰。

## 六、常见问题（FAQ）

| 现象                 | 原因与解决                                                                                |
| ------------------ | ------------------------------------------------------------------------------------ |
| 约束列表里没有 RigLogic 项 | DLL 没装对位置 / MoBu 版本不是 2024 → 检查 plugins 目录                                           |
| Active 勾了但没反应      | ① DNA Path 路径错（检查文件存在）② Skeleton Root 引用组是空的 ③ 骨架命名与 DNA 不匹配（namespace 场景确认拖的是本角色骨骼） |
| 表情面板拖了脸不动          | ① Input Mode 不是 1 ② 面板没 merge 进来或 namespace 不匹配 ③ 改完 Input Mode 没有重开 Active          |
| 表情属性面板上找不到 jawOpen | Input Mode=1 时不创建表情属性（两种模式二选一），切回 0 并重开 Active                                       |
| BlendShape 不动（骨骼动） | 场景里没有带 shape 属性的 LOD0 面部网格（AllMesh 场景才有全套 BS）                                        |
| 修形骨骼想手动调           | 约束占用中不可手调；临时关 Active 可恢复自由（表情/修形归零）                                                  |
| 修改了 DNA 文件         | 重开 Active（或重开场景）让 DNA 重新加载                                                           |
| 性能观测               | 约束属性 **Last Solve Ms** 实时显示单次求解耗时（正常 <1ms）                                           |

## 七、能力边界（提前知道，少走弯路）

- 头身是**两个独立约束**，各配各的 DNA——只做表情可以不建 Body 约束
- 表情两种输入模式**互斥**（面板 or 属性，同一时刻只有一种生效）
- 面部（head.dna）没有缩放输出，身体（body.dna）有——正常现象
- 约束不创建骨骼/网格——场景里得先有完整的 MetaHuman 角色资产
