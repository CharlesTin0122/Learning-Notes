# ✅ **FACS → BlendShape Library 构建流程（Rigging 实操版）**

下面按生产线分 7 步，从输入到输出，每一步包含：

- **目标**
    
- **输入数据**
    
- **核心技术点**
    
- **在 Maya / UE / MetaHuman 类型流程中的具体操作**
    

---

# **1. 采集 FACS 表情基础样本（FACS Capture）**

### 🎯 目标

建立一个“标准动作库”，每个 AU 对应最纯粹的激活形态。

### 📥 输入

- 演员 3D 扫描 / Photogrammetry / 多视角拍摄
    
- FACS 专业指导下采集全部 AU（约 35 个主要 + 约 20 个组合）
    

### 🔧 技术点

- 必须确保动作是“单 AU activation”
    
- 确保中性态 Neutral 的干净度（没有情绪偏移）
    
- 对齐相机、光照一致，保证表情形变干净
    

### ⚙️ 实操

- 使用 **多摄像机阵列**（3DF Zephyr / RealityCapture / Metahuman Scanner）
    
- 输出 1 张 neutral mesh + 多张 FACS pose mesh
    

示例：

```
Neutral
AU01 + AU02 + AU04 + AU06 + AU12 + AU14
AU17 + AU20 + AU23 + AU24 + AU26
……
```

---

# **2. FACS Mesh Alignment（拓扑统一 + Mesh 注册）**

### 🎯 目标

将所有扫描几何统一为**同一拓扑**，便于后续做 BlendShape。

### 📥 输入

- 多个扫描 mesh（拓扑不一致）
    
- Neutral 模型（目标拓扑）
    

### 🔧 技术点

使用 wrap / non-rigid registration 将不同拓扑的扫描 wrap 到统一拓扑。

### ⚙️ 工具链

- R3DS Wrap（最常用）
    
- Wrap4D（动画序列）
    
- Faceware Retopo / ZBrush Project All（弱）
    

### ⚙️ 实操步骤

1. 将 Neutral 设为“base mesh”
    
2. 对每个 AU 扫描做 **Non-rigid Wrap → Transfer Shape**
    
3. 确保眼角、唇线、鼻翼等区域误差低于 0.3mm
    

产出：

```
neutral.fbx  
AU01.fbx  
AU02.fbx  
AU04.fbx  
AU06.fbx  
……
```

---

# **3. 建立 BlendShape Library（单 AU → BS）**

### 🎯 目标

把每个 FACS Pose 转成干净的 BlendShape，作为绑定的表情库。

### 📥 输入

- FACS 注册后的 mesh
    

### 🔧 技术点

失败 BS 的常见问题：

- 含有多 AU 混合（需要清理）
    
- 眼/牙交叉问题
    
- 下颌/面颊不干净
    

需要**强制确保每个 BS 只代表单一 AU**。

### ⚙️ Maya 实操流程

1. 导入 neutral + AUxx mesh
    
2. 每个 AU 建一个 BlendShape target
    
3. 使用 Maya Sculpt Tools / ZBrush 做清理
    
4. 手工分离：
    
    - 上脸 AU（眼眉）
        
    - 下脸 AU（颊/唇）
        
    - 下颌 AU
        
5. 标准命名规则：
    

```
BS_AU01_InnerBrowRaise
BS_AU02_OuterBrowRaise
BS_AU04_BrowLower
BS_AU06_CheekRaise
BS_AU12_Smile
BS_AU14_Dimpler
……
```

产出：  
一个**约 50～80 个 BS** 的库（取决于项目风格）

---

# **4. BlendShape Cleanup（技术清理和矫正）**

### 🎯 目标

提高面部可控性，使其能与下游动画系统搭配使用。

### 📥 输入

- 初级 BS Targets
    

### 🔧 技术点

- 对称 BS 自动镜像（Maya BlendShape Mirror）
    
- 清理耳朵/颈部等区域
    
- 分离眼皮 → 上眼皮、下眼皮
    
- 分离嘴唇 → 上唇、下唇
    
- 下颌旋转由骨骼驱动，BS 只做二级修型（JNT+BS Hybrid）
    

### ⚙️ 实操

- 约束嘴角轨迹（Lip Corner Path）
    
- 修正内唇体积
    
- 与牙齿碰撞（Push Out Tool）
    
- 移除面颊噪点
    

---

# **5. AU → BS 映射（FACS 逻辑 → 数学权重）**

### 🎯 目标

让动画系统根据 AU 数值激活对应的 BlendShape。

### 📥 输入

- AU 数值（0～1）
    
- BlendShape Targets
    

### 🔧 数学逻辑模型

RigLogic/MetaHuman 内部实际使用**两阶段**：

---

### **（1）AU → Raw Curve（线性/非线性映射）**

例如 AU12（微笑）通常是线性增强：

```
BS_AU12 = AU12
```

AU01 + AU02（眉提升）一般是非线性/阻尼：

```
BS_AU01 = max(0, AU01 - 0.2)
BS_AU02 = max(0, AU02 - 0.1)
```

---

### **（2）BS Conflict Resolve（互斥修整）**

如 AU12（微笑）和 AU14（嘴角收紧）不能同时强激活

```
BS_AU12 = BS_AU12 * (1 - BS_AU14)
```

AU04（皱眉）与 AU01/02（扬眉）互斥：

```
BS_AU04 = BS_AU04 * (1 - (BS_AU01 + BS_AU02))
```

---

# **6. BlendShape → RigLogic 结构生成（MetaHuman/UE 专用）**

### 🎯 目标

将 BS 权重、骨骼修形、组合逻辑全部写入 DNA。

### 📥 输入

- BlendShape mesh
    
- BS → Joint Corrective 表（如 jawOpen 修型）
    
- FACS 映射规则
    

### 🔧 技术点

**RigLogic 中的 3 层函数：**

---

## **RigLogic 计算链（核心数学流程）**

### **Stage 1：Control → RawControls**

AU 数值输入

```
raw[i] = f(control[i])
```

### **Stage 2：RawControls → NeuralNet （线性层）**

MetaHuman 早期版本使用 PCA  
现在是 “rig matrix”（矩阵乘法）

```
rawControls = W * controls + B
```

### **Stage 3：RawControls → Blendshape + Joint delta（多段 piecewise 线性）**

```
bs[i] = Σ  rawControls[j] * Weight(j→i)
jointDelta[k] = Σ rawControls[j] * JointWeight(j→k)
```

### **Stage 4：SolveNonLinearConflicts（内置 AU 冲突解算）**

嘴角、眉毛区域用 clamped functions：

```
val = clamp(0, 1, val)
```

# **7. 导出/部署（可用于 UE、MetaHuman、电影管线）**

### 🎯 目标

所有控件行为在引擎中可实时驱动，且不破坏体积 / 牙齿 / 碰撞。

### 📥 输入

- DNA 文件（MetaHuman）
    
- 或 BlendShape + Control curves（非 MH 项目）
    
- 或 Joint corrective（jaw、cheek、lip roll）
    

### ⚙️ 部署方式

1. **UE + RigLogic**（必须 DNA）
    
2. Maya + Local Rig（纯 BS or BS + JNT hybrid）
    
3. Face mocap → AU → RigLogic → Final mesh
    
4. 游戏中 runtime：
    
    - LiveLink Face（ARKit）
        
    - FACS ML model
        
    - Audio-driven ML（如 Cubic Motion）

这是目前业界最标准、最成熟的“面部高保真绑定”生产链，也是 MetaHuman 内部采用的方法。
