# ⭐ 总览：FACS → Facial Rig 的核心思想

面部 Rig 的核心理念：

> **把每个 AU 的最纯净形变 → 抽象成一个可控、可混合的 Rig 通道（控制器/权重）。  
> 再用这些 AU 通道按照数学规则合成所有表情。**

也就是说：

- **FACS 是输入 → BlendShape 是技术化形变 → Rig 是操控界面**
    

你要做的是：

```
FACS AU → 数据采集 → BS Library → AU Control System → 组装成脸控
```

# 🔥《技术动画工作流：基于 FACS 的面部 Rig 生产全流程》

下面是 9 大步骤，每一个步骤都能直接用于生产。

# **STEP 1：确定 FACS 控制体系（AU Selection）**

你不需要实现全部 46 个 AU。

**电影级：约 50–60 控件**  
**游戏级：约 30–45 控件**

推荐的 AU 分组（游戏/实时）：

### ✔ 上半脸（Brows）

- AU1 Inner Brow Raise
    
- AU2 Outer Brow Raise
    
- AU4 Brow Lower
    
- AU6 Cheek Raise（上眼眯眼也在这里）
    
- AU7 Lid Tighten
    

### ✔ 眼部（Eyes）

- AU5 Upper Lid Raise
    
- AU45 Blink
    
- Eye Direction（非 FACS）
    

### ✔ 鼻部（Nose）

- AU9 Nose Wrinkle
    
- AU38/39 鼻翼扩张（项目可选）
    

### ✔ 嘴部（Mouth/Lip）

- AU10 Upper Lip Raise
    
- AU12 Lip Corner Pull
    
- AU14 Dimpler
    
- AU15 Lip Corner Depress
    
- AU16 Lower Lip Depress
    
- AU17 Chin Raise
    
- AU18 Lip Pucker
    
- AU20 Lip Stretch
    
- AU22/23/24 Lip Tighten/Press/Roll
    
- AU26 Jaw Open
    

### ✔ 下颌（Jaw）

- AU26 Jaw Open
    
- Jaw Side / Forward（非 FACS）
    

> 📌 关键：  
> FACS 是“纯行为单元”。Rig 控制器必须与 AU 一一对应（或合并）。

---

# **STEP 2：扫描/采集 FACS Pose（Data Acquisition）**

如果有扫描设备，流程如下：

### 输入：

- Neutral
    
- AU1, AU2, AU4, AU5, AU6 … AU27（严格执行 FACS）
    

### 输出：

- 每个 AU 的“真实形变参考”（mesh）
    

> 技术动画重点：**捕捉到的 FACS 数据必须是“单动作、最大值”形变**。  
> 这是构建 BS Library 的黄金标准。

---

# **STEP 3：拓扑统一（Topology Registration）**

使用 R3DS Wrap / Wrap4D：

```
Neutral mesh 作为 Base → 把所有 AU mesh wrap 到相同拓扑
```

保证所有 AU 的 vertex order 完全一致。

---

# **STEP 4：构建 BlendShape Library（BS Target Production）**

这一步是面部 Rig 最关键的部分。

### 任务是：

**把每个 AU 扫描 → 转成干净、可混合的 BlendShape Target。**

### 操作步骤：

1. 载入 Neutral + AU Mesh
    
2. 对每个 AU 建一个 BS Target
    
3. 在 Maya/ZBrush 清理问题：
    
    - 鼻翼穿插
        
    - 嘴唇漏光
        
    - 眼睑与眼球碰撞
        
4. 分离形变：
    
    - 上唇 / 下唇 分开
        
    - 左 / 右 独立（适用于 AU12/15/20 等）
        
5. 导出一个完整的 **BS Library**：
    

通常游戏项目需要 **50～80 个 BS target**。

---

# **STEP 5：BS + Joint 混合驱动体系设计（Hybrid Rig）**

100% BS 的 Rig 会出现问题：

- 开嘴时体积丢失
    
- 嘴唇裹牙困难
    
- 面颊靠 BS 不自然
    
- 皱纹跟随需要骨骼辅助
    

所以行业最佳解是：

> **骨骼（Primary）负责大形变**  
> **BlendShape（Secondary）负责细节修型**

### 常见骨骼驱动：

- jaw_Open（下颌旋转）
    
- cheekUp（面颊提升）
    
- lip_Up/Lip_Down（唇基线旋转）
    
- eyelid_Upper/Lower（物理旋转）
    

BS 则负责：

- 唇线弯曲
    
- 面颊体积
    
- 嘴角轨迹
    
- 鼻翼形变
    
- 下颌开合的二级形变
    

---

# **STEP 6：设计 AU 控制系统（Rig Logic Layer）**

这是“核心数学层”，类似 MetaHuman RigLogic。

总体结构：

```
Control → Raw AU → Combined AU → BS + Joint Weights
```

含三类数学逻辑：

---

### ✔ ① 线性层（Linear Mapping）

每个 AU 的基本权重：

```
BS_AU12 = AU12
BS_AU04 = AU04
```

---

### ✔ ② 非线性 / 区间映射（Corrective）

例如 AU1 + AU2 的眉毛互斥：

```
AU1_eff = AU1 * (1 - AU4)
AU4_eff = AU4 * (1 - max(AU1, AU2))
```

嘴角 AU12/AU14 冲突：

```
Smile_eff    = AU12 * (1 - AU14)
Dimple_eff   = AU14
```

---

### ✔ ③ 组合 BS（Corrective BS）

某些形变只在多 AU 同时触发时出现：

```
AU12 + AU17 → lipCornerRaiseFix
AU04 + AU05 → browFrownUpperLid
AU10 + AU26 → upperLip_jawOpenFix
```

你需要额外 sculpt **约 10～30 个组合修形**。

---

# **STEP 7：Rig 控件系统（Controller Interface）**

在 Maya 中设计操控界面：

- Brows：左右 + 中间
    
- Eyes：blink, look, wide
    
- Nose：flare
    
- Lips：corner, up, down, pucker, stretch
    
- Jaw：open, side
    

控制器通常不直接驱动点，而是驱动：

```
Controller → AU Value → Weight → BS/JNT
```

这让 Rig 易于调节且便于动画师使用。

---

# **STEP 8：测试与修正（QC / Animation Test）**

技术动画的关键流程：

### 测试内容：

- 所有 AU 单独激活：是否干净？
    
- AU 混合：是否有穿帮？
    
- 嘴角轨迹是否平滑？
    
- 眼睑是否与眼球碰撞？
    
- 牙齿遮挡是否稳定？
    
- 开嘴是否破体积？
    

常见修复：

- 加 Corrective BS
    
- 加局部骨骼
    
- 调整 AU 互斥规则
    
- 调整 weight falloff 区域
    

---

# **STEP 9：部署到 UE / DCC（MetaHuman 风格）**

如果要做 MetaHuman 风格的 RigLogic，可导出：

- Controls（AU）
    
- Joints + skin weights
    
- BlendShapes
    
- 控制映射矩阵（W,B）
    
- Corrective BS 触发规则
    

最终可制成：

- **DNA 文件（RigLogic）**
    
- 或 Maya 控件 Rig
    
- 或项目专用 facial rig
