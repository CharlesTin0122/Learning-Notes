# OpenRigLogic 编译结果使用指南

> 前置：[编译指南](5.2-OpenRigLogic编译指南.md)（产物：`D:\Code\OpenRigLogic\dist\py310\` 下 4 个文件）。
> 原理背景：[RigLogic架构设计](5.1-RigLogic架构设计-OpenRigLogic.md)。
> 以下代码均在 Maya 2024（Python 3.10.8）实测通过（2026-07）。

## 一、产物是什么

| 文件 | 角色 |
|---|---|
| `dna.py` + `_py3dna13_2_5.pyd` | **DNA 库**：读写 MetaHuman .dna 文件（Descriptor/Definition/Behavior/Geometry 全层） |
| `riglogic.py` + `_py3riglogic13_2_5.pyd` | **RigLogic 求解器**：输入控制器值 → 输出关节变换/BS权重/遮罩乘数 |

两个模块相互独立又配合使用：`riglogic.RigLogic()` 直接接受 `dna` 的 reader 对象。

## 二、环境加载

### 通用加载方式

```python
import sys
sys.path.insert(0, r"D:\Code\OpenRigLogic\dist\py310")
import dna
import riglogic
```

适用于：Maya 2024 Script Editor / mayapy、MotionBuilder 2024、任何独立 Python 3.10。

### ⚠️ Maya 中的模块遮蔽问题

装有官方 MetaHumanForMaya 插件的 Maya 会**预先注入同名的 `dna` 模块**（旧版本 DNA 10.1.4；注意官方**不提供** `riglogic` Python 绑定，其求解封在 embeddedRL4.mll C++ 插件里）。直接 import 拿到的是官方版。需要强制用自编版时先清缓存：

```python
import sys
# 清掉官方插件占用的模块缓存
for name in list(sys.modules):
    if name in ("dna", "riglogic") or name.startswith(("_py3dna", "_py3riglogic")):
        del sys.modules[name]
sys.path.insert(0, r"D:\Code\OpenRigLogic\dist\py310")
import dna, riglogic
print(dna.__file__)   # 确认指向 D:\Code\OpenRigLogic\dist\py310\dna.py
```

> 反之，如果只是想读 DNA 而 Maya 已装官方插件，直接 `import dna` 用官方版也完全可以——两者 API 兼容。

## 三、dna 模块：读取 DNA

### 打开文件

```python
path = r"D:\xxx\head.dna"   # MetaHuman Creator 的 DCC Export 导出，或其他来源
stream = dna.FileStream(path, dna.FileStream.AccessMode_Read, dna.FileStream.OpenMode_Binary)
reader = dna.BinaryStreamReader(stream, dna.DataLayer_All)
reader.read()
assert dna.Status.isOk(), dna.Status.get().message   # 错误检查习惯：每次 read/write 后检查
```

`DataLayer_*` 控制加载哪些层（**只读部分层可大幅省内存**）：

| 常量 | 内容 | 典型用途 |
|---|---|---|
| `DataLayer_Descriptor` | 角色名、archetype、坐标系等元数据 | 快速检视 |
| `DataLayer_Definition` | 关节/BS/控制器的名称、层级、映射 | 结构分析 |
| `DataLayer_Behavior` | PSD/线性/条件矩阵（RigLogic 求解所需） | 运行时求解 |
| `DataLayer_Geometry` | 顶点、法线、UV、蒙皮权重、BS delta | 网格重建/导出 |
| `DataLayer_MachineLearnedBehavior` | ML 变形层（RigLogic4 新增） | 高保真求解 |
| `DataLayer_RBFBehavior` / `DataLayer_TwistSwingBehavior` | RBF 姿态驱动 / 扭转摆动（身体 DNA 用） | 身体求解 |
| `DataLayer_All` | 全部 | 通用 |

### 常用查询（Definition 层）

```python
reader.getName()                    # 角色名，如 'Archetype'
reader.getLODCount()                # LOD 数（MetaHuman 头 = 8）
reader.getJointCount()              # 关节数（头 = 870）
reader.getJointName(i)              # 关节名
reader.getJointParentIndex(i)       # 父关节下标（根关节返回自身下标）
reader.getBlendShapeChannelCount()  # BS 通道数（头 = 782）
reader.getBlendShapeChannelName(i)
reader.getMeshCount() / reader.getMeshName(i)     # 各 LOD 网格
reader.getRawControlCount()         # 输入控制器数（头 = 263）
reader.getRawControlName(i)         # 如 'CTRL_expressions.jawOpen'
reader.getGUIControlCount() / reader.getGUIControlName(i)   # GUI 层控制器
```

### 中立姿态与几何（Geometry 层）

```python
# 关节中立值（骨架重建用）
reader.getNeutralJointTranslation(jointIdx)   # -> (x, y, z)
reader.getNeutralJointRotation(jointIdx)      # -> 欧拉角

# 网格几何（meshIdx 对应 getMeshName 的下标）
reader.getVertexPositionCount(meshIdx)
reader.getVertexPosition(meshIdx, vtxIdx)     # -> (x, y, z)

# 蒙皮权重
reader.getSkinWeightsCount(meshIdx)
reader.getSkinWeightsValues(meshIdx, vtxIdx)        # 权重数组
reader.getSkinWeightsJointIndices(meshIdx, vtxIdx)  # 对应关节下标数组

# BlendShape delta
reader.getBlendShapeTargetCount(meshIdx)
reader.getBlendShapeTargetDeltas(meshIdx, targetIdx)        # 稀疏 delta
reader.getBlendShapeTargetVertexIndices(meshIdx, targetIdx) # 受影响顶点
```

> Reader 共 **187 个方法**，覆盖 DNA 全部数据；命名规律为 `get<层><字段>`，用 `dir(reader)` + 补全探索即可。

## 四、dna 模块：写 DNA

`BinaryStreamWriter` 提供 **175 个 set 方法**，与 Reader 一一对应。最常用的模式是"**读入 → 修改 → 写出**"：

```python
# 读入原 DNA
inStream = dna.FileStream(srcPath, dna.FileStream.AccessMode_Read, dna.FileStream.OpenMode_Binary)
reader = dna.BinaryStreamReader(inStream, dna.DataLayer_All)
reader.read()

# 建 writer 并整体拷贝
outStream = dna.FileStream(dstPath, dna.FileStream.AccessMode_Write, dna.FileStream.OpenMode_Binary)
writer = dna.BinaryStreamWriter(outStream)
writer.setFrom(reader)              # 完整复制所有层

# 定点修改（示例：改名 + 改一个关节的中立位移）
writer.setName("MyCharacter")
writer.setNeutralJointTranslations([...])   # 批量接口

writer.write()
assert dna.Status.isOk()
```

典型 Writer 方法族（与 [架构笔记](5.1-RigLogic架构设计-OpenRigLogic.md) 的 behavior 层结构对应）：

- 关节：`setJointName / setJointHierarchy / setNeutralJointTranslations / setJointGroup*`（joint group 的 LODs、input/output indices、values——即块稀疏矩阵的序列化）
- BS：`setBlendShapeChannelName / setBlendShapeChannelInputIndices / setBlendShapeChannelOutputIndices / setBlendShapeTargetDeltas`
- 遮罩：`setAnimatedMap*`（From/To/Slope/Cut——条件矩阵参数）
- 几何：`setVertexPositions / setSkinWeightsValues / ...`

> ⚠️ **加新关节/新 BS 通道**：Writer API 允许写任意数量条目，但必须**自行维护 behavior 层索引一致性**（joint group 的 output indices、LOD 映射等），否则 UE/RigLogic 加载会出错。这正是 SuperRiggingEditor 产品化了的部分。改**已有**条目的数值则安全得多。

## 五、riglogic 模块：运行时求解

### 最小工作流

```python
# 1. 加载 DNA（Behavior 层必需；只求解不重建网格可不加载 Geometry）
stream = dna.FileStream(path, dna.FileStream.AccessMode_Read, dna.FileStream.OpenMode_Binary)
reader = dna.BinaryStreamReader(stream, dna.DataLayer_All)
reader.read()

# 2. 构建求解器（RigLogic = 只读共享数据；RigInstance = 每角色实例的输入输出状态）
rig  = riglogic.RigLogic(reader)
inst = riglogic.RigInstance(rig)

# 3. 设置输入 → 求解 → 取输出
idx = [reader.getRawControlName(i) for i in range(reader.getRawControlCount())].index("CTRL_expressions.jawOpen")
inst.setRawControl(idx, 1.0)
rig.calculate(inst)

joints = inst.getJointOutputs()        # 长度 = 关节数 × 9（tx ty tz rx ry rz sx sy sz 增量）
bs     = inst.getBlendShapeOutputs()   # 长度 = BS 通道数
maps   = inst.getAnimatedMapOutputs()  # 遮罩乘数（皱纹贴图权重）
```

**输出解读**：

- 关节输出是**相对中立姿态的增量**：`joints[j*9+0..2]`=平移增量，`[3..5]`=旋转增量（默认欧拉角），`[6..8]`=缩放增量。应用方式 = 中立值 + 增量
- 每帧循环只需重复第 3 步（设输入 → calculate → 读输出）；RigLogic 对象可被多个 RigInstance 共享（多角色同 DNA 时省内存）

### 实测数据（MetaHuman Archetype head.dna）

jawOpen=1.0 时：667 个关节有非零增量（下颌+颈部+嘴周 IPV 关节），BS 输出中 `jaw_open`=1.0——链路与 UE 内表现一致。

### GUI 控制 vs Raw 控制

```python
inst.setGUIControl(i, v)        # GUI 层（faceboard 控制器空间）
rig.mapGUIToRawControls(inst)   # GUI -> raw 映射（含范围重映射）
# 之后照常 rig.calculate(inst)
```

如果输入直接来自动画数据（如 UE 导出的 raw 曲线）用 `setRawControl`；来自 faceboard UI 用 GUI 路径。

### LOD 控制

```python
inst.setLOD(2)          # 切到 LOD2：calculate 只算该 LOD 需要的关节/BS（近零开销切换）
rig.getJointIndicesForLOD(lod)              # 查询某 LOD 包含哪些关节
rig.getBlendShapeChannelIndicesForLOD(lod)  # 某 LOD 的 BS 通道
```

### 高级配置（Configuration）

```python
cfg = riglogic.Configuration()
cfg.calculationType = riglogic.CalculationType_SSE   # Scalar/SSE/AVX/NEON/AnyVector
cfg.rotationType    = riglogic.RotationType_Quaternions  # 默认 EulerAngles
cfg.loadBlendShapes = False    # 不需要的输出可以不加载（省内存提速）
cfg.translationPruningThreshold = 0.0001   # 微小值剪枝
rig = riglogic.RigLogic(reader, cfg)
```

分部求解接口（性能调优用）：`calculateJoints / calculateBlendShapes / calculateAnimatedMaps / calculateJointGroup(inst, groupIdx)` 可替代全量 `calculate`。

## 六、宿主集成要点

### Maya（已实测）

- Script Editor 直接用"通用加载方式"即可；注意上文**模块遮蔽**问题
- 典型用途：批量烘焙表情（驱动 rig 输出 → setKeyframe）、DNA 检视工具（对比两个角色的 joint group）、校验自制 DNA 的求解正确性

### MotionBuilder 2024（同 Python 3.10，产物直接可用）

- `sys.path.insert` 后同样 import；pyfbsdk 侧把 `getJointOutputs()` 的增量按 DNA 关节名映射到 FBModel 骨骼上即可实现 MetaHuman 面部实时预览（生态空白，值得做）

### 独立命令行工具

- 任何 CPython 3.10 直接用；适合写 DNA diff/批处理/CI 校验脚本
- 注意 .pyd 依赖 `python310.dll`——用 3.11 解释器加载会直接 `DLL load failed`，需按[编译指南](5.2-OpenRigLogic编译指南.md)重编 3.11 版本
