## 一、最常用命令速查

| 命令 | 看什么 | 用途 |
|---|---|---|
| `stat unit` | Game/Draw/GPU/RHIT 整体耗时 | **第一眼看瓶颈在哪** |
| `stat anim` | 动画系统总耗时(蒙皮+Morph+AnimBP) | **角色动画总览** |
| `stat animation` | 动画各阶段细分 | 深入分析 AnimBP/StateMachine |
| `stat cloth` | ChaosCloth 解算耗时 | **布料专项** |
| `stat skeletalmesh` | SkeletalMesh 渲染开销 | 蒙皮、LOD、Draw Call |
| `stat physics` | 物理总耗时(含 Cloth) | 物理系统全局 |
| `stat gpu` | GPU 各 Pass 耗时 | 渲染瓶颈定位 |
| `stat scenerendering` | 渲染总览 | Draw Call、Triangle 数 |

## 二、角色相关专项命令

### 2.1 动画与 Morph

```
stat anim              # 动画总耗时(包含 Morph 收集)
stat animation         # 各 AnimBP 节点耗时
stat morphtarget       # 仅 Morph 相关(部分版本叫 stat MorphTargets)
```

### 2.2 ChaosCloth 专项

```
stat cloth                                # 解算总耗时
stat clothing                             # 布料组件统计
p.Cloth.SolverParallelClothsEnabled 1     # 多线程解算开关检查
p.ChaosCloth.DebugDrawPhysMeshWired 1     # 可视化解算网格
showflag.Cloth 0/1                        # 切换布料显示
```

### 2.3 SkeletalMesh 与蒙皮

```
stat skeletalmesh         # SkM 总耗时
stat initviews            # 可见性剔除
a.SkinnedAsset.ISPC 1     # 检查是否启用 ISPC 加速
```

## 三、进阶组合(实战推荐)

### 3.1 快速诊断角色性能

```
stat unit
stat anim
stat cloth
```

三条一起开,先看 `stat unit` 的 Game/GPU 哪个高,再用 `stat anim` 和 `stat cloth` 定位是动画还是布料。

### 3.2 GPU 详细分析

```
stat gpu
ProfileGPU         # 单帧 GPU 详细 dump(按一次)
DumpGPU            # UE5.2+ 完整 GPU 帧捕获
```

### 3.3 CPU 详细分析

```
stat startfile       # 开始 CPU profile
stat stopfile        # 停止并保存 .ue4stats 文件
```

文件用 **Session Frontend → Profiler** 打开。

### 3.4 Unreal Insights(最强工具)

启动游戏前命令行加:

```
-trace=cpu,gpu,frame,bookmark,animation -tracehost=127.0.0.1
```

或运行时:

```
trace.start cpu,gpu,frame,animation
trace.stop
```

然后用 **UnrealInsights.exe** 打开,可以看到每个角色每帧每个阶段的精确耗时。

## 四、单角色定位

`stat anim` 默认是全局,要看**单个角色**需要:

```
ShowDebug Animation        # 切换到角色后,显示该 Pawn 的 AnimBP 调试
ShowDebug Bones            # 显示骨骼
ShowDebug Cloth            # 显示布料状态(部分版本)
```

`ShowDebug` 系列必须先 `EnableCheats`(在 Shipping 包要解锁开发者命令)。

切换查看目标:

```
ViewActor [角色名]
```

## 五、性能阈值参考

> 60 FPS 预算 16.6ms。下表为单帧预算占比参考。

| 项目 | 健康 | 警告 | 危险 |
|---|---|---|---|
| `stat unit` Game | < 8ms | 8–14ms | > 14ms |
| `stat anim` 单角色 | < 0.5ms | 0.5–1.5ms | > 1.5ms |
| `stat cloth` 单角色 | < 1ms | 1–2.5ms | > 2.5ms |
| 群体场景总 Cloth | < 3ms | 3–6ms | > 6ms |

## 六、推荐工作流

1. **第一步**:`stat unit` + `stat anim` + `stat cloth` 三件套,锁定问题域。
2. **第二步**:
   - 怀疑是 Cloth → `p.ChaosCloth.DebugDrawPhysMeshWired 1` 看解算密度。
   - 怀疑是 Morph → `stat anim` 看 `Update Morph Target Curves` 行。
3. **第三步**:Unreal Insights 抓帧,精确定位单帧到某个 Tick 函数。
4. **第四步**:对症下药——降代理粒子、关 Self Collision、合并 Morph、开 LOD Bias。

## 七、关闭性能监测命令

### 7.1 通用规则

**所有 `stat XXX` 命令再输入一次就是关闭**(切换式 toggle)。

```
stat unit       # 第一次输入:打开
stat unit       # 第二次输入:关闭
```

### 7.2 一键全关

最快的方式:

```
stat none
```

这条命令会**关闭当前屏幕上所有 stat 显示**,不需要逐个关。

### 7.3 各类命令的关闭方式

#### Stat 系列(显示在屏幕上的)

| 打开 | 关闭 |
|---|---|
| `stat unit` | `stat unit` 或 `stat none` |
| `stat anim` | `stat anim` 或 `stat none` |
| `stat cloth` | `stat cloth` 或 `stat none` |
| `stat gpu` | `stat gpu` 或 `stat none` |
| `stat fps` | `stat fps` 或 `stat none` |

#### ShowDebug 系列

```
ShowDebug Animation     # 打开
ShowDebug None          # 关闭所有 ShowDebug
ShowDebug               # 不带参数也可关闭当前
```

#### ShowFlag 系列

```
showflag.Cloth 1        # 打开
showflag.Cloth 0        # 关闭(把 1 改成 0)
```

#### 调试可视化

```
p.ChaosCloth.DebugDrawPhysMeshWired 1   # 打开
p.ChaosCloth.DebugDrawPhysMeshWired 0   # 关闭
```

凡是带数字参数的 `p.XXX` 或 `r.XXX`,**改回 0** 即关闭。

#### Profile 文件录制

```
stat startfile          # 开始录制
stat stopfile           # 停止录制(同时保存文件)
```

#### Unreal Insights Trace

```
trace.start cpu,gpu     # 开始追踪
trace.stop              # 停止追踪
```

#### GPU 单帧捕获

```
ProfileGPU              # 单次触发,不需要关闭
DumpGPU                 # 单次触发,不需要关闭
```

### 7.4 推荐的关闭流程

调试完角色性能后,一条命令清屏:

```
stat none
```

如果还开了 ShowDebug 和 ShowFlag,补两条:

```
ShowDebug None
showflag.Cloth 0
```

## 八、小贴士

- **打包版本(Shipping)** 默认禁用大部分 stat 命令,需要 `EnableCheats` 或开发版本才能用。
- **PIE 退出后** stat 状态不会保留到下次,但 **Standalone/打包游戏** 中会持续显示,记得关。
- 控制台快捷键默认是 **`** (反引号,Tab 上面那个),可以在 `Project Settings → Input → Console Keys` 改。
- 多个 stat 同时打开时,屏幕信息会堆叠;善用 `stat none` 一键清屏后再单独打开需要的项。
- `ProfileGPU` 是**单次触发**类命令,执行一次即弹窗,不需要"关闭"。
