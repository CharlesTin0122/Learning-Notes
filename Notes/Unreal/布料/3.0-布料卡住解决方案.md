在 UE5 的 **Chaos Cloth** 系统下，当动画幅度很大（比如快速挥臂、踢腿、蹲起、翻滚等）时，布料确实很容易**卡在骨骼的胶囊体（Capsule）之间**出不来，或者出现严重穿模后无法自恢复的情况。这是目前 Chaos Cloth 最常见、最难完全根治的一类问题之一。

以下是目前（2025-2026 年主流做法）最有效的几种缓解/解决思路，按优先级和实用性排序：

### 1. 最重要 – 优化碰撞体（Physics Asset）设置（80% 的情况靠这个大幅改善）
| 做法 | 目的 | 具体操作建议 |
|------|------|-------------|
| 使用 **Tapered Capsule** 而非普通 Capsule | 更贴合肢体形状，减少卡住概率 | Physics Asset 编辑器里删除普通 Capsule，改用 Tapered Capsule（锥形胶囊），两端半径可以不同 |
| **缩小胶囊半径**，尤其是大腿/上臂/前臂 | 避免两根胶囊之间缝隙太小 | 大腿胶囊半径通常调到原始的 0.6–0.8 倍，手臂更小（0.5–0.7 倍） |
| 增加关键骨骼的碰撞体数量 | 填补大关节活动时的空隙 | 例如：大腿根部多加一根短 Tapered Capsule，肘部、膝盖附近补小胶囊 |
| 肩部/胸部/臀部适当**加厚** | 防止布料钻进身体 | 肩部胶囊半径可以比手臂粗 20–40% |
| 打开 **Use Complex as Simple**（部分情况） | 用骨骼网格体本身做碰撞（慎用） | 只在极度追求质量且性能允许时开，性能代价很大 |

### 2. 布料配置（Cloth Config）关键参数调整
在 Skeletal Mesh 的 **Clothing** 面板 → Chaos Cloth Config 中重点调这些（建议为不同动作/部位做多套 Config Asset）：

| 参数路径 | 推荐调整方向 | 典型值（激烈动画） | 作用 |
|----------|--------------|---------------------|------|
| Collision → **Friction** | 适当降低 | 0.1–0.3 | 减少粘住感，但别太低否则滑太厉害 |
| Collision → **Collision Thickness** | 加大 | 1.5–4.0（单位 cm） | 给布料“更厚的皮肤”，最直接防卡住 |
| Collision → **Self Collision Thickness** | 加大 | 1.2–3.0 | 防止布料自己卡自己 |
| Collision → **Use Self Intersections** | 通常开启 | - | 开启自碰撞 |
| Solver → **Substeps / Iterations** | 加大 | Substeps 4–8，Iterations 8–15 | 更精确的碰撞响应（性能代价较大） |
| Solver → **Damping** / **Local Damping** | 适当加大 | 0.4–1.2 | 减少剧烈抖动和卡住后的振荡 |
| Backstop → **Enabled + Distance** | 打开并调小 | Distance 0.5–2.0 | 防止布料钻进身体（但会牺牲一些飘逸感） |

### 3. 动画 & 权重绘制层面的缓解手段
- **在 Cloth Paint 工具里**把容易卡住的区域（腋下、裆部、大腿内侧、肘窝等）**Max Distance / Movement** 画低（甚至画到 0–5），让这些地方更多跟随骨骼动画而非物理模拟。
- 激烈动作的关键帧前后**插入过渡帧**，避免动画速度突变。
- 必要时对某些极端 Pose 做**手调布料 Cache**（Sequencer 或 Take Recorder 烘焙布料）。

### 4. 其他进阶/妥协方案（当上面都还不够时）
- **多层布料分离碰撞**：把容易卡的内层布料（如衬衫）和外层（如外套）分别指定不同的 Physics Asset（在 Clothing Data 的 Collision 里可以指定不同的 Physics Asset）。
- 降低对布料的性能期望 → 把 Substeps 做到 6–10 + 高迭代，但只在过场/重要镜头开启（用 Config Switcher 或蓝图动态切换）。
- 极端情况直接放弃 Chaos Cloth，用 **Kawaii Physics** 或 **Niagara 布料**（或 Apex Cloth 遗留系统）做局部模拟。
- 等 UE 5.5/5.6+ 版本的 Cloth 改进（目前 5.4/5.5 已经在逐步优化多层布料和穿透恢复）。

### 快速上手推荐流程（最常解决问题的组合）
1. Physics Asset 全换成 **Tapered Capsule**，半径普遍缩小 20–40%
2. Cloth Config 中 **Collision Thickness** 调到 2.5–3.5
3. 容易卡的区域权重画低（Max Distance < 10）
4. Substeps 4–6 + Iterations 10+
5. 激烈动作测试 → 不行就再把厚度加大 + 对应区域 Backstop 打开

大部分情况下做到第 1、2、3 步，卡在胶囊之间的现象就能改善 70–90%。如果还是很严重，建议把问题区域的截图（包括 Physics Asset 视图 + Cloth Paint 权重图 + 卡住瞬间）发出来，能更精准判断。
