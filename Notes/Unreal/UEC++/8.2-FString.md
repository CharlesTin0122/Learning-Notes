# 概述
* 与  `FText` 和`FName`不同，`FString`可以搜索、修改 和 与其他字符串进行比较。但是，这些操作会导致 `FString` 的开销比不可变字符串类更大。这是因为`FString`对象存储自己的字符数组，而 `FName` and `FText` 对象存储共享字符数组的索引，并且可以仅基于此索引值建立相等性。
* `FString`的底层结构是一个`TArray`数组，`FString` 使用一个指针来指向字符数组的开始位置，并且负责内存的分配和释放。它通常会使用 `TArray<TCHAR>` 或类似的结构来管理底层的字符数据。
* `FString` 的元素类型是 `TCHAR`， `TCHAR` 是一个跨平台字符类型，通常定义为支持 Unicode 字符集的宽字符类型（`wchar_t`）。
	- 在 Windows 平台上，`TCHAR` 通常是 `wchar_t`（16 位字符），支持 UTF-16 编码。
	- 在其他平台上（如 Linux），`TCHAR` 可能是 `char`（8 位字符），支持 UTF-8 编码。
- `FString` 重载了 `operator*`，使得可以通过解引用操作符 `*` 获取到其内部的字符指针（`TCHAR*`）。
# 示例
```cpp
	//创建FString
	MyString = FString(TEXT("This is my test FString."));

	//转换
	FName MyName = FName(*MyString);//FString转化为FName,FName 不区分大小写，所以转换存在损耗
	FText MyText = FText::FromString(MyString);//FString转化为FText, FString 内容不会从 FText 的"自动本地化"中受益

	FString MyString1 = MyName.ToString();//FName转化为FString
	FString MyString2 = MyText.ToString();//FText转化为FString


	FString FloatString = FString::SanitizeFloat(12.35f);//Float转化为FString,清理浮点数转换去掉尾数零的浮点字符串

	FString IntString = FString::FromInt(12);//Int转化为FString

	bool BoolVar = false;
	FString BoolString = BoolVar ? TEXT("true") : TEXT("false");//bool转化为FString

	FVector VectorVal = FVector(13, 12, 5);
	FString VectorString = VectorVal.ToString();//FVector转化为FString

	FRotator RotatorVal = FRotator(30, 60, 91);
	FString RotatorString = RotatorVal.ToString();//FRotator转化为FString

	/**字符串类型转化为数值类型
	* FCString 是 Unreal Engine 中的一个字符串处理类。
	* Atoi 是 FCString 类的一个静态方法，用于将字符串转换为整数（Atoi 的意思是 "ASCII to integer"）。
	* IntString 是一个指向字符串的指针或引用，*IntString 表示解引用这个指针，获取其指向的字符串内容。
	* 当你对 FString 使用解引用操作符（*）时，你实际上是在访问其内部的字符数据。FString 提供了一个重载的 operator*，使得可以通过解引用获取到内部的字符指针。
	* 解引用 FString 返回的是一个 TCHAR* 类型的指针，指向字符串的第一个字符。这意味着你可以像处理 C 风格字符串一样使用它。
	*/
	int32 IntVal = FCString::Atoi(*IntString);
	float FloatVal = FCString::Atof(*FloatString);

	/**字符串比较
	* 重载的 == 运算符可用于比较两个 FString，或将 FString 与 TCHAR*s 数组进行比较。
	*  FString：：Equals（） 方法，它接受 FString 进行测试，并使用 ESearchCase 枚举来表示比较是否应该忽略大小写作为参数。
	* 如果希望比较忽略大小写，请使用 ESearchCase：：IgnoreCase ，否则，请使用 ESearchCase：：CaseSensitive 。
	*/
	bool StringBool = MyString.Equals(TEXT("this is my test fstring."), ESearchCase::IgnoreCase);

	/**搜索
	* FString：：Contains（） 如果找到子字符串，则返回 true，否则返回 false。
	* FString：：Contains（） 可以搜索 FString 或 TCHAR*s 子字符串。
	* ESearchCase 枚举可用于指定搜索是否应忽略大小写。
	* ESearchDir枚举可用于指定搜索的方向。
	* 默认设置是忽略大小写，并从开始时开始搜索。*/
	StringBool = MyString.Contains(TEXT("test"), ESearchCase::IgnoreCase, ESearchDir::FromEnd);
	/** FString::Find() 返回找到的第一个子字符串实例的索引。没有找到返回-1.
	* 与FString::Contains() 一样，您可以指定区分大小写和搜索方向，默认值是忽略大小写并从字符串的开头开始。
	* 也可在索引中任选一个索引10开始搜索。*/
	int32 StringIndex = MyString.Find(TEXT("test"), ESearchCase::CaseSensitive, ESearchDir::FromEnd, 10);

	//替换
	FString ReplacedString = MyString.Replace(TEXT("my"), TEXT("your"));


	//串联字符串
	MyString += FloatString;
	FString NewString = IntString + FloatString;

	//打印
	/**当使用 %s 参数来包含 FStrings 时，必须使用*运算符返回 %s 参数所需的 TCHAR*。
	* %s:字符串；%d:整型；%f：浮点数；%p：指针。
	* 可以指定输出的最小宽度和小数位数。例如，%5d 表示输出至少 5 个字符宽的整数，%.2f 表示输出两位小数的浮点数。
	*/
	const FString PrintString = FString::Printf(TEXT("%02d : %.2f"), IntVal, FloatVal);


	//拆分字符串
	FString LeftStr = MyString.Left(4);//从左侧开始截取4个字符
	FString MiddleStr = MyString.Mid(5);//从中间截取5个字符
	FString RightStr = MyString.Right(7);//从右面开始截取7个字符
	
	/** 分割字符串。在给定的字符串位置分割该字符串，区分大小写。
	* 参数1：用作分隔符的字符串；参数2：字符串指针，存储分隔符之前的字符串内容；参数3：字符串指针存储分隔符之后的字符串内容。
	* 参数4：是否区分大小写；参数5：决定搜索方向。
	* 返回值：布尔。
	*/
	FString FullString = TEXT("C:/Project/MyGame/Unreal");//要分割的字符串
	FString LeftPart, RightPart;//用于储存分割后的字符串
	//对字符串进行分割
	if (FullString.Split(TEXT("/"), &LeftPart, &RightPart, ESearchCase::IgnoreCase, ESearchDir::FromEnd))
	{
		UE_LOG(LogTemp, Log, TEXT("Left: %s, Right: %s"), *LeftPart, *RightPart);
	}

	/**ParseIntoArray，将带分隔符的字符串拆分为字符串数组的元素。 
	* 参数1：要填充的数组；参数2：分隔符；参数3： 空字符串不会添加到数组中
	*/
	TArray<FString> Tokens;
	MyString.ParseIntoArray(Tokens, TEXT(" "), true);

	/** log
	* 参数1：LogTemp 是日志类别。
	* 参数2：Log 是要使用的详细级别。详细程度在 ELogVerbosity 枚举中定义。有效值为 Fatal、Error、Warning、Display、Log、Verbose 或 VeryVerbose。
	* 参数3:是要输出的文本，包括参数的标记。此示例使用 %s 参数，因此*运算符用于返回 %s 参数所需的 TCHAR*。
	*/
	UE_LOG(LogTemp, Log, TEXT("This is a testing statement. %s"), *MyString);
	/**将调试信息打印到视口。
	* 参数1：防止相同信息多次添加的唯一键。使用 -1 作为键，使调试信息短时出现。
	* 参数2：显示时长；参数3：文本颜色；参数4：显示的信息。
	*/
	GEngine->AddOnScreenDebugMessage(-1, 5.f, FColor::Blue, MyString);

	/**编码转换，FString 类基于 TCHAR 的 TArray 构建。
	* 有多个宏可用于将应用程序字符串 （TCHAR*） 转换为 ANSI 或 UTF-8 字符集，反之亦然。
    * StringCast 返回的结果是一个临时对象。直接使用 Get() 返回的指针可能会在其生命周期结束后失效。
    * 应将结果存储到适当的容器（如 FString）中，或保证临时对象的生命周期
	*/

    // 将 ANSI 字符串转换为 TCHAR
    const char* AnsiString1 = "Hello";
    const TCHAR* TCHARString1 = StringCast<TCHAR>(AnsiString1).Get();

    // 将 TCHAR 转换为 ANSI 字符串
    const TCHAR* TCHARString2 = TEXT("Hello World");
    const ANSICHAR* AnsiString2 = StringCast<ANSICHAR>(TCHARString2).Get();

    // 与 FString 结合
    const char* AnsiString3 = "Hello Unreal!";
    FString FString3 = FString(StringCast<TCHAR>(AnsiString3).Get());

    // FTCHAR 转换为 UTF-8 编码
    FString TCHARString4 = TEXT("你好，世界！");
    const UTF8CHAR* UTF8String4 = StringCast<UTF8CHAR>(*TCHARString4).Get();

    // UTF-8 转换为 TCHAR 编码
    const char* UTF8String5 = "你好，世界！";
    const TCHAR* TcharString5 = StringCast<TCHAR>(UTF8String5).Get();



```
