# 概述
- 在 Unreal Engine （UE） 中，文本本地化的主要组件是`FText`类。所有面向用户的文本都应使用此类，因为它通过提供以下功能来支持文本本地化
	- [创建本地化文本文本。](https://dev.epicgames.com/documentation/en-us/unreal-engine/text-localization-in-unreal-engine#textliterals)
	- [设置文本格式（从占位符模式生成文本）](https://dev.epicgames.com/documentation/en-us/unreal-engine/text-localization-in-unreal-engine#textformatting) 
	- [从数字生成文本。](https://dev.epicgames.com/documentation/en-us/unreal-engine/text-localization-in-unreal-engine#numericaltextgeneration) 
	- [从日期和时间生成文本。](https://dev.epicgames.com/documentation/en-us/unreal-engine/text-localization-in-unreal-engine#chronological)
	- [生成派生文本 ，例如将文本设为大写或小写](https://dev.epicgames.com/documentation/en-us/unreal-engine/text-localization-in-unreal-engine#transformative)
- `FText`还具有`AsCultureInvariant`函数（或宏`INVTEXT`），用于创建非本地化或“区域性固定”文本。这对于将玩家名称从外部 API 转换为可在用户界面中显示的内容等操作非常有用。
- 您可以使用 `FText::GetEmpty()` 或 仅使用 `FText()` 来创建空白`FText`。
# 文本本地化
- 在内部，`FText` 被作为[`TSharedRef`](https://api.unrealengine.com/INT/API/Runtime/Core/Templates/TSharedRef/index.html)实现到[`ITextData`](https://api.unrealengine.com/INT/API/Runtime/Core/Internationalization/ITextData/index.html)。这使得复制成本非常低廉，而且[`FTextSnapshot`](https://api.unrealengine.com/INT/API/Runtime/Core/Internationalization/FTextSnapshot/index.html)工具提供了一种有效的方法来检测缓存的FText值是否确实发生了更改。
- 可本地化文本由三个组件组成：一个 **命名空间**；一个 **密钥**（形成其标识）；和一个 **源字符串**（这是被翻译内容的基础，并对`陈旧的`翻译进行验证）。在UE4中创建可本地化文本的最常见方法是使用文本文字值。

**文本文字值宏**

|宏|说明|
|---|---|
|**NSLOCTEXT**|通过定义命名空间、密钥和源字符串创建本地化的文本片段。|
|**LOCTEXT**|通过定义密钥和源字符串创建本地化的文本片段，并使用`LOCTEXT_NAMESPACE`定义命名空间。|
```cpp
// 定义要与LOCTEXT一起使用的命名空间
// 这只在单个文件中有效，并且必须在文件结束前取消定义
#define LOCTEXT_NAMESPACE "MyNamespace"
// 创建文本文字值
constFTextHelloWorld= NSLOCTEXT("MyOtherNamespace","HelloWorld","Hello World!")
constFTextGoodbyeWorld= LOCTEXT("GoodbyeWorld","Goodbye World!")
// 在文件结束前取消定义命名空间
#undef LOCTEXT_NAMESPACE
```
# 示例
```cpp
	//创建
	FText MyText = FText();
	FText MyOtherText = FText();

	//转换
	/*从现有 FString 创建非本地化且区域性固定的FText实例。*/
	MyText.AsCultureInvariant(TEXT("This is Text"));
	/** 这与AsCultureInvariant非编辑器版本中的版本相同。
	* 在编辑器版本中，此函数不会将文本标记为区域性不变，这意味着如果将其分配给已保存资源中的FText属性，它仍然可以本地化。*/
	MyText.FromString(FString(TEXT("This is Text")));
	/*FText从现有 FName .这与调用FromStringFName参数ToString函数的输出相同。*/
	MyText.FromName(FName(TEXT("ThisIsMyTestFName")));

	/**比较，由于 本地化数据比简单字符串更复杂，因此FText它不支持重载运算符比较。它提供了几个函数来执行比较：
	* EqualTo：此函数采用一个ETextComparisonLevel值来确定要使用的比较规则。它返回一个 ID，bool指示在这些比较规则下调用FText是否与另一个调用匹配。
	* EqualToCaseIgnored：此函数是用于调用EqualToETextComparisonLevel值为 Second .返回值直接来自 EqualTo 。
	* CompareTo：此函数采用一个ETextComparisonLevel值来确定要使用的比较规则。它返回int32与大多数字符串或内存比较函数一样。
	* CompareToCaseIgnored：此函数是用于调用CompareToETextComparisonLevel值为 Second .返回值直接来自 CompareTo 。
	*/
	MyOtherText = MyText.FromString(FString(TEXT("This is onather Text")));

	bool CompRet1 = MyText.EqualTo(MyOtherText);//大小写敏感，返回布尔
	bool CompRet2 = MyText.EqualToCaseIgnored(MyOtherText);//大小写不敏感，返回布尔
	int32 CompRet3 = MyText.CompareTo(MyOtherText);//大小写敏感，返回int
	int32 CompRet4 = MyText.CompareToCaseIgnored(MyOtherText);//大小不写敏感，返回int
```
