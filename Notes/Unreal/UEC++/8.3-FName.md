# 概述
- FNames 是一种轻量级类型，用于高效的字符串处理。具体来说，Unreal Engine 维护一个唯一字符串的全局表，FName 存储实例编号和对给定字符串的索引引用，以便于快速查找和访问。
- 此外，FName 子系统使用哈希表提供快速的字符串到 FName 转换。
- FNames 对于表示对象名称、标识符和其他经常比较的字符串特别有用。在 内容浏览器 中命名新资产 ，更改动态材质实例中的参数，或访问 骨架网格体 中的骨骼时，使用的是 FNames 。
- FNames 不区分大小写、不可变且无法操作。
# 示例
```cpp
	//创建
	FName MyName = FName(TEXT("ThisIsMyTestFName"));

	//转换
	FString StringName = MyName.ToString();//FName->FString
	FText TextName = FText::FromName(MyName);//FName -> FText
	// FString -> FName,很危险，因为转换是有损的，因为 FName 不区分大小写。
	MyName = FName(*StringName);
	// FText -> FName,很危险，因为转换是有损的，因为 FName 不区分大小写。
	FString MyString = TextName.ToString();
	MyName = FName(*MyString);


	/**	比较
	* == 运算符可用于比较两个 FNames，并返回 true 或 false。这不是进行字符串比较，而是比较 Index 中的值，这可以显著节省 CPU。
	* FName：：Compare 也可用于比较两个 FNames，如果小于 Other，则返回小于 0，如果等于 Other，则返回 0，如果大于 Other，则返回大于 0。
	*/
	FName OtherFName = FName(TEXT("This Is My Test FName"));
	int32 CompareResult = MyName.Compare(OtherFName);

	/** 使用FName
	* 从 Actor 的 骨骼网格体组件（Skeletal Mesh Component） 获取名为 pelvis 的骨骼。获取其旋转信息
	*/
	FVector rotPelvis = Mesh->GetBoneQuaternion(FName(TEXT("pelvis"))).Euler();

	/**搜索
	* 如果要确定 FName 是否在 name 表中，但不想自动添加它，则可以为 FName 构造函数提供不同的搜索类型
	* FNAME_Find查找名称，如果 name 表中不存在该名称，则 FName 的 Index 设置为 NAME_None 。请注意，我们不会像检查普通字符串那样检查指针是否为 null。
	*/
	if (FName(TEXT("pelvis"), FNAME_Find) != NAME_None)
	{
		FVector PelvisLoc = Mesh->GetBoneLocation(FName(TEXT("pelvis")));
	}
```
