在 **Unreal Engine** 中，`FRunnable` 和 `FRunnableThread` 是用于多线程编程的核心类。它们提供了一个简化的方式来创建和管理独立的线程，并通过实现特定接口来执行并行任务。下面我将详细介绍它们的功能及用法。

### 1. `FRunnable`

`FRunnable` 是一个接口类，允许你创建可执行的任务，这些任务可以在单独的线程上运行。你通过继承 `FRunnable` 类并实现其虚拟函数，来定义在线程中执行的代码。

#### 主要特点：

- **接口类**：`FRunnable` 提供了一个简单的接口，继承并实现其中的虚函数，以定义线程要执行的任务。
- **与线程分离**：`FRunnable` 允许你将线程的执行逻辑与线程的管理（如启动和停止）分开。

#### 主要函数：

- **`Run()`**：必须实现的函数，在线程启动后会被调用。这个函数包含线程执行的主要任务。
- **`Stop()`**：可以被调用以停止线程的执行。
- **`Suspend()`**：挂起线程的执行。
- **`Resume()`**：恢复挂起的线程执行。

#### 用法：

要使用 `FRunnable`，你需要继承它并实现其中的 `Run` 函数。

```cpp
class FMyRunnable : public FRunnable
{
public:
    virtual uint32 Run() override
    {
        // 线程要执行的任务
        while (!bIsStopRequested)
        {
            // 执行一些长时间运行的工作
        }
        return 0;
    }

    void Stop()
    {
        bIsStopRequested = true;
    }

private:
    bool bIsStopRequested = false;
};
```

在上面的例子中，`FMyRunnable` 类继承自 `FRunnable`，并实现了 `Run()` 方法，表示线程要执行的具体任务。可以通过 `Stop()` 方法请求停止线程的执行。

### 2. `FRunnableThread`

`FRunnableThread` 类是一个帮助类，它用来管理和启动 `FRunnable` 对象。通过它，你可以启动、管理和控制一个或多个线程。它接受一个 `FRunnable` 对象，并将其运行在独立的线程上。

#### 主要特点：

- **管理线程**：`FRunnableThread` 用于启动、暂停、恢复和停止线程。
- **与 `FRunnable` 配合使用**：它和 `FRunnable` 结合使用，`FRunnableThread` 管理线程的生命周期，而 `FRunnable` 定义线程的行为。

#### 主要函数：

- **`Create()`**：创建线程并将 `FRunnable` 任务与线程关联。
- **`WaitForCompletion()`**：等待线程完成其执行。
- **`Kill()`**：强制终止线程。
- **`Suspend()`**：挂起线程。
- **`Resume()`**：恢复挂起的线程。

#### 用法：

创建一个 `FRunnable` 对象并通过 `FRunnableThread` 来启动线程。

```cpp
class FMyRunnable : public FRunnable
{
public:
    virtual uint32 Run() override
    {
        // 执行一些任务
        return 0;
    }
};

void StartMyThread()
{
    FMyRunnable* MyRunnable = new FMyRunnable();
    FRunnableThread* MyThread = FRunnableThread::Create(MyRunnable, TEXT("MyThread"));
    
    // 线程创建成功后，可以执行一些操作，比如等待线程完成
    MyThread->WaitForCompletion();
}
```

在上面的代码中，我们首先创建了一个继承自 `FRunnable` 的对象 `FMyRunnable`，然后用 `FRunnableThread::Create()` 创建并启动一个线程来运行 `FMyRunnable` 对象中的 `Run()` 方法。

### `FRunnable` 和 `FRunnableThread` 的关系

- **`FRunnable`** 定义了线程应该执行的任务。它是线程的“工作”部分。
- **`FRunnableThread`** 用于创建和管理线程。它是线程的“控制”部分。

通常，`FRunnable` 用来表示任务，而 `FRunnableThread` 用来执行这个任务。

### 常见的多线程用法

使用 `FRunnable` 和 `FRunnableThread` 的基本步骤通常如下：

1. **继承 `FRunnable` 并实现 `Run()` 方法**，这个方法定义了线程执行的代码。
2. **创建一个 `FRunnableThread` 对象**，并将 `FRunnable` 对象作为参数传入 `FRunnableThread::Create()`，启动一个新线程。
3. 使用 `FRunnableThread` 的方法控制线程的生命周期，比如等待线程完成，或者在需要时强制终止线程。

### 示例：异步处理任务

例如，你可以用 `FRunnable` 和 `FRunnableThread` 来进行后台任务处理，比如读取文件、计算密集型操作等。

```cpp
class FFileReaderRunnable : public FRunnable
{
public:
    virtual uint32 Run() override
    {
        // 模拟耗时的文件读取操作
        FPlatformProcess::Sleep(2.0f);  // 暂停2秒
        UE_LOG(LogTemp, Log, TEXT("File read complete!"));
        return 0;
    }
};

void StartFileReadingThread()
{
    FFileReaderRunnable* FileReaderRunnable = new FFileReaderRunnable();
    FRunnableThread* FileReaderThread = FRunnableThread::Create(FileReaderRunnable, TEXT("FileReaderThread"));
    
    // 可以在此处继续执行其他工作
    // 通过调用 WaitForCompletion() 等待线程完成
    FileReaderThread->WaitForCompletion();
}
```

在这个例子中，我们创建了一个继承自 `FRunnable` 的 `FFileReaderRunnable` 类，在线程中模拟文件读取操作，线程启动后将进行异步任务。

### 总结

- **`FRunnable`** 用于定义线程要执行的任务，它是线程的核心逻辑。
- **`FRunnableThread`** 用于启动、管理和控制线程，它是线程的生命周期管理器。
- 通过结合 `FRunnable` 和 `FRunnableThread`，Unreal Engine 提供了一种简洁、灵活的多线程编程方式，可以帮助开发者高效地进行异步任务处理。

#### 小结

- **`FRunnable`** 代表线程的任务行为。
- **`FRunnableThread`** 管理线程的生命周期。
