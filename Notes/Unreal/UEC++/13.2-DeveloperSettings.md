在**Unreal Engine**中，`UDeveloperSettings` 是一个非常有用的类，主要用于在**编辑器的项目设置面板**中添加自定义配置项。通过继承 `UDeveloperSettings`，开发者可以轻松地创建一套可视化的配置系统，从而无需直接修改 `.ini` 文件即可配置项目参数。

---

### 1. **DeveloperSettings 的主要功能**

- 将**C++属性**暴露到**编辑器的项目设置**面板中。
- 提供便捷的**配置文件存储**和加载机制（通过 `.ini` 文件实现）。
- 支持项目设置的**分类**和**分组**，方便用户进行配置管理。
- 通过默认对象（CDO，Class Default Object）提供**全局访问**配置参数的途径。

---

### 2. **如何使用 `UDeveloperSettings`**

#### 要在`.build.cs`文件中加入模块`"DeveloperSettings"`
```c#
PublicDependencyModuleNames.AddRange(new string[] { 
	"Core", 
	"CoreUObject", 
	"Engine", 
	"InputCore", 
	"EnhancedInput",
	"GameplayTags",
	"DeveloperSettings"
});
```
#### **继承 UDeveloperSettings**

您需要创建一个继承自 `UDeveloperSettings` 的类，并在其中定义配置变量。

示例代码如下：

```cpp
#pragma once

#include "CoreMinimal.h"
#include "Engine/DeveloperSettings.h"
#include "MyGameDeveloperSettings.generated.h"

UCLASS(Config=Game, defaultconfig)
class MYGAME_API UMyGameDeveloperSettings : public UDeveloperSettings
{
    GENERATED_BODY()

public:
    // 设置分类和节名称
    virtual FName GetCategoryName() const override { return FName(TEXT("MyGameSettings")); }
    virtual FName GetSectionName() const override { return FName(TEXT("General")); }

    // 属性
    UPROPERTY(Config, EditAnywhere, BlueprintReadWrite, Category = "Gameplay")
    float PlayerMaxHealth = 100.0f;

    UPROPERTY(Config, EditAnywhere, BlueprintReadWrite, Category = "Gameplay")
    float PlayerSpeed = 600.0f;

    UPROPERTY(Config, EditAnywhere, BlueprintReadWrite, Category = "Graphics")
    bool bEnablePostProcessing = true;
};
```

---

#### **配置宏解释**

- `UCLASS(Config=Game, defaultconfig)`
    
    - `Config=Game`：指定变量存储到 `Game.ini` 文件中。
    - `defaultconfig`：表示配置的默认值将被写入 `DefaultGame.ini`。
- `UPROPERTY(Config, EditAnywhere, ...)`
    
    - `Config`：属性的值可以保存到 `.ini` 文件。
    - `EditAnywhere`：属性可以在编辑器中修改。
    - `BlueprintReadWrite`：属性可以被蓝图读写。

---

#### **.ini 配置文件存储**

在运行时或编辑器中修改配置变量后，系统会将这些配置保存在以下文件中：

1. **默认配置**：`DefaultGame.ini`
2. **运行时配置**：`Game.ini`

例如：

```ini
[/Script/MyGame.MyGameDeveloperSettings]
PlayerMaxHealth=120.0
PlayerSpeed=650.0
bEnablePostProcessing=False
```

---

### 3. **配置项在编辑器中的显示**

当您完成 `UDeveloperSettings` 派生类后，Unreal Engine 会自动将该类的属性显示在**项目设置**中，位置如下：

- 打开**编辑器** -> **项目设置**
- 在左侧的列表中，找到您定义的分类（如 `MyGameSettings`）。

---

### 4. **访问 DeveloperSettings 的配置**

在代码中，您可以通过获取默认对象 (CDO) 来访问配置值，例如：

```cpp
#include "MyGameDeveloperSettings.h"

void SomeFunction()
{
    const UMyGameDeveloperSettings* Settings = GetDefault<UMyGameDeveloperSettings>();
    if (Settings)
    {
        float MaxHealth = Settings->PlayerMaxHealth;
        UE_LOG(LogTemp, Log, TEXT("Max Health: %f"), MaxHealth);
    }
}
```

- `GetDefault<T>()`：获取类的默认对象（CDO），可以安全地读取配置参数。

---

### 5. **使用场景**

`UDeveloperSettings` 非常适合用于：

- **全局配置管理**：如游戏设置、调试开关、图形设置等。
- **团队协作**：方便策划和其他开发者通过编辑器快速修改参数。
- **调试与开发工具**：例如，设置日志级别、开发者选项等。

---

### 6. **优点总结**

- **简单易用**：无需手动处理 `.ini` 文件。
- **自动暴露到编辑器**：让设计人员和策划更容易管理配置。
- **反射系统支持**：与蓝图和编辑器无缝结合。
- **全局访问**：提供静态方法访问默认配置对象。

---

### 7. **注意事项**

1. **Config 属性保存限制**：`Config` 属性只能保存简单的数据类型，如 `int`、`float`、`bool`、`FString` 等。
2. **确保路径唯一**：`UDeveloperSettings` 类必须有独特的 `GetCategoryName()` 和 `GetSectionName()`，以避免冲突。
3. **性能影响**：避免频繁修改配置，因为 `.ini` 文件的读写开销较高。

---

### 总结

`UDeveloperSettings` 是一个非常强大的工具，适合用来管理项目配置和开发者选项。通过继承它，您可以轻松地在编辑器的“项目设置”中添加自定义配置项，并将配置保存到 `.ini` 文件中，方便团队成员修改和调试。
# # 示例

- MyConfigSettings.h
```cpp


#pragma once

#include "CoreMinimal.h"
#include "Engine/DeveloperSettings.h"//提供了UDeveloperSettings基类，允许在编辑器的“项目设置”中添加自定义配置项。
#include "MyConfigSettings.generated.h"


//结构体，可以在蓝图中使用
USTRUCT(BlueprintType)
struct FMySampleDescriber
{
	GENERATED_BODY()

public:
	UPROPERTY(VisibleAnywhere, BlueprintReadOnly, Category = "MyProjectInfo")
	FString AuthorName = TEXT("CharlesTian");

	UPROPERTY(VisibleAnywhere, BlueprintReadOnly, Category = "MyProjectInfo")
	bool bExperiment = false;
};

/** 类
 * Config = MyConfigSettings：设置类的配置存储在 MyConfigSettings 配置文件中。
 * defaultconfig：指定配置文件存储在 DefaultMyConfigSettings.ini 中。
 * 继承 UDeveloperSettings：允许开发者在编辑器 -> 项目设置面板 中添加自定义配置选项。
 */
UCLASS(Config = MyConfigSettings, defaultconfig)
class QUICKSTART_API UMyConfigSettings : public UDeveloperSettings
{
	GENERATED_BODY()
public:
	//构造和析构
	UMyConfigSettings(const FObjectInitializer &ObjectInitializer = FObjectInitializer::Get());
	virtual ~UMyConfigSettings();
	//获取信息
	virtual FName GetContainerName() const;
	virtual FName GetCategoryName() const;
	virtual FName GetSectionName() const ;
	//获取类的默认对象CDO
	static UMyConfigSettings* GetMyCoreSettings();

	UPROPERTY(VisibleAnywhere, BlueprintReadOnly, Category = "MyConfig")
	FString ProjectVersion = TEXT("1.0.0");
	//Config：该变量的值可以保存到配置文件中。
	UPROPERTY(Config, EditAnywhere, BlueprintReadWrite, Category = "MyConfig")
	FString ProjectOtherName = TEXT("asima");

	UPROPERTY(VisibleAnywhere, BlueprintReadOnly, Category = "MyConfig")
	FMySampleDescriber MySampleDescriber;

	UPROPERTY(Config, EditAnywhere, BlueprintReadWrite, Category = "MyConfig")
	FString MyAppID = TEXT("None");

	UPROPERTY(Config, EditAnywhere, BlueprintReadWrite, Category = "MyConfig")
	FString MyAppKey = TEXT("None");
};

```
- MyConfigSettings.cpp
```cpp



#include "MyConfigSettings.h"

UMyConfigSettings::UMyConfigSettings(const FObjectInitializer& ObjectInitializer) : Super(ObjectInitializer)
{
}

UMyConfigSettings::~UMyConfigSettings()
{
}

FName UMyConfigSettings::GetContainerName() const
{
	return FName(TEXT("Project"));
}

FName UMyConfigSettings::GetCategoryName() const
{
	return FName(TEXT("MySettings"));
}

FName UMyConfigSettings::GetSectionName() const
{
	return FName(TEXT("General"));
}

UMyConfigSettings* UMyConfigSettings::GetMyCoreSettings()
{
	//GetMutableDefault,获取类的可修改默认对象CDO
	UMyConfigSettings* Settings = GetMutableDefault<UMyConfigSettings>();
	return Settings;
}
```
