在 **Unreal Engine** 中，`INI` 配置文件是用来存储和管理项目设置、系统参数以及其他游戏配置的文件格式。`INI` 文件格式是一种简单的文本格式，非常适合存储结构化的数据。它在 Unreal Engine 项目中扮演着重要角色，通常用于配置游戏的各种设置（如图形设置、音效设置、网络配置等）以及存储用户或系统的偏好。

### 1. **INI 文件的结构**

`INI` 文件由多个 **Section（部分）**、**Key（键）** 和 **Value（值）** 组成。每个 section 代表一个配置区域，其中包含一组键值对。基本的文件结构如下所示：

```ini
[SectionName]
KeyName=Value
```

- **Section（部分）** 用中括号 `[]` 包围，定义了设置的类别或组。
- **Key（键）** 是该部分中的一个配置项，通常是一个字符串或标识符。
- **Value（值）** 是与键关联的实际配置值，通常是数字、字符串或布尔值。

例如，一个简单的 `INI` 文件：

```ini
[Graphics]
Resolution=1920x1080
VSync=True
AntiAliasing=4x

[Audio]
Volume=0.8
Mute=False
```

### 2. **常见的 INI 配置文件**

Unreal Engine 使用多个 INI 配置文件来管理项目的设置，常见的文件包括：

- **DefaultEngine.ini**: 存储与游戏引擎相关的设置，如图形、网络、输入等。
- **DefaultGame.ini**: 存储与游戏本身相关的设置，如游戏规则、玩家控制等。
- **DefaultInput.ini**: 配置输入绑定，包括键盘、鼠标、控制器等输入设备的设置。
- **DefaultEditor.ini**: 存储与编辑器相关的设置，通常在开发过程中修改。

### 3. **如何在代码中访问 INI 配置文件**

Unreal Engine 提供了丰富的 API 供开发者访问和操作 INI 配置文件。通过以下方法，你可以在 C++ 或蓝图中读取和修改 INI 文件中的设置。

#### **C++ 中的访问方式：**

在 C++ 中，你可以使用 `GConfig` 来访问和修改配置文件中的设置。`GConfig` 是 Unreal Engine 提供的一个全局对象，它允许你读取和写入 INI 文件中的数据。

**读取 INI 配置文件中的值：**

```cpp
FString MyResolution;
GConfig->GetString(TEXT("/Script/Engine.RendererSettings"), TEXT("Resolution"), MyResolution, GGameIni);
```

在这个例子中，我们从 `Engine.RendererSettings` 部分获取了 `Resolution` 配置项的值，并将其存储在 `MyResolution` 变量中。

**修改 INI 配置文件中的值：**

```cpp
GConfig->SetString(TEXT("/Script/Engine.RendererSettings"), TEXT("Resolution"), TEXT("1920x1080"), GGameIni);
GConfig->Flush(false, GGameIni);
```

在这个例子中，我们将 `Resolution` 的值设置为 `1920x1080`，并将更改保存到文件中。

#### **蓝图中的访问方式：**

在蓝图中，虽然没有直接的函数来读取和写入 INI 文件，但你可以通过 **Blueprint Function Library** 来封装 C++ 代码，从而在蓝图中访问 INI 文件。你也可以使用 Unreal Engine 中的其他方法（如 `Config` 函数）来读取和写入配置。

### 4. **应用场景**

INI 配置文件在 Unreal Engine 中非常灵活且功能强大，适用于许多场景：

- **图形设置**：通过 INI 文件，可以方便地存储和加载玩家自定义的图形设置，如分辨率、抗锯齿、阴影质量等。
- **音效设置**：音量、静音等设置常常被存储在 INI 文件中，以便玩家退出并重新启动游戏时，能够恢复到先前的状态。
- **游戏进度**：在一些情况下，INI 文件还可以用于保存游戏的进度（例如关卡、存档等），尽管一般来说，存档数据通常会存储在二进制文件中。

### 5. **读取和修改 INI 配置的注意事项**

- **同步性**：修改 INI 文件时，要确保在修改后调用 `Flush` 来刷新配置，以确保变更被写入磁盘。
- **配置文件的位置**：Unreal Engine 会在多个位置查找配置文件。通常，它会优先使用项目目录下的 INI 文件，如果找不到，它会使用引擎的默认设置。

### 总结

INI 配置文件在 Unreal Engine 中是一种非常重要的机制，广泛用于存储和管理项目和游戏的设置。无论是在 C++ 中，还是通过蓝图接口，开发者都可以灵活地读取和修改这些配置，从而实现对游戏行为和用户设置的精细控制。
