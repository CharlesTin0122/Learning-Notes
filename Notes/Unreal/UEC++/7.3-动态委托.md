**动态委托**（Dynamic Delegates）是委托系统的一个扩展，旨在提供更强大的功能，尤其是支持 **蓝图** 中的调用和绑定。与常规的委托相比，动态委托支持**跨线程**执行和**蓝图可见**性，这使得它们在很多 Unreal Engine 的功能中具有重要地位。

# 动态委托的特点

1. **支持蓝图**：动态委托可以被蓝图类访问和使用，而普通的委托（如 `FDelegate`）则不支持。
2. **跨线程执行**：动态委托支持在不同的线程上调用。这对于异步任务和延迟调用非常重要。
3. **生命周期管理**：动态委托提供更强的生命周期管理，它能够自动追踪绑定的对象生命周期。
4. **灵活性**：动态委托允许使用成员函数和静态函数作为回调函数，并且可以在运行时动态修改。

# 动态委托声明

动态委托使用 `DECLARE_DYNAMIC_DELEGATE` 或 `DECLARE_DYNAMIC_MULTICAST_DELEGATE` 来声明。它们与普通委托类似，但提供了更多的功能和灵活性。

| 声明宏                                                                  | 描述          |
| -------------------------------------------------------------------- | ----------- |
| `DECLARE_DYNAMIC_DELEGATE[_RetVal, ...]\( DelegateName \)`           | 创建一个动态委托。   |
| `DECLARE_DYNAMIC_MULTICAST_DELEGATE[_RetVal, ...]\( DelegateName \)` | 创建一个动态组播委托。 |

# 动态委托绑定

| 辅助宏                                     | 说明                                           |
| --------------------------------------- | -------------------------------------------- |
| `BindDynamic( UserObject, FuncName )`   | 用于在动态委托上调用BindDynamic()的辅助宏。自动生成函数命名字符串。     |
| `AddDynamic( UserObject, FuncName )`    | 用于在动态组播委托上调用AddDynamic()的辅助宏。自动生成函数命名字符串。    |
| `RemoveDynamic( UserObject, FuncName )` | 用于在动态组播委托上调用RemoveDynamic()的辅助宏。自动生成函数命名字符串。 |
# 动态委托执行
通过调用委托的 `Execute()` 函数执行绑定到委托的函数。执行前须检查委托是否已绑定。 此操作是为了使代码更安全，因为有时委托可能含有未初始化且被后续访问的返回值和输出参数。 执行未绑定的委托在某些情况下确实可能导致内存混乱。可调用 `IsBound()` 检查是否可安全执行委托。 同时，对于无返回值的委托，可调用 `ExecuteIfBound()`，但需注意输出参数可能未初始化。

|执行函数|描述|
|---|---|
|`Execute`|不检查其绑定情况即执行一个委托|
|`ExecuteIfBound`|检查一个委托是否已绑定，如是，则调用Execute|
|`IsBound`|检查一个委托是否已绑定，经常出现在包含 `Execute` 调用的代码前|
# 案例
- 单播动态委托（Dynamic Delegate）
```cpp
//声明动态单播委托
DECLARE_DYNAMIC_DELEGATE( FMyDynamicDelegate );
FMyDynamicDelegate MyDelegate; //创建动态单播委托对象
MyDelegate.BindUFunction(this, FName("MyFunction")); //绑定
MyDelegate.ExecuteIfBound();//执行
```
- 多播动态委托（Dynamic Multicast Delegate）
```cpp
DECLARE_DYNAMIC_MULTICAST_DELEGATE( FMyDynamicMulticastDelegate );//声明
FMyDynamicMulticastDelegate MyMulticastDelegate;//创建动态多播委托对象
MyMulticastDelegate.AddUFunction(this, FName("MyFunction"));//绑定
MyMulticastDelegate.Broadcast();//使用 `Broadcast()` 来广播事件，调用所有绑定的回调函数。

```
