在 **Unreal Engine 5** 中，`GraphEvent` 是一种轻量级的异步任务机制，通常用于管理和协调并发任务。它是 **任务图系统（Task Graph System）** 的核心部分，用于描述和调度依赖任务的执行。

以下是对 `GraphEvent` 的详细介绍：

---

### **1. 什么是 GraphEvent？**

`GraphEvent` 是一个抽象概念，表示一个任务或事件的完成状态。它通常由 **Task Graph System** 中的任务创建，用于跟踪任务的执行进度并协调依赖关系。

在 UE 的任务系统中：

- **Graph** 表示任务依赖关系图。
- **Event** 表示单个任务的完成状态。

任务可以通过 `GraphEvent` 相互关联，从而实现复杂的异步任务依赖。

---

### **2. GraphEvent 的工作原理**

- **创建任务**：每个任务通过 `GraphEvent` 表示。
- **任务依赖**：任务可以依赖于其他任务的完成，即等待一个 `GraphEvent`。
- **完成通知**：当任务完成时，通知依赖任务开始执行。

通过这种机制，可以构建任务的依赖链，实现灵活的并发任务调度。

---

### **3. 主要用途**

1. **并发任务的依赖管理**：
    - 通过 `GraphEvent` 可以定义任务之间的依赖关系，确保任务按正确的顺序执行。
2. **性能优化**：
    - 使用任务图系统，可以高效地利用多核 CPU 并行执行任务。
3. **非阻塞任务执行**：
    - `GraphEvent` 的机制避免了线程阻塞问题，任务可以异步执行而不影响主线程。

---

### **4. 使用方式**

#### **创建和分派任务**

使用 `FFunctionGraphTask` 来创建一个任务，并返回一个 `GraphEvent`。

```cpp
#include "Async/TaskGraphInterfaces.h"

// 创建一个任务
FGraphEventRef TaskEvent = FFunctionGraphTask::CreateAndDispatchWhenReady(
    []() {
        // 任务逻辑
        UE_LOG(LogTemp, Log, TEXT("任务正在执行"));
    },
    TStatId(),           // 统计ID（可选）
    nullptr,             // 依赖的事件（可选）
    ENamedThreads::AnyThread // 线程类型
);
```

#### **等待任务完成**

调用 `Wait` 等待任务完成（会阻塞当前线程）。

```cpp
if (TaskEvent.IsValid())
{
    TaskEvent->Wait();  // 等待任务完成
}
```

---

### **5. 高级用法：任务依赖**

可以通过 `Prerequisites` 定义任务的依赖。

```cpp
#include "Async/TaskGraphInterfaces.h"

// 创建依赖任务A
FGraphEventRef TaskA = FFunctionGraphTask::CreateAndDispatchWhenReady(
    []() {
        UE_LOG(LogTemp, Log, TEXT("Task A 执行完成"));
    }
);

// 创建任务B，依赖任务A
FGraphEventRef TaskB = FFunctionGraphTask::CreateAndDispatchWhenReady(
    []() {
        UE_LOG(LogTemp, Log, TEXT("Task B 开始执行，因为 Task A 已完成"));
    },
    TStatId(),           // 统计ID
    TaskA                // 依赖的事件
);
```

---

### **6. GraphEvent 的常用方法**

|方法|说明|
|---|---|
|**`IsComplete()`**|检查任务是否完成，返回布尔值。|
|**`Wait()`**|阻塞当前线程，直到任务完成。|
|**`Execute()`**|手动执行任务（通常由系统调用）。|
|**`IsValid()`**|检查 `GraphEvent` 是否有效。|

---

### **7. GraphEvent 的优点**

1. **任务依赖管理简单**：可以轻松创建复杂的任务依赖。
2. **高性能**：基于任务图的调度机制，可以高效利用 CPU 多线程。
3. **灵活性**：支持自定义线程类型和任务调度逻辑。

---

### **8. 示例：一个任务依赖链**

以下代码实现任务链：`TaskA -> TaskB -> TaskC`。

```cpp
FGraphEventRef TaskA = FFunctionGraphTask::CreateAndDispatchWhenReady(
    []() {
        UE_LOG(LogTemp, Log, TEXT("Task A 执行完成"));
    }
);

FGraphEventRef TaskB = FFunctionGraphTask::CreateAndDispatchWhenReady(
    []() {
        UE_LOG(LogTemp, Log, TEXT("Task B 执行完成"));
    },
    TStatId(),
    TaskA // 依赖 TaskA
);

FGraphEventRef TaskC = FFunctionGraphTask::CreateAndDispatchWhenReady(
    []() {
        UE_LOG(LogTemp, Log, TEXT("Task C 执行完成"));
    },
    TStatId(),
    TaskB // 依赖 TaskB
);

// 等待任务链完成
if (TaskC.IsValid())
{
    TaskC->Wait();
}
```
组合任务链

```cpp
	[]() {UE_LOG(LogTemp, Log, TEXT("任务正在执行")); },// 任务逻辑

);

FGraphEventRef SimpleEventB = FFunctionGraphTask::CreateAndDispatchWhenReady(
	[]() {UE_LOG(LogTemp, Log, TEXT("任务正在执行")); },// 任务逻辑

	SimpleEventA                                      // 依赖的事件，SimpleEventA完成再执行
);


//任务数组
FGraphEventArray SimpleEventArray;
SimpleEventArray.Add(SimpleEventA);
SimpleEventArray.Add(SimpleEventB);

FGraphEventRef SimpleEventC = FFunctionGraphTask::CreateAndDispatchWhenReady(
	[]() {UE_LOG(LogTemp, Log, TEXT("任务正在执行")); },// 任务逻辑

	&SimpleEventArray                               // 依赖的事件，SimpleEventArray完成再执行，要传数组地址
);
```
---

### **9. 注意事项**

- **主线程谨慎阻塞**：避免在游戏主线程中调用 `Wait()`，否则可能导致帧率下降。
- **任务分配过多**：过多小任务会增加任务管理的开销，应适当划分任务粒度。
- **依赖循环**：避免任务之间存在循环依赖，否则会造成死锁。

---

### **总结**

`GraphEvent` 是 Unreal 的任务图系统中重要的一部分，用于高效地管理和协调多线程任务。通过 `GraphEvent` 和相关工具，可以创建复杂的任务依赖链，从而实现灵活且高性能的并发任务调度。
# 示例
```cpp
void UMyThreadSubsystem::BatchGraphEvent()
{
	/** FGraphEventRef = TRefCountPtr<FBaseGraphTask>;是一个一个FBaseGraphTask类型智能指针，指向实现 AddRef/Release 的对象。
	* CreateAndDispatchWhenReady()创建一个任务，并在前提条件完成时调度它
	* @param InFunction - 一个在前提条件完成时执行的函数对象，签名为 `void()` 或 `void(ENamedThreads::Type, const FGraphEventRef&)`
	* @param InStatId - 用于调试或分析工具的任务 StatId
	* @param InPrerequisites - 此任务的前提条件句柄，如果没有前提条件可以为 NULL
	* @param InDesiredThread - 要运行的线程
	* @return 新任务的完成句柄
	*/
	FGraphEventRef SimpleEvent = FFunctionGraphTask::CreateAndDispatchWhenReady(
		[]() {UE_LOG(LogTemp, Log, TEXT("任务正在执行")); },// 任务逻辑
		TStatId(),                                       // 统计ID（可选）
		nullptr,                                        // 依赖的事件（可选）
		ENamedThreads::AnyThread                       // 线程类型
	);
	//如果任务可用，
	if (SimpleEvent.IsValid())
	{
		SimpleEvent->Wait();  // 等待任务完成
	}

	//任务数组
	FGraphEventArray SimpleEventArray;
	for (size_t index = 0; index < 20; index++)
	{
		SimpleEventArray.Add(FFunctionGraphTask::CreateAndDispatchWhenReady(
			[index]() {UE_LOG(LogTemp, Log, TEXT("任务[%d]正在执行"), index); }
		));
	}
	//等待数组任务执行完成
	/*FTaskGraphInterface是task graph system的接口类
	* Get()返回task graph system单例的引用
	*/
	FTaskGraphInterface::Get().WaitUntilTasksComplete(SimpleEventArray);

}
```
