### **Unreal Engine 5 中的多线程编程**

Unreal Engine 5 提供了强大的多线程支持，用于在游戏开发中提升性能，尤其是在处理复杂的任务（如 AI、物理模拟、路径规划、大量数据处理）时非常有用。以下是 Unreal Engine 5 多线程编程的主要内容和技术。

---
### **1. UE5 中多线程的基础概念**

- **主线程（Game Thread）**：
    - 主线程负责游戏逻辑的执行，例如对象更新、蓝图执行和事件处理等。
    - 一般来说，大多数代码都在主线程中运行。
- **渲染线程（Render Thread）**：
    - 用于处理图形相关任务，将渲染指令发送到 GPU。
    - 落后于主线程一到两帧
- **其他线程**：
    - Unreal Engine 使用多个后台线程来执行异步任务，例如物理线程、动画线程和任务线程。
- **任务系统（Task Graph System）**：
    - UE 提供了一个强大的任务系统，允许开发者将工作分配给多个线程以实现并行处理。

---

### **2. UE5 多线程编程方式**

#### **2.1 使用 `FRunnable` 和 `FRunnableThread`**

这是 Unreal 提供的底层线程控制方法。

##### **实现步骤：**

1. **定义一个继承自 `FRunnable` 的类**： 需要实现线程的生命周期函数，例如 `Init()`, `Run()`, 和 `Stop()`。
    
2. **启动线程**： 使用 `FRunnableThread` 启动自定义线程。
    

##### **代码示例：**

**头文件**

```cpp
#pragma once

#include "CoreMinimal.h"
#include "HAL/Runnable.h"

class YOURPROJECT_API FMyThread : public FRunnable
{
public:
    FMyThread();
    virtual ~FMyThread();

    // FRunnable 接口
    virtual bool Init() override;
    virtual uint32 Run() override;
    virtual void Stop() override;

    static FMyThread* CreateThread();
    static void ShutdownThread();

private:
    FThreadSafeCounter StopTaskCounter;
    FRunnableThread* ThreadInstance;
};
```

**源文件**

```cpp
#include "MyThread.h"

FMyThread::FMyThread() : ThreadInstance(nullptr) {}

FMyThread::~FMyThread()
{
    if (ThreadInstance)
    {
        delete ThreadInstance;
        ThreadInstance = nullptr;
    }
}

bool FMyThread::Init()
{
    UE_LOG(LogTemp, Warning, TEXT("Thread Initialized!"));
    return true;
}

uint32 FMyThread::Run()
{
    while (StopTaskCounter.GetValue() == 0)
    {
        UE_LOG(LogTemp, Warning, TEXT("Thread Running..."));
        FPlatformProcess::Sleep(0.1f); // 防止占用 CPU
    }
    return 0;
}

void FMyThread::Stop()
{
    StopTaskCounter.Increment();
    UE_LOG(LogTemp, Warning, TEXT("Thread Stopping..."));
}

FMyThread* FMyThread::CreateThread()
{
    FMyThread* Runnable = new FMyThread();
    Runnable->ThreadInstance = FRunnableThread::Create(Runnable, TEXT("MyCustomThread"));
    return Runnable;
}

void FMyThread::ShutdownThread()
{
    Stop();
    if (ThreadInstance)
    {
        ThreadInstance->Kill(true);
        delete this;
    }
}
```

#### **2.2 使用 Async Tasks**

对于简单的多线程任务，UE 提供了 `AsyncTask` 函数，方便开发者快速启动后台任务。

##### **代码示例：**

```cpp
#include "Async/Async.h"

// 简单的异步任务
void RunAsyncTask()
{
    AsyncTask(ENamedThreads::AnyBackgroundThreadNormalTask, []()
    {
        // 后台线程工作
        UE_LOG(LogTemp, Warning, TEXT("Running Async Task on Background Thread"));

        // 切回主线程
        AsyncTask(ENamedThreads::GameThread, []()
        {
            UE_LOG(LogTemp, Warning, TEXT("Back to Game Thread"));
        });
    });
}
```

##### **优点：**

- 简洁易用。
- 自动管理线程生命周期。
- 支持主线程和后台线程的交互。

---

#### **2.3 使用 `FAsyncTask`**

`FAsyncTask` 是 Unreal 提供的一个模板类，用于封装后台任务。

##### **代码示例：**

**自定义任务类**

```cpp
#pragma once

#include "CoreMinimal.h"

class FMyAsyncTask
{
public:
    FMyAsyncTask(int32 InValue) : Value(InValue) {}

    void DoWork()
    {
        UE_LOG(LogTemp, Warning, TEXT("Async Task Running with Value: %d"), Value);
    }

private:
    int32 Value;
};
```

**任务启动**

```cpp
#include "Async/AsyncWork.h"

void RunFAsyncTask()
{
    FAsyncTask<FMyAsyncTask>* Task = new FAsyncTask<FMyAsyncTask>(42);
    Task->StartBackgroundTask(); // 启动后台任务
}
```

#### **2.4 使用 `FGraphEvent` 和任务图**

任务图（Task Graph）是 Unreal 引擎的内置任务系统，适合处理依赖关系的并行任务。

##### **代码示例：**

```cpp
#include "Async/TaskGraphInterfaces.h"

void RunTaskGraph()
{
    FGraphEventRef Task = FFunctionGraphTask::CreateAndDispatchWhenReady([]()
    {
        UE_LOG(LogTemp, Warning, TEXT("Task Graph Running on Thread"));
    }, TStatId(), nullptr, ENamedThreads::AnyBackgroundThreadNormalTask);

    // 等待任务完成
    FTaskGraphInterface::Get().WaitUntilTaskCompletes(Task);
}
```

### **3. 多线程注意事项**

1. **线程安全性**：
    
    - 多线程环境中需要使用线程安全的数据结构（如 `TArray` 的线程安全版本 `TArray64`）或使用锁（如 `FCriticalSection`）。
2. **避免主线程阻塞**：
    
    - 主线程负责游戏逻辑，尽量避免在主线程中等待后台线程完成任务。
3. **线程管理**：
    
    - 创建线程时需要注意其生命周期，避免线程泄漏。
    - 使用 `AsyncTask` 或任务图可避免手动管理线程。
4. **性能监控**：
    
    - 使用 Unreal 的 Profiler 工具监控线程性能，分析是否引入了额外的开销。

---

### **4. 什么时候使用多线程？**

- **数据加载**：异步加载关卡资源、资产、文件等。
- **计算密集型任务**：复杂的数学运算、路径规划、AI 计算。
- **并行任务**：分离不需要依赖主线程的任务，提高游戏帧率。
- **后台工作**：日志记录、分析数据等。

---

### **5. 总结**

- Unreal Engine 5 提供了从底层线程控制（`FRunnable`）到高级任务系统（`AsyncTask`、`FAsyncTask`）的多线程编程工具。
- 根据任务的复杂程度和需求，选择合适的工具实现多线程逻辑。
- 确保线程安全性和主线程的高效运行，是多线程编程的核心。
