## UObject 创建

UObjects 不支持构造器参数。所有的C++ UObject都会在引擎启动的时候初始化，然后引擎会调用其默认构造器。如果没有默认的构造器，那么 UObject 将不会编译。
- MyObject.h
```cpp
#pragma once

#include "CoreMinimal.h"
#include "UObject/NoExportTypes.h"
#include "MyObject.generated.h"

UCLASS()
class CPPPROJECT_API UMyObject : public UObject
{
	GENERATED_BODY()
public:
	//构造函数
	UMyObject();
	UMyObject(const FObjectInitializer & ObjectInitializer);
	//析构函数
	virtual ~UMyObject();
	//定义属性
	UPROPERTY()
	int32 Health = 20;
};

```
- MyObject.cpp
```cpp
#include "MyObject.h"

//构造函数
UMyObject::UMyObject()
{
	//在构造函数中打印log
	UE_LOG(LogTemp, Warning, TEXT("MyObject init!"));
}
//有参构造
UMyObject::UMyObject(const FObjectInitializer& ObjectInitializer) : Super(ObjectInitializer)
{
}
//析构函数
UMyObject::~UMyObject()
{
	//在析构函数中打印log
	UE_LOG(LogTemp, Warning, TEXT("MyObject Destroy!"));
}
```
UObject 构造器应该轻量化，仅用于设置默认的数值和子对象，构造时不应该调用其它功能和函数。对于 [Actor](https://dev.epicgames.com/documentation/zh-cn/unreal-engine/actors-in-unreal-engine)和[Actor组件](https://dev.epicgames.com/documentation/zh-cn/unreal-engine/components-in-unreal-engine)，初始化功能应该输入 `BeginPlay()` 方法。

UObject 应该仅在运行时使用 NewObject 构建，或者将 CreateDefaultSubobject 用于构造器。

| 方法                                                                | 描述                                                                                             |
| ----------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| [`NewObject<class>`](https://dev.epicgames.com/documentation/404) | 使用所有可用创建选项的可选参数创建一个新实例。提供极高的灵活性，包括带自动生成命名的简单使用案例。                                              |
| `CreateDefaultSubobject<class>`                                   | 创建一个组件或者子对象，可以提供创建子类和返回父类的方法。<br><br>创建默认子对象时，由于它们在引擎启动时构造，UObject 的类构造器应该仅适用于本地数据或者本地加载的静态资产。 |

UObjects 永远都不应使用 `new` 运算符。所有的 UObjects 都由虚幻引擎管理内存和垃圾回收。如果通过 new 或者 delete 手动管理内存，可能会导致内存出错。
# 案例
MyActor.h
```cpp
#pragma once

#include "CoreMinimal.h"
#include "GameFramework/Actor.h"
#include "MyObject.h"

#include "MyActor.generated.h"


UCLASS()
class CPPPROJECT_API AMyActor : public AActor
{
	GENERATED_BODY()
	
public:	
	// Sets default values for this actor's properties
	AMyActor();
	//定义一个属性,蓝图可读写，任何地方可编辑,类别为MyProperty
	UPROPERTY(BlueprintReadWrite, EditAnywhere, Category = "MyProperty");
	int32 Money = 100;
	//获取属性函数
	UFUNCTION(BlueprintCallable, Category = "MyProperty")
	int32 GetCurMoney();
	//获取CDO属性函数
	UFUNCTION(BlueprintCallable, Category = "MyProperty")
	int32 GetCDOMoney();

protected:
	// Called when the game starts or when spawned
	virtual void BeginPlay() override;

public:	
	// Called every frame
	virtual void Tick(float DeltaTime) override;

	//创建MyObject
	UFUNCTION(BlueprintCallable)
	void InitMyObject();

	//获取MyObject属性
	UFUNCTION(BlueprintCallable)
	int32 GetMyObjHealth();

	//指向MyObject对象的指针
	UPROPERTY()
	UMyObject* MyObjPtr = nullptr;

};
```
MyActor.cpp
```cpp
#include "MyActor.h"


// Sets default values,Money属性初始化为200
AMyActor::AMyActor() : Money(200)
{
 	// Set this actor to call Tick() every frame.  You can turn this off to improve performance if you don't need it.
	PrimaryActorTick.bCanEverTick = true;
	//创建根节点，带有transform属性
	RootComponent = CreateDefaultSubobject<USceneComponent>(TEXT("MyRoot"));
	//Money属性修改为300
	Money = 300;

}
//获取属性
int32 AMyActor::GetCurMoney()
{
	return Money;
}
//获取CDO属性
int32 AMyActor::GetCDOMoney()
{
	//通过StaticClass()方法获取AMyActor类的UClass对象。
	UClass *MyClass = AMyActor::StaticClass();
	//GetDefaultObject()是UClass类的方法，用于获取该类的默认对象（CDO）。这行代码将返回一个指向AMyActor类默认对象的指针，并将其存储在MyObject中。
	UObject *MyObject = MyClass->GetDefaultObject();
	//尝试将MyObject指针转换为AMyActor类型的指针。Cast<>是一种类型安全的转换方法，能够检查转换是否成功。如果MyObject确实是一个AMyActor类的对象，它将返回一个有效的指针；如果不是，它将返回nullptr。
	AMyActor* MyCDO = Cast<AMyActor>(MyObject);
	//如果Cast转换成功（即MyCDO不是nullptr），则返回MyCDO的Money属性值。Money是AMyActor类的一个成员变量。
	if (MyCDO) {
		return MyCDO->Money;
	}
	//如果MyCDO为空（即转换失败），则函数返回-1，表示出错或无法获取Money属性。
	return -1;
}

// Called when the game starts or when spawned
void AMyActor::BeginPlay()
{
	Super::BeginPlay();
	
}

// Called every frame
void AMyActor::Tick(float DeltaTime)
{
	Super::Tick(DeltaTime);

}

//创建MyObject对象并用指针指向
void AMyActor::InitMyObject()
{
	//创建一个MyObject对象并返回指针
	MyObjPtr = NewObject<UMyObject>();

	//MyObjPtr->AddToRoot(); //指针添加到根
	//MyObjPtr->RemoveFromRoot(); // 指针从根移除
}

//获取MyObject属性
int32 AMyActor::GetMyObjHealth()
{
	if (MyObjPtr) 
	{
		return MyObjPtr->Health;
	}
	return -1;
}
```
- 在其中`InitMyObject()`方法调用`NewObject<UMyObject>()`创建了MyObject对象并返回一个MyObject对象的指针
- 可以通过该指针访问MyObject对象的属性`MyObjPtr->Health`
- `MyObjPtr`指针变量被`UPROPERTY()`宏修饰，垃圾回收时会检查引用计数，有引用该属性就不会被回收。
