### **Unreal Engine 中的 `TUniquePtr`**

#### 1. **什么是 `TUniquePtr`？**

`TUniquePtr` 是 Unreal Engine 中用于管理动态分配内存的智能指针，类似于标准库中的 `std::unique_ptr`。它提供独占所有权的智能指针功能，确保内存的生命周期由 `TUniquePtr` 独自控制，不会被其他指针共享。

#### 2. **主要特点**

- **独占所有权**：`TUniquePtr` 独占它所管理的对象，不能复制。
- **自动释放资源**：当 `TUniquePtr` 超出作用域时，它会自动删除管理的对象，避免内存泄漏。
- **轻量**：相比 `TSharedPtr`，`TUniquePtr` 更高效，因为它没有引用计数的开销。
- **非共享**：由于不能共享管理权，因此在需要多对象共享所有权时不适合。

---

#### 3. **基本用法**

##### **声明和初始化**

```cpp
TUniquePtr<FMyClass> MyUniquePtr = MakeUnique<FMyClass>();
```

##### **访问对象**

使用 `->` 或 `*` 操作符访问管理的对象：

```cpp
MyUniquePtr->SomeFunction();
(*MyUniquePtr).AnotherFunction();
```

##### **移动所有权**

`TUniquePtr` 不支持复制，但支持通过 `MoveTemp` 进行移动：

```cpp
TUniquePtr<FMyClass> NewPtr = MoveTemp(MyUniquePtr);
// MyUniquePtr 现在为空，所有权转移到 NewPtr
```

##### **重置和释放**

- **重置对象：**
    
    ```cpp
    MyUniquePtr.Reset(); // 释放当前对象
    ```
    
- **获取裸指针：**
    
    ```cpp
    FMyClass* RawPtr = MyUniquePtr.Get(); // 仅用于访问，不改变所有权
    ```
    

---

#### 4. **使用场景**

- **独占对象的管理：**
    - 适用于需要明确所有权且对象不需要在多个地方共享的场景。
- **性能敏感的场景：**
    - 比如在游戏中频繁创建和销毁的临时对象，用 `TUniquePtr` 可以避免共享指针的额外开销。
- **RAII 模式**：
    - 用于资源管理（如文件句柄、内存块等），在超出作用域时自动清理资源。

---

#### 5. **优缺点**

|优点|缺点|
|---|---|
|高效（无引用计数开销）|不支持共享所有权|
|避免手动释放内存，防止泄漏|不适合跨多个对象传递所有权|
|自动清理资源|需要手动处理所有权转移|

---

#### 6. **代码示例**

##### 示例：动态创建和管理对象

```cpp
#include "CoreMinimal.h"
#include "GameFramework/Actor.h"

class FMyResource
{
public:
    FMyResource() { UE_LOG(LogTemp, Warning, TEXT("FMyResource Created")); }
    ~FMyResource() { UE_LOG(LogTemp, Warning, TEXT("FMyResource Destroyed")); }

    void DoSomething() { UE_LOG(LogTemp, Warning, TEXT("FMyResource is doing something")); }
};

class AMyActor : public AActor
{
    GENERATED_BODY()

private:
    TUniquePtr<FMyResource> Resource;

public:
    AMyActor()
    {
        // 初始化资源
        Resource = MakeUnique<FMyResource>();
    }

    void UseResource()
    {
        if (Resource)
        {
            Resource->DoSomething();
        }
    }

    virtual ~AMyActor()
    {
        // Resource 会自动销毁
    }
};
```

##### 示例：移动所有权

```cpp
void TransferOwnership(TUniquePtr<FMyResource> InResource)
{
    InResource->DoSomething();
    // InResource 会在此函数结束时自动销毁
}

void ExampleUsage()
{
    TUniquePtr<FMyResource> MyResource = MakeUnique<FMyResource>();
    TransferOwnership(MoveTemp(MyResource));
    // 此时 MyResource 已经为空
}
```

---

#### 7. **与 `TSharedPtr` 的对比**

|特性|`TUniquePtr`|`TSharedPtr`|
|---|---|---|
|所有权管理|独占|共享|
|引用计数|无|有|
|内存管理性能|高|较低|
|使用场景|独占资源，生命周期明确|多处共享，引用复杂的场景|
|线程安全性|不支持|支持|

---

#### 8. **总结**

`TUniquePtr` 是一种高效、轻量级的智能指针，非常适合管理独占资源的场景。在 Unreal Engine 中，优先使用 `TUniquePtr` 处理不需要共享所有权的动态对象，避免使用原始指针导致的内存管理问题。
