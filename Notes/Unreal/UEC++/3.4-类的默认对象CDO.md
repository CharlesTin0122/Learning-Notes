虚幻引擎包含一个用于处理游戏对象的强大系统。虚幻引擎中所有对象的基类都是 `UObject`。而 `UCLASS` 宏的作用是标记 `UObject` 的子类， 以便 **UObject** 处理系统可以识别它们。

虚幻引擎包含一个用于处理游戏对象的强大系统，我们最直观的称呼它为反射系统。它可以帮助我们记录所有的UObject类信息。UObject是我们所有对象的基类。实际上UObject往上还有UObjectBaseUtility，UObjectBase，但是我们一般不直接用他们。

## UCLASS 宏

**UCLASS** 宏为 `UObject` 提供了一个 `UCLASS` **引用**，用于描述它在虚幻引擎中的类型。每个 UCLASS 都保留一个称作 **类默认对象（Class Default Object）** 的对象，简称CDO。CDO 本质上是一个默认"**模板**"对象，由类构建函数生成，之后就不再修改。

你可以为指定对象获取其 UCLASS 和 CDO，虽然它们通常都是只读类型。 使用 `GetClass()` 函数即可随时访问对象实例的 UCLASS。

`UCLASS` 包含定义类的一套属性和函数。这些是本地代码可用的普通 C++ 函数和变量，但被虚幻引擎特有的元数据所标记，它们在对象系统中的行为也因此受到控制。 如需了解标记语法的更多细节，请查阅[编程参考](https://dev.epicgames.com/documentation/zh-cn/unreal-engine/programming-with-cpp-in-unreal-engine)。

UObject 类还可包括仅限本地的属性，这些属性没有用 UFUNCTION 或者 UPROPERTY 指定器标记用于反射。然而，只有用[指定器](https://dev.epicgames.com/documentation/404)宏标记过的函数和属性会列举在它们对应的 UCLASS 中。
### CDO使用范例
- MyActor.h
```cpp
#pragma once

#include "CoreMinimal.h"
#include "GameFramework/Actor.h"
#include "MyActor.generated.h"


UCLASS()
class CPPPROJECT_API AMyActor : public AActor
{
	GENERATED_BODY()
	
public:	
	// Sets default values for this actor's properties
	AMyActor();
	//定义一个属性,蓝图可读写，任何地方可编辑,类别为MyProperty
	UPROPERTY(BlueprintReadWrite, EditAnywhere, Category = "MyProperty");
	int32 Money = 100;
	//获取属性函数
	UFUNCTION(BlueprintCallable, Category = "MyProperty")
	int32 GetCurMoney();
	//获取CDO属性函数
	UFUNCTION(BlueprintCallable, Category = "MyProperty")
	int32 GetCDOMoney();

protected:
	// Called when the game starts or when spawned
	virtual void BeginPlay() override;

public:	
	// Called every frame
	virtual void Tick(float DeltaTime) override;

};
```
- MyActor.cpp
```cpp
#include "MyActor.h"


// Sets default values,Money属性初始化为200
AMyActor::AMyActor() : Money(200)
{
 	// Set this actor to call Tick() every frame.  You can turn this off to improve performance if you don't need it.
	PrimaryActorTick.bCanEverTick = true;
	//创建根节点，带有transform属性
	RootComponent = CreateDefaultSubobject<USceneComponent>(TEXT("MyRoot"));
	//Money属性修改为300
	Money = 300;

}
//获取属性
int32 AMyActor::GetCurMoney()
{
	return Money;
}
//获取CDO属性
int32 AMyActor::GetCDOMoney()
{
	//通过StaticClass()方法获取AMyActor类的UClass对象。
	UClass *MyClass = AMyActor::StaticClass();
	//GetDefaultObject()是UClass类的方法，用于获取该类的默认对象（CDO）。这行代码将返回一个指向AMyActor类默认对象的指针，并将其存储在MyObject中。
	UObject *MyObject = MyClass->GetDefaultObject();
	//尝试将MyObject指针转换为AMyActor类型的指针。Cast<>是一种类型安全的转换方法，能够检查转换是否成功。如果MyObject确实是一个AMyActor类的对象，它将返回一个有效的指针；如果不是，它将返回nullptr。
	AMyActor* MyCDO = Cast<AMyActor>(MyObject);
	//如果Cast转换成功（即MyCDO不是nullptr），则返回MyCDO的Money属性值。Money是AMyActor类的一个成员变量。
	if (MyCDO) {
		return MyCDO->Money;
	}
	//如果MyCDO为空（即转换失败），则函数返回-1，表示出错或无法获取Money属性。
	return -1;
}

// Called when the game starts or when spawned
void AMyActor::BeginPlay()
{
	Super::BeginPlay();
	
}

// Called every frame
void AMyActor::Tick(float DeltaTime)
{
	Super::Tick(DeltaTime);

}
```
## 属性和函数类型

UObjects 可拥有成员变量（称作属性）或任意类型的函数。然而，为便于虚幻引擎识别并操控这些变量或函数，它们必须以特殊的宏进行标记，并符合一定类型的标准。如需了解这些标准的细节，请查阅 [Properties](https://dev.epicgames.com/documentation/zh-cn/unreal-engine/unreal-engine-uproperties)和[UFunctions](https://dev.epicgames.com/documentation/zh-cn/unreal-engine/ufunctions-in-unreal-engine)参考页面。
