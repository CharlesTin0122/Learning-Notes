# 概念
-  `TSet` 使用通过评估元素的可重写函数，将数据值本身作为键。 `TSet` 添加、查找和删除元素非常快（恒定时间）。默认情况下，`TSet`不支持重复键，但可以使用模板参数激活此行为。
# 特点
- `TSet` 是一个快速容器类，用于在顺序无关的上下文中存储唯一元素。对于大多数用例，只需要一个参数——元素类型。但是，`TSet` 可以使用不同的模板参数进行设置，以更改其行为并使其更加通用。您可以指定基于 `DefaultKeyFuncs` 的派生结构以提供哈希功能，并允许集合中存在具有相同值的多个键。最后，与其他容器类一样，您可以为其数据存储提供自定义内存分配器。
- 与 `TArray` 一样，`TSet` 是同质容器，这意味着它的所有元素都是严格相同的类型。 `TSet` 也是一种值类型，支持通常的复制、赋值和析构函数操作，以及对其元素的强所有权，这些元素在 `TSet` 时被销毁。键类型也必须是值类型。
- `TSet` 使用散列，这意味着 `KeyFuncs` 模板参数（如果提供）告诉集合如何从元素确定键、如何比较两个键是否相等、如何散列密钥，以及是否允许重复密钥。它们的默认值将返回对键的引用，使用 `operator==` 实现相等，使用非成员 `GetTypeHash` 函数进行散列。默认情况下，该集合不允许重复的键。如果您的密钥类型支持这些功能，则可以将其用作设置密钥，而无需提供自定义 `KeyFuncs` 。要编写自定义 `KeyFuncs` ，请扩展 `DefaultKeyFuncs` 结构。
- 最后，`TSet`可以采用可选的分配器来控制内存分配行为。标准虚幻引擎 4 (UE4) 分配器（例如 `FHeapAllocator` 和 `TInlineAllocator` ）不能用作 `TSet` 的分配器。相反，`TSet` 使用集合分配器，它定义集合应使用多少个哈希桶，以及使用哪些标准 UE4 分配器来存储元素。有关详细信息，请参阅`TSetAllocator`。
- 与 `TArray` 不同， `TSet` 元素在内存中的相对顺序不可靠或不稳定，并且迭代元素可能会以与它们原来的顺序不同的顺序返回它们额外。元素也不可能在内存中连续排列。集合的支持数据结构是稀疏数组，它是一个有效支持其元素之间间隙的数组。当从集合中删除元素时，稀疏数组中会出现间隙。然后将新元素添加到数组中可以填补这些空白。然而，即使 `TSet` 不打乱元素来填充间隙，指向集合元素的指针仍然可能无效，因为当整个存储已满并且添加新元素时可以重新分配整个存储。
# 示例
```cpp
	/*创建一个空的 TSet 来保存 FString 数据。 
	*TSet 将直接与 operator== 比较元素，使用 GetTypeHash 对其进行哈希处理，并使用标准堆分配器。
	*此时尚未分配任何内存。
	*/
	UPROPERTY(Category = SetExample, EditAnywhere)
	TSet<FString> FruitSet;

	/*增加元素*/
	FruitSet.Add(TEXT("Banana"));
	FSetElementId SetId = FruitSet.Add(TEXT("Grapefruit"));
	FruitSet.Add(TEXT("Pineapple"));

	/*附加*/
	TSet<FString> FruitSet2;
	FruitSet2.Emplace(TEXT("Kiwi"));
	FruitSet2.Emplace(TEXT("Melon"));
	FruitSet2.Emplace(TEXT("Mango"));
	FruitSet2.Emplace(TEXT("Orange"));
	FruitSet.Append(FruitSet2);

	/*迭代*/
	//range-for迭代
	for (auto& Elem : FruitSet)
	{
		FPlatformMisc::LocalPrint(*FString::Printf(TEXT(" \"%s\"\n"),*Elem));
	}
	//迭代器迭代
	for (auto& Elem : FruitSet)
	{
		FPlatformMisc::LocalPrint(*FString::Printf(TEXT(" \"%s\"\n"),*Elem));
	}

	/*查询*/
	int32 Count = FruitSet.Num();//元素个数
	bool bHasBanana = FruitSet.Contains(TEXT("Banana"));//是否包含特定元素
	/*Find 如果集合包含该键，则返回指向该元素值的指针；如果不包含该键，则返回空指针。对 const 集调用 Find 也会导致它返回的指针也成为 const。*/
	FString* PtrBanana = FruitSet.Find(TEXT("Banana"));// *PtrBanana == "Banana"
	FString* PtrLemon = FruitSet.Find(TEXT("Lemon"));//  PtrLemon == nullptr
	/*Array 函数返回一个 TArray，其中填充了 TSet 中所有元素的副本。您传入的数组将在操作开始时被清空*/
	TArray<FString> FruitArray = FruitSet.Array();

	/*移除*/
	FruitSet.Remove(FSetElementId::FromInteger(0));//移除首位元素
	// FruitSet == [ "Grapefruit","Pineapple","Pear","Orange","Kiwi","Melon","Mango" ]
	int32 RemovedAmountPineapple = FruitSet.Remove(TEXT("Pineapple"));
	// RemovedAmountPineapple == 1
	// FruitSet == [ "Grapefruit","Pear","Orange","Kiwi","Melon","Mango" ]
	int32 RemovedAmountLemon = FruitSet.Remove(TEXT("Lemon"));
	// RemovedAmountLemon == 0
	TSet<FString> FruitSetCopy = FruitSet;
	FruitSetCopy.Empty();

	/*排序，接受二元谓词*/
	FruitSet.Sort([](const FString& A, const FString& B) {return A > B; });
	FruitSet.Sort([](const FString& A, const FString& B) {return A.Len() < B.Len();});

	/*运算符*/
	TSet<FString> NewSet = FruitSet;

	/*Slack */
	FruitSet.Reset();// FruitSet == [ <invalid>, <invalid>, <invalid>, <invalid>, <invalid>, <invalid> ]
	/*要直接创建 slack，例如在添加元素之前预分配内存，请使用 Reserve 函数。*/
	FruitSet.Reserve(10);
	for (int32 i = 0; i < 10; ++i)
	{
		FruitSet.Add(FString::Printf(TEXT("Fruit%d"), i));
	}
	// Remove every other element from the set.
	for (int32 i = 0; i < 10; i += 2)
	{
		FruitSet.Remove(FSetElementId::FromInteger(i));
		// FruitSet == ["Fruit8", <invalid>, "Fruit6", <invalid>, "Fruit4", <invalid>, "Fruit2", <invalid>, "Fruit0", <invalid> ]
	}
	FruitSet.Shrink();
	// FruitSet == ["Fruit8", <invalid>, "Fruit6", <invalid>, "Fruit4", <invalid>, "Fruit2", <invalid>, "Fruit0" ]
	FruitSet.CompactStable();//CompactStable 在合并空元素的同时保持元素顺序，Compact不能。
	// FruitSet == ["Fruit8", "Fruit6", "Fruit4", "Fruit2", "Fruit0", <invalid>, <invalid>, <invalid>, <invalid> ]
	FruitSet.Shrink();
	// FruitSet == ["Fruit8", "Fruit6", "Fruit4", "Fruit2", "Fruit0" ]
```
