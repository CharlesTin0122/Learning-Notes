在 **Unreal Engine** 中，给一个对象添加或修改 **Gameplay Tag** 主要有两种方式：通过 **蓝图** 或 **C++**。下面我将分别介绍这两种方式。

### 1. **通过蓝图给对象添加或修改标签**

在 **蓝图** 中，`Gameplay Tag` 主要通过 `Has Tag`、`Add Tag` 和 `Remove Tag` 等节点来进行操作。你可以根据这些节点来为对象添加、检查或移除标签。

#### **步骤：**

1. **创建一个包含 Gameplay Tag 的变量**：
    
    - 在蓝图中，可以通过变量类型 `GameplayTag` 来存储标签。
2. **添加标签**：
    
    - 使用 `Add Gameplay Tag` 节点将标签添加到对象上。
    - 使用 `Has Tag` 节点来检查对象是否有特定的标签。

#### **示例：**

假设我们需要为一个角色添加 **`Character.Stunned`** 标签，表示角色处于眩晕状态。

1. **获取 `Gameplay Tag` 变量：** 你可以创建一个 `GameplayTag` 类型的变量，比如叫 `StunnedTag`，然后将标签值设为 **`Character.Stunned`**。
    
2. **使用 `Add Gameplay Tag` 节点：**
    
    - 在角色的蓝图（例如角色的 `Character` 或 `PlayerController` 蓝图）中，添加 `Add Gameplay Tag` 节点，并传入需要添加的标签。
    
    ```text
    Add Gameplay Tag (StunnedTag)
    ```
    
    这将在运行时为角色添加 **`Character.Stunned`** 标签。
    
3. **检查标签：** 你可以通过 `Has Tag` 节点检查一个对象是否具有某个标签，例如判断角色是否被眩晕：
    
    ```text
    Has Tag (Character.Stunned)
    ```
    
    如果标签存在，返回 `True`，否则返回 `False`。
    

#### **蓝图中常见的 Gameplay Tag 节点：**

- **Add Gameplay Tag**：向对象添加标签。
- **Has Tag**：检查对象是否有特定标签。
- **Remove Gameplay Tag**：移除对象上的标签。

### 2. **通过 C++ 给对象添加或修改标签**

在 **C++** 中，使用 `FGameplayTag` 类型来表示和操作标签。通常，我们会通过 `GameplayTags` 类提供的 API 来操作标签。

#### **步骤：**

1. **声明和使用 `FGameplayTag`**： `FGameplayTag` 是用于存储标签的结构体。你可以通过它来表示一个标签，并将其赋值给对象。
    
2. **给对象添加标签**： 你可以使用 `AddTag` 方法来为对象添加标签。
    

#### **示例：**

假设我们希望给一个 `ACharacter` 类型的对象添加 **`Character.Stunned`** 标签。

1. **在头文件中声明**： 首先，我们需要确保项目已启用 Gameplay Tags 功能。然后，可以声明一个 `FGameplayTag` 类型的变量，表示我们要添加的标签。
    
    ```cpp
    // GameplayTagHeader.h
    #include "GameplayTagContainer.h"
    
    FGameplayTag StunnedTag;
    ```
    
2. **在 `.cpp` 文件中初始化标签**： 使用 `FGameplayTag::RequestGameplayTag` 方法来初始化标签。
    
    ```cpp
    // GameplayTagHeader.cpp
    StunnedTag = FGameplayTag::RequestGameplayTag(FName("Character.Stunned"));
    ```
    
3. **给对象添加标签**： 假设你在某个角色对象上（如 `ACharacter`）添加标签，可以通过调用 `AddTag` 来为其添加标签。
    
    ```cpp
    // 假设角色已经有一个 `Tags` 成员变量，类型为 `FGameplayTagContainer`
    if (MyCharacter) // 检查角色对象是否有效
    {
        MyCharacter->Tags.AddTag(StunnedTag);  // 给角色添加 "Character.Stunned" 标签
    }
    ```
    
4. **检查对象是否具有标签**： 你可以使用 `HasTag` 方法来检查对象是否具有某个特定标签。
    
    ```cpp
    if (MyCharacter && MyCharacter->Tags.HasTag(StunnedTag))
    {
        // 角色处于眩晕状态
    }
    ```
    
5. **移除标签**： 如果要移除标签，可以使用 `RemoveTag` 方法。
    
    ```cpp
    MyCharacter->Tags.RemoveTag(StunnedTag); // 移除 "Character.Stunned" 标签
    ```
    

#### **示例代码总结：**

```cpp
#include "GameplayTagContainer.h"

// 声明标签
FGameplayTag StunnedTag;

// 在初始化阶段请求标签
StunnedTag = FGameplayTag::RequestGameplayTag(FName("Character.Stunned"));

// 添加标签
if (MyCharacter)
{
    MyCharacter->Tags.AddTag(StunnedTag); // 为角色添加标签
}

// 检查标签
if (MyCharacter && MyCharacter->Tags.HasTag(StunnedTag))
{
    // 如果角色被眩晕，执行相关逻辑
}

// 移除标签
MyCharacter->Tags.RemoveTag(StunnedTag); // 移除标签
```

### 3. **总结**

- **在蓝图中**：你可以通过 `Add Gameplay Tag` 和 `Has Tag` 节点来给对象添加、检查和移除标签。这种方法更适用于没有编程背景的开发人员，操作直观易懂。
    
- **在 C++ 中**：你可以使用 `FGameplayTag` 类型，结合 `AddTag`、`HasTag` 和 `RemoveTag` 方法来为对象添加、检查和删除标签。这种方法提供了更多灵活性和控制，适用于复杂的游戏逻辑实现。
    

无论使用蓝图还是 C++，**Gameplay Tags** 都是 Unreal Engine 中非常强大且灵活的工具，能够帮助你在游戏中管理复杂的状态、行为和事件。
