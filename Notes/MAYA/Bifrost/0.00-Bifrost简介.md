**Bifrost** 是 Autodesk Maya 內建的**視覺化程式設計環境**（visual programming environment），主要用來製作高品質的**程序化特效**（procedural effects）和各種模擬。

它從 Maya 2017 左右開始引入，最初主要專注在液體（Bifrost Fluids），後來不斷擴展，現在已經成為 Maya 中非常強大且全面的特效/程序化工具系統。

### Bifrost 的核心定位（2026 年最新狀態）
- **視覺化節點圖**（Bifrost Graph）：全部用拖拉節點的方式工作，類似 Houdini 的 SOP/VOP，但深度整合在 Maya 裡
- **主要應用領域**（目前已非常全面）：
  1. 流體模擬（Liquids / FLIP Solver）
  2. 氣體/煙火/爆炸（Aero）
  3. 海洋系統（BOSS - Bifrost Ocean Simulation System）
  4. 散佈 / 植被 / 環境生成（scatter, instancing）
  5. 程序化建模與變形
  6. 程序化毛髮 / 纖維 / 鏈條 / 繩索（strands）
  7. MPM 材質模擬（雪、沙、黏性物質、果凍等）
  8. **剛體破壞模擬**（Destruction，从 2025.3/2026.3 開始初步支持，使用 Voronoi + Bullet 物理）
  9. 程序化綁定（Modular Rigging，正在快速發展中）
  10. USD 流程整合與處理

### 2025–2026 年 Bifrost 的重大進展（目前最新狀態）
| 版本       | 重要更新內容                              | 意義 |
|------------|--------------------------------------------|------|
| Maya 2025  | BOSS 海洋系統全面整合到 Bifrost Graph     | 海洋特效更模組化 |
| Maya 2025.3| 雲端 wedging 模擬（Flow Wedging）         | 大量變體測試效率暴增 |
| Maya 2026  | Bifrost Liquids（原生圖內 FLIP 解算器）   | 不再需要舊 Fluids 插件，自適應解析度 + 粒子泡沫 + 彩色液體混合 |
| Maya 2026.3| 初步剛體破壞（Voronoi + Bullet）          | 破壞效果進入 Bifrost 生態 |
| 進行中     | 程序化綁定框架（Modular Rigging）         | 未來可能大幅改變 Maya 綁定工作流 |

### 簡單分類：現在最常見的 Bifrost 使用場景
1. **特效師（FX TD）最愛**
   - 水、黏液、熔岩、血漿
   - 爆炸、煙、火、雲
   - 大規模海洋 + 泡沫 + 浪花
   - 沙塵、雪崩、泥石流

2. **環境美術 / Layout**
   - 快速散佈樹木、草、碎石、垃圾
   - 程序化生成城市廢墟、森林
   - 隨機但可控的實例化

3. **技術美術 / 工具開發者**
   - 製作可重複使用的特效 compound
   - 程序化 rigging 工具
   - 客製化 USD 處理流程

4. **角色特效**
   - 衣服、頭髮的程序化輔助變形
   - 肌肉/皮膚的程序化皺紋（2026.3 新增）

### 學習建議（給不同程度的人）
- **完全新手** → 先從 Bifrost Browser 裡拖現成的 compound 開始玩（爆炸、散佈、簡單液體）
- **有 Houdini 基礎** → 直接跳進 Graph 編輯器，會上手非常快
- **想做水/海洋** → 2026 版直接學 Bifrost Liquids + BOSS
- **想做破壞** → 目前 Maya 2026.3 的 Destruction 還算初階，但已經可以做出中等規模的建築倒塌

總結一句話：

**Bifrost 已經從「Maya 的液體插件」進化成「Maya 內建的程序化特效與工具開發平台」**，正在朝著「Houdini 式的工作流但留在 Maya 裡」的方向快速前進。

如果你現在用 Maya 2026，**強烈建議**把 Bifrost Graph 打開來玩玩看，特別是新的 Liquids 和 Destruction 模組，真的變化很大。
