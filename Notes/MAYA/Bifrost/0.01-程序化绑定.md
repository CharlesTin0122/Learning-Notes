Bifrost 的**程序化綁定**（procedural rigging），在 Maya 2026 系列中主要指的是 **Bifrost Modular Rigging Framework**（模組化綁定框架），這是從 Maya 2026.1 開始正式引入的一套系統（Bifrost 2.14+），到 2026.3 又繼續補充了更多身體部位模組和工具。

它基本上是 Autodesk 想把 Houdini 那種「程序化 + 模組重用」的綁定思維，直接搬進 Maya 裡，讓綁定師可以用 Bifrost Graph 來建構可重複使用、可參數化、可快速迭代的角色綁定。

### 核心概念：模組化（Modular） + 程序化（Procedural）
- 每個綁定部件都做成一個獨立的 **Bifrost Compound**（模組）
- 這些模組像積木一樣拼裝成完整 rig
- 整個 rig 是 100% 程序化的：改比例、改拓撲、改控制器數量、加 twist、加 stretch，都可以透過參數或節點直接調整，而不用重畫骨頭或重連約束

### 目前（2026.3）已有的主要特色

| 部分              | 說明                                                                 | 實用價值 |
|-------------------|----------------------------------------------------------------------|----------|
| **模組類型**      | FK、IK、Spline、Aim、Variable FK、Leg、Spine、Arm 等身體部位模組     | 快速拼出四肢 + 脊椎 + 脖子等基礎結構 |
| **輸入/輸出介面** | 明確定義 parent、input geo、output joints/controls/attributes        | 模組間自動連接，Maya 場景可直接讀取 |
| **轉換到原生 Maya** | Bifrost Rigging 菜單 → Convert to Native Controls/Joints             | 做出來的 rig 能變成標準 Maya joint + NURBS controller，動畫師無感 |
| **無循環模式**    | 可切換成 cycle-free（無循環依賴）模式，方便 playblast / 渲染         | 解決 Maya 常見的 evaluation 卡頓問題 |
| **程序化 secondary motion** | Dynamic Geometry Analysis 節點（2026.3 新增）                        | 自動產生皺紋、肌肉抖動、皮膚滑動等 secondary 動態 |
| **Strands 整合**  | 可把 joint 轉 strands，也可反過來                               | 適合做程序化毛髮、衣服、繩子與骨骼的互動 |
| **Publish 機制**  | 把自訂模組 publish 成可重用模板，團隊共享                           | 工作室級別的 rig library 變得容易建構 |

### 典型工作流程（2026 版）
1. 開 Bifrost Graph Editor
2. 用 **Bifrost Rigging** 菜單（在 Rigging menu set 裡） → Create Rig Graph 或直接新建 graph
3. 拖入現成模組（例如 leg、spine）或自己建 custom module
4. 連接模組（parent/child、geo input）
5. 調整參數（stretchy、volume preservation、twist distribution 等）
6. 執行 Convert to Native → 產生 Maya joints + controllers
7. 動畫師像平常一樣 keyframe
8. 需要改 rig 時 → 回到 Bifrost Graph 改參數或加節點 → 重新 sync

### 優點（相較傳統 Maya rigging）
- **重用性極高**：做一次手臂模組，全公司所有角色都能用（只要比例/關節數相近）
- **改動超快**：角色突然變胖/變高/加手指 → 改幾個數字就行，不用重 bind skin
- **程序化 secondary**：皺紋、肌肉 secondary motion 可以跟 pose 即時連動，不用另外做 blendshape 或 corrective
- **USD 友好**：整個 rig 可以輸出成 USD stage，方便進 Unreal / Houdini
- **不用離開 Maya**：不像 KineFX 要跳 Houdini

### 目前限制（2026.3 階段）
- 還不算完全成熟，很多高階 rigging（如 facial、complex foot-roll、space switching）還需要自訂節點或混合傳統方式
- 學習曲線陡（如果你沒碰過程序化工具，會覺得像在學 Houdini）
- 轉成 native 後的 rig 評估速度有時不如手動搭的（雖然有 cycle-free 模式改善）
- 自訂模組的 UI 還不夠友好（publish 後的參數暴露需要手動整理）

### 學習路徑建議
1. 先看 Autodesk 官方 YouTube 系列：**Bifrost Rigging in Maya**（Matthew Tucker 講的，7 個 part，從 framework 到 publish custom module）
2. 官方文件：搜 "Bifrost Rigging Module Framework"（Maya Help 裡有完整說明）
3. 實作練習：從 leg + spine 開始拼，然後試著做一個簡單的 tail 或 tentacle 自訂模組
4. 進階：結合 strands 做程序化肌肉/皮膚滑動 + Dynamic Geometry Analysis 做皺紋

總結一句：

**Bifrost 程序化綁定 = Maya 原生綁定 + Houdini 式的模組化與程序化**，目前已經可以做出生產級的四肢/脊椎基礎 rig，並大幅加速迭代與 secondary motion 的製作。2026 這一年是它真正開始能投入實戰的階段，如果你們工作室有考慮轉向更程序化的綁定流程，現在正是很好的切入點。
