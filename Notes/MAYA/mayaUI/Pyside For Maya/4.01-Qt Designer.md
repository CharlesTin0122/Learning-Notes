### Qt Designer 简介

Qt Designer 是 Qt 框架提供的一个可视化界面设计工具，用于创建和编辑用户界面（UI）。它允许开发者通过拖放控件的方式快速构建图形界面，生成 `.ui` 文件（基于 XML 格式），这些文件可以被转换为 Python 代码或直接在程序中加载。Qt Designer 主要用于设计基于 Qt 的应用程序界面，适用于 C++、Python（通过 PySide 或 PyQt）等开发环境。

在 Python 中，PySide（Qt for Python）是一个常用的 Qt 绑定库，Qt Designer 可以与 PySide 配合使用，简化 GUI 开发的流程。

---

### Qt Designer 的主要功能
1. **可视化设计**：通过拖拽控件（如按钮、标签、文本框等）设计界面布局，支持多种布局管理器（如垂直布局、水平布局、网格布局等）。
2. **控件丰富**：提供大量内置控件，包括按钮、输入框、组合框、表格、菜单等，满足复杂界面需求。
3. **信号与槽编辑**：支持定义控件之间的信号与槽连接，用于处理用户交互（如点击按钮触发事件）。
4. **跨平台支持**：设计出的界面可在 Windows、macOS、Linux 等平台运行。
5. **生成 .ui 文件**：保存的 `.ui` 文件可通过工具转换为 Python 代码，或在运行时动态加载。

### 在 PySide 中的用法

PySide 是 Qt 的官方 Python 绑定，与 Qt Designer 结合使用可以快速开发 GUI 应用程序。以下是 Qt Designer 在 PySide 中使用的完整流程：

#### 1. **安装 PySide 和 Qt Designer**
确保已安装 PySide6（或其他版本，如 PySide2）和 Qt Designer。可以通过以下命令安装 PySide6：
```bash
pip install pyside6
```
Qt Designer 通常包含在 PySide6 安装中（`pyside6-designer` 命令）或 Qt 官方安装包中。如果未安装，可通过 Qt 官网下载 Qt Creator 或单独的 Qt Designer。

#### 2. **使用 Qt Designer 设计界面**
1. 启动 Qt Designer（运行 `pyside6-designer` 或通过 Qt Creator 打开）。
2. 创建新窗体（Main Window、Widget 或 Dialog）。
3. 在界面上拖放控件（如 QPushButton、QLineEdit、QLabel 等）。
4. 使用布局管理器（如 QVBoxLayout、QHBoxLayout）组织控件，确保界面自适应窗口大小。
5. 设置控件的属性（如对象名称、文本、大小等）。
6. 可选：通过信号与槽编辑器定义交互逻辑（例如，按钮点击触发函数）。
7. 保存设计为 `.ui` 文件，例如 `mainwindow.ui`。

#### 3. **将 .ui 文件集成到 PySide**
`.ui` 文件需要转换为 Python 代码或动态加载到 PySide 程序中。以下是两种常用方法：

##### 方法 1：将 .ui 文件转换为 Python 代码
使用 `pyside6-uic` 工具将 `.ui` 文件转换为 Python 代码：
```bash
pyside6-uic mainwindow.ui -o mainwindow.py
```
这会生成一个 `mainwindow.py` 文件，包含界面定义的 Python 类。

在主程序中导入并使用生成的类：
```python
import sys
from PySide6.QtWidgets import QApplication, QMainWindow
from mainwindow import Ui_MainWindow  # 导入生成的 UI 类

class MainWindow(QMainWindow):
    def __init__(self):
        super().__init__()
        self.ui = Ui_MainWindow()
        self.ui.setupUi(self)  # 设置 UI
        self.ui.pushButton.clicked.connect(self.on_button_clicked)  # 连接信号与槽

    def on_button_clicked(self):
        self.ui.label.setText("Button Clicked!")  # 示例：按钮点击后修改标签文本

if __name__ == "__main__":
    app = QApplication(sys.argv)
    window = MainWindow()
    window.show()
    sys.exit(app.exec())
```

##### 方法 2：动态加载 .ui 文件
不将 `.ui` 文件转换为 Python 代码，而是使用 `PySide6.uic` 模块在运行时加载：
```python
import sys
from PySide6.QtWidgets import QApplication, QMainWindow
from PySide6.QtUiTools import QUiLoader
from PySide6.QtCore import QFile, QIODevice

class MainWindow(QMainWindow):
    def __init__(self):
        super().__init__()
        # 加载 .ui 文件
        loader = QUiLoader()
        file = QFile("mainwindow.ui")
        file.open(QIODevice.ReadOnly)
        self.ui = loader.load(file, self)
        file.close()
        # 连接信号与槽
        self.ui.pushButton.clicked.connect(self.on_button_clicked)

    def on_button_clicked(self):
        self.ui.label.setText("Button Clicked!")

if __name__ == "__main__":
    app = QApplication(sys.argv)
    window = MainWindow()
    window.show()
    sys.exit(app.exec())
```

#### 4. **信号与槽的实现**
- 在 Qt Designer 中，可以通过信号与槽编辑器预定义控件交互（例如，按钮的 `clicked` 信号连接到自定义槽）。
- 在 Python 代码中，使用 `connect()` 方法绑定信号到自定义函数（如上例中的 `on_button_clicked`）。
- 自定义槽函数可以操作界面控件或执行其他逻辑。

#### 5. **注意事项**
- **对象名称**：在 Qt Designer 中为控件设置唯一的 `objectName`，以便在 Python 中通过 `self.ui.<objectName>` 访问。
- **布局管理**：始终使用布局管理器，避免固定大小的控件，确保界面在不同分辨率下自适应。
- **资源文件**：若界面使用图片等资源，可通过 Qt Designer 的资源管理器创建 `.qrc` 文件，并用 `pyside6-rcc` 转换为 Python 模块。
- **版本兼容性**：确保 PySide 版本与 Qt Designer 版本兼容（例如，PySide6 对应 Qt 6.x）。
- **动态加载 vs 静态转换**：
  - 动态加载（方法 2）适合快速原型开发，修改 `.ui` 文件无需重新生成代码。
  - 静态转换（方法 1）适合大型项目，代码更易于维护和优化。

#### 6. **示例：简单计算器界面**
1. 在 Qt Designer 中：
   - 创建一个主窗口。
   - 添加两个 QLineEdit（输入数字）、一个 QPushButton（计算按钮）、一个 QLabel（显示结果）。
   - 使用垂直布局排列控件。
   - 保存为 `calculator.ui`。
2. 转换为 Python 代码：
   ```bash
   pyside6-uic calculator.ui -o calculator.py
   ```
3. 主程序：
   ```python
   import sys
   from PySide6.QtWidgets import QApplication, QMainWindow
   from calculator import Ui_MainWindow

   class MainWindow(QMainWindow):
       def __init__(self):
           super().__init__()
           self.ui = Ui_MainWindow()
           self.ui.setupUi(self)
           self.ui.pushButton.clicked.connect(self.calculate)

       def calculate(self):
           try:
               num1 = float(self.ui.lineEdit.text())
               num2 = float(self.ui.lineEdit_2.text())
               result = num1 + num2
               self.ui.label.setText(f"Result: {result}")
           except ValueError:
               self.ui.label.setText("Invalid input")

   if __name__ == "__main__":
       app = QApplication(sys.argv)
       window = MainWindow()
       window.show()
       sys.exit(app.exec())
   ```

### 优势与局限性
**优势**：
- 快速构建复杂界面，减少手动编码。
- 界面与逻辑分离，便于维护。
- 支持跨平台开发，界面一致性高。

**局限性**：
- Qt Designer 更适合静态界面设计，动态界面需在代码中实现。
- 复杂逻辑仍需在 Python 中编写。
- 学习曲线较陡，需熟悉 Qt 的信号与槽机制。

### 案例
```python 
from pathlib import Path
from PySide2 import QtCore, QtWidgets
from PySide2 import QtUiTools
# from Qt import QtCompat


class DesignerUI(QtWidgets.QDialog):
    _ui_instance = None
    WINDOW_TITLE = "Qt Designer Template"

    def __init__(self, ui_path=None, parent=None):
        if parent is None:
            parent = self.get_maya_main_window()
        super().__init__(parent)

        self.setWindowTitle(DesignerUI.WINDOW_TITLE)

        self.init_ui(ui_path)
        self.create_layout()
        self.create_connections()

    def init_ui(self, ui_path=None):
        if not ui_path:
            ui_path = f"{Path(__file__).parent}/quick_start.ui"
        # Qt.py 库的用法
        # self.ui = QtCompat.loadUi(
        #     r"D:\CT_Tools_mod\scripts\ScriptPackages\Extra\quick_start.ui",
        #     baseinstance=self,
        # )

        # PySide2的用法

        f = QtCore.QFile(ui_path)
        f.open(QtCore.QFile.ReadOnly)

        loader = QtUiTools.QUiLoader()
        self.ui = loader.load(f, parentWidget=self)

        f.close()

    def create_layout(self):
        self.ui.layout().setContentsMargins(6, 6, 6, 6)

    def create_connections(self):
        btn_ok = self.ui.findChild(QtWidgets.QPushButton, "btn_ok")
        btn_ok.clicked.connect(self.on_btn_ok_clicked)

        self.ui.btn_cancel.clicked.connect(self.close)

    @QtCore.Slot()
    def template_slot(self):
        pass

    @QtCore.Slot()
    def on_btn_ok_clicked(self):
        print("clicked OK")

    @staticmethod
    def get_maya_main_window():
        """通过 QApplication 获取 Maya 主窗口的 PySide 实例"""
        # 用于获取当前运行的 maya QApplication 实例
        app = QtWidgets.QApplication.instance()
        # 如果当前没有运行的实例，返回None
        if not app:
            return None
        # app.topLevelWidgets() 返回当前 QApplication 管理的所有顶层窗口（没有父窗口）列表
        for widget in app.topLevelWidgets():
            # 如果窗口的 Qt 对象名称为"MayaWindow"，返回这个窗口实例
            if widget.objectName() == "MayaWindow":
                return widget
        return None

    @classmethod
    def show_ui(cls, ui_Path=None):
        """单例模式显示UI"""
        if cls._ui_instance is None:
            cls._ui_instance = DesignerUI(ui_Path)
        if cls._ui_instance.isHidden():
            cls._ui_instance.show()
        else:
            cls._ui_instance.raise_()
            cls._ui_instance.activateWindow()


if __name__ == "__main__":
    # 在maya中直接运行需要绝对路径
    ui_path = r"D:\CT_Tools_mod\scripts\ScriptPackages\Extra\quick_start.ui"
    DesignerUI.show_ui(ui_path)

```
