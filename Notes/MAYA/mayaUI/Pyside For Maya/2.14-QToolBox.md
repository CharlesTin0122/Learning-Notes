QToolBox 是 PySide（现为 PySide6，Qt for Python 的官方绑定）中的一个控件，用于创建类似工具箱或选项卡式布局的界面，允许用户通过点击标题切换显示不同的内容区域。它类似于 QTabWidget，但以垂直堆叠的方式显示内容，常用于需要节省空间且内容分类明确的界面设计。

### QToolBox 的主要特点
1. **垂直堆叠**：QToolBox 中的每个“页面”以垂直方式排列，每个页面有一个标题，点击标题可以展开或折叠对应的内容。
2. **单一显示**：一次只能显示一个页面的内容，其他页面会折叠隐藏。
3. **轻量设计**：适合在空间有限的情况下组织多个控件组。
4. **动态管理**：支持动态添加、移除或修改页面。

### QToolBox 的核心方法
以下是 QToolBox 的一些常用方法：
- `addItem(widget, title)`：添加一个控件（QWidget）作为新页面，并设置其标题。
- `insertItem(index, widget, title)`：在指定索引位置插入页面。
- `removeItem(index)`：移除指定索引的页面。
- `setCurrentIndex(index)`：设置当前显示的页面索引。
- `currentIndex()`：返回当前显示页面的索引。
- `count()`：返回页面总数。
- `setItemText(index, text)`：设置指定索引页面的标题。
- `itemText(index)`：获取指定索引页面的标题。
- `widget(index)`：返回指定索引的控件。
### 信号和事件

```python
# 当前活动项改变时发出的信号
toolbox.currentChanged.connect(self.on_current_changed)

def on_current_changed(self, index):
    print(f"当前选中的页面索引: {index}")
    print(f"页面标题: {toolbox.itemText(index)}")
```

### 使用 QToolBox 的示例代码
以下是一个简单的 PySide6 示例，展示如何使用 QToolBox 创建一个带有多个页面的工具箱：

```python
import sys
from PySide6.QtWidgets import QApplication, QToolBox, QWidget, QVBoxLayout, QLabel, QPushButton

class MainWindow(QWidget):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("QToolBox 示例")
        
        # 创建主布局
        layout = QVBoxLayout(self)
        
        # 创建 QToolBox
        toolbox = QToolBox()
        layout.addWidget(toolbox)
        
        # 创建第一个页面
        page1 = QWidget()
        page1_layout = QVBoxLayout(page1)
        page1_layout.addWidget(QLabel("这是页面 1 的内容"))
        page1_layout.addWidget(QPushButton("按钮 1"))
        toolbox.addItem(page1, "页面 1")
        
        # 创建第二个页面
        page2 = QWidget()
        page2_layout = QVBoxLayout(page2)
        page2_layout.addWidget(QLabel("这是页面 2 的内容"))
        page2_layout.addWidget(QPushButton("按钮 2"))
        toolbox.addItem(page2, "页面 2")
        
        # 创建第三个页面
        page3 = QWidget()
        page3_layout = QVBoxLayout(page3)
        page3_layout.addWidget(QLabel("这是页面 3 的内容"))
        page3_layout.addWidget(QPushButton("按钮 3"))
        toolbox.addItem(page3, "页面 3")
        
        # 连接信号以监控页面切换
        toolbox.currentChanged.connect(self.on_page_changed)
        
        self.setLayout(layout)
    
    def on_page_changed(self, index):
        print(f"当前页面索引: {index}, 标题: {self.sender().itemText(index)}")

if __name__ == "__main__":
    app = QApplication(sys.argv)
    window = MainWindow()
    window.resize(400, 300)
    window.show()
    sys.exit(app.exec())
```

### 代码说明
1. **创建 QToolBox**：通过 `QToolBox()` 创建工具箱控件，并将其添加到主窗口的布局中。
2. **添加页面**：每个页面是一个 QWidget，可以包含任意子控件（如 QLabel、QPushButton 等）。使用 `addItem()` 将页面及其标题添加到工具箱。
3. **页面切换信号**：通过 `currentChanged` 信号监控页面切换事件，打印当前页面的索引和标题。
4. **布局管理**：每个页面使用 QVBoxLayout 组织其子控件，确保内容排列整齐。

### 使用场景
- **工具面板**：如绘图软件的工具选项（画笔、颜色、图层等）。
- **设置界面**：将不同类别的设置分组，方便用户切换查看。
- **折叠式菜单**：在空间有限的界面中组织大量选项。

### 注意事项
1. **页面内容**：每个页面必须是 QWidget 或其子类的实例，不能直接添加基本数据类型或其他非控件对象。
2. **样式定制**：可以通过 Qt 样式表（QSS）自定义 QToolBox 的标题栏外观，如背景色、字体等。
3. **性能**：如果页面内容复杂（如包含大量控件或图像），建议在切换时动态加载以优化性能。

QToolBox 是一个简单但实用的控件，适合需要垂直组织多个内容区域的场景。通过 PySide6 的 API，你可以轻松创建、配置和管理工具箱页面，并通过信号处理用户交互。如果需要更多高级功能，可以结合 QSS 或其他 Qt 控件进一步扩展其功能。
