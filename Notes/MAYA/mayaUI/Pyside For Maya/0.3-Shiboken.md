Shiboken 是 PySide（Qt for Python）项目中的一个核心组件，主要用于生成 C++ 库与 Python 之间的绑定（bindings）。它是 Qt for Python 的绑定生成器，负责将 C++ 代码（尤其是 Qt 框架）转换为 Python 可调用的模块。Shiboken 的设计目标是生成高效、轻量级的绑定代码，相比其他工具（如 Boost.Python），它生成的二进制文件更小，内存占用更低。以下是对 Shiboken 库的详细介绍，包括其功能、组成、用法及与 PySide 的关系。

---

### 一、Shiboken 简介
Shiboken 是一个 **绑定生成器**（Binding Generator），用于将 C++ 库（特别是 Qt 库）包装为 Python 模块，允许 Python 开发者直接调用 C++ 代码。它是 PySide 的底层技术支持，最初由 Nokia 开发，用于替代基于 Boost.Python 的早期 PySide 实现，目的是减少生成代码的体积和复杂性。Shiboken 使用 CPython 的 C API 生成绑定代码，并结合 **ApiExtractor** 解析 C++ 头文件以提取类、方法等信息。

**关键特点**：
- **高效性**：生成轻量级绑定，减少二进制文件大小和内存占用。[](https://pypi.org/project/Shiboken/)[](https://en.wikipedia.org/wiki/PySide)
- **跨平台**：支持 Windows、macOS、Linux 等平台。
- **LGPL 许可证**：与 PySide 一致，适合开源和商业项目。
- **支持复杂 C++ 特性**：包括多态、运算符重载、函数重载等。[](https://groups.google.com/g/pyside/c/LwChUeGgSCY)
- **与 Qt 紧密集成**：专为 Qt 框架优化，但也可用于其他 C++ 库。

Shiboken 的主要用途是支持 PySide 的开发，同时也允许开发者为自定义 C++ 库生成 Python 绑定。

---

### 二、Shiboken 的组成
Shiboken 由以下两个主要部分组成：

1. **Shiboken 生成器（Generator）**：
   - 功能：解析 C++ 头文件，生成 CPython 扩展模块的 C++ 代码（`.h` 和 `.cpp` 文件）。
   - 依赖：使用 **ApiExtractor** 库（基于 Clang）解析 C++ 代码，提取类、函数、枚举等信息。
   - 工作流程：
     1. 解析 C++ 头文件，生成类型系统信息。
     2. 根据类型系统文件（XML 格式）自定义绑定行为（如修改方法签名、移除类）。
     3. 输出 Python 模块的 C++ 包装代码。
   - 示例：为 Qt 的 `QWidget` 类生成 Python 绑定，使其可在 Python 中调用。

2. **Shiboken 模块（Python Utility Module）**：
   - 功能：提供运行时支持，包含一组 Python 函数，用于访问和管理 Shiboken 生成的绑定对象的内部信息。
   - 常用功能：
     - 检查对象有效性（`shiboken.isValid(obj)`）：判断 C++ 对象是否仍然可用。
     - 包装 C++ 对象（`shiboken.wrapInstance(address, type)`）：为指定内存地址的 C++ 对象创建 Python 包装。
     - 检查对象归属（`shiboken.isOwnedByPython(obj)`）：判断 C++ 对象是否由 Python 管理。
     - 调试信息（`shiboken.dump(obj)`）：输出对象的调试信息，仅限开发者使用。[](https://github.com/PySide/shiboken-docs/blob/master/docs/shibokenmodule.rst)[](https://shiboken.readthedocs.io/en/latest/shibokenmodule.html)
   - 使用场景：集成 PySide 到支持 Python 脚本的 Qt 程序（如 Maya），或用于调试绑定问题。

---

### 三、Shiboken 的安装
Shiboken 通常与 PySide 一起安装，无需单独安装。PySide6（对应 Qt 6）和 PySide2（对应 Qt 5）都包含 Shiboken。安装命令如下：

```bash
pip install pyside6  # 安装 PySide6 和 Shiboken6
# 或者
pip install pyside2  # 安装 PySide2 和 Shiboken2
```

如果需要从源代码构建 Shiboken（例如为自定义 C++ 库生成绑定），需满足以下依赖：
- **Python**：3.6 或更高版本。
- **Qt 库**：Qt 5（用于 PySide2）或 Qt 6（用于 PySide6）。
- **Clang**：用于 ApiExtractor 解析 C++ 代码，建议版本 6.0（PySide2）或 13.0（PySide6）及以上。[](https://pypi.org/project/PySide6/)[](https://pypi.org/project/PySide2/)
- **CMake**：用于构建 Shiboken 和 PySide。
- **LLVM_INSTALL_DIR**：设置 Clang 的 include 和 lib 路径。

源代码安装示例：
```bash
git clone https://code.qt.io/pyside/pyside-setup
cd pyside-setup
git checkout 6.x  # 选择特定版本
python setup.py install --qtpaths=/path/to/qtpaths6 --parallel=8
```

### 四、Shiboken 的用法
Shiboken 主要用于以下两种场景：使用 PySide 的运行时模块，或为自定义 C++ 库生成 Python 绑定。

#### 1. 使用 Shiboken 模块
Shiboken 模块提供了一些工具函数，主要用于调试或与 C++ 对象交互。例如：

```python
import shiboken6 as shiboken
from PySide6.QtWidgets import QPushButton

button = QPushButton("Test")
print(shiboken.isValid(button))  # 检查按钮对象是否有效：True
print(shiboken.isOwnedByPython(button))  # 检查是否由 Python 管理：True
print(shiboken.dump(button))  # 输出按钮对象的调试信息
```

**注意**：
- 这些函数主要用于调试或特定场景（如与 Qt 集成的程序）。
- 如果对象不是 Shiboken 生成的绑定对象（如普通 Python 对象），会抛出 `TypeError`。[](https://github.com/PySide/shiboken-docs/blob/master/docs/shibokenmodule.rst)

#### 2. 为自定义 C++ 库生成绑定
Shiboken 的核心功能是为 C++ 库生成 Python 绑定。以下是生成绑定的基本步骤：

1. **准备 C++ 库**：
   - 提供头文件（`.h`），包含需要绑定的类、函数、枚举等。
   - 示例头文件（`example.h`）：
     ```cpp
     #pragma once
     #include <QObject>
     class MyClass : public QObject {
         Q_OBJECT
     public:
         MyClass(QObject* parent = nullptr);
         QString sayHello() const;
     signals:
         void mySignal(const QString& message);
     public slots:
         void mySlot();
     };
     ```

2. **创建类型系统文件**：
   - 类型系统文件（XML 格式）定义如何生成绑定，可自定义类、方法的行为。
   - 示例（`typesystem.xml`）：
     ```xml
     <typesystem>
         <object-type name="MyClass"/>
     </typesystem>
     ```

3. **运行 Shiboken 生成器**：
   - 使用 `shiboken6` 命令生成绑定代码：
     ```bash
     shiboken6 --generator-set=shiboken --output-directory=generated example.h typesystem.xml
     ```
   - 输出：生成 `generated` 目录，包含 `.h` 和 `.cpp` 文件，用于编译成 Python 模块。

4. **编译和安装**：
   - 使用 CMake 或其他构建工具编译生成的代码。
   - 将生成的 Python 模块安装到 Python 环境中。

5. **在 Python 中使用**：
   ```python
   from generated import MyClass
   obj = MyClass()
   obj.mySignal.connect(lambda msg: print(f"Signal: {msg}"))
   print(obj.sayHello())
   ```

**示例博客**：一个详细的绑定生成教程可参考 basysKom 的文章，介绍了如何为简单的 Qt 库生成绑定。[](https://blog.basyskom.com/2019/using-shiboken2-to-create-python-bindings-for-a-qt-library/)

---

### 五、Shiboken 与 PySide 的关系
- **PySide 的底层技术**：PySide 是基于 Shiboken 生成的 Qt 绑定。Shiboken 解析 Qt 的 C++ 头文件，生成 Python 模块（如 `QtWidgets`、`QtCore`）。
- **版本对应**：
  - PySide2 和 Shiboken2 对应 Qt 5。
  - PySide6 和 Shiboken6 对应 Qt 6。
- **依赖性**：安装 PySide 时会自动包含 Shiboken，无需单独处理。

### 六、Shiboken 的优势与局限
**优势**：
- **轻量级**：相比 Boost.Python，Shiboken 生成的代码更小，内存占用低。[](https://en.wikipedia.org/wiki/PySide)[](https://github.com/pyside/shiboken-docs/blob/master/docs/faq.rst)
- **灵活性**：通过类型系统文件支持高度自定义（如修改方法签名、移除类）。[](https://wiki.qt.io/Qt_for_Python/Shiboken)
- **与 Qt 集成**：专为 Qt 优化，适合开发 Qt 应用程序。
- **跨平台支持**：支持多种操作系统和 Python 版本。

**局限**：
- **文档不足**：Shiboken 的官方文档较为有限，学习曲线较陡，尤其是生成自定义绑定时。[](https://groups.google.com/g/pyside/c/LwChUeGgSCY)
- **复杂性**：生成绑定需要编写类型系统文件，配置 Clang 和 CMake，初学者可能感到复杂。[](https://groups.google.com/g/pyside/c/LwChUeGgSCY)
- **依赖 Clang**：构建过程依赖 Clang 库，增加了配置难度。[](https://pypi.org/project/PySide6/)

### 八、总结
Shiboken 是 PySide 的核心组件，分为生成器（生成 C++ 到 Python 的绑定代码）和运行时模块（提供调试和管理功能）。它通过解析 C++ 头文件并结合类型系统文件，生成高效的 Python 绑定，特别适合与 Qt 框架集成。开发者可以使用 Shiboken 为自定义 C++ 库创建 Python 模块，或通过 Shiboken 模块调试 PySide 应用。虽然功能强大，但由于文档和配置复杂性，初学者可能需要更多实践。建议从官方文档和简单示例（如 `libsample`）开始学习，逐步掌握绑定生成流程。

# 用于获取maya主角面的Python 实例

在 Autodesk Maya 中使用 PySide 开发界面时，经常需要获取 Maya 主窗口的 Python 实例（通常作为 PySide 界面的父窗口），以确保界面正确嵌入 Maya 并避免被 Python 垃圾回收器销毁。Shiboken 库的 `wrapInstance` 函数是实现这一目标的常用工具，它可以将 Maya 的 C++ 窗口指针转换为 PySide 的 Python 对象。以下详细介绍如何在 Maya 中使用 Shiboken 获取主窗口实例，并结合 PySide 开发界面。

---

### 一、背景知识
- **为什么需要获取 Maya 主窗口？**  
  Maya 的界面基于 Qt，而 PySide 是 Qt 的 Python 绑定。为了在 Maya 中创建 PySide 界面并正确管理其生命周期（例如避免窗口被意外销毁），需要将自定义窗口的父对象设置为 Maya 的主窗口。
- **Shiboken 的作用**：
  Shiboken 的 `wrapInstance` 函数可以将 C++ 对象的内存地址（指针）包装为 Python 的 PySide 对象。Maya 提供了 `OpenMayaUI.MQtUtil.mainWindow()` 方法返回主窗口的 C++ 指针，Shiboken 负责将其转换为 `QWidget` 或 `QMainWindow` 的 Python 实例。
- **版本差异**：
  - Maya 2016 及更早版本使用 PySide（基于 Qt 4）和 `shiboken`。
  - Maya 2017 及以上版本使用 PySide2（基于 Qt 5）和 `shiboken2`。
  - Maya 2024 及以上版本支持 PySide6（基于 Qt 6）和 `shiboken6`。

---

### 二、实现步骤
以下是使用 Shiboken 获取 Maya 主窗口并创建 PySide 界面的通用步骤：

1. **导入必要的模块**：
   - `maya.OpenMayaUI`：提供 Maya 的 Qt 界面工具（如 `MQtUtil`）。
   - `PySide2.QtWidgets` 或 `PySide6.QtWidgets`：提供 Qt 控件（如 `QWidget`、`QMainWindow`）。
   - `shiboken2` 或 `shiboken6`：提供 `wrapInstance` 函数。

2. **获取 Maya 主窗口指针**：
   - 使用 `maya.OpenMayaUI.MQtUtil.mainWindow()` 获取主窗口的 C++ 指针。

3. **使用 Shiboken 包装指针**：
   - 调用 `shiboken2.wrapInstance` 或 `shiboken6.wrapInstance`，将指针转换为 `QWidget` 或 `QMainWindow`。

4. **创建 PySide 界面并设置父窗口**：
   - 创建自定义窗口（继承 `QDialog` 或 `QMainWindow`），并将父窗口设置为 Maya 主窗口。

5. **管理窗口生命周期**：
   - 确保窗口对象被正确引用，避免被 Python 垃圾回收器销毁。

---

### 三、代码示例
以下是一个完整的示例，展示如何在 Maya 中使用 Shiboken 获取主窗口并创建 PySide 界面。代码兼容 PySide2（Maya 2017 及以上）和 PySide（Maya 2016 及更早版本）。

```python
import sys
import maya.OpenMayaUI as omui
from PySide2.QtWidgets import QApplication, QMainWindow, QWidget, QVBoxLayout, QPushButton, QLabel

try:
    from shiboken2 import wrapInstance
except ImportError:
    from shiboken import wrapInstance

def get_maya_main_window():
    """获取 Maya 主窗口的 PySide 实例"""
    ptr = omui.MQtUtil.mainWindow()
    if ptr is not None:
        return wrapInstance(int(ptr), QWidget)  # 转换为 QWidget
    return None

class MayaWindow(QMainWindow):
    def __init__(self, parent=None):
        super().__init__(parent)
        self.setWindowTitle("Maya PySide 示例")
        self.setGeometry(100, 100, 300, 200)

        # 创建控件
        self.label = QLabel("欢迎使用 PySide 界面！", self)
        self.button = QPushButton("点击我", self)

        # 设置布局
        layout = QVBoxLayout()
        layout.addWidget(self.label)
        layout.addWidget(self.button)

        # 创建中央部件并设置布局
        container = QWidget()
        container.setLayout(layout)
        self.setCentralWidget(container)

        # 连接信号与槽
        self.button.clicked.connect(self.on_button_click)

    def on_button_click(self):
        self.label.setText("按钮被点击！")

def main():
    # 获取 Maya 的 QApplication 实例
    app = QApplication.instance()
    if not app:
        app = QApplication(sys.argv)

    # 获取 Maya 主窗口
    maya_main_window = get_maya_main_window()
    if not maya_main_window:
        print("无法获取 Maya 主窗口")
        return

    # 创建窗口并设置父窗口
    window = MayaWindow(parent=maya_main_window)
    window.show()

if __name__ == "__main__":
    main()
```

---

### 四、代码说明
1. **模块导入**：
   - 使用 `try-except` 导入 `shiboken2` 或 `shiboken`，确保代码兼容不同 Maya 版本。
   - 导入 `maya.OpenMayaUI` 获取 C++ 指针，`PySide2.QtWidgets` 提供 Qt 控件。

2. **获取主窗口**：
   - `omui.MQtUtil.mainWindow()` 返回 Maya 主窗口的 C++ 指针。
   - `wrapInstance(int(ptr), QWidget)` 将指针包装为 `QWidget` 实例。注意使用 `int(ptr)`（或早期版本的 `long(ptr)`）将指针转换为 Python 整数。

3. **创建界面**：
   - `MayaWindow` 继承 `QMainWindow`，创建简单的标签和按钮界面。
   - 父窗口设置为 `get_maya_main_window()` 的返回值，确保窗口嵌入 Maya。

4. **运行逻辑**：
   - 检查 `QApplication.instance()` 是否存在，避免重复创建 QApplication。
   - 调用 `window.show()` 显示窗口。

---

### 五、现代替代方法（Maya 2017 及以上）
从 Maya 2017 开始，Autodesk 提供了更简便的方式获取主窗口，无需直接使用 Shiboken。例如，可以使用 `pymel` 或遍历 `QApplication` 的顶层窗口：

#### 1. 使用 PyMEL
PyMEL 提供了 `asQtObject()` 方法直接获取 Qt 窗口对象：
```python
import pymel.core as pm
from PySide2.QtWidgets import QDialog

def get_maya_main_window():
    return pm.ui.Window("MayaWindow").asQtObject()

class MayaDialog(QDialog):
    def __init__(self, parent=None):
        super().__init__(parent)
        self.setWindowTitle("PyMEL 示例")
        self.setGeometry(100, 100, 200, 100)

def main():
    maya_main_window = get_maya_main_window()
    dialog = MayaDialog(parent=maya_main_window)
    dialog.show()

if __name__ == "__main__":
    main()
```

#### 2. 使用 QApplication.topLevelWidgets()
遍历顶层窗口，查找 `objectName` 为 `"MayaWindow"` 的窗口：
```python
from PySide2.QtWidgets import QApplication, QDialog

def get_maya_main_window():
    app = QApplication.instance()
    if not app:
        return None
    for widget in app.topLevelWidgets():
        if widget.objectName() == "MayaWindow":
            return widget
    return None

class MayaDialog(QDialog):
    def __init__(self, parent=None):
        super().__init__(parent)
        self.setWindowTitle("QApplication 示例")
        self.setGeometry(100, 100, 200, 100)

def main():
    maya_main_window = get_maya_main_window()
    if not maya_main_window:
        print("无法获取 Maya 主窗口")
        return
    dialog = MayaDialog(parent=maya_main_window)
    dialog.show()

if __name__ == "__main__":
    main()
```

**优点**：
- 代码更简洁，不依赖 `shiboken` 或 `OpenMayaUI`。
- `pymel` 方法更直观，适合快速开发。
- 遍历 `topLevelWidgets` 的方法适用于跨版本兼容。

**缺点**：
- `pymel` 可能增加额外开销。
- 遍历 `topLevelWidgets` 依赖窗口名称，可能在特殊情况下不可靠。

---

### 六、注意事项
1. **Shiboken 版本兼容性**：
   - Maya 2016 及更早版本：使用 `shiboken.wrapInstance` 和 `PySide.QtGui.QWidget`。
   - Maya 2017-2023：使用 `shiboken2.wrapInstance` 和 `PySide2.QtWidgets.QWidget`。
   - Maya 2024 及以上：使用 `shiboken6.wrapInstance` 和 `PySide6.QtWidgets.QWidget`。
   - 代码中应使用 `try-except` 确保兼容性（如示例所示）。

2. **指针类型转换**：
   - 早期版本使用 `long(ptr)`，新版本使用 `int(ptr)`，因为 Python 3 统一了整数类型。
   - 确保使用正确的 `QWidget` 或 `QMainWindow` 作为 `wrapInstance` 的第二个参数。

3. **父窗口的重要性**：
   - 不设置父窗口可能导致窗口被 Python 垃圾回收器销毁，或无法正确嵌入 Maya。
   - 使用 `maya_main_window` 作为父窗口，确保窗口生命周期与 Maya 一致。

4. **调试问题**：
   - 如果 `MQtUtil.mainWindow()` 返回 `None`，检查 Maya 是否在 GUI 模式下运行。
   - 如果 `wrapInstance` 抛出异常，检查 Shiboken 版本和 `QWidget` 类型是否正确。

5. **替代方法的适用性**：
   - 对于简单界面，推荐使用 `pymel` 或 `QApplication.topLevelWidgets()`。
   - 对于需要直接操作 C++ 指针的复杂场景（如自定义插件开发），Shiboken 是更好的选择。

---

### 七、总结
在 Maya 中使用 Shiboken 获取主窗口实例是开发 PySide 界面的标准方法，尤其适用于需要直接操作 Qt 对象的场景。通过 `maya.OpenMayaUI.MQtUtil.mainWindow()` 获取 C++ 指针，再用 `shiboken2.wrapInstance`（或 `shiboken6`）包装为 Python 对象，可以轻松将自定义窗口嵌入 Maya。现代 Maya 版本还提供了 `pymel` 或 `QApplication` 的替代方法，适合快速开发。开发者应根据 Maya 版本选择合适的 Shiboken 和 PySide 模块，并确保正确设置父窗口以管理界面生命周期。
