# 获取maya主窗口PySide实例

```python
from PySide2 import QtWidgets, QtCore
from shiboken2 import wrapInstance  # 用于生成 C++ 库与 Python 之间的绑定
import maya.OpenMayaUI as omui
import pymel.core as pc


# 获取maya主窗口 PySide 实例
def get_maya_main_window():
    """通过 QApplication 获取 Maya 主窗口的 PySide 实例"""
    app = QtWidgets.QApplication.instance()  # 用于获取当前运行的 maya QApplication 实例
    # 如果当前没有运行的 QApplication 实例，返回None
    if not app:
        return None
    # app.topLevelWidgets() 返回当前 QApplication 管理的所有顶层窗口（没有父窗口）列表
    for widget in app.topLevelWidgets():
        # 如果窗口的 Qt 对象名称为"MayaWindow"，返回这个窗口实例
        if widget.objectName() == "MayaWindow":
            return widget
    return None


def get_maya_main_window1():
    """通过 shiboken2 获取 Maya 主窗口的 PySide 实例"""
    ptr = omui.MQtUtil.mainWindow()  # 通过API获取maya主窗口C++指针
    # 如果指针存在则转化为QWidget实例
    if ptr is not None:
        return wrapInstance(int(ptr), QtWidgets.QWidget)  # 转换为 QWidget
    return None


def get_maya_main_window2():
    """通过 pymel 获取 Maya 主窗口的 PySide 实例"""
    return pc.ui.Window("MayaWindow").asQtObject()
```

# 使用控件时禁用maya快捷键
- 只要在控件的类中重写`keyPressEvent`函数，并在函数中不做任何事（pass），也不要调用父类函数。即可在使用插件时禁用maya快捷键防止误操作
```python
    def keyPressEvent(self, event: QtGui.QKeyEvent ):
        """重写keyPressEvent函数，在使用该工具时避免误操作maya
        比如按下键盘“s”键导致剋帧
        """
        pass
```
或者：
```python
    def keyPressEvent(self, event: QtGui.QKeyEvent):
        """重写keyPressEvent函数，继承父控件（maya）键盘操作"""
        # 确保父类的 keyPressEvent 逻辑被执行
        super().keyPressEvent(event)
        # 事件已处理，会阻止事件进一步传播到父控件或系统默认处理。
        # event.ignore() 可明确表示事件未处理，继续向maya传播。
        event.accept()
```
## keyPressEvent 概述

在 PySide 库中，`keyPressEvent` 是一个事件处理函数，用于处理键盘按键按下事件。它通常在自定义控件或窗口类中被重写，以实现对键盘输入的响应。PySide 是 Qt 的 Python 绑定，因此 `keyPressEvent` 继承自 Qt 的 `QKeyEvent` 机制。

### 基本概述
- **定义**：`keyPressEvent` 是 `QWidget`（及其派生类，如 `QMainWindow`、`QDialog` 等）的一个虚函数，用于捕获用户按下键盘按键时的事件。
- **触发时机**：当用户按下键盘上的某个键时，`keyPressEvent` 会被调用。
- **参数**：它接受一个 `QKeyEvent` 对象作为参数，包含了按键的详细信息（如键值、修饰键等）。
- **用途**：通过重写 `keyPressEvent`，开发者可以自定义按键触发的行为，例如响应特定按键（如 Enter、Esc）、处理快捷键或实现自定义输入逻辑。

### 函数签名
```python
def keyPressEvent(self, event: PySide6.QtGui.QKeyEvent) -> None:
```
- **`event`**：`QKeyEvent` 类型的对象，包含按键事件的信息。
- 返回值为 `None`，通常不需要显式返回。

### `QKeyEvent` 常用方法
`QKeyEvent` 对象提供以下常用方法来获取按键信息：
- **`event.key()`**：返回按下的键的代码（`Qt.Key` 枚举值，如 `Qt.Key_Enter`、`Qt.Key_A` 等）。
- **`event.text()`**：返回按键对应的文本（对于可打印字符，如字母、数字；对于功能键如 F1、Enter，可能为空）。
- **`event.modifiers()`**：返回修饰键的状态（如 `Qt.ShiftModifier`、`Qt.ControlModifier` 等）。
- **`event.isAutoRepeat()`**：检查按键是否为自动重复（长按键时触发）。
- **`event.isAccepted()`**：检查事件是否已被处理，若调用 `event.accept()` 则表示事件已处理，通常阻止进一步传播。

### 使用示例
以下是一个简单的示例，展示如何在自定义窗口中重写 `keyPressEvent` 来响应按键：
```python
from PySide6.QtWidgets import QApplication, QMainWindow
from PySide6.QtCore import Qt
import sys

class MainWindow(QMainWindow):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("KeyPressEvent 示例")
        self.resize(400, 300)

    def keyPressEvent(self, event):
        # 检查按下的键
        if event.key() == Qt.Key_Escape:
            print("Esc 键被按下，关闭窗口")
            self.close()
        elif event.key() == Qt.Key_A and event.modifiers() == Qt.ControlModifier:
            print("Ctrl + A 被按下")
        elif event.text():
            print(f"按下的键对应的文本：{event.text()}")
        # 标记事件已处理（可选）
        event.accept()

if __name__ == "__main__":
    app = QApplication(sys.argv)
    window = MainWindow()
    window.show()
    sys.exit(app.exec())
```

### 示例说明
1. **窗口创建**：创建了一个继承自 `QMainWindow` 的自定义窗口。
2. **重写 keyPressEvent**：
   - 如果按下 `Esc` 键（`Qt.Key_Escape`），窗口关闭。
   - 如果按下 `Ctrl + A`，打印相应的提示。
   - 对于其他按键，如果有对应的文本（`event.text()`），打印文本内容。
3. **运行**：运行程序后，按下键盘上的键会触发 `keyPressEvent`，根据条件输出信息或执行操作。

### 注意事项
1. **事件传播**：若未调用 `event.accept()`，事件可能继续传播到父控件或默认处理逻辑。调用 `event.ignore()` 可明确表示事件未处理。
2. **修饰键**：使用 `event.modifiers()` 检查组合键（如 `Ctrl`、`Shift`、`Alt`）。例如，`event.modifiers() & Qt.ControlModifier` 判断是否按下 `Ctrl`。
3. **键值**：`Qt.Key` 枚举（如 `Qt.Key_Space`、`Qt.Key_Enter`）用于标识特定键，适合处理功能键；`event.text()` 适合处理可打印字符。
4. **焦点**：`keyPressEvent` 仅在控件具有键盘焦点时触发。确保控件通过 `setFocusPolicy` 或 `setFocus` 设置了焦点。
5. **性能**：避免在 `keyPressEvent` 中执行复杂逻辑，以免影响响应速度。

### 常见应用场景
- **快捷键处理**：实现自定义快捷键功能（如 `Ctrl+S` 保存文件）。
- **游戏开发**：处理实时键盘输入（如 WASD 控制角色移动）。
- **输入验证**：在文本输入框中过滤或处理特定按键。
- **界面导航**：使用方向键或 Tab 键在控件间切换焦点。

### 参考
- PySide6 官方文档：`QKeyEvent` 和 `QWidget` 的相关章节。
- Qt 键值枚举：`PySide6.QtCore.Qt.Key`。
- 如果需要更复杂的键盘处理，可以结合 `QShortcut` 或 `QAction` 实现快捷键功能。
# 窗口停靠maya界面

`MayaQWidgetDockableMixin` 是 Autodesk Maya 提供的一个 Python 类，位于 `maya.app.general.mayaMixin` 模块中，用于创建可嵌入 Maya 主窗口的自定义用户界面（UI）。它允许开发者使用 PySide 或 PyQt 构建与 Maya 原生工具界面风格一致、支持停靠（dockable）的窗口，从而提升用户体验。以下是对 `MayaQWidgetDockableMixin` 的详细介绍：

### 主要功能
1. **支持停靠功能**：
   - 该类允许创建的 UI 窗口像 Maya 原生工具一样，可以停靠在 Maya 主窗口的指定区域（如左侧、右侧、顶部、底部）或以浮动窗口形式显示。
   - 通过 `show(dockable=True)` 方法启用停靠功能，并可通过参数（如 `area`）指定默认停靠区域，例如 `area='right'`。

2. **与 Maya 工作空间集成**：
   - 使用 `MayaQWidgetDockableMixin` 创建的窗口会被包装为 Maya 的 `workspaceControl`，支持与 Maya 的工作空间系统集成，允许用户拖动、调整大小并保存窗口布局。
   - 窗口状态（如位置、大小）会在 Maya 会话间自动保存，增强工具的持久性。

3. **跨版本兼容性**：
   - 从 Maya 2014 开始，PySide 被集成到 Maya 中，2015 及以上版本引入了 `MayaQWidgetDockableMixin`，简化了停靠 UI 的创建。
   - 在 Maya 2017 及以上版本，推荐使用 PySide2，配合 `shiboken2` 进行窗口对象的包装。

4. **事件处理**：
   - 提供 `dockCloseEventTriggered` 信号，用于捕获窗口关闭事件，便于执行清理操作（如保存设置或移除回调）。
   - 注意：在 Maya 2017 及以上版本，`dockCloseEventTriggered` 信号可能不总是可靠触发，需额外处理（如在 Maya 2018 中，可能需要确保窗口首次运行时已停靠）。

### 使用方法
要使用 `MayaQWidgetDockableMixin`，通常需要结合 PySide2 创建一个继承自 `MayaQWidgetDockableMixin` 和 Qt 窗口类的自定义类。以下是一个典型的工作流程和代码示例：

#### 代码示例
以下是一个简单的例子，展示如何创建一个带有按钮的可停靠窗口：

```python
from PySide2 import QtCore, QtWidgets
from maya import OpenMayaUI
from maya.app.general.mayaMixin import MayaQWidgetDockableMixin
from shiboken2 import wrapInstance
import maya.cmds as cmds

# 获取 Maya 主窗口
def get_maya_window():
    win_ptr = OpenMayaUI.MQtUtil.mainWindow()
    return wrapInstance(int(win_ptr), QtWidgets.QMainWindow)

# 删除已存在的 workspaceControl
def delete_workspace_control(control_name):
    if cmds.workspaceControl(control_name, q=True, exists=True):
        cmds.workspaceControl(control_name, e=True, close=True)
        cmds.deleteUI(control_name, control=True)

# 自定义可停靠窗口
class MyDockableWindow(MayaQWidgetDockableMixin, QtWidgets.QDialog):
    TOOL_NAME = 'MyDockableUI'

    def __init__(self, parent=None):
        # 删除旧的工作空间控件
        delete_workspace_control(self.TOOL_NAME + 'WorkspaceControl')
        
        # 初始化父类
        super(MyDockableWindow, self).__init__(parent=parent)
        self.maya_main_window = get_maya_window()
        self.setObjectName(self.TOOL_NAME)
        
        # 设置窗口属性
        self.setWindowFlags(QtCore.Qt.Window)
        self.setWindowTitle(self.TOOL_NAME)
        self.resize(200, 200)
        
        # 设置布局
        self.setLayout(QtWidgets.QVBoxLayout())
        self.populate_buttons()

    def populate_buttons(self):
        # 添加按钮
        button_cube = QtWidgets.QPushButton('Create Cube')
        button_cube.clicked.connect(cmds.polyCube)
        self.layout().addWidget(button_cube)

        button_sphere = QtWidgets.QPushButton('Create Sphere')
        button_sphere.clicked.connect(cmds.polySphere)
        self.layout().addWidget(button_sphere)

        # 添加垂直间隔
        vertical_spacer = QtWidgets.QSpacerItem(20, 40, QtWidgets.QSizePolicy.Minimum, QtWidgets.QSizePolicy.Expanding)
        self.layout().addItem(vertical_spacer)

# 创建并显示窗口
if __name__ == '__main__':
    my_window = MyDockableWindow()
    my_window.show(dockable=True, area='right')
```

#### 关键步骤解析
1. **继承 `MayaQWidgetDockableMixin`**：
   - 自定义类需继承 `MayaQWidgetDockableMixin` 和一个 Qt 窗口类（如 `QtWidgets.QDialog` 或 `QtWidgets.QMainWindow`）。
   - 这样可以利用 Mixin 类提供的停靠功能，同时保留 Qt 窗口的完整功能。

2. **获取 Maya 主窗口**：
   - 使用 `OpenMayaUI.MQtUtil.mainWindow()` 获取 Maya 主窗口的指针，并通过 `shiboken2.wrapInstance` 转换为 PySide2 的 `QMainWindow` 对象，作为父窗口。

3. **删除旧的工作空间控件**：
   - 在创建新窗口前，使用 `cmds.workspaceControl` 检查并删除已存在的同名 `workspaceControl`，避免冲突。

4. **设置窗口属性**：
   - 设置 `objectName` 和 `windowTitle` 以便 Maya 识别和管理窗口。
   - 使用 `setLayout` 创建布局（如 `QVBoxLayout`），并添加控件（如按钮、标签等）。

5. **显示窗口**：
   - 调用 `show(dockable=True)` 显示窗口，并启用停靠功能。
   - 可通过参数（如 `area='right'`）指定默认停靠区域，或通过 `floating=True` 设置为浮动窗口。

6. **恢复窗口**：
   - 为确保窗口在 Maya 重启后能正确恢复，需设置 `uiScript` 参数，指向一个恢复 UI 的脚本。例如：
     ```python
     my_window.show(dockable=True, uiScript='import my_script; my_script.restore_ui()')
     ```
   - 恢复脚本需要使用 `MQtUtil.findControl` 和 `MQtUtil.addWidgetToMayaLayout` 将窗口重新附加到工作空间控件。

### 注意事项
1. **信号问题**：
   - 在 Maya 2017 及以上版本，`dockCloseEventTriggered` 可能不触发，尤其在窗口未停靠时关闭。解决方法是确保窗口首次运行时已停靠，或使用其他事件（如 `closeEvent`）进行补充处理。

2. **兼容性**：
   - Maya 2017 及以上版本使用 PySide2，早期版本使用 PySide。代码中需处理兼容性（如通过 `try-except` 导入 `PySide2` 或 `PySide`）。

3. **自定义图标问题**：
   - 当窗口设置为可停靠时，Maya 的 `workspaceControl` 会接管窗口，导致自定义图标可能失效。解决方法需通过额外的 MEL 或 Python 脚本调整 `workspaceControl` 属性。

4. **选项卡问题**：
   - 默认情况下，停靠的窗口会带有选项卡。若不希望出现选项卡，可尝试调整 `workspaceControl` 的设置，或使用 `QMainWindow` 替代 `QDialog` 以获得更灵活的布局控制。

### 应用场景
- **自定义工具**：为动画师、建模师等创建集成在 Maya 界面中的工具，如批量操作、场景管理或自定义属性编辑器。
- **工作流优化**：通过停靠窗口减少屏幕杂乱，提高艺术家的工作效率。
- **插件开发**：在开发 Maya 插件时，创建与原生 UI 无缝集成的界面。

from Qt import QtCore, QtWidgets
from shiboken2 import wrapInstance
import maya.OpenMayaUI as omui


class TemplateDialog(QtWidgets.QDialog):
    _ui_instance = None
    WINDOW_TITLE = "Template"

    def __init__(self, parent=None):
        if parent is None:
            parent = self.get_maya_main_window()
        super().__init__(parent)

        self.setWindowTitle(TemplateDialog.WINDOW_TITLE)
        self.setMinimumSize(300, 120)
        # 窗口在关闭时自动彻底销毁对象
        self.setAttribute(QtCore.Qt.WA_DeleteOnClose)

        self.create_widgets()
        self.create_layout()
        self.create_connections()

    def create_widgets(self):
        pass

    def create_layout(self):
        pass

    def create_connections(self):
        pass

    @QtCore.Slot()
    def template_slot(self):
        pass

    def closeEvent(self, event):
        """关闭窗口时清空实例"""
        TemplateDialog._ui_instance = None
        super().closeEvent(event)

    @staticmethod
    def get_maya_main_window():
        """返回 Maya 主窗口的 PySide 实例"""
        ptr = omui.MQtUtil.mainWindow()
        if ptr is not None:
            return wrapInstance(int(ptr), QtWidgets.QMainWindow)
        return None

    @classmethod
    def show_ui(cls):
        """单例显示 UI"""
        # 如果没有单例或者实例不显示，则创建并显示实例
        if cls._ui_instance is None or not cls._ui_instance.isVisible():
            cls._ui_instance = TemplateDialog()
            cls._ui_instance.show()
        # 其他情况实例抬起并激活
        else:
            cls._ui_instance.raise_()
            cls._ui_instance.activateWindow()


# 执行代码
def run():
    TemplateDialog.show_ui()
