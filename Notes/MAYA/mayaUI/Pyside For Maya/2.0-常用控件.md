PySide6（Qt for Python）提供了丰富的控件（Widgets），用于构建图形用户界面（GUI）。这些控件涵盖了输入、显示、布局管理和交互等功能，广泛应用于表单、对话框、设置界面等场景。以下是对 PySide6 中常用控件的介绍，结合您之前询问的控件（`QStackedWidget`、`QListWidget`、`QTabWidget`、`QTextEdit`、`QButtonGroup`、`QGroupBox`、`QSpinBox`、`QDoubleSpinBox`、`QComboBox`、`QSlider`），并补充其他常用控件，内容将简洁概括，突出功能、用途和关键特性。

### 1. **容器类控件**
这些控件用于组织和分组其他控件，提供布局或页面管理功能。

- **`QWidget`**
  - **功能**：所有控件的基础类，作为其他控件的容器或独立窗口。
  - **用途**：用作主窗口、对话框或自定义控件的基类。
  - **关键特性**：
    - 支持任意子控件和布局（`setLayout`）。
    - 可设置大小、位置、样式。
    - 信号：`windowTitleChanged` 等。
  - **示例场景**：主窗口、面板。

- **`QMainWindow`**
  - **功能**：提供主窗口框架，包含菜单栏、工具栏、状态栏和中心区域。
  - **用途**：应用程序主窗口（如编辑器、浏览器）。
  - **关键特性**：
    - 支持 `setMenuBar`、`addToolBar`、`setStatusBar`。
    - 中心区域通过 `setCentralWidget` 设置。
    - 支持停靠窗口（`QDockWidget`）。
  - **示例场景**：复杂应用程序的主界面。

- **`QDialog`**
  - **功能**：模态或非模态对话框，用于临时交互。
  - **用途**：提示、设置、确认窗口。
  - **关键特性**：
    - 支持 `exec()`（模态）或 `show()`（非模态）。
    - 可包含按钮（如 `QDialogButtonBox`）。
    - 信号：`accepted`、`rejected`。
  - **示例场景**：登录框、文件选择对话框。

- **`QGroupBox`**
  - **功能**：带标题和边框的容器，用于分组控件。
  - **用途**：组织相关控件（如表单中的一组选项）。
  - **关键特性**：
    - 支持 `setTitle` 设置标题，`setCheckable(True)` 添加复选框。
    - 使用布局（如 `QVBoxLayout`）管理子控件。
    - 信号：`toggled(bool)`。
  - **示例场景**：设置面板中的分组区域。

- **`QTabWidget`**
  - **功能**：选项卡式容器，带标签栏切换页面。
  - **用途**：多页面界面（如设置窗口、浏览器标签）。
  - **关键特性**：
    - 支持 `addTab`、`setTabsClosable`、`setMovable`。
    - 信号：`currentChanged(int)`、`tabCloseRequested(int)`。
  - **示例场景**：应用程序设置的多标签页。

- **`QStackedWidget`**
  - **功能**：堆栈式容器，一次显示一个页面，需外部控件切换。
  - **用途**：向导界面、动态页面切换。
  - **关键特性**：
    - 支持 `addWidget`、`setCurrentIndex`。
    - 信号：`currentChanged(int)`。
  - **示例场景**：多步骤配置向导。

### 2. **输入类控件**
这些控件用于用户输入数据，如文本、数值或选项选择。

- **`QLineEdit`**
  - **功能**：单行文本输入框。
  - **用途**：输入短文本（如用户名、搜索查询）。
  - **关键特性**：
    - 支持 `setText`、`text`、`setPlaceholderText`。
    - 可设置输入掩码（`setInputMask`）或验证器（`QValidator`）。
    - 信号：`textChanged(str)`、`returnPressed()`。
  - **示例场景**：登录表单、搜索框。

- **`QTextEdit`**
  - **功能**：多行文本编辑器，支持纯文本和富文本。
  - **用途**：编辑长文本、HTML内容（如笔记、聊天）。
  - **关键特性**：
    - 支持 `setHtml`、`toPlainText`、`setReadOnly`。
    - 提供撤销/重做、复制/粘贴。
    - 信号：`textChanged()`、`cursorPositionChanged()`。
  - **示例场景**：文本编辑器、日志显示。

- **`QSpinBox`**
  - **功能**：整数输入控件，带上下箭头。
  - **用途**：输入离散数值（如数量、年龄）。
  - **关键特性**：
    - 支持 `setRange`、`setSingleStep`、`setPrefix`/`setSuffix`。
    - 信号：`valueChanged(int)`。
  - **示例场景**：设置字体大小、数量选择。

- **`QDoubleSpinBox`**
  - **功能**：浮点数输入控件，带上下箭头。
  - **用途**：输入连续数值（如价格、百分比）。
  - **关键特性**：
    - 支持 `setDecimals` 设置小数位数。
    - 信号：`valueChanged(float)`。
  - **示例场景**：调整缩放比例、价格输入。

- **`QComboBox`**
  - **功能**：下拉列表控件，支持选择或输入。
  - **用途**：从预定义选项中选择（如语言、类别）。
  - **关键特性**：
    - 支持 `addItem`、`setEditable`、`setItemData`。
    - 信号：`currentTextChanged(str)`、`currentIndexChanged(int)`。
  - **示例场景**：选择国家、文件类型。

- **`QSlider`**
  - **功能**：滑动条控件，用于快速调整整数值。
  - **用途**：调整连续值（如音量、亮度）。
  - **关键特性**：
    - 支持 `setRange`、`setTickPosition`、`setOrientation`。
    - 信号：`valueChanged(int)`、`sliderMoved(int)`。
  - **示例场景**：音量控制、进度条。

- **`QCheckBox`**
  - **功能**：复选框，支持选中/未选中状态。
  - **用途**：多选选项（如启用/禁用功能）。
  - **关键特性**：
    - 支持 `setChecked`、`isChecked`。
    - 信号：`toggled(bool)`、`stateChanged(int)`。
  - **示例场景**：设置窗口中的开关选项。

- **`QRadioButton`**
  - **功能**：单选按钮，组内互斥。
  - **用途**：从互斥选项中选择（如性别、模式）。
  - **关键特性**：
    - 常与 `QButtonGroup` 结合实现互斥。
    - 信号：`toggled(bool)`。
  - **示例场景**：选择单一配置。

### 3. **显示类控件**
这些控件用于显示信息或内容。

- **`QLabel`**
  - **功能**：显示文本、图像或超链接。
  - **用途**：显示提示、标题或静态内容。
  - **关键特性**：
    - 支持 `setText`、`setPixmap`、`setOpenExternalLinks`。
    - 可设置对齐方式（`setAlignment`）。
    - 信号：`linkActivated(str)`。
  - **示例场景**：表单标签、图片预览。

- **`QTextBrowser`**
  - **功能**：只读富文本显示控件，支持超链接。
  - **用途**：显示HTML内容、帮助文档。
  - **关键特性**：
    - 支持 `setHtml`、`toHtml`、`setSource` 加载文件或URL。
    - 信号：`anchorClicked(QUrl)`。
  - **示例场景**：帮助窗口、网页预览。

- **`QListWidget`**
  - **功能**：列表控件，显示可选择的条目。
  - **用途**：导航菜单、选项列表。
  - **关键特性**：
    - 支持 `addItem`、`setSelectionMode`（单选/多选）。
    - 信号：`itemClicked(QListWidgetItem)`、`currentItemChanged`。
  - **示例场景**：文件列表、侧边栏导航。

### 4. **按钮类控件**
这些控件用于触发操作或管理按钮状态。

- **`QPushButton`**
  - **功能**：标准按钮，触发操作。
  - **用途**：执行命令（如“确定”、“取消”）。
  - **关键特性**：
    - 支持 `setText`、`setIcon`、`setDefault`。
    - 信号：`clicked()`、`pressed()`。
  - **示例场景**：表单提交、对话框按钮。

- **`QButtonGroup`**
  - **功能**：逻辑容器，管理一组按钮的状态（如互斥）。
  - **用途**：组织 `QRadioButton` 或 `QCheckBox`。
  - **关键特性**：
    - 支持 `addButton`、`setExclusive`。
    - 信号：`buttonClicked(QAbstractButton)`、`idClicked(int)`。
  - **示例场景**：单选按钮分组。

### 5. **布局类控件**
这些控件用于组织其他控件的显示位置。

- **`QVBoxLayout` / `QHBoxLayout`**
  - **功能**：垂直或水平布局，自动排列子控件。
  - **用途**：组织控件在垂直或水平方向上的排列。
  - **关键特性**：
    - 支持 `addWidget`、`addLayout`、`addStretch`。
    - 可设置间距（`setSpacing`）和边距（`setContentsMargins`）。
  - **示例场景**：表单、工具栏。

- **`QGridLayout`**
  - **功能**：网格布局，按行列组织控件。
  - **用途**：复杂表单或表格式界面。
  - **关键特性**：
    - 支持 `addWidget(widget, row, column, rowSpan, columnSpan)`。
    - 灵活调整控件跨行/列。
  - **示例场景**：设置面板、计算器界面。

- **`QFormLayout`**
  - **功能**：表单布局，自动配对标签和输入控件。
  - **用途**：创建标准表单（如设置、登录）。
  - **关键特性**：
    - 支持 `addRow(label, widget)`。
    - 自动对齐标签和控件。
  - **示例场景**：用户注册表单。

### 6. **其他常用控件**
- **`QProgressBar`**
  - **功能**：显示任务进度。
  - **用途**：文件下载、任务处理进度。
  - **关键特性**：
    - 支持 `setRange`、`setValue`、`setFormat`。
    - 信号：`valueChanged(int)`。
  - **示例场景**：文件传输进度。

- **`QDateEdit` / `QTimeEdit` / `QDateTimeEdit`**
  - **功能**：日期、时间或日期时间输入控件。
  - **用途**：选择日期或时间。
  - **关键特性**：
    - 支持 `setDate`、`setTime`、`setDateTime`。
    - 信号：`dateChanged(QDate)`、`timeChanged(QTime)`。
  - **示例场景**：日历选择、预约时间。

- **`QToolBar`**
  - **功能**：工具栏，包含按钮或其他控件。
  - **用途**：提供快捷操作（如编辑器工具栏）。
  - **关键特性**：
    - 支持 `addAction`、`addWidget`。
    - 可拖动或浮动。
  - **示例场景**：文本编辑器的格式工具栏。

### 7. **注意事项**
- **布局管理**：大多数控件需通过布局（如 `QVBoxLayout`）组织位置，`QButtonGroup` 除外（仅逻辑管理）。
- **信号与槽**：PySide6 控件依赖信号和槽机制实现交互，合理连接信号以响应用户操作。
- **样式定制**：通过 `setStyleSheet` 或 Qt 样式表自定义控件外观。
- **性能**：复杂界面应避免过多嵌套控件，优化动态加载。
- **事件处理**：可重写控件的事件方法（如 `mousePressEvent`）实现自定义行为。

### 8. **综合示例**
以下是一个结合多种控件的简单 PySide6 示例，展示表单界面：

```python
import sys
from PySide6.QtWidgets import (QApplication, QMainWindow, QGroupBox, QFormLayout, 
                              QLineEdit, QComboBox, QSpinBox, QPushButton, QWidget)
from PySide6.QtCore import Qt

class MainWindow(QMainWindow):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("常用控件示例")
        
        # 主布局
        main_widget = QWidget()
        self.setCentralWidget(main_widget)
        layout = QFormLayout(main_widget)
        
        # 输入控件
        self.name_edit = QLineEdit()
        self.age_spin = QSpinBox()
        self.age_spin.setRange(0, 150)
        self.gender_combo = QComboBox()
        self.gender_combo.addItems(["男", "女", "其他"])
        
        # 分组框
        group_box = QGroupBox("用户信息")
        group_layout = QFormLayout(group_box)
        group_layout.addRow("姓名:", self.name_edit)
        group_layout.addRow("年龄:", self.age_spin)
        group_layout.addRow("性别:", self.gender_combo)
        
        # 按钮
        submit_button = QPushButton("提交")
        submit_button.clicked.connect(self.on_submit)
        
        # 添加到主布局
        layout.addRow(group_box)
        layout.addRow(submit_button)
        
    def on_submit(self):
        name = self.name_edit.text()
        age = self.age_spin.value()
        gender = self.gender_combo.currentText()
        print(f"提交: 姓名={name}, 年龄={age}, 性别={gender}")

if __name__ == "__main__":
    app = QApplication(sys.argv)
    window = MainWindow()
    window.show()
    sys.exit(app.exec())
```

### 9. **总结**
PySide6 的常用控件涵盖容器（`QWidget`、`QGroupBox`、`QTabWidget`、`QStackedWidget`）、输入（`QLineEdit`、`QTextEdit`、`QSpinBox`、`QDoubleSpinBox`、`QComboBox`、`QSlider`、`QCheckBox`、`QRadioButton`）、显示（`QLabel`、`QListWidget`、`QTextBrowser`）、按钮（`QPushButton`、`QButtonGroup`）和布局（`QVBoxLayout`、`QHBoxLayout`、`QGridLayout`、`QFormLayout`）等类别。这些控件通过布局和信号机制组合使用，可构建复杂的交互界面。如果需要更详细的某控件介绍或复杂示例（如结合数据库、自定义控件），请告诉我！
