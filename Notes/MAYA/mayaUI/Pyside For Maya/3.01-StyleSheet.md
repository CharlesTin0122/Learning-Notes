在 PySide（Qt for Python）中，**StyleSheet**（样式表）是一种强大的工具，用于自定义 Qt 应用程序中控件的外观。它基于 CSS（层叠样式表）的语法，允许开发者通过类似 CSS 的规则来设置控件的外观属性，如颜色、字体、边框、背景等。以下是对 PySide 样式表的介绍及其使用方法。

---

### **1. StyleSheet 简介**
- **定义**：PySide 的样式表是一种基于 CSS 的机制，用于定义 Qt 控件（QWidget 或其子类）的视觉样式。
- **作用**：通过样式表，可以统一或单独设置控件的背景色、边框、字体、间距、透明度等外观属性，而无需修改控件代码。
- **适用对象**：几乎所有的 Qt 控件（如 QPushButton、QLabel、QLineEdit 等）都可以通过样式表自定义。
- **语法**：类似 CSS，使用选择器和属性-值对来定义样式。

---

### **2. StyleSheet 基本语法**
样式表的语法由**选择器**和**样式规则**组成，格式如下：

```css
选择器 {
    属性: 值;
    属性: 值;
}
```

- **选择器**：指定应用样式的控件类型或条件，例如：
  - `QPushButton`：选择所有 QPushButton 控件。
  - `#objectName`：选择具有特定 objectName 的控件（通过 `setObjectName` 设置）。
  - `.className`：选择具有特定类名的控件。
  - `QPushButton:hover`：选择鼠标悬停时的 QPushButton。
- **属性**：Qt 支持的样式属性，例如 `background-color`、`color`、`font-size`、`border` 等。
- **值**：属性的具体值，例如颜色（`red`、`#FF0000`）、像素值（`10px`）等。

---

### **3. 常用样式属性**
以下是一些常用的样式表属性及其作用：

| 属性                 | 描述                              | 示例值                     |
|----------------------|-----------------------------------|----------------------------|
| `background-color`   | 设置背景颜色                     | `red`, `#FF0000`, `rgb(255,0,0)` |
| `color`              | 设置文本颜色                     | `blue`, `#0000FF`         |
| `font-size`          | 设置字体大小                     | `14px`, `12pt`            |
| `font-family`        | 设置字体                         | `Arial`, `Times New Roman` |
| `border`             | 设置边框样式                     | `1px solid black`         |
| `border-radius`      | 设置圆角半径                     | `5px`                     |
| `padding`            | 设置内边距                       | `10px`                    |
| `margin`             | 设置外边距                       | `5px`                     |
| `min-width` / `max-width` | 设置控件的最小/最大宽度         | `100px`                   |

更多属性可参考 Qt 官方文档：https://doc.qt.io/qt-6/stylesheet-reference.html

---

### **4. 使用方法**
在 PySide 中，样式表可以通过以下方式应用：

#### **4.1 全局样式表**
通过 `QApplication.setStyleSheet()` 设置全局样式表，影响整个应用程序中的控件。

```python
from PySide6.QtWidgets import QApplication, QPushButton, QMainWindow
import sys

app = QApplication(sys.argv)

window = QMainWindow()
button = QPushButton("Click Me", window)

# 设置全局样式表
app.setStyleSheet("""
    QPushButton {
        background-color: #4CAF50;
        color: white;
        border-radius: 5px;
        padding: 6px;
    }
    QPushButton:hover {
        background-color: #45a049;
    }
""")

window.show()
app.exec()
```

**说明**：
- 上述代码将所有 QPushButton 的背景色设置为绿色，鼠标悬停时颜色略变暗。
- 全局样式表会影响应用程序中所有匹配选择器的控件。

#### **4.2 控件特定样式表**
通过 `QWidget.setStyleSheet()` 为特定控件设置样式表。

```python
from PySide6.QtWidgets import QPushButton, QMainWindow, QApplication
import sys

app = QApplication(sys.argv)
window = QMainWindow()

button = QPushButton("Styled Button", window)
button.setObjectName("myButton")  # 设置对象名称

# 为特定控件设置样式表
button.setStyleSheet("""
    #myButton {
        background-color: blue;
        color: white;
        font-size: 16px;
        border: 2px solid black;
        border-radius: 10px;
    }
""")

window.show()
app.exec()
```

**说明**：
- 通过 `setObjectName("myButton")` 设置控件的对象名称，然后在样式表中使用 `#myButton` 选择器来指定该控件。
- 这种方式只影响特定控件。

#### **4.3 使用伪状态**
Qt 样式表支持伪状态（如 `:hover`、`:pressed`、`:disabled` 等），用于响应用户交互。

```python
button.setStyleSheet("""
    QPushButton {
        background-color: #2196F3;
        color: white;
        border-radius: 8px;
    }
    QPushButton:hover {
        background-color: #1976D2;
    }
    QPushButton:pressed {
        background-color: #0D47A1;
    }
""")
```

**说明**：
- `:hover`：鼠标悬停时的样式。
- `:pressed`：鼠标按下时的样式。

#### **4.4 组合选择器**
可以组合选择器来实现更复杂的样式规则，例如：

```python
app.setStyleSheet("""
    QPushButton#myButton {
        background-color: green;
    }
    QLineEdit[enabled="false"] {
        background-color: gray;
    }
""")
```

**说明**：
- `QPushButton#myButton`：选择对象名称为 `myButton` 的 QPushButton。
- `QLineEdit[enabled="false"]`：选择禁用状态的 QLineEdit。

---

### **5. 注意事项**
1. **优先级**：
   - 控件特定的样式表优先级高于全局样式表。
   - 如果样式冲突，Qt 会根据选择器的特异性（specificity）决定优先级。
2. **性能**：
   - 复杂的样式表可能影响渲染性能，尤其是在大型应用程序中，尽量保持样式表简洁。
3. **平台差异**：
   - 某些样式属性在不同平台（Windows、macOS、Linux）上的表现可能略有不同，需测试兼容性。
4. **调试**：
   - 如果样式表未生效，检查选择器是否正确、属性是否支持，或是否存在拼写错误。
5. **继承**：
   - 子控件会继承父控件的样式表，除非子控件有更具体的样式规则。

### **6. 示例：综合应用**
以下是一个综合示例，展示如何为不同控件设置样式：

```python
from PySide6.QtWidgets import QApplication, QMainWindow, QPushButton, QLineEdit, QVBoxLayout, QWidget
import sys

app = QApplication(sys.argv)
window = QMainWindow()
central_widget = QWidget()
window.setCentralWidget(central_widget)
layout = QVBoxLayout(central_widget)

button = QPushButton("Click Me")
button.setObjectName("actionButton")
line_edit = QLineEdit()
line_edit.setPlaceholderText("Enter text")

layout.addWidget(button)
layout.addWidget(line_edit)

# 设置样式表
app.setStyleSheet("""
    #actionButton {
        background-color: #FF5722;
        color: white;
        font-size: 14px;
        border-radius: 5px;
        padding: 8px;
    }
    #actionButton:hover {
        background-color: #E64A19;
    }
    QLineEdit {
        border: 2px solid #2196F3;
        border-radius: 4px;
        padding: 5px;
        font-size: 12px;
    }
    QLineEdit:focus {
        border-color: #FF9800;
    }
""")

window.show()
app.exec()
```

**效果**：
- 按钮具有橙色背景，悬停时变暗。
- 输入框有蓝色边框，获取焦点时边框变为橙色。
