# 获取maya主窗口PySide实例

```python
from PySide2 import QtWidgets, QtCore
from shiboken2 import wrapInstance  # 用于生成 C++ 库与 Python 之间的绑定
import maya.OpenMayaUI as omui
import pymel.core as pc


# 获取maya主窗口 PySide 实例
def get_maya_main_window():
    """通过 QApplication 获取 Maya 主窗口的 PySide 实例"""
    app = QtWidgets.QApplication.instance()  # 用于获取当前运行的 maya QApplication 实例
    # 如果当前没有运行的 QApplication 实例，返回None
    if not app:
        return None
    # app.topLevelWidgets() 返回当前 QApplication 管理的所有顶层窗口（没有父窗口）列表
    for widget in app.topLevelWidgets():
        # 如果窗口的 Qt 对象名称为"MayaWindow"，返回这个窗口实例
        if widget.objectName() == "MayaWindow":
            return widget
    return None


def get_maya_main_window1():
    """通过 shiboken2 获取 Maya 主窗口的 PySide 实例"""
    ptr = omui.MQtUtil.mainWindow()  # 通过API获取maya主窗口C++指针
    # 如果指针存在则转化为QWidget实例
    if ptr is not None:
        return wrapInstance(int(ptr), QtWidgets.QWidget)  # 转换为 QWidget
    return None


def get_maya_main_window2():
    """通过 pymel 获取 Maya 主窗口的 PySide 实例"""
    return pc.ui.Window("MayaWindow").asQtObject()
```

# 使用控件时禁用maya快捷键
- 只要在控件的类中重写`keyPressEvent`函数，并在函数中不做任何事（pass），也不要调用父类函数。即可在使用插件时禁用maya快捷键防止误操作
```python
    def keyPressEvent(self, event: QtGui.QKeyEvent ):
        """重写keyPressEvent函数，在使用该工具时避免误操作maya
        比如按下键盘“s”键导致剋帧
        """
        pass
```
或者：
```python
    def keyPressEvent(self, event: QtGui.QKeyEvent):
        """重写keyPressEvent函数，继承父控件（maya）键盘操作"""
        # 确保父类的 keyPressEvent 逻辑被执行
        super().keyPressEvent(event)
        # 事件已处理，会阻止事件进一步传播到父控件或系统默认处理。
        # event.ignore() 可明确表示事件未处理，继续向maya传播。
        event.accept()
```
## keyPressEvent 概述

在 PySide 库中，`keyPressEvent` 是一个事件处理函数，用于处理键盘按键按下事件。它通常在自定义控件或窗口类中被重写，以实现对键盘输入的响应。PySide 是 Qt 的 Python 绑定，因此 `keyPressEvent` 继承自 Qt 的 `QKeyEvent` 机制。

### 基本概述
- **定义**：`keyPressEvent` 是 `QWidget`（及其派生类，如 `QMainWindow`、`QDialog` 等）的一个虚函数，用于捕获用户按下键盘按键时的事件。
- **触发时机**：当用户按下键盘上的某个键时，`keyPressEvent` 会被调用。
- **参数**：它接受一个 `QKeyEvent` 对象作为参数，包含了按键的详细信息（如键值、修饰键等）。
- **用途**：通过重写 `keyPressEvent`，开发者可以自定义按键触发的行为，例如响应特定按键（如 Enter、Esc）、处理快捷键或实现自定义输入逻辑。

### 函数签名
```python
def keyPressEvent(self, event: PySide6.QtGui.QKeyEvent) -> None:
```
- **`event`**：`QKeyEvent` 类型的对象，包含按键事件的信息。
- 返回值为 `None`，通常不需要显式返回。

### `QKeyEvent` 常用方法
`QKeyEvent` 对象提供以下常用方法来获取按键信息：
- **`event.key()`**：返回按下的键的代码（`Qt.Key` 枚举值，如 `Qt.Key_Enter`、`Qt.Key_A` 等）。
- **`event.text()`**：返回按键对应的文本（对于可打印字符，如字母、数字；对于功能键如 F1、Enter，可能为空）。
- **`event.modifiers()`**：返回修饰键的状态（如 `Qt.ShiftModifier`、`Qt.ControlModifier` 等）。
- **`event.isAutoRepeat()`**：检查按键是否为自动重复（长按键时触发）。
- **`event.isAccepted()`**：检查事件是否已被处理，若调用 `event.accept()` 则表示事件已处理，通常阻止进一步传播。

### 使用示例
以下是一个简单的示例，展示如何在自定义窗口中重写 `keyPressEvent` 来响应按键：
```python
from PySide6.QtWidgets import QApplication, QMainWindow
from PySide6.QtCore import Qt
import sys

class MainWindow(QMainWindow):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("KeyPressEvent 示例")
        self.resize(400, 300)

    def keyPressEvent(self, event):
        # 检查按下的键
        if event.key() == Qt.Key_Escape:
            print("Esc 键被按下，关闭窗口")
            self.close()
        elif event.key() == Qt.Key_A and event.modifiers() == Qt.ControlModifier:
            print("Ctrl + A 被按下")
        elif event.text():
            print(f"按下的键对应的文本：{event.text()}")
        # 标记事件已处理（可选）
        event.accept()

if __name__ == "__main__":
    app = QApplication(sys.argv)
    window = MainWindow()
    window.show()
    sys.exit(app.exec())
```

### 示例说明
1. **窗口创建**：创建了一个继承自 `QMainWindow` 的自定义窗口。
2. **重写 keyPressEvent**：
   - 如果按下 `Esc` 键（`Qt.Key_Escape`），窗口关闭。
   - 如果按下 `Ctrl + A`，打印相应的提示。
   - 对于其他按键，如果有对应的文本（`event.text()`），打印文本内容。
3. **运行**：运行程序后，按下键盘上的键会触发 `keyPressEvent`，根据条件输出信息或执行操作。

### 注意事项
1. **事件传播**：若未调用 `event.accept()`，事件可能继续传播到父控件或默认处理逻辑。调用 `event.ignore()` 可明确表示事件未处理。
2. **修饰键**：使用 `event.modifiers()` 检查组合键（如 `Ctrl`、`Shift`、`Alt`）。例如，`event.modifiers() & Qt.ControlModifier` 判断是否按下 `Ctrl`。
3. **键值**：`Qt.Key` 枚举（如 `Qt.Key_Space`、`Qt.Key_Enter`）用于标识特定键，适合处理功能键；`event.text()` 适合处理可打印字符。
4. **焦点**：`keyPressEvent` 仅在控件具有键盘焦点时触发。确保控件通过 `setFocusPolicy` 或 `setFocus` 设置了焦点。
5. **性能**：避免在 `keyPressEvent` 中执行复杂逻辑，以免影响响应速度。

### 常见应用场景
- **快捷键处理**：实现自定义快捷键功能（如 `Ctrl+S` 保存文件）。
- **游戏开发**：处理实时键盘输入（如 WASD 控制角色移动）。
- **输入验证**：在文本输入框中过滤或处理特定按键。
- **界面导航**：使用方向键或 Tab 键在控件间切换焦点。
