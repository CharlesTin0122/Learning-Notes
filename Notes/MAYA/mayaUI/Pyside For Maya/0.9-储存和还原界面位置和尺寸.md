- 在构造函数中新增变量用于储存界面的位置和尺寸
```python
    def __init__(self, parent=None):
        if parent is None:
            parent = ToolDialog.maya_main_window()
        super().__init__(parent)

        self.setWindowTitle("Outliner")
        self.setMinimumSize(300, 400)

        self.geometry = None  # 用于上次关闭时储存界面的位置和尺寸
```
- `self.geometry()` 会返回 **窗口在屏幕上的位置和尺寸**。
- 它包含：
    - **x**（左上角的 X 坐标）
    - **y**（左上角的 Y 坐标）
    - **width**（宽度）
    - **height**（高度）
- 重写`closeEvent`和`showEvent`函数，在界面关闭时储存界面的位置和尺寸，在加棉加载时恢复上次关闭时储存的数据
```python
    def showEvent(self, event):
        """重写基类的showEvent，在界面开启时开启scriptJob"""
        # 在界面开启时还原上次关闭界面时储存的界面位置和尺寸
        if self.geometry:
            self.restoreGeometry(self.geometry)

    def closeEvent(self, event):
        """重写基类的closeEvent，在界面关闭时关闭scriptJob"""
        # 在界面关闭时储存界面位置和尺寸
        self.geometry = self.saveGeometry()
```
