在 PySide（Python 的 Qt 绑定库）中，`windowFlags` 是用于设置窗口属性的一个重要工具，它可以控制窗口的行为、外观和特性。`windowFlags` 是 `QtCore.Qt.WindowFlags` 枚举类型的一个实例，用于指定窗口的类型、边框、标题栏等特性。以下是对 `windowFlags` 的详细介绍：

### 1. **什么是 `windowFlags`？**
`windowFlags` 是 `QWidget` 或其子类（如 `QMainWindow`、`QDialog` 等）的一个属性，用于定义窗口的类型和行为。通过调用 `setWindowFlags()` 方法，你可以设置窗口的标志（flags），从而改变窗口的外观和功能。例如，你可以设置窗口是否带有标题栏、是否可以最小化、是否为模态窗口等。

### 2. **常用的 `Qt.WindowFlags` 枚举值**
`Qt.WindowFlags` 提供了多种标志，可以通过按位或运算（`|`）组合使用。以下是一些常见的标志及其作用：

| 标志                                | 描述                                             |
| --------------------------------- | ---------------------------------------------- |
| `Qt.Window`                       | 声明这是一个普通窗口，通常带有标题栏和边框、最大化和最小化按钮。               |
| `Qt.Dialog`                       | 声明这是一个对话框窗口，通常用于模态或非模态对话框。没有最大化最小化按钮。          |
| `Qt.Tool`                         | 声明这是一个工具窗口，通常是小型窗口（如工具栏或浮动窗口），依附于主窗口。          |
| `Qt.Popup`                        | 声明这是一个弹出窗口，通常用于菜单或临时窗口，点击外部会自动关闭。              |
| `Qt.SplashScreen`                 | 声明这是一个启动画面窗口，通常无边框，用于程序启动时的加载界面。               |
| `Qt.FramelessWindowHint`          | 移除窗口的边框和标题栏，创建无边框窗口。                           |
| `Qt.WindowStaysOnTopHint`         | 使窗口始终位于其他窗口之上（置顶）。                             |
| `Qt.WindowStaysOnBottomHint`      | 使窗口始终位于其他窗口之下。                                 |
| `Qt.CustomizeWindowHint`          | 允许自定义窗口标题栏，需与其他标志组合使用（如 `Qt.WindowTitleHint`）。 |
| `Qt.WindowTitleHint`              | 显示窗口标题栏。                                       |
| `Qt.WindowSystemMenuHint`         | 添加系统菜单（通常包含关闭、最小化等按钮）。                         |
| `Qt.WindowMinimizeButtonHint`     | 显示最小化按钮。                                       |
| `Qt.WindowMaximizeButtonHint`     | 显示最大化/还原按钮。                                    |
| `Qt.WindowCloseButtonHint`        | 显示关闭按钮。                                        |
| `Qt.WindowContextHelpButtonHint`  | 显示帮助按钮（通常是“?”按钮）。                              |
| `Qt.MSWindowsFixedSizeDialogHint` | 在 Windows 平台上，固定窗口大小，禁止调整大小。                   |

### 3. **如何使用 `windowFlags`**
在 PySide 中，可以通过 `setWindowFlags()` 方法设置窗口的标志。通常在创建窗口后调用此方法。例如：

```python
from PySide6.QtWidgets import QWidget
from PySide6.QtCore import Qt

class MyWindow(QWidget):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("自定义窗口")
        # 设置无边框窗口，并始终置顶
        self.setWindowFlags(Qt.FramelessWindowHint | Qt.WindowStaysOnTopHint)
        self.resize(300, 200)

if __name__ == "__main__":
    from PySide6.QtWidgets import QApplication
    import sys
    app = QApplication(sys.argv)
    window = MyWindow()
    window.show()
    sys.exit(app.exec())
```

### 4. **组合使用 `windowFlags`**
`windowFlags` 支持通过按位或运算（`|`）组合多个标志。例如，如果你想创建一个无边框、置顶的对话框窗口，可以这样做：

```python
self.setWindowFlags(Qt.Dialog | Qt.FramelessWindowHint | Qt.WindowStaysOnTopHint)
```

### 5. **注意事项**
- **覆盖默认行为**：设置 `windowFlags` 会覆盖窗口的默认属性。例如，设置 `Qt.FramelessWindowHint` 会移除标题栏和边框，因此需要自行实现窗口的拖动或关闭功能。
- **平台差异**：某些标志（如 `Qt.MSWindowsFixedSizeDialogHint`）是特定于平台的，效果可能因操作系统而异。
- **获取当前标志**：可以通过 `windowFlags()` 方法获取当前窗口的标志，例如：
  ```python
  flags = self.windowFlags()
  if flags & Qt.FramelessWindowHint:
      print("窗口是无边框的")
  ```
- **动态修改**：在窗口创建后，可以随时调用 `setWindowFlags()` 修改标志，但可能需要调用 `show()` 刷新窗口以应用更改。

### 6. **常见应用场景**
- **无边框窗口**：用于自定义 UI 界面，如现代化的应用程序窗口。
- **置顶窗口**：用于需要始终可见的工具窗口或提示窗口。
- **模态对话框**：通过 `Qt.Dialog` 和 `Qt.WindowModal` 创建阻止用户操作其他窗口的对话框。
- **启动画面**：通过 `Qt.SplashScreen` 创建程序启动时的加载界面。

### 7. **示例：创建无边框可拖动的窗口**
以下是一个简单的无边框窗口示例，支持鼠标拖动：

```python
from PySide6.QtWidgets import QWidget, QApplication
from PySide6.QtCore import Qt, QPoint
import sys

class FramelessWindow(QWidget):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("无边框窗口")
        self.setWindowFlags(Qt.FramelessWindowHint)  # 无边框
        self.setFixedSize(300, 200)
        self._dragging = False
        self._offset = QPoint()

    def mousePressEvent(self, event):
        if event.button() == Qt.LeftButton:
            self._dragging = True
            self._offset = event.globalPos() - self.pos()

    def mouseMoveEvent(self, event):
        if self._dragging:
            self.move(event.globalPos() - self._offset)

    def mouseReleaseEvent(self, event):
        if event.button() == Qt.LeftButton:
            self._dragging = False

if __name__ == "__main__":
    app = QApplication(sys.argv)
    window = FramelessWindow()
    window.show()
    sys.exit(app.exec())
```

# 应用
- 当我们使用pyside库为其他软件编写插件时，如果继承的是Qwidget控件而没有设置windowFlags，因为他的父类是软件主界面，那么插件界面会直接附加到软件主界面，而不是弹出式界面。
- 要解决此问题需要设置Qwidget控件的windowFlags。
```python
# PySide2
self.setWindowFlags(QtCore.Qt.WindowType.Window)
# PySide6
self.setWindowFlags(Qt.Window)
```
