在 Autodesk Maya 中使用 PySide（或 PySide2/PySide6）开发界面时，确保界面实例单例化（即只存在一个窗口实例，防止多次打开相同的窗口）是一个常见需求。特别是在 Maya 环境中，重复打开窗口可能导致资源浪费或用户体验不佳。以下是实现单例化界面的详细方法，包括代码示例、逻辑说明和注意事项。

---

### 一、单例化窗口的背景与方法
**问题**：
- 默认情况下，每次运行脚本创建 PySide 界面（如 `QDialog` 或 `QMainWindow`）都会生成一个新的窗口实例。
- 在 Maya 中，重复创建窗口可能导致界面堆叠、内存占用增加，或与 Maya 的窗口管理冲突。

**目标**：
- 确保同一界面只有一个实例存在。
- 如果窗口已存在，重新显示或激活它，而不是创建新实例。

**实现方法**：
1. **使用全局变量存储窗口实例**：通过全局变量或模块级变量保存窗口实例，检查其是否存在。
2. **检查窗口有效性**：使用 `isValid`（Shiboken）或窗口状态（如 `isVisible`）判断实例是否可用。
3. **在 Maya 中延迟执行**：使用 `maya.utils.executeDeferred` 确保界面在主线程中创建，避免事件循环冲突。
4. **设置父窗口**：将窗口的父对象设置为 Maya 主窗口，确保生命周期与 Maya 一致。

---

### 二、实现单例化窗口的代码示例
以下是一个完整的示例，展示如何在 Maya 中使用 PySide2 创建一个单例化的界面，并结合 `get_maya_main_window3` 函数（你之前提供的）获取 Maya 主窗口。

```python
import sys
from PySide2.QtWidgets import QApplication, QDialog, QVBoxLayout, QPushButton, QLabel
from maya.utils import executeDeferred

# 全局变量存储窗口实例
_global_window_instance = None

def get_maya_main_window3():
    """通过 QApplication 获取 Maya 主窗口的 PySide 实例"""
    app = QApplication.instance()
    if not app:
        return None
    for widget in app.topLevelWidgets():
        if widget.objectName() == "MayaWindow":
            return widget
    return None

class SingletonDialog(QDialog):
    def __init__(self, parent=None):
        super().__init__(parent)
        self.setWindowTitle("Maya 单例对话框")
        self.setFixedSize(300, 200)

        # 创建控件
        self.label = QLabel("这是一个单例窗口！", self)
        self.button = QPushButton("点击我", self)

        # 设置布局
        layout = QVBoxLayout()
        layout.addWidget(self.label)
        layout.addWidget(self.button)
        self.setLayout(layout)

        # 连接信号与槽
        self.button.clicked.connect(self.on_button_click)

        # 设置窗口标志（可选，确保独立显示）
        # self.setWindowFlags(self.windowFlags() | Qt.Window)

    def on_button_click(self):
        self.label.setText("按钮被点击！")

def show_singleton_dialog():
    """显示单例对话框"""
    global _global_window_instance

    # 检查现有窗口是否有效
    if _global_window_instance is not None and _global_window_instance.isVisible():
        # 如果窗口已存在且可见，激活并置于顶层
        _global_window_instance.raise_()
        _global_window_instance.activateWindow()
        return

    # 获取 Maya 主窗口
    maya_main_window = get_maya_main_window3()
    if not maya_main_window:
        print("无法获取 Maya 主窗口")
        return

    # 创建新窗口实例
    _global_window_instance = SingletonDialog(parent=maya_main_window)
    _global_window_instance.show()

if __name__ == "__main__":
    # 在 Maya 中延迟执行以避免事件循环冲突
    executeDeferred(show_singleton_dialog)
```

---

### 三、代码说明
1. **全局变量 `_global_window_instance`**：
   - 使用模块级变量 `_global_window_instance` 存储窗口实例。
   - 每次调用 `show_singleton_dialog` 时，检查该变量是否已有有效实例。

2. **窗口有效性检查**：
   - `if _global_window_instance is not None and _global_window_instance.isVisible()`：
     - 检查 `_global_window_instance` 是否存在且窗口可见（`isVisible()`）。
     - 如果窗口存在且可见，调用 `raise_()`（将窗口置于顶层）和 `activateWindow()`（激活窗口），避免创建新实例。

3. **获取 Maya 主窗口**：
   - 使用 `get_maya_main_window3` 获取 Maya 主窗口作为父对象。
   - 设置父窗口确保新窗口嵌入 Maya 的窗口层次结构，避免独立显示或被垃圾回收。

4. **延迟执行**：
   - `executeDeferred(show_singleton_dialog)` 确保窗口创建在 Maya 的主线程中运行，避免与 Maya 的事件循环冲突。

5. **窗口标志（注释部分）**：
   - 注释掉的 `self.setWindowFlags(Qt.Window)` 是可选的。如果不设置父窗口（`parent`），需要此标志使 `QDialog` 作为顶层窗口显示。
   - 在本例中，设置了 `maya_main_window` 作为父对象，因此不需要显式设置 `Qt.Window`。

---

### 四、运行方式
1. **保存脚本**：
   - 将代码保存为 `maya_singleton_dialog.py`。

2. **在 Maya 中运行**：
   - 打开 Maya 的脚本编辑器，运行以下命令：
     ```python
     import maya_singleton_dialog
     maya_singleton_dialog.show_singleton_dialog()
     ```
   - 或者直接粘贴整个脚本并执行。

3. **效果**：
   - 第一次运行：显示一个包含标签和按钮的对话框。
   - 再次运行：如果窗口已存在，会激活并置于顶层，而不是创建新窗口。
   - 关闭窗口后：再次运行会重新创建窗口。

### 五、替代单例化方法
除了使用全局变量，还有其他方法实现单例化窗口：

1. **类级单例模式**：
   使用类属性存储窗口实例，适合面向对象设计：
   ```python
   class SingletonDialog(QDialog):
       _instance = None

       @classmethod
       def get_instance(cls, parent=None):
           if cls._instance is None or not cls._instance.isVisible():
               cls._instance = cls(parent)
           return cls._instance

       def __init__(self, parent=None):
           super().__init__(parent)
           self.setWindowTitle("Maya 单例对话框")
           # ... 其余初始化代码
   ```

   使用方式：
   ```python
   def show_singleton_dialog():
       maya_main_window = get_maya_main_window3()
       dialog = SingletonDialog.get_instance(parent=maya_main_window)
       dialog.show()
       dialog.raise_()
       dialog.activateWindow()
   ```

2. **使用 `objectName` 检查现有窗口**：
   通过设置窗口的 `objectName` 并遍历 `QApplication.topLevelWidgets()` 检查是否已存在：
   ```python
   def show_singleton_dialog():
       app = QApplication.instance()
       for widget in app.topLevelWidgets():
           if widget.objectName() == "SingletonDialog":
               widget.raise_()
               widget.activateWindow()
               return
       maya_main_window = get_maya_main_window3()
       dialog = SingletonDialog(parent=maya_main_window)
       dialog.setObjectName("SingletonDialog")
       dialog.show()
   ```

3. **使用 `shiboken2.isValid`**：
   如果结合 Shiboken，可以检查窗口的 C++ 对象是否有效：
   ```python
   import shiboken2
   if _global_window_instance is not None and shiboken2.isValid(_global_window_instance):
       _global_window_instance.raise_()
       _global_window_instance.activateWindow()
   ```

### 六、注意事项
1. **窗口生命周期**：
   - 设置父窗口（`maya_main_window`）可防止窗口被 Python 垃圾回收器销毁。
   - 如果窗口关闭后未被销毁（例如只是隐藏），需检查 `isVisible()` 或 `shiboken2.isValid()`。

2. **Maya 事件循环**：
   - 总是使用 `executeDeferred` 延迟执行 UI 相关代码，避免与 Maya 的事件循环冲突。
   - 不要创建新的 `QApplication` 实例，直接使用 `QApplication.instance()`。

3. **版本兼容性**：
   - 示例使用 PySide2（Maya 2017-2023）。对于 Maya 2024+，替换为 `PySide6`。
   - 对于 Maya 2016 及更早版本，替换为 `PySide` 并调整 `QtWidgets` 为 `QtGui`。

4. **窗口关闭处理**：
   - 如果窗口关闭后需要重新创建，需确保 `_global_window_instance` 被重置：
     ```python
     def show_singleton_dialog():
         global _global_window_instance
         if _global_window_instance is not None and _global_window_instance.isVisible():
             _global_window_instance.raise_()
             _global_window_instance.activateWindow()
         else:
             _global_window_instance = None  # 重置实例
             maya_main_window = get_maya_main_window3()
             _global_window_instance = SingletonDialog(parent=maya_main_window)
             _global_window_instance.show()
     ```

5. **多线程注意**：
   - 窗口创建和操作必须在主线程进行，`executeDeferred` 确保这一点。
   - 如果涉及多线程，使用 `QtCore.QTimer` 或信号触发 UI 更新。

### 七、总结
在 Maya 中实现 PySide 界面的单例化，推荐使用全局变量存储窗口实例，结合 `isVisible()` 检查窗口状态，并通过 `get_maya_main_window3` 设置父窗口。示例代码使用 `QDialog` 创建单例窗口，延迟执行确保与 Maya 兼容。替代方法包括类级单例模式或通过 `objectName` 检查窗口。关键是避免重复创建窗口、正确管理生命周期，并在 Maya 环境中使用 `executeDeferred` 避免冲突。
