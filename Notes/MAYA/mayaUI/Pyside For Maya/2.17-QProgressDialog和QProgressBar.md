在 PySide（Qt for Python）中，`QProgressDialog` 和 `QProgressBar` 是用于显示任务进度或操作进度的两个常用控件。以下是对它们的介绍，以及在使用它们时与 `processEvents` 和 `setWindowModality` 相关的内容。

### 1. QProgressDialog
`QProgressDialog` 是一个对话框控件，用于向用户显示任务的进度（例如文件下载、数据处理等），并提供取消操作的选项。它通常用于长时间运行的任务，允许用户实时查看进度并选择是否中断。

#### 主要特性：
- **进度显示**：显示当前任务的进度（百分比或数值）。
- **取消按钮**：默认提供一个“取消”按钮，用户可以中断操作。
- **自动关闭**：当进度达到 100% 时，对话框可以自动关闭。
- **模态/非模态**：可以通过设置窗口模态性来控制是否阻塞主窗口。

#### 基本用法：
```python
from PySide6.QtWidgets import QProgressDialog, QApplication
import time

app = QApplication([])

# 创建进度对话框
progress = QProgressDialog("Processing...", "Cancel", 0, 100)
progress.setWindowTitle("Progress Dialog")
progress.setWindowModality(Qt.WindowModal)  # 设置为模态窗口

# 模拟一个任务
for i in range(101):
    progress.setValue(i)  # 更新进度
    if progress.wasCanceled():  # 检查是否点击了取消
        break
    time.sleep(0.1)  # 模拟耗时操作
    app.processEvents()  # 处理事件以保持界面响应

progress.close()
app.exec()
```

#### 关键方法：
- `setValue(int)`：设置当前进度值。
- `setMinimum(int)` 和 `setMaximum(int)`：设置进度范围。
- `setLabelText(str)`：设置对话框的描述文本。
- `wasCanceled()`：检查用户是否点击了取消按钮。
- `setCancelButtonText(str)`：设置取消按钮的文本。
- `setAutoClose(bool)`：设置是否在进度完成时自动关闭（默认 True）。

---

### 2. QProgressBar
`QProgressBar` 是一个简单的进度条控件，通常嵌入到其他窗口或布局中，用于显示任务的进度。它不像 `QProgressDialog` 那样自带对话框和取消按钮，但更灵活，可用于自定义界面。

#### 主要特性：
- **轻量级**：仅显示进度条，适合嵌入到主窗口或自定义对话框。
- **自定义样式**：可以通过样式表（QSS）调整外观。
- **方向**：支持水平或垂直进度条。

#### 基本用法：
```python
from PySide6.QtWidgets import QProgressBar, QApplication, QMainWindow
import time

app = QApplication([])

# 创建主窗口
window = QMainWindow()
progress_bar = QProgressBar(window)
progress_bar.setGeometry(50, 50, 200, 25)
progress_bar.setMinimum(0)
progress_bar.setMaximum(100)

window.show()

# 模拟任务
for i in range(101):
    progress_bar.setValue(i)  # 更新进度
    time.sleep(0.1)  # 模拟耗时操作
    app.processEvents()  # 处理事件以保持界面响应

app.exec()
```

#### 关键方法：
- `setValue(int)`：设置当前进度值。
- `setMinimum(int)` 和 `setMaximum(int)`：设置进度范围。
- `setOrientation(Qt.Orientation)`：设置进度条方向（`Qt.Horizontal` 或 `Qt.Vertical`）。
- `setFormat(str)`：自定义进度显示格式（如 `"%p%"` 表示百分比）。
- `reset()`：重置进度条到初始状态。

---

### 3. processEvents
`QApplication.processEvents()` 是 Qt 的事件循环处理方法，用于在长时间运行的任务中保持界面响应。在执行耗时操作（如循环）时，Qt 的事件循环可能会被阻塞，导致界面卡顿。调用 `processEvents()` 可以让 Qt 处理未处理的事件（如界面刷新、用户输入等）。

#### 使用场景：
- 在 `QProgressDialog` 或 `QProgressBar` 的更新循环中，调用 `processEvents()` 确保进度条或对话框实时更新。
- 防止界面在长时间任务中“假死”。

#### 注意事项：
- 过度调用 `processEvents()` 可能会降低性能，应在适当的地方（如每次循环迭代）调用。
- 如果任务在子线程中运行，通常不需要 `processEvents()`，而是通过信号和槽机制更新界面。

#### 示例：
在上述 `QProgressDialog` 和 `QProgressBar` 示例中，`app.processEvents()` 确保进度条或对话框在循环中能够实时更新。

---

### 4. setWindowModality
`setWindowModality(Qt.WindowModality)` 用于设置窗口的模态性，控制窗口是否阻塞其他窗口的交互。`QProgressDialog` 默认是模态的，而 `QProgressBar` 通常嵌入到其他窗口中，模态性由其父窗口控制。

#### 可选值：
- `Qt.NonModal`：非模态，用户可以与主窗口和其他窗口交互。
- `Qt.WindowModal`：窗口模态，阻塞父窗口，但允许与其他顶级窗口交互。
- `Qt.ApplicationModal`：应用程序模态，阻塞整个应用程序的所有窗口。

#### 使用场景：
- 在 `QProgressDialog` 中，设置模态性以决定用户是否可以在任务运行时操作主窗口。
- 例如，`progress.setWindowModality(Qt.WindowModal)` 使进度对话框阻塞其父窗口，但允许其他窗口操作。

#### 示例：
```python
progress = QProgressDialog("Processing...", "Cancel", 0, 100)
progress.setWindowModality(Qt.ApplicationModal)  # 阻塞整个应用程序
```

---

### 注意事项和最佳实践
1. **避免阻塞主线程**：对于耗时任务，建议将任务放到子线程中，通过信号和槽机制更新 `QProgressDialog` 或 `QProgressBar`，以避免频繁调用 `processEvents()`。
2. **用户体验**：
   - 在 `QProgressDialog` 中，设置合理的 `minimumDuration`（默认 4 秒），避免短任务频繁弹出对话框。
   - 使用 `setAutoReset(False)` 和 `setAutoClose(False)` 自定义对话框行为。
3. **性能优化**：更新进度时，尽量减少 `setValue` 的调用频率（如每 1% 更新一次，而不是每次微小变化都更新）。
4. **模态性选择**：根据需求选择合适的模态性，避免不必要的界面阻塞。

---

### 总结
- **`QProgressDialog`**：适合需要取消功能和模态对话框的场景，内置取消按钮和进度显示。
- **`QProgressBar`**：适合嵌入自定义界面，灵活但无内置对话框功能。
- **`processEvents`**：保持界面响应，适用于主线程中的耗时任务。
- **`setWindowModality`**：控制窗口的交互行为，适用于需要模态对话框的场景。

## QProgressDialog：弹出式进度条窗口
```python
import time
from Qt import QtCore, QtWidgets


class MyProgressDialog(QtWidgets.QDialog):
    _ui_instance = None
    WINDOW_TITLE = "Pregress Test"

    def __init__(self, parent=None):
        if parent is None:
            parent = self.get_maya_main_window()
        super().__init__(parent)

        self.setWindowTitle(MyProgressDialog.WINDOW_TITLE)
        self.setMinimumSize(300, 120)
        self.create_widgets()
        self.create_layout()
        self.create_connections()

    def create_widgets(self):
        self.progress_btn = QtWidgets.QPushButton("Do It!")

    def create_layout(self):
        btn_layout = QtWidgets.QHBoxLayout()
        btn_layout.addStretch()
        btn_layout.addWidget(self.progress_btn)

        main_layout = QtWidgets.QVBoxLayout(self)
        main_layout.setContentsMargins(2, 2, 2, 2)
        main_layout.addStretch()
        main_layout.addLayout(btn_layout)

    def create_connections(self):
        self.progress_btn.clicked.connect(self.on_btn_clicked)

    @QtCore.Slot()
    def on_btn_clicked(self):
        # 操作数
        num_operations = 10
        # 进度条对话框
        progress_dialog = QtWidgets.QProgressDialog(
            labelText="Waiting To Process...",
            cancelButtonText="Cancel",
            minimum=0,
            maximum=num_operations,
            parent=self,
        )
        # 设置标签和初始值
        progress_dialog.setWindowTitle("Progress")
        progress_dialog.setValue(0)
        # 设置对话框模态性为 WindowModal，模态性决定了窗口如何与其他窗口交互，特别是在用户输入方面。
        # 窗口模态（Window Modal）意味着当进度对话框显示时，用户无法与 self（父窗口）交互，直到 progress_dialog 关闭或被取消。
        progress_dialog.setWindowModality(QtCore.Qt.WindowModal)
        # 对话框显示
        progress_dialog.show()

        # 是一个静态方法，用于强制处理 Qt 事件循环中的所有待处理事件。
        # 它是 Qt 事件驱动机制的一部分，允许应用程序在执行长时间任务时保持界面的响应性，防止界面“冻结”
        QtCore.QCoreApplication.processEvents()
        # 迭代进度
        for i in range(num_operations):
            # 如果进度条取消按钮被点击，则取消进度
            if progress_dialog.wasCanceled():
                break
            # 设置进度条上方的标签
            progress_dialog.setLabelText(
                f"Processing operation: {i} of {num_operations}"
            )
            # 设置进度条值，会转化为百分比在进度条上显示
            progress_dialog.setValue(i)
            # 每个操作数睡眠0.5秒
            time.sleep(0.5)
            # 进度条事件
            QtCore.QCoreApplication.processEvents()

        # 对话框关闭
        progress_dialog.close()

    @staticmethod
    def get_maya_main_window():
        """通过 QApplication 获取 Maya 主窗口的 PySide 实例"""
        # 用于获取当前运行的 maya QApplication 实例
        app = QtWidgets.QApplication.instance()
        # 如果当前没有运行的实例，返回None
        if not app:
            return None
        # app.topLevelWidgets() 返回当前 QApplication 管理的所有顶层窗口（没有父窗口）列表
        for widget in app.topLevelWidgets():
            # 如果窗口的 Qt 对象名称为"MayaWindow"，返回这个窗口实例
            if widget.objectName() == "MayaWindow":
                return widget
        return None

    @classmethod
    def show_ui(cls):
        """单例模式显示UI"""
        if cls._ui_instance is None:
            cls._ui_instance = MyProgressDialog()
        if cls._ui_instance.isHidden():
            cls._ui_instance.show()
        else:
            cls._ui_instance.raise_()
            cls._ui_instance.activateWindow()


if __name__ == "__main__":
    MyProgressDialog.show_ui()

```
## QProgressBar：嵌入式进度条控件
```python
import time
from Qt import QtCore, QtWidgets


class MyProgressDialog(QtWidgets.QDialog):
    _ui_instance = None
    WINDOW_TITLE = "Pregress Test"

    def __init__(self, parent=None):
        if parent is None:
            parent = self.get_maya_main_window()
        super().__init__(parent)

        self.setWindowTitle(MyProgressDialog.WINDOW_TITLE)
        self.setMinimumSize(300, 120)

        self.is_progressing = False

        self.create_widgets()
        self.create_layout()
        self.create_connections()

    def create_widgets(self):
        self.progress_label = QtWidgets.QLabel("Progress")
        self.progress_bar = QtWidgets.QProgressBar()

        self.doIt_btn = QtWidgets.QPushButton("Do It!")
        self.cancel_btn = QtWidgets.QPushButton("Cancel!")
        self.update_visibility()

    def create_layout(self):
        progress_layout = QtWidgets.QVBoxLayout()
        progress_layout.addWidget(self.progress_label)
        progress_layout.addWidget(self.progress_bar)

        btn_layout = QtWidgets.QHBoxLayout()
        btn_layout.addStretch()
        btn_layout.addWidget(self.doIt_btn)
        btn_layout.addWidget(self.cancel_btn)

        main_layout = QtWidgets.QVBoxLayout(self)
        main_layout.setContentsMargins(2, 2, 2, 2)
        main_layout.addLayout(progress_layout)
        main_layout.addStretch()
        main_layout.addLayout(btn_layout)

    def create_connections(self):
        self.doIt_btn.clicked.connect(self.on_doIt_btn_clicked)
        self.cancel_btn.clicked.connect(self.on_cancel_btn_clicked)

    def update_visibility(self):
        """设置控件的显示和隐藏"""
        self.progress_label.setVisible(self.is_progressing)
        self.progress_bar.setVisible(self.is_progressing)

        self.doIt_btn.setHidden(self.is_progressing)
        self.cancel_btn.setVisible(self.is_progressing)

    @QtCore.Slot()
    def on_doIt_btn_clicked(self):
        # 如果正在进度中，不能再次开启进度
        if self.is_progressing:
            return
        # 操作数
        num_operations = 10
        # 设置进度条控件
        self.progress_bar.setRange(0, num_operations)
        self.progress_bar.setValue(0)
        self.progress_label.setText("Progress")

        self.is_progressing = True
        self.update_visibility()

        # 迭代进度
        for i in range(num_operations):
            # 如果进度条取消按钮被点击，则取消进度
            if not self.is_progressing:
                break
            # 设置进度条上方的标签
            self.progress_label.setText(
                f"Processing operation: {i} of {num_operations}"
            )
            # 设置进度条值，会转化为百分比在进度条上显示
            self.progress_bar.setValue(i)
            # 每个操作数睡眠0.5秒
            time.sleep(0.5)
            # 强制更新进度条显示
            QtCore.QCoreApplication.processEvents()
        # 关闭进度条
        self.is_progressing = False
        # 更新界面显示
        self.update_visibility()

    @QtCore.Slot()
    def on_cancel_btn_clicked(self):
        self.is_progressing = False

    @staticmethod
    def get_maya_main_window():
        """通过 QApplication 获取 Maya 主窗口的 PySide 实例"""
        # 用于获取当前运行的 maya QApplication 实例
        app = QtWidgets.QApplication.instance()
        # 如果当前没有运行的实例，返回None
        if not app:
            return None
        # app.topLevelWidgets() 返回当前 QApplication 管理的所有顶层窗口（没有父窗口）列表
        for widget in app.topLevelWidgets():
            # 如果窗口的 Qt 对象名称为"MayaWindow"，返回这个窗口实例
            if widget.objectName() == "MayaWindow":
                return widget
        return None

    @classmethod
    def show_ui(cls):
        """单例模式显示UI"""
        if cls._ui_instance is None:
            cls._ui_instance = MyProgressDialog()
        if cls._ui_instance.isHidden():
            cls._ui_instance.show()
        else:
            cls._ui_instance.raise_()
            cls._ui_instance.activateWindow()


if __name__ == "__main__":
    MyProgressDialog.show_ui()
```
