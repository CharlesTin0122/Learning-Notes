在 PySide（Qt for Python）中，`QImage` 和 `QPixmap` 是处理图像的两个核心类，分别用于不同的场景和用途。以下是对它们的介绍以及如何使用它们处理图片的说明。

### 1. **QImage**
- **用途**：`QImage` 是一个用于图像处理的类，主要用于像素级别的操作（如编辑、转换、加载和保存图像）。它独立于窗口系统，适合在非 GUI 线程中进行图像处理。
- **特点**：
  - 提供对图像像素的直接访问，适合图像编辑（如调整亮度、裁剪、绘制）。
  - 支持多种图像格式（如 PNG、JPEG、BMP 等）。
  - 可以轻松转换为其他格式或用于数据处理。
  - 内存占用较低，适合后台处理。
- **常见操作**：
  - 加载图像：`QImage("image.png")`
  - 获取像素值：`QImage.pixel(x, y)`
  - 设置像素值：`QImage.setPixel(x, y, color)`
  - 缩放：`QImage.scaled(width, height, Qt.AspectRatioMode)`
  - 保存图像：`QImage.save("output.png")`

### 2. **QPixmap**
- **用途**：`QPixmap` 是一个专为在 GUI 中显示图像的类，优化了在 `QWidget` 或 `QPainter` 上绘制图像的性能。它依赖于窗口系统，适合在界面上显示图像。
- **特点**：
  - 适合直接在 `QLabel`、`QPushButton` 或其他控件上显示。
  - 性能针对屏幕渲染优化，但不适合复杂的像素级操作。
  - 可以从 `QImage` 转换而来，用于显示经过处理的图像。
- **常见操作**：
  - 加载图像：`QPixmap("image.png")`
  - 设置到控件：`QLabel.setPixmap(pixmap)`
  - 缩放：`QPixmap.scaled(width, height, Qt.AspectRatioMode)`
  - 转换为 `QImage`：`QPixmap.toImage()`

### 3. **QImage 和 QPixmap 的对比**
| 特性                | QImage                              | QPixmap                             |
|---------------------|-------------------------------------|-------------------------------------|
| **用途**            | 图像处理（像素级操作）               | 图像显示（GUI 渲染）                |
| **依赖性**          | 独立于窗口系统                     | 依赖窗口系统                       |
| **性能**            | 适合后台处理                       | 适合屏幕显示                       |
| **典型场景**        | 编辑、保存、格式转换               | 在窗口、按钮、标签上显示图像       |
| **转换**            | 可转为 `QPixmap`                   | 可转为 `QImage`                    |

### 4. **如何处理图片**
以下是一些常见的图片处理场景及代码示例，使用 PySide6（PySide 的最新版本）。

#### 示例 1：加载和显示图片
```python
from PySide6.QtWidgets import QApplication, QLabel, QMainWindow
from PySide6.QtGui import QPixmap
import sys

app = QApplication(sys.argv)
window = QMainWindow()
label = QLabel(window)

# 加载图片到 QPixmap
pixmap = QPixmap("example.jpg")
# 缩放图片
pixmap = pixmap.scaled(300, 300, aspectRatioMode=Qt.KeepAspectRatio)
label.setPixmap(pixmap)

window.setCentralWidget(label)
window.show()
app.exec()
```

#### 示例 2：编辑图片（调整亮度）
```python
from PySide6.QtGui import QImage, QColor
from PySide6.QtCore import Qt

# 加载图片到 QImage
image = QImage("example.jpg")

# 调整亮度（示例：增加亮度）
for y in range(image.height()):
    for x in range(image.width()):
        color = QColor(image.pixel(x, y))
        # 增加亮度（简单示例：RGB 各增加 50）
        r = min(color.red() + 50, 255)
        g = min(color.green() + 50, 255)
        b = min(color.blue() + 50, 255)
        image.setPixel(x, y, QColor(r, g, b).rgb())

# 保存处理后的图片
image.save("output.jpg")
```

#### 示例 3：QImage 和 QPixmap 互转并显示
```python
from PySide6.QtWidgets import QApplication, QLabel, QMainWindow
from PySide6.QtGui import QImage, QPixmap
from PySide6.QtCore import Qt
import sys

app = QApplication(sys.argv)
window = QMainWindow()
label = QLabel(window)

# 加载图片到 QImage
image = QImage("example.jpg")
# 转换为 QPixmap 以显示
pixmap = QPixmap.fromImage(image)
pixmap = pixmap.scaled(300, 300, aspectRatioMode=Qt.KeepAspectRatio)
label.setPixmap(pixmap)

window.setCentralWidget(label)
window.show()
app.exec()
```

#### 示例 4：处理大图片并显示部分区域
```python
from PySide6.QtWidgets import QApplication, QLabel, QMainWindow
from PySide6.QtGui import QImage, QPixmap
from PySide6.QtCore import Qt
import sys

app = QApplication(sys.argv)
window = QMainWindow()
label = QLabel(window)

# 加载大图片
image = QImage("large_image.jpg")
# 裁剪部分区域（x, y, width, height）
cropped_image = image.copy(100, 100, 200, 200)
# 转换为 QPixmap 显示
pixmap = QPixmap.fromImage(cropped_image)
label.setPixmap(pixmap)

window.setCentralWidget(label)
window.show()
app.exec()
```

### 5. **注意事项**
- **格式支持**：PySide 支持常见的图像格式（如 PNG、JPEG、BMP），但某些格式可能需要 Qt 插件支持（如 WebP）。
- **性能优化**：
  - 对于大图像，尽量使用 `QImage` 进行处理，完成后转换为 `QPixmap` 显示。
  - 使用 `scaled()` 时，选择合适的 `Qt.AspectRatioMode`（如 `KeepAspectRatio`）以保持图像比例。
- **线程安全**：
  - `QImage` 可在非 GUI 线程中使用。
  - `QPixmap` 必须在 GUI 线程中使用。
- **内存管理**：处理大图像时，注意释放内存，避免内存泄漏。

### 6. **其他工具**
- 如果需要更复杂的图像处理（如滤镜、边缘检测），可以结合 `QImage` 与其他库（如 Pillow 或 OpenCV），处理后再转换为 `QPixmap` 显示。
- PySide 的 `QPainter` 可以用来在 `QImage` 或 `QPixmap` 上绘制图形、文字等。

```python
from pathlib import Path
from Qt import QtCore, QtWidgets, QtGui


class TemplateDialog(QtWidgets.QDialog):
    _ui_instance = None
    WINDOW_TITLE = "Template"

    def __init__(self, parent=None):
        if parent is None:
            parent = self.get_maya_main_window()
        super().__init__(parent)

        self.setWindowTitle(TemplateDialog.WINDOW_TITLE)
        self.setMinimumSize(300, 120)

        self.create_widgets()
        self.create_layout()
        self.create_connections()

    def create_widgets(self):
        self.image_label = QtWidgets.QLabel("Image Label")
        self.adding_images()
        self.apply_btn = QtWidgets.QPushButton("Apply")
        self.close_btn = QtWidgets.QPushButton("Close")

    def create_layout(self):
        btn_layout = QtWidgets.QHBoxLayout()
        btn_layout.addWidget(self.apply_btn)
        btn_layout.addWidget(self.close_btn)

        main_layout = QtWidgets.QVBoxLayout(self)
        main_layout.addWidget(self.image_label)
        main_layout.addStretch()
        main_layout.addLayout(btn_layout)

    def adding_images(self):
        # 获取当前文件路径
        current_file_path = Path(__file__).resolve()
        # 获取包的根路径
        for parent in current_file_path.parents:
            if (parent / "__init__.py").exists():
                project_file_path = parent
        # 获取图片路径
        image_path = Path(project_file_path, "icons", "profile.png")
        # 创建并缩放图像
        image = QtGui.QImage(str(image_path))
        # Qt.KeepAspectRatio 确保图像比例不变。Qt.SmoothTransformation 提高缩放质量
        image = image.scaled(
            80, 80, QtCore.Qt.KeepAspectRatio, QtCore.Qt.SmoothTransformation
        )
        # 创建并使用QPixmap
        pixmap = QtGui.QPixmap.fromImage(image)
        self.image_label.setPixmap(pixmap)

    def create_connections(self):
        pass

    @QtCore.Slot()
    def template_slot(self):
        pass

    @staticmethod
    def get_maya_main_window():
        """通过 QApplication 获取 Maya 主窗口的 PySide 实例"""
        # 用于获取当前运行的 maya QApplication 实例
        app = QtWidgets.QApplication.instance()
        # 如果当前没有运行的实例，返回None
        if not app:
            return None
        # app.topLevelWidgets() 返回当前 QApplication 管理的所有顶层窗口（没有父窗口）列表
        for widget in app.topLevelWidgets():
            # 如果窗口的 Qt 对象名称为"MayaWindow"，返回这个窗口实例
            if widget.objectName() == "MayaWindow":
                return widget
        return None

    @classmethod
    def show_ui(cls):
        """单例模式显示UI"""
        if cls._ui_instance is None:
            cls._ui_instance = TemplateDialog()
        if cls._ui_instance.isHidden():
            cls._ui_instance.show()
        else:
            cls._ui_instance.raise_()
            cls._ui_instance.activateWindow()


if __name__ == "__main__":
    TemplateDialog.show_ui()
```
