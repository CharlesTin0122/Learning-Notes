Qualoth 是目前 Autodesk Maya 中最专业、最强大的**商用布料/布料模拟插件**之一，由韩国公司 **FXGear** 开发，已经有接近20年的历史，在影视 VFX、电影、游戏 AAA 级角色布料模拟领域有非常广泛的应用。

### Qualoth 的核心优势（2025-2026 年现状）

| 方面                      | Qualoth 的表现                     | 与 nCloth 对比     | 与 Marvelous Designer 对比   |
| ----------------------- | ------------------------------- | --------------- | ------------------------- |
| 模拟速度                    | 非常快（尤其是多层布料）                    | 中等～慢            | MD 建模快，模拟本身不算特别快          |
| 多层布料穿透处理                | 极强（2025 版本提升 3× 速度）             | 经常穿帮，需要大量约束     | 很好，但转 Maya 后仍需二次解算        |
| 快速运动碰撞稳定性               | 非常优秀（高速运动、激烈打斗）                 | 较容易爆炸或穿模        | 一般（MD 不擅长极端物理）            |
| 自碰撞（Self-collision）     | 非常鲁棒，几乎不会穿模                     | 需要调很多参数，很容易出问题  | 很好，但细节褶皱有时过度              |
| 与 Marvelous Designer 兼容 | 2025 版原生支持 MD 元数据无缝导入           | 无原生支持           | —（本身就是 MD）                |
| 高分辨率布料细节                | 能保留非常细小的褶皱                      | 高 res 容易爆炸或计算极慢 | 细节很好，但转引擎/Maya 常丢失        |
| 缓存与播放流畅度                | 支持 Maya Cached Playback（2020 后） | 原生支持            | 需导出缓存                     |
| 主要使用场景                  | 影视特效、电影角色布料最终解算                 | 中低预算项目、原型测试     | 建模 + 初次模拟（常作为 Qualoth 上游） |

### 2025-2026 年 Qualoth 的重要更新点

- **无缝导入 Marvelous Designer**（包括缝线信息、分组、图层等元数据）
- **多层布料碰撞速度提升约 3 倍**
- 继续保持对高速运动物体、复杂自碰撞的极强稳定性
- 依然是很多大厂 VFX 部门最终布料解算器的首选（尤其需要打斗、翻滚、爆炸等激烈动作时）

### 典型工作流程（现在最常见组合）

1. Marvelous Designer → 快速制作服装版型 + 初次模拟 + 摆姿势
2. 导出 .zpac / .fbx + 元数据 → 导入 Maya + Qualoth
3. Qualoth 内做精细物理调整、与骨骼/动画最终匹配
4. 输出缓存 → 给渲染（Arnold / V-Ray / Redshift 等）

### 谁在用 Qualoth？

# 参数调优
Qualoth 的参数调优其实**80%靠经验 + 针对性分层调整**，而不是把所有参数都拉到极端。以下是2025-2026年主流工作流中最实用、最常被大厂VFX/游戏布料艺术家使用的调参思路和常见数值范围（以Maya Qualoth节点为主）。

我把参数按**优先级顺序**排列，先调最重要的几个就能解决90%的爆炸/穿模/太软/太硬问题。

### 调参黄金顺序（推荐执行顺序）

| 优先级 | 参数组 / 节点属性                  | 目的                              | 常见起始值 / 推荐范围                  | 快速判断标准（看哪里出问题）                  |
|--------|------------------------------------|-----------------------------------|----------------------------------------|-----------------------------------------------|
| 1      | Time Step / Substeps               | 决定整体稳定性（防爆炸核心）      | 0.008–0.016（或更小到0.004）           | 高速运动/激烈碰撞先把这个降到0.005以下       |
| 2      | Self Collision → Thickness / Proximity | 自碰撞厚度 & 检测距离             | Thickness: 0.8–2.5 cm<br>Proximity: 1.2–2.5×Thickness | 穿模最严重时 → 先加厚到2.0–3.0再降回正常     |
| 3      | Material → Stretch Resistance      | 布料抗拉伸（防过度变形）          | 棉/丝绸: 80–300<br>牛仔/皮革: 400–1500<br>厚外套: 800–3000 | 布料被拉得像橡皮 → 加大到2–5倍               |
| 4      | Shear Resistance                   | 抗剪切（防斜向变形、保持形状）    | 通常设为 Stretch 的 0.4–0.8倍         | 布料斜向扭曲严重 → 加大到接近Stretch值       |
| 5      | Bend Resistance / Bend Angle Dropoff | 抗弯折（控制褶皱硬度）            | 薄布: 5–30<br>厚布/西装: 40–150<br>皮革: 200+ | 褶皱太软/太平 → 加大Bend<br>褶皱太死板 → 减小+用Dropoff |
| 6      | Damping → Stretch / Bend / Air     | 消抖 & 减慢运动（防高频抖动）     | Stretch Damp: 0.02–0.15<br>Bend Damp: 0.05–0.4<br>Air Damp: 0.1–1.0 | 布料抖个不停 → 加大Damping（但别超过0.3）    |
| 7      | Friction → Cloth-Cloth / Cloth-Collider | 摩擦力（防滑溜）                  | Cloth-Cloth: 0.15–0.4<br>Collider: 0.2–0.6 | 布料在身上滑太快 → 加大到0.35+               |
| 8      | Global → Gravity Scale / Drag      | 整体重力/空气阻力微调             | Gravity: 0.9–1.1<br>Drag: 0.2–1.5      | 布料下坠太慢/太快 → 微调Gravity              |
| 9      | Collision → Max Penetration Depth  | 允许的最大穿透深度（最后手段）    | 默认或0.5–2.0 cm                       | 实在消不掉穿模 → 临时开到3–5cm再慢慢降       |

### 快速调试口诀（从业者常用）

- 先稳 → Time Step ↓ + Self Collision Thickness ↑ + Substeps ↑（通常到4–8）
- 再形 → Stretch & Shear 往上加（从低往高试，翻倍测试）
- 后褶 → Bend Resistance + Bend Damp 微调（Dropoff功能2020年后很强，建议用）
- 最后味 → Friction + Air Damping + 小幅Bend Angle Dropoff（保留小褶皱但消大抖动）

### 额外高阶小技巧（2025+版本常用）

1. 用 **Bend Angle Dropoff** + **Bend Damp Dropoff** 组合：大角度弯折阻尼强，小角度弱 → 保留细褶皱但不乱抖。
2. 多层布料时 → 每层单独给一点 **Cloth-Cloth Friction** 差异（内层0.4，外层0.25），减少层间粘连感。
3. 从Marvelous Designer导入后 → 记得检查 **UV Scale Factor** 是否匹配，Scale不一致会导致Stretch Resistance实际强度错乱。
4. 激烈打斗/翻滚镜头 → Time Step 强制0.004–0.008 + Self Proximity 加大到3–5倍Thickness，几乎无穿模。
5. 想快算 → 降低 **Max Solver Iterations** 到40–80（默认200+），配合更大的Time Step，先跑low-res看趋势。
