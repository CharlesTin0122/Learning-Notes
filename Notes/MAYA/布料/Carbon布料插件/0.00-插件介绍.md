**Carbon**（全称 **Carbon for Maya**，也常被称为 **Carbon Cloth** 或 **Numerion Carbon**）是目前Maya中最强大的第三方**布料/软体解算插件**之一，由英国公司 **Numerion Software** 开发。

它在VFX影视行业（尤其是英雄布料、数字双人、复杂多层服装）中被广泛使用，很多顶级工作室（如MPC、ILM等）都用过或正在使用它。

### 核心特点（与nCloth、Qualoth、Bifrost MPM对比）

| 项目              | Carbon for Maya                          | nCloth (Maya内置)          | Qualoth                  | Bifrost MPM            |
|-------------------|------------------------------------------|-----------------------------|--------------------------|------------------------|
| 解算速度          | 非常快（优化极好）                       | 中等～慢                    | 较快                     | 很快（GPU可加速）      |
| 稳定性            | 极高（极少爆炸）                         | 一般（经常需要调参救火）    | 较高                     | 较高                   |
| 多层布料/自碰撞   | 非常优秀，支持厚衣服、多层、缝线         | 中等                        | 很好                     | 较好                   |
| Hero级布料细节    | 目前行业顶尖之一                         | 较难达到电影级精细          | 优秀                     | 正在追赶               |
| 与CLO/Marvelous Designer兼容 | 极佳（有专用Garment Processor）          | 一般                        | 好                       | 一般                   |
| 各向异性/真实织物 | 支持非常真实的各向异性布料               | 有限                        | 支持                     | 支持                   |
| 软体/皮肤/羽毛    | 支持（不只布料）                         | 部分支持                    | 主要布料                 | 优秀（颗粒+布料）      |
| 学习曲线          | 中等偏高（参数非常多且专业）             | 较低                        | 中等                     | 中高                   |
| 价格              | 商业付费（较贵）                         | 免费                        | 付费                     | 免费（Maya内）         |
| 2025-2026支持     | 支持Maya 2023–2026（最新3.0版）          | 原生支持                    | 支持                     | 原生支持               |

2025年9月刚发布的 **Carbon 3.0** 版本进一步强化了从CLO/Marvelous Designer导入的流程（支持welded和unwelded两种模式），以及物理LOD、多材质预设等功能。

### 主要节点类型（Maya内常用）

- **Carbon Simulation**：核心解算器节点（控制时间步长、子步、迭代、重力、阻尼等全局参数）
- **Carbon Cloth**：布料对象（支持start/reference/goal三种网格输入）
- **Carbon Cloth Material**：材质属性（支撑、剪切、弯曲、压缩、各向异性、塑性等，非常物理化）
- **Carbon Collider**：碰撞体
- **Carbon Stitching / Carbon Crease**：缝线、褶皱约束
- **Carbon Garment Processor**：专门处理CLO/MD导入的服装（新功能最实用）
- **Carbon Binding**：绑定、焊接、软绑定等

### 典型使用场景

- 电影/剧集中的主角服装（多层西装、长袍、婚纱、斗篷）
- 数字人/虚拟角色的皮肤+衣服联合模拟
- 飘逸长裙、旗帜、帆布、绳索
- 需要极高稳定性和细节的商业广告、虚拟制片
- 从CLO/Marvelous Designer直接导入高精度缝制服装后继续做Maya里的二次动力学

### 快速入门建议

1. 官网下载试用版（numerion-software.com）
2. 先看官方YouTube频道 **Numerion Software** 的Maya教程系列（从Carbon Simulation、Material、Garment Processor开始看）
3. 导入CLO/MD衣服 → 用Garment Processor处理 → 赋Material预设 → 创建Simulation → 跑解算
4. 常用技巧：用Reference Mesh + Start Mesh组合来解决初始穿模问题

一句话总结：

**如果你的项目对布料品质要求非常高（尤其是Hero cloth、多层复杂服装），而且预算允许，Carbon目前是Maya生态里最接近“又快又稳又真实”的顶级选择。**
