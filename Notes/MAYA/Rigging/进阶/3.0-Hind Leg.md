# 驱动骨骼
- 添加驱动骨骼
- ![](attachments/3.0-Hind%20Leg-2.png)
- 驱动骨骼轴向跟腿部骨骼一致，驱动骨骼第一节长度跟腿部骨骼第一节长度一致，驱动骨骼第二节长度等于腿部骨骼第二三级长度之和
- 通过在驱动骨骼创建旋转平面IK，来对位末端位置，然后使用腿部膝盖骨骼给驱动骨骼IK句柄一个极向量约束
- ![](attachments/3.0-Hind%20Leg-3.png)
- 然后调整驱动骨骼IK句柄的Twist属性为180，实现骨骼反转
- ![](attachments/3.0-Hind%20Leg-4.png)![](attachments/3.0-Hind%20Leg-5.png)
- 对位完成后删除IK句柄，执行冻结变换
- 再次为驱动骨骼添加旋转平面IK，创建极向量控制器，添加及向量约束，此时骨骼反转，我们再次为IK句柄的Twist属性值设为180
- ![](attachments/3.0-Hind%20Leg-6.png)
- 将此IK句柄作为反转脚脚踝骨骼子对象
- 创建其他腿部控制器IK
- 创建第三节骨骼控制器，位置在脚踝，我们要使用他的旋转来操纵第三节骨骼旋转
- ![](attachments/3.0-Hind%20Leg-7.png)
- 我们使用驱动骨骼第二节，旋转约束第三节骨骼控制器的偏移组（取消勾选保持偏移），这样控制器的朝向会始终跟随驱动骨骼第二节
- ![](attachments/3.0-Hind%20Leg-8.png)
- 我们将控制器层级置于反转脚脚踝骨骼层级之下，这样此控制器会跟随脚踝运动
- 添加IK
	- 为主骨骼1、3创建foot_ik
	- 3、4创建carpus_ik
	- 4、5创建ball_ik
	- 5、6创建toe_ik
- 使用我们的极向量控制器为foot_ik和carpus_ik添加极向量约束
- 将foot_ik和carpus_ik作为脚踝控制器的子对象
- ![](attachments/3.0-Hind%20Leg-9.png)![](attachments/3.0-Hind%20Leg-10.png)
- 将ball_ik和toe_ik放置于对应的反转脚骨骼层级之下
- ![](attachments/3.0-Hind%20Leg-11.png)
