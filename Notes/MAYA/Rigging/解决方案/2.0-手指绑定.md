# 计算原理
- 伸展形态，骨骼之间的距离称为：0,1,2,3...。骨骼和手指下表面之间的距离称为：h0,h1,h2,h3...
[Open: 8.0-手指绑定-1765266566388.png](attachments/d5af1b1ac48cf87cba8e98fb5434f9a4_MD5.jpg)
![|782x210](attachments/d5af1b1ac48cf87cba8e98fb5434f9a4_MD5.jpg)
- 弯曲形态，我们发现：1指节长度 = 3指节长度 + 掌骨高度
[Open: 8.0-手指绑定-1765266690658.png](attachments/4d219c503a875ac1d5341ee65a398f49_MD5.jpg)
![|575x452](attachments/4d219c503a875ac1d5341ee65a398f49_MD5.jpg)
- 并且，2指节长度 = 1指节骨骼高度 + 3指节骨骼高度
- [Open: 8.0-手指绑定-1765266838888.png](attachments/984d993884e08cdcc6644f148f1e4b08_MD5.jpg)
![|587x567](attachments/984d993884e08cdcc6644f148f1e4b08_MD5.jpg)
# 总结
- 我们发现手指的变形效果跟手指的长度和粗度有关，
	- 如果是粗一点的手指，需要将骨骼位置向下移动
	- 如果是细一点的手指需要将骨骼位置向上移动
- 1指节长度 = 3指节长度 + 掌骨高度
- 2指节长度 = 1指节骨骼高度 + 3指节骨骼高度
- 修改方法：使用Move Skined Joints 命令，修改骨骼位置，不断尝试比较，尝试完成后确定骨骼位置，然后根据位置重构骨架
# 手指朝向问题
绑定时可能会遇到手指弯曲后不能平行的问题
[Open: 8.0-手指绑定-1765275765723.png](attachments/ecf8e773f9cdb65c250c62d854bb0dd3_MD5.jpg)
![](attachments/ecf8e773f9cdb65c250c62d854bb0dd3_MD5.jpg)
- 这主要是因为骨骼次轴（一般手指沿X轴延伸，即X轴为主轴，绕Z轴旋转，Y轴便是次轴），适当调整Y轴朝向即可
![|481x381](attachments/ee97cb5c9ecc65318bafa107ae2319a7_MD5.jpg)![|553x380](attachments/8b7dae70f2490c1d24a51f23fa808836_MD5.jpg)
- 解决方案：手动修改骨骼局部旋转轴，不断尝试比较，尝试完成后确定骨骼朝向，然后根据朝向重构骨架
