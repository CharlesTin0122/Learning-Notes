Maya（Autodesk Maya）中的**变形器（Deformers）** 是非常核心且强大的工具之一，主要用于：

- **建模阶段**：快速塑造、调整模型形状（非破坏性）
- **动画阶段**：驱动几何体产生各种形变动画（如表情、肌肉、布料摆动等）

简单来说，变形器就是“以各种方式扭曲、挤压、拉伸、弯曲几何体点”的高级工具包。

### Maya主要变形器分类与用途（2024-2025最新常用列表）

| 类别         | 变形器名称                | 中文常用叫法      | 主要用途与特点                          | 典型使用场景                     |
| ---------- | -------------------- | ----------- | -------------------------------- | -------------------------- |
| 基础/点控制类    | **Cluster**          | 集群 / 簇变形    | 通过控制柄（百分比权重）移动一组点                | 局部调整、简单肌肉控制、手指弯曲           |
|            | **Lattice**          | 晶格 / 格子变形   | 用一个可控的立方体格子来变形内部物体               | 整体有机形变、卡通风格挤压拉伸            |
| 融合/目标形状类   | **Blend Shape**      | 融合变形 / 混合形状 | 把一个模型渐变成另一个模型（同拓扑）               | 面部表情、口型、 corrective shapes |
|            | **Morph**            | 变形 / 渐变变形   | 类似Blend Shape但更现代的节点（较新版本）       | 高级形状混合                     |
| 非线性变形类     | **Bend**             | 弯曲          | 沿轴向弯折物体                          | 手臂弯曲、植物枝条、纸张卷曲             |
|            | **Twist**            | 扭曲 / 扭转     | 沿轴向旋转扭曲                          | 毛巾拧干、蛇形运动、钻头               |
|            | **Sine**             | 正弦波         | 产生波浪状周期性变形                       | 水波、触手、布料飘动                 |
|            | **Squash & Stretch** | 压扁 & 拉伸     | 经典卡通风格体积保持挤压拉伸                   | 弹跳球、Q版角色跳跃                 |
|            | **Flare**            | 喇叭 / 扩张     | 从中心向外或向内扩张/收缩                    | 爆炸效果、花朵绽放                  |
|            | **Wave**             | 波浪          | 线性方向的波浪传播                        | 海浪、旗帜飘动                    |
| 高级/物理类     | **Jiggle**           | 果冻 / 抖动     | 模拟软体二次抖动（有衰减）                    | 脂肪、胸、肚子晃动                  |
|            | **Delta Mush**       | Delta Mush  | 保持体积、修复蒙皮塌陷（非常常用）                | 角色绑定后修正形变、肌肉保持             |
|            | **Curve Warp**       | 曲线扭曲 / 路径变形 | 让物体沿着一条NURBS曲线变形                 | 头发、绳子、藤蔓沿路径生长              |
|            | **Maya Muscle**      | Maya肌肉系统    | 完整的肌肉模拟系统（拉伸、挤压、碰撞）              | 真实感角色肌肉动画                  |

### 快速记忆口诀（最常用的几个）

“**三剑客**” → **Blend Shape + Cluster + Lattice**（几乎所有 rigging 都会用到）

“**非线性六兄弟**” → Bend / Twist / Sine / Squash / Flare / Wave

“**救命三件套**” → Delta Mush + Jiggle + Corrective Blend Shape（修型神器）

### 使用小技巧与注意事项（2024-2025版）

1. **变形顺序非常重要**  
   Maya按历史栈从上到下计算变形。先弯曲再正弦 ≠ 先正弦再弯曲

2. **常用快捷操作**
   - Deform → Create Lattice / Cluster / Bend 等
   - 中键拖动操纵器手柄快速调整
   - Paint Weights Tool 可以画权重（几乎所有变形器都支持）

3. **想永久应用变形？**
   - 修改 → Freeze Transformations（冻结变换）
   - Edit Deformers → Delete by Type（删除历史，但保留形状）

4. **2025新特性亮点**
   - **ML Deformer**（机器学习变形器）：训练一次复杂变形后，可以用极低代价实时计算，非常适合高精度面部/肌肉系统迁移到游戏引擎
