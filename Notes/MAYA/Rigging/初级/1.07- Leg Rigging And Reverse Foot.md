# Leg Rigging
- 与手臂绑定大致相同，只不过手臂绑定的IKFK骨骼只有三节，上臂 前臂和手掌，但是脚部IKFK骨骼包含整个腿部骨架
- ![](初级/attachments/07-%20Leg%20Rigging%20And%20Reverse%20Foot.png)
- IK骨骼除了大腿小腿和脚骨骼设置旋转平面IK解算器。脚踝到脚趾，脚趾到脚尖要分别设置单链IK解算器，之所以能使用单链IK，是因为我们不想出现平面旋转的现象。
- ![](初级/attachments/07-%20Leg%20Rigging%20And%20Reverse%20Foot-7.png)
# Reverse Foot
## 设置反转脚骨骼
- 从主骨骼拷贝一份脚部骨骼
- ![](初级/attachments/07-%20Leg%20Rigging%20And%20Reverse%20Foot-1.png)
- 将脚尖骨骼拷贝一份移动到在脚后跟
- ![](初级/attachments/07-%20Leg%20Rigging%20And%20Reverse%20Foot-2.png)
- 将新的脚后跟骨骼作为脚尖骨骼的子对象
- ![](初级/attachments/07-%20Leg%20Rigging%20And%20Reverse%20Foot-3.png)
- 将脚后跟骨骼作为根骨骼，使用RerootSkeleton命令
- ![](初级/attachments/07-%20Leg%20Rigging%20And%20Reverse%20Foot-4.png)
- 这就是一个反转脚的骨骼结构
- ![](初级/attachments/07-%20Leg%20Rigging%20And%20Reverse%20Foot-5.png)![](初级/attachments/07-%20Leg%20Rigging%20And%20Reverse%20Foot-6.png)
## 设置反转脚绑定

- 将反转脚骨骼作为IK脚控制器的子对象，使得IK脚控制器可以直接操控反转脚骨骼，再通过反转脚骨骼控制主骨骼。
-  ![](初级/attachments/07-%20Leg%20Rigging%20And%20Reverse%20Foot-8.png)
- 将腿部IK骨骼的所有IK效应器作为对应位置反转脚骨骼的子对象
- ![](初级/attachments/07-%20Leg%20Rigging%20And%20Reverse%20Foot-11.png)
- 这样，我们就用反转脚骨骼控制了主骨骼的脚部骨骼
- ![](初级/attachments/07-%20Leg%20Rigging%20And%20Reverse%20Foot-12.png)
- 原理：脚部控制器控制反转脚骨骼，反转脚骨骼控制IK效应器，IK效应器控制主骨骼
- 现在我么要打几个组用来控制脚部
	- 现在我们无法操控脚趾单独旋转，因为脚趾骨骼被IK控制了，我们需要脚趾有一个单独的控制。我们需要移动脚尖骨骼来达到类似脚趾旋转的效果
	- 我们给脚尖的IK效应器打组，并将轴心移动到脚趾骨骼的位置，这样我们旋转这个组就达到了旋转脚趾的效果
	- ![](初级/attachments/07-%20Leg%20Rigging%20And%20Reverse%20Foot-13.png)![|500](初级/attachments/07-%20Leg%20Rigging%20And%20Reverse%20Foot-14.png)
- 现在我们需要脚掌两侧的旋转轴心
	- 将反转脚骨骼的根骨骼heel_l_rev，打组两次并将轴心移动到脚掌两侧作为脚掌两侧的旋转轴心，这样旋转这两个组就会有旋转脚掌的感觉
	- ![](初级/attachments/07-%20Leg%20Rigging%20And%20Reverse%20Foot-16.png)![|300](初级/attachments/07-%20Leg%20Rigging%20And%20Reverse%20Foot-15.png)
	- 这样一个反转脚的基本装配就完成了，现在我们给控制器添加属性，来控制这些装配
## 设置属性
- 在脚部IK控制器上新增属性，属性均为浮点值
- ![](初级/attachments/07-%20Leg%20Rigging%20And%20Reverse%20Foot-17.png)
- 打开链接编辑器ConnectionEditor
- 链接 foot_l_ik_ctrl.HeelTwist 属性 >> heel_l_rev.RotateZ 属性（反转脚脚后跟骨骼），该属性用于脚掌沿脚后跟旋转
- 链接 foot_l_ik_ctrl.ToeTwist 属性 >> ball_l_rev_end.RotateZ 属性（反转脚脚尖骨骼），该属性用于脚掌沿脚尖旋转
- 链接 foot_l_ik_ctrl.ToeTap 属性 >> toe_l_tap_grp.RotateX 属性（反转脚脚尖IK打组），该属性用于单独控制脚尖旋转
- 我们是用NodeEditor来处理脚的Bank属性
- ![](初级/attachments/07-%20Leg%20Rigging%20And%20Reverse%20Foot-18.png)![](初级/attachments/07-%20Leg%20Rigging%20And%20Reverse%20Foot-19.png)
- 判断 foot_l_ik_ctrl.Bank 属性是否大于0
	- 如果大于0，则Bank 属性值赋予bank_l_outer的Z轴旋转
	- 如果小于0，则Bank 属性值赋予bank_l_iner的Z轴旋转
- 添加Roll属性，并使用驱动关键帧（也可以使用NodeEditor）
- ![](初级/attachments/07-%20Leg%20Rigging%20And%20Reverse%20Foot-20.png)
- 在Roll值为0的时候Key帧
- 在Roll值为-10，heel_l_rev.rotateX 值为40的时候Key帧
- ![](初级/attachments/07-%20Leg%20Rigging%20And%20Reverse%20Foot-21.png)
- 在Roll值为5，ball_l_rev.rotateX 值为-35的时候Key帧
- ![](初级/attachments/07-%20Leg%20Rigging%20And%20Reverse%20Foot-22.png)
- 在Roll值为10，ball_l_rev.rotateX 值为0，ball_l_rev_end.rotateX 值为-50的时候Key帧
- ![](初级/attachments/07-%20Leg%20Rigging%20And%20Reverse%20Foot-23.png)
- 这样脚部绑定 就完成了
