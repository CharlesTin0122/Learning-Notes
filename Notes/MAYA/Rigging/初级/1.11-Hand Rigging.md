# 手指关节绑定
- 为手指关节创建FK控制器,并父子约束骨骼
- 拇指末端两关节，其他手指末端三关节
- ![|500](初级/attachments/06-Hand%20Rigging-3.png)![](初级/attachments/06-Hand%20Rigging-1.png)
- 创建一个空组，命名hand_l_ctrl_grp，变换对齐到手掌骨骼，将手指控制器作为其子对象，且被手掌骨骼父子约束
- ![](初级/attachments/06-Hand%20Rigging-2.png)，其逻辑是：
	- 手部控制器（ik或fk）控制手掌骨骼（约束）
	- 手掌骨骼控制手指总控制器hand_l_ctrl_grp（约束）
	- 手指总控制器hand_l_ctrl_grp控制手指控制器（父子）
	- 手指控制器控制手指骨骼（约束）
- 最后整理大纲
- ![](初级/attachments/06-Hand%20Rigging-4.png)
# 手掌关节绑定
- 我们试图用手指根关节的控制器位移和旋转来控制手掌关节的旋转，即 index_01_l_ctrl 控制 index_metacarpal_l
	- 使用手指根关节的控制器X轴位移来控制手掌关节Z轴旋转
	- 使用手指根关节的控制器Z轴位移来控制手掌关节X轴旋转
	- 使用手指根关节的控制器Y轴旋转来控制手掌关节Y轴旋转
- ![](初级/attachments/06-Hand%20Rigging-5.png)
	- 我们在中间加一个乘除节点来缩放值，我们将控制器按轴向手动调整位置和旋转，来得到合适的乘除节点input2的值
	- ![](初级/attachments/06-Hand%20Rigging-6.png)![](初级/attachments/06-Hand%20Rigging-7.png)
- 我们将乘除节点的input2的值移动到IKFK控制器上，为控制器添加属性
- ![](初级/attachments/06-Hand%20Rigging-8.png)
- 并将其链接到节点
- ![](初级/attachments/06-Hand%20Rigging-9.png)
- 这样我么就可以通过控制器属性来控制手掌骨骼的偏移大小
- 其他手指按此制作，拇指因为跟其他手指轴向不同，需要单独制作属性
- ![|800](初级/attachments/06-Hand%20Rigging-10.png)

# 驱动关键帧
- 创建用于握拳的驱动关键帧
- 因为我们的控制器和偏移组都有自己的功能，因此我们在控制器之上偏移组之下再打一次组，用于驱动关键帧
- ![](初级/attachments/06-Hand%20Rigging-12.png)
- 对于其他手指，重复此操作
- 在手臂IKFK控制器添加浮点属性Fist握拳，值范围0:1
- ![](初级/attachments/06-Hand%20Rigging-13.png)
- 打开驱动关键帧编辑载入驱动和被驱动对象，创建驱动关键帧
- ![](初级/attachments/06-Hand%20Rigging-14.png)
