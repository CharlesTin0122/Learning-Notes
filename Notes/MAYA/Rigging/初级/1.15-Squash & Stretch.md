# 实现扭曲骨骼缩放
- 我们的目标是让扭曲骨骼的位置保持在骨骼的中间位置
- ![](attachments/10-Squash%20&%20Stretch-6.png)
- 使用骨骼之间的距离 / 2 来作为扭曲骨骼的Y轴位置以实现扭曲骨骼的位置保持在骨骼的中间位置
- 另外扭曲骨骼也需要Y轴的缩放值，跟其他IK骨骼一样
- 我们要在FK状态下禁用扭曲骨骼的Y轴缩放
![](attachments/10-Squash%20&%20Stretch-7.png)

- 在手臂IK控制上添加属性
	- Stretchiness，float(0:1)，是手臂缩放的总开关
	- Stretch_Type，Enum(None，Both，Stretch，----，Squash)，是手臂缩放模式
- ![](attachments/10-Squash%20&%20Stretch-9.png)
- 在节点编辑器中，实现缩放开关
- ![](attachments/10-Squash%20&%20Stretch-10.png)
- 在节点编辑器中实现手臂缩放模式，只要原理是更改条件节点（Condition）的Operation来实现
- ![](attachments/10-Squash%20&%20Stretch-11.png)
	- 如果Operation是Equal，不实现缩小和放大
	- 如果Operation是NotEqual，同时实现缩小和放大
	- 如果Operation是GreatThan，实现放大，不实现缩小
	- 如果Operation是LessThan，实现缩小，不实现放大
- 回到节点编辑器
- ![](attachments/10-Squash%20&%20Stretch-13.png)
	- 我们将控制器枚举属性Stretch_Type链接到条件节点（Condition）的Operation选项，使得枚举值和条件值一一对应
		- None -> Equal，不实现缩小和放大
		- Both -> NotEqual，同时实现缩小和放大
		- Stretch -> GreatThan，实现放大，不实现缩小
		- ---- -> Gtreater or Equal，效果跟GreatThan几乎相同，一般不使用
		- Squash -> LessThan，实现缩小，不实现放大
# 问题修正
- 当我们将手臂拉长，然后再切换IKFKSwitch到0.5的时候会发现，前臂扭曲骨骼脱离了前臂骨骼
- ![](attachments/10-Squash%20&%20Stretch-14.png)
- 做所以会发生这样的问题，是因为当前IKFKSwitch为0.5，主骨骼在FK和IK骨骼中间位置。但是我们的IK骨骼产生了拉伸，使得Twist骨骼发生了偏移。如果IK骨骼当前没有拉伸，那么骨骼位置就是这正确的。
- 当前节点，我们不解决这个问题。可以将IKFKSwitch的属性设为Int类型，规避IKFKSwitch的属性中间值。
# 实现肢体体积守恒
- 肢体体积守恒是一种体积补偿。就是肢体在拉伸的时候变细，或者缩短的时候变粗。实现一种卡通效果。我们通过缩放主骨骼的非主轴（YZ轴）向来实现。
- 具体原理是使肢体的动态长度和静态长度之间的比值进行幂计算，一般是比值的-0.5次幂。在将值连接至主骨骼的非主轴（YZ轴）

$$
x^{-0.5} = \frac{1}{x^{0.5}} = \frac{1}{\sqrt{x}}
$$
- #### 1. **为何是 -0.5 次幂？**

	体积是三维空间的乘积，如果你在一个方向上拉长 `scaleX = r`，为了体积恒定，需要满足：
	
	```
	scaleX * scaleY * scaleZ = constant
	```
	
	假设你只调整 Y 和 Z（主轴是 X），并且让 Y = Z，则：
	
	```
	scaleX = r
	scaleY = scaleZ = s
	r * s * s = 1  =>  s^2 = 1/r  =>  s = pow(r, -0.5)
	```
	
	这就解释了为什么是 `pow(ratio, -0.5)`。这样比值越大，肢体的横向缩放越小。
