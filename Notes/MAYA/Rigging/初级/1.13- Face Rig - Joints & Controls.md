# 绑定
## 嘴唇骨骼绑定原理
- 主要原理是用控制器位移控制嘴唇根骨骼旋转，使嘴唇的移动更加合理
- ![](初级/attachments/13-%20Face%20Rig%20-%20Joints%20&%20Controls-25.png)
- ![](初级/attachments/13-%20Face%20Rig%20-%20Joints%20&%20Controls-26.png)
- 这样可以实现控制器的位移控制根骨骼的旋转，但是角色的面部不是一个球形（唇尖更突出，唇角更后移），所以当控制器沿着X轴移动的时候我们希望骨骼沿着-Z轴缩短，这样可以使骨骼位移更贴合面部。
- ![](初级/attachments/1.13-%20Face%20Rig%20-%20Joints%20&%20Controls.png)

- 增加了一个locator用于在控制器和骨骼之间作为中间控制器，其原理是：
	- 控制器点约束locator
	- locator节点链接骨骼
	- 这样可以在众多嘴唇控制器层级之上再增加一个嘴部的总控制器，总控制器移动会带动嘴唇控制器移动，但是嘴唇控制器的位移数值不会改变无法驱动骨骼，但是增加的点约束的locator是有位移数值的，可以驱动骨骼运动
- ![](初级/attachments/1.13-%20Face%20Rig%20-%20Joints%20&%20Controls-1.png)
- 可使用脚本执行
```python
import pymel.core as pc

# 获取选的对象
objs = pc.selected()

jnt_ctrl = objs[0]
end_jnt = objs[1]
root_jnt = end_jnt.getParent()
# 创建控制器和骨骼之间的中间控制器用于嘴部总控制器有效
loc_between = pc.spaceLocator(name=f"{end_jnt.name()}_loc")
loc_between_grp = pc.group(loc_between, name=f"{end_jnt.name()}_loc_offset")
pc.matchTransform(loc_between_grp, end_jnt, position=True, rotation=True)
pc.pointConstraint(jnt_ctrl, loc_between)
# 处理根骨骼旋转
orient_mult_node = pc.createNode("multiplyDivide", name=f"{end_jnt.name()}_orient_mult")
orient_reverse_node = pc.createNode(
    "multiplyDivide", name=f"{end_jnt.name()}_orient_reverse"
)
orient_reverse_node.input2X.set(-1)
orient_reverse_node.outputX.connect(orient_mult_node.input2Y, force=1)
# 设置和链接属性
loc_between.translate.connect(orient_mult_node.input1, force=1)
orient_mult_node.outputX.connect(root_jnt.rotateY, force=1)
orient_mult_node.outputY.connect(root_jnt.rotateX, force=1)
# 处理末端骨骼位移

# 创建节点
gradient_mult_node = pc.createNode(
    "multiplyDivide", name=f"{end_jnt.name()}_gradient_mult"
)
trans_mult_node = pc.createNode("multiplyDivide", name=f"{end_jnt.name()}_trans_mult")
offset_pma_node = pc.createNode("plusMinusAverage", name=f"{end_jnt.name()}_offset_pma")
offset_pma_node.operation.set(2)
invert_reverse_node = pc.createNode(
    "multiplyDivide", name=f"{end_jnt.name()}_invert_reverse"
)
# 链接节点
loc_between.translateX.connect(gradient_mult_node.input1X, force=1)


loc_between.translateX.connect(trans_mult_node.input1X, force=1)
gradient_mult_node.outputX.connect(trans_mult_node.input2X, force=1)

trans_mult_node.outputX.connect(offset_pma_node.input1D[0], force=1)
offset_pma_node.input1D[1].set(end_jnt.translateZ.get())

offset_pma_node.output1D.connect(invert_reverse_node.input1X, force=1)
invert_reverse_node.input2X.set(-1)

invert_reverse_node.outputX.connect(end_jnt.translateZ, force=1)

# 为控制器添加属性
pc.addAttr(
    jnt_ctrl, longName="Gradient", attributeType="float", defaultValue=1, keyable=True
)
pc.addAttr(
    jnt_ctrl,
    longName="Offset",
    attributeType="float",
    defaultValue=end_jnt.translateZ.get(),
    keyable=True,
)
pc.addAttr(
    jnt_ctrl, longName="Movement", attributeType="float", defaultValue=1, keyable=True
)
# 链接控制器属性
pc.connectAttr((jnt_ctrl + ".Gradient"), (gradient_mult_node.input2X), force=1)
pc.connectAttr((jnt_ctrl + ".Offset"), (offset_pma_node.input1D[1]), force=1)
pc.connectAttr((jnt_ctrl + ".Movement"), (orient_mult_node.input2X), force=1)
pc.connectAttr((jnt_ctrl + ".Movement"), (orient_reverse_node.input1X), force=1)

```
## 嘴唇绑定

- 创建一个嘴部总控制器mouth_ctrl，放置在head_ctrl层级之下
- ![](初级/attachments/13-%20Face%20Rig%20-%20Joints%20&%20Controls-29.png)
- 将嘴唇控制器作为mouth_ctrl的子对象
- ![](初级/attachments/13-%20Face%20Rig%20-%20Joints%20&%20Controls-30.png)
- 此时下巴控制器无法再控制下嘴唇骨骼，所以在mouth层级之下创建一个组lower_lips_ctrls_offste，该组的变换为下巴骨骼（jaw）的变换，并将所有下嘴唇控制器放入其层级之下，使用下巴控制器给该组一个旋转约束
