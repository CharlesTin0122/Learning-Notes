# Bug
- 当根控制器Y轴旋转接近90度时，脊椎骨骼会发生扭曲现象
- ![](初级/attachments/2.08-%20Root%20Control%20Support-2.png)
- 这是因为脊椎的扭曲受到脊椎控制骨骼影响（SplineIK的Roll和Twist），而脊椎控制骨骼受到脊椎IK控制器的约束。当根控制器Y轴旋转时，脊椎控制器上不会有数值，因为他们之间的父子关系，而控制骨骼上会产生旋转数值，因为他是约束关系（受到控制器的父子约束）。
- 因此我们使用控制器来控制IKHandle的Roll和Twist，而不是控制骨骼。
- ![](初级/attachments/2.08-%20Root%20Control%20Support-5.png)
- 此时问题解决了，但是当我们旋转根控制器的Y轴接近180度时又会发生翻转
- ![](初级/attachments/2.08-%20Root%20Control%20Support-6.png)
- 让我们打开脊椎IKHandle的属性面板，勾选EnableTwistControl
- ![|500](初级/attachments/2.08-%20Root%20Control%20Support-7.png)
- 问题解决了，世界向上类型为场景向上，向前轴向为+X轴，向上轴向为+Y轴
- 当我们旋转根骨骼Z轴时，脊椎骨骼又发生了扭曲现象
- ![|800](初级/attachments/2.08-%20Root%20Control%20Support-8.png)
- 我们更新脊椎IKHandle的属性面板
- ![](初级/attachments/2.08-%20Root%20Control%20Support-9.png)
- 使世界向上类型为对象旋转向上，而世界向上对象设置为local_ctrl即根控制器。向上向量为Y轴
