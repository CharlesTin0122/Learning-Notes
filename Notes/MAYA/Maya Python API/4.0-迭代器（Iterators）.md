在Maya Python API 1.0中，迭代器（Iterators）是用于遍历复杂数据结构（如场景中的节点、属性或几何数据）的工具，提供了高效、便捷的方式来访问和操作Maya场景中的对象。Maya Python API 1.0（基于`OpenMaya`模块）中的迭代器主要用于处理DAG（有向无环图）节点、依赖图（Dependency Graph）节点、网格几何数据等。以下是对Maya Python API 1.0中常见迭代器的介绍及其用法：

---

### 1. **主要迭代器类型**
Maya Python API 1.0 提供了以下几种常用的迭代器，位于`OpenMaya`模块中：

- **`MItDag`**：用于遍历DAG（有向无环图）中的节点，例如场景中的变换节点、形状节点等。
- **`MItDependencyNodes`**：用于遍历依赖图中的所有节点（如材质、纹理、灯光等）。
- **`MItDependencyGraph`**：用于遍历依赖图中与特定节点或属性相关的节点（支持上游/下游遍历）。
- **`MItMeshVertex`**：用于遍历网格（Mesh）上的顶点。
- **`MItMeshEdge`**：用于遍历网格上的边。
- **`MItMeshPolygon`**：用于遍历网格上的多边形面。
- **`MItMeshFaceVertex`**：用于遍历网格上每个面上的顶点。
- **`MItSelectionList`**：用于遍历当前选择列表中的对象。

这些迭代器允许开发者以编程方式访问和操作Maya场景中的复杂数据结构。

---

### 2. **迭代器的工作原理**
迭代器通常通过以下步骤使用：
1. **初始化迭代器**：为特定对象或数据结构创建迭代器实例。
2. **遍历数据**：使用`isDone()`检查是否到达数据末尾，并通过`next()`移动到下一个元素。
3. **获取数据**：通过迭代器提供的方法（如`node()`、`item()`等）获取当前元素的数据。
4. **操作数据**：根据需要对当前元素执行操作。

---

### 3. **常用迭代器的用法和示例**

#### **3.1 MItDag：遍历DAG节点**
`MItDag`用于遍历场景中的DAG节点，可以按深度优先或广度优先方式遍历。

**示例：列出场景中所有变换节点**
```python
import maya.OpenMaya as om

# 创建DAG迭代器，遍历所有变换节点
dag_iterator = om.MItDag(om.MItDag.kDepthFirst, om.MFn.kTransform)

while not dag_iterator.isDone():
    # 获取当前节点的MObject
    dag_node = dag_iterator.currentItem()
    # 获取节点名称
    fn_dag = om.MFnDagNode(dag_node)
    print(fn_dag.fullPathName())
    # 移动到下一个节点
    dag_iterator.next()
```

**说明**：
- `kDepthFirst`：深度优先遍历。
- `kBreadthFirst`：广度优先遍历。
- `om.MFn.kTransform`：只遍历变换节点，可以替换为其他类型（如`kMesh`）。

---

#### **3.2 MItDependencyNodes：遍历所有依赖节点**
`MItDependencyNodes`用于遍历场景中所有的依赖节点（如材质、灯光、动画曲线等）。

**示例：列出场景中所有材质**
```python
import maya.OpenMaya as om

# 创建依赖节点迭代器，遍历所有材质
dep_iterator = om.MItDependencyNodes(om.MFn.kLambert)

while not dep_iterator.isDone():
    node = dep_iterator.thisNode()
    fn_dep = om.MFnDependencyNode(node)
    print(fn_dep.name())
    dep_iterator.next()
```

**说明**：
- `om.MFn.kLambert`：只遍历Lambert材质，可以替换为其他类型（如`kCamera`、`kLight`）。
- `thisNode()`：获取当前节点的`MObject`。

---

#### **3.3 MItDependencyGraph：遍历节点的连接**
`MItDependencyGraph`用于遍历与某个节点或属性相关的节点（如上游或下游的连接）。

**示例：查找某个节点的所有输入连接**
```python
import maya.OpenMaya as om

# 获取选中的节点
sel_list = om.MSelectionList()
om.MGlobal.getActiveSelectionList(sel_list)
node = om.MObject()
sel_list.getDependNode(0, node)

# 创建依赖图迭代器，遍历上游节点
dg_iterator = om.MItDependencyGraph(
    node,
    om.MFn.kInvalid,  # 遍历所有类型的节点
    om.MItDependencyGraph.kUpstream  # 上游方向
)

while not dg_iterator.isDone():
    current_node = dg_iterator.currentItem()
    fn_dep = om.MFnDependencyNode(current_node)
    print(fn_dep.name())
    dg_iterator.next()
```

**说明**：
- `kUpstream`：遍历输入连接。
- `kDownstream`：遍历输出连接。
- 可以指定特定节点类型（如`kShader`）来过滤遍历结果。

---

#### **3.4 MItMeshVertex：遍历网格顶点**
`MItMeshVertex`用于遍历网格对象的顶点。

**示例：打印选定网格的所有顶点位置**
```python
import maya.OpenMaya as om

# 获取选中的网格
sel_list = om.MSelectionList()
om.MGlobal.getActiveSelectionList(sel_list)
dag_path = om.MDagPath()
sel_list.getDagPath(0, dag_path)

# 创建顶点迭代器
vertex_iterator = om.MItMeshVertex(dag_path)

while not vertex_iterator.isDone():
    point = vertex_iterator.position(om.MSpace.kWorld)  # 获取世界空间坐标
    print(f"Vertex {vertex_iterator.index()}: {point.x}, {point.y}, {point.z}")
    vertex_iterator.next()
```

**说明**：
- `position()`：获取顶点的世界或对象空间坐标。
- `index()`：获取当前顶点的索引。

---

# 案例
```python
import maya.OpenMaya as om


"""
# 创建MItDag迭代器
# 第一个参数：遍历方式
# om.MItDag.kDepthFirst：深度优先遍历
# om.MItDag.kBreadthFirst: 广度优先遍历
# 第二个参数：过滤类型。
# 如果不想提供过滤类型可使用om.MFn.kInvalid
# "k"前缀表示常量或枚举，用于标记固定的、不可更改的枚举值或类型标识符
"""
dagIterator = om.MItDag(om.MItDag.kDepthFirst, om.MFn.kTransform)
# 创建MFnDagNode,用于处理遍历到的数据
dagNodeFn = om.MFnDagNode()
# 遍历场景
while not dagIterator.isDone():
    # 获取当前遍历到的对象的MObject
    curObj = dagIterator.currentItem()
    # 获取当前遍历到的对象深度
    depth = dagIterator.depth()
    # 将遍历到的MObject写入MFnDagNode
    dagNodeFn.setObject(curObj)
    # 获取当前遍历到的对象的信息
    name = dagNodeFn.name()
    type = curObj.apiTypeStr()
    path = dagNodeFn.fullPathName()

    printOut = ""
    for i in range(0, depth):
        printOut += "------>"
    printOut += f"Name: {name}, Type: {type}, Path: {path}"
    print(printOut)

    dagIterator.next()
```
