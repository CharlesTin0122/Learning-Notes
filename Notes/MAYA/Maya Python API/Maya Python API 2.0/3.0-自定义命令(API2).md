# MPxCommand
在 Autodesk Maya 的 Python API 2.0 中，`MPxCommand` 是一个用于创建自定义命令的基类，允许开发者通过 Python 定义可在 Maya 中执行的命令。它是 `OpenMaya` 模块的一部分，位于 `OpenMaya.MPxCommand`，提供了与 C++ API 中 `MPxCommand` 类似的功能，适合扩展 Maya 的功能或自动化任务。

### 主要特点
1. **自定义命令**：`MPxCommand` 允许开发者创建可在 Maya 的命令行、MEL 脚本或 Python 脚本中调用的自定义命令。
2. **Python 与 C++ 的桥接**：它是 C++ `MPxCommand` 类的 Python 绑定，提供了与 Maya 核心交互的能力。
3. **命令模式支持**：支持 `doIt`、`undoIt` 和 `redoIt` 方法，用于实现命令的执行、撤销和重做功能。
4. **语法支持**：可以通过 `MSyntax` 定义命令的标志和参数，支持复杂的命令行输入。

### 核心方法
以下是 `MPxCommand` 类的关键方法，开发者需要重写这些方法来实现自定义逻辑：

1. **doIt(argList: OpenMaya.MArgList)**  
   - 这是命令执行的入口点，接收用户传入的参数（`MArgList`）。
   - 通常用于解析参数并执行命令的主要逻辑。
   - 如果命令支持撤销，`doIt` 应准备必要的数据并调用其他方法来完成实际工作。

2. **undoIt()**  
   - 定义命令的撤销逻辑。
   - 如果命令修改了 Maya 场景（如创建节点或更改属性），此方法应恢复场景到命令执行前的状态。

3. **redoIt()**  
   - 定义命令的重做逻辑。
   - 在撤销后重新执行命令时调用，通常恢复 `doIt` 中执行的操作。

4. **isUndoable()**  
   - 返回一个布尔值，指示命令是否支持撤销。
   - 默认返回 `False`，需要重写为 `True` 以启用撤销功能。

5. **hasSyntax()**  
   - 返回一个布尔值，指示命令是否定义了自定义语法（通过 `MSyntax`）。
   - 如果使用 `MSyntax` 定义了标志或参数，应返回 `True`。

6. **syntax()**  
   - 返回一个 `OpenMaya.MSyntax` 对象，用于定义命令的标志和参数。
   - 通过重写此方法，可以为命令设置复杂的输入规则。

### 使用步骤
1. **创建自定义命令类**  
   继承 `OpenMaya.MPxCommand`，并实现必要的虚函数（如 `doIt`、`undoIt`、`redoIt`）。

2. **定义命令语法（可选）**  
   使用 `OpenMaya.MSyntax` 和 `OpenMaya.MArgParser` 定义命令的标志和参数。

3. **注册命令**  
   使用 `OpenMaya.MFnPlugin.registerCommand` 在插件初始化时将命令注册到 Maya。

4. **注销命令**  
   在插件卸载时，使用 `OpenMaya.MFnPlugin.deregisterCommand` 注销命令。

### 示例代码
以下是一个简单的自定义命令示例，创建一个空变换节点并支持撤销/重做：

```python
import maya.OpenMaya as OpenMaya

class CreateEmptyNodeCmd(OpenMaya.MPxCommand):
    kCommandName = "createEmptyNode"

    def __init__(self):
        super(CreateEmptyNodeCmd, self).__init__()
        self.node = None

    def doIt(self, argList):
        # 创建一个空的变换节点
        dagMod = OpenMaya.MDagModifier()
        self.node = dagMod.createNode("transform")
        dagMod.doIt()
        self.setResult(self.node.partialPathName())

    def undoIt(self):
        # 删除创建的节点
        if self.node is not None:
            dagMod = OpenMaya.MDagModifier()
            dagMod.deleteNode(self.node)
            dagMod.doIt()

    def redoIt(self):
        # 重新创建节点
        dagMod = OpenMaya.MDagModifier()
        self.node = dagMod.createNode("transform")
        dagMod.doIt()

    def isUndoable(self):
        return True

def cmdCreator():
    return OpenMaya.MPxCommand(CreateEmptyNodeCmd())

def initializePlugin(mobject):
    mplugin = OpenMaya.MFnPlugin(mobject)
    try:
        mplugin.registerCommand(CreateEmptyNodeCmd.kCommandName, cmdCreator)
    except:
        OpenMaya.MGlobal.displayError("Failed to register command: %s" % CreateEmptyNodeCmd.kCommandName)

def uninitializePlugin(mobject):
    mplugin = OpenMaya.MFnPlugin(mobject)
    try:
        mplugin.deregisterCommand(CreateEmptyNodeCmd.kCommandName)
    except:
        OpenMaya.MGlobal.displayError("Failed to deregister command: %s" % CreateEmptyNodeCmd.kCommandName)
```

### 如何使用
1. 将上述代码保存为 Python 文件（例如 `createEmptyNode.py`）。
2. 在 Maya 中加载插件：
   ```python
   import maya.cmds as cmds
   cmds.loadPlugin("createEmptyNode.py")
   ```
3. 执行命令：
   ```python
   cmds.createEmptyNode()
   ```
4. 撤销命令：
   ```python
   cmds.undo()
   ```

### 注意事项
- **性能**：确保 `doIt`、`undoIt` 和 `redoIt` 的操作高效，避免不必要的复杂计算。
- **错误处理**：在 `doIt` 中使用 `MArgParser` 解析参数时，需妥善处理无效输入。
- **线程安全**：Maya 的 Python API 通常在主线程中运行，避免在命令中引入多线程操作。
- **兼容性**：Maya Python API 2.0 与 C++ API 高度一致，但某些高级功能可能需要结合 MEL 或 C++ 实现。

### 高级用法
- **添加标志**：通过 `MSyntax` 定义命令标志，例如 `-name` 或 `-position`，以支持更复杂的输入。
  ```python
  def syntax(self):
      syntax = OpenMaya.MSyntax()
      syntax.addFlag("-n", "-name", OpenMaya.MSyntax.kString)
      return syntax
  ```
- **查询模式**：通过 `MSyntax.enableQuery(True)` 支持查询模式，允许命令返回信息而不修改场景。
- **错误反馈**：使用 `OpenMaya.MGlobal.displayError` 或 `OpenMaya.MGlobal.displayWarning` 向用户反馈信息。

## 简单命令
```python
import maya.api.OpenMaya as om
import pymel.core as pm


def maya_useNewAPI():
    """告诉maya调用的是maya Python API 2.0"""
    pass


class SimpleCmd(om.MPxCommand):
    """插件类
    命令：
    pm.SimpleCmd(v=True)
    # Result: ['1.0.0']

    pm.SimpleCmd(s=35)
    # Size: 35

    pm.SimpleCmd("Charles", "Tian")
    # Hello Charles Tian

    pm.SimpleCmd(t = ("Charles", "Tian"))
    # Hello Charles Tian
    """

    COMMAND_NAME = "SimpleCmd"  # 命令名称常量

    VERSION_FLAG = ["-v", "-version"]
    SIZE_FLAG = ["-s", "-size"]
    TEXT_FLAG = ["-t", "-text"]

    def __init__(self):
        """构造函数"""
        super().__init__()
        self.undoable = False

    def doIt(self, argList):
        """插件执行逻辑"""
        try:
            # 通过MArgDatabase解析输入参数，将输入参数与命令语法对比
            arg_db = om.MArgDatabase(self.syntax(), argList)
        except Exception as e:
            self.displayError(f"Failed to parsing arguments: {e}")
            raise
        # 判断标志是否设立
        version_flag_enabled = arg_db.isFlagSet(
            SimpleCmd.VERSION_FLAG[0]
        ) or arg_db.isFlagSet(SimpleCmd.VERSION_FLAG[1])

        size_flag_enabled = arg_db.isFlagSet(
            SimpleCmd.SIZE_FLAG[0]
        ) or arg_db.isFlagSet(SimpleCmd.SIZE_FLAG[1])

        text_flag_enabled = arg_db.isFlagSet(
            SimpleCmd.TEXT_FLAG[0]
        ) or arg_db.isFlagSet(SimpleCmd.TEXT_FLAG[1])

        # version flag
        if version_flag_enabled:
            # version参数设置命令返回值（v=True）
            self.setResult("1.0.0")
        # size flag
        elif size_flag_enabled:
            # size 参数(s = 35)
            size = 0
            if arg_db.isFlagSet(SimpleCmd.SIZE_FLAG[0]):
                # 从MArgDatabase获取字符串参数
                size = arg_db.flagArgumentInt(SimpleCmd.SIZE_FLAG[0], 0)
            # 输出字符串
            self.displayInfo(f"Size: {size}")
        # text flag
        elif text_flag_enabled:
            first_text = arg_db.commandArgumentString(SimpleCmd.TEXT_FLAG[0], 0)
            last_text = arg_db.commandArgumentString(SimpleCmd.TEXT_FLAG[0], 1)
            # 输出字符串
            self.displayInfo(f"Hello {first_text} {last_text}")
        # command object
        else:
            # 输出命令对象拼接
            try:
                first_name = arg_db.commandArgumentString(0)
                last_name = arg_db.commandArgumentString(1)
            except Exception:  # 防止未输入任何参数报错
                first_name = "Simple"
                last_name = "Cmd"

            # 输出字符串
            self.displayInfo(f"Hello {first_name} {last_name}")

    def isUndoable(self):
        """是否可撤销"""
        return self.undoable

    def undoIt(self):
        """撤销"""

    def redoIt(self):
        """重做"""

    @classmethod
    def creator(cls):
        """返回类的实例"""
        return cls()

    @classmethod
    def create_syntax(cls):
        """创建参数语法"""
        syntax = om.MSyntax()
        # 添加标志
        syntax.addFlag(cls.VERSION_FLAG[0], cls.VERSION_FLAG[1])
        syntax.addFlag(cls.SIZE_FLAG[0], cls.SIZE_FLAG[1], (om.MSyntax.kDouble))
        # 标志参数为元祖（x，y）
        syntax.addFlag(
            cls.TEXT_FLAG[0], cls.TEXT_FLAG[1], (om.MSyntax.kString, om.MSyntax.kString)
        )
        # 添加命令对象：mc.polyCube("myCube", q=True, sx=True)，"myCube"是一个命令对象
        syntax.addArg(om.MSyntax.kString)
        syntax.addArg(om.MSyntax.kString)
        return syntax


def initializePlugin(plugin):
    """加载插件并注册命令"""
    vendor = "Charles Tian"
    version = "1.0.0"
    plugin_fn = om.MFnPlugin(plugin, vendor, version)
    try:
        plugin_fn.registerCommand(
            SimpleCmd.COMMAND_NAME, SimpleCmd.creator, SimpleCmd.create_syntax
        )
    except Exception as e:
        om.MGlobal.displayError(
            f"Failed to register command {SimpleCmd.COMMAND_NAME}:{e}"
        )


def uninitializePlugin(plugin):
    """卸载插件，并取消注册命令"""
    plugin_fn = om.MFnPlugin(plugin)
    try:
        plugin_fn.deregisterCommand(SimpleCmd.COMMAND_NAME)
    except Exception as e:
        om.MGlobal.displayError(
            f"Failed to deregister command {SimpleCmd.COMMAND_NAME}:{e}"
        )


if __name__ == "__mian__":
    pm.newFile(force=True)

    plugin_name = "simple_cmd"

    pm.unloadPlugin(plugin_name)

    pm.loadPlugin(plugin_name)

    pm.SimpleCmd()

```

```python
import pymel.core as pm


def maya_useNewAPI():
    """告诉maya调用的是maya Python API 2.0"""
    pass


class SimpleCmd(om.MPxCommand):
    """插件类
    命令：
    pm.SimpleCmd("pCube1")
    // Result: pCube1 polyCube1
    """

    COMMAND_NAME = "SimpleCmd"  # 命令名称常量

    VERSION_FLAG = ["-v", "-version"]

    def __init__(self):
        """构造函数"""
        super().__init__()
        self.undoable = False

    def doIt(self, argList):
        """插件执行逻辑"""
        try:
            # 通过MArgDatabase解析输入参数，将输入参数与命令语法对比
            arg_db = om.MArgDatabase(self.syntax(), argList)
        except Exception as e:
            self.displayError(f"Failed to parsing arguments: {e}")
            raise
        # 判断标志是否设立
        version_flag_enabled = arg_db.isFlagSet(
            SimpleCmd.VERSION_FLAG[0]
        ) or arg_db.isFlagSet(SimpleCmd.VERSION_FLAG[1])

        # version flag
        if version_flag_enabled:
            # version参数设置命令返回值（v=True）
            self.setResult("1.0.0")
        # selection list arguments
        else:
            # 获取选择列表
            selection_list = arg_db.getObjectList()
            # 遍历选择列表并打印选择对象名称
            for i in range(selection_list.length()):
                depand_fn = om.MFnDependencyNode(selection_list.getDependNode(i))
                print(depand_fn.name())

    def isUndoable(self):
        """是否可撤销"""
        return self.undoable

    def undoIt(self):
        """撤销"""

    def redoIt(self):
        """重做"""

    @classmethod
    def creator(cls):
        """返回类的实例"""
        return cls()

    @classmethod
    def create_syntax(cls):
        """创建参数语法"""
        syntax = om.MSyntax()
        # 选择列表作为参数，可使用场景内的对象名称作为参数 pm.SimpleCmd("pCube1")
        # 参数1：选择列表，参数2：场景内选择的最小数量，参数3：场景内选择的最大数量
        syntax.setObjectType(om.MSyntax.kSelectionList, 0, 2)
        # 使用maya场景内的选择列表作为默认参数, pm.SimpleCmd()
        syntax.useSelectionAsDefault(True)
        return syntax

    version = "1.0.0"
    plugin_fn = om.MFnPlugin(plugin, vendor, version)
```

## 查询和编辑
```python
import maya.api.OpenMaya as om


def maya_useNewAPI():
    """告诉maya调用的是maya Python API 2.0"""
    pass


class SimpleCmd(om.MPxCommand):
    """
    A simple Maya command to query or edit transform nodes.

    Usage:
        pm.SimpleCmd()  # Returns the name of the selected transform node
        pm.SimpleCmd(v=True) # Returns the command version
        pm.SimpleCmd(q=True, t=True) # Queries the translation of the selected node
        pm.SimpleCmd(e=True, t=(1.0, 2.0, 3.0))) # Sets the translation of the selected node
    """

    # 命令名称常量
    COMMAND_NAME = "SimpleCmd"
    # 命令标志常量
    VERSION_FLAG = ["-v", "-version"]
    TRANSLATE_FLAG = [
        "-t",
        "-translate",
        (om.MSyntax.kDouble, om.MSyntax.kDouble, om.MSyntax.kDouble),
    ]

    def __init__(self):
        """构造函数"""
        super().__init__()
        self.undoable = False
        self.selected_obj = None
        self.original_translation = None
        self.new_translation = None

    def doIt(self, argList):
        """插件执行逻辑，命令执行时执行一次，获取逻辑所需变量，然后执行 redoIt()"""
        try:
            # 通过MArgDatabase解析输入参数，将输入参数与命令语法对比
            arg_db = om.MArgDatabase(self.syntax(), argList)
        except Exception as e:
            self.displayError(f"Failed to parse arguments: {e}")
            raise

        # 【优化】获取选择列表，并增加长度检查以提供更友好的错误提示
        selection_list = arg_db.getObjectList()
        if selection_list.length() == 0:
            self.displayError("No object selected. Please select a transform node.")
            return  # 提前返回，避免后续代码出错

        self.selected_obj = selection_list.getDependNode(0)

        # 如果对象的类型不是kTransform，则抛出异常
        if not self.selected_obj.hasFn(om.MFn.kTransform):
            raise RuntimeError("This command requires a transform node.")

        # 是否是编辑
        self.edit = arg_db.isEdit
        # 是否是查询
        self.query = arg_db.isQuery
        # 是否设置translate标志
        self.translate = arg_db.isFlagSet(SimpleCmd.TRANSLATE_FLAG[0])

        if self.translate:
            transform_fn = om.MFnTransform(self.selected_obj)
            self.original_translation = transform_fn.translation(om.MSpace.kTransform)

            # 如果设置了编辑标志，则通过参数获取新的translation
            if self.edit:
                self.new_translation = [
                    arg_db.flagArgumentDouble(SimpleCmd.TRANSLATE_FLAG[0], 0),
                    arg_db.flagArgumentDouble(SimpleCmd.TRANSLATE_FLAG[0], 1),
                    arg_db.flagArgumentDouble(SimpleCmd.TRANSLATE_FLAG[0], 2),
                ]
                # 设置可撤销为真
                self.undoable = True

        # 是否设置了version标志
        self.version = arg_db.isFlagSet(SimpleCmd.VERSION_FLAG[0])

        # 调用redoIt方法
        self.redoIt()

    def isUndoable(self):
        """是否可撤销"""
        return self.undoable

    def undoIt(self):
        """撤销"""
        # 获取 MFnTransform 实例
        transform_fn = om.MFnTransform(self.selected_obj)
        # 将对象位置设置为初始位置
        # 【优化】使用 * 解包元组，代码更明确
        transform_fn.setTranslation(
            om.MVector(*self.original_translation), om.MSpace.kTransform
        )

    def redoIt(self):
        """重做，主要命令逻辑实现"""
        transform_fn = om.MFnTransform(self.selected_obj)

        if self.query:
            if self.translate:
                # 【优化】查询时返回元组，与 Maya 原生命令行为更一致
                self.setResult(tuple(self.original_translation))
            else:
                raise RuntimeError("Flag does not support query")
        elif self.edit:
            if self.translate:
                # 【优化】使用 * 解包列表，代码更明确
                transform_fn.setTranslation(
                    om.MVector(*self.new_translation), om.MSpace.kTransform
                )
            else:
                raise RuntimeError("Flag does not support edit")
        elif self.version:
            self.setResult("1.0.0")
        else:
            # 默认行为：返回对象名称
            self.setResult(transform_fn.name())

    @classmethod
    def creator(cls):
        """返回类的实例"""
        return cls()

    @classmethod
    def create_syntax(cls):
        """创建参数语法"""
        syntax = om.MSyntax()
        syntax.enableQuery = True
        syntax.enableEdit = True

        syntax.addFlag(*cls.VERSION_FLAG)
        syntax.addFlag(*cls.TRANSLATE_FLAG)

        # 设置对象类型为选择列表，最小长度为1，最大长度为1
        # 注意：这里设置了最小为1，但 doIt 中的检查是更保险的做法
        syntax.setObjectType(om.MSyntax.kSelectionList, 1, 1)
        # 将当前选择作为命令的默认对象
        syntax.useSelectionAsDefault(True)

        return syntax


def initializePlugin(plugin):
    """加载插件并注册命令"""
    vendor = "Charles Tian"
    version = "1.0.0"
    plugin_fn = om.MFnPlugin(plugin, vendor, version)
    try:
        plugin_fn.registerCommand(
            SimpleCmd.COMMAND_NAME, SimpleCmd.creator, SimpleCmd.create_syntax
        )
    except Exception as e:
        om.MGlobal.displayError(
            f"Failed to register command {SimpleCmd.COMMAND_NAME}: {e}"
        )


def uninitializePlugin(plugin):
    """卸载插件，并取消注册命令"""
    plugin_fn = om.MFnPlugin(plugin)
    try:
        plugin_fn.deregisterCommand(SimpleCmd.COMMAND_NAME)
    except Exception as e:
        om.MGlobal.displayError(
            f"Failed to deregister command {SimpleCmd.COMMAND_NAME}: {e}"
        )
```
