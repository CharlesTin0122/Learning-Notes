- 节点解释
	- pCubeShape1Orig 节点：是一个隐藏的中间形状节点shape节点，用于储存模型在蒙皮前的初始几何形状。
	- bindPose1 节点：bindPose 节点（DAG 姿势节点），记录了骨骼（joint1）在绑定蒙皮时的初始姿势（Bind Pose）。
	- skinCluster1 节点：skinCluster 节点（变形器节点），是蒙皮系统的核心节点，负责计算模型顶点在骨骼驱动下的变形。存储了模型顶点与骨骼之间的权重信息（Skin Weights），以及影响每个顶点的骨骼列表。
## 权重的组织方式
- 权重数组的组织方式是：每个顶点的权重按影响对象顺序连续排列。例如，对于顶点 0，权重是 `[w0_j0, w0_j1, ...]`；顶点 1 是` [w1_j0, w1_j1, ...]`。其中w代表点权重，j代表影响对象（骨骼）
- 在一个模型的蒙皮信息中有 numInfluences个影响对象，获取第j个骨骼的第i个点的权重为：
```
  j * numInfluences + i
```
