在 Autodesk Maya 的 Python API 2.0 中，`MAnimCurve` 是 `OpenMayaAnim` 模块中的一个类，用于表示和操作 Maya 场景中的动画曲线（Animation Curve）。它提供了对动画曲线的低级别访问，允许开发者以编程方式查询和修改动画曲线的关键帧、切线、权重等属性。以下是对 `MAnimCurve` 的详细介绍，涵盖其功能、方法和使用场景。

---

### 1. **概述**
`MAnimCurve` 是 Maya Python API 2.0 中用于表示动画曲线节点的类，属于 `OpenMayaAnim` 模块。动画曲线是 Maya 中存储动画数据的核心组件，用于描述对象属性（如平移、旋转、缩放等）随时间变化的曲线。`MAnimCurve` 提供了对这些曲线的精确控制，适合需要复杂动画操作的开发任务。

与 `maya.cmds` 提供的命令（如 `setKeyframe` 或 `keyframe`）相比，`MAnimCurve` 是更底层的接口，性能更高，但使用起来需要更多的代码来处理节点和数据。

---

### 2. **主要功能**
`MAnimCurve` 提供了丰富的接口来操作动画曲线的关键帧、切线和属性。以下是其核心功能和方法的分类说明：

#### **初始化和访问**
要使用 `MAnimCurve`，需要通过一个有效的 `MObject`（表示动画曲线节点）来初始化。例如：
```python
from maya import OpenMaya, OpenMayaAnim

# 获取动画曲线节点的 MObject
sel_list = OpenMaya.MSelectionList()
sel_list.add("myCurve")  # 假设场景中有一个名为 myCurve 的动画曲线
mobj = OpenMaya.MObject()
sel_list.getDependNode(0, mobj)

# 初始化 MAnimCurve
anim_curve = OpenMayaAnim.MAnimCurve(mobj)
```

#### **关键帧操作**
`MAnimCurve` 提供了多种方法来查询和修改关键帧：
- **`numKeys()`**: 返回动画曲线的关键帧数量。
  ```python
  num_keys = anim_curve.numKeys()
  print(f"Number of keyframes: {num_keys}")
  ```
- **`time(index)`**: 获取指定关键帧的时间，返回一个 `MTime` 对象。
- **`value(index)`**: 获取指定关键帧的值（浮点数）。
  ```python
  for i in range(anim_curve.numKeys()):
      time = anim_curve.time(i).value()  # 获取时间（以帧为单位）
      value = anim_curve.value(i)
      print(f"Keyframe {i}: Time = {time}, Value = {value}")
  ```
- **`setTime(index, time)`**: 设置指定关键帧的时间（需要 `MTime` 对象）。
- **`setValue(index, value)`**: 设置指定关键帧的值。
- **`addKey(time, value, tangentInType, tangentOutType, change=None)`**: 添加一个新的关键帧。
  ```python
  anim_curve.addKey(OpenMaya.MTime(10.0), 5.0, 
                    OpenMayaAnim.MAnimCurve.kTangentLinear, 
                    OpenMayaAnim.MAnimCurve.kTangentLinear)
  ```
- **`remove(index, change=None)`**: 删除指定索引的关键帧。

#### **切线控制**
切线决定了关键帧之间的插值方式，`MAnimCurve` 提供了以下方法来管理切线：
- **`inTangentType(index)`** 和 **`outTangentType(index)`**: 获取指定关键帧的输入或输出切线类型。
- **`setInTangentType(index, tangentType)`** 和 **`setOutTangentType(index, tangentType)`**: 设置切线类型。
  - 常见的切线类型包括：
    - `kTangentLinear`: 线性插值。
    - `kTangentSmooth`: 平滑插值。
    - `kTangentStep`: 阶梯插值。
    - `kTangentClamped`: 限制插值。
- **`isWeighted(index)`**: 检查关键帧是否使用加权切线。
- **`setIsWeighted(index, weighted)`**: 设置是否为加权切线。
- **`setTangent(index, x, y, isInTangent)`**: 设置自定义切线向量。
  ```python
  anim_curve.setInTangentType(0, OpenMayaAnim.MAnimCurve.kTangentSmooth)
  anim_curve.setIsWeighted(0, True)
  ```

#### **曲线评估**
- **`evaluate(time)`**: 在指定时间（`MTime` 对象）评估动画曲线的值。
  ```python
  value = anim_curve.evaluate(OpenMaya.MTime(5.0))
  print(f"Value at frame 5: {value}")
  ```
- **`isStatic()`**: 检查动画曲线是否为静态（即没有关键帧变化或值恒定）。

#### **曲线类型和连接**
- **`animCurveType()`**: 返回动画曲线的类型，例如：
  - `kAnimCurveTL`: 平移曲线（Translation）。
  - `kAnimCurveTA`: 旋转曲线（Angle）。
  - `kAnimCurveTU`: 无单位曲线（Unitless）。
  - `kAnimCurveTT`: 时间到时间曲线。
- **`input()`** 和 **`output()`**: 获取动画曲线的输入和输出连接（例如时间驱动或连接的属性）。
  ```python
  input_plug = anim_curve.input()
  if input_plug.isNull():
      print("No input connection")
  ```

#### **其他属性**
- **`isBreakdown(index)`**: 检查指定关键帧是否为“Breakdown”类型（用于动画制作中的辅助关键帧）。
- **`setIsBreakdown(index, isBreakdown)`**: 设置关键帧是否为 Breakdown。
- **`preInfinityType()`** 和 **`postInfinityType()`**: 获取或设置曲线在起始和结束时间之外的行为（例如循环、振荡、常量等）。
- **`setPreInfinityType(type)`** 和 **`setPostInfinityType(type)`**: 设置无限延伸行为。

### 3. **动画曲线类型**
`MAnimCurve` 支持的动画曲线类型对应于 Maya 的不同动画节点：
- `kAnimCurveTL`: 用于平移（X、Y、Z 轴）。代表输入为time，输出为Linear(线性距离)
- `kAnimCurveTA`: 用于旋转（角度）。代表输入为time，输出为angle（角度）
- `kAnimCurveTU`: 用于无单位属性（如透明度、缩放）。代表输入为time，输出为 unitless（无单位）
- `kAnimCurveTT`: 用于时间到时间的映射。代表输入为time，输出为 time。
- `kAnimCurveTAU`: 用于单位到角度的转换。
- 不止是时间可以作为输入，无单位属性unitless也可以作为输入（UL,UA,UU,UT）,常用于驱动关键帧

通过 `animCurveType()` 方法可以确认曲线的具体类型。

### 4. **使用场景**
`MAnimCurve` 适用于以下场景：
- **批量处理动画**：遍历和修改大量关键帧，例如调整时间偏移或值缩放。
- **动态创建动画**：通过 `addKey` 方法生成新的动画曲线。
- **分析动画数据**：使用 `evaluate` 方法提取特定时间点的值，或检查曲线的连接关系。
- **优化动画**：删除冗余关键帧、调整切线以优化曲线平滑度。
- **自定义动画工具**：开发复杂的动画工具，例如曲线平滑器或关键帧清理工具。

---

### 5. **注意事项**
- **性能**：`MAnimCurve` 是低级 API，适合高性能需求，但代码复杂度较高。对于简单任务，推荐使用 `maya.cmds`（如 `keyframe` 或 `setKeyframe`）。
- **时间单位**：时间值通过 `MTime` 对象处理，需注意 Maya 的时间单位设置（帧或秒）。
- **错误处理**：确保输入的 `MObject` 是有效的动画曲线节点，否则会抛出异常。
- **API 版本**：`MAnimCurve` 是 Python API 2.0 的一部分，需确保 Maya 版本兼容。
- **Undo 支持**：某些操作（如 `addKey` 或 `remove`）需要通过 `MAnimCurveChange` 对象支持撤销功能。

### 6. **示例代码**
以下是一个示例，展示如何创建动画曲线、添加关键帧并评估值：
```python
from maya import OpenMaya, OpenMayaAnim

# 创建一个新的 animCurveTL 节点
dag_modifier = OpenMaya.MDagModifier()
anim_curve_obj = dag_modifier.createNode("animCurveTL")
dag_modifier.doIt()

# 初始化 MAnimCurve
anim_curve = OpenMayaAnim.MAnimCurve(anim_curve_obj)

# 添加关键帧
anim_curve.addKey(OpenMaya.MTime(0.0), 0.0, 
                  OpenMayaAnim.MAnimCurve.kTangentLinear, 
                  OpenMayaAnim.MAnimCurve.kTangentLinear)
anim_curve.addKey(OpenMaya.MTime(10.0), 5.0, 
                  OpenMayaAnim.MAnimCurve.kTangentLinear, 
                  OpenMayaAnim.MAnimCurve.kTangentLinear)

# 评估曲线
value = anim_curve.evaluate(OpenMaya.MTime(5.0))
print(f"Value at frame 5: {value}")

# 修改切线
anim_curve.setInTangentType(0, OpenMayaAnim.MAnimCurve.kTangentSmooth)
```
