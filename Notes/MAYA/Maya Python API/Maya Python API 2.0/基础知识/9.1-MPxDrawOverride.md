在 Autodesk Maya 的 Python API 2.0 中，`MPxDrawOverride` 是一个用于自定义节点在 Maya 视口（特别是 Viewport 2.0）中绘制方式的基类。它属于 `OpenMayaUI` 模块（`from maya.api.OpenMayaUI import MPxDrawOverride`），主要用于为自定义节点或 DAG 节点（如定位器、几何体等）提供高级绘制功能。与 `MPxLocatorNode` 相比，`MPxDrawOverride` 提供更灵活、更现代化的绘制控制，专为 Maya 的 Viewport 2.0 设计，支持复杂的渲染效果（如自定义着色器、纹理等）。

以下是对 `MPxDrawOverride` 的详细介绍：

---

### 1. **概述**
`MPxDrawOverride` 是一个基类，用于定义自定义节点在 Viewport 2.0 中的绘制逻辑。它允许开发者完全控制节点的渲染方式，适用于以下场景：
- 自定义定位器、几何体或其他 DAG 节点的绘制。
- 实现复杂的渲染效果，如动态着色、纹理映射或 GPU 加速绘制。
- 优化视口性能，通过选择性地绘制节点的不同部分。
- 支持 Maya 的现代渲染管线（Viewport 2.0），包括 OpenGL 和 DirectX。

与 `MPxLocatorNode` 的 `draw` 方法不同，`MPxDrawOverride` 提供了更细粒度的控制，允许开发者在绘制准备阶段、绘制阶段和清理阶段分别定义逻辑，并且可以利用 Maya 的渲染 API（如 `MHWRender`）来实现高效渲染。

---

### 2. **主要功能**
`MPxDrawOverride` 的核心在于通过重写特定方法来控制节点的绘制流程。以下是其主要功能和关键方法：

#### (1) **绘制流程控制**
`MPxDrawOverride` 将绘制过程分为几个阶段，开发者可以通过重写以下方法来自定义行为：
- **`prepareForDraw`**：
  - 签名：`prepareForDraw(dagPath, cameraPath, drawRequest, drawData)`
  - 作用：在绘制之前准备数据，例如计算几何体、更新缓冲区或加载纹理。
  - 参数：
    - `dagPath`：`MDagPath`，表示节点的 DAG 路径。
    - `cameraPath`：当前相机的 DAG 路径。
    - `drawRequest`：`MHWRender.MFrameContext`，提供渲染上下文信息。
    - `drawData`：`MUserData`，用于在绘制阶段传递自定义数据。
  - 通常用于初始化绘制所需的资源。

- **`addUIDrawables`**：
  - 签名：`addUIDrawables(drawManager, frameContext, data)`
  - 作用：定义节点的绘制逻辑，使用 `MHWRender.MDrawManager` 绘制几何体（如线、点、网格等）。
  - 参数：
    - `drawManager`：`MHWRender.MDrawManager`，提供绘制工具。
    - `frameContext`：`MHWRender.MFrameContext`，提供渲染上下文。
    - `data`：从 `prepareForDraw` 传递的自定义数据。
  - 这是实际执行绘制的地方，支持绘制 2D/3D 几何体、文本等。

- **`hasUIDrawables`**：
  - 签名：`hasUIDrawables() -> bool`
  - 作用：指示节点是否需要绘制 UI 元素。返回 `True` 表示需要调用 `addUIDrawables`。

- **`supportedDrawAPIs`**：
  - 签名：`supportedDrawAPIs() -> MHWRender.MRenderer.DrawAPI`
  - 作用：指定支持的渲染 API（如 OpenGL、DirectX）。通常返回 `MHWRender.MRenderer.kOpenGL | MHWRender.MRenderer.kDirectX11`。

#### (2) **支持 Viewport 2.0**
- `MPxDrawOverride` 是为 Viewport 2.0 设计的，充分利用了 Maya 的硬件渲染管线。
- 它支持复杂的渲染效果，例如：
  - 使用自定义着色器（通过 `MHWRender.MShaderInstance`）。
  - 绘制动态几何体（如基于输入属性的形状）。
  - 支持透明度、深度测试和抗锯齿。

#### (3) **性能优化**
- **选择性绘制**：通过 `isBounded` 和 `boundingBox` 方法，可以限制绘制范围以优化性能。
- **缓存数据**：在 `prepareForDraw` 中缓存几何数据，避免重复计算。
- **跳过不必要的绘制**：通过 `excludedFromPostEffects` 或 `isTransparent` 方法控制是否参与后期效果或透明渲染。

#### (4) **与节点的关系**
- `MPxDrawOverride` 通常与自定义 DAG 节点（如继承自 `MPxLocatorNode` 或 `MPxNode`）关联。
- 通过 `MFnPlugin.registerNode` 注册节点时，可以指定 `MPxDrawOverride` 作为其绘制处理器。

### 3. **创建自定义绘制节点的步骤**
以下是使用 `MPxDrawOverride` 创建自定义绘制节点的步骤：

#### (1) **导入模块**
```python
from maya.api import OpenMaya, OpenMayaUI, OpenMayaRender
```

#### (2) **定义自定义绘制类**
继承 `MPxDrawOverride` 并实现绘制逻辑：
```python
class CustomDrawOverride(OpenMayaUI.MPxDrawOverride):
    def __init__(self, obj):
        super(CustomDrawOverride, self).__init__(obj, None, False)

    @staticmethod
    def creator(obj):
        return CustomDrawOverride(obj)

    def supportedDrawAPIs(self):
        return OpenMayaRender.MRenderer.kOpenGL | OpenMayaRender.MRenderer.kDirectX11

    def prepareForDraw(self, dagPath, cameraPath, frameContext, data):
        # 准备绘制数据
        data = OpenMaya.MUserData(False)  # False 表示不删除数据
        data.customData = {"size": 1.0}  # 示例：存储绘制参数
        return data

    def hasUIDrawables(self):
        return True

    def addUIDrawables(self, drawManager, frameContext, data):
        # 开始绘制
        drawManager.beginDrawable()
        
        # 设置颜色（例如白色）
        drawManager.setColor(OpenMaya.MColor((1.0, 1.0, 1.0)))
        
        # 绘制一个简单的线框正方形
        drawManager.line(OpenMaya.MPoint(-1.0, 0.0, -1.0), OpenMaya.MPoint(1.0, 0.0, -1.0))
        drawManager.line(OpenMaya.MPoint(1.0, 0.0, -1.0), OpenMaya.MPoint(1.0, 0.0, 1.0))
        drawManager.line(OpenMaya.MPoint(1.0, 0.0, 1.0), OpenMaya.MPoint(-1.0, 0.0, 1.0))
        drawManager.line(OpenMaya.MPoint(-1.0, 0.0, 1.0), OpenMaya.MPoint(-1.0, 0.0, -1.0))
        
        drawManager.endDrawable()

    def boundingBox(self, dagPath, cameraPath):
        # 定义边界框
        corner1 = OpenMaya.MPoint(-1.0, -0.1, -1.0)
        corner2 = OpenMaya.MPoint(1.0, 0.1, 1.0)
        return OpenMaya.MBoundingBox(corner1, corner2)
```

#### (4) **注册节点和绘制处理器**
```python
def initializePlugin(plugin):
    fnPlugin = OpenMaya.MFnPlugin(plugin, "YourName", "1.0.0")
    try:
        fnPlugin.registerNode(
            CustomLocator.kNodeName,
            CustomLocator.kNodeID,
            CustomLocator.creator,
            CustomLocator.initialize,
            OpenMaya.MPxNode.kLocatorNode,
            drawDbClassification="drawdb/geometry/customLocator",
            drawRegistrantId=CustomLocator.kNodeName
        )
        OpenMayaUI.MDrawRegistry.registerDrawOverrideCreator(
            "drawdb/geometry/customLocator",
            CustomLocator.kNodeName,
            CustomDrawOverride.creator
        )
    except:
        OpenMaya.MGlobal.displayError("Failed to register node or draw override")

def uninitializePlugin(plugin):
    fnPlugin = OpenMaya.MFnPlugin(plugin)
    try:
        OpenMayaUI.MDrawRegistry.deregisterDrawOverrideCreator(
            "drawdb/geometry/customLocator",
            CustomLocator.kNodeName
        )
        fnPlugin.deregisterNode(CustomLocator.kNodeID)
    except:
        OpenMaya.MGlobal.displayError("Failed to deregister node or draw override")
```

### 4. **关键方法和属性**
以下是 `MPxDrawOverride` 的关键方法和属性，开发者可能需要重写或使用：

- **`prepareForDraw`**：准备绘制数据，缓存几何体或参数。
- **`addUIDrawables`**：执行绘制操作，使用 `MDrawManager` 提供的工具。
- **`hasUIDrawables`**：指示是否需要调用 `addUIDrawables`。
- **`supportedDrawAPIs`**：指定支持的渲染 API。
- **`boundingBox`**：定义节点的边界框，用于视口选择和优化。
- **`isBounded`**：返回 `True` 表示节点有边界框。
- **`excludedFromPostEffects`**：返回 `True` 表示跳过后期效果（如抗锯齿、阴影）。
- **`isTransparent`**：返回 `True` 表示节点需要透明渲染。

---

### 5. **与 MPxLocatorNode 的区别**
- **`MPxLocatorNode`**：
  - 使用 `draw` 方法直接调用 OpenGL 或 Viewport 2.0 绘制。
  - 更适合简单的定位器绘制，代码结构较简单。
  - 对 Viewport 2.0 的支持有限，难以实现复杂渲染效果。
- **`MPxDrawOverride`**：
  - 专为 Viewport 2.0 设计，支持现代渲染管线。
  - 提供更细粒度的控制（如准备阶段和绘制阶段分离）。
  - 支持复杂的渲染效果，如自定义着色器或动态几何体。
  - 更适合需要高性能或复杂渲染的场景。

---

### 6. **注意事项**
- **Viewport 2.0 依赖**：`MPxDrawOverride` 仅在 Viewport 2.0 中有效，确保 Maya 偏好设置中启用了 Viewport 2.0。
- **性能优化**：在 `prepareForDraw` 中尽量缓存数据，避免在 `addUIDrawables` 中执行复杂计算。
- **资源管理**：如果使用着色器或纹理，确保在 `prepareForDraw` 中正确初始化和释放资源。
- **调试**：使用 `MGlobal.displayInfo` 或 `MGlobal.displayError` 输出调试信息。
- **兼容性**：确保 `supportedDrawAPIs` 返回正确的 API，以匹配 Maya 的渲染设置。

### 7. **示例：绘制一个动态大小的圆形定位器**
以下是一个完整的示例，展示如何使用 `MPxDrawOverride` 绘制一个基于属性大小的圆形定位器：

```python
from maya.api import OpenMaya, OpenMayaUI, OpenMayaRender

class CircleLocator(OpenMayaUI.MPxLocatorNode):
    kNodeName = "circleLocator"
    kNodeID = OpenMaya.MTypeId(0x00080004)
    sizeAttr = OpenMaya.MObject()

    @classmethod
    def creator(cls):
        return cls()

    @classmethod
    def initialize(cls):
        nAttr = OpenMaya.MFnNumericAttribute()
        cls.sizeAttr = nAttr.create("size", "sz", OpenMaya.MFnNumericData.kFloat, 1.0)
        nAttr.setMin(0.1)
        nAttr.setMax(10.0)
        nAttr.setKeyable(True)
        cls.addAttribute(cls.sizeAttr)

class CircleDrawOverride(OpenMayaUI.MPxDrawOverride):
    def __init__(self, obj):
        super(CircleDrawOverride, self).__init__(obj, None, False)

    @staticmethod
    def creator(obj):
        return CircleDrawOverride(obj)

    def supportedDrawAPIs(self):
        return OpenMayaRender.MRenderer.kOpenGL | OpenMayaRender.MRenderer.kDirectX11

    def prepareForDraw(self, dagPath, cameraPath, frameContext, data):
        # 获取节点的大小属性
        node = OpenMaya.MFnDependencyNode(dagPath.node())
        sizePlug = node.findPlug("size", False)
        size = sizePlug.asFloat()
        
        # 存储绘制数据
        data = OpenMaya.MUserData(False)
        data.customData = {"size": size}
        return data

    def hasUIDrawables(self):
        return True

    def addUIDrawables(self, drawManager, frameContext, data):
        drawManager.beginDrawable()
        
        # 设置颜色（例如白色）
        drawManager.setColor(OpenMaya.MColor((1.0, 1.0, 1.0)))
        
        # 绘制圆形
        size = data.customData["size"]
        drawManager.circle(OpenMaya.MPoint(0, 0, 0), OpenMaya.MVector(0, 1, 0), size, False)
        
        drawManager.endDrawable()

    def boundingBox(self, dagPath, cameraPath):
        # 获取大小属性以计算边界框
        node = OpenMaya.MFnDependencyNode(dagPath.node())
        sizePlug = node.findPlug("size", False)
        size = sizePlug.asFloat()
        
        corner1 = OpenMaya.MPoint(-size, -0.1, -size)
        corner2 = OpenMaya.MPoint(size, 0.1, size)
        return OpenMaya.MBoundingBox(corner1, corner2)

def initializePlugin(plugin):
    fnPlugin = OpenMaya.MFnPlugin(plugin, "YourName", "1.0.0")
    try:
        fnPlugin.registerNode(
            CircleLocator.kNodeName,
            CircleLocator.kNodeID,
            CircleLocator.creator,
            CircleLocator.initialize,
            OpenMaya.MPxNode.kLocatorNode,
            drawDbClassification="drawdb/geometry/circleLocator",
            drawRegistrantId=CircleLocator.kNodeName
        )
        OpenMayaUI.MDrawRegistry.registerDrawOverrideCreator(
            "drawdb/geometry/circleLocator",
            CircleLocator.kNodeName,
            CircleDrawOverride.creator
        )
    except:
        OpenMaya.MGlobal.displayError("Failed to register node or draw override")

def uninitializePlugin(plugin):
    fnPlugin = OpenMaya.MFnPlugin(plugin)
    try:
        OpenMayaUI.MDrawRegistry.deregisterDrawOverrideCreator(
            "drawdb/geometry/circleLocator",
            CircleLocator.kNodeName
        )
        fnPlugin.deregisterNode(CircleLocator.kNodeID)
    except:
        OpenMaya.MGlobal.displayError("Failed to deregister node or draw override")
```

运行后，这个节点会在 Maya 场景中创建一个圆形定位器，其大小可以通过节点的 `size` 属性动态调整。
