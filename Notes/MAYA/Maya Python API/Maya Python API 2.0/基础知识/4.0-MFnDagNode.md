在 Autodesk Maya 的 Python API 2.0 中，MFnDagNode 是 OpenMaya 模块（from maya import OpenMaya）中的一个函数集类，专门用于操作 Maya 场景中的 DAG（有向无环图）节点。DAG 节点是具有层级关系的节点，例如变换节点（transform）、几何体（mesh）、相机（camera）、灯光（light）等。MFnDagNode 继承自 MFnDependencyNode，提供了对 DAG 节点的特定功能，如处理父子关系、变换矩阵和实例化等。以下是对 MFnDagNode 的详细介绍：

---

### **1. 概述**
在 Maya Python API 2.0 中（`maya.api.OpenMaya`），`MFnDagNode` 是用于操作 Maya 场景中 DAG（有向无环图）节点的函数集，绑定到一个 `MObject` 或 `MDagPath`。DAG 节点包括变换节点（`transform`）、几何体（`mesh`）、相机（`camera`）、灯光（`light`）等，具有层级关系。`MFnDagNode` 继承自 `MFnDependencyNode`，提供了处理 DAG 节点特有功能的方法，如层级管理、变换操作和实例化处理。

与 API 1.0 相比，API 2.0 的接口更现代化，语法更简洁，且在某些情况下性能更优。`MFnDagNode` 在 API 2.0 中的功能和方法与 API 1.0 类似，但需要注意导入路径和某些方法调用的细微差异。

---

### **2. 主要功能**
`MFnDagNode` 在 API 2.0 中的主要功能包括：
- **层级管理**：访问和修改节点的父子关系。
- **变换操作**：获取或设置节点的平移、旋转、缩放等变换信息。
- **实例化处理**：管理节点的实例化状态（如一个几何体被多个变换节点引用）。
- **路径操作**：通过 `MDagPath` 获取节点的完整路径，处理实例化场景。
- **类型检查**：验证节点是否为特定 DAG 类型。

### **3. 常用方法**
以下是 `MFnDagNode` 在 API 2.0 中的常用方法及其功能（方法名称和功能与 API 1.0 基本一致，但使用 API 2.0 的导入和对象管理）：

#### **初始化**
- **`MFnDagNode(mobject)`**: 绑定到一个 `MObject`。
- **`MFnDagNode(dagPath)`**: 绑定到一个 `MDagPath`（推荐用于实例化节点）。
  ```python
  import maya.api.OpenMaya as om
  mobject = om.MObject()  # 假设从 MSelectionList 获取
  fn_dag = om.MFnDagNode(mobject)
  ```

#### **节点信息**
- **`name()`**: 返回节点名称（字符串）。
  ```python
  node_name = fn_dag.name()  # 如 "pCube1"
  ```

- **`typeName()`**: 返回节点类型名称（字符串）。
  ```python
  type_name = fn_dag.typeName()  # 如 "transform" 或 "mesh"
  ```

- **`fullPathName()`**: 返回节点的完整 DAG 路径名称。
  ```python
  full_path = fn_dag.fullPathName()  # 如 "|group1|pCube1"
  ```

- **`partialPathName()`**: 返回节点的短路径名称。
  ```python
  partial_path = fn_dag.partialPathName()  # 如 "pCube1"
  ```

#### **层级管理**
- **`parentCount()`**: 返回父节点数量。
  ```python
  parent_count = fn_dag.parentCount()
  ```

- **`parent(index)`**: 获取指定索引的父节点（返回 `MObject`）。
  ```python
  parent_mobject = fn_dag.parent(0)
  ```

- **`childCount()`**: 返回子节点数量。
  ```python
  child_count = fn_dag.childCount()
  ```

- **`child(index)`**: 获取指定索引的子节点（返回 `MObject`）。
  ```python
  child_mobject = fn_dag.child(0)
  ```

- **`dagPath()`**: 返回节点的 `MDagPath`。
  ```python
  dag_path = fn_dag.dagPath()
  ```

#### **变换操作**
- **`transformationMatrix()`**: 返回节点的变换矩阵（`MMatrix`）。
  ```python
  matrix = fn_dag.transformationMatrix()
  ```

- **`getPath()`**: 获取节点的 `MDagPath`。
  ```python
  dag_path = om.MDagPath()
  fn_dag.getPath(dag_path)
  ```

#### **实例化管理**
- **`isInstanced()`**: 检查节点是否为实例化节点。
  ```python
  is_instanced = fn_dag.isInstanced()
  ```

- **`instanceCount(indirect)`**: 返回节点的实例数量。
  - `indirect`: 如果为 `True`，包括间接实例。
  ```python
  instance_count = fn_dag.instanceCount(True)
  ```

#### **其他操作**
- **`isIntermediateObject()`**: 检查节点是否为中间对象。
  ```python
  is_intermediate = fn_dag.isIntermediateObject()
  ```

- **`isParentOf(mobject)`**: 检查指定节点是否为当前节点的父节点。
  ```python
  is_parent = fn_dag.isParentOf(parent_mobject)
  ```

### **4. 使用场景**
`MFnDagNode` 在 API 2.0 中的典型应用场景包括：
- **遍历场景层级**：获取节点的父子关系，构建场景树。
- **变换操作**：修改节点的平移、旋转、缩放等。
- **实例化处理**：处理多实例节点（如一个网格被多个变换节点引用）。
- **路径管理**：通过 `MDagPath` 获取节点的完整路径。

#### **示例：获取选中节点的层级信息（API 2.0）**
```python
import maya.api.OpenMaya as om

# 获取当前选择列表
sel_list = om.MGlobal.getActiveSelectionList()

# 遍历选择列表
for i in range(sel_list.length()):
    dag_path = om.MDagPath()
    sel_list.getDagPath(i, dag_path)
    fn_dag = om.MFnDagNode(dag_path)
    print(f"Node: {fn_dag.fullPathName()}")
    print(f"Parent count: {fn_dag.parentCount()}")
    print(f"Child count: {fn_dag.childCount()}")
    if fn_dag.isInstanced():
        print(f"Instance count: {fn_dag.instanceCount(True)}")
```

输出示例：
```
Node: |group1|pCube1
Parent count: 1
Child count: 1
Instance count: 1
```

#### **示例：获取节点的变换矩阵**
```python
import maya.api.OpenMaya as om

sel_list = om.MGlobal.getActiveSelectionList()
dag_path = om.MDagPath()
sel_list.getDagPath(0, dag_path)
fn_dag = om.MFnDagNode(dag_path)

# 获取变换矩阵

print(f"Transformation matrix: {matrix}")
```

#### **示例：遍历子节点**
列出选中节点的所有子节点：
```python

    child_mobject = fn_dag.child(i)
    child_fn_dag = om.MFnDagNode(child_mobject)
    print(f"Child node: {child_fn_dag.fullPathName()}")
```

### **5. API 2.0 与 API 1.0 的差异**
- **导入路径**：API 2.0 使用 `maya.api.OpenMaya`，而 API 1.0 使用 `maya.OpenMaya`。
- **性能改进**：API 2.0 在某些操作（如矩阵计算和节点访问）上进行了优化。
- **方法一致性**：`MFnDagNode` 的方法名称和功能在 API 2.0 中与 API 1.0 基本相同，但某些返回类型（如矩阵或数组）可能更现代化（如使用 Python 原生类型）。
- **向后兼容性**：API 2.0 是对 API 1.0 的重构，建议新项目优先使用 API 2.0，但老项目可能仍依赖 API 1.0。

### **6. 注意事项**
- **正确绑定**：确保 `MObject` 或 `MDagPath` 是有效的 DAG 节点，否则初始化 `MFnDagNode` 会抛出异常。推荐使用 `MDagPath` 初始化以支持实例化节点。
- **与 `MFnDependencyNode` 的区别**：`MFnDagNode` 专注于 DAG 节点的层级和变换操作，而 `MFnDependencyNode` 适用于所有依赖节点（包括非 DAG 节点，如材质）。
- **实例化处理**：对于实例化节点，使用 `MDagPath` 而不是 `MObject`，以确保正确的路径上下文。
- **性能**：频繁访问层级或变换矩阵可能影响性能，建议缓存 `MDagPath` 或 `MMatrix`。
- **类型检查**：使用 `typeName()` 或 `MObject.hasFn()` 确保节点支持 `MFnDagNode` 操作。

### **7. 相关类和模块**
- **`MObject`**: `MFnDagNode` 绑定的节点句柄。
- **`MDagPath`**: 表示 DAG 节点的路径，推荐用于初始化 `MFnDagNode`。
- **`MFnDependencyNode`**: `MFnDagNode` 的基类，处理通用依赖节点功能。
- **`MSelectionList`**: 用于获取包含 `MObject` 或 `MDagPath` 的选择列表。
- **`MMatrix`**: 用于处理节点的变换矩阵。
- **`MGlobal`**: 提供全局操作，如获取当前选择。

### **8. 常见 DAG 节点类型**
`MFnDagNode` 常处理的节点类型包括：
- `transform`: 变换节点。
- `mesh`: 网格几何体。
- `nurbsCurve` / `nurbsSurface`: NURBS 曲线或表面。
- `camera`: 相机节点。
- `light`: 灯光节点（如 `spotLight`、`pointLight`）。

具体类型可通过 `typeName()` 或 `MObject.apiType()` 检查。
