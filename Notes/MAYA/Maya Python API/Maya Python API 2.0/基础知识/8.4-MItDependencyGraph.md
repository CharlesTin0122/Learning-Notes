在 Maya Python API 2.0 中，`MItDependencyGraph` 是一个强大的迭代器类，用于遍历 Maya 场景中的依赖图（Dependency Graph），即节点之间的连接关系。它允许开发者以编程方式探索节点网络，例如查找与特定节点相关的上游或下游节点、属性连接或特定类型的节点。以下是对 `MItDependencyGraph` 的详细介绍，使用正确的导入方式 `import maya.api.OpenMaya as om`。

---

### 1. **概述**
`MItDependencyGraph` 位于 `maya.api.OpenMaya` 模块中，用于迭代 Maya 依赖图中的节点。它可以基于给定的起点节点（如 `MObject` 或 `MPlug`）遍历依赖图，按照指定的方向（上游或下游）和过滤条件（如节点类型或属性）访问相关节点。

- **依赖图**：Maya 的依赖图是由节点（`MObject`）和它们之间的连接（通过 `MPlug`）组成的网络，控制着场景中数据的流动和计算。
- **用途**：`MItDependencyGraph` 常用于分析节点之间的关系、查找特定类型的节点（如材质、变换节点）或调试复杂的节点网络。

---

### 2. **主要功能**
- **遍历依赖图**：支持按上游（输入）或下游（输出）方向迭代节点。
- **过滤节点**：可以根据节点类型（如 `MFn.kTransform`、`MFn.kMesh`）或特定属性过滤迭代结果。
- **访问节点和属性**：提供对节点（`MObject`）、插头（`MPlug`）和 DAG 路径（`MDagPath`）的访问。
- **灵活性**：支持深度优先或广度优先遍历，以及处理循环网络（避免无限循环）。

---

### 3. **构造函数**
`MItDependencyGraph` 有多个构造函数，常用的形式如下：

```python
MItDependencyGraph(start_node_or_plug, filter_type=om.MFn.kInvalid, direction=om.MItDependencyGraph.kDownstream, traversal=om.MItDependencyGraph.kDepthFirst, level=om.MItDependencyGraph.kNodeLevel)
```

- **参数**：
  - `start_node_or_plug`：迭代的起点，可以是 `MObject`（节点）或 `MPlug`（属性）。
  - `filter_type`：过滤器，指定要迭代的节点类型（如 `MFn.kMesh`、`MFn.kShader`）。默认是 `MFn.kInvalid`（不过滤）。
  - `direction`：遍历方向：
    - `om.MItDependencyGraph.kDownstream`：下游（从起点到输出）。
    - `om.MItDependencyGraph.kUpstream`：上游（从起点到输入）。
  - `traversal`：遍历方式：
    - `om.MItDependencyGraph.kDepthFirst`：深度优先。
    - `om.MItDependencyGraph.kBreadthFirst`：广度优先。
  - `level`：迭代级别：
    - `om.MItDependencyGraph.kNodeLevel`：仅迭代节点。
    - `om.MItDependencyGraph.kPlugLevel`：迭代到属性级别。

- **示例**：
```python
import maya.api.OpenMaya as om

# 获取某个节点（例如 pCube1 的 shape 节点）
sel_list = om.MSelectionList()
sel_list.add("pCube1Shape")
mobj = sel_list.getDependNode(0)

# 创建迭代器，遍历下游的 mesh 节点
iterator = om.MItDependencyGraph(mobj, om.MFn.kMesh, om.MItDependencyGraph.kDownstream)
```

### 4. **常用方法**
以下是 `MItDependencyGraph` 类中常用的方法及其功能：

- **isDone()**  
  检查迭代是否完成。返回 `True` 表示迭代器已到达依赖图的末尾。  
  示例：
  ```python
  while not iterator.isDone():
      # 处理当前节点
      iterator.next()
  ```

- **next()**  
  移动到依赖图中的下一个节点或插头。  
  注意：调用此方法会更新迭代器的当前指针。

- **currentNode()**  
  返回当前节点的 `MObject`。  
  示例：
  ```python
  mobj = iterator.currentNode()
  fn_dep = om.MFnDependencyNode(mobj)
  print(f"Node: {fn_dep.name()}")
  ```

- **currentPlug()**  
  返回当前插头（`MPlug`），仅在 `kPlugLevel` 模式下有效。  
  示例：
  ```python
  plug = iterator.currentPlug()
  print(f"Plug: {plug.name()}")
  ```

- **currentItem()**  
  返回当前迭代项（可以是 `MObject` 或 `MPlug`，取决于迭代级别）。  
  示例：
  ```python
  item = iterator.currentItem()
  if iterator.currentLevel() == om.MItDependencyGraph.kNodeLevel:
      fn_dep = om.MFnDependencyNode(item)
      print(f"Node: {fn_dep.name()}")
  ```

- **getNodePath(dag_path_array)**  
  获取当前节点的 DAG 路径（`MDagPath`），适用于 DAG 节点。  
  参数 `dag_path_array` 是一个 `MDagPathArray` 对象。  
  示例：
  ```python
  dag_path_array = om.MDagPathArray()
  iterator.getNodePath(dag_path_array)
  for i in range(dag_path_array.length()):
      print(f"DAG Path: {dag_path_array[i].fullPathName()}")
  ```

- **reset()**  
  重置迭代器到起点，允许重新遍历。

- **prune()**  
  修剪当前分支，跳过对当前节点的进一步遍历（用于优化或避免循环）。  
  示例：
  ```python
  if some_condition:
      iterator.prune()  # 跳过当前节点及其子网络
      iterator.next()
  ```

### 5. **使用场景**
`MItDependencyGraph` 常用于以下场景：
- **查找材质或着色器**：从 mesh 节点遍历到其连接的着色器组（shading group）或材质。
- **分析节点网络**：检查节点的输入或输出连接，例如查找影响某个属性的上游节点。
- **批量操作**：对依赖图中特定类型的节点执行操作（如修改所有灯光的强度）。
- **调试**：探索复杂的节点连接，了解数据流向。

---

### 6. **代码示例**
以下是一个示例，展示如何使用 `MItDependencyGraph` 查找与选定 mesh 节点连接的材质（shader）：

```python
import maya.api.OpenMaya as om

# 获取选定的 mesh 节点
sel_list = om.MSelectionList()
om.MGlobal.getActiveSelectionList(sel_list)
mobj = sel_list.getDependNode(0)

# 创建迭代器，查找下游的着色器组 (shadingEngine)
iterator = om.MItDependencyGraph(
    mobj,
    om.MFn.kShadingEngine,
    om.MItDependencyGraph.kDownstream,
    om.MItDependencyGraph.kDepthFirst,
    om.MItDependencyGraph.kNodeLevel
)

# 遍历依赖图
while not iterator.isDone():
    current_node = iterator.thisNode()
    fn_dep = om.MFnDependencyNode(current_node)
    print(f"Found shading group: {fn_dep.name()}")
    
    # 查找连接到 shadingEngine 的材质
    shader_plug = fn_dep.findPlug("surfaceShader", False)
    if shader_plug.isConnected():
        connected_plugs = om.MPlugArray()
        shader_plug.connectedTo(connected_plugs, True, False)
        if connected_plugs.length() > 0:
            shader_node = connected_plugs[0].node()
            fn_shader = om.MFnDependencyNode(shader_node)
            print(f"Connected shader: {fn_shader.name()}")
    
    iterator.next()
```

**输出示例**（假设选择了一个 mesh，其连接到 lambert1 材质）：
```
Found shading group: initialShadingGroup
Connected shader: lambert1
```

### 7. **注意事项**
- **正确导入**：始终使用 `import maya.api.OpenMaya as om` 来访问 Maya Python API 2.0 的功能。
- **循环网络**：依赖图可能包含循环连接，使用 `prune()` 或检查 `isDone()` 来避免无限循环。
- **过滤效率**：指定 `filter_type`（如 `MFn.kShadingEngine`）可以显著提高遍历效率。
- **DAG vs DG**：`MItDependencyGraph` 主要用于依赖图（DG 节点和连接），但也可以通过 `getNodePath` 处理 DAG 节点的路径。
- **错误处理**：确保起点节点或插头有效，否则迭代器可能无法正确初始化。

- `MDagPath`：表示 DAG 节点的路径。
- `MFnDependencyNode` 和 `MFnDagNode`：用于操作节点和提取信息。
