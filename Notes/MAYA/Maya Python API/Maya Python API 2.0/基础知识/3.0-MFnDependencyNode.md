在 Autodesk Maya 的 Python API 2.0 中，`MFnDependencyNode` 是 `OpenMaya` 模块（`from maya import OpenMaya`）中的一个重要函数集类，用于操作 Maya 场景中的依赖节点（Dependency Node）。它提供了对依赖节点的属性、连接、名称等信息的访问和修改功能，是 Maya API 中处理节点的核心工具之一。以下是对 `MFnDependencyNode` 的详细介绍：

---

### **1. 概述**
`MFnDependencyNode` 是一个函数集（Function Set），用于操作 Maya 场景中的依赖节点。依赖节点是 Maya 场景中所有非 DAG（有向无环图）节点和 DAG 节点的基类，包括变换节点、几何体、材质、控制器等。`MFnDependencyNode` 通过绑定到一个 `MObject`（表示一个节点）来提供对节点属性和行为的访问。

与 `maya.cmds` 相比，`MFnDependencyNode` 提供更底层的访问，性能更高，适合需要高效处理节点或属性的开发场景。

---

### **2. 主要功能**
`MFnDependencyNode` 的主要功能包括：
- **节点信息访问**：获取节点的名称、类型、UUID 等。
- **属性操作**：查询、修改节点的属性（Attribute）或连接（Connection）。
- **节点管理**：支持节点的锁定状态、隐藏状态等操作。
- **连接处理**：管理节点之间的输入输出连接（如通过 `MPlug`）。
- **类型检查**：验证节点的类型是否支持特定操作。

---

### **3. 常用方法**
以下是 `MFnDependencyNode` 的一些常用方法及其功能：

#### **初始化**
- **`MFnDependencyNode(mobject)`**: 构造函数，将函数集绑定到一个 `MObject`。
  ```python
  import maya.OpenMaya as om
  mobject = om.MObject()  # 假设已从 MSelectionList 获取
  fn_node = om.MFnDependencyNode(mobject)
  ```

#### **节点信息**
- **`name()`**: 返回节点的名称（字符串）。
  ```python
  node_name = fn_node.name()  # 获取节点名称，如 "pCube1"
  ```

- **`typeName()`**: 返回节点的类型名称（字符串）。
  ```python
  type_name = fn_node.typeName()  # 如 "transform" 或 "mesh"
  ```

- **`typeId()`**: 返回节点的类型 ID（`MTypeId`）。
  ```python
  type_id = fn_node.typeId()
  ```

- **`uuid()`**: 返回节点的唯一标识符（UUID）。
  ```python
  node_uuid = fn_node.uuid().asString()  # 获取 UUID 字符串
  ```

#### **属性操作**
- **`attributeCount()`**: 返回节点上的属性数量。
  ```python
  attr_count = fn_node.attributeCount()
  ```

- **`attribute(index)`**: 获取指定索引的属性（返回 `MObject`）。
  ```python
  attr = fn_node.attribute(0)  # 获取第一个属性
  ```

- **`findPlug(attrName, network=False)`**: 查找指定名称的属性，返回 `MPlug` 对象。
  - `attrName`: 属性名称（如 "translateX"）。
  - `network`: 如果为 `True`，包括网络属性。
  ```python
  plug = fn_node.findPlug("translateX", False)
  ```

- **`hasAttribute(attrName)`**: 检查节点是否具有指定名称的属性。
  ```python
  has_attr = fn_node.hasAttribute("translateX")  # 返回 True 或 False
  ```

#### **节点状态**
- **`isLocked()`**: 检查节点是否被锁定。
  ```python
  is_locked = fn_node.isLocked()
  ```

- **`setLocked(state)`**: 设置节点的锁定状态。
  ```python
  fn_node.setLocked(True)  # 锁定节点
  ```

- **`isHidden()`**: 检查节点是否隐藏。
  ```python
  is_hidden = fn_node.isHidden()
  ```

#### **连接管理**
- **`getConnections()`**: 返回节点上所有连接的 `MPlugArray`。
  ```python
  plug_array = fn_node.getConnections()
  for i in range(plug_array.length()):
      print(plug_array[i].name())
  ```

- **`sourceConnections(plug)`**: 获取指定属性的源连接（输入）。
- **`destinationConnections(plug)`**: 获取指定属性的目标连接（输出）。

### **4. 使用场景**
`MFnDependencyNode` 常用于以下场景：
- **获取节点信息**：如名称、类型、UUID。
- **操作属性**：读取或设置属性值（如变换节点的平移、旋转）。
- **管理节点连接**：检查或修改节点之间的连接关系（如材质分配、动画曲线）。
- **节点筛选**：根据类型或属性筛选特定节点。

#### **示例：获取选中节点的名称和类型**
```python
import maya.OpenMaya as om

# 获取当前选择列表
sel_list = om.MGlobal.getActiveSelectionList()

# 遍历选择列表
for i in range(sel_list.length()):
    mobject = om.MObject()
    sel_list.getDependNode(i, mobject)
    if not mobject.isNull():
        fn_node = om.MFnDependencyNode(mobject)
        print(f"Node: {fn_node.name()}, Type: {fn_node.typeName()}")
```

输出示例：
```
Node: pCube1, Type: transform
Node: lambert1, Type: lambert
```

#### **示例：修改节点属性**
设置选中节点的 `translateX` 属性值：
```python
import maya.OpenMaya as om

sel_list = om.MGlobal.getActiveSelectionList()
mobject = om.MObject()
sel_list.getDependNode(0, mobject)
fn_node = om.MFnDependencyNode(mobject)

# 获取 translateX 属性并设置值
plug = fn_node.findPlug("translateX", False)
plug.setFloat(10.0)  # 设置 translateX 为 10.0
```

#### **示例：检查节点连接**
列出选中节点的所有属性连接：
```python
import maya.OpenMaya as om

sel_list = om.MGlobal.getActiveSelectionList()
mobject = om.MObject()
sel_list.getDependNode(0, mobject)
fn_node = om.MFnDependencyNode(mobject)

# 获取所有连接
plug_array = fn_node.getConnections()
for i in range(plug_array.length()):
    print(f"Connected plug: {plug_array[i].name()}")
```

### **5. 注意事项**
- **绑定正确性**：确保 `MObject` 是有效的依赖节点，否则初始化 `MFnDependencyNode` 会抛出错误。
- **类型检查**：某些方法（如 `findPlug`）需要确保属性存在，否则会抛出异常，建议使用 `hasAttribute` 检查。
- **性能**：`MFnDependencyNode` 提供高效的底层操作，但频繁访问属性或连接可能影响性能，建议缓存 `MPlug`。
- **与 `MFnDagNode` 的区别**：`MFnDependencyNode` 用于所有依赖节点（包括 DAG 节点和非 DAG 节点），而 `MFnDagNode` 专门用于处理 DAG 节点的层级关系（如父子关系）。
- **属性操作**：通过 `MPlug` 操作属性值时，注意属性类型（如 `float`、`double`、`string`）的正确匹配。

---

### **6. 相关类和模块**
- **`MObject`**: `MFnDependencyNode` 绑定的节点句柄。
- **`MPlug`**: 用于访问和修改节点的具体属性。
- **`MSelectionList`**: 用于获取包含 `MObject` 的选择列表。
- **`MFnDagNode`**: 用于处理 DAG 节点的函数集，继承自 `MFnDependencyNode`。
- **`MGlobal`**: 提供全局操作，如获取当前选择。

---

### **7. 常见类型**
`MFnDependencyNode` 可以操作的节点类型包括：
- 变换节点（`transform`）
- 几何体（`mesh`、`nurbsCurve` 等）
- 材质（`lambert`、`phong` 等）
- 控制器（`animCurve` 等）
- 其他依赖节点（如 `shadingEngine`、`objectSet`）

具体类型可通过 `typeName()` 或 `MObject.apiType()` 检查。
