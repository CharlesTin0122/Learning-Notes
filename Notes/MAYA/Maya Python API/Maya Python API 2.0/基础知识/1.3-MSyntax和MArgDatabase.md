# MSyntax
在 Autodesk Maya 的 Python API 2.0 中，`MSyntax` 是一个用于定义和配置 Maya 命令语法的类，属于 `OpenMaya` 模块（`Autodesk.Maya.OpenMaya`）。它主要用于自定义 Maya 插件或命令的开发者，用来指定命令的输入参数、标志（flags）及其行为。以下是对 `MSyntax` 的详细介绍：

### 1. **MSyntax 的作用**
`MSyntax` 用于定义一个 Maya 命令的语法规则，包括：
- 命令支持的标志（flags），例如短名称、长名称和参数类型。
- 命令的运行模式（如查询、编辑或创建模式）。
- 命令所需的对象或参数的数量和类型。

通过 `MSyntax`，开发者可以明确命令的输入格式，确保 Maya 能够正确解析用户输入的参数。

### 2. **主要方法**
以下是 `MSyntax` 类中常用的方法：

- **`addFlag(shortName, longName, flagType)`**
  - 添加一个命令标志，指定其短名称（如 `-q`）、长名称（如 `-query`）和参数类型。
  - 参数 `flagType` 定义标志接受的数据类型，例如：
    - `MSyntax.kNoArg`：无参数的标志（如布尔标志）。
    - `MSyntax.kString`：字符串参数。
    - `MSyntax.kDouble`：浮点数参数。
    - `MSyntax.kLong`：整数参数。
    - `MSyntax.kSelectionItem`：选择的对象或组件。
    - `MSyntax.kStringObjects`：字符串对象列表。
  - 示例：
    ```python
    syntax.addFlag("-q", "-query", MSyntax.kNoArg)  # 添加一个无参数的查询标志
    syntax.addFlag("-n", "-name", MSyntax.kString)  # 添加一个接受字符串的标志
    ```

- **`setObjectType(type, minObjects, maxObjects)`**
  - 定义命令需要的对象类型和数量。
  - 参数：
    - `type`：对象类型，如 `MSyntax.kSelectionList`（选择列表）。
    - `minObjects`：最小对象数量。
    - `maxObjects`：最大对象数量（0 表示无上限）。
  - 示例：
    ```python
    syntax.setObjectType(MSyntax.kSelectionList, 1, 1)  # 需要恰好 1 个选择对象
    ```

- **`useSelectionAsDefault(value)`**
  - 设置是否默认使用当前的选择列表作为命令的输入对象。
  - 示例：
    ```python
    syntax.useSelectionAsDefault(True)  # 默认使用当前选择
    ```

- **`enableQuery(value)`**
  - 启用或禁用命令的查询模式（`-query` 标志）。
  - 示例：
    ```python
    syntax.enableQuery(True)  # 允许查询模式
    ```

- **`enableEdit(value)`**
  - 启用或禁用命令的编辑模式（`-edit` 标志）。
  - 示例：
    ```python
    syntax.enableEdit(True)  # 允许编辑模式
    ```

- **`makeFlagMultiUse(flag)`**
  - 允许一个标志被多次使用（多值标志）。
  - 示例：
    ```python
    syntax.makeFlagMultiUse("-n")  # 允许 -n 标志多次使用
    ```

### 3. **使用场景**
`MSyntax` 通常在自定义 Maya 命令（`MPxCommand`）的 `syntax()` 方法中被调用，用于定义命令的输入参数规则。以下是一个简单的例子：

```python
from maya import OpenMaya

class MyCommand(OpenMaya.MPxCommand):
    def __init__(self):
        OpenMaya.MPxCommand.__init__(self)

    @staticmethod
    def syntaxCreator():
        syntax = OpenMaya.MSyntax()
        # 添加一个查询标志
        syntax.addFlag("-q", "-query", OpenMaya.MSyntax.kNoArg)
        # 添加一个接受字符串的标志
        syntax.addFlag("-n", "-name", OpenMaya.MSyntax.kString)
        # 需要 1 个选择对象
        syntax.setObjectType(OpenMaya.MSyntax.kSelectionList, 1, 1)
        # 启用查询模式
        syntax.enableQuery(True)
        return syntax

    def doIt(self, args):
        # 解析参数
        argData = OpenMaya.MArgDatabase(self.syntax(), args)
        if argData.isFlagSet("-q"):
            print("Query mode is active")
        if argData.isFlagSet("-n"):
            name = argData.flagArgumentString("-n", 0)
            print(f"Name provided: {name}")
        # 获取选择的对象
        selection = OpenMaya.MSelectionList()
        argData.getObjects(selection)
        obj = OpenMaya.MObject()
        selection.getDependNode(0, obj)
        print(f"Selected object: {obj}")

    @staticmethod
    def creator():
        return MyCommand()
```

### 4. **如何使用命令**
假设上述命令注册为 `myCommand`，在 Maya 中可以这样调用：
```python
# 创建模式
myCommand -n "myObject" pSphere1

# 查询模式
myCommand -q -n "myObject" pSphere1
```

### 5. **注意事项**
- **参数解析**：在命令的 `doIt` 方法中，使用 `MArgDatabase` 来解析用户输入的参数，并与 `MSyntax` 定义的规则匹配。
- **标志冲突**：短名称和长名称必须唯一，避免与现有 Maya 命令冲突。
- **对象类型**：确保 `setObjectType` 定义的对象类型与命令逻辑一致，否则可能导致解析错误。
- **查询/编辑模式**：如果命令支持 `-query` 或 `-edit`，需要在 `doIt` 方法中处理这些模式的逻辑。

### 6. **与 Python API 1.0 的区别**
在 Maya Python API 1.0 中，命令语法通常通过 `maya.cmds` 或 MEL 定义，而 API 2.0 的 `MSyntax` 提供了更底层的控制，适合需要高性能或复杂逻辑的插件开发。API 2.0 的 `MSyntax` 直接与 C++ API 的 `MSyntax` 类对齐，性能更优，且更适合大型项目。

# MArgDatabase
在 Autodesk Maya 的 Python API 2.0 中，`MArgDatabase` 是一个用于解析和处理自定义命令参数的类，属于 `OpenMaya` 模块（`Autodesk.Maya.OpenMaya`）。它与 `MSyntax` 配合使用，用于解析用户输入的命令行参数，并确保这些参数符合 `MSyntax` 定义的语法规则。以下是对 `MArgDatabase` 的详细介绍：

### 1. **MArgDatabase 的作用**
`MArgDatabase` 的主要功能是从用户输入的命令参数中提取标志（flags）、参数值和选择对象，并提供便捷的方法来查询这些参数。它是自定义 Maya 命令（`MPxCommand`）中处理输入的核心工具，特别是在 `doIt` 方法中。

- **核心用途**：
  - 解析命令的标志和参数值。
  - 获取用户选择的对象或节点。
  - 验证输入是否符合 `MSyntax` 定义的规则。

### 2. **创建 MArgDatabase**
`MArgDatabase` 通常在自定义命令的 `doIt` 方法中创建，通过传入 `MSyntax` 对象和用户提供的参数（`MArgList`）。示例：
```python
argData = OpenMaya.MArgDatabase(self.syntax(), args)
```
- `self.syntax()`：返回命令的 `MSyntax` 对象，定义了命令的语法规则。
- `args`：`MArgList` 对象，包含用户输入的实际参数。

### 3. **主要方法**
以下是 `MArgDatabase` 类中常用的方法：

- **`isFlagSet(flag)`**
  - 检查是否设置了某个标志（短名称或长名称）。
  - 返回：`True`（标志存在）或 `False`（标志不存在）。
  - 示例：
    ```python
    if argData.isFlagSet("-q"):
        print("Query flag is set")
    ```

- **`flagArgument<Type>(flag, index)`**
  - 获取指定标志的参数值，`<Type>` 根据标志类型可以是：
    - `flagArgumentString`：获取字符串参数。
    - `flagArgumentDouble`：获取浮点数参数。
    - `flagArgumentLong`：获取整数参数。
    - `flagArgumentBool`：获取布尔参数。
  - 参数：
    - `flag`：标志的短名称或长名称。
    - `index`：如果标志是多值标志（multi-use flag），指定第几个参数（从 0 开始）。
  - 示例：
    ```python
    name = argData.flagArgumentString("-n", 0)  # 获取 -n 标志的第一个字符串参数
    ```

- **`getFlagArgumentList(flag)`**
  - 返回一个标志的所有参数值（适用于多值标志）。
  - 返回类型：`MArgList`。
  - 示例：
    ```python
    argList = argData.getFlagArgumentList("-n")  # 获取 -n 标志的所有参数
    ```

- **`getObjects(selectionList)`**
  - 获取命令输入的选择对象，存储到 `MSelectionList` 中。
  - 示例：
    ```python
    selection = OpenMaya.MSelectionList()
    argData.getObjects(selection)
    obj = OpenMaya.MObject()
    selection.getDependNode(0, obj)  # 获取第一个选择对象
    ```

- **`isQuery()`**
  - 检查命令是否处于查询模式（`-query` 或 `-q` 标志）。
  - 返回：`True`（查询模式）或 `False`。
  - 示例：
    ```python
    if argData.isQuery():
        print("Command is in query mode")
    ```

- **`isEdit()`**
  - 检查命令是否处于编辑模式（`-edit` 或 `-e` 标志）。
  - 返回：`True`（编辑模式）或 `False`。
  - 示例：
    ```python
    if argData.isEdit():
        print("Command is in edit mode")
    ```

### 4. **使用场景**
`MArgDatabase` 通常在自定义 Maya 命令的 `doIt` 方法中用于解析用户输入。以下是一个完整的示例，展示如何结合 `MSyntax` 和 `MArgDatabase` 创建一个自定义命令：

```python
from maya import OpenMaya

class MyCommand(OpenMaya.MPxCommand):
    kCommandName = "myCommand"

    def __init__(self):
        OpenMaya.MPxCommand.__init__(self)

    @staticmethod
    def syntaxCreator():
        syntax = OpenMaya.MSyntax()
        syntax.addFlag("-q", "-query", OpenMaya.MSyntax.kNoArg)  # 查询标志
        syntax.addFlag("-n", "-name", OpenMaya.MSyntax.kString)  # 字符串参数
        syntax.setObjectType(OpenMaya.MSyntax.kSelectionList, 1, 1)  # 需要 1 个对象
        syntax.enableQuery(True)
        return syntax

    def doIt(self, args):
        # 创建 MArgDatabase 解析参数
        argData = OpenMaya.MArgDatabase(self.syntax(), args)

        # 检查查询模式
        if argData.isQuery():
            print("Running in query mode")

        # 获取 -n 标志的字符串参数
        name = ""
        if argData.isFlagSet("-n"):
            name = argData.flagArgumentString("-n", 0)
            print(f"Name: {name}")

        # 获取选择对象
        selection = OpenMaya.MSelectionList()
        argData.getObjects(selection)
        obj = OpenMaya.MObject()
        selection.getDependNode(0, obj)
        fnDag = OpenMaya.MFnDagNode(obj)
        print(f"Selected object: {fnDag.name()}")

    @staticmethod
    def creator():
        return MyCommand()

# 注册命令
def initializePlugin(plugin):
    pluginFn = OpenMaya.MFnPlugin(plugin)
    pluginFn.registerCommand(MyCommand.kCommandName, MyCommand.creator, MyCommand.syntaxCreator)

def uninitializePlugin(plugin):
    pluginFn = OpenMaya.MFnPlugin(plugin)
    pluginFn.deregisterCommand(MyCommand.kCommandName)
```

### 5. **如何使用命令**
假设命令注册为 `myCommand`，在 Maya 中可以这样调用：
```python
# 创建模式
myCommand -n "myObject" pSphere1

# 查询模式
myCommand -q -n "myObject" pSphere1
```

### 6. **注意事项**
- **错误处理**：如果用户输入的参数不符合 `MSyntax` 定义的规则，`MArgDatabase` 初始化会抛出异常。建议在 `doIt` 方法中使用 `try-except` 捕获错误。
  ```python
  try:
      argData = OpenMaya.MArgDatabase(self.syntax(), args)
  except:
      self.displayError("Invalid arguments provided")
      return
  ```
- **多值标志**：如果 `MSyntax` 中设置了 `makeFlagMultiUse`，使用 `getFlagArgumentList` 获取所有值。
- **选择对象**：`getObjects` 依赖于 `MSyntax.setObjectType` 的配置，确保选择对象的数量和类型正确。
- **查询/编辑模式**：需要检查 `isQuery` 和 `isEdit`，并在命令逻辑中实现相应功能。

### 7. **与 MSyntax 的关系**
- `MSyntax` 定义命令的语法规则（标志、对象数量等）。
- `MArgDatabase` 解析用户输入，并根据 `MSyntax` 的规则验证和提取参数。
- 二者配合使用，`MSyntax` 提供蓝图，`MArgDatabase` 负责实际解析。

### 8. **与 Python API 1.0 的区别**
在 Maya Python API 1.0 中，参数解析通常通过 `maya.cmds` 或 MEL 脚本完成，依赖字符串处理，效率较低且易出错。API 2.0 的 `MArgDatabase` 提供了更结构化的方式，直接与 C++ API 对接，性能更高，适合复杂插件开发。
