在 Autodesk Maya 中，`MPxLocatorNode` 是 Maya Python API 2.0（`OpenMaya` 模块）中的一个基类，用于创建自定义的定位器节点（Locator Node）。定位器节点是一种特殊的节点，通常用于在 3D 场景中提供可视化标记或控制点，常用于辅助动画、绑定或其他场景设置。`MPxLocatorNode` 继承自 `MPxNode`，并提供了一些额外的功能，专门用于定义在 Maya 视口中绘制自定义几何形状的节点。

以下是对 `MPxLocatorNode` 的详细介绍：

---

### 1. **概述**
`MPxLocatorNode` 是 Maya C++ API 的 Python 绑定版本，允许开发者通过 Python 创建自定义的定位器节点。定位器节点的主要功能是在 Maya 的 3D 视口中绘制用户定义的几何形状或标记（例如线条、点、形状等），并可以与场景中的其他节点交互。它通常用于：
- 创建自定义的可视化工具（如控制点、辅助线）。
- 定义交互式工具，用于绑定、动画或其他工作流程。
- 实现自定义的场景标记或 HUD 元素。

在 Python API 2.0 中，`MPxLocatorNode` 位于 `OpenMayaUI` 模块中（`from maya.api.OpenMayaUI import MPxLocatorNode`），因为它与视口绘制相关。

---

### 2. **主要功能**
`MPxLocatorNode` 提供了一些关键方法和属性，允许开发者自定义定位器的行为和绘制方式。以下是一些重要的功能：

#### (1) **自定义绘制**
- **draw 方法**：这是 `MPxLocatorNode` 的核心方法，用于定义定位器在视口中的绘制逻辑。开发者需要重写 `draw` 方法来指定如何绘制几何形状。
  - 方法签名：`draw(view, path, style, status)`
  - 参数：
    - `view`：`M3dView` 对象，表示当前的 3D 视口。
    - `path`：`MDagPath` 对象，表示节点的 DAG 路径。
    - `style`：绘制样式（如 `M3dView.kFlatShaded` 或 `M3dView.kWireFrame`）。
    - `status`：节点的显示状态（如选中、活动等）。
  - 在 `draw` 方法中，可以使用 OpenGL 或 Maya 的绘制工具（如 `MOpenGL` 或 `MDrawUtils`）来绘制几何形状。

#### (2) **支持硬件和软件绘制**
- `MPxLocatorNode` 支持在 Maya 的视口中进行硬件加速绘制（OpenGL 或 DirectX，视 Maya 版本和设置而定）。
- 开发者可以选择在视口中绘制 2D 或 3D 几何体，例如点、线、多边形等。

#### (3) **属性支持**
- 继承自 `MPxNode`，`MPxLocatorNode` 可以添加自定义属性（`MPlug` 和 `MObject`），用于控制定位器的行为或外观。
- 例如，可以添加浮点属性来控制定位器的大小、颜色或旋转。

#### (4) **视口交互**
- 定位器节点可以响应视口中的选择、变换（如平移、旋转、缩放）等操作。
- 通过重写 `compute` 方法，可以根据输入属性动态更新定位器的状态。

#### (5) **支持 Viewport 2.0**
- 在 Maya 的 Viewport 2.0 中，`MPxLocatorNode` 支持更复杂的绘制功能，例如使用自定义着色器或纹理。
- 需要重写 `draw` 方法以兼容 Viewport 2.0 的绘制管线。

### 3. **创建自定义定位器节点的步骤**
以下是使用 Maya Python API 2.0 创建自定义 `MPxLocatorNode` 的一般步骤：

#### (1) **导入必要的模块**
```python
from maya.api import OpenMaya, OpenMayaUI
```

#### (2) **定义自定义定位器类**
继承 `MPxLocatorNode` 并实现必要的初始化和绘制逻辑：
```python
class CustomLocator(OpenMayaUI.MPxLocatorNode):
    # 节点名称和唯一ID
    kNodeName = "customLocator"
    kNodeID = OpenMaya.MTypeId(0x00080001)  # 确保 ID 唯一

    def __init__(self):
        super(CustomLocator, self).__init__()

    def draw(self, view, path, style, status):
        # 获取当前视口
        view.beginGL()

        # 使用 OpenGL 绘制简单的几何体（例如一个正方形）
        OpenMayaRender.MGLFunctionTable().glBegin(OpenMayaRender.MGL_LINES)
        OpenMayaRender.MGLFunctionTable().glVertex3f(-1.0, 0.0, -1.0)
        OpenMayaRender.MGLFunctionTable().glVertex3f(1.0, 0.0, -1.0)
        OpenMayaRender.MGLFunctionTable().glVertex3f(1.0, 0.0, 1.0)
        OpenMayaRender.MGLFunctionTable().glVertex3f(-1.0, 0.0, 1.0)
        OpenMayaRender.MGLFunctionTable().glEnd()

        view.endGL()

    @classmethod
    def creator(cls):
        return cls()

    @classmethod
    def initialize(cls):
        # 添加自定义属性（可选）
        pass
```

#### (3) **注册节点**
将自定义节点注册到 Maya 中：
```python
def initializePlugin(plugin):
    vendor = "YourName"
    version = "1.0.0"
    fnPlugin = OpenMaya.MFnPlugin(plugin, vendor, version)
    try:
        fnPlugin.registerNode(
            CustomLocator.kNodeName,
            CustomLocator.kNodeID,
            CustomLocator.creator,
            CustomLocator.initialize,
            OpenMaya.MPxNode.kLocatorNode
        )
    except:
        OpenMaya.MGlobal.displayError("Failed to register node: {}".format(CustomLocator.kNodeName))

def uninitializePlugin(plugin):
    fnPlugin = OpenMaya.MFnPlugin(plugin)
    try:
        fnPlugin.deregisterNode(CustomLocator.kNodeID)
    except:
        OpenMaya.MGlobal.displayError("Failed to deregister node: {}".format(CustomLocator.kNodeName))
```

#### (4) **加载插件**
- 将上述代码保存为 `.py` 文件（例如 `customLocator.py`）。
- 在 Maya 中通过插件管理器加载该脚本，或者使用以下命令：
  ```python
  import maya.cmds as cmds
  cmds.loadPlugin("customLocator.py")
  cmds.createNode("customLocator")
  ```

### 4. **关键方法和属性**
以下是 `MPxLocatorNode` 的一些关键方法和属性，开发者可能需要重写或使用：

- **`draw`**：如上所述，用于自定义视口绘制逻辑。
- **`compute`**：用于计算节点的输出数据（继承自 `MPxNode`）。
  - 签名：`compute(plug, dataBlock)`
  - 用于根据输入属性更新输出属性。
- **`isBounded`**：返回 `True` 或 `False`，指示定位器是否有边界框。
  - 默认返回 `False`，需要重写以支持边界框。
- **`boundingBox`**：定义定位器的边界框，用于视口选择和渲染。
  - 签名：`boundingBox() -> MBoundingBox`
- **`getShapeSelectionMask`**：控制定位器在视口中的选择行为。

### 5. **注意事项**
- **Viewport 2.0 兼容性**：在 Maya 2016 及以上版本中，推荐使用 Viewport 2.0 的绘制方法（如 `MRenderUtilities`），以确保兼容性和性能。
- **OpenGL 使用**：Maya Python API 2.0 提供了 `OpenMayaRender.MGLFunctionTable` 来调用 OpenGL 函数，但需要注意 OpenGL 的版本兼容性。
- **线程安全**：绘制逻辑必须是线程安全的，避免在 `draw` 方法中访问非线程安全的资源。
- **性能优化**：避免在 `draw` 方法中执行复杂计算，确保绘制操作高效。
- **调试**：使用 `MGlobal.displayInfo` 或 `MGlobal.displayError` 输出调试信息，便于排查问题。

### 6. **示例：绘制一个简单的十字形定位器**
以下是一个完整的示例，展示如何创建一个绘制十字形定位器的节点：
```python
from maya.api import OpenMaya, OpenMayaUI, OpenMayaRender

class CrossLocator(OpenMayaUI.MPxLocatorNode):
    kNodeName = "crossLocator"
    kNodeID = OpenMaya.MTypeId(0x00080002)

    def __init__(self):
        super(CrossLocator, self).__init__()

    def draw(self, view, path, style, status):
        view.beginGL()

        # 设置颜色（例如，选中时为绿色，未选中时为白色）
        if status == OpenMayaUI.M3dView.kActive:
            OpenMayaRender.MGLFunctionTable().glColor3f(0.0, 1.0, 0.0)
        else:
            OpenMayaRender.MGLFunctionTable().glColor3f(1.0, 1.0, 1.0)

        # 绘制十字形
        OpenMayaRender.MGLFunctionTable().glBegin(OpenMayaRender.MGL_LINES)
        # 水平线
        OpenMayaRender.MGLFunctionTable().glVertex3f(-1.0, 0.0, 0.0)
        OpenMayaRender.MGLFunctionTable().glVertex3f(1.0, 0.0, 0.0)
        # 垂直线
        OpenMayaRender.MGLFunctionTable().glVertex3f(0.0, -1.0, 0.0)
        OpenMayaRender.MGLFunctionTable().glVertex3f(0.0, 1.0, 0.0)
        OpenMayaRender.MGLFunctionTable().glEnd()

        view.endGL()

    @classmethod
    def creator(cls):
        return cls()

    @classmethod
    def initialize(cls):
        pass

def initializePlugin(plugin):
    fnPlugin = OpenMaya.MFnPlugin(plugin, "YourName", "1.0.0")
    try:
        fnPlugin.registerNode(
            CrossLocator.kNodeName,
            CrossLocator.kNodeID,
            CrossLocator.creator,
            CrossLocator.initialize,
            OpenMaya.MPxNode.kLocatorNode
        )
    except:
        OpenMaya.MGlobal.displayError("Failed to register node: {}".format(CrossLocator.kNodeName))

def uninitializePlugin(plugin):
    fnPlugin = OpenMaya.MFnPlugin(plugin)
    try:
        fnPlugin.deregisterNode(CrossLocator.kNodeID)
    except:
        OpenMaya.MGlobal.displayError("Failed to deregister node: {}".format(CrossLocator.kNodeName))
```

运行后，这个节点会在 Maya 场景中创建一个十字形定位器，选中时显示为绿色，未选中时显示为白色。
