# MFnAttribute

在 **Maya Python API 2.0** 中，`OpenMaya.MFnAttribute` 是用于定义和操作 Maya 节点属性的基类。它是创建和配置节点属性的核心工具，允许开发者定义属性的类型、名称、行为以及其他特性（如是否可连接、是否存储值等）。以下是对 `MFnAttribute` 的详细介绍，包括其功能、子类、常用方法和使用场景。

### 1. **MFnAttribute 的定义**
- **MFnAttribute** 是 Maya 功能集（Function Set）的一部分，用于创建和管理节点上的属性（`Attribute`）。
- 它是抽象基类，实际使用时通常通过其子类（如 `MFnNumericAttribute`、`MFnTypedAttribute` 等）来创建特定类型的属性。
- 属性定义了节点的接口，决定了节点可以存储或处理的数据类型，以及数据在依赖图中的行为。

### 2. **MFnAttribute 的作用**
- **定义属性**：为自定义节点或现有节点添加动态属性，指定其名称、类型和行为。
- **控制属性行为**：设置属性的可连接性、存储性、默认值、范围等特性。
- **支持依赖图**：通过属性定义，`MFnAttribute` 决定了节点如何与其他节点交互（如输入/输出连接）。
- **动态性和扩展性**：支持动态添加属性到现有节点，或在自定义节点（如 `MPxNode`）中定义静态属性。

### 3. **MFnAttribute 的子类**
`MFnAttribute` 是一个基类，实际使用时会通过以下子类创建特定类型的属性：
- **MFnNumericAttribute**：用于数值类型属性（如 `float`、`int`、`double`、`boolean` 等）。
- **MFnTypedAttribute**：用于非数值类型属性（如 `string`、`matrix`、`mesh`、`nurbsCurve` 等）。
- **MFnEnumAttribute**：用于枚举类型属性，允许定义一组预定义的选项。
- **MFnUnitAttribute**：用于带单位的属性（如 `angle`、`time`、`distance`）。
- **MFnMatrixAttribute**：用于矩阵类型属性。
- **MFnCompoundAttribute**：用于复合属性，允许将多个子属性组合成一个父属性（如 `translate` 包含 `translateX`、`translateY`、`translateZ`）。
- **MFnMessageAttribute**：用于消息类型属性，仅用于连接，不存储值。

### 4. **常用方法**
以下是 `MFnAttribute` 及其子类的常用方法，用于配置属性的行为和特性：

#### 创建属性
- `create(name, shortName, type, defaultValue=None)`：创建属性，指定长名称、短名称、类型和默认值。
  - 示例：`nAttr.create("myFloat", "mf", OpenMaya.MFnNumericData.kFloat, 0.0)`
- `createColor(name, shortName)`：创建颜色属性（RGB 三通道浮点）。
  - 示例：`nAttr.createColor("myColor", "mc")`
- `createPoint(name, shortName)`：创建点属性（三维浮点向量）。
  - 示例：`nAttr.createPoint("myPoint", "mp")`

#### 设置属性特性

在maya Python API 2.0 中使用的是`attr.keyable`这中形式

- `setStorable(bool)`：设置属性是否存储在文件中。
  - 示例：`attr.setStorable(True)`（默认存储）。
- `setWritable(bool)`：设置属性是否可接受输入连接。
  - 示例：`attr.setWritable(True)`（允许输入连接）。
- `setReadable(bool)`：设置属性是否可作为输出。
  - 示例：`attr.setReadable(True)`（允许输出连接）。
- `setKeyable(bool)`：设置属性是否可以在 Channel Box 中设置关键帧。
  - 示例：`attr.setKeyable(True)`。
- `setHidden(bool)`：设置属性是否在 UI 中隐藏。
  - 示例：`attr.setHidden(True)`。
- `setArray(bool)`：设置属性是否为数组类型。
  - 示例：`attr.setArray(True)`。
- `setDefault(value)`：设置属性的默认值。
  - 示例：`nAttr.setDefault(1.0)`。
- `setMin(value)`, `setMax(value)`：设置数值属性的最小/最大值。
  - 示例：`nAttr.setMin(0.0)`。
- `setAffectsWorldSpace(bool)`：设置属性是否影响世界空间（常用于变换节点）。
  - 示例：`attr.setAffectsWorldSpace(True)`。

#### 复合属性（MFnCompoundAttribute）
- `addChild(childAttr)`：将子属性添加到复合属性中。
  - 示例：`compoundAttr.addChild(childAttr)`。

#### 枚举属性（MFnEnumAttribute）
- `addField(name, value)`：添加枚举字段及其值。
  - 示例：`enumAttr.addField("Option1", 0)`。

### 5. **使用示例**
以下是一个创建自定义节点的示例，展示如何使用 `MFnAttribute` 定义属性并添加到节点：

```python
import maya.OpenMaya as OpenMaya
import maya.OpenMayaMPx as OpenMayaMPx

class MyNode(OpenMayaMPx.MPxNode):
    # 定义属性
    inputAttr = OpenMaya.MObject()
    outputAttr = OpenMaya.MObject()

    def __init__(self):
        OpenMayaMPx.MPxNode.__init__(self)

    @staticmethod
    def creator():
        return OpenMayaMPx.asMPxPtr(MyNode())

    @staticmethod
    def initialize():
        # 创建输入属性（浮点型）
        nAttr = OpenMaya.MFnNumericAttribute()
        MyNode.inputAttr = nAttr.create("input", "in", OpenMaya.MFnNumericData.kFloat, 0.0)
        nAttr.setStorable(True)
        nAttr.setWritable(True)
        nAttr.setKeyable(True)

        # 创建输出属性（浮点型）
        MyNode.outputAttr = nAttr.create("output", "out", OpenMaya.MFnNumericData.kFloat, 0.0)
        nAttr.setStorable(False)
        nAttr.setWritable(False)
        nAttr.setReadable(True)

        # 添加属性到节点
        MyNode.addAttribute(MyNode.inputAttr)
        MyNode.addAttribute(MyNode.outputAttr)

        # 设置属性影响关系
        MyNode.attributeAffects(MyNode.inputAttr, MyNode.outputAttr)

    def compute(self, plug, dataBlock):
        if plug == MyNode.outputAttr:
            # 获取输入值
            inputHandle = dataBlock.inputValue(MyNode.inputAttr)
            inputValue = inputHandle.asFloat()

            # 计算输出值
            outputHandle = dataBlock.outputValue(MyNode.outputAttr)
            outputHandle.setFloat(inputValue * 2.0)
            dataBlock.setClean(plug)

        return OpenMaya.MStatus.kSuccess
```

- **说明**：
  - 创建两个浮点型属性 `input` 和 `output`，分别作为输入和输出。
  - 设置 `input` 可存储、可写、可设置关键帧；`output` 不可写、只读。
  - 使用 `attributeAffects` 定义输入属性影响输出属性。
  - 在 `compute` 方法中，基于输入值计算输出值。

### 6. **MFnAttribute 与 MPlug 的关系**
- **MFnAttribute**：用于定义属性的元数据（如类型、名称、行为），是属性的模板，存在于节点类型级别。
- **MPlug**：是属性的实例，存在于具体节点上，表示属性的值或连接状态。
- 通过 `MFnDependencyNode.findPlug` 获取 `MPlug`，其对应的 `MObject` 由 `MFnAttribute.create` 创建。
- 示例：`MFnAttribute` 定义了 `translateX` 的类型和行为，而 `pCube1.translateX` 是 `MPlug`，存储具体的值或连接。

### 7. **注意事项**
- **类型匹配**：确保属性类型与操作匹配（如 `MFnNumericAttribute` 用于数值，`MFnTypedAttribute` 用于字符串或几何数据）。
- **性能**：动态添加大量属性可能影响节点初始化性能，建议在 `initialize` 方法中优化属性创建。
- **属性影响**：使用 `attributeAffects` 明确属性之间的依赖关系，以确保依赖图正确更新。
- **线程安全**：`MFnAttribute` 操作通常不是线程安全的，建议在主线程中调用。
- **动态属性**：动态属性可以通过 `MFnDependencyNode.addAttribute` 添加到现有节点，需确保属性名称唯一。

### 8. **总结**
`OpenMaya.MFnAttribute` 是 Maya Python API 2.0 中用于定义和配置节点属性的核心基类，通过其子类（如 `MFnNumericAttribute`、`MFnTypedAttribute`）可以创建各种类型的属性。它定义了属性的元数据（如类型、名称、可连接性），为节点在依赖图中的数据交互提供基础。结合 `MPlug`，`MFnAttribute` 实现了属性定义与实例化操作的分离，是自定义节点开发和动态属性管理的基础。

# MPlug
在 **Maya Python API 2.0** 中，`OpenMaya.MPlug` 是 Maya 用来表示节点上某个属性（`Attribute`）实例的类。它是依赖图（Dependency Graph）中属性的动态表示，用于访问或操作属性的值、连接状态以及依赖关系。以下是对 `MPlug` 的详细介绍，包括其定义、功能、常用方法和使用场景。

### 1. **MPlug 的定义**
- **MPlug**（Plug）表示一个节点上某个属性的具体实例。它是 `Attribute`（通过 `MFnAttribute` 定义）在特定节点上的实现，包含属性的值或连接信息。
- 在 Maya 的依赖图中，`MPlug` 是节点之间数据传递的“连接点”，可以表示输入或输出。
- `MPlug` 由 `OpenMaya.MPlug` 类表示，通常通过 `MFnDependencyNode.findPlug` 或其他 API 方法获取。

### 2. **MPlug 的作用**
- **访问属性值**：读取或设置节点上属性的值（如浮点数、向量、字符串等）。
- **管理连接**：查询或操作属性与其他节点的连接关系（如输入源或输出目标）。
- **处理复合/数组属性**：支持访问复合属性（如 `translate` 的 `translateX`）或数组属性的子元素。
- **依赖图操作**：在自定义节点的 `compute` 方法中，`MPlug` 用于处理数据流和计算逻辑。

### 3. **MPlug 的关键特性**
- **网络化 vs 非网络化**：
  - 网络化 `MPlug`（通过 `findPlug(attr, True)` 获取）：包含依赖图中的连接信息，适合查询连接关系。
  - 非网络化 `MPlug`（通过 `findPlug(attr, False)` 获取）：仅包含本地值，适合高效的值操作。
- **层级结构**：
  - 对于复合属性（如 `translate`），`MPlug` 可以表示顶层属性或子属性（如 `translateX`）。
  - 对于数组属性，`MPlug` 可以表示整个数组或特定索引的元素。
- **动态性**：`MPlug` 是运行时的实例，同一个 `Attribute` 在不同节点上会有不同的 `MPlug`，存储不同的值或连接。

### 4. **常用方法**
以下是 `MPlug` 类的一些常用方法，涵盖值操作、连接查询和层级处理：

#### 值操作
- `asFloat()`, `asDouble()`, `asInt()`, `asString()`, 等：获取属性的值，根据属性类型选择合适方法。
  - 示例：`value = plug.asFloat()` 获取浮点值。
- `setFloat(value)`, `setDouble(value)`, `setInt(value)`, `setString(value)`, 等：设置属性的值。
  - 示例：`plug.setFloat(10.0)` 设置浮点值。
- `isLocked()`：检查属性是否被锁定（无法修改）。
  - 示例：`if plug.isLocked(): print("Attribute is locked")`
- `setLocked(True/False)`：设置属性的锁定状态。

#### 连接查询
- `isConnected()`：检查 `MPlug` 是否有输入或输出连接。
  - 示例：`if plug.isConnected(): print("Plug is connected")`
- `source()`：返回输入连接的 `MPlug`（如果有）。
  - 示例：`source_plug = plug.source()`
- `destinations()`：返回所有输出连接的 `MPlug` 列表。
  - 示例：`dest_plugs = plug.destinations()`
- `connectedTo(destinations, source)`：返回与该 `MPlug` 连接的 `MPlug` 列表，`destinations=True` 查询输出，`source=True` 查询输入。
  - 示例：`connected_plugs = plug.connectedTo(True, False)`

#### 层级和数组操作
- `child(index)`：访问复合属性的子属性 `MPlug`。
  - 示例：`tx_plug = translate_plug.child(0)` 获取 `translateX`。
- `numChildren()`：返回复合属性的子属性数量。
  - 示例：`count = plug.numChildren()`
- `elementByLogicalIndex(index)`：访问数组属性的特定元素。
  - 示例：`element_plug = array_plug.elementByLogicalIndex(0)`
- `numElements()`：返回数组属性的元素数量。
  - 示例：`count = plug.numElements()`
- `isArray()`：检查 `MPlug` 是否为数组属性。
  - 示例：`if plug.isArray(): print("This is an array plug")`
- `isCompound()`：检查 `MPlug` 是否为复合属性。
  - 示例：`if plug.isCompound(): print("This is a compound plug")`

#### 属性信息
- `name()`：返回 `MPlug` 的完整名称（包括节点名和属性名，如 `pCube1.translateX`）。
  - 示例：`print(plug.name())`
- `attribute()`：返回对应的 `MObject`（`Attribute` 对象）。
  - 示例：`attr = plug.attribute()`
- `node()`：返回 `MPlug` 所属的节点的 `MObject`。
  - 示例：`node = plug.node()`

### 5. **使用示例**
以下是一些典型的使用场景：

### 6. **注意事项**
- **网络化 vs 非网络化**：
  - 使用 `findPlug(attr, True)` 获取网络化 `MPlug` 以查询连接关系。
  - 使用 `findPlug(attr, False)` 获取非网络化 `MPlug` 以高效操作值。
- **类型安全**：
  - 调用值操作方法（如 `asFloat`）时，确保 `MPlug` 的属性类型匹配，否则会抛出异常。
  - 示例：`asFloat()` 仅适用于浮点型属性。
- **性能**：
  - 频繁调用 `MPlug` 方法（如 `findPlug` 或连接查询）可能影响性能，建议缓存 `MPlug` 实例。
- **数组和复合属性**：
  - 处理数组属性时，检查 `numElements()` 以避免访问无效索引。
  - 处理复合属性时，使用 `child()` 访问子属性。
- **脏状态**：
  - 修改 `MPlug` 的值会标记依赖图为“脏”（dirty），可能触发其他节点的重新计算。
- **线程安全**：
  - `MPlug` 操作不是线程安全的，建议在 Maya 主线程中执行。

### 7. **与 Attribute 的关系**
- `MPlug` 是 `Attribute`（`MFnAttribute` 创建的属性定义）在特定节点上的实例。
- 一个 `Attribute` 可以在多个节点上生成不同的 `MPlug`，每个 `MPlug` 存储该节点上属性的值或连接。
- 例如，`translateX` 是一个 `Attribute`，而 `pCube1.translateX` 和 `pSphere1.translateX` 是两个不同的 `MPlug`。

### 8. **总结**
`OpenMaya.MPlug` 是 Maya Python API 2.0 中用于操作节点属性实例的核心类，提供了读取/设置值、查询连接和处理复合/数组属性的能力。它是依赖图中数据交互的关键组件，广泛用于自定义节点开发、场景分析和数据操作。根据任务需求选择网络化或非网络化的 `MPlug`，并注意类型安全和性能优化。

# attribute和plug的关系

在 **Maya Python API 2.0** 中，`attribute` 和 `plug` 是两个密切相关的概念，它们在节点和数据流的管理中扮演重要角色。以下是它们之间的关系以及详细介绍：

### 1. **基本概念**
- **Attribute（属性）**：
  - `Attribute` 是 Maya 节点上定义的数据接口，代表节点可以存储或处理的数据点。它可以看作是节点的“属性定义”，描述了数据的类型、名称、默认值、行为（如是否可连接、是否可设置等）。
  - 在 Maya 中，属性分为动态属性（Dynamic Attribute）和内置属性（Built-in Attribute）。动态属性由用户通过脚本或界面添加，而内置属性由 Maya 的节点类型预定义。
  - 在 Python API 2.0 中，属性通常通过 `OpenMaya.MFnAttribute` 或其子类（如 `MFnNumericAttribute`、`MFnTypedAttribute` 等）来创建和操作。
  - 属性是静态的元数据，定义了节点的结构和行为，但本身不存储具体的值。

- **Plug（插头）**：
  - `Plug` 是属性在特定节点实例上的具体“连接点”或“实例化”。它表示一个节点上的某个属性的值或连接状态。
  - 在 Python API 2.0 中，`Plug` 由 `OpenMaya.MPlug` 类表示。它可以用来获取或设置属性的值，或者查询属性的连接关系（如输入或输出连接）。
  - `Plug` 是动态的，代表了属性在运行时的具体状态，比如某个属性的当前值或它与其他节点的连接。

### 2. **Attribute 和 Plug 的关系**
- **一对多的关系**：
  - 一个 `Attribute` 定义了一个属性的模板，而一个节点上的这个属性会实例化为一个或多个 `Plug`。
  - 例如，同一个 `Attribute`（如 `translateX`）在不同节点实例上会有不同的 `Plug`，每个 `Plug` 存储该节点上该属性的具体值或连接。
  - 如果属性是数组类型（如 `float[3]`），则一个 `Attribute` 可以对应多个 `Plug`（例如，`translate[0]`、`translate[1]`、`translate[2]`）。

- **属性的元数据 vs 插头的实例数据**：
  - `Attribute` 定义了属性的元数据，比如名称、类型（浮点、整数、字符串等）、默认值、可连接性等。它通过 `MFnAttribute` 创建并添加到节点类型（`MFnDependencyNode` 或 `MPxNode`）。
  - `Plug` 是 `Attribute` 在某个节点上的具体实例，用于存储或访问属性的值、检查连接状态或修改数据流。

- **连接与数据流**：
  - 在 Maya 的依赖图（Dependency Graph）中，节点之间的数据传递通过 `Plug` 之间的连接实现。一个节点的输出 `Plug` 可以连接到另一个节点的输入 `Plug`，而这些 `Plug` 都是基于它们对应的 `Attribute` 定义的。
  - 例如，`node1.translateX`（一个 `Plug`）可以连接到 `node2.translateX`（另一个 `Plug`），但前提是这两个 `Plug` 对应的 `Attribute` 类型兼容。

### 3. **在代码中的体现**
在 Maya Python API 2.0 中，`Attribute` 和 `Plug` 的操作通常如下：

#### 创建 Attribute
使用 `OpenMaya.MFn*Attribute` 类来定义属性并添加到节点。例如：

```python
import maya.OpenMaya as OpenMaya

def initialize():
    nAttr = OpenMaya.MFnNumericAttribute()
    MyNode.myAttribute = nAttr.create("myAttribute", "ma", OpenMaya.MFnNumericData.kFloat, 0.0)
    nAttr.setStorable(True)
    nAttr.setWritable(True)
    nAttr.setReadable(True)
    MyNode.addAttribute(MyNode.myAttribute)
```

- 这里 `myAttribute` 是一个 `Attribute`，定义了一个浮点型属性，添加到自定义节点 `MyNode` 上。

#### 操作 Plug
使用 `OpenMaya.MPlug` 来访问或修改节点上某个属性的值或连接。例如：

```python
import maya.OpenMaya as OpenMaya

def compute(self, plug, dataBlock):
    if plug == MyNode.myAttribute:
        dataHandle = dataBlock.inputValue(MyNode.myAttribute)
        value = dataHandle.asFloat()
        print(f"Current value of myAttribute: {value}")
        # 修改值
        outputHandle = dataBlock.outputValue(MyNode.myAttribute)
        outputHandle.setFloat(value + 1.0)
        dataBlock.setClean(plug)
    return OpenMaya.MStatus.kSuccess
```

- 这里 `plug` 是一个 `MPlug` 实例，表示某个节点上的 `myAttribute` 属性。通过 `MPlug`，可以读取或设置属性的值，或者检查其连接状态。

### 4. **关键区别与联系**
- **定义 vs 实例**：
  - `Attribute` 是属性的定义，存在于节点类型的元数据中，描述属性的行为和限制。
  - `Plug` 是属性的实例，存在于具体节点上，包含实际的数据或连接信息。
- **生命周期**：
  - `Attribute` 在节点类型初始化时定义，通常在插件的 `initialize` 方法中创建。
  - `Plug` 在节点实例化后存在，可以通过 `MPlug` 类动态查询或操作。
- **用途**：
  - `Attribute` 用于定义节点的接口和行为（如是否可连接、是否存储值等）。
  - `Plug` 用于运行时的数据操作（如获取值、设置值、建立连接）。

### 5. **注意事项**
- **兼容性**：确保连接的 `Plug` 对应的 `Attribute` 类型匹配，否则会导致连接失败或运行时错误。
- **数组属性**：对于数组类型的 `Attribute`，需要通过 `MPlug.elementByLogicalIndex()` 或 `MPlug.elementByPhysicalIndex()` 访问具体的 `Plug`。
- **性能**：频繁操作 `MPlug`（如查询值或连接）可能影响性能，建议在 `compute` 方法中优化逻辑。
- **脏状态**：修改 `Plug` 的值会影响依赖图的脏状态（dirty state），可能触发其他节点的重新计算。

### 6. **总结**
- `Attribute` 是节点的静态属性定义，描述了数据的类型和行为。
- `Plug` 是属性的动态实例，代表节点上属性的具体值或连接。
- 在 Maya Python API 2.0 中，`Attribute` 通过 `MFnAttribute` 创建，`Plug` 通过 `MPlug` 操作，二者共同构成了 Maya 依赖图的核心机制，用于实现节点的数据管理和计算。
