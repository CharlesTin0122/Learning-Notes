在 Autodesk Maya 的 Python API 2.0（`maya.api.OpenMaya`）中，`MGlobal` 是一个核心模块，提供了与 Maya 的全局功能交互的静态方法。它充当了 Maya 环境的全局接口，用于管理场景、选择、命令执行、错误处理以及其他全局设置。`MGlobal` 是开发者在编写插件或脚本时常用的工具，尤其在需要访问或修改 Maya 场景状态、执行命令或获取环境信息时。以下是对 `MGlobal` 的全面介绍，包括其功能、关键方法、典型用法和注意事项。

---

### 1. **什么是 `MGlobal`？**
- **定义**：`MGlobal` 是 `maya.api.OpenMaya` 模块中的一个类，包含一组静态方法，用于与 Maya 的全局环境交互。它提供了对场景管理、选择列表、命令执行、错误日志等的访问。
- **作用**：
  - 管理全局选择列表（`MSelectionList`）。
  - 执行 MEL 或 Python 命令。
  - 获取和设置 Maya 的全局状态（如时间、单位、视图设置）。
  - 提供错误和警告的日志功能。
  - 访问 Maya 的场景信息（如对象、节点）。
- **典型应用场景**：
  - 获取或设置当前选定的对象。
  - 执行 MEL 命令（如创建节点或设置属性）。
  - 检查 Maya 的运行环境（如 API 版本、UI 状态）。
  - 显示错误或警告信息。

- **模块位置**：`MGlobal` 位于 `maya.api.OpenMaya` 模块中，通常通过以下方式导入：
  ```python
  import maya.api.OpenMaya as om
  ```

### 2. **核心功能**
`MGlobal` 提供了丰富的静态方法，涵盖以下主要功能领域：

#### **2.1 选择列表管理**
- 管理 Maya 的全局选择列表（`MSelectionList`），用于获取或设置当前选定的对象。
- 常用方法：
  - **`getActiveSelectionList()`**：
    - 返回当前场景的活动选择列表（`MSelectionList`）。
    - 示例：
      ```python
      selection_list = om.MGlobal.getActiveSelectionList()
      for i in range(selection_list.length()):
          dag_path = selection_list.getDagPath(i)
          print(dag_path.fullPathName())
      ```
  - **`setActiveSelectionList(selection_list, listAdjustment=MGlobal.kReplaceList)`**：
    - 设置当前选择列表。
    - 参数 `listAdjustment` 控制选择行为：`kReplaceList`（替换）、`kAddToList`（添加）、`kRemoveFromList`（移除）。
    - 示例：
      ```python
      selection_list = om.MSelectionList()
      selection_list.add("pCube1")
      om.MGlobal.setActiveSelectionList(selection_list)
      ```
  - **`getSelectionListByName(name)`**：
    - 根据节点名称获取选择列表。
    - 示例：
      ```python
      selection_list = om.MGlobal.getSelectionListByName("pCube*")
      ```

#### **2.2 命令执行**
- 执行 MEL 或 Python 命令，允许在 API 中调用 Maya 的命令系统。
- 常用方法：
  - **`executeCommand(command, result, displayEnabled, undoEnabled)`**：
    - 执行 MEL 命令并返回结果。
    - 参数：
      - `command`：MEL 命令字符串。
      - `result`：输出结果（列表或单个值）。
      - `displayEnabled`：是否在 Maya 的命令窗口显示输出。
      - `undoEnabled`：是否支持撤销。
    - 示例：
      ```python
      result = []
      om.MGlobal.executeCommand("ls -sl", result, True, True)
      print(result)  # 输出当前选择的对象
      ```
  - **`executeCommandStringResult(command, displayEnabled=False, undoEnabled=False)`**：
    - 执行 MEL 命令并返回字符串结果。
    - 示例：
      ```python
      node_name = om.MGlobal.executeCommandStringResult("createNode transform")
      print(node_name)  # 输出新创建的节点名称
      ```
  - **`executePythonCommand(command, result)`**：
    - 执行 Python 命令。
    - 示例：
      ```python
      result = []
      om.MGlobal.executePythonCommand("import maya.cmds as cmds; cmds.ls(sl=True)", result)
      print(result)
      ```

#### **2.3 错误和日志管理**
- 提供显示错误、警告和信息的功能。
- 常用方法：
  - **`displayInfo(message)`**：
    - 在 Maya 的命令窗口或状态栏显示信息。
    - 示例：
      ```python
      om.MGlobal.displayInfo("Operation completed successfully")
      ```
  - **`displayWarning(message)`**：
    - 显示警告信息。
    - 示例：
      ```python
      om.MGlobal.displayWarning("Invalid selection")
      ```
  - **`displayError(message)`**：
    - 显示错误信息，通常会导致脚本停止。
    - 示例：
      ```python
      om.MGlobal.displayError("Failed to process node")
      ```

#### **2.4 全局状态管理**
- 获取或设置 Maya 的全局状态，如时间、单位、视图等。
- 常用方法：
  - **`mayaState()`**：
    - 返回 Maya 的运行状态（`kInteractive`, `kBatch`, `kLibraryApp`）。
    - 示例：
      ```python
      if om.MGlobal.mayaState() == om.MGlobal.kInteractive:
          print("Running in interactive mode")
      ```
  - **`currentTime()`**：
    - 获取当前时间（帧）。
    - 示例：
      ```python
      time = om.MGlobal.currentTime()
      print(f"Current time: {time}")
      ```
  - **`setTime(time)`**：
    - 设置当前时间。
    - 示例：
      ```python
      om.MGlobal.setTime(10.0)  # 设置时间为第 10 帧
      ```

#### **2.5 场景管理**
- 访问场景中的对象或节点。
- 常用方法：
  - **`getRichSelection()`**：
    - 返回扩展的选择列表（`MRichSelection`），包括软选择和对称选择信息。
    - 示例：
      ```python
      rich_selection = om.MGlobal.getRichSelection()
      selection_list = rich_selection.getSelection()
      ```
  - **`clearSelectionList()`**：
    - 清空当前选择列表。
    - 示例：
      ```python
      om.MGlobal.clearSelectionList()
      ```

#### **2.6 其他功能**
- **设置选项变量**：
  - **`setOptionVarValue(name, value)`**：设置 Maya 的选项变量（持久化设置）。
  - 示例：
    ```python
    om.MGlobal.setOptionVarValue("myOption", 1)
    ```
- **获取 API 版本**：
  - **`apiVersion()`**：返回当前 Maya API 的版本。
  - 示例：
    ```python
    version = om.MGlobal.apiVersion()
    print(f"Maya API version: {version}")
    ```

### 3. **典型用法**
以下是一些典型的使用场景，展示 `MGlobal` 的功能：

#### **3.1 获取当前选择并操作**
获取当前选定的对象并打印其路径：
```python
import maya.api.OpenMaya as om

selection_list = om.MGlobal.getActiveSelectionList()
for i in range(selection_list.length()):
    dag_path = selection_list.getDagPath(i)
    print(f"Selected: {dag_path.fullPathName()}")
```

#### **3.2 执行 MEL 命令**
创建节点并设置属性：
```python
result = []
om.MGlobal.executeCommand("createNode transform -n myNode", result, True, True)
om.MGlobal.executeCommand("setAttr myNode.translateX 5.0")
```

#### **3.3 显示错误信息**
在操作失败时显示错误：
```python
try:
    selection_list = om.MGlobal.getActiveSelectionList()
    dag_path = selection_list.getDagPath(0)
except RuntimeError:
    om.MGlobal.displayError("No objects selected")
```

#### **3.4 设置选择列表**
选择场景中的特定对象：
```python
selection_list = om.MSelectionList()
selection_list.add("pCube1")
om.MGlobal.setActiveSelectionList(selection_list, om.MGlobal.kReplaceList)
```

#### **3.5 检查 Maya 运行模式**
根据运行模式执行不同逻辑：
```python
if om.MGlobal.mayaState() == om.MGlobal.kBatch:
    print("Running in batch mode, skipping UI operations")
else:
    om.MGlobal.displayInfo("Running in interactive mode")
```

### 4. **结合其他类的使用**
`MGlobal` 常与其他 Maya API 类协作，以下是一些常见组合：

- **`MSelectionList`**：
  - 用于处理选择列表，`MGlobal.getActiveSelectionList` 和 `setActiveSelectionList` 是主要入口。
  - 示例：
    ```python
    selection_list = om.MSelectionList()
    selection_list.add("pSphere1")
    om.MGlobal.setActiveSelectionList(selection_list)
    ```

- **`MDagPath`**：
  - 从 `MSelectionList` 获取 `MDagPath`，用于操作场景中的 DAG 节点。
  - 示例：
    ```python
    dag_path = om.MGlobal.getActiveSelectionList().getDagPath(0)
    print(dag_path.fullPathName())
    ```

- **`MFnDagNode` 和 `MFnDependencyNode`**：
  - 用于操作节点的属性或层次结构。
  - 示例：
    ```python
    dag_path = om.MGlobal.getActiveSelectionList().getDagPath(0)
    dag_node = om.MFnDagNode(dag_path)
    print(dag_node.fullPathName())
    ```

- **`MPxContext` 和 `MPxToolCommand`**：
  - 在自定义交互工具中，`MGlobal` 用于获取选择或执行命令。
  - 示例：
    ```python
    class CustomContext(omui.MPxContext):
        def doPress(self, event):
            selection_list = om.MGlobal.getActiveSelectionList()
            if not selection_list.isEmpty():
                om.MGlobal.displayInfo("Selection detected")
    ```

### 5. **注意事项**
1. **线程安全**：
   - `MGlobal` 的方法不是线程安全的，必须在 Maya 的主线程中调用（例如 Script Editor 或插件环境）。
   - 避免在多线程环境中使用 `MGlobal`。

2. **性能考虑**：
   - 频繁调用 `executeCommand` 可能影响性能，建议缓存结果或使用 API 方法替代 MEL 命令。
   - 示例：用 `MFnDependencyNode.setAttr` 替代 `executeCommand("setAttr ...")`。

3. **错误处理**：
   - 使用 `try-except` 捕获选择或命令执行中的异常。
   - 示例：
     ```python
     try:
         dag_path = om.MGlobal.getActiveSelectionList().getDagPath(0)
     except RuntimeError:
         om.MGlobal.displayError("No valid selection")
     ```

4. **命令执行的撤销支持**：
   - 使用 `executeCommand` 时，设置 `undoEnabled=True` 以支持撤销，但需确保命令本身支持撤销。
   - 示例：
     ```python
     om.MGlobal.executeCommand("createNode transform", undoEnabled=True)
     ```

5. **兼容性**：
   - `MGlobal` 的方法在不同 Maya 版本中可能有细微差异，建议检查 `apiVersion` 或文档以确保兼容性。
