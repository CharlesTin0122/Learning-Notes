在 Maya Python API 2.0 中，`MAnimCurveChange` 是 `OpenMayaAnim` 模块（`maya.api.OpenMayaAnim`）中的一个类，用于管理动画曲线的更改操作，并支持撤销和重做功能。它主要用于在修改动画曲线（例如通过 `MFnAnimCurve` 类操作关键帧）时，记录这些更改以便在 Maya 的撤销栈中正确处理。

以下是对 `MAnimCurveChange` 的详细介绍：

### 1. **作用与功能**
`MAnimCurveChange` 是一个缓存类，用于存储动画曲线的修改操作，例如添加、移除或调整关键帧、设置切线角度等。这些修改会被记录下来，以便在用户执行撤销（Undo）或重做（Redo）操作时，Maya 能够正确恢复或重新应用这些更改。

- **支持撤销/重做**：通过 `MAnimCurveChange`，开发者可以确保动画曲线的修改操作与 Maya 的撤销栈兼容。
- **性能优化**：它允许批量记录更改，而不是每次修改都直接影响场景，从而提高性能。
- **典型使用场景**：在脚本或插件中修改动画曲线（如插入关键帧、移除关键帧、更改切线类型等）时，使用 `MAnimCurveChange` 来确保这些操作是可逆的。

### 2. **关键方法**
`MAnimCurveChange` 本身没有直接的公共方法用于修改动画曲线，而是作为一个参数传递给 `MFnAnimCurve` 的方法，以跟踪更改。以下是一些与 `MAnimCurveChange` 相关的典型用法，结合 `MFnAnimCurve` 的方法：

- **创建实例**：
  ```python
  import maya.api.OpenMayaAnim as oma
  change = oma.MAnimCurveChange()
  ```
  创建一个 `MAnimCurveChange` 实例，用于缓存后续的动画曲线更改。

- **与 `MFnAnimCurve` 结合使用**：
  `MAnimCurveChange` 通常作为可选参数传递给 `MFnAnimCurve` 的方法。例如：
  - `addKey(time, breakdown=False, change=None)`：插入一个关键帧，`change` 参数可以传入 `MAnimCurveChange` 实例以记录操作。
  - `remove(index, change=None)`：移除指定索引的关键帧，`change` 用于记录移除操作。
  - `setAngle(index, setAngle, isInTangent, change=None)`：设置关键帧的切线角度，`change` 记录角度更改。
  - `addKeys(times, values, tangentInType=kTangentGlobal, tangentOutType=kTangentGlobal, keepExistingKeys=False, change=None)`：批量添加关键帧，`change` 记录所有添加操作。

  示例：
  ```python
  import maya.api.OpenMaya as om
  import maya.api.OpenMayaAnim as oma

  # 获取动画曲线
  selection_list = om.MSelectionList()
  selection_list.add('pCube1_translateX')  # 假设这是一个动画曲线的名称
  mcurve = oma.MFnAnimCurve(selection_list.getDependNode(0))

  # 创建 MAnimCurveChange 实例
  change = oma.MAnimCurveChange()

  # 添加一个关键帧并记录更改
  mcurve.addKey(om.MTime(1.0), 10.0, change=change)

  # 执行撤销
  change.undoIt()

  # 执行重做
  change.redoIt()
  ```

- **撤销与重做**：
  - `undoIt()`：撤销所有记录在 `MAnimCurveChange` 实例中的动画曲线更改。
  - `redoIt()`：重新应用所有记录的更改。

### 3. **注意事项**
- **撤销栈管理**：`MAnimCurveChange` 的使用确保了动画曲线修改操作可以被 Maya 的撤销系统正确处理。如果不使用 `MAnimCurveChange`，直接修改动画曲线可能导致撤销栈损坏或操作不可逆。
- **对象生命周期**：`MAnimCurveChange` 实例需要保持活动状态，直到撤销或重做操作完成。如果 Python 垃圾回收器提前回收了该对象，可能会导致撤销/重做失败。
- **API 版本兼容性**：`MAnimCurveChange` 是 Maya Python API 2.0 的一部分（`maya.api.OpenMayaAnim`），不要与 API 1.0 的对象混用（如 `maya.OpenMayaAnim` 中的对象），否则可能导致类型不兼容错误。[](https://www.dilenshah.com/post/maya-python-api-2-0)
- **性能考虑**：对于大量关键帧操作，`MAnimCurveChange` 可以显著减少对场景的直接修改，提高脚本执行效率。

### 4. **实际应用示例**
以下是一个完整的示例，展示如何使用 `MAnimCurveChange` 来添加和移除关键帧，并支持撤销/重做：

```python
import maya.api.OpenMaya as om
import maya.api.OpenMayaAnim as oma

def modify_anim_curve():
    # 获取动画曲线
    sel_list = om.MSelectionList()
    sel_list.add('pCube1_translateX')  # 假设 pCube1.translateX 已连接到一个动画曲线
    mcurve = oma.MFnAnimCurve(sel_list.getDependNode(0))

    # 创建 MAnimCurveChange 实例
    change = oma.MAnimCurveChange()

    # 添加关键帧
    mcurve.addKey(om.MTime(5.0), 20.0, change=change)
    print("Added keyframe at time 5.0 with value 20.0")

    # 移除关键帧（假设索引 0 处有一个关键帧）
    mcurve.remove(0, change=change)
    print("Removed keyframe at index 0")

    # 撤销更改
    change.undoIt()
    print("Undid changes")

    # 重做更改
    change.redoIt()
    print("Redid changes")

# 执行函数
modify_anim_curve()
```

### 5. **与 Maya 命令的对比**
`MAnimCurveChange` 的功能类似于 `maya.cmds` 中的 `setKeyframe` 或 `keyframe` 命令（例如 `maya.cmds.setKeyframe(insert=True)`），但通过 API 2.0 提供的控制更加底层和高效。使用 `MAnimCurveChange` 的主要优势在于：
- 直接操作底层动画曲线数据，性能更高。
- 提供更细粒度的控制，例如可以单独修改切线类型或关键帧属性。
- 更好地集成到自定义插件或复杂工具中。
