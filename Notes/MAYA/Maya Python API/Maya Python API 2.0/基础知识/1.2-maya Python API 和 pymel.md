PyMEL 是 Autodesk Maya 的一个第三方 Python 库，构建在 Maya 的 Python API（包括 API 1.0 和 API 2.0）以及 Maya 的命令模块（`maya.cmds`）之上，旨在提供更简洁、面向对象的方式来操作 Maya 场景。PyMEL 与 Maya Python API（特别是 `maya.api.OpenMaya` 和 `maya.api.OpenMayaUI`）之间的交互是许多高级 Maya 开发者的常见需求，因为两者各有优势，可以结合使用以实现更高效的开发流程。以下是对 PyMEL 和 Maya Python API 交互的全面介绍，包括它们的区别、交互方式、典型用例以及注意事项。

---
```python
import maya.api.OpenMaya as om
import pymel.core as pm

node = pm.PyNode("locator1")
# 获取节点的API类'MFnTransform'
node.__apicls__() # 'MFnTransform'
# 返回节点的 MObjectHandle，这是一个封装 MObject 的句柄对象，用于跟踪节点是否有效（即使节点被重命名或删除）。
node.__apihandle__()# 'MObjectHandle *'
# 返回节点的 MDagPath，表示 DAG 节点在场景层次结构中的路径。
node.__apimdagpath__()# 'MDagPath *'
# 返回与节点类型对应的 Maya API 函数集实例（MFn* 类）
node.__apimfn__() # 'MFnTransform *'
# 返回节点的 MObject，表示 Maya 依赖图中的节点对象。
node.__apimobject__()# 'MObject *'
# 返回节点的底层 Maya API 对象，优先返回 MDagPath（对于 DAG 节点）或 MObject（对于依赖节点）。
node.__apiobject__() # 'MDagPath *' 
# 返回 'MDagPath *', 'MFnTransform *', 'MObjectHandle *'，
node.__apiobjects__ # 'MDagPath *'，'MFnTransform *'，'MObjectHandle *'
```
### 1. **PyMEL 和 Maya Python API 的概述**

#### **1.1 PyMEL 简介**
- **定义**：PyMEL 是一个开源 Python 库，封装了 `maya.cmds` 和部分 Maya API，提供面向对象的接口来操作 Maya 场景中的节点、属性、变换等。
- **特点**：
  - **面向对象**：将 Maya 节点包装为类（如 `pymel.core.PyNode`），支持属性访问（如 `node.translateX`）和方法调用。
  - **简洁易用**：语法更直观，减少了 `maya.cmds` 的冗长命令。
  - **兼容性**：内置对 `maya.cmds` 的支持，部分功能调用底层 API。
  - **广泛使用**：适合快速脚本编写和场景管理。
- **模块**：`pymel.core` 是主要模块，提供了节点操作、场景管理和 UI 相关的功能。
- **示例**：
  ```python
  import pymel.core as pm
  cube = pm.polyCube(name="myCube")[0]  # 创建立方体
  cube.translateX.set(5.0)  # 设置平移
  print(cube.translateX.get())  # 获取平移值
  ```

#### **1.2 Maya Python API 简介**
- **定义**：Maya Python API（包括 API 1.0 和 API 2.0）是 Maya 提供的低级接口，允许直接访问 Maya 的核心数据结构（如 `MObject`、`MDagPath`）和功能（如依赖图、视图交互）。
- **特点**：
  - **低级控制**：提供对 Maya 底层数据结构的直接访问，适合高性能插件开发。
  - **复杂但强大**：需要手动管理对象（如 `MObject`、`MDataBlock`），但支持自定义节点、上下文和渲染逻辑。
  - **模块**：
    - `maya.api.OpenMaya`：核心功能（节点、依赖图、变换）。
    - `maya.api.OpenMayaUI`：UI 和视图交互。
    - `maya.api.OpenMayaRender`：Viewport 2.0 渲染。
- **示例**：
  ```python
  import maya.api.OpenMaya as om
  selection_list = om.MGlobal.getActiveSelectionList()
  dag_path = selection_list.getDagPath(0)
  transform_fn = om.MFnTransform(dag_path)
  transform_fn.setTranslation(om.MVector(5, 0, 0), om.MSpace.kWorld)
  ```

#### **1.3 两者的主要区别**
| 特性                     | PyMEL                              | Maya Python API                     |
|--------------------------|------------------------------------|-------------------------------------|
| **接口风格**             | 面向对象，简洁直观                | 面向过程，低级控制                  |
| **易用性**               | 高，适合快速脚本编写              | 较低，需熟悉 Maya 数据结构          |
| **性能**                 | 较慢（封装层开销）                | 更快（直接访问底层）                |
| **功能覆盖**             | 覆盖常用场景，部分高级功能缺失    | 覆盖所有 Maya 功能，包括自定义插件Robert

### 2. **PyMEL 和 Maya Python API 的交互方式**
PyMEL 和 Maya Python API 之间的交互主要通过以下机制实现：
- **PyMEL 对象与 API 对象的转换**：PyMEL 的节点对象（如 `pymel.core.PyNode`）可以转换为 Maya API 的 `MObject` 或 `MDagPath`，反之亦然。
- **调用底层 API**：PyMEL 内部使用 `maya.cmds` 和 Maya API 实现功能，开发者可以直接访问 PyMEL 对象的底层 API 数据。
- **混合使用**：在脚本或插件中，开发者可以结合 PyMEL 的简洁性和 API 的高性能或高级功能。

#### **2.1 PyMEL 到 Maya Python API 的转换**
PyMEL 提供了方法来获取底层 Maya API 对象（`MObject` 或 `MDagPath`），以便在需要时使用 API 进行低级操作：
- **`PyNode.__apiobject__()`**：
  - 返回节点的 `MObject`。
  - 示例：
    ```python
    import pymel.core as pm
    import maya.api.OpenMaya as om

    cube = pm.PyNode("pCube1")  # PyMEL 节点
    mobject = cube.__apiobject__()  # 获取 MObject
    dag_node = om.MFnDagNode(mobject)
    print(dag_node.fullPathName())  # 输出节点路径
    ```
- **`PyNode.__apimdagpath__()`**：
  - 返回节点的 `MDagPath`（适用于 DAG 节点）。
  - 示例：
    ```python
    dag_path = cube.__apimdagpath__()
    transform_fn = om.MFnTransform(dag_path)
    translation = transform_fn.translation(om.MSpace.kWorld)
    print(f"Translation: {translation}")
    ```

#### **2.2 Maya Python API 到 PyMEL 的转换**
从 Maya API 的对象（如 `MObject` 或 `MDagPath`）可以转换为 PyMEL 的 `PyNode` 对象：
- **`pymel.core.PyNode(mobject)`**：
  - 将 `MObject` 或 `MDagPath` 转换为 PyMEL 的 `PyNode`。
  - 示例：
    ```python
    selection_list = om.MGlobal.getActiveSelectionList()
    dag_path = selection_list.getDagPath(0)
    py_node = pm.PyNode(dag_path)
    py_node.translateX.set(10.0)  # 使用 PyMEL 设置属性
    ```

#### **2.3 混合使用的场景**
- **场景 1：使用 PyMEL 简化选择，API 执行高性能操作**
  - PyMEL 适合快速获取节点或选择，而 API 适合高效的操作（如批量变换）。
  - 示例：
    ```python
    # 使用 PyMEL 获取选定对象
    selected = pm.selected()
    for node in selected:
        mobject = node.__apiobject__()
        transform_fn = om.MFnTransform(mobject)
        transform_fn.setTranslation(om.MVector(0, 5, 0), om.MSpace.kWorld)
    ```

- **场景 2：自定义节点插件**
  - 在自定义 `MPxNode` 中，使用 API 定义节点和计算逻辑，使用 PyMEL 处理用户输入或场景操作。
  - 示例：
    ```python
    class CustomNode(om.MPxNode):
        input_attr = om.MObject()

        @staticmethod
        def initialize():
            n_attr = om.MFnNumericAttribute()
            CustomNode.input_attr = n_attr.create("input", "in", om.MFnNumericData.kFloat)
            CustomNode.addAttribute(CustomNode.input_attr)

        def compute(self, plug, data):
            input_handle = data.inputValue(CustomNode.input_attr)
            input_value = input_handle.asFloat()
            # 使用 PyMEL 操作其他节点
            pm_node = pm.PyNode(data.context().thisNode())
            pm_node.output.set(input_value * 2)
    ```

- **场景 3：交互工具**
  - 在 `MPxContext` 中，使用 PyMEL 获取节点或属性，使用 API 处理交互逻辑。
  - 示例：
    ```python
    class CustomContext(omui.MPxContext):
        def doPress(self, event):
            selected = pm.selected()  # 使用 PyMEL 获取选择
            if selected:
                dag_path = selected[0].__apimdagpath__()
                transform_fn = om.MFnTransform(dag_path)
                transform_fn.setTranslation(om.MVector(0, 5, 0), om.MSpace.kWorld)
    ```

### 3. **典型用例**
以下是一些结合 PyMEL 和 Maya Python API 的实际用例：

#### **3.1 批量移动选定对象**
- 使用 PyMEL 获取选定对象，API 执行高效变换：
  ```python
  selected = pm.selected()  # PyMEL 获取选择
  for node in selected:
      dag_path = node.__apimdagpath__()
      transform_fn = om.MFnTransform(dag_path)
      transform_fn.setTranslation(om.MVector(0, 5, 0), om.MSpace.kWorld)
  ```

#### **3.2 检查节点是否存在并设置属性**
- 使用 PyMEL 检查节点，API 修改属性：
  ```python
  if pm.objExists("pCube1"):
      cube = pm.PyNode("pCube1")
      mobject = cube.__apiobject__()
      dep_node = om.MFnDependencyNode(mobject)
      dep_node.findPlug("translateX", False).setFloat(10.0)
  ```

#### **3.3 创建自定义节点并连接**
- 使用 API 定义节点，PyMEL 连接属性：
  ```python
  class CustomNode(om.MPxNode):
      input_attr = om.MObject()
      output_attr = om.MObject()

      @staticmethod
      def initialize():
          n_attr = om.MFnNumericAttribute()
          CustomNode.input_attr = n_attr.create("input", "in", om.MFnNumericData.kFloat)
          CustomNode.addAttribute(CustomNode.input_attr)
          CustomNode.output_attr = n_attr.create("output", "out", om.MFnNumericData.kFloat)
          CustomNode.addAttribute(CustomNode.output_attr)

      def compute(self, plug, data):
          input_handle = data.inputValue(CustomNode.input_attr)
          pm_node = pm.PyNode(data.context().thisNode())
          pm_node.output.set(input_handle.asFloat() * 2)

  # 使用 PyMEL 创建并连接节点
  node = pm.createNode("customNode")
  pm.connectAttr("pCube1.translateX", f"{node}.input")
  ```

#### **3.4 交互工具中混合使用**
- 在 `MPxContext` 中使用 PyMEL 获取选择，API 处理交互：
  ```python
  class CustomContext(omui.MPxContext):
      def doPress(self, event):
          selected = pm.selected()
  ```

### 4. **注意事项**
1. **性能考虑**：
   - PyMEL 的封装层增加了开销，适合快速开发，但在大规模场景操作时可能比直接使用 API 慢。
   - 对于性能敏感的操作（如批量处理数千个节点），优先使用 API。

2. **对象生命周期**：
   - API 对象（如 `MObject`, `MDagPath`）由 Maya 管理，需注意避免在 Python 中存储引用，以防止内存泄漏。
   - PyMEL 的 `PyNode` 对象自动管理生命周期，但转换为 API 对象后需谨慎处理。

3. **线程安全**：
   - 无论是 PyMEL 还是 Maya API，都不是线程安全的，必须在 Maya 主线程中调用。

4. **兼容性**：
   - PyMEL 基于 `maya.cmds` 和 API 1.0，部分功能可能未完全适配 API 2.0（尤其在较老的 Maya 版本中）。
   - 检查 Maya 版本和 PyMEL 版本以确保兼容性。

5. **错误处理**：
   - PyMEL 和 API 都需要妥善处理异常，例如节点不存在或选择为空。
   - 示例：
     ```python
     try:
         node = pm.PyNode("pCube1")
         mobject = node.__apiobject__()
     except pm.MayaNodeError:
         om.MGlobal.displayError("Node does not exist")
     ```

6. **调试**：
   - 使用 `om.MGlobal.displayInfo/Warning/Error` 或 `pm.warning` 输出调试信息。
   - 示例：
     ```python
     pm.warning("Processing node...")
     ```
