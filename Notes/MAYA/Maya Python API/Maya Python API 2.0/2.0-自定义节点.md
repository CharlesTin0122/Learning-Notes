# MPxNode

在 **Maya Python API 2.0** 中，`OpenMayaMPx.MPxNode` 是用于创建自定义节点的基类。它允许开发者定义新的节点类型，以扩展 Maya 的功能，实现自定义的计算逻辑、属性和依赖图行为。`MPxNode` 是 Maya 插件开发中的核心类，广泛用于创建自定义变形器、工具、动画节点等。以下是对 `MPxNode` 的详细介绍，包括其定义、功能、关键方法和使用示例。

### 1. **MPxNode 的定义**
- **MPxNode** 是 Maya Python API 2.0 提供的基类，位于 `OpenMayaMPx` 模块中，用于创建自定义依赖节点（Dependency Node）。
- 它继承自 Maya 的内部节点体系，允许开发者定义节点的属性（通过 `MFnAttribute`）、计算逻辑（通过 `compute` 方法）以及其他行为。
- 自定义节点可以集成到 Maya 的依赖图（Dependency Graph）中，与其他节点交互，处理输入输出数据。

### 2. **MPxNode 的作用**
- **自定义计算逻辑**：通过重写 `compute` 方法，定义节点如何根据输入属性计算输出属性。
- **属性管理**：通过 `MFnAttribute` 定义节点的输入和输出属性，控制其类型和行为。
- **依赖图集成**：支持在 Maya 的依赖图中与其他节点建立连接，参与数据流计算。
- **扩展功能**：用于实现自定义效果，如新的变形器、数学运算节点、控制器等。

### 3. **关键方法**
以下是 `MPxNode` 类的核心方法，开发者通常需要重写或使用这些方法：

#### 初始化相关
- `creator()`（静态方法）：
  - 创建节点实例，返回 `OpenMayaMPx.asMPxPtr` 包装的节点对象。
  - 示例：`return OpenMayaMPx.asMPxPtr(MyNode())`
- `initialize()`（静态方法）：
  - 定义节点的属性（使用 `MFnAttribute` 创建），并通过 `addAttribute` 添加到节点。
  - 设置属性之间的依赖关系（使用 `attributeAffects`）。
  - 示例：`MyNode.addAttribute(MyNode.inputAttr)`

#### 计算逻辑
- `compute(plug, dataBlock)`：
  - 核心方法，用于定义节点的计算逻辑。
  - 参数：
    - `plug`：需要计算的 `MPlug`（输出属性）。
    - `dataBlock`：`MDataBlock`，提供输入/输出数据的访问接口。
  - 返回：`OpenMaya.MStatus`（通常为 `kSuccess` 或 `kUnknownParameter`）。
  - 示例：根据输入值计算输出值并设置到 `dataBlock`。
- `setDependentsDirty(plug, plugArray)`：
  - 当输入属性变“脏”（dirty）时调用，允许开发者标记受影响的输出属性。
  - 用于优化依赖图更新，避免不必要的计算。

#### 属性管理
- `addAttribute(attr)`（类方法）：
  - 将通过 `MFnAttribute` 创建的属性添加到节点。
  - 示例：`MyNode.addAttribute(MyNode.inputAttr)`
- `attributeAffects(inputAttr, outputAttr)`（类方法）：
  - 定义输入属性如何影响输出属性，优化依赖图的计算。
  - 示例：`MyNode.attributeAffects(MyNode.inputAttr, MyNode.outputAttr)`

#### 其他方法
- `postConstructor()`：
  - 在节点构造后调用，可用于初始化节点状态。
- `isPassiveOutput(plug)`：
  - 检查输出属性是否为“被动”输出（不触发计算）。
- `shouldSave(plug)`：
  - 控制属性是否保存到文件中（默认基于 `MFnAttribute.setStorable`）。
- `connectionMade()` 和 `connectionBroken()`
	- 当插头连接或断开连接时被调用
	- 在连接变化时特殊处理很有用

### 4. **创建自定义节点的步骤**
1. **定义节点类**：
   - 继承 `OpenMayaMPx.MPxNode`。
   - 定义类级别的属性（`MObject`）存储节点的属性。
2. **实现 creator 方法**：
   - 返回节点实例。
3. **实现 initialize 方法**：
   - 创建属性（使用 `MFnAttribute` 或其子类）。
   - 添加属性到节点。
   - 设置属性依赖关系。
4. **实现 compute 方法**：
   - 定义输入到输出的计算逻辑。
5. **注册节点**：
   - 使用 `MFnPlugin.registerNode` 注册节点到 Maya。
6. **卸载节点**：
   - 使用 `MFnPlugin.deregisterNode` 卸载节点。

### 5. **使用示例**
以下是一个简单的自定义节点示例，实现一个浮点数加法节点：

```python
import maya.OpenMaya as OpenMaya
import maya.OpenMayaMPx as OpenMayaMPx

# 节点 ID（必须唯一）
kPluginNodeTypeName = "myAddNode"
kPluginNodeId = OpenMaya.MTypeId(0x87000)

class MyAddNode(OpenMayaMPx.MPxNode):
    # 定义属性
    input1Attr = OpenMaya.MObject()
    input2Attr = OpenMaya.MObject()
    outputAttr = OpenMaya.MObject()

    def __init__(self):
        OpenMayaMPx.MPxNode.__init__(self)

    @staticmethod
    def creator():
        return OpenMayaMPx.asMPxPtr(MyAddNode())

    @staticmethod
    def initialize():
        # 创建输入属性 1
        nAttr = OpenMaya.MFnNumericAttribute()
        MyAddNode.input1Attr = nAttr.create("input1", "in1", OpenMaya.MFnNumericData.kFloat, 0.0)
        nAttr.setStorable(True)
        nAttr.setWritable(True)
        nAttr.setKeyable(True)

        # 创建输入属性 2
        MyAddNode.input2Attr = nAttr.create("input2", "in2", OpenMaya.MFnNumericData.kFloat, 0.0)
        nAttr.setStorable(True)
        nAttr.setWritable(True)
        nAttr.setKeyable(True)

        # 创建输出属性
        MyAddNode.outputAttr = nAttr.create("output", "out", OpenMaya.MFnNumericData.kFloat, 0.0)
        nAttr.setStorable(False)
        nAttr.setWritable(False)
        nAttr.setReadable(True)

        # 添加属性到节点
        MyAddNode.addAttribute(MyAddNode.input1Attr)
        MyAddNode.addAttribute(MyAddNode.input2Attr)
        MyAddNode.addAttribute(MyAddNode.outputAttr)

        # 设置属性影响关系
        MyAddNode.attributeAffects(MyAddNode.input1Attr, MyAddNode.outputAttr)
        MyAddNode.attributeAffects(MyAddNode.input2Attr, MyAddNode.outputAttr)

    def compute(self, plug, dataBlock):
        if plug == MyAddNode.outputAttr:
            # 获取输入值
            input1Handle = dataBlock.inputValue(MyAddNode.input1Attr)
            input2Handle = dataBlock.inputValue(MyAddNode.input2Attr)
            input1 = input1Handle.asFloat()
            input2 = input2Handle.asFloat()

            # 计算输出
            outputHandle = dataBlock.outputValue(MyAddNode.outputAttr)
            outputHandle.setFloat(input1 + input2)
            dataBlock.setClean(plug)

        return OpenMaya.MStatus.kSuccess

# 插件初始化
def initializePlugin(mobject):
    mplugin = OpenMayaMPx.MFnPlugin(mobject)
    try:
        mplugin.registerNode(kPluginNodeTypeName, kPluginNodeId, MyAddNode.creator, MyAddNode.initialize)
    except:
        raise Exception("Unable to register node")

# 插件卸载
def uninitializePlugin(mobject):
    mplugin = OpenMayaMPx.MFnPlugin(mobject)
    try:
        mplugin.deregisterNode(kPluginNodeId)
    except:
        raise Exception("Unable to deregister node")
```

- **说明**：
  - 创建一个节点 `myAddNode`，接受两个浮点输入（`input1` 和 `input2`），输出它们的和（`output`）。
  - `initialize` 方法定义了属性并设置依赖关系。
  - `compute` 方法实现加法逻辑。
  - `initializePlugin` 和 `uninitializePlugin` 用于注册和卸载节点。

### 6. **MPxNode 与 Attribute/Plug 的关系**
- **Attribute**：
  - 通过 `MFnAttribute` 创建，定义节点的属性元数据。
  - 在 `initialize` 方法中添加到节点。
- **Plug**：
  - `MPlug` 是属性的实例，用于在 `compute` 方法中访问输入/输出值。
  - 通过 `MDataBlock.inputValue` 或 `outputValue` 获取。
- **关系**：
  - `MPxNode` 定义节点的逻辑，`MFnAttribute` 定义属性的结构，`MPlug` 提供运行时的值和连接。
  - 在 `compute` 方法中，`MPlug` 和 `MDataBlock` 结合使用，处理节点的输入输出。

### 7. **注意事项**
- **节点 ID**：
  - 每个自定义节点需要唯一的 `MTypeId`（通常从 0x80000 开始，避开 Maya 保留范围）。
- **性能优化**：
  - 在 `compute` 方法中，只处理请求的 `plug`，避免不必要的计算。
  - 使用 `attributeAffects` 明确依赖关系，减少依赖图的无效更新。
- **线程安全**：
  - `MPxNode` 的方法（如 `compute`）通常在 Maya 主线程中调用，不是线程安全的。
- **错误处理**：
  - 在 `compute` 方法中，返回 `kUnknownParameter` 对于无关的 `plug` 请求。
  - 检查 `MStatus` 返回值以处理潜在错误。
- **属性存储**：
  - 确保输入属性设置为 `storable=True`，输出属性通常为 `storable=False`。

### 8. **总结**
`OpenMayaMPx.MPxNode` 是 Maya Python API 2.0 中用于创建自定义节点的基类，提供了定义属性（通过 `MFnAttribute`）、实现计算逻辑（通过 `compute`）和集成到依赖图的能力。它是开发自定义工具、变形器或节点的核心组件。通过重写 `creator`、`initialize` 和 `compute` 方法，开发者可以实现灵活的节点功能。
# 案例
## 案例：两数相乘
- 一个数学节点，简单的两数相乘
```python
import maya.api.OpenMaya as om
import pymel.core as pm


def maya_useNewAPI():
    """告知maya使用maya Python api 2.0"""
    pass


class MultiplyNode(om.MPxNode):
    """简单两数相乘节点"""

    # 节点名称个节点ID
    TYPE_NAME = "multiplyNode"
    TYPE_ID = om.MTypeId(0x0007F7F8)

    # 节点属性：乘数、被乘数和积
    multiplier_obj = om.MObject
    multiplicand_obj = om.MObject
    product_obj = om.MObject

    def __init__(self):
        """构造函数"""
        super().__init__()

    def compute(self, plug, dataBlock):
        """重写计算函数，节点核心逻辑。
        Args:
            plug (MPlug): 属性句柄，maya请求拉取的plug
            dataBlock (MDataBlock): 节点数据容器
        """
        # 检查maya请求拉取的 plug 是否是当前节点输出属性
        if plug == MultiplyNode.product_obj:
            # 获取输入属性数值
            multiplier = dataBlock.inputValue(MultiplyNode.multiplier_obj).asInt()
            multiplicand = dataBlock.inputValue(
                MultiplyNode.multiplicand_obj
            ).asDouble()
            # 计算输出属性数值
            product = multiplier * multiplicand
            # 获取输出属性的 MDataHandle
            product_data_handle = dataBlock.outputValue(MultiplyNode.product_obj)
            # 设置输出属性数值
            product_data_handle.setDouble(product)
            # 数值输出plug为“净”
            dataBlock.setClean(plug)

    @classmethod
    def creator(cls):
        """节点创建器，返回实例"""
        return cls()

    @classmethod
    def initialize(cls):
        """节点初始化，初始化所有节点属性"""
        # 获取数字属性函数集
        numeric_attr = om.MFnNumericAttribute()

        # 创建属性
        cls.multiplier_obj = numeric_attr.create(
            "multiplier", "mul", om.MFnNumericData.kInt, 2
        )
        numeric_attr.keyable = True  # 属性可剋，插头出现在节点左侧
        numeric_attr.readable = False  # 属性不可读，插头不出现在节点右侧

        cls.multiplicand_obj = numeric_attr.create(
            "multiplicand", "mulc", om.MFnNumericData.kDouble, 0.0
        )
        numeric_attr.keyable = True
        numeric_attr.readable = False

        cls.product_obj = numeric_attr.create(
            "product", "prod", om.MFnNumericData.kDouble, 0.0
        )
        numeric_attr.writable = False  # 属性不可写，不会出现在属性编辑器中

        # 添加属性
        cls.addAttribute(cls.multiplier_obj)
        cls.addAttribute(cls.multiplicand_obj)
        cls.addAttribute(cls.product_obj)
        # 设置属性影响
        cls.attributeAffects(cls.multiplier_obj, cls.product_obj)
        cls.attributeAffects(cls.multiplicand_obj, cls.product_obj)


def initializePlugin(plugin):
    vendor = "Charles Tian"
    version = "1.0.0"
    plugin_fn = om.MFnPlugin(plugin, vendor, version)
    try:
        plugin_fn.registerNode(
            MultiplyNode.TYPE_NAME,
            MultiplyNode.TYPE_ID,
            MultiplyNode.creator,
            MultiplyNode.initialize,
            om.MPxNode.kDependNode,
        )
    except Exception as e:
        om.MGlobal.displayError(
            f"Failed to register Node: {MultiplyNode.typeName}, {e}"
        )


def uninitializePlugin(plugin):
    plugin_fn = om.MFnPlugin(plugin)
    try:
        plugin_fn.deregisterNode(MultiplyNode.TYPE_ID)
    except Exception as e:
        om.MGlobal.displayError(
            f"Failed to deregister Node: {MultiplyNode.typeName}, {e}"
        )


if __name__ == "__main__":
    pm.newFile(force=True)

    plugin_name = "multiply_node"

    pm.unloadPlugin(plugin_name)

    pm.loadPlugin(plugin_name)

    node_name = "multiplyNode"
    pm.createNode(node_name)

```
## 案例：轮子滚动节点

- 算法：旋转= 移动距离 / 轮子周长 * 360 = distance / 2πr * 2π = distance / radius
- 
```python
import maya.api.OpenMaya as om
import pymel.core as pm


def maya_useNewAPI():
    """告知maya使用maya Python api 2.0"""
    pass


class RollingNode(om.MPxNode):
    """轮子转动节点"""

    # 节点名称个节点ID
    TYPE_NAME = "rollingNode"
    TYPE_ID = om.MTypeId(0x0007F7F9)

    # 定义属性，属性定义为类属性而不是实例属性
    inRadius = om.MObject()
    inDistance = om.MObject()
    outRotation = om.MObject()

    def __init__(self):
        """构造函数"""
        super().__init__()

    def compute(self, plug, dataBlock):
        """重写计算函数，节点核心逻辑：
            旋转角度 = 移动距离 / 轮子周长 * 360 = distance / 2πr * 2π = distance / radius
        Args:
            plug (MPlug): 属性句柄，maya请求拉取的plug
            dataBlock (MDataBlock): 节点数据容器
        """
        # 检查maya请求拉取的 plug 是否是当前节点输出属性
        if plug == RollingNode.outRotation:
            # 获取输入属性数值
            inDistance_val = dataBlock.inputValue(RollingNode.inDistance).asDouble()
            inRadius_val = dataBlock.inputValue(RollingNode.inRadius).asDouble()

            if inRadius_val == 0:
                outRotation_val = 0
            else:
                # 计算输出属性数值
                outRotation_val = inDistance_val / inRadius_val
            # 获取输出属性的 MDataHandle
            outRotation_data_handle = dataBlock.outputValue(RollingNode.outRotation)
            # 设置输出属性数值
            outRotation_data_handle.setDouble(outRotation_val)
            # 数值输出plug为“净”
            dataBlock.setClean(plug)

    @classmethod
    def creator(cls):
        """节点创建器，返回实例"""
        return cls()

    @classmethod
    def initialize(cls):
        """节点初始化，初始化所有节点属性"""
        # 获取数字属性函数集
        numeric_attr = om.MFnNumericAttribute()

        # 创建属性
        cls.inDistance = numeric_attr.create(
            "distance", "dis", om.MFnNumericData.kDouble, 0.0
        )
        numeric_attr.keyable = True
        numeric_attr.readable = False

        cls.inRadius = numeric_attr.create(
            "radius", "rad", om.MFnNumericData.kDouble, 0.0
        )
        numeric_attr.keyable = True  # 属性可剋，插头出现在节点左侧
        numeric_attr.readable = False  # 属性不可读，插头不出现在节点右侧

        # MFnUnitAttribute用于带单位的属性（如 `MAngle`、`MTime`、`MDistance`）
        unit_attr = om.MFnUnitAttribute()
        # 单位为弧度：om.MFnUnitAttribute.kAngle
        cls.outRotation = unit_attr.create(
            "rotation", "rot", om.MFnUnitAttribute.kAngle, 0.0
        )
        unit_attr.writable = False  # 属性不可写，不会出现在属性编辑器中

        # 添加属性
        cls.addAttribute(cls.inDistance)
        cls.addAttribute(cls.inRadius)
        cls.addAttribute(cls.outRotation)
        # 设置属性影响
        cls.attributeAffects(cls.inDistance, cls.outRotation)
        cls.attributeAffects(cls.inRadius, cls.outRotation)


def initializePlugin(plugin):
    vendor = "Charles Tian"
    version = "1.0.0"
    plugin_fn = om.MFnPlugin(plugin, vendor, version)
    try:
        plugin_fn.registerNode(
            RollingNode.TYPE_NAME,
            RollingNode.TYPE_ID,
            RollingNode.creator,
            RollingNode.initialize,
            om.MPxNode.kDependNode,
        )
    except Exception as e:
        om.MGlobal.displayError(f"Failed to register Node: {RollingNode.typeName}, {e}")


def uninitializePlugin(plugin):
    plugin_fn = om.MFnPlugin(plugin)
    try:
        plugin_fn.deregisterNode(RollingNode.TYPE_ID)
    except Exception as e:
        om.MGlobal.displayError(
            f"Failed to deregister Node: {RollingNode.typeName}, {e}"
        )


if __name__ == "__main__":
    pm.newFile(force=True)

    plugin_name = "rolling_node"

    pm.unloadPlugin(plugin_name)

    pm.loadPlugin(plugin_name)

    node_name = "rollingNode"
    pm.createNode(node_name)
```
