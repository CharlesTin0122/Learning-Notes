在 Maya Python API 2.0（`maya.api.OpenMaya`）中，遍历 DAG（Directed Acyclic Graph，有向无环图）节点是常见的操作，用于处理场景中的层次结构。以下是使用 Maya Python API 2.0 遍历 DAG 节点的详细步骤和代码示例。

### 主要步骤
1. **获取场景中的 DAG 节点**：使用 `OpenMaya.MDagPath` 或 `OpenMaya.MItDag` 来访问 DAG 层次结构。
2. **使用迭代器遍历**：`MItDag` 是专门用于遍历 DAG 节点的迭代器，可以按深度优先或广度优先方式遍历。
3. **处理节点**：在遍历过程中，可以获取节点的名称、类型或其他属性。
### 主要用到的类
- MitDag：Dag节点迭代器
	- 构造函数：`dag_iter = om.MItDag(traversal_type, filter_type)`
	- rese方法：reset(root=None, traversal_type=None, filter_type=None)
	- 要提供一个根节点用于开始遍历
	- 可以用于深度遍历或广度遍历
	- 要提供一个过滤器来限制遍历结果
	- 只能从根节点向上遍历
- MFnDagNode：Dag节点函数集
	- `parent(index)`：获取父对象
	- `parentCount()`：获取父对象数量
	- `child(index)`：获取子对象
	- `childCount()`：获取子对象数量
- MDagPath：Dag节点路径
- MDagPathArray：Dag节点路径数组
### 遍历方法
- 如果要找到一个跟节点下的节点要使用MitDag遍历
- 如果想找到一个节点的父节点或者子节点，要使用MFnDagNode来查找
- 如果要找到场景中的所有摄像机transform节点，要用从worldNode开始遍历找到所有shape节点，再使用MFnDagNode获取其父节点
### 代码示例
以下是一个使用 Maya Python API 2.0 遍历 DAG 节点的示例代码：

```python
import maya.api.OpenMaya as om

def traverse_dag():
    # 创建 DAG 迭代器
    dag_iterator = om.MItDag(om.MItDag.kDepthFirst, om.MFn.kInvalid)
    
    # 遍历所有 DAG 节点
    while not dag_iterator.isDone():
        # 获取当前节点的 MDagPath
        dag_path = dag_iterator.getPath()
        
        # 获取节点的 MObject
        node = dag_iterator.currentItem()
        
        # 创建 MFnDagNode 来获取节点信息
        dag_node = om.MFnDagNode(dag_path)
        
        # 获取节点名称
        node_name = dag_node.name()
        
        # 获取节点类型
        node_type = dag_path.node().apiTypeStr
        
        # 获取节点深度
        depth = dag_iterator.depth()
        
        # 打印节点信息
        print(f"{'  ' * depth}Node: {node_name}, Type: {node_type}, Depth: {depth}")
        
        # 移动到下一个节点
        dag_iterator.next()

# 执行遍历
traverse_dag()
```

### 代码说明
1. **导入模块**：
   - 使用 `maya.api.OpenMaya` 提供 Maya Python API 2.0 的功能。

2. **创建迭代器**：
   - `MItDag` 是 DAG 节点的迭代器，构造函数接受两个参数：
     - 遍历方式：`kDepthFirst`（深度优先）或 `kBreadthFirst`（广度优先）。
     - 节点过滤器：`MFn.kInvalid` 表示不过滤，遍历所有类型的节点。如果需要特定类型（如 `MFn.kMesh`），可以指定。

3. **遍历节点**：
   - `dag_iterator.isDone()`：检查是否遍历完成。
   - `dag_iterator.getPath()`：获取当前节点的 `MDagPath`，包含节点的完整路径信息。
   - `dag_iterator.currentItem()`：获取当前节点的 `MObject`。
   - `dag_iterator.depth()`：获取当前节点的层级深度。
   - `dag_iterator.next()`：移动到下一个节点。

4. **获取节点信息**：
   - 使用 `MFnDagNode` 获取节点的名称、类型等信息。
   - `dag_path.node().apiTypeStr` 返回节点的 API 类型（如 `kTransform`、`kMesh` 等）。

5. **输出格式**：
   - 使用 `depth` 缩进打印，显示层次结构。

### 示例输出
假设场景中有以下节点：

  |pSphere1
    |pSphereShape1
```

运行代码后，输出可能如下：

```

### 注意事项
1. **节点过滤**：
   - 如果只想遍历特定类型的节点，可以在创建 `MItDag` 时指定类型。例如，只遍历 mesh 节点：
     ```python
     dag_iterator = om.MItDag(om.MItDag.kDepthFirst, om.MFn.kMesh)
     ```

2. **性能考虑**：
   - 深度优先 (`kDepthFirst`) 适合需要处理子节点的情况，广度优先 (`kBreadthFirst`) 适合按层次顺序处理。
   - 遍历大型场景时，建议根据需求过滤节点类型以提高效率。

3. **访问节点属性**：
   - 使用 `MFnDagNode` 或其他功能集（如 `MFnTransform`、`MFnMesh`）可以进一步访问节点的属性，例如变换矩阵、顶点数据等。

4. **错误处理**：
   - 确保处理异常情况，例如空场景或无效节点：
     ```python
     try:
         dag_iterator = om.MItDag(om.MItDag.kDepthFirst, om.MFn.kInvalid)
         while not dag_iterator.isDone():
             # 处理节点
             dag_iterator.next()
     except Exception as e:
         print(f"Error during traversal: {e}")
     ```

### 高级用法
如果需要处理特定节点的子节点，可以使用 `MDagPath` 的方法：
```python
def get_children(dag_path):
    dag_node = om.MFnDagNode(dag_path)
    for i in range(dag_node.childCount()):
        child = dag_node.child(i)
        child_dag_path = om.MDagPath.getAPathTo(child)

```

使用 `MItDag` 遍历 DAG 节点是 Maya Python API 2.0 中高效的方式。通过设置遍历方式和节点过滤器，可以灵活地处理场景中的节点。上述代码提供了基本的遍历框架，可以根据需求扩展，例如筛选特定节点类型或提取更多属性。

## 案例1：遍历dagNode
```python
import maya.api.OpenMaya as om

selection_list = om.MGlobal.getActiveSelectionList()  # 获取选择列表

traversal_type = om.MItDag.kBreadthFirst  # 遍历方式为广度优先,kDepthFirst为深度优先
filter_type = om.MFn.kMesh  # 过滤器为Mesh

# 创建迭代器，参数：迭代类型，过滤器
dag_iter = om.MItDag(traversal_type, filter_type)
# 如果选择列表不为空
if not selection_list.isEmpty():
    # 获取选择列表第一项的dependNode作为根节点
    root_node = selection_list.getDependNode(0)
    # 重置过滤器，参数：根节点，迭代类型，过滤器
    dag_iter.reset(root_node, traversal_type, filter_type)
# 遍历场景，从世界根节点开始遍历
while not dag_iter.isDone():
    # 打印短名称，长名称用：fullPathName()
    # print(dag_iter.partialPathName())
    # 获取 MDagPath
    dag_path = dag_iter.getPath()
    # 利用MDagPath打印对象长名称
    print(dag_path.fullPathName())
    # 继续迭代
    dag_iter.next()

```
