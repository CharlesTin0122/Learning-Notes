以下是Maya软件中事件描述的翻译列表，事件名称保持原文不变，仅翻译事件描述：

angularToleranceChanged: 当角度单位的公差发生变化时。此公差可以通过以下方式更改：
- 使用MEL命令“tolerance”带“-angular”标志
- 更改选项->常规首选项->建模选项卡->切向公差

angularUnitChanged: 当用户更改角度单位时。

axisAtOriginChanged: 当原点处的轴发生变化时。

axisInViewChanged: 当特定视图中的轴发生变化时。

ColorIndexChanged: 当颜色索引值发生变化时。

constructionHistoryChanged: 当构造历史被打开或关闭时。

currentContainerChanged: 当用户设置或取消当前容器时。

currentSoundNodeChanged: 当时间滑块中显示的声音发生变化时，原因包括：
- 声音被移除（或不再显示）在时间滑块中右键点击
- 显示新的声音 在时间滑块中右键点击
- 声音显示被切换 动画选项
- 声音显示模式被更改 动画选项

DagObjectCreated: 当创建新的DAG对象时。

deleteAll: 当执行新建文件操作时。

DisplayColorChanged: 当显示颜色发生变化时。

displayLayerChange: 当图层被创建或销毁时。

displayLayerManagerChange: 当显示图层管理器发生变化时。

DisplayRGBColorChanged: 当RGB显示颜色发生变化时。

glFrameTrigger: 仅限内部使用。

ChannelBoxLabelSelected: 当通道框标签（第一列）选择发生变化时。

gridDisplayChanged: 仅限内部使用。

idle: 当Maya处于空闲状态且没有高优先级空闲任务时。

idleHigh: 当Maya处于空闲状态时。此事件在低优先级空闲任务之前调用。通常应使用“idle”代替。

lightLinkingChanged: 当发生任何修改光照链接关系的更改时。

lightLinkingChangedNonSG: 当发生任何修改光照链接关系的更改时，但不包括材质分配的更改。

linearToleranceChanged: 当线性公差发生变化时。此公差可以通过以下方式更改：
- 使用MEL命令“tolerance”带“-linear”标志
- 更改选项->常规首选项->建模选项卡->位置公差

linearUnitChanged: 当用户通过选项菜单更改线性单位时。

MenuModeChanged: 当用户更改主Maya窗口菜单栏的菜单集时（例如，从“建模”更改为“动画”）。

RecentCommandChanged: 仅限内部使用。

NewSceneOpened: 当打开新场景时。

PostSceneRead: 在场景被读取后。具体来说，在文件打开、导入或所有子引用被读取后。

nurbsToPolygonsPrefsChanged: 当NURBS到多边形的首选项发生变化时。这些首选项可以通过以下方式更改：
- 使用MEL命令“nurbsToPolygonsPref”
- 更改多边形->NURBS到多边形->选项框中的首选项

playbackRangeChanged: 当播放关键帧范围发生变化时。

playbackRangeSliderChanged: 当动画开始/结束范围（即时间滑块范围中最左或最右的输入单元格，内部单元格调整播放范围）发生变化时。

preferredRendererChanged: 当首选渲染器发生变化时。

quitApplication: 当用户选择退出时，通过quit MEL命令或退出菜单项。

Redo: 当用户从菜单中选择重做且有可重做的操作时。此回调可用于更新UI或本地存储。在此回调期间不要更改场景或DG的状态。

renderLayerChange: 当渲染层节点被创建或删除时。

renderLayerManagerChange: 当当前渲染层发生变化时。

RebuildUIValues: 仅限内部使用。

SceneOpened: 当场景被打开时。

SceneSaved: 当场景被保存时。

SelectionChanged: 当进行新选择时。

UFESelectionChanged: 当进行新的UFE选择时。

SelectModeChanged: 当选择模式发生变化时。

SelectPreferenceChanged: 仅限内部使用。

SelectPriorityChanged: 当选择优先级发生变化时。

SelectTypeChanged: 当选择类型发生变化时。

setEditorChanged: 已废弃，不再使用。

SetModified: 当使用set命令修改集合时。

SequencerActiveShotChanged: 当活动序列镜头发生变化时。

snapModeChanged: 当捕捉模式发生变化时，例如更改为网格捕捉。

timeChanged: 当时间发生变化时。

timeUnitChanged: 当用户更改时间单位时。

ToolChanged: 当用户更改工具/上下文时。

PostToolChanged: 在用户更改工具/上下文之后。

NameChanged: 当用户使用rename命令更改对象名称时。

Undo: 当用户从菜单中选择撤销且有可撤销的操作时。此回调可用于更新UI或本地存储。在此回调期间不要更改场景或DG的状态。

modelEditorChanged: 当用户更改模型编辑器的选项时。

colorMgtEnabledChanged: 当全局每场景颜色管理启用标志发生变化时。

colorMgtConfigFileEnableChanged: 当全局每场景颜色管理OCIO配置启用标志发生变化时。

colorMgtPrefsViewTransformChanged: 当全局每场景颜色管理视图转换首选项发生变化时。

colorMgtWorkingSpaceChanged: 当全局每场景颜色管理工作空间发生变化时。

colorMgtConfigFilePathChanged: 当全局每场景颜色管理OCIO配置文件路径发生变化时。

colorMgtConfigChanged: 当颜色管理模式从原生更改为OCIO，或加载不同的OCIO配置时。

colorMgtPrefsReloaded: 当所有全局每场景颜色管理设置被重新加载时。

colorMgtUserPrefsChanged: 当任何用户级颜色管理首选项发生变化时。

colorMgtOutputChanged: 当颜色管理转换或其启用状态发生变化时。

colorMgtOCIORulesChanged: 当OCIO模式下的规则类型发生变化时。

colorMgtRefreshed: 当颜色管理被刷新以捕获环境变量变化时。

metadataVisualStatusChanged: 仅限内部使用。

shapeEditorTreeviewSelectionChanged: 当形状编辑器的树视图中进行新选择时。

RenderViewCameraChanged: 当渲染视图的当前相机发生变化时。

tabletModeChanged: 仅限Windows：如果您的设备是平板电脑，则可转换模式已更改。可以使用命令about -tabletMode查询您的设备当前是运行在平板模式还是笔记本模式（键盘已连接）。
