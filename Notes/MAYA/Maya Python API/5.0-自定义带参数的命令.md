我们来看一个命令
```python
mc.polyCube("myCube", q=True, sx=True)
```
- 这条命令参数中：
	- "myCube"是一个字符串参数，我们称之为命令对象（Command Object），这通常是一个对象的名称，也叫做命令参数（Command Argument）
- 后面的参数是Flag（标志），q和sx都是短名称，True都是标志的值，我们称之为标志参数（Flag Argument）

### 1. **自定义命令的基本概念**
- **MPxCommand**：`OpenMayaMPx.MPxCommand` 是Maya Python API中用于创建自定义命令的基类。开发者需要继承这个类并实现核心方法（如 `doIt`）来定义命令的行为。
- **参数支持**：通过实现 `isUndoable` 和 `undoIt`/`redoIt` 方法，可以支持命令的撤销和重做功能。
- **参数解析**：自定义命令可以通过 `MSyntax` 和 `MArgDatabase` 类定义和解析参数（标志），支持短标志（如 `-n`）、长标志（如 `-name`）以及带值的参数。

#### 1.**MSyntax 介绍**

##### **定义**

MSyntax 是 Maya API 中的一个类，位于 OpenMaya 模块，用于定义自定义命令的语法（即命令支持的标志和参数类型）。它指定了命令可以接受哪些标志（flags）、这些标志的类型（如字符串、整数、布尔等），以及标志的行为（例如是否允许多个值）。

##### **主要功能**

- **定义标志**：通过 addFlag 方法为命令添加短标志（如 -n）和长标志（如 -name），并指定其数据类型。
- **支持多种参数类型**：包括布尔、整数、浮点数、字符串、选择对象等。
- **支持对象列表**：通过 setObjectType 定义命令接受的对象（如选择列表中的节点）。
- **查询/编辑模式**：通过 enableQuery 和 enableEdit 支持命令的查询（-query）和编辑（-edit）模式。

##### **常用方法**

- addFlag(shortName, longName, argType)：添加一个标志，指定短名称、长名称和参数类型。
    - shortName：短标志（如 -n）。
    - longName：长标志（如 -name）。
    - argType：参数类型，如 MSyntax.kString、MSyntax.kLong、MSyntax.kBoolean 等。
- setObjectType(objectType, minObjects, maxObjects)：定义命令接受的对象类型和数量范围。
    - objectType：如 MSyntax.kSelectionItem（选择对象）。
    - minObjects / maxObjects：对象的最小和最大数量。
- enableQuery(boolean)：启用或禁用查询模式（-query 或 -q）。
- enableEdit(boolean)：启用或禁用编辑模式（-edit 或 -e）。
- makeFlagMultiUse(flag)：允许标志被多次使用（例如，-n "name1" -n "name2"）。

##### **支持的参数类型**

- MSyntax.kBoolean：布尔值（如 -v true）。
- MSyntax.kLong：整数（如 -c 5）。
- MSyntax.kDouble：浮点数（如 -r 3.14）。
- MSyntax.kString：字符串（如 -n "example"）。
- MSyntax.kSelectionItem：选择对象（如节点或组件）。
- MSyntax.kNoArg：无参数的标志（仅标志存在与否）。

---

####  2.**MArgDatabase 介绍**

##### **定义**

MArgDatabase 是 Maya API 中的一个类，位于 OpenMaya 模块，用于解析用户在命令中传递的参数（基于 MSyntax 定义的语法）。它从 MArgList（用户输入的参数列表）中提取标志和值，并提供便捷的方法来访问这些参数。

MArgDatabase是MArgParser的子类，这个类有解析和储存标志参数的能力，继承后增加了检索功能。

##### **主要功能**

- **解析参数**：根据 MSyntax 定义的语法，从 MArgList 中提取标志的值。
- **检查标志存在性**：通过 isFlagSet 检查是否提供了某个标志。
- **获取参数值**：根据标志名称获取布尔、整数、浮点数、字符串等值。
- **支持查询/编辑模式**：检查命令是否以查询（-query）或编辑（-edit）模式运行。
- **处理对象列表**：获取命令中传递的对象（如选中的节点）。

##### **常用方法**

- isFlagSet(flag)：检查指定标志是否在参数列表中。
- flagArgumentBool(flag, index)：获取布尔标志的值。
- flagArgumentInt(flag, index)：获取整数标志的值。
- flagArgumentDouble(flag, index)：获取浮点数标志的值。
- flagArgumentString(flag, index)：获取字符串标志的值。
- getObjects(selectionList)：获取命令中传递的对象（存储到 MSelectionList）。
- isQuery()：检查是否为查询模式。
- isEdit()：检查是否为编辑模式。
- flagArgumentCount(flag)：返回某标志被使用的次数（用于多值标志）。

#### 3.Undo和Redo
- 在 Autodesk Maya 中，Undo 和 Redo 的数据结构基于栈（Stack），具体是一个双栈模型，即一个 Undo 栈和一个 Redo 栈。这种设计符合命令模式（Command Pattern）中对撤销和重做的典型实现方式。
- **Undo 栈**：
    - 每次执行一个命令（或操作），Maya 将该命令（通常以命令对象或相关数据结构的形式）压入 **Undo 栈**。
    - Undo 栈是一个后进先出（LIFO, Last-In-First-Out）的结构，意味着最近执行的命令会首先被撤销。
    - 当用户执行 Undo 操作（例如按 Ctrl+Z 或调用 cmds.undo()），Maya 从 Undo 栈顶部弹出一个命令，执行其 undoIt 方法（如果命令支持撤销），并将该命令压入 Redo 栈。
- **Redo 栈**：
    - Redo 栈同样是一个 LIFO 结构，用于存储已撤销的命令。
    - 当用户执行 Redo 操作（例如按 Ctrl+Shift+Z 或调用 cmds.redo()），Maya 从 Redo 栈顶部弹出一个命令，执行其 redoIt 方法，并将该命令重新压回 Undo 栈。
- **双栈模型**：
    - Undo 和 Redo 栈共同工作，形成一个双向的操作历史记录。
    - 每次执行新命令时，Redo 栈会被清空，因为新的操作会覆盖之前撤销的历史。

### 2. **实现自定义命令的步骤**
以下是创建带参数的自定义命令的完整流程：

#### **步骤 1：导入必要的模块**
需要使用 `OpenMaya` 和 `OpenMayaMPx` 模块来定义命令和处理参数。

```python
import maya.OpenMaya as om
import maya.OpenMayaMPx as ompx
```

#### **步骤 2：定义命令类**
继承 `ompx.MPxCommand` 类，并实现以下关键方法：
- `doIt(argList)`：命令的主要执行逻辑，接收参数列表（`MArgList`）。
- `isUndoable()`：返回布尔值，指示命令是否支持撤销。
- `undoIt()` 和 `redoIt()`：实现撤销和重做逻辑（如果支持撤销）。
- `creator()`：静态方法，返回命令实例。
- `syntaxCreator()`：定义命令的语法（标志和参数）。

#### **步骤 3：定义命令语法**
使用 `MSyntax` 类定义命令支持的标志和参数。常见的标志类型包括：
- 布尔标志（如 `-enable`）
- 字符串参数（如 `-name "value"`)
- 数字参数（如 `-count 5`）

#### **步骤 4：解析参数**
在 `doIt` 方法中使用 `MArgDatabase` 解析传入的参数，并根据参数值执行逻辑。

#### **步骤 5：注册命令**
通过插件注册函数将命令注册到Maya，使其可以通过MEL或Python调用。

### 3. **示例：带参数的自定义命令**
以下是一个完整的示例，展示如何创建一个带参数的自定义命令 `customPrintCmd`，该命令接受以下参数：
- `-n` / `-name`（字符串）：指定一个名称。
- `-c` / `-count`（整数）：指定打印次数。
- `-v` / `-verbose`（布尔）：控制是否打印详细信息。

```python
import maya.OpenMaya as om
import maya.OpenMayaMPx as ompx

# 命令名称
kPluginCmdName = "customPrintCmd"

# 标志定义
kNameFlag = "-n"
kNameLongFlag = "-name"
kCountFlag = "-c"
kCountLongFlag = "-count"
kVerboseFlag = "-v"
kVerboseLongFlag = "-verbose"

class CustomPrintCmd(ompx.MPxCommand):
    def __init__(self):
        ompx.MPxCommand.__init__(self)
        self.name = ""
        self.count = 1
        self.verbose = False

    @staticmethod
    def creator():
        """创建命令实例"""
        return ompx.asMPxPtr(CustomPrintCmd())

    @staticmethod
    def syntaxCreator():
        """定义命令语法"""
        syntax = om.MSyntax()
        # 添加字符串类型的 -name 标志
        syntax.addFlag(kNameFlag, kNameLongFlag, om.MSyntax.kString)
        # 添加整数类型的 -count 标志
        syntax.addFlag(kCountFlag, kCountLongFlag, om.MSyntax.kLong)
        # 添加布尔类型的 -verbose 标志
        syntax.addFlag(kVerboseFlag, kVerboseLongFlag, om.MSyntax.kBoolean)
        return syntax

    def isUndoable(self):
        """支持撤销"""
        return True

    def undoIt(self):
        """撤销逻辑：打印撤销信息"""
        om.MGlobal.displayInfo(f"Undoing command for name: {self.name}")

    def redoIt(self):
        """重做逻辑：重新执行打印"""
        self.executeCommand()

    def doIt(self, argList):
        """主执行逻辑：解析参数并调用执行"""
        # 创建参数解析器
        argData = om.MArgDatabase(self.syntax(), argList)

        # 解析参数
        if argData.isFlagSet(kNameFlag):
            self.name = argData.flagArgumentString(kNameFlag, 0)
        if argData.isFlagSet(kCountFlag):
            self.count = argData.flagArgumentInt(kCountFlag, 0)
        if argData.isFlagSet(kVerboseFlag):
            self.verbose = argData.flagArgumentBool(kVerboseFlag, 0)

        # 执行命令逻辑
        self.executeCommand()

        # 设置结果
        self.setResult(f"Printed {self.name} {self.count} times")

    def executeCommand(self):
        """实际执行打印逻辑"""
        for i in range(self.count):
            message = f"Print {i+1}: {self.name}"
            if self.verbose:
                message += " (Verbose mode)"
            om.MGlobal.displayInfo(message)

# 插件初始化
def maya_useNewAPI():
    pass

def initializePlugin(mobject):
    """注册插件"""
    mplugin = ompx.MFnPlugin(mobject, "Custom Author", "1.0", "Any")
    try:
        mplugin.registerCommand(kPluginCmdName, CustomPrintCmd.creator, CustomPrintCmd.syntaxCreator)
    except:
        om.MGlobal.displayError("Failed to register command: %s" % kPluginCmdName)
        raise

def uninitializePlugin(mobject):
    """卸载插件"""
    mplugin = ompx.MFnPlugin(mobject)
    try:
        mplugin.deregisterCommand(kPluginCmdName)
    except:
        om.MGlobal.displayError("Failed to deregister command: %s" % kPluginCmdName)
        raise
```

  - `-n` / `-name`：接受字符串参数，指定要打印的名称。
  - `-c` / `-count`：接受整数参数，指定打印次数。

### 6. **关键点和注意事项**
- **标志类型**：`MSyntax` 支持多种参数类型：
  - `kString`：字符串。
  - `kLong` / `kDouble`：整数/浮点数。
  - `kBoolean`：布尔值。
  - `kSelectionItem`：选择对象。
- **错误处理**：在 `doIt` 中检查 `argData.isFlagSet` 避免未提供参数时的错误。
- **性能**：对于复杂命令，避免在 `doIt` 中执行所有逻辑，建议将核心逻辑放入 `redoIt`，以优化撤销/重做性能。
- **插件管理**：确保插件正确注册和卸载，避免冲突。
- **命名冲突**：命令名称和标志名称应避免与Maya内置命令冲突。

### 8. **总结**
通过继承 `OpenMayaMPx.MPxCommand` 并使用 `MSyntax` 和 `MArgDatabase`，可以在Maya Python API 1.0中创建带参数的自定义命令。上述示例展示了如何定义一个支持字符串、整数和布尔参数的命令，并实现撤销/重做功能。开发者可以根据需求扩展标志类型、添加查询/编辑模式，或集成更复杂的逻辑。
# 案例
```python
import maya.OpenMaya as om
import maya.OpenMayaMPx as mpx
import maya.OpenMayaFX as fx

# 命令名称
kPluginCommandName = "vertexParticle"
# 命令参数
kHelpFlag = "-h"  # 帮助短标志
kHelpLongFlag = "-help"  # 帮助长标志
kSparseFlag = "-s"  # 稀疏短标志，用于每隔多少个定点创建一个粒子
kSparseLongFlag = "-sparse"  # 稀疏长标志
helpMessage = "This command creates a particle system from the vertices of a mesh."


# 自定义命令类，继承自 OpenMayaMPx.MPxCommand
class PluginCommand(mpx.MPxCommand):
    """自定义 Maya 命令插件"""

    def __init__(self):
        """调用父类构造函数"""
        mpx.MPxCommand.__init__(self)

    def argumentParser(self, argList):
        """
        解析命令参数
        接收参数列表argList：MArgList Object
        返回解析后的参数列表
        """
        # 获取实例的语法对象
        # OpenMayaMPx.MPxCommand 基类提供了一个内置方法 syntax()，
        # 它返回由 syntaxCreator 方法创建的 MSyntax 对象。
        syntax = self.syntax()
        # 创建MArgDatabase实例，用于解析参数
        parsedArguments = om.MArgDatabase(syntax, argList)
        # 解析参数
        if parsedArguments.isFlagSet(kSparseFlag):
            self.sparse = parsedArguments.flagArgumentDouble(kSparseFlag, 0)
            return om.MStatus.kSuccess
        if parsedArguments.isFlagSet(kSparseLongFlag):
            self.sparse = parsedArguments.flagArgumentDouble(kSparseLongFlag, 0)
            return om.MStatus.kSuccess
        if parsedArguments.isFlagSet(kHelpFlag):
            # help标志没有参数，所以打印信息
            self.setResult(helpMessage)
            return om.MStatus.kSuccess
        if parsedArguments.isFlagSet(kHelpLongFlag):
            # help标志没有参数，所以打印信息
            self.setResult(helpMessage)
            return om.MStatus.kSuccess

    def doIt(self, argList):
        """执行命令逻辑，
        接收参数列表argList：MArgList Object
        执行操作
        """
        print("Do It!")


# 初始化插件
def cmdCreator():
    """
    创建命令实例
    PluginCommand()：创建插件实例
    OpenMayaMPx.asMPxPtr()：返回实例指针
    """
    return mpx.asMPxPtr(PluginCommand())


def syntexCreator():
    """
    为命令创建语法对象，用于收集命令参数
    Returns:
        om.Msyntax: 语法对象
    """
    # 创建语法对象
    syntax = om.Msyntax()
    # 添加命令参数：短名称，长名称，数据类型
    syntax.addFlag(kHelpFlag, kHelpLongFlag)
    syntax.addFlag(kSparseFlag, kSparseLongFlag, om.MSyntax.kDouble)
    # 返回语法对象
    return syntax


# 注册插件
def initializePlugin(mobject):
    """
    注册插件到 Maya
    创建MFnPlugin实例
    mobject参数是maya生成的句柄用来捕获插件实例指针
    """
    mplugin = mpx.MFnPlugin(mobject, "CharlesT", "1.0", "Any")
    try:
        # 注册命令,参数为命令名称和命令创建函数,还有语法创建函数
        mplugin.registerCommand(kPluginCommandName, cmdCreator, syntexCreator)
    except Exception as e:
        om.MGlobal.displayError(e, f"Failed to register command: {kPluginCommandName}")


# 卸载插件
def uninitializePlugin(mobject):
    """从 Maya 卸载插件"""
    # 创建MFnPlugin实例
    mplugin = mpx.MFnPlugin(mobject)
    try:
        # 注销命令，只需命令名称即可注销
        mplugin.deregisterCommand(kPluginCommandName)
    except Exception as e:
        om.MGlobal.displayError(
            e, f"Failed to deregister command: {kPluginCommandName}"
        )

```
