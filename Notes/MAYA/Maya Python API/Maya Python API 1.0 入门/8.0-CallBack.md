在 Maya Python API 1.0 中，`CallBack` 机制主要用于处理事件驱动的编程，允许开发者在特定事件发生时执行自定义的回调函数。Maya 的 API 提供了一种方式来注册回调，以便在特定条件下（例如场景变化、节点属性修改、时间变化等）触发自定义代码。以下是对 Maya Python API 1.0 中回调机制的介绍：

### 1. **回调的概述**
Maya Python API 1.0 通过 `OpenMaya.MMessage` 模块提供回调功能。回调（Callback）是一种机制，允许开发者将自定义的 Python 函数绑定到 Maya 的事件（如节点创建、属性变化、场景保存等）。当这些事件发生时，Maya 会调用注册的回调函数，并传递相关参数。

回调的核心类是 `OpenMaya.MMessage`，它提供了多种方法来注册和移除回调。常见的回调类型包括：
- **节点相关回调**：如节点创建、删除或属性变化。
- **场景相关回调**：如场景打开、保存或关闭。
- **时间相关回调**：如时间轴变化。
- **UI相关回调**：如界面元素的变化。

### 2. **主要类和方法**
以下是与回调相关的主要类和方法：

#### `OpenMaya.MMessage`
- **作用**：基类，用于管理所有类型的回调。
- **常用方法**：
  - `MMessage.addCallback`：注册一个回调函数。
  - `MMessage.removeCallback`：移除已注册的回调（需要回调的 ID）。
  - `MMessage.nodeCallbacks`：专门用于节点相关的事件回调。

#### 回调的注册
回调通过 `MMessage` 类或其子类的静态方法注册，常用的方法包括：
- `MMessage.addNodeAddedCallback`：当新节点添加到场景时触发。
- `MMessage.addNodeRemovedCallback`：当节点从场景中移除时触发。
- `MMessage.addAttributeChangedCallback`：当节点属性发生变化时触发。
- `MMessage.addTimeChangeCallback`：当时间轴变化时触发。
- `MMessage.addSceneMessage`：用于场景事件（如打开、保存）。

#### 回调函数的签名
回调函数需要遵循特定的参数签名，具体取决于事件类型。通常，回调函数会接收与事件相关的参数（如 `MObject` 表示节点、`MTime` 表示时间等），以及一个可选的 `clientData` 参数（用户自定义数据）。

示例回调函数签名：
```python
def myCallback(node, clientData):
    print(f"Node {node} triggered the callback!")
```

### 3. **注册回调的步骤**
以下是注册回调的基本步骤：
1. **导入模块**：
   ```python
   from maya.OpenMaya import MMessage, MObject
   ```

2. **定义回调函数**：
   回调函数必须符合事件类型要求的参数签名。例如：
   ```python
   def onNodeAdded(node, clientData):
       print(f"New node added: {node}")
   ```

3. **注册回调**：
   使用适当的 `MMessage` 方法注册回调，并保存回调 ID（用于后续移除）：
   ```python
   callbackId = MMessage.addNodeAddedCallback(onNodeAdded)
   ```

4. **移除回调**：
   当不再需要回调时，使用回调 ID 移除：
   ```python
   MMessage.removeCallback(callbackId)
   ```

### 4. **示例代码**
以下是一个完整的示例，展示如何注册一个回调来监听新节点的创建：
```python
import maya.OpenMaya as OpenMaya

def onNodeAdded(node, clientData):
    print(f"New node created: {node}")

# 注册回调
callbackId = OpenMaya.MMessage.addNodeAddedCallback(onNodeAdded)

# 注意：在脚本结束时移除回调以防止内存泄漏
# OpenMaya.MMessage.removeCallback(callbackId)
```

### 5. **注意事项**
- **回调 ID 管理**：每次注册回调都会返回一个唯一的 ID，建议保存此 ID 以便在适当的时候移除回调。未移除的回调可能导致内存泄漏或意外行为。
- **线程安全**：Maya 的回调在主线程中执行，但仍需注意线程安全问题，避免在回调中执行耗时操作。
- **性能影响**：过多或复杂的回调可能影响 Maya 的性能，建议仅注册必要的回调。
- **调试**：回调函数中的错误可能导致 Maya 崩溃，建议在回调函数中使用异常处理（try-except）。

### 6. **常见回调类型**
以下是一些常见的回调类型及其用途：
- **MMessage.addNodeAddedCallback**：监听新节点创建。
- **MMessage.addNodeRemovedCallback**：监听节点删除。
- **MMessage.addAttributeChangedCallback**：监听节点属性变化（如位置、旋转）。
- **MSceneMessage.addCallback**：监听场景事件（如 `kBeforeSave`、`kAfterOpen`）。
- **MTimerMessage.addTimerCallback**：定期执行回调，适合动画或实时更新。

### 7. **局限性**
- Maya Python API 1.0 的回调机制功能较为基础，相比 API 2.0 缺少一些高级功能（如更灵活的事件过滤）。
- 回调函数的执行环境受到 Maya 主线程的限制，可能不适合复杂的异步操作。

### 8. **总结**
Maya Python API 1.0 的回调机制通过 `OpenMaya.MMessage` 提供了一种灵活的事件处理方式，适合需要动态响应场景变化的脚本开发。开发者需要谨慎管理回调的注册和移除，确保代码的健壮性和性能。如果需要更复杂的回调管理，建议考虑使用 Maya Python API 2.0（如果适用）。

# 案例
```python
import maya.OpenMaya as om
import maya.OpenMayaMPx as mpx
import math

# 变形器名称：波纹变形器
kNodeName = "Ripple"
# 节点ID在`0x80000` - `0xFFFFFFF`之间
kNodeId = om.MTypeId(0x103FFF)


# 变形器类
class RippleDeformer(mpx.MPxDeformerNode):
    # 变形器属性
    inAmplitude = om.MObject()  # 振幅
    inDisplace = om.MObject()  # 偏移

    def __init__(self):
        """构造函数：调用父类构造函数"""
        super(RippleDeformer, self).__init__()

    @staticmethod
    def deformerCreator():
        """变形器创建：返回变形器实例指针"""
        return mpx.asMPxPtr(RippleDeformer())

    @staticmethod
    def deformerInitializer():
        """初始化变形器属性"""
        # 创建数字属性函数集
        mFnAttr = om.MFnNumericAttribute()
        # 创建属性：长名称，短名称，类型，默认值
        RippleDeformer.inAmplitude = mFnAttr.create(
            "AmplitudeValue", "AmpVal", om.MFnNumericData.kFloat, 0.0
        )
        mFnAttr.setKeyable(True)
        mFnAttr.setMin(0.0)
        mFnAttr.setMax(1.0)

        RippleDeformer.inDisplace = mFnAttr.create(
            "DisplaceValue", "DispVal", om.MFnNumericData.kFloat, 0.0
        )
        mFnAttr.setKeyable(True)
        mFnAttr.setMin(0.0)
        mFnAttr.setMax(10.0)
        # 添加属性，将属性添加到dataBlock
        RippleDeformer.addAttribute(RippleDeformer.inAmplitude)
        RippleDeformer.addAttribute(RippleDeformer.inDisplace)
        # 定义属性依赖关系,
        """
        在 Maya Python API 1.0 中，`OpenMayaMPx.MPxDeformerNode` 提供了以下内置属性，用于自定义变形器的开发。
        这些属性maya早期通过 `OpenMayaMPx.cvar`(control variable) 访问：

        - `input`: 输入几何体数组（MPlug 类型），用于连接上游节点的输出几何体。
        访问方式：`OpenMayaMPx.cvar.MPxDeformerNode_input`
        - `inputGeom`: 输入几何体数据（MDataHandle 类型），表示具体的输入几何体（如 MFnMesh 或 MFnNurbsCurve）。
        访问方式：`OpenMayaMPx.cvar.MPxDeformerNode_inputGeom`
        - `envelope`: 浮点型属性（MPlug 类型，范围 0.0 到 1.0），用于控制变形器的整体强度或开关效果。
        访问方式：`OpenMayaMPx.cvar.MPxDeformerNode_envelope`
        - `outputGeom`: 输出几何体数据（MDataHandle 类型），用于存储变形后的几何体。
        访问方式：`OpenMayaMPx.cvar.MPxDeformerNode_outputGeom`

        这些属性在 `deform` 方法中通过 `MDataBlock` 访问和操作，用于实现自定义变形逻辑。
        """

        RippleDeformer.attributeAffects(
            RippleDeformer.inAmplitude, RippleDeformer.outputGeom
        )
        RippleDeformer.attributeAffects(
            RippleDeformer.inDisplace, RippleDeformer.outputGeom
        )
        RippleDeformer.attributeAffects(RippleDeformer.input, RippleDeformer.outputGeom)

    def deform(
        self,
        dataBlock: om.MDataBlock,
        geomIter: om.MItGeometry,
        matrix: om.MMatrix,
        geomIndex: int,
    ):
        """_summary_变形器变形逻辑

        Args:
            dataBlock (MDataBlock): 存储节点属性数据
            geomIter (MItGeometry): 几何体迭代器
            matrix (MMatrix): 世界空间变换矩阵
            geomIndex (int): 输入几何体的索引
        """

        """获取内置属性"""
        # 从dataBlock获取输入几何体数组（inputArrayAttribute）句柄
        inputArrayHandle = dataBlock.inputArrayValue(RippleDeformer.input)
        # 利用句柄根据参数geomIndex跳转到受影响的输入数组元素 inputArrayElement
        inputArrayHandle.jumpToElement(geomIndex)
        # 获取该数组元素的句柄
        inputElementHandle = inputArrayHandle.inputValue()
        # 数组元素包含：groupId 和inputGeom，
        # 获取inputGeom的句柄,inputGeom是 `MPxDeformerNode` 的内置属性，表示输入几何体
        inputGeomHandle = inputElementHandle.child(RippleDeformer.inputGeom)
        inMesh = inputGeomHandle.asMesh()
        # 获取envelope属性句柄，并将其转化为浮点数值
        envelopeVal = dataBlock.inputValue(RippleDeformer.envelope).asFloat()

        """获取自定义属性"""
        inAmplitudeVal = dataBlock.inputValue(RippleDeformer.inAmplitude).asFloat()
        inDisplaceVal = dataBlock.inputValue(RippleDeformer.inDisplace).asFloat()

        """处理变形逻辑"""
        mFnMesh = om.MFnMesh(inMesh)  # 函数集
        mFloatVectorArray_normal = om.MFloatVectorArray()  # 浮点数向量数组
        # 获取顶点法线向量数组
        # 参数：angleWeighted（bool）是否开启角度加权平均值，normals(MFloatVectorArray)，space（MSpace::Space）
        mFnMesh.getVertexNormals(False, mFloatVectorArray_normal, om.MSpace.kObject)
        # 遍历所有顶点
        while not geomIter.isDone():
            # 重新计算定点位置
            pointPosition = geomIter.position()
            pointPosition.x = (
                pointPosition.x
                + math.sin(geomIter.index() + inDisplaceVal)
                * inAmplitudeVal
                * mFloatVectorArray_normal[geomIter.index()].x
                * envelopeVal
            )

            pointPosition.y = (
                pointPosition.y
                + math.sin(geomIter.index() + inDisplaceVal)
                * inAmplitudeVal
                * mFloatVectorArray_normal[geomIter.index()].y
                * envelopeVal
            )
            pointPosition.z = (
                pointPosition.z
                + math.sin(geomIter.index() + inDisplaceVal)
                * inAmplitudeVal
                * mFloatVectorArray_normal[geomIter.index()].z
                * envelopeVal
            )
            # 重新设置顶点位置
            geomIter.setPosition(pointPosition)
            geomIter.next()


# 加载和卸载插件
def initializePlugin(mobject):
    """
    注册插件到 Maya
    mobject参数是maya生成的句柄用来捕获命令实例的指针
    """
    mplugin = mpx.MFnPlugin(mobject, "Charles Tian", "1.0")
    try:
        # 注册节点插件
        mplugin.registerNode(
            kNodeName,  # 节点名称
            kNodeId,  # 节点ID
            RippleDeformer.deformerCreator,  # 节点创建函数，返回节点实例指针
            RippleDeformer.deformerInitializer,  # 节点属性初始化函数
            mpx.MPxNode.kDeformerNode,  # 节点类型为变形器节点
        )
    except Exception:
        om.MGlobal.displayError(f"Failed to register node: {kNodeName}\n")


def uninitializePlugin(mobject):
    """
    从 Maya 卸载插件
    卸载插件只需命令名称即可
    """
    mplugin = mpx.MFnPlugin(mobject)
    try:
        # 卸载插件需要NodeId
        mplugin.deregisterNode(kNodeId)
    except Exception:
        om.MGlobal.displayError(f"Failed to deregister node: {kNodeName}\n")
        raise
```

```python
import maya.OpenMaya as om
import maya.OpenMayaMPx as mpx
import math

# 变形器名称
kNodeName = "RippleDeformer"
# 节点ID在`0x80000` - `0xFFFFFFF`之间 (修正了变量名拼写)
kNodeID = om.MTypeId(0x102FFF)


# 变形器类
class RippleDeformer(mpx.MPxDeformerNode):
    # 变形器属性
    inAmplitude = om.MObject()  # 振幅
    inDisplace = om.MObject()  # 偏移

    def __init__(self):
        """构造函数：调用父类构造函数"""
        super(RippleDeformer, self).__init__()

    @staticmethod
    def deformerCreator():
        """变形器创建：返回变形器实例指针"""
        return mpx.asMPxPtr(RippleDeformer())

    @staticmethod
    def deformerInitializer():
        """初始化变形器属性"""
        mFnAttr = om.MFnNumericAttribute()

        # 创建振幅属性
        RippleDeformer.inAmplitude = mFnAttr.create(
            "amplitude", "amp", om.MFnNumericData.kFloat, 1.0
        )
        mFnAttr.setKeyable(True)
        mFnAttr.setMin(0.0)
        mFnAttr.setMax(10.0)

        # 创建偏移属性
        RippleDeformer.inDisplace = mFnAttr.create(
            "displace", "disp", om.MFnNumericData.kFloat, 0.0
        )
        mFnAttr.setKeyable(True)
        mFnAttr.setMin(0.0)
        mFnAttr.setMax(10.0)

        # 添加属性
        RippleDeformer.addAttribute(RippleDeformer.inAmplitude)
        RippleDeformer.addAttribute(RippleDeformer.inDisplace)

        # 定义属性依赖关系
        # 当振幅、偏移或输入几何体发生变化时，输出几何体需要重新计算
        RippleDeformer.attributeAffects(
            RippleDeformer.inAmplitude, RippleDeformer.outputGeom
        )
        RippleDeformer.attributeAffects(
            RippleDeformer.inDisplace, RippleDeformer.outputGeom
        )
        RippleDeformer.attributeAffects(RippleDeformer.input, RippleDeformer.outputGeom)

    def deform(
        self,
        dataBlock: om.MDataBlock,
        geomIter: om.MItGeometry,
        matrix: om.MMatrix,
        geomIndex: int,
    ):
        """
        变形器核心逻辑

        Args:
            dataBlock (MDataBlock): 存储节点属性数据
            geomIter (MItGeometry): 几何体迭代器，用于遍历所有顶点
            matrix (MMatrix): 世界空间变换矩阵
            geomIndex (int): 输入几何体的索引
        """
        # 获取 envelope (封套) 属性值，这是所有变形器节点的内置属性
        envelope = dataBlock.inputValue(RippleDeformer.envelope).asFloat()
        if envelope == 0.0:  # 如果封套值为0，则无需计算
            return

        # 获取自定义属性的值
        amplitude = dataBlock.inputValue(RippleDeformer.inAmplitude).asFloat()
        displace = dataBlock.inputValue(RippleDeformer.inDisplace).asFloat()

        # 遍历所有受影响的顶点,geomIter会找到受影响的几何体
        while not geomIter.isDone():
            # 计算偏移量
            # 使用顶点索引来创建波纹效果，确保每个顶点的偏移都不同
            index = geomIter.index()
            sine_val = math.sin(index + displace)

            # 计算最终的偏移距离
            displacement_amount = sine_val * amplitude * envelope

            # 从迭代器直接获取当前顶点的法线向量（在对象空间）
            # 这比为整个网格重新计算法线要高效得多
            normal = geomIter.normal(om.MSpace.kObject)

            # 将原始顶点位置沿着法线方向进行偏移
            # MPoint + MVector = MPoint
            new_position = geomIter.position() + (normal * displacement_amount)

            # 设置顶点的新位置
            geomIter.setPosition(new_position)

            # 移动到下一个顶点
            geomIter.next()
```
