# MFn
在 Maya Python API 1.0 中，`MFn`（Function Set，功能集）是 `maya.OpenMaya` 模块中的一组核心类，用于操作 Maya 场景中特定类型的对象（如节点、组件或数据）。`MFn` 类通过绑定到 `MObject` 或 `MDagPath` 来提供特定于对象类型的功能，是 API 1.0 中访问和修改 Maya 数据的主要工具。以下是对 `MFn` 的详细介绍，包括其定义、功能、主要类、用途和示例。

### 1. **定义**
- **`MFn`** 是 Maya Function Set 的缩写，是一组类的集合，每个类针对特定类型的 Maya 对象（如变换节点、网格、相机、动画曲线等）提供操作方法。
- 每个 `MFn` 类本质上是一个接口，封装了对特定类型 `MObject` 或 `MDagPath` 的访问和操作逻辑。
- `MFn` 类通过绑定到 `MObject` 或 `MDagPath` 来操作对象，确保类型安全和高性能。

### 2. **功能**
- **类型特定操作**：每个 `MFn` 类针对特定对象类型提供方法，例如 `MFnTransform` 用于变换操作，`MFnMesh` 用于网格几何操作。
- **绑定机制**：`MFn` 类需要绑定到一个有效的 `MObject` 或 `MDagPath`，以访问对象的属性或执行操作。
- **高效性**：相比 `maya.cmds`，`MFn` 提供更底层的访问，性能更高，适合复杂任务或插件开发。
- **模块化**：`MFn` 类覆盖了 Maya 的大多数对象类型，包括节点、组件、动画、渲染等，功能全面。

### 3. **主要 `MFn` 类**
`MFn` 类按功能和对象类型可分为以下几大类（以下是 Maya Python API 1.0 中常见的 `MFn` 类）：

#### **3.1 节点相关类**
这些类用于操作 Maya 场景中的节点（如变换、网格、相机等）：
- **`MFnDependencyNode`**：
  - **用途**：操作依赖节点（Dependency Node）的通用属性，如名称、属性值。
  - **常见方法**：
    - `setObject(MObject)`：绑定到 `MObject`。
    - `name()`：获取节点名称。
    - `findPlug(plugName)`：获取节点的属性（`MPlug`）。
  - **适用对象**：任何依赖节点（如变换、网格、材质）。
- **`MFnTransform`**：
  - **用途**：操作变换节点（Transform Node），如位置、旋转、缩放。
  - **常见方法**：
    - `setTranslation(vector, space)`：设置平移。
    - `setRotation(quaternion, space)`：设置旋转。
    - `getScale()`：获取缩放值。
  - **适用对象**：变换节点（如 `transform` 类型的节点）。
- **`MFnMesh`**：
  - **用途**：操作网格几何体（Mesh），如顶点、边、面。
  - **常见方法**：
    - `numVertices()`：获取顶点数量。
    - `getPoints(space)`：获取所有顶点坐标。
    - `setPoint(index, point)`：设置顶点位置。
  - **适用对象**：多边形网格或 NURBS 表面。
- **`MFnCamera`**：
  - **用途**：操作相机节点，如焦距、视场角。
  - **常见方法**：
    - `setFocalLength(value)`：设置焦距。
    - `getFilmAspectRatio()`：获取宽高比。
  - **适用对象**：相机节点。
- **`MFnLight`**（及其子类，如 `MFnPointLight`、`MFnSpotLight`）：
  - **用途**：操作灯光属性，如颜色、强度。
  - **常见方法**：
    - `setColor(color)`：设置灯光颜色。
    - `setIntensity(value)`：设置灯光强度。
  - **适用对象**：灯光节点（如点光源、聚光灯）。

#### **3.2 动画相关类（`maya.OpenMayaAnim`）**
这些类用于操作动画相关数据：
- **`MFnAnimCurve`**：
  - **用途**：操作动画曲线（Animation Curve），如关键帧。
  - **常见方法**：
    - `addKey(time, value)`：添加关键帧。
    - `evaluate(time)`：获取指定时间的值。
  - **适用对象**：动画曲线节点。
- **`MFnSkinCluster`**：
  - **用途**：操作皮肤绑定（Skin Cluster），如权重。
  - **常见方法**：
    - `getWeights(dagPath, component)`：获取顶点权重。
    - `setWeights(dagPath, component, weights)`：设置顶点权重。
  - **适用对象**：皮肤集群节点。
- **`MFnIkHandle`**：
  - **用途**：操作反向动力学（IK）句柄。
  - **常见方法**：
    - `setStartJoint(joint)`：设置 IK 链的起始关节。
  - **适用对象**：IK 句柄。

#### **3.3 特效相关类（`maya.OpenMayaFX`）**
- **`MFnParticleSystem`**：
  - **用途**：操作粒子系统，如粒子位置、速度。
  - **常见方法**：
    - `position(index)`：获取粒子位置。
    - `setCount(count)`：设置粒子数量。
  - **适用对象**：粒子系统节点。

#### **3.4 其他类**
- **`MFnNurbsCurve`** 和 **`MFnNurbsSurface`**：
  - **用途**：操作 NURBS 曲线或表面。
  - **适用对象**：NURBS 几何体。
- **`MFnAttribute`**（及其子类，如 `MFnNumericAttribute`、`MFnTypedAttribute`）：
  - **用途**：创建和定义节点属性（如浮点数、字符串）。
  - **适用对象**：自定义节点（结合 `maya.OpenMayaMPx` 使用）。
- **`MFnDagNode`**：
  - **用途**：操作 DAG 节点（如变换、网格），提供层级结构信息。
  - **常见方法**：
    - `parent(index)`：获取父节点。
    - `child(index)`：获取子节点。
  - **适用对象**：DAG 节点。

### 4. **工作原理**
- **绑定**：`MFn` 类需要绑定到一个有效的 `MObject` 或 `MDagPath`，以确保操作的对象类型正确。例如，`MFnMesh` 只能绑定到网格类型的 `MObject`。
- **类型检查**：通过 `MObject.hasFn(functionSet)` 检查对象是否支持特定功能集（如 `MFn.kMesh`）。
- **操作**：绑定后，使用 `MFn` 类的方法读取或修改对象的属性、几何或行为。
- **销毁**：`MFn` 对象的生命周期与绑定对象相关，需确保 `MObject` 未被场景删除。

### 5. **用途**
- **场景操作**：修改节点属性（如变换位置、网格顶点）。
- **插件开发**：结合 `maya.OpenMayaMPx` 创建自定义节点或命令。
- **动画处理**：编辑关键帧、权重或动力学数据。
- **特效和渲染**：操作粒子、灯光或材质。
- **批量处理**：结合 `MSelectionList` 批量操作选定对象。

### 6. **代码示例**
#### **示例 1：使用 `MFnTransform` 移动选定对象**
```python
import maya.OpenMaya as om

# 获取当前选择列表
sel_list = om.MSelectionList()
om.MGlobal.getActiveSelectionList(sel_list)

# 获取第一个选定对象的 MObject
mobject = om.MObject()
sel_list.getDependNode(0, mobject)

# 检查是否为变换节点并移动
if mobject.hasFn(om.MFn.kTransform):
    transform_fn = om.MFnTransform(mobject)
    transform_fn.setTranslation(om.MVector(5.0, 0.0, 0.0), om.MSpace.kWorld)
    print("Moved node:", om.MFnDependencyNode(mobject).name())
else:
    print("Selected object is not a transform node.")
```

#### **示例 2：使用 `MFnMesh` 获取网格顶点**
```python
import maya.OpenMaya as om

# 获取当前选择列表
sel_list = om.MSelectionList()
om.MGlobal.getActiveSelectionList(sel_list)

# 获取第一个选定对象的 MDagPath
dag_path = om.MDagPath()
sel_list.getDagPath(0, dag_path)

# 检查是否为网格并获取顶点
if dag_path.hasFn(om.MFn.kMesh):
    mesh_fn = om.MFnMesh(dag_path)
    points = om.MPointArray()
    mesh_fn.getPoints(points, om.MSpace.kWorld)
    for i in range(points.length()):
        print(f"Vertex {i}: {points[i].x}, {points[i].y}, {points[i].z}")
else:
    print("Selected object is not a mesh.")
```

### 7. **注意事项**
- **类型安全**：确保 `MObject` 或 `MDagPath` 的类型与 `MFn` 类匹配，否则会导致错误（如将相机绑定到 `MFnMesh`）。
- **性能**：`MFn` 类比 `maya.cmds` 快，但需要手动管理对象状态（如检查 `MObject.isNull()`）。
- **DAG vs 依赖节点**：对于 DAG 节点（如变换、网格），优先使用 `MDagPath` 绑定到 `MFn` 类（如 `MFnMesh`），以处理层级关系。
- **API 2.0 对比**：API 2.0（`maya.api.OpenMaya`）中的 `MFn` 类更 Pythonic，语法更简洁，但 API 1.0 的 `MFn` 仍广泛用于旧项目或插件开发。
- **文档**：`MFn` 类的文档以 C++ 为主，Python 示例较少，需参考 Autodesk 官方文档（`help.autodesk.com`）。

### 8. **总结**
`MFn` 是 Maya Python API 1.0 的核心组件，通过功能集类（如 `MFnTransform`、`MFnMesh`、`MFnAnimCurve`）提供对特定类型对象的操作。它们通过绑定 `MObject` 或 `MDagPath` 实现类型安全的访问，适合场景操作、动画处理、特效开发和插件开发。`MFn` 类种类繁多，覆盖了 Maya 的大多数功能，结合 `MSelectionList` 和 `MObject`，是 API 1.0 的核心操作工具。

# MPlug
在 Maya Python API 1.0 中，`MPlug` 是 `maya.OpenMaya` 模块中的一个核心类，用于表示和操作 Maya 场景中节点上的属性（Attribute）。它是访问和修改节点属性的主要工具，提供对节点数据（如数值、连接关系）的低级控制。以下是对 `MPlug` 的详细介绍，包括定义、功能、用途、关键方法和示例。

### 1. **定义**
- **`MPlug`**（Maya Plug）是 Maya Python API 1.0 中的类，表示一个节点上的特定属性（Attribute），如 `translateX`、`visibility` 或自定义属性。
- 每个 `MPlug` 由两部分组成：
  - **节点**：通过 `MObject` 表示，指定属性所属的节点。
  - **属性**：通过 `MObject` 表示，指定节点上的具体属性（如 `MFnAttribute` 创建的属性）。
- `MPlug` 是一个连接点（Connection Point），用于读取或设置属性的值，或者管理属性之间的连接（如驱动关系）。

### 2. **功能**
- **属性访问**：读取或设置节点属性的值（如浮点数、向量、字符串）。
- **连接管理**：查询、创建或断开属性之间的连接（如将一个节点的 `translateX` 连接到另一个节点的属性）。
- **动态属性**：支持操作动态添加的属性（用户在节点上添加的自定义属性）。
- **高效性**：`MPlug` 提供对属性的低级访问，性能高于 `maya.cmds.getAttr` 或 `maya.cmds.setAttr`。
- **数组和复合属性**：支持处理数组属性（如顶点权重数组）或复合属性（如 `translate` 包含 `translateX`、`translateY`、`translateZ`）。

### 3. **用途**
- **读取和修改属性值**：如获取或设置节点的平移、旋转、可见性等。
- **管理连接**：检查属性的输入/输出连接，或创建新的连接。
- **插件开发**：在自定义节点（`MPxNode`）中操作输入/输出属性。
- **批量处理**：结合 `MSelectionList` 和 `MFnDependencyNode` 批量修改多个节点的属性。
- **动画和绑定**：操作动画曲线的输入或皮肤权重等。

### 4. **关键方法**
以下是 `MPlug` 的一些常用方法：
- **构造函数和绑定**：
  - `MPlug(MObject node, MObject attribute)`：通过节点和属性对象创建 `MPlug`。
  - `setAttribute(MObject attribute)`：绑定 `MPlug` 到指定属性。
- **值操作**：
  - `getValue()`：获取属性的值（根据类型返回，如 `asFloat()`、`asInt()`）。
  - `setValue(value)`：设置属性的值（如 `setFloat(value)`、`setInt(value)`）。
  - `asFloat()`, `asInt()`, `asString()`, `asMObject()`：获取特定类型的值。
- **连接管理**：
  - `isConnected()`：检查属性是否已连接。
  - `connectedTo(MPlugArray, asDestination, asSource)`：获取与该属性连接的 `MPlug` 列表（作为目标或源）。
  - `source()`：获取该属性的输入连接（如果存在）。
  - `destinations()`：获取该属性的输出连接。
- **数组和复合属性**：
  - `isArray()`：检查是否为数组属性。
  - `isCompound()`：检查是否为复合属性。
  - `numElements()`：获取数组属性的元素数量。
  - `child(index)`：获取复合属性的子属性（如 `translateX` 是 `translate` 的子属性）。
  - `elementByLogicalIndex(index)`：访问数组属性的特定元素。
- **状态检查**：
  - `isLocked()`：检查属性是否被锁定（无法修改）。
  - `isKeyable()`：检查属性是否可设置关键帧。
  - `isNull()`：检查 `MPlug` 是否有效。

### 5. **工作原理**
- **绑定**：`MPlug` 需要绑定到一个节点（`MObject`）和属性（通过 `MFnAttribute` 或属性名称）。通常通过 `MFnDependencyNode.findPlug(plugName)` 获取 `MPlug`。
- **值操作**：使用类型特定的方法（如 `asFloat()`、`setDouble()`）读写值，确保类型匹配。
- **连接操作**：通过 `MPlug` 检查或修改依赖图中的连接关系，例如连接两个节点的属性。
- **数组和复合属性**：`MPlug` 支持多级属性操作，如访问 `translate.translateX` 或数组属性（如 `weightList[0]`）。

### 6. **代码示例**
#### **示例 1：读取和设置节点的 `translateX` 属性**
```python
import maya.OpenMaya as om

# 获取当前选择列表
sel_list = om.MSelectionList()
om.MGlobal.getActiveSelectionList(sel_list)

# 获取第一个选定对象的 MObject
mobject = om.MObject()
sel_list.getDependNode(0, mobject)

# 使用 MFnDependencyNode 获取 translateX 属性
node_fn = om.MFnDependencyNode(mobject)
plug = node_fn.findPlug("translateX")

# 读取值
if not plug.isNull():
    print(f"translateX value: {plug.asFloat()}")
    # 设置新值
    plug.setFloat(10.0)
    print(f"Set translateX to: {plug.asFloat()}")
else:
    print("translateX plug not found.")
```

#### **示例 2：检查属性连接**
```python
import maya.OpenMaya as om

# 获取当前选择列表
sel_list = om.MSelectionList()
om.MGlobal.getActiveSelectionList(sel_list)

# 获取第一个选定对象的 MObject
mobject = om.MObject()
sel_list.getDependNode(0, mobject)

# 获取 translateX 的 MPlug
node_fn = om.MFnDependencyNode(mobject)
plug = node_fn.findPlug("translateX")

# 检查输入连接
if plug.isConnected():
    connected_plugs = om.MPlugArray()
    plug.connectedTo(connected_plugs, True, False)  # True: as destination, False: as source
    for i in range(connected_plugs.length()):
        source_plug = connected_plugs[i]
        source_node = om.MFnDependencyNode(source_plug.node())
        print(f"translateX connected to: {source_node.name()}.{source_plug.name()}")
else:
    print("translateX has no input connections.")
```

#### **示例 3：操作数组属性（如顶点权重）**
```python
import maya.OpenMaya as om

# 获取皮肤集群的 MPlug（假设已知皮肤集群节点）
sel_list = om.MSelectionList()
sel_list.add("skinCluster1")  # 假设皮肤集群名称
mobject = om.MObject()
sel_list.getDependNode(0, mobject)

# 获取 weightList 数组属性
node_fn = om.MFnDependencyNode(mobject)
weight_list_plug = node_fn.findPlug("weightList")

# 遍历 weightList 数组
for i in range(weight_list_plug.numElements()):
    weight_plug = weight_list_plug.elementByLogicalIndex(i)
    weights = weight_plug.child(0)  # weightList[i].weights
    for j in range(weights.numElements()):
        value = weights.elementByLogicalIndex(j).asFloat()
        print(f"Vertex {i}, Joint {j}: Weight = {value}")
```

### 7. **注意事项**
- **类型匹配**：读取或设置值时，需确保类型正确（如用 `asFloat()` 读取浮点数属性），否则会抛出错误。
- **属性查找**：使用 `MFnDependencyNode.findPlug(plugName)` 获取 `MPlug`，确保属性名称正确（大小写敏感）。
- **连接管理**：操作连接时，使用 `MDGModifier` 或 `MGlobal.executeCommand` 确保连接的正确性。
- **数组和复合属性**：处理复杂属性（如 `weightList` 或 `translate`）时，需小心索引和子属性操作。
- **性能**：`MPlug` 比 `maya.cmds.getAttr` 快，但需要手动检查有效性（如 `isNull()`、`isLocked()`）。
- **API 2.0 对比**：在 API 2.0（`maya.api.OpenMaya`）中，`MPlug` 的操作更 Pythonic（如通过属性名称直接访问），但 API 1.0 的 `MPlug` 仍广泛用于旧项目。

### 8. **总结**
`MPlug` 是 Maya Python API 1.0 中用于操作节点属性的核心类，提供了读取、设置属性值以及管理属性连接的能力。它支持简单属性（如 `translateX`）、复合属性（如 `translate`）和数组属性（如 `weightList`），是处理节点数据和依赖图关系的关键工具。结合 `MFnDependencyNode` 和 `MSelectionList`，`MPlug` 广泛应用于场景操作、动画处理和插件开发。

```python
import maya.OpenMaya as om

# 创建并添加选择列表
selection_list = om.MSelectionList()
selection_list.add("pPlane1")

# 创建MObject和DagPath
m_obj = om.MObject()
dag_path= om.MDagPath()


# 获取选择列表获取MObject和dagpath
selection_list.getDependNode(0, m_obj)
selection_list.getDagPath(0,dag_path)

# 使用MFn函数集,MFnMesh接收DagPath和MObject，而MFnDepend只接受MObject
mFnMesh = om.MFnMesh(dag_path)# mFnMesh获取的是shape节点：|pPlane1|pPlaneShape1
print(mFnMesh.fullPathName())
mFnDependNode = om.MFnDependencyNode(m_obj)# 获取的是transform节点：pPlane1
print(mFnDependNode.name())

# 获取shape节点的所有连接
mPlugArray = om.MPlugArray()
mFnMesh.getConnections(mPlugArray)
mPlugArray.length()# 连接的plug数量2
print(mPlugArray[0].name())#pPlaneShape1.instObjGroups[0]-材质连接
print(mPlugArray[1].name())# pPlaneShape1.inMesh - Mesh连接

mPlugArray2 = om.MPlugArray()
# connectedTo函数获取连接，shape节点作为目标，获取源节点的所有连接（只有一个）
#参数：array:MPlugArray, asDst:bool, asSrc:bool, ReturnStatus:MStatus = Null
mPlugArray[1].connectedTo(mPlugArray2, True, False)
print(mPlugArray2[0].name()) # polyPlane1.output

# 通过plug获取node
m_obj2 = mPlugArray2[0].node()
mFnDependNode2 = om.MFnDependencyNode(m_obj2)
print(mFnDependNode2.name())# polyPlane1

# 获取属性
mPlug_width = mFnDependNode2.findPlug("width")
mPlug_height = mFnDependNode2.findPlug("height")
mPlug_subWidth = mFnDependNode2.findPlug("subdivisionsWidth")
mPlug_subHeight = mFnDependNode2.findPlug("subdivisionsHeight")

print(mPlug_width.asInt())#10
print(mPlug_height.asInt())#15
```
