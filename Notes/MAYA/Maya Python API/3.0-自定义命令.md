# 概述
编写一个maya命令插件需要一下步骤
以下是使用 Maya Python API 1.0 编写插件的基本步骤，简洁清晰，涵盖核心流程：

### 1. **设置开发环境**
- **确保 Maya 开发环境**：安装 Maya（支持 Python API 1.0 的版本，如 Maya 2016 或更早版本）。确认 Maya 的 Python 解释器可用。
- **导入必要的模块**：使用 `maya.OpenMaya` 模块，这是 Maya Python API 1.0 的核心模块。
- **开发工具**：选择一个代码编辑器（如 PyCharm、VS Code）并配置好 Maya Python 环境（`mayapy`）。

### 2. **创建插件的基本结构**
Maya 插件通常是一个 Python 脚本（`.py` 文件），需要实现特定的函数和类来注册插件。基本结构如下：

```python
import maya.OpenMaya as OpenMaya
import maya.OpenMayaMPx as OpenMayaMPx

# 插件名称
kPluginCmdName = "myCustomCommand"

# 命令类
class MyCommand(OpenMayaMPx.MPxCommand):
    def __init__(self):
        OpenMayaMPx.MPxCommand.__init__(self)

    def doIt(self, args):
        # 插件逻辑在此实现
        print("My custom command is running!")

# 初始化插件
def cmdCreator():
	# 自定义类的实例指针，maya句柄会捕获这个指针进行执行
    return OpenMayaMPx.asMPxPtr(MyCommand())

# 注册插件
def initializePlugin(mobject):
    mplugin = OpenMayaMPx.MFnPlugin(mobject, "YourName", "1.0", "Any")
    mplugin.registerCommand(kPluginCmdName, cmdCreator)

# 卸载插件
def uninitializePlugin(mobject):
    mplugin = OpenMayaMPx.MFnPlugin(mobject)
    mplugin.deregisterCommand(kPluginCmdName)
```
- 我们编写了一个插件类MyCommand继承自OpenMayaMPx.MPxCommand
- `cmdCreator()`函数会创建一个插件类的实例`MyCommand()`，并返回他的指针（asMPxPtr）
- maya会生成一个句柄来捕获这个指针，将其添加到maya核心（maya core）
### 3. **实现插件逻辑**
- **继承基类**：根据插件类型（如命令、节点、工具等），继承适当的基类（如 `MPxCommand`、`MPxNode`）。
- **重写方法**：在 `doIt` 方法（对于命令）或 `compute` 方法（对于节点）中实现核心逻辑。
  - 例如，访问场景中的对象：
    ```python
    def doIt(self, args):
        selection = OpenMaya.MSelectionList()
        OpenMaya.MGlobal.getActiveSelectionList(selection)
        print("Selected objects:", selection)
    ```

### 4. **保存插件**
- 将代码保存为 `.py` 文件（例如 `myPlugin.py`）。
- 放置在 Maya 插件路径中，例如：
  - Windows: `C:\Users\<User>\Documents\maya\plug-ins`
  - macOS/Linux: `~/maya/plug-ins`

### 5. **加载和测试插件**
- **在 Maya 中加载**：
  1. 打开 Maya，进入 **Plug-in Manager**（`Window > Settings/Preferences > Plug-in Manager`）。
  2. 浏览并加载你的 `.py` 文件。
  3. 确保勾选 “Loaded” 和 “Auto load” 选项。
- **测试插件**：
  - 在 Maya 的命令行或脚本编辑器中运行插件命令（例如 `myCustomCommand`）。
  - 检查输出或调试信息。

### 6. **调试和优化**
- **调试**：使用 `print` 或 Maya 的 Script Editor 输出调试信息。也可以用 `OpenMaya.MGlobal.displayInfo/Warning/Error`。
- **错误处理**：确保插件能处理异常情况，例如无效输入。
- **性能优化**：避免不必要的计算，合理使用 Maya API 的数据结构（如 `MObject`, `MFnDagNode`）。

### 7. **扩展功能（可选）**
- **添加参数**：通过 `MSyntax` 和 `MArgList` 支持命令行参数。
  ```python
  def syntaxCreator():
      syntax = OpenMaya.MSyntax()
      syntax.addFlag("-n", "-name", OpenMaya.MSyntax.kString)
      return syntax
  ```
- **创建自定义节点**：继承 `OpenMayaMPx.MPxNode`，定义输入/输出属性。
- **UI 集成**：使用 `maya.cmds` 或 `OpenMayaUI` 添加界面。

### 8. **分发插件**
- 确保插件文件和依赖（如其他 Python 模块）打包完整。
- 提供说明文档，描述插件功能和使用方法。

### 注意事项
- **API 1.0 的局限性**：Maya Python API 1.0 功能较旧，推荐检查是否需要升级到 API 2.0（如果使用较新版本的 Maya）。
- **文档参考**：查阅 Autodesk 官方 Maya API 文档或 `OpenMaya` 模块的帮助（`help(OpenMaya)`）。
- **测试环境**：在不同 Maya 版本上测试兼容性。
# 案例
```python
import maya.OpenMaya as om
import maya.OpenMayaMPx as mpx

# 命令名称
kPluginCommandName = "pluginCommand"

# 自定义命令类，继承自 OpenMayaMPx.MPxCommand
class PluginCommand(mpx.MPxCommand):
    """自定义 Maya 命令插件"""

    def __init__(self):
        """调用父类构造函数"""
        mpx.MPxCommand.__init__(self)

    def doIt(self, argList):
        """执行命令逻辑"""
        print("Do It!")

# 初始化插件
def cmdCreator():
    """
    创建命令实例
    PluginCommand()：创建插件实例
    OpenMayaMPx.asMPxPtr()：返回实例指针
    """
    return mpx.asMPxPtr(PluginCommand())

# 注册插件
def initializePlugin(mobject):
    """
    注册插件到 Maya
    创建MFnPlugin实例
    mobject参数是maya生成的句柄用来捕获插件实例指针
    """
    mplugin = mpx.MFnPlugin(mobject, "CharlesT", "1.0", "Any")
    try:
        # 注册命令,参数为命令名称和命令创建函数
        mplugin.registerCommand(kPluginCommandName, cmdCreator)
    except Exception as e:
        om.MGlobal.displayError(e, f"Failed to register command: {kPluginCommandName}")

# 卸载插件
def uninitializePlugin(mobject):
    """从 Maya 卸载插件"""
    # 创建MFnPlugin实例
    mplugin = mpx.MFnPlugin(mobject)
    try:
        # 注销命令，只需命令名称即可注销
        mplugin.deregisterCommand(kPluginCommandName)
    except Exception as e:
        om.MGlobal.displayError(
            e, f"Failed to deregister command: {kPluginCommandName}"
        )
```
- 将代码保存为：F:\code\maya_api\pluginCommand.py
- 要加载插件，在maya中运行：
```python
import maya.cmds as mc
mc.loadPlugin("F:\code\maya_api\pluginCommand.py")
```
- 即可加载插件，调用`initializePlugin()`
- 然后运行：
```python
mc.pluginCommand()
```
- 自定义命令将执行
- 要卸载插件，执行
```python
mc.unloadPlugin("F:\code\maya_api\pluginCommand.py")
```
	- 调用`uninitializePlugin()`函数
