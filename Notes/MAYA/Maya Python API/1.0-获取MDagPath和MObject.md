# DG节点

在 Autodesk Maya 中，**DG 节点**（Dependency Graph Node，依赖图节点）是 Maya 场景核心架构的基础组成部分。Maya 的依赖图（Dependency Graph, DG）是一个数据流驱动的系统，用于管理场景中对象之间的关系和计算。DG 节点是依赖图中的基本单元，负责存储数据、执行计算或定义场景中的对象行为。以下是对 DG 节点的详细介绍，包括其定义、类型、功能及在 Maya Python API 中的使用。

### 1. **DG 节点概述**
- **定义**：DG 节点是 Maya 依赖图中的一个实体，表示场景中的对象（如几何体、变换、材质）或计算单元（如数学运算）。每个节点包含**属性（Attributes）**，这些属性可以通过连接（Connections）与其他节点的属性交互，形成数据流。
- **依赖图（DG）**：Maya 的场景通过依赖图组织，节点之间的连接定义了数据的输入和输出关系。例如，一个变换节点的矩阵输出可以连接到几何节点的输入，从而驱动其位置。
- **核心作用**：
  - **存储数据**：如位置、旋转、顶点数据等。
  - **执行计算**：如变形、动画、着色等。
  - **管理关系**：通过属性连接控制场景中的行为。

### 2. **DG 节点的类型**
DG 节点可以分为以下几类，根据其功能和用途：
- **依赖节点（Dependency Nodes）**：最基本的节点类型，包含所有非 DAG 节点的节点（如材质、着色器、控制器）。
- **DAG 节点（Directed Acyclic Graph Nodes）**：依赖图中的一种特殊节点，具有层次结构（父子关系），如变换节点（`transform`）、几何体节点（`mesh`）。DAG 节点是 DG 节点的子集。
- **自定义节点**：通过 Maya API（如 `MPxNode`）创建的节点，用于实现特定功能。
- **内置节点**：Maya 提供的标准节点，如 `transform`、`mesh`、`lambert`、`animCurve` 等。

### 3. **DG 节点的组成**
- **属性（Attributes）**：
  - 每个节点包含多个属性，用于存储数据（如 `translateX`、`visibility`）。
  - 属性分为输入和输出，输入属性接收数据，输出属性提供数据。
  - 可以使用 `MFnAttribute` 或 `maya.cmds` 操作属性。
- **连接（Connections）**：
  - 属性之间的连接形成数据流。例如，`animCurve.output` 连接到 `transform.translateX`。
  - 连接可以通过 API（如 `MPlug`）或 `maya.cmds.connectAttr` 创建。
- **功能集（MFn）**：
  - 使用 Maya Python API 的 `MFn` 类（如 `MFnDependencyNode`、`MFnTransform`）来操作节点的属性和行为。
- **节点类型**：
  - 每个节点有唯一的类型标识（如 `kTransform`、`kMesh`），可通过 API 查询。

### 4. **DG 节点的工作原理**
- **数据流驱动**：Maya 的依赖图是数据驱动的，节点的计算基于其输入属性的值。当输入属性发生变化，Maya 会标记相关节点为“脏（dirty）”，触发重新计算。
- **计算过程**：
  - 每个节点有一个 `compute` 方法（在自定义节点中由开发者实现），用于根据输入计算输出。
  - Maya 的调度器（Evaluator）决定节点的计算顺序，确保依赖关系正确处理。
- **脏标记（Dirty Flag）**：
  - 当输入属性改变时，节点被标记为“脏”，Maya 会重新计算受影响的节点。
  - 开发者可以通过 API 控制脏标记（如 `MDataBlock.setClean`）。

### 5. **DG 节点在 Maya Python API 中的使用**
Maya Python API 提供了丰富的工具来操作 DG 节点，主要通过 `OpenMaya` 或 `maya.api.OpenMaya` 模块。以下是典型用法：

#### **查询 DG 节点**
使用 `MFnDependencyNode` 获取节点信息：
```python
from maya import OpenMaya

# 获取当前选中的节点
sel_list = OpenMaya.MSelectionList()
OpenMaya.MGlobal.getActiveSelectionList(sel_list)
obj = OpenMaya.MObject()
sel_list.getDependNode(0, obj)

# 使用 MFnDependencyNode 查询节点信息
fn_dep = OpenMaya.MFnDependencyNode(obj)
print(f"Node Name: {fn_dep.name()}")
print(f"Node Type: {fn_dep.typeName()}")
```

#### **遍历所有 DG 节点**
使用 `MItDependencyNodes` 迭代器遍历场景中的节点：
```python
from maya import OpenMaya

# 遍历所有依赖节点
iterator = OpenMaya.MItDependencyNodes()
while not iterator.isDone():
    obj = iterator.thisNode()
    fn_dep = OpenMaya.MFnDependencyNode(obj)
    print(f"Node: {fn_dep.name()}, Type: {fn_dep.typeName()}")
    iterator.next()
```

#### **操作 DAG 节点**
DAG 节点是 DG 节点的子集，具有层次结构，使用 `MDagPath` 和 `MFnDagNode` 操作：
```python
from maya import OpenMaya

# 获取选中对象的 DAG 路径
sel_list = OpenMaya.MSelectionList()
OpenMaya.MGlobal.getActiveSelectionList(sel_list)
dag_path = OpenMaya.MDagPath()
sel_list.getDagPath(0, dag_path)

# 使用 MFnDagNode 获取信息
fn_dag = OpenMaya.MFnDagNode(dag_path)
print(f"DAG Node: {fn_dag.fullPathName()}")
```

#### **创建自定义 DG 节点**
使用 `MPxNode` 创建自定义节点，定义其计算逻辑：
```python
from maya import OpenMaya, OpenMayaMPx

class SimpleMathNode(OpenMayaMPx.MPxNode):
    kPluginNodeId = OpenMaya.MTypeId(0x00080001)
    aInput1 = OpenMaya.MObject()
    aInput2 = OpenMaya.MObject()
    aOutput = OpenMaya.MObject()

    def __init__(self):
        super(SimpleMathNode, self).__init__()

    def compute(self, plug, data):
        if plug == SimpleMathNode.aOutput:
            input1 = data.inputValue(SimpleMathNode.aInput1).asFloat()
            input2 = data.inputValue(SimpleMathNode.aInput2).asFloat()
            result = input1 + input2
            output_handle = data.outputValue(SimpleMathNode.aOutput)
            output_handle.setFloat(result)
            data.setClean(plug)

def creator():
    return OpenMayaMPx.asMPxPtr(SimpleMathNode())

def initialize():
    fn_attr = OpenMaya.MFnNumericAttribute()
    SimpleMathNode.aInput1 = fn_attr.create("input1", "in1", OpenMaya.MFnNumericData.kFloat, 0.0)
    SimpleMathNode.aInput2 = fn_attr.create("input2", "in2", OpenMaya.MFnNumericData.kFloat, 0.0)
    SimpleMathNode.aOutput = fn_attr.create("output", "out", OpenMaya.MFnNumericData.kFloat, 0.0)
    fn_attr.setReadable(True)
    fn_attr.setWritable(False)
    SimpleMathNode.addAttribute(SimpleMathNode.aInput1)
    SimpleMathNode.addAttribute(SimpleMathNode.aInput2)
    SimpleMathNode.addAttribute(SimpleMathNode.aOutput)
    SimpleMathNode.attributeAffects(SimpleMathNode.aInput1, SimpleMathNode.aOutput)
    SimpleMathNode.attributeAffects(SimpleMathNode.aInput2, SimpleMathNode.aOutput)

def initializePlugin(plugin):
    fn_plugin = OpenMayaMPx.MFnPlugin(plugin)
    fn_plugin.registerNode("simpleMathNode", SimpleMathNode.kPluginNodeId, creator, initialize)

def uninitializePlugin(plugin):
    fn_plugin = OpenMayaMPx.MFnPlugin(plugin)
    fn_plugin.deregisterNode(SimpleMathNode.kPluginNodeId)
```
- **说明**：
  - 创建一个自定义节点 `simpleMathNode`，计算两个输入属性的和。
  - 使用 `MFnNumericAttribute` 定义输入和输出属性。
  - 在 `compute` 方法中实现计算逻辑。
  - 通过 `attributeAffects` 定义属性依赖关系。

### 6. **DG 节点的关键特性**
- **动态性**：DG 节点支持动态添加属性（Dynamic Attributes），允许在运行时扩展节点功能。
- **层次结构**：DAG 节点支持父子关系，适用于变换和几何体；非 DAG 节点（如材质）仅存在于依赖图中。
- **高效计算**：Maya 的依赖图优化了计算，只更新“脏”节点，减少冗余计算。
- **连接性**：属性连接支持复杂的数据流，如动画曲线驱动变换，或材质驱动渲染。

### 7. **注意事项**
- **性能**：操作大量 DG 节点时，需优化代码（如批量处理、减少不必要的查询）。
- **节点类型**：确保使用正确的 `MFn` 类（如 `MFnMesh` 用于网格，`MFnTransform` 用于变换）。
- **线程安全**：自定义节点需考虑 Maya 的多线程环境，避免数据竞争。
- **脏标记管理**：在自定义节点中正确设置脏标记（如 `data.setClean`），确保依赖图更新正确。
- **API 版本**：API 2.0 的 `MFn` 类（如 `maya.api.OpenMaya.MFnDependencyNode`）更简洁，推荐使用。

### 9. **总结**
DG 节点是 Maya 场景管理的核心，分为依赖节点和 DAG 节点，负责存储数据、执行计算和管理关系。通过 Maya Python API（`OpenMaya` 或 `maya.api.OpenMaya`），开发者可以查询、修改节点或创建自定义节点。`MPxNode` 用于扩展 DG 节点功能，`MFn` 类用于操作现有节点，两者结合实现复杂功能。

# DAG节点
在Autodesk Maya软件中，DAG节点（Directed Acyclic Graph Node，定向非循环图节点）是Maya场景层次结构的核心组成部分，用于表示和组织场景中的对象及其关系。以下是对DAG节点的详细介绍：

### 1. **什么是DAG节点？**
DAG节点是Maya中用于表示场景中对象的节点，存储了对象的几何、变换（位置、旋转、缩放）和其他相关属性的信息。DAG是“有向无环图”的缩写，意味着这些节点以有向的方式连接（父子关系），且不会形成循环。

- **DAG的含义**：DAG是一种树状结构，节点之间通过父子关系组织，父节点影响子节点（例如，父节点的变换会传递给子节点）。
- **节点类型**：DAG节点主要包括变换节点（Transform Node）和形状节点（Shape Node）：
  - **变换节点**：存储对象的空间信息（如位置、旋转、缩放），例如一个立方体的变换节点控制它在场景中的位置和方向。
  - **形状节点**：存储对象的几何信息（如顶点、法线、UV等），通常是变换节点的子节点。例如，一个立方体的形状节点定义其几何形状。
  
### 2. **DAG节点的层次结构**
在Maya中，DAG节点通过层次结构组织，表现为Outliner（大纲视图）中的父子关系：
- **父子关系**：父节点可以有多个子节点，子节点继承父节点的变换。例如，一个手臂模型的父节点可能是上臂，子节点是前臂和手。
- **世界空间与局部空间**：每个DAG节点的变换是相对于其父节点的（局部空间）。如果没有父节点，则相对于世界空间。
- **路径**：每个DAG节点在场景中有唯一的DAG路径（DAG Path），用于标识节点在层次结构中的位置。例如，`pCube1|pCube2`表示pCube2是pCube1的子节点。

### 3. **DAG节点的主要属性**
DAG节点包含多种属性，存储在节点的属性编辑器中，常见包括：
- **变换属性**：如translate（位移）、rotate（旋转）、scale（缩放）。
- **可见性**：控制节点是否在视图中显示（visibility属性）。
- **层级信息**：父节点、子节点关系。
- **形状相关**：形状节点的几何数据，如顶点位置、材质信息等。
- DAG节点（Directed Acyclic Graph Node）是DG节点（Dependency Graph Node）的一种特殊子集。

### 4. **DAG节点与Dependecy Graph（依赖图）**
虽然DAG节点是Maya场景层次结构的一部分，但它们与依赖图（Dependency Graph，DG）节点有区别：
- **DAG节点**：主要处理场景中的空间和层次关系，涉及变换和几何。
- **DG节点**：处理非空间的依赖关系，如材质、动画曲线、约束等，属于计算和逻辑处理。
- 两者通过节点的连接（如形状节点的输出连接到材质节点）共同构成了Maya场景的完整数据流。

### 5. **DAG节点的用途**
- **场景管理**：通过DAG节点的层次结构，可以方便地组织和管理复杂的场景，如角色、道具、环境等。
- **动画与绑定**：DAG节点控制对象的变换，动画师通过关键帧或约束操作这些节点实现动画。
- **渲染与模拟**：形状节点提供几何数据，供渲染器或物理模拟使用。
- **脚本与编程**：通过Maya的API（如Python或MEL），可以访问和操作DAG节点，实现自动化任务。例如，获取某个对象的DAG路径或修改其变换属性。

### 6. **操作DAG节点的常用方法**
- **通过界面**：
  - **Outliner**：查看和编辑DAG节点的层次结构。
  - **Hypergraph**：以图形化方式显示DAG节点的连接。
  - **Attribute Editor**：修改节点的属性。
- **通过脚本**：
  - 使用`pymel`或`maya.cmds`操作DAG节点。例如：
    ```python
    import maya.cmds as cmds
    # 创建一个立方体（包含变换节点和形状节点）
    cube = cmds.polyCube()[0]  # 返回变换节点
    # 获取形状节点
    shape = cmds.listRelatives(cube, shapes=True)[0]
    print(f"Transform Node: {cube}, Shape Node: {shape}")
    ```
  - 获取DAG路径：` cmds.ls("pCube1", long=True)` 返回完整路径。
- **通过API**：使用OpenMaya API（如`MDagPath`）精确操作DAG节点。

### 7. **注意事项**
- **唯一性**：DAG节点在同一层次结构中必须有唯一名称，否则可能导致引用错误。
- **性能**：复杂的DAG层次结构可能影响场景性能，需合理组织节点。
- **实例化**：DAG节点支持实例化（Instance），允许多个变换节点共享同一个形状节点，节省内存。

### 总结
DAG节点是Maya场景管理的基础，负责存储和管理对象的空间和几何信息。通过父子关系和变换属性，DAG节点实现了场景的层次化组织，广泛应用于建模、动画、渲染等流程。掌握DAG节点的结构和操作方式（通过界面或脚本），可以更高效地使用Maya进行三维创作。
# MObject 和MSelectionList
在 Maya Python API 1.0 中，`MObject` 和 `MSelectionList` 是核心类，广泛用于操作和访问 Maya 场景中的数据。以下是对这两者的详细介绍，包括定义、功能、用途和示例。

### 1. **`MObject`**
#### **定义**
- **`MObject`** 是 Maya Python API 1.0（位于 `maya.OpenMaya` 模块）中的核心数据结构，用于表示 Maya 场景中的任何对象，例如节点（变换、网格、相机等）、组件（顶点、边、面）或其他数据实体。
- 它是 Maya 内部的句柄（Handle），类似于 C++ 中的指针，指向底层的 Maya 对象，但不直接包含对象的具体数据。开发者通过绑定 `MObject` 到功能集（`MFn` 类）来操作具体类型的数据。

#### **功能**
- **通用性**：`MObject` 是一个通用的对象句柄，可以表示任何类型的 Maya 对象（如变换节点、网格、灯光、属性等）。
- **绑定到功能集**：通过 `MFn` 类（如 `MFnTransform`、`MFnMesh`）绑定 `MObject`，以访问和操作对象的特定属性或行为。
- **高效性**：`MObject` 提供了对 Maya 核心数据的低级访问，性能高于 `maya.cmds`，适合处理复杂场景。
- **生命周期管理**：`MObject` 是临时的，场景中的对象可能被删除或更改，需检查其有效性（通过 `MObject.hasFn` 或 `MObject.isNull`）。

#### **用途**
- 获取和操作场景中的节点（如变换、网格、相机）。
- 访问节点的属性（如通过 `MPlug`）。
- 用于插件开发，传递节点数据（如在 `MPxNode` 中）。
- 处理 DAG（有向无环图）或依赖图中的对象。

#### **关键方法**
- `MObject.isNull()`：检查 `MObject` 是否有效。
- `MObject.hasFn(functionSet)`：检查 `MObject` 是否支持特定功能集（如 `MFn.kTransform`）。
- `MObject.apiType()`：返回对象的 API 类型（如 `MFn.kMesh` 表示网格）。

#### **示例**
获取场景中第一个选中对象的 `MObject` 并打印其名称：
```python
import maya.OpenMaya as om

# 获取当前选择列表
sel_list = om.MSelectionList()
om.MGlobal.getActiveSelectionList(sel_list)

# 获取第一个选定对象的 MObject
mobject = om.MObject()
sel_list.getDependNode(0, mobject)

# 使用 MFnDependencyNode 获取节点名称
if not mobject.isNull():
    node_fn = om.MFnDependencyNode(mobject)
    print("Selected node:", node_fn.name())
else:
    print("No valid object selected.")
```

### 2. **`MSelectionList`**
#### **定义**
- **`MSelectionList`** 是 `maya.OpenMaya` 模块中的类，用于存储和管理 Maya 场景中选定的对象或组件（如节点、顶点、边、面）。
- 它是一个容器，类似 Python 列表，保存一组 `MObject` 或 `MDagPath`，表示当前选中的对象或组件。

#### **功能**
- **存储选定对象**：保存用户在 Maya 界面中选择的节点或组件（如顶点、边）。
- **支持多种数据类型**：可以存储节点（`MObject`）、DAG 路径（`MDagPath`）或组件（如顶点索引）。
- **迭代和访问**：提供方法遍历选定对象，获取其 `MObject` 或 `MDagPath`。
- **动态管理**：支持添加、移除或清空选择项，适合脚本和插件开发。

#### **用途**
- 获取用户当前选中的对象或组件。
- 批量处理选定节点（如修改多个对象的属性）。
- 在插件中处理用户交互（如基于选择执行操作）。
- 结合 `MDagPath` 处理层级结构中的对象。

#### **关键方法**
- `MSelectionList.add(name)`：通过对象名称添加对象到选择列表。
- `MSelectionList.getDependNode(index, MObject)`：获取指定索引处的 `MObject`。
- `MSelectionList.getDagPath(index, MDagPath)`：获取指定索引处的 `MDagPath`（用于 DAG 节点）。
- `MSelectionList.length()`：返回选择列表中的对象数量。
- `MSelectionList.clear()`：清空选择列表。
- `MSelectionList.getSelectionStrings()`：返回选择对象的名称列表。

#### **示例**
获取当前选中的所有对象名称：
```python
import maya.OpenMaya as om

# 获取当前选择列表
sel_list = om.MSelectionList()
om.MGlobal.getActiveSelectionList(sel_list)

# 遍历选择列表
for i in range(sel_list.length()):
    mobject = om.MObject()
    sel_list.getDependNode(i, mobject)
    if not mobject.isNull():
        node_fn = om.MFnDependencyNode(mobject)
        print("Selected node:", node_fn.name())
```

获取选中的顶点组件：
```python
import maya.OpenMaya as om

# 获取当前选择列表
sel_list = om.MSelectionList()
om.MGlobal.getActiveSelectionList(sel_list)

# 遍历选择列表，检查组件
for i in range(sel_list.length()):
    dag_path = om.MDagPath()
    component = om.MObject()
    sel_list.getDagPath(i, dag_path, component)
    
    if not component.isNull():
        # 检查是否为顶点组件
        if component.hasFn(om.MFn.kMeshVertComponent):
            vertex_iter = om.MItMeshVertex(dag_path, component)
            while not vertex_iter.isDone():
                print("Selected vertex index:", vertex_iter.index())
                vertex_iter.next()
```

### 3. **两者的关系**
- **`MObject` 是单个对象的句柄**，表示场景中的一个实体（如节点或组件）。
- **`MSelectionList` 是 `MObject` 的集合**，用于管理多个选定对象或组件。
- **典型用法**：通常通过 `MSelectionList` 获取选中的 `MObject`，然后绑定到 `MFn` 类（如 `MFnTransform` 或 `MFnMesh`）进行具体操作。
- **互补性**：`MSelectionList` 提供批量访问的入口，而 `MObject` 是操作的核心句柄。

### 4. **注意事项**
- **有效性检查**：操作 `MObject` 前，需检查 `isNull()` 或 `hasFn()`，因为对象可能已被删除或不可用。
- **类型安全**：`MObject` 是通用的，绑定到错误的 `MFn` 类会导致错误（如将网格绑定到 `MFnTransform`）。
- **性能**：`MSelectionList` 和 `MObject` 的操作比 `maya.cmds` 更快，但需要手动管理内存和状态。
- **DAG vs 依赖节点**：对于 DAG 节点（如变换、网格），建议使用 `MDagPath`（通过 `MSelectionList.getDagPath` 获取）以处理层级结构，而非仅依赖 `MObject`。
- **API 2.0 的改进**：在 API 2.0（`maya.api.OpenMaya`）中，`MObject` 和 `MSelectionList` 的操作更 Pythonic（如通过迭代器访问），但 API 1.0 仍广泛用于旧项目。

### 5. **总结**
- **`MObject`** 是 Maya Python API 1.0 的核心句柄，表示场景中的单个对象，需结合 `MFn` 类操作其属性或行为。
- **`MSelectionList`** 是管理选定对象的容器，用于批量获取和处理 `MObject` 或 `MDagPath`，支持节点和组件操作。
- 两者结合使用是 API 1.0 的常见模式，适用于场景操作、选择处理和插件开发。`MObject` 提供精确的单对象控制，`MSelectionList` 提供批量选择的灵活性。

```python
import maya.OpenMaya as om

# 创建选择列表
selection_list = om.MSelectionList()

dag_path= om.MDagPath()

print(dag_path.fullPathName())

# 创建MObject
m_obj = om.MObject()
# 获取选择列表的第0个对象的DependNode写入MObject
selection_list.getDependNode(0, m_obj)
# 获取当前MObject类型
m_obj.apiTypeStr()# 'kTransform'
m_obj.apiType() # 110
```
