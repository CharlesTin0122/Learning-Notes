Quad Remesher 是目前三维软件里（特别是Maya、Blender和Max）最顶级的自动四边形拓扑插件之一。

结合你作为**动画TA和绑定**的背景，这个工具对于处理那些拓扑杂乱（比如扫描模型、ZBrush雕刻的高模、或者布线糟糕导致无法顺利刷权重的模型）非常有用。

以下是截图中各个参数的详细含义，以及它们在绑定和动画管线中的实际意义：

### 1. 基础设置

- **Target Quad Count (目标四边形数量)**: `截图当前值：5000` 你期望重新拓扑后模型包含的大致四边形面数。注意这是一个“目标值”，算法为了保证布线质量，最终生成的面数可能会有轻微的上下浮动。

### 2. Quads size settings (四边形尺寸设置 - 控制网格疏密)

这个面板主要控制多边形在模型表面的分布均匀度。

- **Adaptive Size (自适应尺寸)**: `截图当前值：50` (范围通常是0-100)
    - **值偏高 (如 100)**：网格大小高度自适应曲率。在细节多、弯曲度高的地方会生成密集的小格子；在平坦区域会生成稀疏的大格子。适合**硬表面**或静态模型。
    - **值偏低 (如 0)**：强制生成大小一致的均匀网格。
    - 💡 **TA视角**：对于**需要做骨骼形变（Deformation）的角色模型**，我们通常希望网格大小相对均匀，这样蒙皮权重的过渡才会平滑，所以给角色拓扑时这个值往往设置得偏低（比如0~10）。
- **Adaptive Quad Count (自适应四边形数量)**: `未勾选` 如果勾选，算法会优先满足“Adaptive Size”的计算需求，从而**打破**最上面你设置的 `5000` 面数限制。如果为了保细节可以勾选，如果为了严控项目面数预算则不勾选。
- **Use Vertex Colors for Quads Density (使用顶点颜色控制密度)**: `未勾选` 非常高阶实用的功能。勾选后，你可以先在Maya里使用“绘制顶点颜色工具”（Paint Vertex Color），用不同的颜色灰度来手动控制局部面数密度（比如在角色脸部画红色增加密度，在后脑勺画蓝色减少密度）。
- **Quads Density (paint) (绘制密度倍增器)**: `截图当前值：1.00` 配合上述顶点颜色功能使用的全局倍增器，控制你绘制的密度的强度。

### 3. Edge Loops Control (循环边控制 - 引导布线走向)

这一块是让自动布线看起来像“人工布线”的关键，它决定了边的流向（Edge Flow）。

- **Use Materials (使用材质边界引导)**: `未勾选` 如果模型上分配了多个不同的材质球（比如衣服一个材质，皮肤一个材质），勾选后，插件会在材质的交界处强制生成一圈完美的循环边。
- **Use existing Harden/Soften edges (使用已有的软硬边)**: `未勾选` 💡 **TA视角**：极其好用！它会直接读取Maya自身的“软硬边”数据。如果你提前手动把需要折角的地方设置了 Hard Edges，插件就会严格沿着这些硬边进行循环边排布。
- **Use Normals Splitting (使用法线分裂)**: `未勾选` 基于模型法线断开的地方来引导循环边，原理类似于上一个软硬边。
- **Detect Hard-Edges by angle (按角度自动检测硬边)**: `已勾选` 插件会自动计算相邻面的夹角（比如大于某个度数的直角或锐角），并在这些拐角处生成硬边和循环边布线。**截图中勾选了此项，说明当前设置偏向于处理带有明显结构转折的模型（如硬表面道具或机械体）。**

### 4. Misc (杂项)

- **Symmetry (对称) [ X | Y | Z ]**: `均未勾选` 💡 **TA视角**：**如果是给角色做拓扑，一定要勾选对应的对称轴（通常是X轴）！** 否则左右两边布线不对称，后期镜像蒙皮权重（Mirror Skin Weights）时会遇到巨大的麻烦。
- **Hide Input Object (隐藏输入对象)**: `已勾选` 点击计算完成后，自动把你的原始高模/原模型隐藏掉（按H键的效果），方便你直接在视图里检查新生生成的低模拓扑。

**总结建议：** 如果你是在处理UE项目里的**角色/怪物**蒙皮模型，建议的设置是：

1. 降低 `Adaptive Size`（比如调到0-20），保证形变网格均匀。
2. 务必在下方 `Symmetry` 中勾选 X轴 对称。
3. 如果模型面部细节不够，可以尝试勾选 `Use Vertex Colors` 来手动刷高面部布线密度。
