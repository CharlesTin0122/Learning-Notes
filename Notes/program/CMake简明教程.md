# CMake初体验
## `C\C++`编译流程
1. 预处理：C和CPP文件经过预处理器进行预处理，对头文件进行展开，对应的宏进行替换，去掉注释，预处理结束后文件仍然是源文件C和CPP文件
2. 编译：源文件经过编译器(GCC，Clang)进行编译，编译结束后得到汇编文件。
3. 汇编：汇编器对汇编文件进行处理，得到二进制object文件，也就是`.obj`文件
4. 链接：链接器对二进制object文件进行链接，得到二进制文件`.exe`
## 概念
- CMake是一个开源的跨平台的自动化构建工具，通过CMake我们可以轻松的构建和管理我们的项目。
