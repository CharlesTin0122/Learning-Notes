# 1）二进制和位的概念
## 无符号二进制表示

- 四位二进制数表示的范围是，$0000-1111$，$0-(8+4+2+1)$，即$0 \rightarrow (2^4-1)$
- int,整型，32位二进制数，可以表示$0 \rightarrow(2^{32}-1)$
- long,长整型，64位二进制数，可以表示$0 \rightarrow(2^{64}-1)$
## 有符号二进制
### 非负数
- $0:(0000)$,最高位（最左位）是符号位，0表示非负。后面三位$000$是数值位.
- $1 : (0001)$
- $2 : (0010)$
- ...
- 7 : (0111)
> 四位非负二进制数，首位为符号位，其余为数值位，只能表示到0-7。
### 负数
####  负数十进制转二进制、
- 要表示一个负数，首先确定其绝对值的二进制表示形式(无符号正值)，然后取其二进制补码。二进制补码是将该数的绝对值用二进制表示，然后将其按位**取反加一**，或者**减一取反**。
- -1 : (1111)
	- 无符号+1为(0001)
	- 每位取反为(1110)
	- 然后加一为(1111)
- -2 : (1110)
	- 无符号+2为(0010)
	- 2-1为(0001)
	- 每位取反为(1110)
- ...
- -7 : (1001)
	- 无符号+7为(0111)
	- 7-1为(0110)
	- 每位取反为(1001)
- -8 : (1000)
	- 无符号+8为(1000)
	- 8-1为(0111)
	- 每位取反为(1000)
####  负数二进制转十进制
- 取反，加一，相反数。
- (1001) :  -7
	- 首位符号位为1，判断此数为负
	- 每位取反为(0110)
	- 将值加1为(0111)
	- 无符号(0111)为7，故有符号(1001) 为-7
- (1000) : -8
	- 首位符号位为1，判断此数为负
	- 每位取反为(0111)
	- 将值加1为(1000)
	- 无符号(1000)为8，故有符号(1000)为-8

> [!INFO] INFO
> 有符号4位二进制数可表示：-8 ~ -1， 0~+7（16个数字），其中:
>-8 ~ -1为负数值(1000, 1001..., 1111)，共8个
> 0~+7为非负数值，(0000, 0001..., 0111)，共8个
> 同理：有符号32位二进制数，
> $-2^{31}\rightarrow-1$为$2^{31}$个负数，$0 \rightarrow2^{31}-1$为$2^{31}$个非负数，有符号32位二进制数共有$2^{32}$个数。
### 取反和相反数
#### 取反
- (00101111)取反`~`为(11010000)，1变0,0变1。
#### 相反数
- 取反加一获得相反数

>[! INFO] INFO
>  二进制的补码和相反数在数学上是不同的概念，但它们之间存在一定的关系。
>1. **相反数**：一个数的相反数是指与该数的和为零的数。例如，对于十进制数，5的相反数是-5，-5的相反数是5。在二进制中，一个数的相反数可以通过对该数的每一位取反然后加1来得到。例如，十进制数5的二进制表示是101，其相反数是010（每一位取反）+ 1 = 011。
>2. **补码**：补码是用来表示有符号整数的一种编码方式。在补码表示法中，正数的补码与其本身相同，而负数的补码是其相反数的二进制表示形式。补码有一个重要的特性是，在补码中，负数的加法运算可以与正数的加法运算一样进行，而不需要额外的处理。
#### 整数最小值的特殊性：取绝对值和相反数还是自己。
- 有符号整数最小的负数（4位二进制数-8(1000)，32位-2147483648(1000...00)）,因为没有对应的正数（四位二进制最小值-8，最大值7），故无法转换相反数，取绝对值和相反数还是自己。
# 2）位运算
- `|`,`&`是位运算，`||`,`&&`是逻辑运算。
## 或运算`|`
- 对应每位只要有1，结果就是1。
## 与运算`&`
- 对应每位都是1，结果才是1。
## 异或运算`^`
- 对应每位相同为0，不同为1。
## 左移`>>`,右移`<<`
- 非负数左移一位$\times2$，右移一位$\div 2$，只对非负数有效，负数不要用。
# 3）为什么这么设计二进制
- 为了加法的逻辑是一套逻辑，没有条件转移
	- 非负+非负
	- 负+非负
	- 非负+负
	- 负+负
- 共用一套加法逻辑
# 4）打印二进制函数
```cpp
#include<iostream>
#include<string>
using namespace std;
//打印int数(32位)的二进制形式
void print_binary(int num)
{
	for (int i = 31; i >= 0; i--)//0-31共32位
	{
		//三目运算符，condition ? value_if_true : value_if_false
		//((num & (1 << i)) == 0)条件成立则打印"0"，否则打印"1"。
		//num 与运算& 1左移i位结果是否为0，可用来判断此位的数值。
		//三目运算符的优先级比<<运算符低，因此需要用括号将左移表达式括起来，使其先执行
		cout << (((num & (1 << i)) == 0) ? "0" : "1");
	}
}

//主函数
int main()
{
	print_binary(2);

	system("pause");
	return 0;
}
```
