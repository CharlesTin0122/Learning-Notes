# 概念和特点
## 概念
- 快速排序（quick sort）是一种基于分治策略的排序算法，运行高效，应用广泛。
## 特点
- 是冒泡排序的升级算法，每次选择基准数，把小于基准数的放到基准数的左边，大以基准数的放到基准数右边。采用分治思想处理剩余元素，直至整个序列变为有序序列。

# 算法思想
- 选择数组中的某个元素作为“基准数”，将所有小于基准数的元素移到其左侧，而大于基准数的元素移到其右侧。然后对基准数左边和右边的序列继续操作。直到整个序列有序。

# 实现步骤
1. 选取数组最左端元素作为基准数，初始化两个索引 `l` 和 r 分别指向数组的两端。`val = arr[l]`
2. 从`r`开始向前查找小于`val`的数字，从`l`开始向后查找大于`val`的数字,找到后交换。
4. 重复上面的过程，直到`l == r`。将基准数交换至两个子数组的分界线。
5. 此时，基准数`val`左边的数值都比基准数小，右边的都比基准数大。
6. 然后，对基准数`val`左边的序列和右边的序列分别进行上述步骤（递归）。

# 代码
```cpp
/* 元素交换 */
void swap(int nums[], int i, int j)
{
    if (i != j)
    { // 只有在 i != j 时才进行交换
        int tmp = nums[i];
        nums[i] = nums[j];
        nums[j] = tmp;
    }
}

/* 哨兵划分 */
int partition(int nums[], int left, int right)
{
    int i = left, j = right;
    int pivot = nums[left]; // 使用 pivot 代替 nums[left]

    while (i < j)
    {
        // 从右向左找第一个小于 pivot 的元素
        while (i < j && nums[j] >= pivot)
            j--;
        // 从左向右找第一个大于 pivot 的元素
        while (i < j && nums[i] <= pivot)
            i++;
        swap(nums, i, j); // 交换这两个元素
    }
    swap(nums, i, left); // 将 pivot 放置到正确位置
    return i;            // 返回 pivot 的最终位置
}

/* 快速排序 */
void quickSort(int nums[], int left, int right)
{
    if (left >= right)
        return;
    int pivot = partition(nums, left, right);
    quickSort(nums, left, pivot - 1);  // 递归左子数组
    quickSort(nums, pivot + 1, right); // 递归右子数组
}
```
# 算法优化
- 随着快排算法的执行，数据越来越趋于有序，在一定范围内，可以采用插入排序来代替快速排序。
```cpp
/* 快速排序 */
void quickSort(int nums[], int left, int right)
{
    if (left >= right)
        return;
    // 算法优化1，当函数进行到数据量小于指定数量时，使用插入排序
    if (right - left < 100)
    {
        insertionSort(nums, left, right);
        return;
    }
    int pivot = partition(nums, left, right);
    quickSort(nums, left, pivot - 1);  // 递归左子数组
    quickSort(nums, pivot + 1, right); // 递归右子数组
}
```
- 三数取中法，旨在挑选合适的基准数，防止快排退化成冒泡排序。`left`，`middle = (left + right) / 2`，`right`,三个索引中取值在中间`(arr[left] < arr[middle] < arr[right])`的数`arr[middle]`放到首位元素作为基准数。
```cpp
/* 选取三个候选元素的中位数 */
int medianThree(int nums[], int left, int mid, int right)
{
    int l = nums[left], m = nums[mid], r = nums[right];
    if ((l <= m && m <= r) || (r <= m && m <= l))
        return mid; // m 在 l 和 r 之间
    if ((m <= l && l <= r) || (r <= l && l <= m))
        return left; // l 在 m 和 r 之间
    return right;
}
/* 哨兵划分 */
int partition(int nums[], int left, int right)
{
    // 选取三个候选元素的中位数
    int med = medianThree(nums, left, (left + right) / 2, right);
    // 将中位数交换至数组最左端
    swap(nums, left, med);
    // 以 nums[left] 为基准数
    int i = left, j = right;
    int pivot = nums[left]; // 使用 pivot 代替 nums[left]

    while (i < j)
    {
        // 从右向左找第一个小于 pivot 的元素
        while (i < j && nums[j] >= pivot)
            j--;
        // 从左向右找第一个大于 pivot 的元素
        while (i < j && nums[i] <= pivot)
            i++;
        swap(nums, i, j); // 交换这两个元素
    }
    swap(nums, i, left); // 将 pivot 放置到正确位置
    return i;            // 返回 pivot 的最终位置
}
```

# 算法分析
- **时间复杂度为 𝑂(𝑛log⁡𝑛)、非自适应排序**：在平均情况下，哨兵划分的递归层数为 log⁡𝑛 ，每层中的总循环数为 𝑛 ，总体使用 𝑂(𝑛log⁡𝑛) 时间。在最差情况下，每轮哨兵划分操作都将长度为 𝑛 的数组划分为长度为 0 和 𝑛−1 的两个子数组，此时递归层数达到 𝑛 ，每层中的循环数为 𝑛 ，总体使用 𝑂(𝑛2) 时间。
- 每次分区都能把数组均匀地分为两部分。因此递归调用的深度为 `log n`。在这种情况下，递归栈的深度为 `O(log n)`，因此整体的空间复杂度为 `O(log n)`。
- **非稳定排序**：在哨兵划分的最后一步，基准数可能会被交换至相等元素的右侧。
