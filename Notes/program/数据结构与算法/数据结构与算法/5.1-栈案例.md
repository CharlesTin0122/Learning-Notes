给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s` ，判断字符串是否有效。

有效字符串需满足：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

**示例 1：**

```
输入：s = "()"
输出：true
```

**示例 2：**

```
输入：s = "()[]{}"
输出：true
```

**示例 3：**

```
输入：s = "(]"
输出：false
```

**提示：**

- `1 <= s.length <= 104`
- `s` 仅由括号 `'()[]{}'` 组成
## 解题思路
- 初始化一个空栈。
- 遍历字符串中的每个字符。
- 如果字符是左括号，将其压入栈中。
- 如果字符是右括号，检查栈是否为空（首元素为右括号）或栈顶元素是否不是对应的左括号。如果是，则字符串无效。
- 如果在遍历结束后栈不为空，则字符串无效。
- 如果遍历结束后栈为空，则字符串有效。
## 代码
```cpp
class Solution 
{
public:
    bool isValid(string s) 
    {
        // 栈用于存放左括号
        stack<char> st;
        //遍历字符串s
        for (char c : s) 
        {
            // 如果是左括号，将其压入栈中
            if (c == '(' || c == '{' || c == '[') 
            {
                st.push(c);
            } 
            // 如果是右括号,则比对
            else 
            {
                // 检查栈是否为空，如果为空，则首元素为右括号，直接返回false
                if (st.empty()) return false;
                // 对比栈顶元素是否不是对应的左括号
                if ((c == ')' && st.top() != '(') ||
                    (c == '}' && st.top() != '{') ||
                    (c == ']' && st.top() != '[')) 
                {
                    return false;
                }
                // 如果括号匹配，弹出栈顶元素，继续遍历字符串s
                st.pop();
            }
        }

        // 如果栈为空，说明所有括号都闭合，返回true，否则返回false
        return st.empty();
    }
};
```

给你一个字符串数组 `tokens` ，表示一个根据 [逆波兰表示法](https://baike.baidu.com/item/%E9%80%86%E6%B3%A2%E5%85%B0%E5%BC%8F/128437 "https://baike.baidu.com/item/%E9%80%86%E6%B3%A2%E5%85%B0%E5%BC%8F/128437") 表示的算术表达式。

请你计算该表达式。返回一个表示表达式值的整数。

**注意：**

- 有效的算符为 `'+'`、`'-'`、`'*'` 和 `'/'` 。
- 每个操作数（运算对象）都可以是一个整数或者另一个表达式。
- 两个整数之间的除法总是 **向零截断** 。
- 表达式中不含除零运算。
- 输入是一个根据逆波兰表示法表示的算术表达式。
- 答案及所有中间计算结果可以用 **32 位** 整数表示。

**示例 1：**

```
输入：tokens = ["2","1","+","3","*"]
输出：9
解释：该算式转化为常见的中缀算术表达式为：((2 + 1) * 3) = 9
```

**示例 2：**

```
输入：tokens = ["4","13","5","/","+"]
输出：6
解释：该算式转化为常见的中缀算术表达式为：(4 + (13 / 5)) = 6
```

**示例 3：**

```
输入：tokens = ["10","6","9","3","+","-11","*","/","*","17","+","5","+"]
输出：22
解释：该算式转化为常见的中缀算术表达式为：
  ((10 * (6 / ((9 + 3) * -11))) + 17) + 5
= ((10 * (6 / (12 * -11))) + 17) + 5
= ((10 * (6 / -132)) + 17) + 5
= ((10 * 0) + 17) + 5
= (0 + 17) + 5
= 17 + 5
= 22
```

**提示：**

- `1 <= tokens.length <= 104`
- `tokens[i]` 是一个算符（`"+"`、`"-"`、`"*"` 或 `"/"`），或是在范围 `[-200, 200]` 内的一个整数

**逆波兰表达式：**

逆波兰表达式是一种后缀表达式，所谓后缀就是指算符写在后面。

- 平常使用的算式则是一种中缀表达式，如 `( 1 + 2 ) * ( 3 + 4 )` 。
- 该算式的逆波兰表达式写法为 `( ( 1 2 + ) ( 3 4 + ) * )` 。

逆波兰表达式主要有以下两个优点：

- 去掉括号后表达式无歧义，上式即便写成 `1 2 + 3 4 + *` 也可以依据次序计算出正确结果。
- 适合用栈操作运算：遇到数字则入栈；遇到算符则取出栈顶两个数字进行计算，并将结果压入栈中
## 解题思路
1. 创建栈用于储存数据
2. 遇到数字则入栈
3. 遇到算符则出栈顶两个数字
4. 先出的作为右操作数，后出的作为左操作数。两数根据算符进行计算，并将结果压入栈中
## 代码
```cpp
class Solution 
{
public:
    //判断字符串是否为数字，如果不为`+,-,*,/`，必为数字
    bool isNumber(string & str)
    {
        return !(str == "+" || str == "-" || str == "*" || str == "/");
    }
    //解题函数
    int evalRPN(vector<string>& tokens) 
    {
        //定义整型栈，用于储存整型数据
        stack<int> intStack;
        //遍历字符串vector
        for (string &elem: tokens)
        {
            //如果字符串为数字字符串，则入栈
            if (isNumber(elem))
            {
                //字符串转数字：stoi(int), stol(long),stof(float)
                //数字转字符串： to_string(int/long/float/double/bool)
                intStack.push(stoi(elem));
            }
            //如果字符串为运算符，则计算
            else
            {
                //弹出右左操作数
                int right_val = intStack.top();
                intStack.pop();
                int left_val = intStack.top(); 
                intStack.pop();
                //计算
                int ret = 0;
                //switch的条件为int,或者char,不能是string,所以用elem[0]，字符串中的第一个字符为char类型
                switch (elem[0])
                {
                    case '+':
                    ret = left_val + right_val;
                    break;

                    case '-':
                    ret = left_val - right_val;
                    break;

                    case '*':
                    ret = left_val * right_val;
                    break;

                    case '/':
                    ret = left_val / right_val;
                    break;
                }
                //计算结果入栈
                intStack.push(ret);
            }
        }
        //返回栈中最终剩余的元素
        return intStack.top();
    }
};
```
# 中缀表达式转逆波兰表达式
## 问题描述
-  中缀表达式： `( 1 + 2 ) * ( 3 + 4 )`，运算符在操作数的中间。
- 逆波兰表达式：`1 2 + 3 4 + *`，是一种后缀表达式，所谓后缀就是指算符写在后面。
-  用栈求解四则运算表达式的过程：
1. 中缀表达式转逆波兰表达式（本题要解决的问题）
2. 栈计算逆波兰表达式（上一题是解决此问题）
- 中缀表达式转逆波兰表达式：`2 + (4 + 6) / 2 + 6 / 3` =>`2, 4, 6, +, 2, /, +, 6, 3, /, +`
## 解题思路
1. 定义一个栈 `s` 用来存储操作符和括号，定义一个字符串 `postfix` 来存储最终的后缀表达式。
2. 遍历输入的中缀表达式 `infix`，每次处理一个字符 `c`
3. 如果字符 `c` 是空格，直接跳过。
4. 判断 `c` 是否是字母或数字（即操作数），如果是操作数，直接将其添加到 `postfix` 字符串中
5. 遇到括号：
	1. 如果字符 `c` 是左括号，将其压入栈中。
	2. 如果字符 `c` 是右括号，表示当前子表达式结束。将栈中的操作符弹出并添加到 `postfix`，直到遇到左括号 `(`。
	3. 弹出左括号后继续处理下一个字符。
6. 遇到运算符：如果字符 `c` 是操作符（`+`、`-`、`*`、`/`）
	1. 循环判断栈顶的操作符是否优先级 **大于或等于** 当前操作符。如果是，则弹出栈顶操作符并添加到 `postfix` 中
	2. 将当前操作符 `c` 压入栈中
7. **处理剩余的操作符**：在遍历完所有字符后，栈中可能还有剩余的操作符。将它们依次弹出并添加到 `postfix`。
8. **返回结果**：返回最终的后缀表达式字符串 `postfix`。
### 例子演示

以表达式 `2 + (4 + 6) / 2 + 6 / 3` 为例，代码会执行以下步骤：

1. 读到 `2`：它是操作数，直接添加到 `postfix` => `postfix = "2"`.
2. 读到 `+`：它是操作符，压入栈中 => `stack = "+"`.
3. 读到 `(`：它是左括号，压入栈中 => `stack = "+("`.
4. 读到 `4`：它是操作数，直接添加到 `postfix` => `postfix = "24"`.
5. 读到 `+`：它是操作符，压入栈中 => `stack = "+(+"`
6. 读到 `6`：它是操作数，直接添加到 `postfix` => `postfix = "246"`.
7. 读到 `)`：右括号，开始弹栈直到遇到左括号 `(`，将 `+` 添加到 `postfix` => `postfix = "246+"`, `stack = "+"`.
8. 读到 `/`：操作符 `/` 的优先级高于栈顶 `+`，直接压入栈中 => `stack = "+/"`.
9. 读到 `2`：它是操作数，直接添加到 `postfix` => `postfix = "246+2"`.
10. 读到 `+`：栈顶的 `/` 优先级高于 `+`，弹出 `/` 添加到 `postfix`，然后 `+` 入栈 => `postfix = "246+2/"`, `stack = "+"`.
11. 读到 `6`：它是操作数，直接添加到 `postfix` => `postfix = "246+2/6"`.
12. 读到 `/`：`/` 优先级高于 `+`，压入栈中 => `stack = "+/"`.
13. 读到 `3`：它是操作数，直接添加到 `postfix` => `postfix = "246+2/63"`.
14. 结束后，弹出剩余的操作符并添加到 `postfix` => `postfix = "246+2/63/+"`.

最终，生成的后缀表达式为 `246+2/63/+`。
## 代码
```cpp
#include <cctype>
#include <iostream>
#include <stack>
#include <string>

// 返回操作符的优先级
int precedence(char op)
{
    if (op == '+' || op == '-')
        return 1;
    if (op == '*' || op == '/')
        return 2;
    return 0;
}
// 检查字符是否为操作符
bool isOperator(char c)
{
    return c == '+' || c == '-' || c == '*' || c == '/';
}
// 将中缀表达式转换为后缀表达式
std::string infixToPostfix(const std::string &infix)
{
    std::stack<char> s;  // 栈用于存储操作符和括号
    std::string postfix; // 用于存储最终生成的后缀表达式
    // 遍历中缀表达式中的每个字符
    for (char c : infix)
    {
        // 跳过空格
        if (isspace(c))
            continue;
        // 如果是操作数（字母或数字），直接添加到后缀表达式中
        if (isalnum(c))
        {
            postfix += c;
        }
        // 如果是左括号，压入栈中
        else if (c == '(')
        {
            s.push(c);
        }
        // 如果是右括号
        else if (c == ')')
        {
            // 将栈中的操作符弹出到后缀表达式中，直到遇到左括号
            while (!s.empty() && s.top() != '(')
            {
                postfix += s.top(); // 将操作符添加到后缀表达式中
                s.pop();            // 弹出栈顶操作符
            }
            // 弹出左括号
            if (!s.empty())
                s.pop();
            // 若没有匹配的左括号，则抛出错误
            else
                throw std::runtime_error("Mismatched parentheses in expression");
        }
        // 如果是操作符
        else if (isOperator(c))
        {
            // 弹出所有优先级大于或等于当前操作符的栈顶操作符，并将它们添加到后缀表达式中
            while (!s.empty() && precedence(s.top()) >= precedence(c))
            {
                postfix += s.top();
                s.pop();
            }
            // 当前操作符压入栈中
            s.push(c);
        }
        // 遇到非法字符时抛出错误
        else
        {
            throw std::runtime_error("Invalid character in expression");
        }
    }
    // 将栈中剩余的操作符弹出并添加到后缀表达式中
    while (!s.empty())
    {
        // 若剩余括号，则抛出错误
        if (s.top() == '(' || s.top() == ')')
            throw std::runtime_error("Mismatched parentheses in expression");
        // 将栈中剩余的操作符弹出并添加到后缀表达式中
        postfix += s.top();
        s.pop();
    }
    // 返回最终的后缀表达式
    return postfix;
}

// 测试函数
int main()
{
    std::cout << infixToPostfix("2 + (4 + 6) / 2 + 6 / 3") << std::endl;
}
```
