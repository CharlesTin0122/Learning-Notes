# 概念和特点
二分查找（binary search）是一种基于分治策略的高效搜索算法。它利用数据的有序性，每轮缩小一半搜索范围，直至找到目标元素或搜索区间为空为止。
- 搜索过程从数组的中间元素开始，如果中间元素正好是要查找的元素，则搜索过程结束；
- 如果某一特定元素大于或者小于中间元素，则在数组大于或小于中间元素的那一半中查找，而且跟开始一样从中间元素开始比较。
- 如果在某一步骤数组为空，则代表找不到。
- 这种搜索算法每一次比较都使搜索范围缩小一半。
## 时空复杂度
- 二分查找算法在[最坏情况](https://zh.wikipedia.org/w/index.php?title=%E6%9C%80%E5%9D%8F%E6%83%85%E5%86%B5&action=edit&redlink=1)下是[对数时间复杂度](https://zh.wikipedia.org/wiki/%E6%97%B6%E9%97%B4%E5%A4%8D%E6%9D%82%E5%BA%A6#%E5%AF%B9%E6%95%B0%E6%97%B6%E9%97%B4 "时间复杂度")的，需要进行𝑂(log⁡𝑛)次比较操作。
- 二分查找算法使用常数空间，对于任何大小的输入数据，算法使用的空间都是一样的。
- 数组的所有查找路径际上就是下面这棵BST树，二分查找算法就是从root根节点开始查找的过程，每次查找只会沿着一条路径进行。
- 二分查找算法的最多搜索次数就是这颗BST树的层数：$L = \log_2^n$

>若数组不包含该元素，则返回 −1 。示例如图所示。

## 步骤
1. 定义两个下标，`first`和`last`，分别指向首元素和末元素。
2. 遍历数组，条件为：`first <= last`。
	1. 定义一个中间索引：`middle = (first + last) / 2`用于比较。
	2. 使用中间索引`nums[middle]`对`target`值进行比较。如果相等则返回`middle`
	3. 如果`nums[middle] > target`,则查找前一半数据：调整查找区间`last = middle - 1`。
	4. 如果`nums[middle] < target`，则查找后一半数据：调整查找区间`firat = middle + 1`
## 代码
```cpp
#include <iostream>

// 二分查找
int binarySearch(int arr[], int size, int target)
{
    // 定义区间索引
    int first = 0;
    int last = size - 1;
    // 遍历数组，条件为first不大于last
    while (first <= last)
    {
        // 定义中间索引用于比较
        int middle = (first + last) / 2;
        // 当中间索引等于目标值时，返回中间索引
        if (arr[middle] == target)
        {
            return middle;
        }
        // 当中间索引大于目标值时，调整区间为前一半区间
        else if (arr[middle] > target)
        {
            last = middle - 1;
        }
        // 当中间索引小于目标值时，调整区间为后一半区间
        else
        {
            first = middle + 1;
        }
    }
    // 目标未找到返回-1
    return -1;
}
// 测试函数
int main()
{
    int arr[] = {12, 25, 34, 39, 57, 63, 78, 82, 96, 100};
    int size = sizeof(arr) / sizeof(arr[0]);
    std::cout << binarySearch(arr, size, 39) << std::endl;
    std::cout << binarySearch(arr, size, 12) << std::endl;
    std::cout << binarySearch(arr, size, 100) << std::endl;
    std::cout << binarySearch(arr, size, 2) << std::endl;
}
```
# 二分查找递归实现
## 代码
```cpp
#include <iostream>

// 在数组arr的[start, end]范围内递归二分查找值target，找到返回索引，找不到返回-1.
int binarySearch(int arr[], int start, int end, int target)
{
    // 递推结束条件
    if (start > end)
    {
        return -1;
    }
    // 定义中间索引用于比对
    int middle = (start + end) / 2;
    // 如果中间索引等于目标值，返回索引
    if (arr[middle] == target)
    {
        return middle;
    }
    // 如果中间索引大于目标索引，则查找前一半区间
    else if (arr[middle] > target)
    {
        return binarySearch(arr, start, middle - 1, target);
    }
    // 如果中间索引小于目标索引，则查找后一半区间
    else
    {
        return binarySearch(arr, middle + 1, end, target);
    }
}
// 测试函数
int main()
{
    int arr[] = {12, 25, 34, 39, 57, 63, 78, 82, 96, 100};
    int size = sizeof(arr) / sizeof(arr[0]);
    std::cout << binarySearch(arr, 0, size, 39) << std::endl;
    std::cout << binarySearch(arr, 0, size, 12) << std::endl;
    std::cout << binarySearch(arr, 0, size, 100) << std::endl;
    std::cout << binarySearch(arr, 0, size, 2) << std::endl;
}
```
