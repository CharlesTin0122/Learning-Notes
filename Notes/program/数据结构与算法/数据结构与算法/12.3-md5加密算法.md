# 概念
MD5（Message Digest Algorithm 5）是一种广泛使用的哈希函数，由Ronald Rivest于1991年设计并发布。它是一种密码学散列函数，通常用于生成一个128位（16字节）的哈希值，用于确保数据完整性。这意味着给定一段输入数据（无论大小），MD5算法会生成一个固定长度的哈希值，通常称为“消息摘要”。

以下是MD5的一些主要特点：
### 1. **输入和输出**
   - **输入**：可以是任意长度的数据。
   - **输出**：固定为128位（16字节）的哈希值，通常以32位十六进制数字表示。

### 2. **不可逆性**
   - MD5是一种单向散列函数，理论上无法通过反向计算来恢复原始输入数据。

### 3. **固定长度输出**
   - 无论输入数据的大小，MD5总是会生成128位的输出。这种固定长度使它适用于生成数字签名和校验和。

### 4. **广泛应用**
   - 数据完整性验证：通过比较文件的MD5值，确保传输过程中数据没有发生改变。
   - 密码存储：一些旧的系统曾使用MD5对密码进行哈希处理（现在不再安全）。
   - 数字签名和证书：MD5曾用于加密通信中的签名生成。

### 5. **安全性问题**
   尽管MD5在过去被广泛应用，但随着计算能力的提升，MD5已经被认为不够安全，主要因为以下原因：
   - **碰撞攻击**：可以找到两个不同的输入产生相同的MD5哈希值。这意味着MD5不再满足加密学上“抗碰撞”的要求。
   - **暴力破解**：随着计算技术的进步，通过暴力破解的方法，可以在短时间内找出对应于某一哈希值的输入。

因此，许多现代应用程序已经转向更安全的哈希算法，如SHA-256或SHA-3等。
总结来说，虽然MD5曾经在数据完整性和密码学应用中广泛使用，但由于其安全性问题，已逐渐被弃用。
# 实现

下面是一个简单的 C++ MD5 实现，分为 `md5.h` 和 `md5.cpp` 两个文件。这种实现主要适合学习和小型项目，若需要高性能或高安全性，建议使用成熟的加密库如 OpenSSL 或 Crypto++。

### 文件1：`md5.h`
```cpp
#ifndef MD5_H
#define MD5_H

#include <string>
#include <cstdint>

class MD5 {
public:
    MD5();
    void update(const unsigned char* data, size_t length);
    void update(const std::string& data);
    std::string finalize();
    
private:
    void transform(const uint8_t block[64]);
    void encode(uint8_t* output, const uint32_t* input, size_t length);
    void decode(uint32_t* output, const uint8_t* input, size_t length);
    void finalizeHash();

    bool finalized;
    uint8_t buffer[64];
    uint32_t state[4];
    uint64_t bitCount;
    uint8_t digest[16];
};

// 工具函数
std::string md5(const std::string& data);

#endif // MD5_H
```

static constexpr uint32_t S11 = 7;
static constexpr uint32_t S12 = 12;
static constexpr uint32_t S13 = 17;
static constexpr uint32_t S14 = 22;
static constexpr uint32_t S21 = 5;
static constexpr uint32_t S22 = 9;
static constexpr uint32_t S23 = 14;
static constexpr uint32_t S24 = 20;
static constexpr uint32_t S31 = 4;
static constexpr uint32_t S32 = 11;

// 基本操作
inline uint32_t F(uint32_t x, uint32_t y, uint32_t z) { return (x & y) | (~x & z); }
inline uint32_t G(uint32_t x, uint32_t y, uint32_t z) { return (x & z) | (y & ~z); }
inline uint32_t H(uint32_t x, uint32_t y, uint32_t z) { return x ^ y ^ z; }
inline uint32_t I(uint32_t x, uint32_t y, uint32_t z) { return y ^ (x | ~z); }

inline uint32_t rotateLeft(uint32_t x, int n) { return (x << n) | (x >> (32 - n)); }

inline void FF(uint32_t& a, uint32_t b, uint32_t c, uint32_t d, uint32_t x, uint32_t s, uint32_t ac) {
    a = rotateLeft(a + F(b, c, d) + x + ac, s) + b;
}

inline void GG(uint32_t& a, uint32_t b, uint32_t c, uint32_t d, uint32_t x, uint32_t s, uint32_t ac) {
    a = rotateLeft(a + G(b, c, d) + x + ac, s) + b;
}

inline void HH(uint32_t& a, uint32_t b, uint32_t c, uint32_t d, uint32_t x, uint32_t s, uint32_t ac) {
    a = rotateLeft(a + H(b, c, d) + x + ac, s) + b;
}

inline void II(uint32_t& a, uint32_t b, uint32_t c, uint32_t d, uint32_t x, uint32_t s, uint32_t ac) {
    a = rotateLeft(a + I(b, c, d) + x + ac, s) + b;
}

MD5::MD5() {
    finalized = false;
    bitCount = 0;

    // 初始化状态
    state[0] = 0x67452301;
    state[1] = 0xefcdab89;
    state[2] = 0x98badcfe;
    state[3] = 0x10325476;

    std::memset(buffer, 0, sizeof(buffer));
    std::memset(digest, 0, sizeof(digest));
}

void MD5::update(const unsigned char* data, size_t length) {
    size_t index = bitCount / 8 % 64;
    bitCount += length * 8;

    size_t firstPart = 64 - index;
    size_t i = 0;

    if (length >= firstPart) {
        std::memcpy(&buffer[index], data, firstPart);
        transform(buffer);

        for (i = firstPart; i + 63 < length; i += 64) {
            transform(&data[i]);
        }

        index = 0;
    }

    std::memcpy(&buffer[index], &data[i], length - i);
}

void MD5::update(const std::string& data) {
    update(reinterpret_cast<const unsigned char*>(data.c_str()), data.size());
}

void MD5::finalizeHash() {
    if (finalized) return;

    unsigned char padding[64] = { 0x80 };
    unsigned char bits[8];

    // 将 bitCount 拆分成两个 32 位整数
    uint32_t bitCountLow = static_cast<uint32_t>(bitCount);
    uint32_t bitCountHigh = static_cast<uint32_t>(bitCount >> 32);

    // 先对低位和高位分别进行编码
    encode(bits, &bitCountLow, 4);
    encode(bits + 4, &bitCountHigh, 4);

    size_t index = bitCount / 8 % 64;
    size_t padLength = (index < 56) ? (56 - index) : (120 - index);

    update(padding, padLength);
    update(bits, 8);

    encode(digest, state, 16);
    finalized = true;
}

std::string MD5::finalize() {
    finalizeHash();

    std::ostringstream result;
    for (int i = 0; i < 16; ++i) {
        result << std::hex << std::setw(2) << std::setfill('0') << (int)digest[i];
    }

    return result.str();
}

void MD5::encode(uint8_t* output, const uint32_t* input, size_t length) {
    for (size_t i = 0; i < length / 4; i++) {
        output[i * 4] = (input[i] & 0xff);
        output[i * 4 + 1] = ((input[i] >> 8) & 0xff);
        output[i * 4 + 2] = ((input[i] >> 16) & 0xff);
        output[i * 4 + 3] = ((input[i] >> 24) & 0xff);
    }
}

void MD5::decode(uint32_t* output, const uint8_t* input, size_t length) {
    for (size_t i = 0; i < length / 4; i++) {
        output[i] = (input[i * 4]) |
                    (input[i * 4 + 1] << 8) |
                    (input[i * 4 + 2] << 16) |
                    (input[i * 4 + 3] << 24);
    }
}

std::string md5(const std::string& data) {
    MD5 md5;
    md5.update(data);
    return md5.finalize();
}
