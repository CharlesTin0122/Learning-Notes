## 递归的核心思想
- 《算法导论》中有这样一句话：串行逻辑是给人看的，循环逻辑是给计算机看的，递归逻辑是给神看的。

递归（recursion）是一种算法策略，通过函数调用自身来解决问题。它主要包含两个阶段。

1. **递**：程序不断深入地调用自身，通常传入更小或更简化的参数，直到达到“终止条件”。
2. **归**：触发“终止条件”后，程序从最深层的递归函数开始逐层返回，汇聚每一层的结果。

而从实现的角度看，递归代码主要包含三个要素。

1. **终止条件**：用于决定什么时候由“递”转“归”。
2. **递归调用**：对应“递”，函数调用自身，通常输入更小或更简化的参数。
3. **返回结果**：对应“归”，将当前递归层级的结果返回至上一层。
### 递归的特点
- 不管多大的数据规模，求解问题的方式是一样的。
- 不同规模的数据，其计算结果是有规律可循的。

## 使用递归的注意事项
- 一定要搞清楚递归函数的作用是什么，包括返回值，参数列表，实现了什么功能。
- 一定要有递归结束的条件，递推到达结束条件后开始回归。
- 搞清楚相近数据规模（n和n-1）之间的计算规律和关系。
- 递归问题的思考是水平方向的，只需考虑相近数据规模（n和n-1）之间的计算规律。
- 递归程序的执行，是垂直方向的
## 伪代码
```
def recursion(大规模问题):
    if 递归终止条件:
        递归终止时的处理方法
    
    return recursion(小规模问题)

```

## 代码
```cpp
#include <iostream>

/* 递归求和 */
int recur(int n) 
{
    // 终止条件
    if (n == 1)
        return 1;
    //数据关系
    return n + recur(n - 1);
}
```
