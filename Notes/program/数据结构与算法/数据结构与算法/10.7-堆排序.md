# 概念和特点
- 堆排序（heap sort）是一种基于[堆数据结构](9.0-堆.md)实现的高效排序算法。我们可以利用已经学过的“建堆操作”和“元素出堆操作”实现堆排序。
# 算法思想
1. 输入数组并建立大顶堆，堆顶元素为最大值元素。
2. 堆顶元素与堆底元素交换，此时数组最大值位于末尾。末尾元素已排序不再处理，对其余元素进行堆化（sift down），并循环此过程。
- 总结：此过程就是将堆顶元素不断交换到末尾的过程，最终实现升序排列。
# 实现步骤
设数组的长度为 𝑛 ，堆排序的流程：。
1. 输入数组并建立大顶堆。完成后，最大元素位于堆顶。
2. 将堆顶元素（第一个元素）与堆底元素（最后一个元素）交换。完成交换后，堆的长度减 1 ，已排序元素数量加 1 。
3. 从堆顶元素开始，从顶到底执行堆化操作（sift down）。完成堆化后，堆的性质得到修复。
4. 循环执行第 `2.` 步和第 `3.` 步。循环 𝑛−1 轮后，即可完成数组排序。

>[!INFO] Tips
>实际上，元素出堆操作中也包含第 `2.` 步和第 `3.` 步，只是多了一个弹出元素的步骤。
# 代码
```cpp
#include <iostream>

// 下沉堆化函数
void siftDown(int arr[], int index, int size)
{
    int val = arr[index];
    // 第一个非叶节点:(size -1 -1) / 2 = size / 2 - 1
    while (index < size / 2)
    {
        // 设最大子节点的为左子节点
        int maxChild = 2 * index + 1;
        // 如果右子节点存在且大于左子节点，那么最大子节点为右子节点
        if (maxChild + 1 < size && arr[maxChild + 1] > arr[maxChild])
        {
            maxChild += 1;
        }
        // 如果最大子节点的值大于当前值
        if (arr[maxChild] > val)
        {
            arr[index] = arr[maxChild]; // 最大子节点的值赋给当前值
            index = maxChild;           // 更新索引为最大子节点
        }
        // 如果最大子节点小于等于当前值，跳出循环。
        else
        {
            break;
        }
    }
    // 最终节点赋值
    arr[index] = val;
}

// 堆排序
void heapSort(int arr[], int size)
{
    // 末尾元素索引
    int n = size - 1;
    // 从第一个非叶节点开始逆序向上进行下沉处理，使数组变为大顶堆
    for (int i = (n - 1) / 2; i >= 0; i--)
    {
        siftDown(arr, i, size);
    }
    // 将堆顶元素与末尾元素互换，并将剩余元素堆化
    for (int i = n; i > 0; i--)
    {
        int tmp = arr[0];
        arr[0] = arr[i];
        arr[i] = tmp;

        // 堆化剩余元素,第三个参数：参与调整的元素个数
        siftDown(arr, 0, i);
    }
}```
# 算法分析
- **时间复杂度为 𝑂(𝑛log⁡𝑛)、非自适应排序**：建堆操作使用 𝑂(𝑛) 时间。从堆中提取最大元素的时间复杂度为 𝑂(log⁡𝑛) ，共循环 𝑛−1 轮。
- **空间复杂度为 𝑂(1)、原地排序**：几个指针变量使用 𝑂(1) 空间。元素交换和堆化操作都是在原数组上进行的。
- **非稳定排序**：在交换堆顶元素和堆底元素时，相等元素的相对位置可能发生变化。
