# 概念
- 求Top K问题（Top K problem）是指在一个数据集中找到前K个最大或最小的元素。这类问题在数据挖掘、机器学习、数据库查询等领域广泛应用，例如从大量数据中找到前K个最受欢迎的商品、排名前K的用户评论、或者最相关的搜索结果。
# 解决方案

## 堆排序法
- 利用大根堆过滤前top k小的数据，小根堆过滤前top k大的数据，O(n)线性时间内找到top k元素。
- 求值最大的K个元素，用小根堆。将堆顶元素较小值不断淘汰，放入较大值。
- 求值最小的K个元素，用大根堆。将堆顶元素较大值不断淘汰，放入较小值。
### 案例1
- 求出数组中最小的k个元素
1. 需要一个大根堆，大根堆堆顶元素最大的，思想是：将堆顶元素较大值不断淘汰，放入较小值。
2. 获取序列前三个元素组成大根堆，然后遍历后续元素，
	1. 如果元素值值大于堆顶，直接跳过。
	2. 如果元素值小于堆顶元素，则堆顶出堆(堆化)，将较小值放入堆底(堆化)。
	3. 循环此过程，直至遍历结束，最终堆内元素便是所求最小的三个元素
### 代码
```cpp
#include <cstdlib>
#include <ctime>
#include <functional>
#include <iostream>
#include <queue>
#include <vector>
//求数组中k个最小值
std::priority_queue<int, std::vector<int>, std::less<int>> Minimum_element(
    std::vector<int> vec, int k)
{
    // 创建大根堆，值为int类型，底层结构为vector，比较函数为小于
    std::priority_queue<int, std::vector<int>, std::less<int>> heap;
    // 将数组前k个元素放入堆中
    for (int i = 0; i < k; i++)
    {
        heap.push(vec[i]);
    }
    // 将剩余元素依次与堆顶进行比较，大于堆顶则跳过，小于堆顶则出堆并插入
    for (int i = k; i < vec.size(); i++)
    {
        if (vec[i] < heap.top())
        {
            heap.pop();
            heap.push(vec[i]);
        }
    }
    return heap;
}

int main()
{
    // 构建数组
    std::vector<int> vec;
    srand((unsigned int)time(NULL));
    for (int i = 0; i < 100; i++)
    {
        vec.push_back(rand() % 100);
    }
    for (int val : vec)
    {
        std::cout << val << " ";
    }
    std::cout << std::endl;

    // 求值最小的五个元素
    std::priority_queue<int> que = Minimum_element(vec, 5);
    std::cout << "值最小的无个元素为：" << std::endl;
    for (int i = 0; i < 5; i++)
    {
        std::cout << que.top() << " ";
        que.pop();
    }
    std::cout << std::endl;
}
```
### 案例2
- 求数组中重复次数最少的前k个元素
```cpp
#include <cstdlib>
#include <ctime>
#include <iostream>
#include <queue>
#include <unordered_map>
#include <vector>

// 重复次数最少的前k个元素
std::vector<int> least_repete_nums(const std::vector<int> &vec, int k)
{
    // 创建无序映射，用于储存元素和元素出现次数
    std::unordered_map<int, int> map;
    for (int elem : vec)
    {
        map[elem]++;
    }

    using pairType = std::pair<int, int>;
    // lambda表达式，比较函数
    auto cmp = [](const pairType &a, const pairType &b) -> bool { return a.second < b.second; };

    // 创建优先级队列，大根堆，储存重复次数最少的前k个元素

    /* decltype 是 C++11中的关键字，用于获取变量或表达式的类型。decltype(cmp) 获取了 cmp的类型，cmp 是一个 lambda 函数
     * que(cmp)这是优先级队列的构造函数。在创建优先级队列对象 que 时，将 cmp传递给它，作为优先级队列的比较函数 */
    std::priority_queue<pairType, std::vector<pairType>, decltype(cmp)> que(cmp);
    // 将元素和其出现次数放入优先级队列
    for (const auto &elem : map)
    {
        que.push(elem);
        // 如果优先队列中元素个数超过 k，则弹出队列中最大（即出现次数最多）的元素。
        if (que.size() > k)
        {
            que.pop();
        }
    }
    // 打印结果
    while (!que.empty())
    {
        std::cout << "val: " << que.top().first << "cnt: " << que.top().second << std::endl;
        que.pop();
    }
    // 将结果存入向量中
    std::vector<int> result;
    while (!que.empty())
    {
        result.push_back(que.top().first);
        que.pop();
    }

    return result;
}

int main()
{
    // 构建数组
    std::vector<int> vec;
    srand((unsigned int)time(NULL));
    for (int i = 0; i < 100; i++)
    {
        vec.push_back(rand() % 10);
    }
    std::vector<int> ret = least_repete_nums(vec, 3);
}
```

## 快排分割法
利用快排分割函数每次返回的基准数的位置，找出前top k大的数据或者前top k小的数据。
### 案例1
- 求数组中最小的K个元素
```cpp
#include <cstdlib>
#include <ctime>
#include <iostream>
#include <vector>

// 快排分割函数
int partition(std::vector<int> &vec, int begin, int end)
{
    // 以vec[begin]为基准数
    int val = vec[begin], l = begin, r = end;
    // 从右向左找小于基准数的值，从左向右找大于基准数的值，找到后互换
    while (l < r)
    {
        while (l < r && vec[r] >= val)
        {
            r--;
        }
        while (l < r && vec[l] <= val)
        {
            l++;
        }
        if (l < r)
        {
            std::swap(vec[l], vec[r]);
        }
    }
    // 将基准数交换至两子数组的分界线
    std::swap(vec[begin], vec[l]);
    // 返回基准数的索引
    return l;
}

// 快排分割求最小值topK
std::vector<int> sel_sort_Min_elems(std::vector<int> &vec, int begin, int end, int k)
{
    // 快排分割数组
    int pivot = partition(vec, begin, end);
    // 递归终止条件,基准点刚好在k-1位置，找到了前k个最小元素
    if (pivot == k - 1)
    {
        return std::vector<int>(vec.begin(), vec.begin() + k);
    }
    // 当基准数索引大于k个元素的末尾索引时，递归分割左侧数据
    else if (pivot > k - 1)
    {
        return sel_sort_Min_elems(vec, begin, pivot - 1, k);
    }
    // 当基准数索引小于k个元素的末尾索引时，递归分割右侧数据
    else
    {
        return sel_sort_Min_elems(vec, pivot + 1, end, k);
    }
}
int main()
{
    // 构建数组
    std::vector<int> vec;
    srand((unsigned int)time(NULL));
    for (int i = 0; i < 100; i++)
    {
        vec.push_back(rand() % 1000);
    }
    //测试函数
    std::vector<int> vec1 = sel_sort_Min_elems(vec, 0, 99, 5);
    for (const int elem : vec1)
    {
        std::cout << elem << " ";
    }
    std::cout << std::endl;
}
```
