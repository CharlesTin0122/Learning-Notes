# 概念和特点
基数排序（Radix Sort）是一种非比较型整数排序算法，它通过将数据按位进行排序来实现排序目的。基数排序通常用于对整数或字符串等数据进行排序，特别适用于大量数据且数据范围较小时。
# 算法思想
基数排序通过以下步骤进行排序：

1. **按位排序**： 基数排序从数据的最低有效位（Least Significant Digit，简称 LSD）开始，一直到最高有效位（Most Significant Digit，简称 MSD）为止，对每个位数进行排序。每一位的排序通常使用稳定的排序算法，如计数排序或桶排序。
    
2. **从低到高排序**： 从最低位开始，逐步对每一位上的数字进行排序。首先排序个位，然后排序十位，依次类推，直到最高位。
假设有一组整数 `170, 45, 75, 90, 802, 24, 2, 66`，基数排序的过程如下：

1. **第一轮**（对个位数进行排序）：
    
    - 按个位数排序，结果为：`170, 90, 802, 2, 24, 45, 75, 66`
2. **第二轮**（对十位数进行排序）：
    
    - 按十位数排序，结果为：`802, 2, 24, 45, 66, 170, 75, 90`
3. **第三轮**（对百位数进行排序）：
    
    - 按百位数排序，结果为：`2, 24, 45, 66, 75, 90, 170, 802`

此时排序完成，最终结果为：`2, 24, 45, 66, 75, 90, 170, 802`。
# 实现步骤
1. 找出最长的数字，确定要处理的排序位数
2. 依次由个位开始处理，把相应位数上的数字，放入相应序号的桶内，完成后再按照桶序号依次取出桶内数据放回原始数组中
3. 当处理完所有的位数，最终得到有序的序列
# 代码
```cpp
#include <cstddef>
#include <cstdlib>
#include <ctime>
#include <iostream>
#include <string>
#include <vector>

// 基数排序
void radixSort(int arr[], int size)
{
    // 获取绝对值最大值
    int maxData = arr[0];
    for (int i = 0; i < size; i++)
    {
        if (abs(arr[i]) > maxData)
        {
            maxData = abs(arr[i]);
        }
    }
    // 获取最大值位数:将int转化为string并获取长度。
    int maxLen = std::to_string(maxData).size();
    // 利用vector创建二维vector桶
    std::vector<std::vector<int>> vecs;
    // 定义取模数和被除数
    int mod = 10, dev = 1;
    // 遍历最大元素位数，每次遍历取模数和被除数*10，以获取每位数字
    for (int i = 0; i < maxLen; mod *= 10, dev *= 10, i++)
    {
        // vector重定大小,为了能处理负数，0-9号桶放负数，10-19号桶放正数
        vecs.resize(20);
        // 遍历所有元素
        for (int j = 0; j < size; j++)
        {
            // 得到当前元素的第i位的数字，将数字作为vecs索引桶
            int index = arr[j] % mod / dev + 10;
            // 将数字放入对应桶
            vecs[index].push_back(arr[j]);
        }
        // 依次遍历所有桶，将元素拷贝回原始数组
        int idx = 0;
        for (std::vector<int> vec : vecs)
        {
            for (int elem : vec)
            {
                arr[idx++] = elem;
            }
        }
        // 清空桶
        vecs.clear();
    }
}
```
# 算法分析
相较于计数排序，基数排序适用于数值范围较大的情况，**但前提是数据必须可以表示为固定位数的格式，且位数不能过大**。例如，浮点数不适合使用基数排序，因为其位数 𝑘 过大，可能导致时间复杂度 𝑂(𝑛𝑘)≫𝑂(𝑛2) 。

- **时间复杂度为 𝑂(𝑛𝑘)、非自适应排序**：设数据量为 𝑛、数据为 𝑑 进制、最大位数为 𝑘 ，则对某一位执行计数排序使用 𝑂(𝑛+𝑑) 时间，排序所有 𝑘 位使用 𝑂((𝑛+𝑑)𝑘) 时间。通常情况下，𝑑 和 𝑘 都相对较小，时间复杂度趋向 𝑂(𝑛) 。
- **空间复杂度为 𝑂(𝑛+𝑑)、非原地排序**：与计数排序相同，基数排序需要借助长度为 𝑛 和 𝑑 的数组 `res` 和 `counter` 。
- **稳定排序**：当计数排序稳定时，基数排序也稳定；当计数排序不稳定时，基数排序无法保证得到正确的排序结果。
