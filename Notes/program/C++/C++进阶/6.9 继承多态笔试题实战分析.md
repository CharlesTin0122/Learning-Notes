# 题一
- 请查看如下代码并给出输出结果
```cpp
    // 堆区实例化派生类,基类指针指向派生类
    Animal *p1 = new Cat("jiafei");
    Animal *p2 = new Dog("Husky");
    // 指针强转为int*
    int *p11 = (int *)p1;
    int *p22 = (int *)p2;
    // 指针首位交换，虚函数指针交换
    int tmp = p11[0];
    p11[0] = p22[0];
    p22[0] = tmp;
    // 调用虚函数
    p1->bark(); // p1 -> Cat vfptr -> Dog vftable -> bark() ->"woof"
    p2->bark(); // p2 -> Dog vfptr -> Cat vftable -> bark() ->"meow"
    // 释放内存
    delete p1;
    delete p2;
```

答案：
```
"woof"
"meow"
```
## 解题思路
- 堆区实例化派生类,基类指针指向派生类
- 指针强转为`int*`，`p11[0]`和`p22[0]`，均是指针的前4个字节，为对象的虚函数指针
- 连个对象的虚函数指针做了交换
- 导致他们调用的虚函数`bark()`，也做了交换。
- 所以猫叫狗的声音，狗叫猫的声音。
# 题二
请查看如下代码并给出输出结果
```cpp
#include <iostream>

// 基类
class Base
{
public:
    virtual void show(int i = 10) { std::cout << "Call Base::show() i : " << i << std::endl; }
};
// 派生类
class Derive : public Base
{
public:
    void show(int i = 20) override { std::cout << "Call Derive::show() i : " << i << std::endl; }
};
// 主函数
int main()
{
    Base *p = new Derive();
    /* p指针通过动态绑定调用Derive::show()，但是函数默认值却是Base::show()的10.
     * 函数调用，参数压栈是在编译时期就确定好的。p是一个Base *类型，压栈的参数是Base::show()
     * 动态绑定是在运行时期调用自身虚函数的。
     * 所以，函数参数是基类的10，函数调用是派生类的Derive::show()
     */
    p->show(); // Call Derive::show() i : 10

    delete p;

    return 0;
}
```
结果
```
Call Derive::show() i : 10
```
## 解题思路
* p指针通过动态绑定调用Derive::show()，但是函数默认值却是Base::show()的10.
	* 函数调用，参数压栈是在编译时期就确定好的。p是一个Base *类型，压栈的参数是Base::show()
	* 动态绑定是在运行时期调用自身虚函数的。
	* 所以，函数参数是基类的10，函数调用是派生类的Derive::show()
# 问题三
请看如下代码是否可以正常运行
```cpp
#include <iostream>

// 基类
class Base
{
public:
    virtual void show() { std::cout << "Call Base::show() i : " << std::endl; }
};
// 派生类
class Derive : public Base
{
    // 派生类虚函数为私有
private:
    void show() override { std::cout << "Call Derive::show() i : " << std::endl; }
};
// 主函数
int main()
{
    // 基类指针指向堆上的派生类对象
    Base *p = new Derive();
    // 指针调用私有虚函数，可以调用
    /* 成员方法能不能调用，就是成员的访问权限是在编译阶段确定的。
     * 在编译阶段，检查的是Base::show()方法，是public限定的，所以编译通过。
     * 而基类指针指向派生类对象来调用虚函数，触发了动态绑定，是在运行阶段才确定的。
     * p指针调用Base::show()方法发现是个虚函数，查看对象vfptr指向的vftable中的函数地址为Derive::show()，直接调用。
     */
    p->show();

    delete p;

    return 0;
}
```
答案
- 可以运行通过
## 解题思路
* 成员方法能不能调用，就是成员的访问权限，是在编译阶段确定的。
* 在编译阶段，检查的是Base::show()方法，是public限定的，所以编译通过。
* 而基类指针指向派生类对象来调用虚函数，触发了动态绑定，是在运行阶段才确定的。
* 程序运行时，p指针调用Base::show()方法发现是个虚函数，查看对象vfptr指向的vftable中的函数地址为Derive::show()，直接调用。
# 题四
- 分析如下代码是否可以成功运行
```cpp
#include <cstring>
#include <iostream>

// 基类
class Base
{
public:
    Base()
    {
        std::cout << "Call Base()" << std::endl;
        clear();
    }
    // 将该对象内存上的值全部置0
    void clear() { memset(this, 0, sizeof(*this)); }
    virtual void show() { std::cout << "Call Base::show()" << std::endl; }
};
// 派生类
class Derive : public Base
{
public:
    Derive() { std::cout << "Call Derive()" << std::endl; }
    void show() override { std::cout << "Call Derive::show()" << std::endl; }
};
// 主函数
int main()
{
    // 基类指针指向堆上的基类对象
    Base *p = new Base();
    /*
     *构建基类对象时，对象在内存上的虚函数表值全部置0，无法调用虚函数，所以出错
     */
    p->show();
    delete p;
    // 基类指针指向堆上的派生类对象
    Base *q = new Derive();
    /* 派生类在构造时先调用基类构造方法，再调用派生类构造方法。
     * 基类构造方法在生成栈帧后就将vftable的地址写入对象的vfptr。写入之后再运行构造函数内的代码。将对象在内存上的虚函数表值全部置0。
     * 派生类构造函数在生成栈帧后就将vftable的地址写入对象的vfptr。派生类构造方法中没有将内存置0的操作，所以vfptr是有效的。可以执行。
     */
    q->show();
    delete q;

    return 0;
}
```
