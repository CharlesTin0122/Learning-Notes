# 对象池

C++中的**对象池（Object Pool）**是一种**资源管理模式**，用于减少对象创建和销毁的开销，特别是在频繁创建、销毁大量对象时。对象池通过**预先分配一组对象**，并在需要时重复使用这些对象，从而避免了频繁的内存分配和释放。它非常适用于需要频繁创建和销毁相似对象的场景，例如游戏开发中的子弹、网络连接池等。

### 核心概念
1. **池的预分配**：在初始化阶段，对象池会预先创建一组对象（或内存块）。
2. **对象重用**：当请求对象时，从池中返回一个未被使用的对象；当对象不再需要时，将其归还池中，而不是销毁。
3. **对象闲置管理**：池中有一部分对象可能闲置，但不被销毁，以便在下一次请求时快速提供。
4. **性能优化**：通过对象重用，避免了频繁的动态内存分配，提升了性能，尤其是在系统对内存分配敏感时。

### 对象池的典型使用场景
- **游戏开发**：在游戏中，像子弹、敌人或特效这样的对象频繁创建和销毁。使用对象池可以显著减少开销，提升帧率。
- **数据库连接池**：数据库连接的建立和释放代价较高，通过连接池可以提高性能。
- **线程池**：创建和销毁线程开销较大，通过线程池可以高效地管理线程资源。

### 对象池的优点
- **减少内存分配和释放的开销**。
- **提升性能**，特别是在内存分配频繁的场景。
- **控制资源数量**，避免资源过度使用。

### 对象池的缺点
- **内存占用**：预先分配的对象在未被使用时仍然占用内存。
- **复杂性增加**：对象池需要额外的管理逻辑，可能增加代码的复杂性。

### C++中对象池的实现思路

C++中可以通过使用一个数组或容器来存储对象，并通过**空闲列表（free list）**来管理哪些对象可用。以下是一个简单的对象池的伪代码结构：

```cpp
template<typename T>
class ObjectPool {
public:
    // 初始化池，创建n个对象
    ObjectPool(size_t n) {
        for (size_t i = 0; i < n; ++i) {
            pool.push_back(new T());  // 预先创建对象
        }
    }
    
    // 获取一个可用对象
    T* acquire() {
        if (pool.empty()) {
            return nullptr;  // 池已空
        }
        T* obj = pool.back();
        pool.pop_back();
        return obj;
    }
    
    // 归还对象到池中
    void release(T* obj) {
        pool.push_back(obj);  // 对象归还
    }

    ~ObjectPool() {
        for (T* obj : pool) {
            delete obj;  // 释放所有对象
        }
    }

private:
    std::vector<T*> pool;  // 存储对象的容器
};
```

### 代码解释
- **`acquire()`**：用于从池中获取一个对象。如果池为空，则返回`nullptr`。
- **`release()`**：将对象放回池中，以便下次重用。
- **池的大小管理**：可以通过在池耗尽时动态创建新对象，或者设置一个最大池大小来限制内存使用。

### 小结
对象池模式是一种高效的资源管理策略，特别适合需要频繁创建和销毁大量相同类型对象的场景。通过减少内存分配和释放的次数，显著提升了程序的性能。

```cpp

#include <cstddef>
#include <iostream>
#include <stdexcept>

// 链式队列
template <typename T>
class LinkedQueue
{
public:
    // 构造函数，生成一个头节点
    LinkedQueue() { _front = _rear = new QueueItem(); }
    // 析构函数
    ~LinkedQueue()
    {
        // 释放队列
        QueueItem *cur = _front;
        while (cur)
        {
            _front = _front->_next; // 队首指针后移
            delete cur;             // 删除当前节点
            cur = _front;           // 游标指针接收队首指针
        }
        // 释放对象池
        // 清理对象池
        while (QueueItem::_itemPool)
        {
            std::cout << "Release object pool " << std::endl;
            QueueItem *next = QueueItem::_itemPool->_next;
            ::operator delete(QueueItem::_itemPool);
            QueueItem::_itemPool = next;
        }
    };
    // 入队
    void push(const T &val)
    {
        QueueItem *item = new QueueItem(val); // 创建新对象
        _rear->_next = item;                  // 队尾指针域指向新对象
        _rear = item;                         // 队尾指针指向新对象
    }
    // 出队操作
    void pop()
    {
        // 如果队列为空，抛出异常
        if (this->empty()) throw std::runtime_error("Queue is empty,can`t pop!");

        // 临时变量接收要删除的节点
        QueueItem *tmp = _front->_next;
        if (!tmp) return; // 如果队列空了，直接返回
        // 修改头节点的指针域指向删除节点的后继
        _front->_next = tmp->_next;
        // 如果队列中只有一个节点，重置_rear，要不然会丢失_rear
        if (_front->_next == nullptr) { _rear = _front; }
        // 删除节点
        delete tmp;
    }
    // 查看队首
    T front() const
    {
        if (empty()) throw std::runtime_error("Queue is empty, can't return front!");
        return _front->_next->_data;
    }
    // 判空
    bool empty() const { return _front == _rear; }

private:
    // 链式队列元素结构体
    struct QueueItem
    {
        // 构造函数，T()为0构造,调用T类型的默认构造
        QueueItem(T data = T()) : _data(data), _next(nullptr) {}
        /*new和delete操作符重载，给QueueItem提供自定义内存管理
         *当开辟内存的时候对象还不存在，当释放内存的时候对象已析构，跟对象无关，所以这两个方法编译器会处理成静态方法
         */
        // new操作符重载，创建一个十万对象的对象池，对象池底层是一个链表结构
        void *operator new(size_t size)
        {
            std::cout << "new obj" << std::endl;
            // 如果对象池为空，开辟对象池
            if (_itemPool == nullptr)
            {
                // 开辟十万个对象的对象池
                _itemPool = (QueueItem *)new char[POOL_ITEM_SIZE * sizeof(QueueItem)];
                // 对象池串联为链表
                QueueItem *p = _itemPool;
                for (; p < _itemPool + POOL_ITEM_SIZE - 1; ++p)
                {
                    p->_next = p + 1;
                }
                p->_next = nullptr; // 最后一个对象指针域置空
            }
            // 指针后移，然后返回之前的节点
            QueueItem *ptr = _itemPool;
            _itemPool = _itemPool->_next;
            return ptr;
        }
        // delete操作符重载,将对象归还对象池,头插法将对象插入对象池链表
        void operator delete(void *ptr)
        {
            std::cout << "return obj" << std::endl;
            QueueItem *p = (QueueItem *)ptr; // 指针转化为QueueItem类型指针
            p->_next = _itemPool;            // 指针地址域指向头节点地址
            _itemPool = p;                   // 更新头节点地址
        }
        T _data;
        QueueItem *_next;
        // 对象池大小，静态常量可以在类内初始化
        static const int POOL_ITEM_SIZE = 100000;
        // 对象池首地址，静态成员变量类内声明，类外定义和初始化
        static QueueItem *_itemPool;
    };
    QueueItem *_front; // 队首
    QueueItem *_rear;  // 队尾
};

// 静态成员变量类外定义和初始化
template <typename T>
// typename用于确定LinkedQueue<T>::QueueItem的类型
typename LinkedQueue<T>::QueueItem *LinkedQueue<T>::QueueItem::_itemPool = nullptr;

int main()
{
    LinkedQueue<int> que;
    // 一百万次的开辟内存，构建对象和析构对象，释放内存。
    // 可以创建一个对象池，池内部放置若干QueueItem对象
    for (int i = 0; i < 100; ++i)
    {
        que.push(i);
        que.pop();
    }

    return 0;
}
```
