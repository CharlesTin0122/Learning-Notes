# 引子
参考上节课MyVector类[MyVector类](4.3%20实现C++%20STL向量容器vector代码.md)，我们发现：
- `new`关键字在开辟空间的同时会调用构造函数构造对象，创建空容器的时候会构造size个对象，我们需要的只是开辟空间，而不是构造对象。
- `delete`关键字在释放空间的同时会调用析构函数析构对象，我们需要析构容器有效元素，然后释放指针指向的堆内存。
- 当我们向容器中添加数据时，应当在容器中构造对象，但是现在只是将对象的值写入了容器中已经构造好的对象中。因为new关键字已经在开辟内存的同时构造了对象。
- 当我们在容器中移除对象时，我们只是将`_last--`，对象并没有析构。当我们再为此对象赋值时，该对象之前指向的内存就丢失了。我们只需要析构对象，而不释放对象的内存。
- 我们需要把内存开辟释放和对象构造析构分开处理。
- 因此，我们需要容器的空间配置器allocator。
# 容器的空间配置器allocator
做四件事
- 内存开辟
- 内存释放
- 对象构造
- 对象析构
```cpp
#include <cstddef>
#include <cstdlib>
#include <iostream>
#include <stdexcept>

// 实现容器的空间配置器，容器底层内存开辟释放，对象构造析构，都使用空间适配器来实现
template <typename T>
struct MyAllocator
{
    // 内存开辟
    T *allocate(size_t size)
    {
        // 使用malloc函数只开辟内存，不构造对象
        T *ptr = (T *)malloc(sizeof(T) * size);
        if (!ptr) { throw std::bad_alloc(); }
        return ptr;
    }
    // 内存释放
    void deallocate(T *ptr) { free(ptr); }
    // 对象构造,在ptr地址构造值为val的对象
    void construct(T *ptr, const T &val)
    {
        // 定位new,在ptr地址构造值为val的对象，调用T类型对象的拷贝构造函数
        new (ptr) T(val);
    }
    // 对象析构
    void destroy(T *ptr)
    {
        // 调用T类型的析构函数
        ptr->~T();
    }
};

// 实现vector类,ALLOC是非类型模板参数：空间配置器，意味着它在编译期必须是一个常量
template <typename T, typename ALLOC = MyAllocator<T>>
class MyVector
{
public:
    // 构造函数
    MyVector(int size = 10)
    {
        // 使用空间配置器开辟内存
        //_first = new T[size];
        _first = _allocator.allocate(size);
        _last = _first;
        _end = _first + size;
    }
    // 拷贝构造函数
    MyVector(const MyVector<T> &other)
    {
        // 计算参数对象长度
        int otherSize = other._end - other._first;
        // 分配新内存
        //_first = new T[otherSize];
        _first = _allocator.allocate(otherSize);
        // 拷贝数据
        int otherLen = other._last - other._first;
        for (int i = 0; i < otherLen; i++)
        {
            // 利用空间配置器构建对象
            //  this->_first[i] = other._first[i];
            _allocator.construct(_first + i, other._first[i]);
        }

        this->_last = this->_first + otherLen;
        this->_end = this->_first + otherSize;
    }
    // 赋值运算符重载
    MyVector<T> &operator=(const MyVector<T> &other)
    {
        // 防止自赋值
        if (this == &other) return *this;
        // 删除旧数据
        // delete[] _first;
        // 利用空间配置器析构有效元素
        for (T *p = _first; p != _last; ++p)
        {
            _allocator.destroy(p);
        }
        // 利用空间配置器释放堆上的数组内存
        _allocator.deallocate(_first);
        // 填充新数据
        // 计算参数对象长度
        int otherSize = other._end - other._first;
        // 分配新内存
        //_first = new T[otherSize];
        _first = _allocator.allocate(otherSize);
        // 拷贝数据
        int otherLen = other._last - other._first;
        for (int i = 0; i < otherLen; i++)
        {
            // 利用空间配置器构建对象
            //  this->_first[i] = other._first[i];
            _allocator.construct(_first + i, other._first[i]);
        }

        this->_last = this->_first + otherLen;
        this->_end = this->_first + otherSize;

        return *this;
    }
    ~MyVector()
    {
        // 利用空间配置器析构有效元素
        // delete[] _first;
        for (T *p = _first; p != _last; ++p)
        {
            _allocator.destroy(p);
        }
        // 利用空间配置器释放堆上的数组内存
        _allocator.deallocate(_first);
        _first = _last = _end = nullptr;
    }
    // 添加元素
    void push(const T &val)
    {
        if (this->full()) this->expand();
        // 在_last地址构造一个值为val的对象
        //*_last++ = val;
        _allocator.construct(_last, val);
        _last++;
    }
    // 弹出元素
    void pop()
    {
        if (this->empty()) throw std::runtime_error("vector is empty!");
        // 析构要删除的元素，并且_last指针自减
        --_last;
        _allocator.destroy(_last);
    }
    // 返回末尾元素
    T back() const
    {
        if (this->empty()) throw std::runtime_error("vector is empty!");
        return *(_last - 1);
    }
    bool full() const { return _last == _end; }
    bool empty() const { return _last == _first; }
    int size() const { return _last - _first; }

    void print() const
    {
        for (int i = 0; i < this->size(); i++)
        {
            std::cout << _first[i] << " ";
        }
        std::cout << std::endl;
    }

private:
    T *_first;        // 指向数组起始位置
    T *_last;         // 指向数组中有效元素的后继位置
    T *_end;          // 指向数组空间的后继位置
    ALLOC _allocator; // 定义容器的空间配置器对象
    // 扩容
    void expand()
    {
        // 获取新数组容量和长度
        int newSize = (_end - _first) * 2;
        int len = _last - _first;
        // 申请新空间
        // T *newData = new T[newSize];
        T *newData = _allocator.allocate(newSize);
        // 赋值
        for (int i = 0; i < len; i++)
        {
            // newData[i] = _first[i]
            _allocator.construct(newData + i, _first[i]);
        }
        // delete[] _first;
        for (T *p = _first; p != _last; ++p)
        {
            _allocator.destroy(p);
        }
        _allocator.deallocate(_first);

        _first = newData;
        _last = _first + len;
        _end = _first + newSize;
    }
};

int main()
{
    MyVector<int> vec;
    for (int i = 0; i < 20; i++)
    {
        vec.push(rand() % 100);
    }
    vec.print();
    vec.pop();
    vec.print();
    std::cout << std::endl;
}
```
# STL 中的allocator
C++ 中的 **allocator** 是一种用于管理容器中的内存分配和释放的工具。它主要用于标准模板库（STL）中的容器类，比如 `vector`, `list`, `map`, 等。`allocator` 允许容器与底层的内存管理机制解耦，这样可以通过自定义内存分配器来优化性能、减少内存碎片，或者满足某些特殊需求。

### `allocator` 的核心功能
`allocator` 主要负责两件事：
1. **内存分配（allocation）：** 负责为某类型的对象分配原始内存，不调用构造函数。
2. **内存释放（deallocation）：** 负责释放对象的原始内存，不调用析构函数。
3. **对象构造与销毁：** 在已经分配的内存上构造或销毁对象。

C++ 标准库的 `std::allocator` 类是 STL 容器默认使用的分配器，它为容器管理内存提供了一个默认的实现。`std::allocator` 直接使用 `operator new` 和 `operator delete` 来分配和释放内存。

### `allocator` 的典型用法
以 `std::allocator` 为例，它是一个模板类，通常用于指定容器中存储元素的类型。

```cpp
#include <iostream>
#include <memory> // for std::allocator

int main() {
    // 创建一个 int 类型的 allocator
    std::allocator<int> alloc;

    // 分配内存，不调用构造函数
    int* p = alloc.allocate(3); // 分配3个int的内存空间

    // 使用构造函数在分配的内存上构造对象
    alloc.construct(p, 10);       // 在 p[0] 上构造值为 10 的对象
    alloc.construct(p + 1, 20);   // 在 p[1] 上构造值为 20 的对象
    alloc.construct(p + 2, 30);   // 在 p[2] 上构造值为 30 的对象

    // 输出分配并构造的值
    std::cout << p[0] << " " << p[1] << " " << p[2] << std::endl;

    // 销毁对象，但不释放内存
    alloc.destroy(p);       // 销毁 p[0]
    alloc.destroy(p + 1);   // 销毁 p[1]
    alloc.destroy(p + 2);   // 销毁 p[2]

    // 释放内存，不调用析构函数
    alloc.deallocate(p, 3); // 释放分配的内存
    return 0;
}
```

### `allocator` 的接口

以下是 `std::allocator` 类的常用成员函数：

- **`allocate(size_t n)`**: 为 `n` 个对象分配未初始化的内存。
- **`deallocate(T* p, size_t n)`**: 释放之前分配的 `n` 个对象的内存。
- **`construct(T* p, Args&&... args)`**: 在指针 `p` 指向的内存上调用对象的构造函数。
- **`destroy(T* p)`**: 在指针 `p` 指向的内存上调用对象的析构函数。

### 自定义 `allocator`
用户可以通过自定义 `allocator` 来改变容器的内存分配策略。以下是自定义一个简单的分配器的步骤：

1. **继承标准的分配器接口**。
2. **提供内存分配、释放和构造对象的机制**。

一个简单的自定义 allocator 模板实现如下：

```cpp
#include <iostream>
#include <memory>

template <typename T>
class MyAllocator {
public:
    using value_type = T;

    // 分配内存但不初始化对象
    T* allocate(std::size_t n) {
        std::cout << "Allocating " << n << " objects." << std::endl;
        return static_cast<T*>(::operator new(n * sizeof(T)));
    }

    // 释放分配的内存
    void deallocate(T* p, std::size_t n) {
        std::cout << "Deallocating " << n << " objects." << std::endl;
        ::operator delete(p);
    }

    // 调用对象的构造函数
    template <typename U, typename... Args>
    void construct(U* p, Args&&... args) {
        new (p) U(std::forward<Args>(args)...);
    }

    // 调用对象的析构函数
    template <typename U>
    void destroy(U* p) {
        p->~U();
    }
};

// 测试自定义allocator
int main() {
    MyAllocator<int> alloc;

    int* p = alloc.allocate(3);
    alloc.construct(p, 100);
    alloc.construct(p + 1, 200);
    alloc.construct(p + 2, 300);

    std::cout << p[0] << " " << p[1] << " " << p[2] << std::endl;

    alloc.destroy(p);
    alloc.destroy(p + 1);
    alloc.destroy(p + 2);
    alloc.deallocate(p, 3);

    return 0;
}
```

### 总结
`allocator` 是 C++ 标准库中容器类用于管理内存的机制，它将内存管理和容器逻辑分离，使得内存分配过程更加灵活。通过 `std::allocator` 提供的接口，开发者可以自定义内存分配策略，并根据具体需求编写高效的分配器。
