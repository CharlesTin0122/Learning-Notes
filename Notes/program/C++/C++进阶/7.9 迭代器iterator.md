# 迭代器类型
- const_iterator： 常量正向迭代器，正向遍历，只读不写。在底层代码中，iterator是const_iterator的派生类，因此const_iterator类型可以接收iterator类型对象。
	- 源代码结构如下：
```cpp
class const_iterator
{
public:
	const T &operator* (){return *_ptr}
};

class iterator : public const_iterator
{
	T &operator* (){return *_ptr}
}
```
- iterator：正向迭代器，正向遍历，可读可写
- reverse_iterator：反向迭代器，反向遍历，示例如下
```cpp
    std::vector<int> vec;
    for (int i = 0; i < 20; ++i)
    {
        vec.push_back(rand() % 100 + 1);
    }
    // reverse_iterator反向迭代器，
    // rbegin()返回的是最后一个元素的反向迭代器表示
    // rend()返回的是首元素前趋位置的反向迭代器表示
    std::vector<int>::reverse_iterator rit = vec.rbegin();
    while (rit != vec.rend())
    {
        std::cout << *rit << " ";
        ++rit;
    }
    std::cout << std::endl;
```
- const_reverse_iterator：常量反向迭代器，反向遍历，不可修改
