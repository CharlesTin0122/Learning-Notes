# 概念和分类
底层是链式哈希表，增删查近$O(1)$
- unordered_set：无序单重集合
- unordered_multiset：无序多重集合
- unordered_map：无序单重映射
- unordered_multimap：无序多重映射
# 常用方法
- 增加元素：`insert(val)`
- 遍历元素：`iterator`迭代器遍历
- 删除元素：`erase(key)`, `erase(it)`
- 查找元素：`operator[]`, `find(key)`
# set 示例
```cpp
    // 无序单重集合，存储的元素无序且不会重复
    std::unordered_set<int> set1;
    for (int i = 0; i < 20; ++i)
    {
        set1.insert(rand() % 20 + 1); // 插入位置由哈希函数决定，无需提供迭代器
    }

    std::cout << set1.size() << std::endl;    // 返回集合元素个数
    std::cout << set1.count(15) << std::endl; // 返回值为15的元素个数

    // 迭代器遍历
    for (auto it = set1.begin(); it != set1.end(); ++it)
    {
        std::cout << *it << " ";
    }
    std::cout << std::endl;

    // 按Key删除元素
    auto it = set1.begin();
    while (it != set1.end())
    {
        // 连续删除，要更新迭代器
        if (*it == 19) { it = set1.erase(it); }
        else { ++it; }
    }
    // 查找find(val),返回迭代器
    it = set1.find(15);
```
# map示例
```cpp
    // 创建无序单重映射，key无序且不重复
    std::unordered_map<int, std::string> map;
    // 映射中插入pair对象
    map.insert(std::make_pair(10, "ZhangSan"));
    map.insert({11, "LiSi"});
    map.insert(std::pair<int, std::string>(12, "WangWu"));
    // 元素个数
    std::cout << map.size() << std::endl;
    // 按key查询,map提供了operator[]运算符重载
    std::cout << map[11] << std::endl;
    // 当[]访问key不存在的元素时，映射会自动插入对应[key,T()]的元素
    map[13] = "ZhaoLiu";
    //[]修改操作
    map[12] = "WangEr";
    // 按key删除元素
    map.erase(13);
    // find()查找
    auto it = map.find(12);
    if (it != map.end())
    {
        // it -> pair
        std::cout << it->first << ": " << it->second << std::endl;
    }
```
# 应用
- 海量数据查重、去重
## 查重示例
```cpp
// 数组查重，统计哪些数字重复了，并统计重复次数

// 创建数组
const int ARR_LEN = 100;
int arr[ARR_LEN] = {0};
for (int i = 0; i < ARR_LEN; ++i)
{
	arr[i] = rand() % 20 + 1;
}
// 数组查重，统计哪些数字重复了，并统计重复次数
std::unordered_map<int, int> map; // 创建无需单重映射
// 遍历数组，如果映射中没有该值，则新增该值为key的元素，且value++
for (const int val : arr)
{
	map[val]++;
}
// foreach遍历映射,打印数字和重复次数
for (const std::pair<int, int> &p : map)
{
	if (p.second > 1) { std::cout << p.first << " : " << p.second << std::endl; }
}
```
## 去重示例
```cpp
// 创建数组
const int ARR_LEN = 100;
int arr[ARR_LEN] = {0};
for (int i = 0; i < ARR_LEN; ++i)
{
	arr[i] = rand() % 20 + 1;
}

// 数据去重

// 创建无序单重集合
std::unordered_set<int> set;
// 数组元素放入集合，自动去重
for (const int val : arr)
{
	set.insert(val);
}
// 打集合元素
for (const int &val : set)
{
	std::cout << val << " ";
}
std::cout << std::endl;
```
