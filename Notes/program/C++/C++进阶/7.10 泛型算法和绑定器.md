# 常用算法
- sort：排序
- find：查找
- find_if：条件查找
- binary_search：二分查找
- for_each：遍历
# 特点
- 泛型算法由模板实现
- 泛型算法接收的都是迭代器
- 泛型算法参数可以接收函数对象
# 代码案例
```cpp
    // 定义数组
    int arr[] = {12, 4, 78, 9, 21, 43, 56, 42, 31};
    // 将数组元素填充向量容器，参数1：数组首元素地址，参数2：数组末元素地址
    std::vector<int> vec(arr, arr + sizeof(arr) / sizeof(arr[0]));
    // 循环打印
    for (const int &val : vec)
    {
        std::cout << val << " ";
    }
    std::cout << std::endl;
    // 泛型算法 sort,升排列
    std::sort(vec.begin(), vec.end());
    // 泛型算法，二分查找,对容器的排序有要求。它要求容器中的元素必须是升序排列，否则结果可能不正确。
    if (std::binary_search(vec.begin(), vec.end(), 21))
    {
        std::cout << " find 21" << std::endl;
    }
    // 泛型算法 sort,传入函数对象greater使其降序排列
    std::sort(vec.begin(), vec.end(), std::greater<int>());
    // 泛型算法，查找
    auto it1 = std::find(vec.begin(), vec.end(), 21);
    if (it1 != vec.end()) { std::cout << "find 21" << std::endl; }
    // 泛型算法，按条件查找，将48按序插入容器,需要一个一元函数对象,需要使用绑定器
    // 二元函数对象 + 绑定器 = 一元函数对象
    // greater(48, b)，找到第一个小于48的数,std::placeholders::_1绑定参数位置
    auto it2 =
        find_if(vec.begin(), vec.end(),
                std::bind(std::greater<int>(), 48, std::placeholders::_1));
    // 也可以使用lambda表达式实现
    auto it3 = find_if(vec.begin(), vec.end(),
                       [](int val) -> bool { return val < 48; });
    vec.insert(it3, 48);
    // 循环打印
    for (const int &val : vec)
    {
        std::cout << val << " ";
    }
    std::cout << std::endl;

    // 打印所有偶数
    std::for_each(vec.begin(), vec.end(),
                  [](int val) -> void
                  {
                      if (val % 2 == 0) { std::cout << val << " "; }
                  });
    std::cout << std::endl;
```
# 绑定器
在 C++ 中，**绑定器（Binder）** 是一个功能强大的工具，主要用于将函数对象与参数绑定在一起，创建新的可调用对象。这一机制在使用 STL 算法时非常有用，尤其是当你需要对函数进行适配或传递额外参数时。

### 绑定器的主要类型

1. **`std::bind`**：
   - 用于创建一个新函数对象，将一个函数或可调用对象及其部分参数绑定在一起。
   - 可以绑定普通函数、成员函数或 Lambda 表达式。
   - 语法示例：
     ```cpp
     #include <iostream>
     #include <functional>

     void add(int a, int b) {
         std::cout << "Sum: " << (a + b) << std::endl;
     }

     int main() {
         // 绑定参数
         auto boundAdd = std::bind(add, 5, std::placeholders::_1);
         
         // 调用时只需提供剩余的参数
         boundAdd(10); // 输出: Sum: 15
         return 0;
     }
     ```

2. **`std::placeholders`**：
   - 与 `std::bind` 结合使用，用于指明哪些参数是占位符。
   - 通过 `_1`, `_2`, `_3` 等占位符表示需要在调用时提供的参数。

### 绑定器的用途

- **简化函数调用**：通过固定某些参数，创建新的简化调用接口。
- **适配算法**：使已有的函数适配 STL 算法的接口。
- **创建回调**：在事件处理或异步编程中，将特定操作绑定为回调函数。

### 注意事项

- **性能**：`std::bind` 的性能可能不如直接使用 Lambda 表达式，因为 Lambda 是更轻量级的。
- **可读性**：过度使用绑定器可能导致代码的可读性降低，建议适量使用。

### 示例

使用 `std::bind` 和 STL 算法结合的示例：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <functional>

void printValue(int value) {
    std::cout << value << " ";
}

int main() {
    std::vector<int> vec = {1, 2, 3, 4, 5};

    // 使用 std::bind 绑定打印函数
    auto boundPrint = std::bind(printValue, std::placeholders::_1);
    
    // 使用 std::for_each 与绑定器
    std::for_each(vec.begin(), vec.end(), boundPrint);
    std::cout << std::endl;

    return 0;
}
```

在这个示例中，`std::bind` 将 `printValue` 函数与参数绑定在一起，并用于 STL 的 `std::for_each` 算法中。

### 总结

绑定器是 C++ 中的强大工具，能够提高代码的灵活性和可复用性，尤其在需要处理复杂函数调用时。理解和正确使用绑定器，可以帮助你更高效地编写 C++ 代码。
