C++中的构造函数和析构函数是类中用于管理对象生命周期的两个特殊函数。构造函数用于初始化对象，而析构函数则用于清理对象在销毁时的资源。它们对面向对象编程的核心概念——对象的创建和销毁，起到了至关重要的作用。

---

### **构造函数（Constructor）**

#### 1. 定义
构造函数是在创建类对象时自动调用的特殊成员函数，其主要作用是对对象进行初始化。构造函数的名称与类名相同，并且没有返回类型（包括`void`）。

#### 2. 特点
- **名称与类名相同**：构造函数的名称必须与类名完全相同。
- **没有返回值**：构造函数不能有返回类型，也不能返回值。
- **自动调用**：当对象被创建时，构造函数会自动调用。
- **可以重载**：可以定义多个构造函数（参数不同），通过重载来实现不同的初始化方式。

#### 3. 构造函数的类型
- **默认构造函数**：不带参数的构造函数。如果用户没有定义构造函数，编译器会生成一个默认的无参数构造函数。
  ```cpp
  class MyClass {
  public:
      MyClass() {  // 默认构造函数
          // 初始化代码
      }
  };
  ```

- **带参数的构造函数**：允许通过传递参数来初始化对象的状态。
  ```cpp
  class MyClass {
  public:
      int x;
      MyClass(int val) {  // 带参数的构造函数
          x = val;
      }
  };
  ```

- **拷贝构造函数**：用于通过另一个同类型的对象来初始化新对象，通常以对象的引用作为参数。
  ```cpp
  class MyClass {
  public:
      int x;
      MyClass(const MyClass &obj) {  // 拷贝构造函数
          x = obj.x;
      }
  };
  ```

#### 4. 示例
```cpp
#include <iostream>
using namespace std;

class MyClass {
public:
    int x;
    
    // 默认构造函数
    MyClass() {
        x = 0;
        cout << "Default constructor called\n";
    }

    // 带参数的构造函数
    MyClass(int val) {
        x = val;
        cout << "Parameterized constructor called\n";
    }

    // 拷贝构造函数
    MyClass(const MyClass &obj) {
        x = obj.x;
        cout << "Copy constructor called\n";
    }
};

int main() {
    MyClass obj1;            // 调用默认构造函数
    MyClass obj2(10);        // 调用带参数的构造函数
    MyClass obj3 = obj2;     // 调用拷贝构造函数

    return 0;
}
```

#### 输出：
```
Default constructor called
Parameterized constructor called
Copy constructor called
```

### **析构函数（Destructor）**

#### 1. 定义
析构函数是在对象的生命周期结束时自动调用的特殊成员函数，其主要作用是执行对象的清理工作，比如释放内存或关闭文件。析构函数的名称是在类名前加`~`符号构成的，没有参数和返回值。

#### 2. 特点
- **名称是类名前加`~`**：析构函数的名称是类名之前加上波浪号`~`。
- **没有返回值**：与构造函数一样，析构函数也不能有返回类型。
- **无参数**：析构函数不能有参数，因此不能被重载。
- **自动调用**：当对象的生命周期结束时，析构函数会被自动调用（例如当对象超出作用域时或通过`delete`删除时）。
- 析构函数只能有一个。

#### 3. 作用
析构函数的主要作用是释放对象使用的资源，如动态分配的内存、打开的文件句柄或其他系统资源。

#### 4. 示例
```cpp
#include <iostream>
using namespace std;

class MyClass {
public:
    MyClass() {
        cout << "Constructor called\n";
    }

    ~MyClass() {
        cout << "Destructor called\n";
    }
};

int main() {
    MyClass obj;  // 构造函数会被调用

    // 当函数结束，obj超出作用域时，析构函数会自动调用
    return 0;
}
```

#### 输出：
```
Constructor called
Destructor called
```

### **构造函数和析构函数的配对使用**
构造函数和析构函数通常成对使用，用构造函数进行对象的初始化，用析构函数释放对象使用的资源。特别是在涉及动态内存分配的场景下，这一点尤为重要，以避免内存泄漏。

#### 示例：动态分配内存
```cpp
#include <iostream>
using namespace std;

class MyClass {
private:
    int* ptr;
public:
    // 构造函数：动态分配内存
    MyClass(int val) {
        ptr = new int;
        *ptr = val;
        cout << "Memory allocated for ptr\n";
    }

    // 析构函数：释放内存
    ~MyClass() {
        delete ptr;
        cout << "Memory deallocated for ptr\n";
    }
};

int main() {
    MyClass obj(42);  // 构造函数分配内存

    // 当程序结束时，析构函数自动调用并释放内存
    return 0;
}
```

#### 输出：
```
Memory allocated for ptr
Memory deallocated for ptr
```

### 案例
```cpp
#include <iostream>

// 利用面向对象实现一个顺序栈
class SeqStack
{
public:
    // 构造函数
    SeqStack(int size = 10)
    {
        std::cout << this << "constructor" << std::endl;

        _data = new int[size];
        _top = -1;
        _size = size;
    }
    // 析构函数
    ~SeqStack()
    {
        std::cout << this << "destructor" << std::endl;

        delete[] _data;
        _data = nullptr;
        _top = -1;
        _size = 0;
    }
    void push(int val)
    {
        if (full()) { resieze(); }
        _data[++_top] = val;
    }
    void pop()
    {
        if (empty()) { return; }
        _top--;
    }
    int top()
    {
        if (empty()) { return -1; }
        return _data[_top];
    }
    bool empty() { return _top == -1; }
    bool full() { return _top == _size - 1; }

private:
    int *_data;
    int _top;
    int _size;

    void resieze()
    {
        int *newData = new int[_size * 2];
        for (int i = 0; i < _size; i++)
        {
            newData[i] = _data[i];
        }
        delete[] _data;
        _data = newData;
        _size *= 2;
    }
};
int main()
{
    SeqStack s(5);

    for (int i = 0; i < 15; i++)
    {
        s.push(rand() % 100);
    }

    while (!s.empty())
    {
        std::cout << s.top() << " ";
        s.pop();
    }
    std::cout << std::endl;

    return 0;
}
```
### **总结**
- **构造函数**用于初始化对象，在对象创建时自动调用，可以重载。
- **析构函数**用于清理对象资源，在对象销毁时自动调用，不可重载。
- 构造函数和析构函数是管理对象生命周期的关键部分，确保对象的正确创建和销毁，特别是在涉及动态资源管理时。

这两者一起保障了C++中对象生命周期的安全性与资源管理的有效性。
