# 迭代器为何会失效
- 移除元素
	- 当容器移除某个元素后，移除位置元素到容器末尾元素迭代器全部失效。
- 添加元素
	- 当容器添加元素但是没有引起扩容操作时，插入位置元素到容器末尾元素迭代器全部失效。
	- 当容器添加元素并且引起容器内存扩容操作时，所有元素迭代器全部失效。
# 如何解决迭代器失效问题
- 对插入/移除点的迭代器进行更新操作。
- `erase()`和`insert()`函数在移除和插入元素后会返回一个新的合法迭代器，更新迭代器变量即可。
```cpp
#include <cstdlib>
#include <iostream>
#include <vector>

// 打印函数
void print(const std::vector<int> &vec)
{
    for (const int &val : vec)
    {
        std::cout << val << " ";
    }
    std::cout << std::endl;
}
int main()
{
    // 创建容器
    std::vector<int> vec;
    for (int i = 0; i < 20; ++i)
    {
        vec.push_back(rand() % 100 + 1);
    }
    print(vec);

    // 场景1，将vec容器中所有的偶数全部删除
    auto it1 = vec.begin();
    while (it1 != vec.end())
    {
        // 如果当前元素是偶数，移除元素并接收更新后的迭代器
        if (*it1 % 2 == 0)
        {
            // 移除元素迭代器会失效，使用it1变量接收更新后的迭代器
            it1 = vec.erase(it1);
        }
        // 如果当前元素是奇数，后移迭代器
        else { ++it1; }
    }
    print(vec);
    // 场景2，将vec容器中所有的奇数前面放置一个该数-1的值
    auto it2 = vec.begin();
    while (it2 != vec.end())
    {
        // 如果元素为奇数
        if (*it2 % 2 != 0)
        {
            // 插入元素会导致迭代器失效，使用it2变量接收更新后的迭代器
            it2 = vec.insert(it2, *it2 - 1);
            // 因为插入了新元素，接收新迭代器后遍历到下个元素需要迭代器+2
            it2 += 2;
        }
        // 如果元素为偶数，迭代器+1
        else { it2++; }
    }
    print(vec);

    return 0;
}
```
