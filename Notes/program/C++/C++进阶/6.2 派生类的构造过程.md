# 派生类如何初始化从基类继承来的成员变量
```cpp
#include <iostream>
class Base
{
public:
    Base(int val) : ma(val) { std::cout << "Base()" << std::endl; }
    ~Base() { std::cout << "~Base()" << std::endl; }

protected:
    int ma;
};

// 派生类/子类，类B继承自类A
class Derive : public Base
{
public:
    // Base(val)调用基类构造函数进行初始化，ma(val);
    Derive(int val) : Base(val), mb(val) { std::cout << "Derive()" << std::endl; }
    ~Derive() { std::cout << "~Derive()" << std::endl; }

private:
    int mb;
};

int main()
{
    Derive d(20);

    return 0;
}
```
- 派生类可以从基类继承除**构造函数**和**析构函数**外的所有的成员（变量和方法）。因为**构造函数**和**析构函数**只有在自身类中才有意义。
- 要通过调用基类相应的构造函数进行初始化。
- 派生类的构造和析构函数负责初始化和清理派生类自身成员变量。
- 派生类从基类继承的成员由基类的构造和析构函数来负责初始化和清理。
# 派生类的构造过程
```
Base()
Derive()
~Derive()
~Base()
```
1. 派生类调用基类的构造函数，初始化从基类继承来的成员。
2. 调用派生类自身的构造函数，初始化从派生类自身的成员。
3. ...
4. 调用派生类自身析构函数，释放派生类自身成员可能占用的外部资源。
5.  调用基类的析构函数，释放派生类从基类继承来的成员可能占用的外部资源
