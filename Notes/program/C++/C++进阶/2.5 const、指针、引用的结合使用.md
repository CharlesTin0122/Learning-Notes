在C++中，`const`、指针和引用可以结合使用来表达不同的语义和约束。这些组合在控制变量的可变性、传递效率和保护数据完整性方面非常有用。下面是这些概念结合使用的详细解释和示例：

### 1. `const` 和 指针的结合
指针和 `const` 的结合主要有三种情况，分别表示不同的含义：

#### 1.1 指向常量的指针 (`const T*`)
语法：`const T* ptr;`

- `ptr` 是一个指针，它指向一个常量对象，即该对象的值不能通过指针修改。
- 但是，`ptr` 本身是可以改变的，可以指向不同的地址。

```cpp
int x = 10;
int y = 20;
const int* ptr = &x;  // ptr 指向常量 x，不能修改 x 的值
// *ptr = 15;  // 错误，不能通过 ptr 修改 x 的值
ptr = &y;  // 合法，ptr 可以指向不同的地址
```

#### 1.2 常量指针 (`T* const`)
语法：`T* const ptr;`

- `ptr` 是一个常量指针，即指针本身不可变，它的值（地址）不能被改变，但指向的对象的值是可以改变的。

```cpp
int x = 10;
int* const ptr = &x;  // ptr 是一个常量指针
*ptr = 15;  // 合法，可以修改 x 的值
// ptr = &y;  // 错误，不能修改 ptr 指向的地址
```

#### 1.3 指向常量的常量指针 (`const T* const`)
语法：`const T* const ptr;`

- `ptr` 是一个指向常量对象的常量指针，即既不能通过指针修改对象的值，也不能改变指针本身的地址。

```cpp
int x = 10;
const int* const ptr = &x;  // ptr 是一个指向常量的常量指针
// *ptr = 15;  // 错误，不能修改 x 的值
// ptr = &y;   // 错误，不能修改 ptr 的指向
```

### 2. `const` 和 引用的结合
引用（reference）本身有点像常量指针，但它比指针的语法更简洁。`const` 和引用的结合使用也可以用来控制引用的可变性。

#### 2.1 常量引用 (`const T&`)
语法：`const T& ref = obj;`

- `ref` 是对 `obj` 的常量引用，不能通过 `ref` 修改 `obj` 的值。这通常用于传递函数参数时，以避免拷贝并防止修改原始对象。

```cpp
int x = 10;
const int& ref = x;
// ref = 15;  // 错误，不能修改 x 的值
x = 15;  // 合法，可以直接修改 x 的值
```

#### 2.2 普通引用 (`T&`)
语法：`T& ref = obj;`

- `ref` 是一个普通的引用，可以通过它修改引用的对象。

```cpp
int x = 10;
int& ref = x;
ref = 15;  // 合法，可以通过 ref 修改 x 的值
```

### 3. `const`、指针和引用在函数参数中的使用
在函数参数中，`const`、指针和引用的结合常用来提高效率和确保代码的正确性。

#### 3.1 使用 `const` 引用作为函数参数
当函数接收一个大对象时，传值会产生性能开销，可以用 `const` 引用传参。

```cpp
void print(const std::string& str) {
    std::cout << str << std::endl;
}
```

- 这里使用了 `const std::string&`，避免了字符串的拷贝，同时保证函数不会修改传入的字符串。

#### 3.2 使用 `const` 指针作为函数参数
类似地，指针也可以用 `const` 修饰，防止函数修改指向的对象。

```cpp
void print(const int* ptr) {
    std::cout << *ptr << std::endl;
}
```

- 在这个例子中，`const int* ptr` 确保了指向的整数值不会被修改。

### 总结
- `const T*`：指向常量的指针，指向的对象不能被修改，但指针本身可以变。
- `T* const`：常量指针，指针本身不能变，但指向的对象可以被修改。
- `const T* const`：指向常量的常量指针，既不能修改指向的对象，也不能修改指针本身。
- `const T&`：常量引用，引用的对象不能被修改。

通过这些组合，可以实现更灵活的变量管理，确保数据的安全性和代码的效率。
