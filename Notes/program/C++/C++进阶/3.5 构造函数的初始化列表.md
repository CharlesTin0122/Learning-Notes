在C++中，构造函数的初始化列表（Initializer List）是用于在对象的构造过程中对成员变量进行初始化的一种机制。它的语法是在构造函数的参数列表后、函数体之前，以冒号（`:`）开头，后跟成员变量的初始化表达式。

### 初始化列表的语法：
```cpp
class MyClass {
public:
    int x;
    int y;

    // 构造函数使用初始化列表
    MyClass(int a, int b) : x(a), y(b) {
        // 构造函数体可以是空的
    }
};
```

在上面的代码中，`x` 和 `y` 被在构造函数体之前就已经用 `a` 和 `b` 初始化了。

### 初始化列表的优势：
1. **提高性能**：对于内置类型（如 `int`）的初始化，区别不大，但对于自定义类型（如对象），初始化列表可以避免调用默认构造函数，然后再通过赋值操作来赋值。初始化列表可以直接调用带参数的构造函数，减少一次对象的构造和赋值开销。

2. **必须使用初始化列表的情况**：
   - **常量成员变量**：`const` 修饰的成员变量只能在初始化列表中初始化，不能在构造函数体内赋值。
   - **引用类型成员**：C++中的引用成员变量一旦初始化后就不能再指向其他对象，因此必须在初始化列表中初始化。
   - **没有默认构造函数的成员**：如果类中的成员是某种没有默认构造函数的对象类型，必须通过初始化列表指定其构造函数参数。

### 示例：
```cpp
class Point {
public:
    const int x;
    int& y;

    // 使用初始化列表初始化 x 和 y
    Point(int a, int& b) : x(a), y(b) {
        // 构造函数体
    }
};
```
在上面的代码中，`x` 是一个常量，`y` 是一个引用，都必须在初始化列表中进行初始化。

### 初始化顺序：
初始化列表的顺序不是根据其在列表中的顺序，而是根据成员变量在类中的声明顺序。这意味着即使你在初始化列表中按照不同的顺序写初始化，也会根据类中声明的顺序进行初始化。

```cpp
class Example {
    int a;
    int b;
public:
    Example(int x, int y) : b(y), a(x) { }  // a 在 b 之后初始化，尽管顺序相反
};
```

尽量按照成员变量的声明顺序来编写初始化列表，以避免潜在的错误。如下
```cpp
class Test
{
public:
    Test(int data = 20) : mb(data), ma(mb) {}
    void showInfo()
    {
        std::cout << "ma = " << ma << std::endl;
        std::cout << "mb = " << mb << std::endl;
    }

private:
    int ma;
    int mb;
};

int main()
{
    Test t;
    t.showInfo();

    return 0;
}
```
- 初始化列表的顺序不是根据其在列表中的顺序，而是根据成员变量在类中的声明顺序。所以ma先初始化，mb后初始化。
- 所以ma被赋值mb，mb未被初始化，GCC编译器下值为0，VS编译器下值为：0xCCCCCCCC，也就是-858993460
- mb被赋值20。
