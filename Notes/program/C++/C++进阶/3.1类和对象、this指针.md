## this 指针

- 类的实例化，可以实例化无数对象，每个对象都有自己的成员变量，但是他们共享一套成员方法。
- 类的成员方法经过编译后，会在成员方法中隐式传递一个this指针，指向当前对象的地址。
- 成员方法通过this指针隐式传递，指向当前对象。成员方法通过this指针区分对象。

在C++中，`this`指针是每个非静态成员函数内部自动可用的一个指针，它指向调用该成员函数的对象。`this`指针可以让成员函数访问调用它的当前对象的成员变量和成员函数。

### **`this`指针的特点**
1. **指向当前对象**：`this`指针指向调用成员函数的那个对象的地址。
2. **只能在非静态成员函数中使用**：`this`指针只能用于非静态成员函数，因为静态成员函数不属于任何具体的对象，而是属于类本身。
3. **常见的隐式传递**：在成员函数中，编译器会隐式地将当前对象作为参数传递给成员函数，使得可以直接访问对象的成员变量和成员函数，而不必显式使用`this`。
4. **常量对象的`this`指针**：对于常量对象，`this`指针的类型是`const`，因此只能调用常量成员函数。

### **`this`指针的用途**

#### 1. **区分成员变量和局部变量**
在成员函数中，如果成员变量和局部变量同名，`this`指针可以用来明确区分成员变量和局部变量。通过`this->`语法，可以明确访问当前对象的成员变量。

#### 示例：
```cpp
#include <iostream>
using namespace std;

class MyClass {
private:
    int x;
public:
    MyClass(int x) {  // 局部变量x与成员变量x同名
        this->x = x;  // 使用this指针来区分成员变量和局部变量
    }

    void print() {
        cout << "x = " << this->x << endl;  // this->x也可以简写为x
    }
};

int main() {
    MyClass obj(10);
    obj.print();  // 输出: x = 10
    return 0;
}
```

#### 2. **返回对象自身（返回`*this`）**
在某些操作中，比如链式调用（chained invocation），可以通过返回`*this`指针来返回当前对象的引用。这使得可以连续调用多个成员函数。

#### 示例：链式调用
```cpp
#include <iostream>
using namespace std;

class MyClass {
private:
    int x;
public:
    MyClass(int x) {
        this->x = x;
    }

    MyClass& setX(int x) {
        this->x = x;
        return *this;  // 返回当前对象的引用
    }

    MyClass& print() {
        cout << "x = " << this->x << endl;
        return *this;  // 返回当前对象的引用
    }
};

int main() {
    MyClass obj(10);

    // 链式调用
    obj.setX(20).print().setX(30).print();

    return 0;
}
```

#### 输出：
```
x = 20
x = 30
```

#### 3. **用于防止对象自身的赋值（自赋值检测）**
在重载赋值运算符时，`this`指针可以用于检测自赋值的情况。这样可以避免不必要的操作或潜在的问题。

#### 示例：重载赋值运算符
```cpp
#include <iostream>
using namespace std;

class MyClass {
private:
    int* data;
public:
    MyClass(int val) {
        data = new int(val);
    }

    // 重载赋值运算符
    MyClass& operator=(const MyClass& other) {
        if (this == &other) {  // 防止自赋值
            return *this;
        }

        // 释放旧内存并分配新内存
        delete data;
        data = new int(*(other.data));
        return *this;
    }

    void print() {
        cout << "data = " << *data << endl;
    }

    ~MyClass() {
        delete data;
    }
};

int main() {
    MyClass obj1(10);
    MyClass obj2(20);

    obj1 = obj2;  // 调用赋值运算符
    obj1.print();

    obj1 = obj1;  // 自赋值，不进行任何操作
    obj1.print();

    return 0;
}
```

#### 输出：
```
data = 20
data = 20
```

在赋值运算符中，`if (this == &other)` 检测当前对象是否和右侧的对象是同一个对象（即自赋值情况），如果是，就不执行后续的内存操作，避免重复的赋值或资源泄漏。

### **总结**
- **`this`指针指向当前对象**，可以在类的非静态成员函数中使用，用于访问当前对象的成员。
- **典型用途**包括：
  - 区分成员变量和局部变量。
  - 在链式调用中返回当前对象的引用。
  - 在重载赋值运算符时防止自赋值。

`this`指针是C++中管理对象的一个重要工具，帮助程序员精确控制和操作对象的成员。
```cpp
#include <iostream>

class Goods
{
public:
    // 类内实现的成员方法自动处理为 inline 内联函数
    void init(std::string name, double price, int amount);
    void showInfo();

    std::string getName() { return _name; }
    double getPrice() { return _price; }
    int getAmount() { return _amount; }

    void setName(std::string name) { _name = name; }
    void setPrice(double price) { _price = price; }
    void setAmount(int amount) { _amount = amount; }

private:
    std::string _name; // 名称
    double _price;     // 单价
    int _amount;       // 数量
};
// 成员方法类外实现，为普通函数，不作为内联函数
void Goods::init(std::string name, double price, int amount)
{
    _name = name;
    _price = price;
    _amount = amount;
}
void Goods::showInfo() { std::cout << _name << " " << _price << " " << _amount << std::endl; }

int main()
{
    // 类的实例化，可以实例化无数对象，每个对象都有自己的成员变量，但是他们共享一套成员方法。
    // 类的成员方法经过编译后，会在成员方法中隐式传递一个this指针，指向当前对象的地址。
    // 成员方法通过this指针隐式传递，指向当前对象。成员方法通过this指针区分对象。
    Goods good;
    // 相当于 init(Goods *this, "bread", 32.56, 7)
    good.init("bread", 32.56, 7);
    good.showInfo();
    // 对象的大小只和成员变量有关
    std::cout << sizeof(good) << std::endl;

    return 0;
}
```
