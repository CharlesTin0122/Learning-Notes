# 编译过程
### 1. 预处理（Preprocessing）

预处理是编译的第一个阶段，处理源代码中的**预处理指令**。这些指令通常以`#`开头，例如`#include`、`#define`等。预处理的结果是生成一个扩展后的源文件，主要执行以下任务：

- **头文件包含**：将通过`#include`指令引用的头文件内容插入到源文件中。
- **宏替换**：将使用`#define`定义的宏替换为具体的值或表达式。
- **条件编译**：根据条件编译指令（如`#ifdef`、`#ifndef`等），编译器决定是否包含某些代码段。
- `pragma lib`和`pragma link`是在链接阶段处理的，而不是预处理阶段。

预处理完成后，结果是一个纯文本文件，扩展后的代码会被传递给编译器的下一阶段。

### 2. 编译（Compilation）

编译阶段是将预处理过的源代码转换为**汇编代码**。编译器将高层次的C++代码翻译成低级的机器指令。在此过程中，编译器会进行语法检查、语义分析和优化。具体流程包括：

- **语法分析**：检查代码的语法是否符合C++语言规范。
- **语义分析**：确保代码的语义正确，例如变量是否声明、函数参数类型是否匹配等。
- **代码优化**：在一定范围内进行优化，使生成的代码运行更高效。比如删除不必要的计算，或将某些表达式简化。

编译的输出是**汇编代码**，这是一种针对特定处理器的低级代码格式。

### 3. 汇编（Assembly）

汇编阶段的任务是将汇编代码转化为**目标代码**（object file）。汇编程序将汇编语言转换为机器语言，并生成一个与平台相关的二进制文件。这个文件包含了机器可执行的指令，但还不完整，因为它可能依赖其他代码（例如库函数或其他源文件的代码）。

输出的目标文件通常以`.o`或`.obj`为后缀。
# 目标文件
## 组成
每个目标文件由若干数据段组成：
- elf：文件头
- .text：代码段
- .data：数据段
- .bss：数据段
- .symbal：符号表
- .section table：段表
- ...

## 代码案例
sum.cpp
```cpp
int gdata = 10;       // 产生gdata符号，放入.data段
int sum(int a, int b) // 生成_Z3sumii符号，放入.text段
{
    return a + b;
}
```
main.cpp
```cpp
#include <iostream>

extern int gdata;  // 生成符号 gdata, 外部引用数据*UND*
int sum(int, int); // 生成符号 sun, 外部引用数据*UND*
int data = 20;     // 生成符号data, 放入.data段

int main() // 生成main符号，放在.test段
{
    int a = gdata;
    int b = data;
    int ret = sum(a, b);
    std::cout << ret << std::endl;

    return 0;
}
```
- 编译过程集中，符号是不分配虚拟地址的，地址默认都为0，因此目标文件无法执行。
# 链接过程
链接：编译完成的所有目标文件（Win环境下为`*.obj`文件，Linux下为`*.o`）,静态库文件（Win环境下为`*.lib`，Linux下为`*.a`）参与链接
1. 符号解析：所有`*.o`文件段(`.text`, `.data`...)进行合并。符号表（`.symtab`）进行合并后，进行符号解析。**所有对符号的引用都要找到该符号定义的地方**。符号未定义和符号重定义都会报错。
2. 符号重定位（重定向）：符号解析完成后，给所有符号分配虚拟地址。
3. **库链接**：链接器还会将需要的库函数（如标准库函数）与目标文件进行合并。库可以是静态库（在编译时将库文件打包到可执行文件中）或动态库（在运行时加载）。
4. 得到可执行文件（Win环境下为`*.exe`文件，Linux下为`*.out`文件） 
# 执行过程
- 可执行文件和目标文件都是有各种段组成的，但是可执行文件多了program headers 程序头段，程序头段有LOAD指令,告诉系统，程序运行时将**代码段**和**数据段**加载到内存中。还可能包括其他段，比如**堆栈段**和**堆段**，这些段会在程序运行时动态分配。
- 可执行文件的文件头（elf）有入口点地址，从此处开始运行程序。
- 当操作系统加载一个可执行文件时，它会为这个进程创建一个虚拟地址空间，并将可执行文件的各个段（.text, .data, .bss等）映射到这个虚拟地址空间的不同区域。
