# 问题
- 是不是虚函数的调用一定都是动态绑定？
	- 在类的构造函数当中，调用虚函数，也是静态绑定。
	- 用对象本身调用虚函数是静态绑定
	- 只有用指针（引用）调用虚函数，才会触发动态绑定。
# 代码
```cpp
Base base;     // 基类对象
Derive derive; // 派生类对象

// 用对象本身调用虚函数是静态绑定
base.show();
derive.show();

// 只有用指针(引用)调用虚函数，才会触发动态绑定
Base *p = &base; // 基类指针指向基类对象
p->show();
Base *q = &derive; // 基类指针指向派生类对象
q->show();

Base &b = base; // 基类引用指向基类对象
b.show();
Base &d = derive; // 基类引用指向派生类对象
d.show();

Derive *a = &derive; // 派生类指针指向派生类对象
a->show();
Derive &c = derive; // 派生类引用指向派生类对象
c.show();

Derive *e = (Derive *)&base; // 派生类指针指向强转为派生类指针的基类对象
e->show(); // e的虚函数指针指向base对象的虚函数表，内存上只有一个基类对象。最终还是调用Base::show()
```
