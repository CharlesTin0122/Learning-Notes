# deque双端队列容器
- 底层数据结构：是一个动态开辟的二维数组，一维数组大小从2开始，以二倍方式扩容。每次扩容后原来第二维的数组从新的第一维数组下标oldsize/2位置开始存放，上下都预留相同的空间，方便支持首尾元素添加。
- 增加元素
	- `deq.push_back(10);`从末尾添加元素$O(1)$,可能触发扩容
	- `deq.push_front(10);`从队首添加元素$O(1)$,可能触发扩容
	- `deq.insert(it, 20);`指定位置插入元素$O(n)$，导致后续元素后移，可能触发扩容
- 移除操作
	- `deq.pop_back();`从末尾删除元素$O(1)$
	- `deq.pop_front();`从队首删除元素$O(1)$
	- `deq.erase(it);`指定位置移除元素$O(n)$，导致后续元素前移
- 查询
	- iterator
- 注意事项
		- 对容器进行连续插入或移除操作（insert/erase），一定要更新迭代器，否则第一次插入或移除操作完成后会导致迭代器失效。

# list链表容器
- 底层数据结构：是一个双向的循环链表
- 增加元素

	- `list.push_front(10);`从队首添加元素$O(1)$
	- `lisst.insert(it, 20);`指定位置插入元素$O(1)$
