C++中的函数模板（Function Template）是用于创建通用函数的一种机制，允许我们编写可以处理不同数据类型的函数，而不必为每种类型分别编写一遍。函数模板提高了代码的复用性和灵活性，特别适合那些对多种类型进行类似操作的函数。是对类型的参数化。

### 函数模板的语法：
函数模板的语法在函数定义前添加了模板声明，格式如下：
```cpp
template<typename T>
返回类型 函数名(参数列表) {
    // 函数体
}
```

- `template<typename T>`：表示定义了一个模板，`T`是一个类型参数，可以被实际的数据类型替代。
- `T`：在函数中作为占位符，实际调用时会被具体的类型替换。

### 示例：
以下是一个简单的函数模板示例，用于返回两个数中的较大者：
```cpp
#include <iostream>
using namespace std;

template<typename T>
T getMax(T a, T b) {
    return (a > b) ? a : b;
}

int main() {
    int i = 10, j = 20;
    double x = 5.5, y = 3.3;
    
    cout << "Max of i and j: " << getMax(i, j) << endl;
    cout << "Max of x and y: " << getMax(x, y) << endl;
    
    return 0;
}
```

### 输出：
```
Max of i and j: 20
Max of x and y: 5.5
```

在这个例子中，`getMax`是一个模板函数，可以用于比较两种不同类型的变量（如整数和浮点数），在编译时，编译器会根据传递的实际参数类型自动生成相应类型的具体函数。

### 模板的特点：
1. **类型参数化**：通过模板参数，可以使函数适用于不同的数据类型。
2. **自动推导类型**：在调用模板函数时，编译器会根据实参自动推导出模板参数的类型，因此调用时可以省略模板参数。
   ```cpp
   getMax(10, 20);  // 编译器自动推导T为int
   getMax(5.5, 3.3);  // 编译器自动推导T为double
   ```

3. **多个类型参数**：函数模板可以有多个模板参数，用逗号分隔。
   ```cpp
   template<typename T1, typename T2>
   void func(T1 a, T2 b) {
       // 函数体
   }
   ```

4. **显式指定模板类型**：如果编译器无法推导出模板参数类型，或者需要强制指定某种类型，可以显式指定模板类型。
   ```cpp
   cout << getMax<int>(10, 20.5);  // 强制指定T为int
   ```

### 示例：多个模板参数
下面是一个具有多个模板参数的示例，进行两个不同类型数据的加法：
```cpp
#include <iostream>
using namespace std;

template<typename T1, typename T2>
auto add(T1 a, T2 b) -> decltype(a + b) {
    return a + b;
}

int main() {
    int i = 10;
    double d = 5.5;
    
    cout << "Sum of i and d: " << add(i, d) << endl;
    
    return 0;
}
```

### 输出：
```
Sum of i and d: 15.5
```

### 函数模板的优点：
1. **代码复用**：只需编写一次函数模板，就可以支持多种数据类型。
2. **类型安全**：与C语言的宏相比，模板在编译时进行类型检查，能够保证类型安全。
3. **提高效率**：函数模板的实例化是在编译时完成的，因此在运行时不会增加开销。

函数模板是C++泛型编程的重要组成部分，它通过参数化类型，使代码更加灵活和通用。
### 函数模板的特例化
#### 代码
```cpp
#include <cstring>
#include <iostream>

// 定义模板参数列表
template <typename T1, typename T2>
// 定义函数模板
bool compare(T1 a, T2 b)
{
    std::cout << "template compare" << std::endl;
    return a > b;
}
// 函数模板的特例化，提供const char* 类型的特例化版本
template <>
bool compare(const char *a, const char *b)
{
    // `return a > b;`是在比较两个字符串地址的大小，是无意义的,
    // 字符串的比较要用strcmp()函数
    std::cout << "compare<const char*>" << std::endl;
    return strcmp(a, b) > 0;
}
// 非模板函数,普通函数
bool compare(const char *a, const char *b)
{
    std::cout << "normal compare" << std::endl;
    return strcmp(a, b) > 0;
}

int main()
{
    // 在函数调用点，用用户指定的类型从函数模板实例化一个函数出来
    compare<int, int>(10, 20);
    // 函数的实参推演，可以根据用户提供的实参类型推导出模板参数的具体类型
    compare(10, 20);

    compare<int, double>(10, 20);
    compare(10, 20.5);
    // 调用非模板函数,编译器优先将函数处理为函数名，没有该函数的话，才会处理成模板函数
    compare("aaa", "bbb");
    // 调用模板特例化
    compare<const char *, const char *>("aaa", "bbb");

    return 0;
}

```
#### 要点
- 函数模板：是不进行编译的，因为不知道参数类型
- 模板的实例化：在函数调用点，用用户指定的类型从函数模板实例化一个模板函数出来
- 模板函数：是要编译的函数代码
- 模板特例化：对于某些类型来说，依赖编译器默认实例化的模板代码，代码处理逻辑是不正确的，就需要对模板进行特例化，就是特殊的实例化（不是编译器提供的而是用户提供的）。
- 函数模板是不能在一个文件中定义，在另一个文件中调用的，应该在同一个文件中定义和调用。因为函数模板是不编译的，要在函数调用点，用用户指定的类型从函数模板实例化一个模板函数出来编译。
- 所以，模板代码一般都是放置在头文件中的。然后在源文件当中直接进行包含（#include），在编译时头文件直接在原文件中展开，这样模板就能正常实例化了。
### 模板的非类型参数
#### 代码
```cpp
#include <iostream>

// 模板的非类型参数, 是常量，只读不写
template <typename T, int SIZE>
void sort(T *arr)
{
    for (int i = 0; i < SIZE - 1; ++i)
    {
        for (int j = 0; j < SIZE - 1 - i; ++j)
        {
            if (arr[j] > arr[j + 1])
            {
                T tmp = arr[j]; // 使用T类型来保证通用性
                arr[j] = arr[j + 1];
                arr[j + 1] = tmp;
            }
        }
    }
}

int main()
{
    int arr[] = {12, 2, 36, 14, 58, 47, 19, 5, 87};
    const int size = sizeof(arr) / sizeof(arr[0]);
    sort<int, size>(arr); // 模板非类型参数需要在编译期确定大小

    for (const int val : arr)
    {
        std::cout << val << " ";
    }
    std::cout << std::endl;

    return 0;
}

```
#### 要点
- 模板声明 `template <typename T, int SIZE>`
	- 这是模板函数的声明。`typename T` 表示模板可以接受任意类型 `T`，而 `int SIZE` 是一个**非类型模板参数**，意味着它在编译期必须是一个常量（这里表示数组的大小）。
	- 模板的非类型参数在编译时是固定的，比如在后面调用 `sort<int, size>(arr)` 时，`size` 必须在编译期确定（这里使用了 `const int size`）。
- 函数调用 `sort<int, size>(arr)`
	- `sort<int, size>(arr)`：调用模板函数 `sort`，模板类型参数 `T` 被推断为 `int`，非类型参数 `SIZE` 被设定为 `size`（数组大小）。
