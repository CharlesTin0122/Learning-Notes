C++中的函数重载（Function Overloading）是指在同一个作用域内，允许多个函数同名但参数不同，从而根据调用时提供的参数类型或数量，自动选择合适的函数版本来执行。函数重载是C++的一项重要特性，它通过允许函数名称重复使用，提高了代码的可读性和灵活性。

### 函数重载的规则：
1. **参数个数不同**：函数的参数个数可以不同。
   ```cpp
   void print(int i);
   void print(int i, int j);
   ```

2. **参数类型不同**：函数的参数类型可以不同。
   ```cpp
   void print(int i);
   void print(double d);
   ```

3. **参数顺序不同**：如果参数的类型不同，参数的顺序也可以不同。
   ```cpp
   void display(int i, double d);
   void display(double d, int i);
   ```

### 注意：
- **返回类型不同不构成重载**：仅仅通过返回类型的不同无法实现函数重载。
  ```cpp
  int func();
  double func();  // 错误：返回类型不同不算重载
  ```

- **参数的默认值要小心**：使用函数重载时，如果一个函数的参数有默认值，可能会导致二义性问题。
  ```cpp
  void func(int x, int y = 10);
  void func(int x);  // 调用func(5)时，会产生二义性错误
  ```

### 示例：
以下是一个简单的函数重载的示例：
```cpp
#include <iostream>
using namespace std;

void display(int i) {
    cout << "Integer: " << i << endl;
}

void display(double d) {
    cout << "Double: " << d << endl;
}

void display(int i, double d) {
    cout << "Integer and Double: " << i << ", " << d << endl;
}

int main() {
    display(10);           // 调用 display(int)
    display(5.5);          // 调用 display(double)
    display(10, 5.5);      // 调用 display(int, double)
    return 0;
}
```

### 输出：
```
Integer: 10
Double: 5.5
Integer and Double: 10, 5.5
```

通过函数重载，可以根据不同的参数来执行不同的代码逻辑，从而提高程序的灵活性和可维护性。
### 问题
- 为什么C++支持函数重载，而C语言不支持函数重载
	- C++代码在编译生成函数符号时，函数符号由**函数名**和**参数类型**组成：`compare_int_int`
	- C语言代码在编译生成函数符号时，函数符号只有**函数名**组成：`compare`
- 函数重载需要注意什么
	- 函数重载要处在同一个作用域下，处在不同的作用域下是不构成函数重载的。会优先调用处在同一作用域下的函数。
	- 函数的参数被const和volatile关键字修饰时，不构成函数重载。
	```cpp
	//属于函数重定义，不属于函数重载，int 和 const int 都是 int 类型
	void func(int a){};
	void func(const int a){};
	```
	- 一组函数函数名相同，参数类型相同，返回值类型不同，不属于函数重载。
- C与C++语言之间如何互相调用，请看如下代码
```c
//test.c

int sum(int a, int b)//生成符号为：sum，放置在.text 代码段
{
	return a + b;
}
```

```cpp
//main.cpp

int sum(int a, int b);//生成符号为：sum_int_int，因为是符号的引用，所以是"UND",undefine.
int main()
{
	int ret = sum(10, 20);
	std::cout << ret << std::endl;

	return 0;
}
```

- C++代码在编译生成函数符号时，函数符号由**函数名**和**参数类型**组成：`sum_int_int`
- C语言代码在编译生成函数符号时，函数符号只有**函数名**组成：`sum`
- 所以C++调用C代码会导致找不到C语言的函数符号
- 解决办法是使用extern关键字，如下
```c
//test.c

int sum(int a, int b)//生成符号为：sum，放置在.text 代码段
{
	return a + b;
}
```

```cpp
//main.cpp

ectern "C"
{
	int sum(int a, int b);//生成符号为：sum_int_int，因为是符号的引用，所以是"UND",undefine.
}

int main()
{
	int ret = sum(10, 20);
	std::cout << ret << std::endl;

	return 0;
}
```
- 反之，C语言要调用C++代码，如下
```c
//test.cpp

extern "C"
{
	int sum(int a, int b)//生成符号为：sum，放置在.text 代码段
	{
		return a + b;
	}
}
```

```cpp
//main.c

int sum(int a, int b);//生成符号为：sum_int_int，因为是符号的引用，所以是"UND",undefine.

int main()
{
	int ret = sum(10, 20);
	std::cout << ret << std::endl;

	return 0;
}
```
- 可以通过 `__cplusplus`宏，是一个在C++语言中预定义的宏，用于标识当前编译器支持的C++标准版本。这个宏的值会随着C++标准的演变而更新，通常用于编写与不同C++标准兼容的代码。
```cpp
#include <iostream>

int main() {
    #if __cplusplus >= 202002L
        std::cout << "Compiled with C++20 or later\n";
    #elif __cplusplus >= 201703L
        std::cout << "Compiled with C++17\n";
    #elif __cplusplus >= 201402L
        std::cout << "Compiled with C++14\n";
    #elif __cplusplus >= 201103L
        std::cout << "Compiled with C++11\n";
    #else
        std::cout << "Compiled with an older C++ version\n";
    #endif
    return 0;
}

```
- 也可以用来判断是否在C++环境
```cpp
#ifdef __cplusplus
extern "C"
{
#endif
    int sum(int a, int b) // 生成符号为：sum，放置在.text 代码段
    {
        return a + b;
    }

#ifdef __cplusplus
}
#endif
```
- 如果在C++环境下，则会执行`extern "C"{}`
- 如果在C环境下，不执行`extern "C"{}`，直接执行`sum`函数
- 这样，无论在C环境还是C++环境下都可以调用`sum`函数
