# 引子
```cpp
// 基类/父类，类A派生了类B
class A
{
public:
    int ma;

protected:
    int mb;

private:
    int mc;
};

// 派生类/子类，类B继承自类A
class B : public A
{
public:
    int md;
    int ma;

protected:
    int me;

private:
    int mf;
};
```

# 继承的意义
- 代码的复用
- 在基类中提供统一的虚函数接口，让派生类重写，实现多态。
# 继承的访问权限
- 基类成员的访问限定，在派生类里是不可能超过继承方式的。
- 友元可以访问所有的成员变量
- public成员：自身，派生类和外部都可访问。
- protected成员：只有自身，派生类可以访问，外部不可访问。
- private成员：只有自身可以访问，派生类和外部不可访问。

| 继承方式      | 基类的访问权限   | 派生类的访问权限  | 外部访问权限 |
| --------- | --------- | --------- | ------ |
| public    | public    | public    | Yes    |
|           | protected | protected | No     |
|           | private   | 不可见       | No     |
| protected | public    | protected | No     |
|           | protected | protected | No     |
|           | private   | 不可见       | No     |
| private   | public    | private   | No     |
|           | protected | private   | No     |
|           | private   | 不可见       | No     |
- 外部只能访问对象的public成员，其他成员无法访问。
- 在继承结构中，派生类可以从基类继承private成员，但是无法直接访问。
- 在基类中定义的成员，想被派生类访问，但是不想被外部访问，那么在基类中将相关成员定义为protected成员。
- 在基类中定义的成员，想要派生类和外部都无法访问，那么在基类中将相关成员定义为private成员。
# 默认继承方式
- 如果派生类没有写访问限定符，那么要判断派生类是用class定义的还是struct定义的
	- class定义派生类：默认继承方式是private
	- struct定义派生类，默认继承方式是public
