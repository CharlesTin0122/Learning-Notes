在C++中，函数对象（Function Object）是指重载了`operator()`的类实例。它可以像普通函数一样被调用，通常用于提供更灵活的功能和更高的效率。也叫做仿函数。
### 函数对象的特点

1. **可调用性**：函数对象可以像函数一样被调用，通过重载`operator()`实现。
2. **状态保持**：函数对象可以包含状态（成员变量），允许在调用时存储信息。
3. **高效性**：由于函数对象在编译时就能确定类型，可以优化性能，避免函数指针的开销。

### 示例
下面是一个简单的函数对象的例子：
```cpp
#include <iostream>

// 定义一个函数对象
class Adder {
public:
    Adder(int toAdd) : value(toAdd) {}

    // 重载 operator()
    int operator()(int x) const {
        return x + value;
    }

private:
    int value; // 存储要加的值
};

int main() {
    Adder addFive(5); // 创建一个函数对象，添加5
    std::cout << addFive(10) << std::endl; // 输出 15
    return 0;
}
```
# 函数指针和函数对象的区别

## 使用函数指针进行比较操作
```cpp
#include <iostream>

// 使用函数指针进行比较操作

// 比较函数
template <typename T>
bool myGreater(T a, T b)
{
    return a > b;
}

template <typename T>
bool myLess(T a, T b)
{
    return a < b;
}
// Compare 是一个非类型模板参数，表示一个可调用对象的类型（如函数指针、函数对象或 lambda 表达式）。
// 这个参数使得 compare函数能够接受任何可以进行比较的函数或函数对象。
template <typename T, typename Compare>
bool compare(T a, T b, Compare comp)
{
    // 通过函数指针调用函数，是没有办法内联的，因为编译阶段无法知道调用的是哪个函数，运行的时候才知道。效率很低，因为有函数调用开销
    return comp(a, b);
}

// 主函数
int main()
{
    std::cout << compare(10, 20, myGreater<int>) << std::endl;
    std::cout << compare(10, 20, myLess<int>) << std::endl;
}
```
* 通过函数指针调用函数，是没有办法内联的，因为编译阶段无法知道调用的是哪个函数，运行的时候才知道。效率很低，因为有函数调用开销。所以要使用函数对象。
## 使用函数对象进行比较操作
```cpp
#include <iostream>

// 使用函数对象进行比较操作

// 函数对象
template <typename T>
class myGreater
{
public:
    bool operator()(T a, T b) { return a > b; }
};

template <typename T>
class myLess
{
public:
    bool operator()(T a, T b) { return a < b; }
};
// Compare 是一个非类型模板参数，表示一个可调用对象的类型（如函数指针、函数对象或 lambda 表达式）。
// 这个参数使得 compare函数能够接受任何可以进行比较的函数或函数对象。
template <typename T, typename Compare>
bool compare(T a, T b, Compare comp)
{
    // 通过函数对象调用operator()函数，是完全可以内联的，可以省略函数的调用开销，效率较高。
    // 因为函数对象是用类生成的，可以添加相关的成员变量，用来记录函数对象使用时更多的信息。
    return comp(a, b);
}

// 主函数
int main()
{
    std::cout << compare(10, 20, myGreater<int>()) << std::endl;
    std::cout << compare(10, 20, myLess<int>()) << std::endl;
}
```

- 通过函数对象调用operator()函数，是完全可以内联的，可以省略函数的调用开销，效率较高。
- 因为函数对象是用类生成的，可以添加相关的成员变量，用来记录函数对象使用时更多的信息。
# 函数对象的应用
## priority_queue优先级队列
```cpp
#include <cstdlib>
#include <iostream>
#include <queue>
#include <vector>

// 主函数
int main()
{
    // 优先级队列对层是一个vector容器构建的大根堆

    std::priority_queue<int> que1;
    for (int i = 0; i < 10; ++i)
    {
        que1.push(rand() % 100 + 1);
    }

    while (!que1.empty())
    {
        std::cout << que1.top() << " ";
        que1.pop();
    }
    std::cout << std::endl;

    // 实现小根堆

    std::priority_queue<int, std::vector<int>, std::greater<int>> que2;
    for (int i = 0; i < 10; ++i)
    {
        que2.push(rand() % 100 + 1);
    }

    while (!que2.empty())
    {
        std::cout << que2.top() << " ";
        que2.pop();
    }
    std::cout << std::endl;

    return 0;
}
```

# 应用场景

- **算法**：STL算法（如`std::sort`）常常使用函数对象作为比较器。
- **自定义行为**：可以为算法或数据结构提供自定义的处理逻辑。
# 总结

函数对象是C++中强大而灵活的工具，结合了函数的调用特性与类的封装特性，适用于多种编程场景，尤其是在需要传递可调用对象的情况下。
