# 容器适配器
- 适配器底层没有自己的数据结构，他是另外一个容器的封装，他的方法全部由底层依赖的容器实现的。
- 容器适配器没有实现自己的迭代器
# stack
- 特点：先入后出
- 底层数据结构：deque
- 方法：
	- push, pop, top, size, empty
```cpp
    // 创建容器，有效元素数量为0
    std::stack<int> s1;

    // 入栈
    for (int i = 0; i < 20; i++)
    {
        s1.push(rand() % 100 + 1);
    }
    std::cout << s1.size() << std::endl;
    // 循环打印，出栈
    while (!s1.empty())
    {
        std::cout << s1.top() << " ";
        s1.pop();
    }
    std::cout << std::endl;
```
# queue
- 特点：先入先出
- 底层数据结构：deque
- 方法：
	- push, pop, front, size, empty
```cpp
    // 创建容器，有效元素数量为0
    std::queue<int> que;

    // 入队
    for (int i = 0; i < 20; i++)
    {
        que.push(rand() % 100 + 1);
    }
    std::cout << que.size() << std::endl;
    // 循环打印，出队
    while (!que.empty())
    {
        std::cout << que.front() << " ";
        que.pop();
    }
    std::cout << std::endl;
```
# priority_queue
- 特点：大根堆
- 底层数据结构：vector
- 方法：
	- push, pop, top, size, empty
```cpp
    // 创建容器，有效元素数量为0
    std::priority_queue<int> pQue;

    // 入队
    for (int i = 0; i < 20; i++)
    {
        pQue.push(rand() % 100 + 1);
    }
    std::cout << pQue.size() << std::endl;
    // 循环打印，出队
    while (!pQue.empty())
    {
        std::cout << pQue.top() << " ";
        pQue.pop();
    }
    std::cout << std::endl;
```
# 问题
- 为什么stack和queue底层依赖的是deque，而priority_queue底层数据结构依赖的却是vector？
	- vector的初始内存使用效率太低了，需要频繁扩容。而deque初始化缓冲区就有4096/sizeof(T)个空间。
	- 对于queue来说需要支持尾部插入和头部删除操作。deque是最佳选择。如果使用vector，其出队效率很低。
	- vector需要大片的连续内存，而deque只需要分段的小片内存。当存储大量数据是，显然deque对于内存的利用率更好一些。
	- priority_queue的底层数据是一个大根堆结构。大根堆结构的节点关系需要通过索引来计算，需要大量的索引查询操作。
