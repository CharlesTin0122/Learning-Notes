C++ STL ：Standard Template Library 标准模板库
# 标准容器
## 顺序容器
- Vector：向量容器
- deque：双端队列容器
- list：链表容器
## 容器适配器
- stack：栈
- Queue：队列
- priority_queue：优先级队列，底层是大根堆
## 关联容器
### 无序关联容器
底层是链式哈希表，增删查近$O(1)$
- unordered_set：无序集合
- unordered_multiset：无序多重集合
- unordered_map：无序映射
- unordered_multimap：无序多重映射
### 有序关联容器
底层是红黑树实现，增删查$O(log_2^n)$
- set：集合
- multiset：多重集合
- map：映射
- multimap：多重映射
# 近容器
- array：数组
- string：字符串
- bitset：位容器
# 迭代器
- iterator和const_iterator
- reverse_iterator和const_reverse_iterator
# 函数对象
- greater
- less

- sort
