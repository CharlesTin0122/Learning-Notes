# 运算符重载
- 意义：使对象的运算表现的和编译器内置类型一样。
- 举例：
```cpp
template <typename T>
T sum(T a, T b)
{
	return a + b;
}
```
- 在上述代码中，如果a， b传入的实参为自定义类型，那么编译器就无法将自定义类型相加。那么就用到了运算符重载，让编译器知道如何将自定义类型相加。
- 表达式`a + b`本质上就是对象a调用加法函数，将对象b作为实参传入加法函数，返回得到结果。`a.operator+(b);`
# 复数类案例
```cpp
#include <iostream>
#include <ostream>

class Complex
{
public:
    Complex(int r = 0, int i = 0) : _real(r), _image(i) {}
    // 加法运算符重载，指导编译器怎么做complex类对象的加法操作
    // 不能返回引用，因为函数内的局部变量在函数结束后会被释放
    Complex operator+(const Complex &other)
    {
        return Complex(this->_real + other._real, this->_image + other._image);
    }
    void show() { std::cout << _real << " + " << _image << 'i' << std::endl; }
    // 前置自增运算符重载，因为*this在函数结束后仍然存在，所以返回值是引用
    Complex &operator++()
    {
        // 先自增再返回
        _real += 1;
        return *this;
    }
    // 后置自增运算符重载，comp在函数结束后被释放，所以返回值不能是引用
    Complex operator++(int)
    {
        // 返回自身，再自增
        // Complex comp = *this;
        // _real += 1;
        // return comp;
        // 对象优化,返回一个临时对象，构造参数是_real和_image.然后_real自增
        return Complex(_real++, _image);
    }
    // 复合赋值运算符重载
    void operator+=(const Complex &other)
    {
        _real += other._real;
        _image += other._image;
    }

private:
    int _real;
    int _image;
    // 友元函数，用于全局函数调用对象的私有属性
    friend Complex operator+(const Complex &lhs, const Complex &rhs);
    friend std::ostream &operator<<(std::ostream &out, const Complex &comp);
    friend std::istream &operator>>(std::istream &in, Complex &comp);
};
// 全局加法运算符重载函数
Complex operator+(const Complex &lhs, const Complex &rhs)
{
    return Complex(lhs._real + rhs._real, lhs._image + rhs._image);
}
/*
 * 输出运算符重载，因为对象在右侧，只能提供全局方法
 * ostream &operator<<(operator &out, const Complex &comp)
 * 因为需要连续输出cout << X << endl，所以返回值为cout也就是ostream类型
 * 流iostream是不断变化的，不能用const修饰
 */
std::ostream &operator<<(std::ostream &out, const Complex &comp)
{
    // 先输出，再返回输出流out
    out << comp._real << " + " << comp._image << 'i' << std::endl;
    return out;
}
// 输入运算符重载
std::istream &operator>>(std::istream &in, Complex &comp)
{
    // 先输入实部，再输入虚部，然后返回输入流in
    in >> comp._real >> comp._image;
    return in;
}
int main()
{
    Complex comp1(10, 10);
    Complex comp2(20, 20);
    // 编译器试图寻找对象comp1有没有operator+(comp2)方法,试图将comp2对象作为实参传入
    Complex comp3 = comp1 + comp2;
    comp3.show();
    /*
    comp1调用operator+(15)方法，会做一个类型强转，将数值15转化为一个Complex类型。
    将15作为实参传入构造函数中构造一个临时对象，
    替代r形参Complex(int r = 15, int i = 0)构造对象，然后相加
    */
    Complex comp4 = comp1 + 15;
    comp4.show();
    /*
     * 数值30是一个int类型，int类型的operator+无法调用comp2对象作为实参
     * 编译器做对象运算的时候，会调用对象的运算符重载函数（优先调用成员方法）；
     * 如果没有成员运算符重载方法的话，就在全局作用域找合适的运算符重载函数。
     * 我们可以在全局编写一个运算符重载函数::operator+(30, comp1)
     * 在调用全局运算符重载函数时，编译器会将30强转为Complex类型，
     * 调用构造函数Complex(int r = 30, int i = 0)，构造临时对象
     */
    Complex comp5 = 30 + comp2;
    comp5.show();

    /*
     * ++，--单目运算符重载，
     * operator++()是前置++运算符重载++a，operator++(int)是后置++运算符重载a++
     */
    // 先赋值再自增
    comp5 = comp1++;
    comp1.show();
    comp5.show();
    // 先自增再赋值
    comp5 = ++comp1;
    comp1.show();
    comp5.show();
    // 复合赋值运算符,comp1.operator+=(comp2)
    comp1 += comp2;
    comp1.show();

    // 输出运算符
    std::cout << comp1 << std::endl;
    // 输入运算符
    std::cin >> comp1 >> comp2;
    std::cout << comp1 << comp2 << std::endl;
    return 0;
}
```
