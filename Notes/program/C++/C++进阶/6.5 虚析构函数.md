### 虚析构函数

在C++中，**虚析构函数**是用来确保在删除通过基类指针指向派生类对象时，派生类的析构函数被正确调用的重要机制。这对于实现安全的动态内存管理和避免资源泄漏至关重要。

#### 1. 为什么需要虚析构函数？

当你通过基类指针删除一个派生类对象时，如果基类的析构函数不是虚函数，将只会调用基类的析构函数。这意味着派生类的析构函数不会被调用，从而可能导致资源泄漏，例如内存未释放或打开的文件未关闭。

#### 2. 如何定义虚析构函数？

要定义虚析构函数，只需在基类的析构函数前加上`virtual`关键字。这样，删除基类指针时，C++会首先调用派生类的析构函数，然后再调用基类的析构函数。

#### 3. 示例代码

下面是一个简单的示例，演示如何使用虚析构函数：

```cpp
#include <iostream>

class Base {
public:
    // 定义虚析构函数
    virtual ~Base() {
        std::cout << "Base destructor called." << std::endl;
    }
};

class Derived : public Base {
public:
    ~Derived() override { // 重写派生类析构函数
        std::cout << "Derived destructor called." << std::endl;
    }
};

int main() {
    Base* b = new Derived(); // 创建派生类对象
    delete b;               // 通过基类指针删除对象
    return 0;
}
```

#### 4. 输出结果

在上述代码中，输出将是：
```
Derived destructor called.
Base destructor called.
```
这表明：
- 当通过基类指针`b`删除`Derived`对象时，首先调用`Derived`的析构函数，之后再调用`Base`的析构函数。

#### 5. 关键点

- **安全性**：使用虚析构函数可以防止资源泄漏，确保在删除基类指针时正确释放派生类的资源。
- **多态性**：虚析构函数与虚函数类似，确保在运行时能够正确确定调用哪个析构函数。

### 小结

虚析构函数是面向对象编程中至关重要的特性，特别是在涉及动态内存管理和多态性的情况下。通过确保在基类指针删除派生类对象时调用正确的析构函数，虚析构函数有效地维护了资源的正确管理。
# 问题
- 哪些函数不能实现成虚函数？
	- 对象中存储了虚函数指针vfptr，虚函数指针指向虚函数表vftable，虚函数表中储存了虚函数地址。因此
		- 虚函数可以产生地址，存储在vftable当中。
		- 对象必须存在。
	- 构造函数不能实现成虚函数，而且构造函数中调用任何函数都是静态绑定。就算调用虚函数，也不会发生动态绑定。
		- 因为派生对象构造过程中，先调用基类构造函数，再调用派生类构造函数。因为在调用基类构造函数之前不能调用派生类构造函数，所以构造函数不能实现成虚函数。
	- static静态方法不能实现成虚函数。因为静态方法调用根本就不依赖对象。虚函数指针vfptr都没地方放。
	- 析构函数可以实现成虚函数。因为析构函数调用时对象是存在的。
		- 当基类指针（引用）指向堆上开辟出来的派生类对象的时候，它调用析构的时候必须发生动态绑定，必须使用虚析构。否则会导致派生类的析构函数无法调用。
