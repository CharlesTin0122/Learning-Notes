在C++中，**抽象类**是一种不能实例化的类，通常用于作为基类，定义接口和规范供派生类实现。抽象类主要通过包含至少一个**纯虚函数**来实现。

#### 1. 纯虚函数
纯虚函数是指在基类中声明但不提供实现的虚函数。它的声明形式是在函数后面加上`= 0`，表示该函数是一个接口，必须在派生类中实现。

#### 2. 抽象类的定义
抽象类可以包含：
- 纯虚函数
- 虚函数（可以提供实现）
- 普通成员函数和数据成员

任何包含至少一个纯虚函数的类都被认为是抽象类。

#### 3. 示例代码

以下是一个示例，展示如何定义和使用抽象类：

```cpp
#include <iostream>

// 抽象类
class Shape {
public:
    // 纯虚函数
    virtual void draw() = 0; // 定义接口

    // 普通成员函数
    void describe() {
        std::cout << "This is a shape." << std::endl;
    }
};

// 派生类实现纯虚函数
class Circle : public Shape {
public:
    void draw() override { // 必须实现
        std::cout << "Drawing a circle." << std::endl;
    }
};

// 另一个派生类
class Square : public Shape {
public:
    void draw() override { // 必须实现
        std::cout << "Drawing a square." << std::endl;
    }
};

int main() {
    // Shape s; // 错误：无法实例化抽象类

    Shape* shape1 = new Circle(); // 创建Circle对象
    shape1->describe();            // 调用普通成员函数
    shape1->draw();                // 调用纯虚函数

    Shape* shape2 = new Square();  // 创建Square对象
    shape2->describe();            // 调用普通成员函数
    shape2->draw();                // 调用纯虚函数

    delete shape1; // 释放内存
    delete shape2; // 释放内存

    return 0;
}
```

#### 4. 输出结果

在上述代码中，输出将是：
```
This is a shape.
Drawing a circle.
This is a shape.
Drawing a square.
```

#### 5. 抽象类的特性
- **不能实例化**：抽象类无法被直接创建对象。但是可以定义指针和引用变量。
- **多态性**：抽象类提供了一种接口，可以实现运行时多态。
- **代码复用**：可以在抽象类中定义通用的功能，派生类可以共享和扩展这些功能。

### 小结

抽象类是C++中实现接口和多态的重要工具。通过定义抽象类，开发者可以建立清晰的接口规范，使得派生类在实现时具有一致性。这种设计模式有助于提高代码的可维护性和扩展性。

```cpp
#include <iostream>
#include <string>

// 抽象类
class Car
{
public:
    Car(std::string name, double oil) : _name(name), _oil(oil) {}
    // 获取剩余油量还能行驶公里数
    double getLeftMiles()
    {
        // 调用纯虚函数，实现动态绑定
        return _oil * getMilesPerGallon();
    }
    std::string getName() const { return _name; }

protected:
    std::string _name;
    double _oil;
    // 纯虚函数，每加仑油跑多远
    virtual double getMilesPerGallon() = 0;
};
// 派生类
class Benze : public Car
{
public:
    Benze(std::string name, double oil) : Car(name, oil) {}
    double getMilesPerGallon() override { return 20.6; }
};
class Audi : public Car
{
public:
    Audi(std::string name, double oil) : Car(name, oil) {}
    double getMilesPerGallon() override { return 17.3; }
};
class BMW : public Car
{
public:
    BMW(std::string name, double oil) : Car(name, oil) {}
    double getMilesPerGallon() override { return 19.5; }
};
// 统一接口API，获取汽车剩余续航里程

void showCarLeftMiles(Car &car) { std::cout << car.getName() << " : " << car.getLeftMiles() << std::endl; }

int main()
{
    Benze benze("benchi", 20.6);
    Audi audi("aodi", 38.7);
    BMW bmw("baoma", 27.3);
    showCarLeftMiles(benze);
    showCarLeftMiles(audi);
    showCarLeftMiles(bmw);
}
```
