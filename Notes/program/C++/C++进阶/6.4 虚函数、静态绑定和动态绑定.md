在C++中，虚函数、静态绑定和动态绑定是面向对象编程的重要概念。以下是它们的详细介绍：

### 1. 虚函数
虚函数是一个在基类中声明为`virtual`的成员函数。它允许派生类重写基类的函数。当通过基类指针或引用调用该函数时，将执行派生类中重写的版本。

#### 例子：
```cpp
class Base {
public:
    virtual void show() {
        std::cout << "Base class show function." << std::endl;
    }
};

class Derived : public Base {
public:
    void show() override { // 使用 override 可以增强可读性
        std::cout << "Derived class show function." << std::endl;
    }
};

void demonstrate(Base* b) {
    b->show(); // 动态绑定
}

int main() {
    Base b;
    Derived d;
    demonstrate(&b); // 输出：Base class show function.
    demonstrate(&d); // 输出：Derived class show function.
    return 0;
}
```

### 2. 静态绑定
静态绑定是在编译时确定函数调用的版本。在没有虚函数的情况下，基于对象的类型来决定调用哪个函数。

#### 例子：
```cpp
class Example {
public:
    void show() {
        std::cout << "Static binding." << std::endl;
    }
};

int main() {
    Example e;
    e.show(); // 静态绑定，编译时确定
    return 0;
}
```

### 3. 动态绑定
动态绑定是在运行时确定函数调用的版本。它通过虚函数实现，允许程序在运行时根据对象的实际类型来选择正确的函数。

#### 动态绑定的工作原理：
- 当一个对象被创建时，C++会为它生成一个虚函数表（vtable），其中包含该对象可以调用的虚函数的地址。
- 通过基类指针调用虚函数时，C++会查找相应的vtable来找到实际的函数地址。

### 小结
- **虚函数**：实现动态绑定的机制，允许子类重写基类函数。
- **静态绑定**：编译时确定调用的函数，速度快但灵活性差。
- **动态绑定**：运行时确定调用的函数，更灵活但稍慢。

这些概念使得C++能够实现多态性，增强了程序的灵活性和可扩展性。
# 案例
```cpp
#include <iostream>
#include <typeinfo>
// 基类/父类
class Base
{
public:
    Base(int val = 10) : ma(val) {}
    // 基类方法，虚函数
    virtual void show() { std::cout << "Base::show()" << std::endl; }
    void show(int) { std::cout << "Base::show(int)" << std::endl; }

protected:
    int ma;
};

// 派生类/子类，类B继承自类A
class Derive : public Base
{
public:
    // Base(val)调用基类构造函数进行初始化，ma(val);
    Derive(int val = 20) : Base(val), mb(val) {}
    // 派生类方法
    void show() { std::cout << "Derive::show()" << std::endl; }

private:
    int mb;
};

int main()
{
    Derive derive(50); // 派生类对象
    Base *p = &derive; // 基类指针指向派生类对象

    /*通过指针p调用基类show方法,发现该方法不是虚函数，就进行静态绑定，
     *编译阶段就已确定好的函数调用，是一个静态绑定。静态（编译时期）绑定（函数的调用）。
     *通过指针p调用基类show方法,发现该方法是一个虚函数，就进行动态绑定，
     *运行时期的绑定叫做动态（运行时期）绑定（函数的调用）
     */
    p->show();   // 动态绑定
    p->show(10); // 静态绑定
    // p的类型是Base*指针
    std::cout << typeid(p).name() << std::endl; // class Base*
    /* 判断*p的类型要看基类有没有虚函数
     * 如果基类Base没有虚函数，*p就是编译时期的类型Base类型
     * 如果基类Base有虚函数，*p就是运行时期的类型，即派生类虚函数表中RTTI指针指向的类型，Derive类型。
     * p指向的是派生类对象derive，derive的前四字节为vfptr，指向的是派生类的vftable的RTTI指针，指向的是Derive类型
     */
    std::cout << typeid(*p).name() << std::endl; // class Derive

    return 0;
}
```
## 要点
## 虚函数表
- 如果类内定义了虚函数，那么编译阶段，编译器会给这个类类型产生一个唯一的vftable虚函数表。
- 虚函数表中主要存储的内容就是RTTI指针和虚函数地址。
- RTTI指针：runtime type information，运行时的类型信息，记录该类类型。
- 当程序运行时，每一张虚函数表都会加载到内存的`.rodata`只读数据区。
## 虚函数指针
- 一个类定义了虚函数，那么这个类定义的对象，其运行时内存中开始部分多存储一个vfptr虚函数指针，指向相应类型的虚函数表vftable。
- 一个类型定义多个对象，他们的vfptr指向的都是同一张vftable。
- 一个类里面的虚函数个数，不影响对象的内存大小（vfptr只有一个），影响的是虚函数表的大小。
## 派生类
- 如果派生类中的方法和基类继承来的方法，返回值、函数名和参数列表都相同，并且基类的方法是虚函数。那么派生类的这个方法，自动处理成虚函数。派生类的同名方法将在自身的虚函数表中覆盖基类的同名方法，他们之间是覆盖的关系。
