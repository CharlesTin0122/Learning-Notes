# 拷贝构造函数
在C++中，**拷贝构造函数**（Copy Constructor）用于创建一个新的对象，并用另一个同类型的对象来初始化这个新对象。它的主要作用是复制对象的成员数据，从而构建一个与现有对象相似的副本。

### 1. 拷贝构造函数的定义
拷贝构造函数是一种特殊的构造函数，函数原型如下：

```cpp
ClassName(const ClassName &obj);
```

其中，`ClassName`是类名，参数`obj`是引用类型的对象，通常传递为`const`以防止修改传入的对象。

### 2. 拷贝构造函数的默认行为
如果用户没有显式定义拷贝构造函数，编译器会自动生成一个**默认拷贝构造函数**。这个默认的拷贝构造函数执行的是**浅拷贝**，即逐个成员变量进行简单的复制操作。对于内置类型成员，复制的是值，而对于指针等复杂类型成员，复制的是地址。

### 3. 自定义拷贝构造函数
对于类中包含指针、动态内存等需要特殊管理的资源时，默认的浅拷贝可能会引发问题，如双重释放或悬空指针。此时，需要编写自定义的拷贝构造函数，实现**深拷贝**，即为每个动态分配的资源创建新的副本。

#### 自定义拷贝构造函数的例子：
```cpp
#include <iostream>

class Example {
public:
    int* ptr;

    // 普通构造函数
    Example(int val) {
        ptr = new int(val);  // 动态分配内存
        std::cout << "普通构造函数调用" << std::endl;
    }

    // 自定义拷贝构造函数（深拷贝）
    Example(const Example &obj) {
        ptr = new int(*obj.ptr);  // 为指针分配新的内存，并复制内容
        std::cout << "拷贝构造函数调用" << std::endl;
    }

    ~Example() {
        delete ptr;  // 释放动态内存
        std::cout << "析构函数调用" << std::endl;
    }
};

int main() {
    Example obj1(10);      // 调用普通构造函数
    Example obj2 = obj1;    // 调用拷贝构造函数
    std::cout << "obj1.ptr = " << *obj1.ptr << std::endl;
    std::cout << "obj2.ptr = " << *obj2.ptr << std::endl;
    return 0;
}
```

在上面的例子中，自定义的拷贝构造函数通过为`ptr`指针分配新的内存空间，确保深拷贝行为。输出结果如下：
```
普通构造函数调用
拷贝构造函数调用
obj1.ptr = 10
obj2.ptr = 10
析构函数调用
析构函数调用
```

可以看到，`obj1`和`obj2`各自有独立的内存空间，深拷贝确保两个对象之间不会产生干扰。

### 4. 拷贝构造函数的调用场景
拷贝构造函数在以下几种情况下会自动调用：
1. **通过一个对象初始化另一个对象**：
   ```cpp
   Example obj2 = obj1;  // 这里调用了拷贝构造函数
   ```
2. **将对象作为函数参数按值传递**：
   ```cpp
   void func(Example obj);  // 传递时会调用拷贝构造函数
   ```
3. **函数按值返回对象**：
   ```cpp
   Example func() {
       Example obj(10);
       return obj;  // 返回时调用拷贝构造函数
   }
   ```

### 5. 拷贝构造函数与赋值运算符的区别
- **拷贝构造函数**：用于创建新的对象，并用现有对象进行初始化。它在对象的生命周期开始时调用。
- **赋值运算符**：用于将一个已存在的对象赋值给另一个已存在的对象，发生在对象已经初始化之后。
### 6.拷贝构造函数拷贝数据时尽量使用for循环赋值，而不是`memcpy`和`realloc`。
- **for 循环逐个赋值**：适用于 **任意类型的对象**，包括自定义类型的对象。这是因为在 C++ 中，对象通常有构造函数、析构函数、赋值操作符等。当进行拷贝时，每个对象的拷贝行为是通过其拷贝构造函数或赋值操作符来完成的。通过 `for` 循环逐个调用拷贝构造函数，可以确保每个对象被正确构造和初始化。
- **`memcpy`**：`memcpy` 是一种 **低级别** 的字节拷贝操作，它只会按字节复制内存，而不会调用对象的构造函数、析构函数或其他相关的操作符。因此，`memcpy` 只适用于 **简单的 POD 类型**（Plain Old Data，纯旧数据类型），比如基本数据类型（如 `int`、`float`）和简单的结构体。如果对非 POD 类型的对象使用 `memcpy`，会跳过其拷贝构造函数，导致资源管理错误（如内存泄漏或双重释放）。
- **`realloc`**：`realloc` 是 C 标准库中的函数，用于重新分配内存。它也仅适用于简单的内存块操作。和 `memcpy` 一样，`realloc` 不会调用对象的构造函数或析构函数，因此也只适用于 POD 类型，且一般用于动态分配内存的情况，而不是对象的拷贝。
### 总结：
- **拷贝构造函数**用于在创建对象时，将一个对象的值复制到新对象。
- 如果类中有指针或动态分配的资源，通常需要定义自定义的拷贝构造函数以避免浅拷贝带来的问题（如内存泄漏和双重释放）。
- C++默认会生成浅拷贝的拷贝构造函数，但在需要深拷贝的场景下需要手动编写。
# 浅拷贝与深拷贝
在C++中，浅拷贝（Shallow Copy）和深拷贝（Deep Copy）是两种不同的对象复制方式，主要区别在于对指针或动态内存等资源的处理。

### 1. 浅拷贝（Shallow Copy）
浅拷贝只复制对象的成员变量，而不关心这些成员变量是否指向堆（heap）中的动态内存。对于普通的成员变量（如整数、浮点数等），浅拷贝是没问题的；但如果对象中包含指针，浅拷贝只复制指针的地址，而不复制指针指向的数据。

- **优点**: 浅拷贝执行起来非常快，因为它仅仅复制了基本类型的成员变量和指针。
- **缺点**: 浅拷贝可能会导致多个对象共享同一块堆内存，如果一个对象释放了这块内存，其他对象再访问时会出现问题（悬空指针）。
  
#### 浅拷贝的示例：
```cpp
class Example {
public:
    int* ptr;
    Example(int val) {
        ptr = new int(val);
    }
    
    // 浅拷贝构造函数
    Example(const Example &obj) {
        this->ptr = obj.ptr;  // 只复制指针地址
    }
    
    ~Example() {
        delete ptr;  // 可能导致多次释放同一块内存
    }
};
```

在上面的代码中，浅拷贝构造函数只复制了指针的地址，这样两个对象的`ptr`指针将指向同一个内存区域，这会引发双重释放（double delete）问题。

### 2. 深拷贝（Deep Copy）
深拷贝不仅复制对象的成员变量，还会为所有指针或动态分配的内存创建一份独立的副本。也就是说，深拷贝会复制指针所指向的数据，而不仅仅是指针本身。

- **优点**: 深拷贝为每个对象分配独立的内存，解决了浅拷贝中的双重释放和悬空指针问题。
- **缺点**: 深拷贝比浅拷贝要慢，因为它需要为每个对象分配新内存，并复制数据。

#### 深拷贝的示例：
```cpp
class Example {
public:
    int* ptr;
    Example(int val) {
        ptr = new int(val);
    }
    
    // 深拷贝构造函数
    Example(const Example &obj) {
        // 分配新的内存，并复制数据
        ptr = new int(*obj.ptr);
    }
    
    ~Example() {
        delete ptr;  // 每个对象独立释放内存
    }
};
```

在深拷贝的例子中，每次进行复制时，都会为`ptr`指针分配新的内存并复制指针指向的内容，从而避免了多次释放同一块内存的风险。

### 总结：
- **浅拷贝**: 只复制对象的成员变量及其指针，多个对象共享同一块堆内存。
- **深拷贝**: 不仅复制成员变量，还为指针指向的数据分配新的内存，确保每个对象都有独立的数据副本。
# 被释放内存的性质
当 C++ 程序中的析构函数通过 `delete` 释放了一块堆内存后，该内存被系统标记为 **可用内存**。这块已释放的可用内存有以下几个主要性质：

### 1. 未分配状态，可以被重新分配

这块内存被标记为可用，意味着操作系统或内存管理器认为它不再被程序所占用，其他部分的程序或进程可能会在后续分配内存时重新使用这块空间。新的内存分配可能会覆盖该内存的原始数据。

### 2. **内容未必被清除**

释放内存后，内存的内容通常不会被立即清除。这意味着即使这块内存已经被释放，原来的数据可能仍然暂时留在该内存区域中，直到这块内存被分配给新的对象或程序，并被新数据覆盖。这种未清除的内存数据被称为 **"脏数据"**（stale data），虽然程序不能合法访问它，但它在物理上仍然存在于内存中。

### 3. **不能合法访问**

虽然内存中的数据暂时还在，但对程序来说，这块内存已经被标记为“无效”或“不可用”。任何试图通过悬空指针访问该内存的操作都会导致 **未定义行为**。未定义行为的后果无法预测，可能包括程序崩溃、数据损坏，甚至错误的运行结果。

### 4. **可能引发双重释放错误**

如果程序在后续尝试再次释放这块内存（例如通过 `delete` 一个悬空指针），会引发 **双重释放错误**（double free）。双重释放通常会导致程序崩溃，或者在某些情况下可能导致更难以检测的内存错误。

### 5. **内存碎片化的风险**

如果程序频繁地分配和释放不同大小的内存块，而内存管理器不能高效地将这些已释放的内存重新利用，就可能导致内存 **碎片化**。碎片化会导致程序运行时内存效率降低，尽管总内存量足够，仍然可能无法找到足够大的连续内存块进行分配。

### 6. **安全风险**

如果某个程序通过悬空指针访问并读取了已经释放的内存数据，而该数据没有被立即覆盖，可能会带来潜在的安全风险。这种情况在某些安全敏感的场景下（如处理密码或机密数据的程序）可能会被恶意利用，称为 **"内存重用漏洞"**（memory reuse vulnerability）。

总的来说，虽然释放后的内存仍然物理存在，但对程序来说它是不可访问的，任何访问或操作都可能带来未定义行为或内存管理问题
# 要点
- 当你没有提供构造函数时，编译器会为你生成默认构造函数和默认析构函数，他们是一个空函数。
- 当你没有提供拷贝构造函数的时候，编译器会为你生成一个默认拷贝构造函数，默认的拷贝构造函数执行的是**浅拷贝**，即逐个成员变量进行简单的复制操作。
- `SeqStack s2 = s1;`本质上就是 `SeqStack s2(s1);`
- 在 C++ 中，如果一个对象对另一个对象进行了 **浅拷贝**（shallow copy），这意味着两个对象的指针指向同一块堆内存。当其中一个对象被销毁时，如果该对象的析构函数释放了这块堆内存（例如通过 `delete`），那么这块内存就会被系统标记为 **可用** 内存，可以被其他进程或程序重新分配。
- 但是，由于浅拷贝的两个对象共享同一个指针，所以当第一个对象析构并释放内存后，另一个对象的指针仍然指向这块已经释放的内存。如果尝试通过另一个对象访问这块内存（例如读写数据），就会产生 **悬空指针**（dangling pointer）问题。悬空指针指向的是一块已经被释放的内存，访问这块内存可能会导致 **未定义行为**，例如程序崩溃或数据损坏。
- 拷贝构造函数拷贝数据时尽量使用for循环赋值，而不是`memcpy`和`realloc`。
 ```cpp
#include <cstdlib>
#include <iostream>

// 利用面向对象实现一个顺序栈
class SeqStack
{
public:
    // 构造函数
    SeqStack(int size = 10)
    {
        std::cout << this << " constructor" << std::endl;

        _data = new int[size];
        _top = -1;
        _size = size;
    }
    // 拷贝构造函数
    SeqStack(const SeqStack &src)
    {
        std::cout << this << " copy constructor" << std::endl;

        _data = new int[src._size];
        for (int i = 0; i <= src._size; i++)
        {
            _data[i] = src._data[i];
        }
        _top = src._top;
        _size = src._size;
    }
    // = 赋值运算符重载
    void operator=(const SeqStack &src)
    {
        std::cout << this << " operator=" << std::endl;
        // 如果两个对象相同`s1 =s1`，不处理
        if (this == &src) { return; }
        // 释放旧空间
        delete[] _data;
        // 申请新空间,并拷贝数据
        _data = new int[src._size];
        for (int i = 0; i <= src._size; i++)
        {
            _data[i] = src._data[i];
        }
        _top = src._top;
        _size = src._size;
    }
    // 析构函数
    ~SeqStack()
    {
        std::cout << this << " destructor" << std::endl;

        delete[] _data;
        _data = nullptr;
        _top = -1;
        _size = 0;
    }
    void push(int val)
    {
        if (full()) { resieze(); }
        _data[++_top] = val;
    }
    void pop()
    {
        if (empty()) { return; }
        _top--;
    }
    int top()
    {
        if (empty()) { return -1; }
        return _data[_top];
    }
    bool empty() { return _top == -1; }
    bool full() { return _top == _size - 1; }

private:
    int *_data;
    int _top;
    int _size;

    void resieze()
    {
        int *newData = new int[_size * 2];
        for (int i = 0; i < _size; i++)
        {
            newData[i] = _data[i];
        }
        delete[] _data;
        _data = newData;
        _size *= 2;
    }
};
int main()
{
    SeqStack s(5);

    for (int i = 0; i < 15; i++)
    {
        s.push(rand() % 100);
    }
    // 调用拷贝构造函数
    SeqStack s2(s);
    // 调用=赋值运算符重载
    SeqStack s3;
    s3 = s2;

    return 0;
}
```
