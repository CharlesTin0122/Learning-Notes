# 基本概念

- `std::vector<int> vec;`向量容器
	- 底层数据结构：动态开辟的数组，每次以原来空间大小的两倍进行扩容。
	- 增加元素：
		- `vec.push_back(20);`末尾添加元素$O(1)$，可能导致扩容。
		- `vec.insert(it, 20);`迭代器位置添加元素$O(n)$，可能导致扩容。
	- 删除元素
		- `vec.pop_back();`删除末尾元素$O(1)$
		- `vec.erase(it);`删除it指定位置元素$O(n)$
	- 查询元素
		- `vec[5];`数组索引随机访问$O(1)$
		- 迭代器遍历$O(n)$
		- 泛型算法`find()`，`for_each`
	- 常用方法
		- `size();`返回元素个数
		- `empty();`判空
		- `reserve(20);`给容器预留空间，只给容器底层开辟指定大小的内存空间，不会添加元素
		- `resize(20);`重置容器大小，扩容。不仅给容器底层开辟指定大小的内存空间，还会会添加新的元素
		- `swap();`两个容器元素互换
	- 注意事项
		- 对容器进行连续插入或移除操作（insert/erase），一定要更新迭代器，否则第一次插入或移除操作完成后会导致迭代器失效。
# 增删改查案例
```cpp
    // 创建容器
    std::vector<int> vec;
    // 填充数据
    for (int i = 0; i < 20; i++)
    {
        vec.push_back(rand() % 100 + 1);
    }
    // 遍历打印
    for (const int val : vec)
    {
        std::cout << val << " ";
    }
    std::cout << std::endl;
    // 删除所有偶数
    auto it = vec.begin();
    while (it != vec.end())
    {
        // erase方法连续移除元素，要记得接收更新后的迭代器，防止迭代器失效。
        if (*it % 2 == 0) { it = vec.erase(it); }
        else { ++it; }
    }

    // 迭代器遍历打印
    for (auto it1 = vec.begin(); it1 != vec.end(); it1++)
    {
        std::cout << *it1 << " ";
    }
    std::cout << std::endl;
    // 给容器中所有的奇数前面增加一个该奇数-1的偶数
    auto it2 = vec.begin();
    while (it2 != vec.end())
    {
        if (*it2 % 2 != 0)
        {
            // insert方法连续插入元素，要记得接收更新后的迭代器，防止迭代器失效。
            it2 = vec.insert(it2, *it2 - 1);
            // 插入元素后，迭代器要后移两个位置，跳过新插入的元素和已经迭代过的元素，继续遍历
            it2 += 2;
        }
        else { ++it2; }
    }
    // 遍历打印
    for (int i = 0; i < vec.size(); i++)
    {
        std::cout << vec[i] << " ";
    }
    std::cout << std::endl;
```
# reserve方法案例
```cpp
    // 创建容器，有效元素数量为0
    std::vector<int> vec;
    // 给vec容器开辟20个元素的内存空间，并不会添加元素
    vec.reserve(20);
    // 查询信息
    std::cout << vec.empty() << std::endl;
    std::cout << vec.size() << std::endl;
    // 填充数据，已开辟空间，不会导致扩容。
    for (int i = 0; i < 20; i++)
    {
        vec.push_back(rand() % 100 + 1);
    }
    // 遍历打印
    for (const int val : vec)
    {
        std::cout << val << " ";
    }
    std::cout << std::endl;
```
# resize方法案例
```cpp
    // 创建容器，有效元素数量为0
    std::vector<int> vec;
    // 给vec容器开辟20个元素的内存空间，会添加20个值为int()的元素
    vec.resize(20);
    // 查询信息
    std::cout << vec.empty() << std::endl;
    std::cout << vec.size() << std::endl;
    // 填充数据，从第20个元素向后添加
    for (int i = 0; i < 20; i++)
    {
        vec.push_back(rand() % 100 + 1);
    }
    // 遍历打印
    for (const int val : vec)
    {
        std::cout << val << " ";
    }
    std::cout << std::endl;
```
