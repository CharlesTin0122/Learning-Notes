# 比较vector和deque容器
- 底层数据结构不同，vector的数据结构是一个动态开辟的数组。deque的数据结构是一个动态开辟的二维数组。
- 前中后插入删除元素的时间复杂度不同。
- 对于内存的使用效率来说，vector需要大片的内存连续空间。deque不需要，内存使用效率更高。
- 如果有在队首插入删除元素是的需求，可以使用deque容器，如果需要大量索引随机访问，使用vector容器
# vector和deque容器在中间位置插入和移除元素的时候哪一个容器效率更好？
- vector和deque容器在中间位置插入和移除元素的时间复杂度都是$O(n)$
- 由于deque容器的第二维内存空间不是连续的，所以在deque容器的中间位置进行元素的插入和移除，造成元素移动要比vector要慢。
# 比较vector和list容器
- 底层数据结构不同，vector的数据结构是一个动态开辟的数组。list的数据结构是双向循环链表。
- vector容器增加删除查询的时间复杂度都是$O(n)$,但是vector容器支持通过索引随机访问，时间复杂度为$O(1)$,可以通过索引快速访问元素
- list容器增加删除元素的时间复杂度是$O(1)$，查询的时间复杂度是$O(n)$。
- 如果有大量的插入删除操作，优先使用list，如果查询操作较多，则使用vector
