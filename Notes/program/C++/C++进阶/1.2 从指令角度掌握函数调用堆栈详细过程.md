请看如下代码：
```cpp
#include <iostream>

int sum(int a, int b)
{
    int temp = 0;
    temp = a + b;
    return temp;
}

int main()
{
    int a = 10;
    int b = 20;
    int ret = sum(a, b);
    std::cout << ret << std::endl;

    return 0;
}
```
现在有两个问题：
1. main函数调用sum函数，sum函数执行完毕后，怎么知道回到哪个函数？
2. sum函数执行完，回到main函数后，怎么知道从哪一行指令继续运行？
