### 静态成员变量
#### 静态成员变量简介

**静态成员变量**（`static` member variables）是属于类而不是属于某个对象的变量。在C++中，静态成员变量只有一个实例，无论类的对象有多少个，它们共享同一个静态成员变量。静态成员变量在程序执行开始时就被分配内存，并在程序结束时释放。

#### 静态成员变量的特性

1. **类范围共享：**
   - 静态成员变量是类的所有对象共享的。这意味着修改一个对象的静态成员变量会影响所有对象，因为它们指向同一块内存。
   
2. **生命周期：**
   - 静态成员变量在程序启动时分配内存，并在程序结束时销毁。它的生命周期比普通成员变量长得多。

3. **类外定义：**
   - 静态成员变量声明在类内部，但必须在类外进行定义和初始化。类外定义时不能使用`static`关键字。

4. **可以通过类名或对象访问：**
   - 静态成员变量可以通过类名直接访问，也可以通过对象访问，但通常推荐使用类名来访问，以明确它是类的属性而非对象的属性。

#### 静态成员变量的定义与使用

##### 1. **声明与定义**

```cpp
class MyClass {
public:
    static int staticValue;  // 静态成员变量声明
};

// 静态成员变量定义（类外进行）
int MyClass::staticValue = 0;
```

在上面的代码中，`staticValue`是类`MyClass`的静态成员变量。它在类内被声明为`static`，但必须在类外定义并初始化。

##### 2. **访问静态成员变量**

静态成员变量可以通过类名或对象进行访问：

```cpp
int main() {
    // 通过类名访问
    MyClass::staticValue = 10;
    
    // 通过对象访问
    MyClass obj1, obj2;
    obj1.staticValue = 20;

    // 打印静态成员变量
    std::cout << "obj1: " << obj1.staticValue << std::endl;
    std::cout << "obj2: " << obj2.staticValue << std::endl;
    std::cout << "Class: " << MyClass::staticValue << std::endl;
    
    return 0;
}
```

输出结果：
```
obj1: 20
obj2: 20
Class: 20
```

可以看到，`obj1`和`obj2`的`staticValue`值是相同的，这证明它们共享同一个静态成员变量。

#### 静态成员变量的应用场景

1. **计数器：**
   - 静态成员变量常用于类的实例化计数，记录当前已创建了多少个对象。
   
   示例：
   ```cpp
   class MyClass {
   public:
       MyClass() { ++count; }
       static int getCount() { return count; }

   private:
       static int count;
   };

   int MyClass::count = 0;
   
   int main() {
       MyClass obj1, obj2;
       std::cout << "Object count: " << MyClass::getCount() << std::endl;
       return 0;
   }
   ```
   输出：
   ```
   Object count: 2
   ```

2. **全局配置信息：**
   - 静态成员变量可用于存储类的全局配置信息，所有对象共享这些信息。

3. **类的共享资源：**
   - 静态成员变量可以用于存储需要在多个对象之间共享的数据或资源，例如连接池、缓存等。
   - **静态成员变量的声明在类内部**是为了告诉编译器类有这个成员，并允许类中的静态方法和其它成员函数使用它。
   - **静态成员变量的定义在类外部**是因为静态成员属于整个类，而不是某个对象，必须全局唯一；类外定义可以分配内存并防止重复定义。

#### 总结

静态成员变量是一个类级别的成员，所有对象共享。它适合用于需要跨对象共享数据的场景，并且它的生命周期较长，贯穿整个程序运行期。

## 成员方法

在C++中，成员方法是类的一部分，用来操作类的成员变量。根据方法的性质，可以分为普通成员方法、常成员方法和静态成员方法。它们的定义和使用方式各有不同。

### 1. **普通成员方法**
普通成员方法是最常见的成员方法，它能够修改类的成员变量，并且与具体的对象关联。调用时，方法通过隐含的`this`指针访问调用它的对象。这个方法可以读写对象的成员变量。

**定义示例：**
```cpp
class MyClass {
public:
    void setValue(int v) { value = v; }  // 普通成员方法，可以修改value
private:
    int value;
};
```

**特点：**
- 可以读写类的成员变量。
- 只能通过对象来调用，例如：`obj.setValue(10);`。

### 2. **常成员方法**
常成员方法不能修改类的成员变量，也不能调用非`const`方法。为了保证这一点，常成员方法需要在声明和定义时使用`const`关键字。

**定义示例：**
```cpp
class MyClass {
public:
    int getValue() const { return value; }  // 常成员方法，不能修改成员变量
private:
    int value;
};
```

**特点：**
- **不能修改**类的成员变量，除非这些变量是`mutable`类型。
- 在方法声明的尾部加上`const`关键字。
- 只能调用其它的常成员方法。
- 可以通过`const`对象调用，例如：
    ```cpp
    const MyClass obj;
    obj.getValue();
    ```

### 3. **静态成员方法**
静态成员方法与具体的对象无关，它属于类本身而不是某个对象。静态成员方法只能访问静态成员变量，不能访问普通的成员变量，因为它不通过`this`指针来操作对象。

**定义示例：**
```cpp
class MyClass {
public:
    static void setStaticValue(int v) { staticValue = v; }  // 静态成员方法
    static int getStaticValue() { return staticValue; }
private:
    static int staticValue;  // 静态成员变量
};
```

**特点：**
- 静态方法只能访问静态成员变量，不能访问非静态成员变量。
- 通过类名或者对象名调用，例如：
    ```cpp
    MyClass::setStaticValue(10);
    MyClass obj;
    obj.getStaticValue();
    ```
- 不依赖于类的对象存在，可以直接通过类名调用。

### **区别与关系**
1. **普通成员方法**可以修改和访问类的成员变量，必须通过对象调用，并且每个对象的普通成员方法操作的对象实例变量不同。
2. **常成员方法**不能修改成员变量，通常用于只读操作，`const`修饰保证了方法的安全性。
3. **静态成员方法**与对象无关，它操作的是类的静态变量，与普通的成员变量无关，主要用于处理与对象无关的类级别的逻辑。

总结来看，普通成员方法关注具体对象的操作，常成员方法用于保证不会修改状态，而静态成员方法则完全脱离具体对象用于类级别的操作。
### 总结
#### 普通成员方法
- 属于类的作用域
- 调用该方法，需要依赖一个对象，常对象无法调用，因为对象的this指针类型不同：`const classname *this`不能调用` classname *this`
- 可以任意访问对象的私有成员变量
- 编译器会添加一个`this`行参变量
#### 静态成员方法，static
- 属于类的作用域
- 用类名作用域来调用方法
- 可以任意访问对象的私有成员，只能调用静态成员
- 不会生成`this`行参变量
#### 常成员方法，const
- 属于类作用域
- 调用该方法，需要依赖一个对象，普通对象和常对象都可以调用
- 可以任意访问对象的私有成员变量，但是只能读，不能写
- 生成this指针为`const classname *this`，常对象可以调用常方法
```cpp
#include <iostream>

// 日期类
class Date
{
public:
    Date(int year = 1900, int month = 1, int day = 1)
    {
        _year = year;
        _month = month;
        _day = day;
    }
    void showDate() const
    {
        std::cout << _year << "-" << _month << "-" << _day << std::endl;
    }

private:
    int _year;  // 年
    int _month; // 月
    int _day;   // 日
};

// 商品类
class Goods
{
public:
    // 构造函数的初始化列表，成员对象的初始化
    Goods(std::string name, double price, int amount, int y, int m, int d)
        : _date(y, m, d), _name(name), _price(price), _amount(amount)

    {
        // 记录所有产生对象的数量
        _count++;
    }

    // 常成员方法
    void showInfo() const
    {
        std::cout << _name << " " << _price << " " << _amount << std::endl;
        _date.showDate();
    }

    std::string getName() const { return _name; }
    double getPrice() const { return _price; }
    int getAmount() const { return _amount; }

    void setName(std::string name) { _name = name; }
    void setPrice(double price) { _price = price; }
    void setAmount(int amount) { _amount = amount; }

    // 静态成员函数，没有this指针, 只能访问静态成员变量
    static int getCount() { return _count; }

private:
    std::string _name; // 名称
    double _price;     // 单价
    int _amount;       // 数量
    Date _date;        // 生产日期，成员对象
    // 商品总数量，静态成员变量，不属于某个对象，所有对象共享。类内声明，类外定义。
    static int _count;
};
// 静态成员变量类外定义，类外初始化
int Goods::_count = 0;

int main()
{

    Goods good1("bread", 32.56, 7, 2022, 1, 1);
    good1.showInfo();

    Goods good2("milk", 13.66, 10, 2022, 2, 2);
    good2.showInfo();

    Goods good3("apple", 24.0, 10, 2022, 3, 3);
    good3.showInfo();

    Goods good4("orange", 36.45, 10, 2022, 4, 4);
    good4.showInfo();

    // 统计商品总数量
    std::cout << "商品总数量：" << Goods::getCount() << std::endl;
    // 常对象，不能修改成员变量
    const Goods good5("mima", 36.45, 10, 2022, 4, 4);
    // 常对象在调用方法时 Goods::showInfo(&good5),
    // this 指针为 const Goods* 类型,而方法是一个Goods:: *this 类型，
    // 所以不能调用，所以成员方法要加const 修饰，才能调用。
    good5.showInfo();

    return 0;
}
```
