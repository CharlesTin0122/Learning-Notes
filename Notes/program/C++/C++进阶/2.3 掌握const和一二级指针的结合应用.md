# 常量使用的常见错误
- const关键字修饰的变量是一个常量，他跟普通变量的主要区别是
	- 编译方式不同，所有出现常量的地方都被常量的初始化值替换
	- 常量不能作为左值
- const修饰的常量常出现的错误是
	- 常量不能作为左值（试图直接修改常量的值）
	- 不能把常量的地址泄露给一个普通的指针或者普通的引用变量（试图间接修改常量的值）
```cpp
//声明一个常量
const int a = 10;
// 错误，不能直接修改常量值
a = 20; 
// 错误，不能将常量地址泄露给普通指针，&a 的类型是 const int*
int *p = &a 
```
# const和一级指针的结合
C++语言规范中有这样的描述：const修饰的是离他最近的类型。有四种情况
- `const int *p`：指针 `p` 指向一个 `const int` 类型的值，表示**指针指向的值不能被修改**，但指针 `p` 本身可以指向其他位置。
- `int const *p`：与第一种声明完全等效。这是另一种写法，表示**指针指向的值是常量**，但指针本身可以被修改。
- `int *const p`：表示指针 `p` 是常量，**指针不能改变所指向的地址**，但你可以修改指针所指向的值。
- `const int *const p`：表示指针 `p` 是常量，并且指针指向的值也是常量。**你既不能修改指针的地址，也不能修改指针指向的值**。
总结：
- `const` 放在类型前或指针符 `*` 前时，表示**指针指向的值**是常量，不能通过指针修改值。
- `const` 放在指针声明的最后（`*` 后面）时，表示**指针本身是常量**，不能修改它指向的地址。
```cpp
//声明一个常量
const int a = 10;
//声明一个常量指针来接收a的地址
const int *p = &a;

```
# const和二级指针的结合
请看如下代码
```cpp
//声明变量
int a = 10;
//指针p指向a
int *p = &a;
//二级指针q指向p
int **q = &p;
```

![|](attachments/2.3%20掌握const和一二级指针的结合应用.png)
- const和二级指针的结合，有三种情况
	- `const int **q`：const修饰的是`**q`，`**q`（指向的数据）不能修改。`q` 可以被赋值，`*q`可以被赋值。
	- `const int *const *q`：指向的指针`*q`和指向的数据都不能修改
	- `int *const *q`：const修饰的是`*q`，不能被赋值。`q`可以被赋值。`**q`可以被赋值。
	- `int **const q`：const修饰的是`q`，不能被赋值。`*q`可以被赋值。`**q`可以被赋值。
# 总结const和指针类型转换公式
等号`=`两侧分别是左值和右值
- `int * = const int*`：是错误的
- `const int* = int*`：是可以的

- `int** = const int**`：是错误的
- `const int** = int**`：是错误的，编译器不能保证最终指向的 `int` 值是不可修改的。
举例：
```cpp
int a = 10;
const int* cp = &a;

int** pp;
const int** cpp = pp; // 错误

// 如果允许这种赋值，可以这样做：
*cpp = &a;    // cpp 被赋值一个 const int*，指向 a
**pp = 20;    // 通过 pp 修改了 a，这违反了 const 限制

```

- `int** = int *const*`：是错误的，本质上是`int* = const int*
- `int *const* = int**`：是可以的，本质上是`cont int* = int*
# 例题
## 题目1
- 请选择下面哪些代码是错误的? A
 A. 错误
```cpp
int a = 10;
const int *p = &a;
//不能把一个整型常量的地址赋给一个普通指针，应当使用`const int *q = p;`
int *q = p; 
```
B. 正确
```cpp
int a= 10;
int *const p = &a;
//左值为`int*`，右值为`int*`
int *q = p;
```
C. 正确
```cpp
int a= 10;
int *const p = &a;
//左值为`int*`，右值为`int*`
int *const q = p;
```
D.正确
```cpp
int a = 10;
int *const p = &a;
//左值为`const int*`，右值为`int*`
const int *q = p;
```
