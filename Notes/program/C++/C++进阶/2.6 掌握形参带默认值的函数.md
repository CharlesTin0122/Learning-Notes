在C++中，函数的形参（函数参数）可以带有默认值，允许调用者在调用函数时省略某些参数。带默认值的参数使函数更加灵活和易于使用，尤其是当某些参数通常有一个合理的默认值时。默认参数在函数声明中指定，但只能在函数的右侧参数中设置默认值。

### 使用默认参数的规则：
1. 默认参数必须从**右向左**设置。也就是说，如果一个形参有默认值，则它右边的所有形参也必须有默认值。
2. 默认参数可以在函数声明或定义中指定，但只能在一个地方设置，通常是在声明中。

### 语法：
```cpp
返回类型 函数名(参数类型1 参数名1 = 默认值1, 参数类型2 参数名2 = 默认值2, ...);
```

### 示例 1：基本用法
```cpp
#include <iostream>

// 声明和定义函数时为参数设置默认值
void printMessage(const std::string& message = "Hello, World!", int repeat = 1) {
    for (int i = 0; i < repeat; ++i) {
        std::cout << message << std::endl;
    }
}

int main() {
    printMessage();                  // 使用默认参数，输出 "Hello, World!" 一次
    printMessage("Hi there!");        // 使用部分默认参数，输出 "Hi there!" 一次
    printMessage("Goodbye", 3);       // 覆盖默认参数，输出 "Goodbye" 三次
    return 0;
}
```
#### 输出：
```
Hello, World!
Hi there!
Goodbye
Goodbye
Goodbye
```

### 示例 2：默认参数的声明和定义分开
```cpp
#include <iostream>

// 在函数声明中指定默认参数
void printMessage(const std::string& message = "Hello, World!", int repeat = 1);

void printMessage(const std::string& message, int repeat) {
    for (int i = 0; i < repeat; ++i) {
        std::cout << message << std::endl;
    }
}

int main() {
    printMessage();                  // 使用默认参数
    printMessage("Hi there!");        // 使用部分默认参数
    printMessage("Goodbye", 3);       // 覆盖默认参数
    return 0;
}
```

### 注意事项：
1. **默认参数只能在函数声明或定义中的一个地方设置**。如果在声明中已经设置了默认参数，在定义中不能再次设置。
    ```cpp
    // 错误：不能在定义中重新设置默认值
    void printMessage(const std::string& message = "Hello, World!", int repeat = 1);  // 在声明中设置默认值
    void printMessage(const std::string& message = "Hi", int repeat = 1) {  // 错误
        // 函数体
    }
    ```

2. **不能在中间的参数设置默认值**。只能从右向左依次设置默认参数，否则会导致调用时的歧义。
    ```cpp
    void func(int a, int b = 2, int c);  // 错误：c 没有默认值，但 b 有默认值
    ```

3. **默认参数的求值时机**：默认参数是在函数调用时被求值的，而不是在函数声明或定义时求值。

### 示例 3：结合默认参数和函数重载
带有默认参数的函数可以与函数重载结合使用。但需要注意避免产生二义性。

```cpp
#include <iostream>

void display(int x, int y = 10) {
    std::cout << "display(int, int): " << x << ", " << y << std::endl;
}

// 重载版本
void display(double x) {
    std::cout << "display(double): " << x << std::endl;
}

int main() {
    display(5);      // 调用 display(int, int)，输出: 5, 10
    display(3, 7);   // 调用 display(int, int)，输出: 3, 7
    display(2.5);    // 调用 display(double)，输出: 2.5
    return 0;
}
```
#### 输出：
```
display(int, int): 5, 10
display(int, int): 3, 7
display(double): 2.5
```

在这个例子中，C++ 通过参数的类型来区分调用哪一个版本的 `display` 函数。虽然 `display(int, int)` 有默认参数，但 `display(double)` 可以明确地通过参数类型来匹配调用。

### 总结：
- 默认参数可以提高函数的灵活性，使得调用者可以选择省略部分参数。
- 默认参数从右向左设置，且不能在中间有未设置默认值的参数。
- 默认参数只能在声明或定义中设置一次。
- 默认参数可以结合函数重载使用，但要小心避免二义性。

使用默认参数可以减少函数的重载数量，使代码更加简洁和易读。
