# 指向函数的指针
指向函数的指针（Function Pointer）是指向函数的指针变量。在C和C++中，函数指针可以存储一个函数的地址，并可以用来调用该函数。使用函数指针的主要优点是可以实现更灵活的代码设计，比如回调函数和动态函数调用等。

### 基本概念

1. **声明函数指针**：
   要声明一个指向函数的指针，首先要定义函数的返回类型和参数类型。例如，假设我们有一个返回 `int` 并接受两个 `int` 参数的函数：

   ```c
   int add(int a, int b) {
       return a + b;
   }
   ```

   该函数的指针可以这样声明：

   ```c
   int (*funcPtr)(int, int);
   ```

2. **赋值**：
   可以将函数的地址赋值给函数指针。可以通过使用函数名（即函数的地址）来进行赋值：

   ```c
   funcPtr = add;  // 或者 funcPtr = &add;
   ```

3. **调用函数**：
   使用函数指针调用函数与直接调用函数类似：

   ```c
   int result = funcPtr(2, 3); // result = 5
   ```

### 使用示例

以下是一个完整的示例：

```c
#include <stdio.h>

// 定义一个函数
int add(int a, int b) {
    return a + b;
}

// 主函数
int main() {
    // 声明一个指向函数的指针
    int (*funcPtr)(int, int);
    
    // 将函数的地址赋值给指针
    funcPtr = add;

    // 使用指针调用函数
    int result = funcPtr(10, 20);
    printf("Result: %d\n", result); // 输出：Result: 30

    return 0;
}
```

### 常见用途

- **回调函数**：函数指针可以作为参数传递，以允许函数作为参数传递给其他函数。
- **动态函数调用**：在运行时决定调用哪个函数，提高程序的灵活性。
- **实现多态**：在某些情况下，函数指针可以用来模拟面向对象的多态特性。

通过理解和使用指向函数的指针，可以写出更灵活和高效的代码。
# 指向成员变量和成员函数的指针
```cpp
#include <iostream>

class Test
{
public:
    int ma;
    static int mb;
    void func() { std::cout << "call Test::func()" << std::endl; }
    static void static_func()
    {
        std::cout << "call Test::static_func()" << std::endl;
    }
};
int Test::mb;  // 定义静态成员变量

int main()
{
    Test t1;
    Test *t2 = new Test();

    // 指针指向成员变量需要借助作用域
    int Test::*p = &Test::ma;
    // 修改对象的成员变量
    t1.*p = 20;
    std::cout << t1.*p << std::endl;  // 输出 20
    std::cout << t1.ma << std::endl;  // 输出 20

    t2->*p = 30;
    std::cout << t2->*p << std::endl;  // 输出 30
    std::cout << t2->ma << std::endl;  // 输出 30

    // 静态成员变量不必依赖对象就可以操作
    int *p1 = &Test::mb;
    *p1 = 40;
    std::cout << *p1 << std::endl;  // 输出 40

    // 指向成员方法的指针, 需要加类作用域
    void (Test::*pfunc)() = &Test::func;
    // 调用成员方法要借助对象
    (t1.*pfunc)();    // 调用 t1 的成员函数，输出 "call Test::func()"
    (t2->*pfunc)();   // 调用 t2 的成员函数，输出 "call Test::func()"

    // 指向静态成员方法的指针
    void (*pfunc2)() = &Test::static_func;
    // 通过指针调用静态成员方法
    pfunc2();  // 输出 "call Test::static_func()"

    delete t2;  // 释放动态分配的内存
    return 0;
}

```
