# 问题
- 如何解释多态？
	- 静态（编译时期）多态
		- 函数重载
		- 模板（类模板，函数模板）
	- 动态（运行时期）多态
		- 在继承结构中基类指针（引用）指向派生类对象，通过该指针（引用）调用同名覆盖方法（虚函数），基类指针指向哪个派生类对象，就会调用该对象的覆盖方法，称为多态。
		- 多态底层是通过动态绑定实现的。
```cpp
#include <iostream>
#include <string>

// 基类，动物类
class Animal
{
public:
    Animal(std::string name) : _name(name) {}
    virtual void bark() {}

protected:
    std::string _name;
};
// 派生类
class Cat : public Animal
{
public:
    Cat(std::string name) : Animal(name) {}
    void bark() override { std::cout << "Meo!" << std::endl; }
};
class Dog : public Animal
{
public:
    Dog(std::string name) : Animal(name) {}
    void bark() override { std::cout << "woof!" << std::endl; }
};

// 全局函数,API接口。接收一个Animal类对象，返回叫声
void bark(Animal &p)
{
    p.bark(); // 虚函数，动态绑定
}

int main()
{
    Cat cat("mao");
    bark(cat); // 调用cat的vfptr指向的vftable中的Cat::bark()
    Dog dog("gou");
    bark(dog); // 调用dog的vfptr指向的vftable中的Dog::bark()

    return 0;
}
```
