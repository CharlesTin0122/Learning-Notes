代码想要变成可执行的程序，需要通过编译步骤进行转换。

编译（翻译）：将C++代码的文本，编译（翻译）为计算机可以执行的程序（如.exe）

进行翻译动作，需要一个工具，称之为：编译器

可以执行C++代码编译（翻译）工作的编译器有很多，课程选择：mingw

### 手动编译代码

在某个文件夹内，如：`d:\dev\code\cpp\itheima_cpp`，新建代码文件`hello_world.cpp`，内容如下：

```cpp
#include "iostream"
using namespace std;

int main()
{
    cout << "Hello World!!!" << endl;
    
    return 0;
}
```

  

通过cmd（命令提示符）程序进行编译：

输入`d:`，切换到D盘

输入：`cd D:\dev\code\cpp\itheima_cpp`，切换到代码文件夹

![](attachments/8b8609e102aa5ea29c5759faa7f5e192_MD5.jpg)

  

通过 `g++ 被编译的代码文件 -o 生产的程序名称` ， 此格式编译得到程序

如：`g++ hello_world.cpp -o hello_world.exe`

![](attachments/9afc04b2d2f3e2062f8b927b1f01c947_MD5.jpg)

输入程序名，回车执行，如：`hello_world.exe`
