在C++语言中，`priority_queue` 是一个标准模板库（STL）容器适配器，用于实现优先级队列。优先级队列是一种特殊的队列数据结构，其中每个元素都有一个优先级，并且出队时总是优先级最高的元素。

### 1. 特性
- **基于堆**：`priority_queue` 底层通常是通过最大堆（默认为 `std::vector`）实现的。因此，默认情况下，它是一个最大优先队列，其中最大元素具有最高优先级。
- **自动排序**：元素在插入队列时会自动进行排序，以确保队列的第一个元素始终是优先级最高的元素。

### 2. 主要操作
- **`push`**: 插入元素到优先队列中。
- **`pop`**: 移除优先队列中优先级最高的元素（即堆顶元素）。
- **`top`**: 访问优先队列中优先级最高的元素。
- **`empty`**: 检查优先队列是否为空。
- **`size`**: 返回优先队列中元素的数量。

### 3. 使用示例

```cpp
#include <iostream>
#include <queue>
#include <vector>

int main() {
    // 默认情况下，priority_queue是一个最大堆
    std::priority_queue<int> pq;

    // 插入元素
    pq.push(10);
    pq.push(20);
    pq.push(15);

    // 输出并移除优先级最高的元素
    std::cout << "Priority Queue Top Element: " << pq.top() << std::endl; // 输出20
    pq.pop();

    std::cout << "Priority Queue Top Element after pop: " << pq.top() << std::endl; // 输出15

    return 0;
}
```

### 4. 自定义比较函数
`priority_queue` 默认是最大堆，如果需要实现最小堆或根据自定义规则排序，可以通过传递比较函数或仿函数实现。

例如，实现一个最小堆：

```cpp
#include <iostream>
#include <queue>
#include <vector>
#include <functional>

int main() {
    // 使用greater<int>作为比较函数来实现最小堆
    std::priority_queue<int, std::vector<int>, std::greater<int>> minHeap;

    // 插入元素
    minHeap.push(10);
    minHeap.push(20);
    minHeap.push(15);

    // 输出并移除优先级最高的元素
    std::cout << "Min-Heap Top Element: " << minHeap.top() << std::endl; // 输出10
    minHeap.pop();

    std::cout << "Min-Heap Top Element after pop: " << minHeap.top() << std::endl; // 输出15

    return 0;
}
```
### 4.1构造函数
在 C++ 中，`std::priority_queue` 是一个模板类，支持自定义底层容器和排序规则。具体来说，`std::priority_queue<int, std::vector<int>, std::greater<int>> minHeap;` 这个定义中的三个模板参数分别代表：

1. **第一个参数 `int`**：
   - **类型**：优先队列中存储的元素的类型。
   - **解释**：在这个例子中，优先队列将存储 `int` 类型的整数。

2. **第二个参数 `std::vector<int>`**：
   - **容器类型**：指定优先队列底层使用的容器类型。
   - **解释**：`std::priority_queue` 默认使用 `std::vector` 作为底层容器来存储数据。这里明确指定使用 `std::vector<int>` 来存储 `int` 类型的数据。
   - **替代方案**：可以使用其他符合堆要求的容器类型，如 `std::deque`，但不能使用 `std::list`，因为 `std::list` 不支持随机访问。

3. **第三个参数 `std::greater<int>`**：
   - **比较器**：定义优先队列中元素的排序规则。
   - **解释**：`std::greater<int>` 是一个仿函数，用于指定排序方式。在这个例子中，它将优先队列定义为一个 **最小堆**，即队列中最小的元素具有最高优先级。
   - **默认值**：`std::less<int>`，用于实现最大堆。最大元素在堆顶。

##### 总结
- 第一个参数是存储的数据类型。
- 第二个参数是底层容器类型（通常是 `std::vector`）。
- 第三个参数是比较函数（用于确定优先级队列的顺序，默认是最大堆，使用 `std::less`；此处使用 `std::greater` 实现最小堆）。

通过传递这三个参数，你可以精确控制 `std::priority_queue` 的行为和底层实现。
### 5. 适用场景
`priority_queue` 适用于需要频繁访问或删除最大（或最小）元素的场景，如任务调度、路径查找算法（如 Dijkstra 算法）等。

### 总结
- `priority_queue` 是 C++ STL 中用于实现优先级队列的容器适配器。
- 默认情况下，它是一个最大堆，但可以通过自定义比较函数实现其他类型的优先级队列。
- 主要操作包括插入、删除、访问堆顶元素等。
