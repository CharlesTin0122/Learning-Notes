# 管理系统需求
职工管理系统可以用来管理公司内所有员工的信息，利用C++来实现一个基于多态的职工管理系统

公司职工分为三类，员工，经理，老板。显示信息时，需要显示职工编号，姓名，岗位，指责
- 员工指责：完成任务
- 经理指责：管理员工
- 老板指责：掌控全局
要实现的功能如下：
- 退出管理程序
- 增加职工信息
- 显示职工信息
- 删除离职员工
- 修改职工信息
- 查找职工信息
- 按照编号排序
- 清空所有信息
