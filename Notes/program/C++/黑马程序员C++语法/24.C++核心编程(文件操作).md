C++中对文件操作需要包含头文件`<fstream>`
文件类型分为两种
- 文本文件：文件以文本ASCII码的形式储存在计算机中
- 二进制文件：文件以文本的二进制形式储存在计算机中
操作文件三大类
- ofstream：写操作
- ifstream：读操作
- fstream：读写操作
# ASCII码文本文件操作
## 写文件
1. 包含头文件：`#include <fstream>`
2. 创建流对象：`ofstream ofs;`
3. 打开文件：`ofs.open("文件路径"， 打开方式)`
4. 写入数据：`ofs << "写入数据"`
5. 关闭文件：`ofs.close();`
文件打开方式：

| 打开方式        | 意义            |
| ----------- | ------------- |
| ios::in     | 为读取文件而打开文件    |
| ios::out    | 为写文件而打开文件     |
| ios::ate    | 初始位置：文件末尾     |
| ios::app    | 追加方式写文件       |
| ios::trunc  | 如果文件存在先删除，再创建 |
| ios::binary | 二进制方式         |
注意：文件打开方式可以配合使用，利用`|`操作符。例如`ios::binary | ios::out`,为写二进制文件而打开文件。
示例：
```cpp
#include <iostream>
#include <fstream>
#include <string>
using namespace std;

// 写文本文件
void test01()
{
	
	ofstream ofs;//实例化ofstream类对象，输出文件流

	ofs.open("test.txt", ios::out); //以写文件模式打开文件test.txt，若文件不存在则创建文件
	//写入内容
	ofs << "姓名：张三" << endl;
	ofs << "性别：男" << endl;
	ofs << "年龄：17" << endl;
	//关闭文件
	ofs.close();
}
// 主函数
int main()
{
	// 设置控制台输出为UTF-8编码，以支持中文输出
	system("chcp 65001>nul");
	//执行测试函数
	test01();
	//按任意键继续
	system("Pause");
	return 0;
}
```
> [!INFO] 总结
> - 文件操作必须包含头文件`fstream`
> - 写文件可以利用`ofstream`，或者`fstream`类
> - 打开文件需要指定文件路径以及打开方式
> - 利用`<<`想文件中写入数据
> - 操作完毕要关闭文件
## 读文件
读取文件步骤如下：
1. 包含头文件：`#include <fstream>`
2. 创建流对象：`ifstream ifs;`
3. 打开文件：`ifs.open("文件路径"， 打开方式)`
4. 读取数据：四种方式
5. 关闭文件：`ifs.close();`
示例：

	{
		cout << "文件打开失败" << endl;
		return;
	}
	// //第一种读取方法
	// char buf[1024] = { 0 };// 定义一个字符数组，用来存放读取的内容
	// // 利用while循环，将ifs中的数据逐行读取输入到buf中,如果没有内容了`ifs >> buf`返回`0`
	// while (ifs >> buf) 
	// {
	// 	cout << buf << endl;// 逐行打印buf中的内容
	// }
	// //第二种读取方法
	// char buf[1024] = { 0 };
	// //ifs.getline()字符串提取函数，参数1为提取到的字符数组，参数2为字符数组的长度，如果没有内容了返回0
	// while (ifs.getline(buf, sizeof(buf))) 
	// {
	// 	cout << buf << endl;
	// }
	//第三种读取方法
	string buf;// 定义一个字符串对象，用来存放读取的内容
	// getline()从数据流中读取数据输入字符串。参数1为输入流，参数2为字符串。

	{
		cout << buf << endl;
	}

	// char c; // 定义一个字符变量，用来存放读取的内容
	// // `ifs.get()`逐个字符循环读取文件内容，直到文件结束`ifs.get() = EOF`
	// // EOF:End Of File,文件结尾之意。

	// 	cout << c;

// 主函数

{
	// 设置控制台输出为UTF-8编码，以支持中文输出

# 二进制文本文件操作
以二进制方式对文件进行读写，打开方式要指定为`ios::binary`
## 写文件
二进制方式写文件主要利用流对象调用成员函数write。
函数原型：`ostream & write(const char *buffer, int len);`
参数解释：字符指针buffer指向内存中的一段储存空间，len是读写的字节数
示例：
```cpp
#include <iostream>
#include <fstream>
#include <string>
using namespace std;

// 二进制文件写入

// 定义Person类
class Person
{
public:
	char m_name[64];
	int m_age;
};
void test01()
{
	ofstream ofs;
	// 以二进制的方式为写入打开文件
	ofs.open("person.txt", ios::out | ios::binary);
	if (!ofs.is_open())
	{
		cout << "打开文件失败" << endl;
		return;
	}
	Person p1 = {"张三", 17};
	// 写入数据,参数1：数据的指针(Person的对象p1取地址并强转为const char*类型)，参数2：数据的长度
	ofs.write((const char *)&p1, sizeof(p1));
	ofs.close();
}
// 主函数
int main()
{
	// 设置控制台输出为UTF-8编码，以支持中文输出
	system("chcp 65001>nul");
	// 执行测试函数
	test01();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
## 读文件
二进制方式读取文件主要利用流对象调用成员函数read
函数原型：`istream& read(char *buffer, int len);`
参数解释：参数1，字符指针buffer指向内存中的一段空间。参数2，读写的字节数。
示例：
```cpp
#include <iostream>
#include <fstream>
#include <string>
using namespace std;

// 二进制文件写入

// 定义Person类
class Person
{
public:
	char m_name[64];
	int m_age;
};
void test01()
{
	ifstream ifs;
	ifs.open("person.txt", ios::in | ios::binary);
	if (!ifs.is_open())
	{
		cout << "文件打开失败" << endl;
		return;
	}
	// 读取文件
	Person p; // 创建对象用来存放读取的数据
	// 读取数据，并且将读取的数据存放到对象中
	// 参数1，Person对象p取址并强转为Char*类型，参数2，sizeof(Person)表示读取的字节数
	ifs.read((char *)&p, sizeof(p));
	// 打印数据
	cout << "姓名：" << p.m_name << endl;
	cout << "年龄：" << p.m_age << endl;
	// 关闭文件
	ifs.close();
}
// 主函数
int main()
{
	// 设置控制台输出为UTF-8编码，以支持中文输出
	system("chcp 65001>nul");
	// 执行测试函数
	test01();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
