# 常用排序算法
学习目标：
- 掌握常用的排序算法
算法简介
- `sort();`//对容器元素进行排序
- `random_shuffle();`//指定范围内元素随机排序
- `merge();`//元素容器合并，并储存到另一容器
- `reverse();`//反转排序注定范围的元素
## sort
### 功能描述
- 对容器内元素进行排序，默认为升序排列
### 函数原型
- `sort(begin, end, _pred);`
### 示例
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <functional>
using namespace std;

//STL算法 sort

//打印函数
void print_vec(const vector<int>& v)
{
	for (const int& elem : v)
	{
		cout << elem << " ";
	}
	cout << endl;
}

//测试函数
void test01()
{
	vector<int> v = { 9,8,7,6,7,4,3,7,1 };//创建源容器
	sort(v.begin(), v.end());//升序排列
	print_vec(v);//打印元素

	sort(v.begin(), v.end(), greater<int>());//降序排列
	print_vec(v);//打印元素

}

// 主函数
int main()
{
	test01();
	//test02();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
## random_shuffle
### 功能描述
- 指定范围内元素随机排序
### 函数原型
- `random_shuffle(begin, end)`
## 示例
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <functional>
using namespace std;

//STL算法 random_shuffle

//打印函数
void print_vec(const vector<int>& v)
{
	for (const int& elem : v)
	{
		cout << elem << " ";
	}
	cout << endl;
}

//测试函数
void test01()
{
	srand((unsigned int)time(NULL));//利用时间生成随机数种子
	vector<int> v = { 1,2,3,4,5,6,7,8,9 };//创建源容器
	random_shuffle(v.begin(), v.end());//打乱排序
	print_vec(v);
}

// 主函数
int main()
{
	test01();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
## merge
### 功能描述
- 合并两个容器并储存到另一个容器中
- 两个容器必须是有序的，合并后仍是一个有序序列
### 函数原型
- `merge(begin1, end1, begin2, end2, dest);`
	1. begin1：容器1开始迭代器
	2. end1：容器1结束迭代器
	3. begin2：容器2开始迭代器
	4. end2：容器2结束迭代器
	5. dest：目标容器开始迭代器
### 示例
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <functional>
using namespace std;

//STL算法 merge

//打印函数
void print_vec(const vector<int>& v)
{
	for (const int& elem : v)
	{
		cout << elem << " ";
	}
	cout << endl;
}

//测试函数
void test01()
{
	vector<int> v1 = { 1,2,3,4 };//创建源容器1
	vector<int> v2 = { 5,6,7,8,9 };//创建源容器2
	vector<int> v3;//创建目标容器
	v3.resize(v1.size() + v2.size());//目标容器开辟空间
	//合并容器到v3,源容器必须为有序序列
	merge(v1.begin(), v1.end(), v2.begin(), v2.end(), v3.begin());

	print_vec(v3);
}

// 主函数
int main()
{
	test01();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
## reverse
### 功能描述
- 将容器内的元素进行反转排序
### 函数原型
- `reverse(begin, end);`
### 示例
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <functional>
using namespace std;

//STL算法 reverse

//打印函数
void print_vec(const vector<int>& v)
{
	for (const int& elem : v)
	{
		cout << elem << " ";
	}
	cout << endl;
}

//测试函数
void test01()
{
	vector<int> v = { 1,4,7,2,5,8,3,6,9 };
	reverse(v.begin(), v.end());//反转容器元素序列
	print_vec(v);
}

// 主函数
int main()
{
	test01();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
