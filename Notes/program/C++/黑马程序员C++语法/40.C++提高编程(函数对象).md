# 函数对象的概念
## 概念
- 重载**函数调用操作符**`()`的类，其对象被称为函数对象
- 函数对象使用重载的`()`时，其行为类似函数调用，也叫**仿函数**
## 本质
- 函数对象（仿函数），是一个**类**，不是函数。
# 函数对象的使用
- 函数对象在使用时，可以像普通函数那样调用，可以有参数可以有返回值
- 函数对象超出普通函数的概念，函数对象可以有自己的属性
- 函数对象可以作为参数传递
## 示例
```cpp
#include <iostream>
using namespace std;

//函数对象（仿函数）

//1.函数对象可以像普通函数那样调用，可以有参数，返回值
class MyAdd
{
public:
	int operator()(int a, int b)
	{
		return a + b;
	}
};
//2.函数对象超出函数的概念，可以有自己的状态属性
class MyPrint
{
public:
	int count;//计数器，记录调用次数
	//构建方法，实例化对象时计数器初始化
	MyPrint()
	{
		this->count = 0;
	}

	void operator()(string str)
	{
		cout << str << endl;//打印字符串
		this->count++;//每次打印字符串计数器加一
	}
};
//3.函数对象可以作为参数传递
void do_print(MyPrint& mp, string str)
{
	mp(str);
}

//测试函数
void test01()
{
	//仿函数案例1
	MyAdd my_add;//创建函数对象
	int res = my_add(3, 5);//调用函数对象
	cout << res << endl;

	//仿函数案例2
	MyPrint my_print;
	my_print("Hello");
	my_print("Hello");
	my_print("Hello");
	cout << my_print.count << endl;

	//仿函数案例3
	MyPrint my_print1;
	do_print(my_print1, "Hello CPP");
}

// 主函数
int main()
{
	test01();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
# 谓词
## 概念
- 在C++编程语言中，谓词（predicate）是一种常用的概念，尤其是在使用标准模板库（STL）时。谓词是一个返回布尔值的函数或函数对象，用于在算法中进行条件判断。
- 如果`operator()`接收一个参数，叫做一元谓词
- 如果`operator()`接收两个参数，叫做二元谓词
## 一元谓词
### 示例
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

//一元谓词,仿函数参数为一个
class GreaterFive
{
public:
	bool operator()(int a)
	{
		return a > 5;
	}
};
//测试函数
void test01()
{
	//定义vector容器
	vector<int> vec = { 1,2,3,4,5,6,7,8,9 };
	//查找容器中大于5的数字，参数1、2：容器区间；参数3：匿名函数对象,返回值是迭代器
	vector<int>::iterator it = find_if(vec.begin(), vec.end(), GreaterFive());
	//打印大于5的第一个元素
	cout << *it << endl;
}

// 主函数
int main()
{
	test01();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
## 二元谓词
### 示例
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

//二元谓词,仿函数参数为两个
class MyCompare
{
public:
	bool operator()(int a, int b)
	{
		return a > b;
	}
};
//测试函数
void test01()
{
	//定义vector容器
	vector<int> vec = { 7,4,1,8,5,2,9,6,3 };
	//sort()默认为升序排列，使用函数对象改变排序规则为降序
	sort(vec.begin(), vec.end(), MyCompare());
	//打印容器
	for (const int& elem : vec)
	{
		cout << elem << endl;
	}
}

// 主函数
int main()
{
	test01();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
