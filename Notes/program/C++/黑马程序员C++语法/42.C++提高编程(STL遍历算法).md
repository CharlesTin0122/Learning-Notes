# 概述
- STL常用算法主要由头文件`<algorithm>`, `<functional>`,`<numeric>组成
- `<algorithm>`是所有STL头文件中最大的一个，范围涉及比较，交换，查找，遍历，复制，修改等
- `<numeric>`体积很小，只包括了几个在序列上面进行简单数学运算的模板函数
- `<functional>`定义了一些模板类，用以声明函数对象
# 常用遍历算法
## 算法简介
- `for_each` // 遍历容器
- `transform`//搬运容器元素至另一容器
## for_each
### 功能描述
- 遍历容器元素
### 函数原型
- `for_each(iterator_begin, iterator_end, _func);`//遍历容器元素
### 示例：
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <functional>
using namespace std;

//STL算法 for_each

//回调函数
void print_elem1(int val)
{
	cout << val << " ";
}
//函数对象
class print_elem2
{
public:
	void operator()(int val)
	{
		val++;
		cout << val << " ";
	}
};

//测试函数
void test01()
{
	//创建容器
	vector<int> vec1 = { 1,4,7,2,5,8,3,6,9 };
	//for_each函数遍历容器，每个元素执行回调函数print_elem1
	//参数1,2：容器区间，参数3：回调函数名
	for_each(vec1.begin(), vec1.end(), print_elem1);
	cout << endl;
	//参数1,2：容器区间，参数3：函数对象
	for_each(vec1.begin(), vec1.end(), print_elem2());


}

// 主函数
int main()
{
	test01();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
## transform
### 更能描述
- 搬运容器元素至另一容器
### 函数原型
`teansform(begin1, end1, begin2, _func);`
1. 参数1：源容器开始迭代器
2. 参数2：源容器结束迭代器
3. 参数3：目标容器开始迭代器
4. 参数4：回调函数或函数对象
### 示例
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <functional>
using namespace std;

//STL算法 transform

//打印元素回调函数，供for_each函数调用
void print_elem(int val)
{
	cout << val << " ";
}
//自增函数对象，供transform函数使用
class Transform
{
public:
	int operator()(int val)
	{
		val++;
		return val;
	}
};

//测试函数
void test01()
{
	
	vector<int> vec1 = { 1,4,7,2,5,8,3,6,9 };//创建源容器
	vector<int> vec2; //创建目标容器
	vec2.resize(vec1.size());//开辟目标容器空间
	transform(vec1.begin(), vec1.end(), vec2.begin(), Transform());//搬运元素至目标容器并自增
	for_each(vec2.begin(), vec2.end(), print_elem);//遍历打印蒜素
	cout << endl;

}

// 主函数
int main()
{
	test01();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
