# 类模板语法
类模板的作用：建立一个通用类，类中的成员数据类型可以不具体指定，用一个虚拟的类来表示
语法：
```
template<typename>
class
```
解释：
template--声明创建模板
typename--表明后面的符号是一种数据类型，可以用class代替
T--通用的数据类型，名字可替换，通常为大写
示例：
```cpp
#include <iostream>
#include <string>
using namespace std;
// 类模板

// 定义一个类模板
template <class NameType, class AgeType>
class Person
{
public:
	NameType m_name;
	AgeType m_age;
	Person(NameType name, AgeType age)
	{
		this->m_name = name;
		this->m_age = age;
	}
	void show_info()
	{
		cout << "name:" << this->m_name << endl;
		cout << "age:" << this->m_age << endl;
	}
};

// 测试函数
void test01()
{
	// 指定参数类型
	Person<string, int> p1("Tom", 19);
	p1.show_info();
}
// 主函数
int main()
{
	// 设置控制台输出为UTF-8编码，以支持中文输出
	system("chcp 65001>nul");
	// 执行测试函数
	test01();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
# 类模板和函数模板的区别
- 类模板没有自动类型推导的使用方法
- 类模板在模板参数列表中可以有默认参数
示例：
```cpp
#include <iostream>
#include <string>
using namespace std;
// 类模板

// 定义一个类模板
template <class NameType, class AgeType = int>
class Person
{
public:
	NameType m_name;
	AgeType m_age;
	Person(NameType name, AgeType age)
	{
		this->m_name = name;
		this->m_age = age;
	}
	void show_info()
	{
		cout << "name:" << this->m_name << endl;
		cout << "age:" << this->m_age << endl;
	}
};

// 测试函数
void test01()
{
	// 指定参数类型
	// Person p0("jim", 22); 错误，无法自动类型推导

	// 只能显示指定类型
	// 年龄参数已经通过默认参数指定为int,调用时可不指定
	// 只有类模板可以这样做，函数模板不可以
	Person<string> p1("Tom", 19);
	p1.show_info();
}
// 主函数
int main()
{
	// 设置控制台输出为UTF-8编码，以支持中文输出
	system("chcp 65001>nul");
	// 执行测试函数
	test01();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
# 类模板中的成员函数创建时机
类模板中的成员函数和和普通类中的成员函数创建实际是有区别的
- 普通类中的成员函数一开始就可以创建
- 类模板中的成员函数在调用时才创建
示例：
```cpp
#include <iostream>
#include <string>
using namespace std;
// 类模板中成员函数的创建时机

// 定义类
class Person1
{
public:
	void show_person1()
	{
		cout << "Person1 show" << endl;
	}
};
class Person2
{
public:
	void show_person2()
	{
		cout << "Person2 show" << endl;
	}
};
// 定义类模板
template <class T>
class MyClass
{
public:
	T obj;
	// 类模板中的成员函数，调用时才会创建，因为调用时才能知道他们参数的数据类型
	void func1()
	{
		obj.show_person1();
	}
	void func2()
	{
		obj.show_person2();
	}
};
// 测试函数
void test01()
{
	MyClass<Person1> a;
	a.func1();

	MyClass<Person2> b;
	b.func2();
}
// 主函数
int main()
{
	// 设置控制台输出为UTF-8编码，以支持中文输出
	system("chcp 65001>nul");
	// 执行测试函数
	test01();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
# 类模板对象做函数参数
类模板实例化对象，向函数传参的方式有三种：
1. 指定传入类型：直接显示对象的数据类型
2. 参数模板化：将对象中的参数变为模板进行传递
3. 整个类模板化：将这个对象类型模板化进行传递
示例：
```cpp
#include <iostream>
#include <string>
using namespace std;
// 类模板对象做函数参数

// 定义类模板
template <class T1, class T2>
class Person
{
public:
	T1 m_name;
	T2 m_age;
	Person(T1 name, T2 age)
	{
		this->m_name = name;
		this->m_age = age;
	}
	void show_info()
	{
		cout << "name:" << this->m_name << endl;
		cout << "age:" << this->m_age << endl;
	}
};
// 1.指定传入类型
void print_info1(Person<string, int>& p)
{
	p.show_info();
}
void test01()
{
	Person<string, int> p("jim", 17);
	print_info1(p);
}
//2.函数模板化，利用函数模板类型推导
template<class T1, class T2>
void print_info2(Person<T1, T2>& p)
{
	p.show_info();
	cout << "Type T1:" << typeid(T1).name() << endl;
	cout << "Type T2:" << typeid(T2).name() << endl;
}
void test02()
{
	Person<string, int> p("Tom", 23);
	print_info2(p);
}
//3.将整个类模板化
template<class T>
void print_info3(T &p)
{
	p.show_info();
	cout << "Type T:" << typeid(T).name() << endl;
}
void test03()
{
	Person<string, int> p("Lucy", 19);
	print_info3(p);
}
// 主函数
int main()
{
	// 设置控制台输出为UTF-8编码，以支持中文输出
	system("chcp 65001>nul");
	// 执行测试函数
	test01();
	test02();
	test03();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
> [!INFO] 总结
> 用第一种方法
# 类模板与继承
类模板的继承注意一下几点：
- 当子类继承的父类是一个类模板时，子类在声明的时候需要指出父类中的T类型
- 如果不指定，编译器无法给子类分配内存
- 如果想灵活的指定父类中T的类型，子类也需要变为类模板
示例：
```cpp
#include <iostream>
#include <string>
using namespace std;
// 类模板与继承

// 定义父类模板
template <class T>
class Base
{
	//子类实例化数据类型char传入子类T2数据类型，再通过继承传给父类T数据类型
	T m;
};
//定义子类

//1.必须确定父类中参数T的数据类型，才能继承给子类
class Son1:public Base<int>
{
};
void test01()
{
	Son1 s1;
}
//2.想要灵活指定父类中T的类型，子类也需要变为类模板
template <class T1, class T2>
class Son2 :public Base<T2>
{
	//此时T1类型int传递给obj,T2类型char传给父类的数据类型T
	T1 obj;
public:
	Son2()
	{
		cout << typeid(T1).name() << endl;
		cout << typeid(T2).name() << endl;
	}
};
//测试函数
void test02()
{
	//实例化子类时传入两个类型int,char，其中int传给T1，char传给T2.
	Son2<int, char> s2;
}

// 主函数
int main()
{
	// 设置控制台输出为UTF-8编码，以支持中文输出
	system("chcp 65001>nul");
	// 执行测试函数
	test01();
	test02();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
