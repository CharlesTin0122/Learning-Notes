# 基本概念
- Queue是一种先进后出（First In Last Out，FIFO）的数据结构，他有两个出口
- queue容器允许从一段新增元素，从另一端移除元素
- queue只有队首和队尾的元素可以被外界使用，因此queue不允许有遍历行为
![|800](attachments/35.C++提高编程(queue容器).png)
# 常用接口
## 构造函数
- `queue<T> que;`//默认构造函数
- `queue(const queue& que);`拷贝构造函数
## 赋值操作
- `queue& operator=(const queue& que);`//重载=运算符
## 数据存取
- `push(elem);`//往队尾添加元素
- `pop();`//从队首移除元素
- `back();`//返回最后一个元素
- `front();`//返回第一个元素
## 大小操作
- `empty();`//判断队列是否为空
- `size();`//返回队列大小
# 示例
```cpp
#include <iostream>
#include <queue>
using namespace std;

//queue容器

//创建类
class Person
{
public:
	string m_name;
	int m_age;

	Person(string name, int age)
	{
		this->m_name = name;
		this->m_age = age;
	}
};

//测试函数
void test01()
{
	//创建容器
	queue<Person> que;
	//添加元素
	Person p1("Jim", 9);
	Person p2("Tom", 45);
	Person p3("Lucy", 27);
	Person p4("Lily", 79);
	Person p5("Jerry", 16);

	que.push(p1);
	que.push(p2);
	que.push(p3);
	que.push(p4);
	que.push(p5);

	cout << "元素数量为： " << que.size() << endl;
	//只要队列不为空，查看队首队尾，出队
	while (!que.empty())
	{
		//查看元素信息
		cout << que.front().m_name << que.front().m_age << endl;
		cout << que.back().m_name << que.back().m_age << endl;
		que.pop();//出队
	}
	cout << "元素数量为： " << que.size() << endl;

}

// 主函数
int main()
{
	test01();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
