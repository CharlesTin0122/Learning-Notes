# 内建函数对象意义
## 概念
- STL内建了一些函数对象
## 分类
- 算术仿函数
- 关系仿函数
- 逻辑仿函数
## 用法
- 这些仿函数所产生的对象，用法和一般函数完全相同
- 使用内建函数对象，需要引入头文件`#include <functional>`
# 算术仿函数
## 功能描述
- 实现四则运算
- 其中`negate`是一元运算，其余为二元运算
## 函数原型
- `template<class T> T plus<T>`            //加法仿函数
- `template<class T> T minus<T>`          //减法仿函数
- `template<class T> T multiplies<T>` //乘法仿函数
- `template<class T> T devides<T>`      //除法仿函数
- `template<class T> T modulus<T>`      //取模仿函数
- `template<class T> T negate<T>`       //相反数仿函数
## 示例
```cpp
#include <iostream>
#include <functional> //内建函数对象头文件
using namespace std;

//算术仿函数


//测试函数
void test01()
{
	//相反数仿函数
	negate<int> n;
	int a = n(50);//对整数进行相反数操作
	cout << a << endl;
	//加法仿函数
	plus<int> p;
	int b = p(10, 20);
	cout << b << endl;
}

// 主函数
int main()
{
	test01();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
# 关系仿函数
## 功能描述
- 实现关系对比
## 函数原型
- `template<class T> bool equal_to<T>`            //等于
- `template<class T> bool not_equal_to<T>`    //不等于
- `template<class T> bool greater<T>`             //大于
- `template<class T> bool greater_equal<T>` //大于等于
- `template<class T> bool less<T>`                  //小于
- `template<class T> bool less_equal<T>`      //小于等于
## 示例
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <functional>
using namespace std;

//关系仿函数

//打印容器函数
void print_vec(const vector<int>& vec)
{
	for (const int& elem : vec)
	{
		cout << elem << " ";
	}
	cout << endl;
}

//测试函数
void test01()
{
	//创建容器
	vector<int> vec = { 1,4,7,3,6,9,2,5,8 };
	//打印容器元素
	cout << "-----排序前-----" << endl;
	print_vec(vec);
	//降序排列,利用内建函数对象greater<int>()
	sort(vec.begin(), vec.end(), greater<int>());
	//打印容器元素
	cout << "-----排序后-----" << endl;
	print_vec(vec);

}

// 主函数
int main()
{
	test01();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
# 逻辑仿函数
## 功能描述
- 实现逻辑运算
## 函数原型
- `template<class T > bool logical_and<T>` //逻辑与：双方为真才为真
- `template<class T > bool logical_or<T>`   //逻辑或：双方为假才为假
- `template<class T > bool logical_not<T>` //逻辑非：取反
## 示例
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <functional>
using namespace std;

//逻辑仿函数

//打印容器函数
void print_vec(const vector<bool>& vec)
{
	for (const int& elem : vec)
	{
		cout << elem << " ";
	}
	cout << endl;
}

//测试函数
void test01()
{
	//创建容器
	vector<bool> vec1 = { 1,0,0,1,1,0,1,0,1 };
	cout << "-----取反前-----" << endl;
	print_vec(vec1);
	//利用仿函数逻辑非取反并放入另一个容器
	vector<bool> vec2;
	//目标容器开辟空间
	vec2.resize(vec1.size());
	//transform搬运容器元素至另一个容器，
	//参数1，2：原容器区间；参数3：新容器插入位置，参数4：处理元素函数
	transform(vec1.begin(), vec1.end(), vec2.begin(), logical_not<bool>());
	cout << "-----取反后-----" << endl;
	print_vec(vec2);

}

// 主函数
int main()
{
	test01();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
