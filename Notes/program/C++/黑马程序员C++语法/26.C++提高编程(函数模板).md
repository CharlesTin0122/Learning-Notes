# 泛型编程
- C++的一种编程思想叫做泛型编程，主要利用的技术就是模板
- C++提供两类模板机制：函数模板和类模板
## 模板的概念
- 模板就是建立通用的模具以提高复用性。
- 模板不可直接使用，他只是一个框架。
- 模板可通用但不是万能的。
## 函数模板
- 函数模板的概念：建立一个通用函数，其函数返回值和参数可以不具体定制，用一个虚拟类型来代表
- 语法：
```cpp
templete<typeanme T>
函数声明及其定义
```
- 解释：
	- template：声明创建模板
	- typename：表明后面的符号是一种数据类型，可以用class代替
	- T：通用的数据类型，名称可替换，通常为大写字母
- 示例：交换数据
```cpp
#include <iostream>
#include <string>
using namespace std;

//模板函数：交换数据
template<typename T> //声明一个模板，告诉编译器这是一个模板，T是一个通用数据类型
void my_swap(T &a, T &b){
	T temp = a;
	a = b;
	b = temp;
}

//测试函数
void test01(){
	int a = 10;
	int b = 20;
	//两种方式使用模板
	//1.自动类型推导，编译器根据提供的参数数据类型自行推导T的数据类型
	// my_swap(a, b);
	//2.显示指定类型，尖括号中指定参数T数据类型
	my_swap<int>(a, b);
	cout << "a:" << a << "\tb:" << b << endl;
}
// 主函数
int main()
{
	// 设置控制台输出为UTF-8编码，以支持中文输出
	system("chcp 65001>nul");
	// 执行测试函数
	test01();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
- 注意事项：
	- 自动类型推导，必须推导出一致的数据类型T，才能使用
	- 模板必须确定出T的数据类型，才可以使用
### 案例：数字排序
```cpp
#include <iostream>
#include <string>
using namespace std;

//实现一个通用的数组排序函数，从大到小选择排序

//模板函数：交换数据
template<typename T> //声明一个模板，告诉编译器这是一个模板，T是一个通用数据类型
void my_swap(T &a, T &b){
	T temp = a;
	a = b;
	b = temp;
}

//模板函数：选择排序算法
template<typename T>
void my_sort(T arr[], int len) {
    for (int i = 0; i < len - 1; i++) { // 循环到倒数第二个元素
        int maxIndex = i; // 假设当前位置是最大元素
        for (int j = i + 1; j < len; j++) { // 寻找未排序部分的最大元素
            if (arr[j] > arr[maxIndex]) { // 如果找到更大的元素
                maxIndex = j; // 更新最大元素的下标
            }
        }
        if (maxIndex != i) { // 如果最大元素的下标不是当前位置
            my_swap(arr[maxIndex], arr[i]); // 交换最大元素和当前位置的元素
        }
    }
}

//模板函数：打印数组
template<typename T>
void pint_arr(T arr[], int len){
	for (int i = 0; i < len; i++){
		cout << arr[i] << " ";
	}
	cout << endl;
}

//测试函数
void test01(){
	char char_arr[] = "badcfe";
	int len = sizeof(char_arr)/sizeof(char_arr[0]);
	my_sort(char_arr, len);
	pint_arr(char_arr, len);
}
void test02(){
	int int_arr[] = {7,5,1,3,9,6,4,2,8};
	int len = sizeof(int_arr)/sizeof(int_arr[0]);
	my_sort(int_arr, len);
	pint_arr(int_arr, len);
}
// 主函数
int main()
{
	// 设置控制台输出为UTF-8编码，以支持中文输出
	system("chcp 65001>nul");
	// 执行测试函数
	test01();
	test02();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
### 普通函数和函数模版的区别
- 普通函数调用时可以发生自动类型转换（隐式类型转换）
- 函数模板调用时，如果利用自动类型推导，不会发生隐式类型转换
- 如果利用显示指定类型的方式，可以发生隐式类型转换
示例：
```cpp
#include <iostream>
#include <string>
using namespace std;

// 普通函数和函数模板的区别

// 普通函数：相加
int nor_add(int a, int b)
{
	return a + b;
}

// 模板函数：相加
template <typename T>
T tem_add(T a, T b)
{
	return a + b;
}

// 测试函数
void test01()
{
	int a = 10;					   // 整型
	char b = 'c';				   // 字符型
	cout << nor_add(a, b) << endl; // 运行时字符型通过ASCII码被自动转换为整型，c->99
	/*1.自动类型推导,无法实现类型转换*/
	// tem_add(a, b);
	/*2.显示指定类型,可以进行类型转换*/
	cout << tem_add<int>(a, b) << endl;
}
// 主函数
int main()
{
	// 设置控制台输出为UTF-8编码，以支持中文输出
	system("chcp 65001>nul");
	// 执行测试函数
	test01();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
> [!INFO] 总结
> 建议使用显示指定类型的方式调用函数模版，自己确定通用类型T.
### 普通函数和函数模版的调用规则
- 如果普通函数和函数模板都可以实现，编译器优先使用普通函数
- 可以用过空模板参数列表<>来强制调用函数模板
- 函数模板也可以发生重载
- 如果函数模板可以产生更好的匹配，编译器优先调用函数模板
示例：
```cpp
#include <iostream>
#include <string>
using namespace std;

// 普通函数和函数模板的调用

// 普通函数
void my_print(int a, int b)
{
	cout << "调用普通函数" << endl;
}

// 模板函数
template <class T>
void my_print(T a, T b)
{
	cout << "调用函数模板" << endl;
	;
}
// 函数模板重载
template <class T>
void my_print(T a, T b, T c)
{
	cout << "调用函数模板重载" << endl;
	;
}

// 测试函数
void test01()
{
	int a = 10;
	int b = 20;
	int c = 30;
	char d = 'a';
	char e = 'b';

	my_print(a, b);	   // 此时默认调用普通函数
	my_print<>(a, b);  // 通过空模板参数列表< >，强制调用函数模版
	my_print(a, b, c); // 通过参数调用函数模板重载
	my_print(d, e);	   // 如果函数模板可以产生更好的参数匹配，编译器优先调用函数模板
}
// 主函数
int main()
{
	// 设置控制台输出为UTF-8编码，以支持中文输出
	system("chcp 65001>nul");
	// 执行测试函数
	test01();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
> [!INFO] 总结
> 既然提供了函数模板，最好就不用提供普通函数，否则容易出现二义性。
## 模板的局限性
- 模板的通用型并不是万能的
例如：
```cpp
template<class T>
void f(T a, T b)
{
    a = b;
}
```
在上述代码中，如果传入的a和b是一个数组，数组之间无法赋值，就无法实现了。

再例如：
```cpp
template<class T>
void f(T a, T b)
{
    if (a > b) {...}
}
```
在上述代码中，如果T的数据类型传入的是Person这样的自定义类型，也无法正常运行。

因此C++为了解决这类问题，提供模板的重载，可以为这些特定的类型提供具体化的模板。
示例：
```cpp
#include <iostream>
#include <string>
using namespace std;
//模板的局限性

//定义一个类
class Person
{
public:
	string m_name;
	int m_age;
	Person(string name, int age)
	{
		this->m_name = name;
		this->m_age = age;
	}
};
//普通函数模板
template <class T>
bool my_compare(T &a, T &b)
{
	if (a == b)
	{
		return true;
	}
	else
	{
		return false;
	}
}
//具体化函数模版，以template <>开头，通过指定名称；来指出类型。集体化优先于常规模板
template <>
bool my_compare(Person &p1, Person &p2)
{
	if (p1.m_name == p2.m_name && p1.m_age == p2.m_age)
	{
		return true;
	}
	else
	{
		return false;
	}
}
//测试函数
void test01()
{
	int a = 10;
	int b = 20;
	bool res = my_compare(a, b);
	if (res)
	{
		cout << "a = b" << endl;
	}
	else
	{
		cout << "a != b" << endl;
	}
}

void test02()
{
	Person p1("Tom", 10);
	Person p2("Tom", 10);
	bool res = my_compare(p1, p2);
	if (res)
	{
		cout << "p1 = p2" << endl;
	}
	else
	{
		cout << "p1 != p2" << endl;
	}
}
// 主函数
int main()
{
	// 设置控制台输出为UTF-8编码，以支持中文输出
	system("chcp 65001>nul");
	// 执行测试函数
	test01();
	test02();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
> [!INFO] 总结
> 1. 利用具体化模板可以解决自定义类型的通用化
> 2. 学习模板不是为了写模板，而是在STL中能够运用系统提供的模板。
