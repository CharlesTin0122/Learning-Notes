# 多态的基本概念
多态是C++面向对象的三大特征之一
多态分为两类：
- 静态多态：**函数重载**和**运算符重载**属于静态多态，复用函数名
- 动态多态：**派生类**和**虚函数**实现的运行时多态
静态多态和动态多态的区别：
- 静态多态的函数地址早绑定 - 编译阶段确定函数地址
- 动态多态的函数地址晚绑定 - 运行阶段确定函数地址
动态多态满足条件
- 有继承关系
- 子类重写父类的虚函数（函数返回值类型，函数名称，参数列表完全相同）
动态多态的使用
- 父类的引用或指针指向子类的对象
示例：
```cpp
#include<iostream>
#include<string>
using namespace std;
//面相对象特性——多态

//构建基类
class Animal{
public:
	//虚函数，
	virtual void speak() {
		cout << "bbbbbb" << endl;
	}
};

//构建子类
class Cat: public Animal {
public:
	void speak() {
		cout << "meow" << endl;
	}
};
class Dog : public Animal {
public:
	void speak() {
		cout << "woof" << endl;
	}
};

//测试函数
//地址早绑定，在编译阶段确定函数地址为父类speak方法
//如果想让猫叫，那么这个函数地址不能早绑定，需要在运行阶段进行绑定。父类方法设为虚函数。
void do_speak(Animal &animal){ // Animal &animal = cat_1,父类的引用和指针可以直接指向子类对象
	animal.speak();
}
//测试函数
void test01() {
	Cat cat_1;
	Dog dog_1;
	do_speak(cat_1);
	do_speak(dog_1);
}
//主函数
int main(){
	test01();

	system("pause");
	return 0;
}
```
## 虚函数
定义：
虚函数是C++语言中实现多态性的一种重要机制。它允许子类重写基类中定义的函数，从而使程序能够根据对象的实际类型调用正确的方法（对象调用自身的重写方法，而不是父类方法）。

声明：
虚函数的声明使用`virtual`关键字。例如，以下代码声明了一个名为`print`的虚函数：
```cpp
class Animal {
public:
  virtual void print(){};
};

```
在上面的代码中，`print`函数被声明为虚函数。子类可以重写基类中的虚函数。

原理：
当使用基类指针或引用调用虚函数时，实际调用的函数是与该对象实际类型相关联的函数。这是由虚函数表（vtable）实现的。每个虚函数表都包含指向该类中所有虚函数的指针。当使用基类指针或引用调用虚函数时，编译器会首先查找虚函数表，然后根据对象的实际类型调用相应的函数。
1. 当父类中创建一个虚函数时，父类中会生成一个**虚函数指针**vfptr(virtual function pointer)，此指针指向一个**虚函数表**vftable(virtual function table)。
2. 虚函数表vftable内部记录虚函数地址(&Animal::speak)。
3. 如果子类没有重写虚函数，则子类完全继承虚函数，虚函数指针和虚函数表(&Animal::speak)。
4. 如果子类重写虚函数，子类会将虚函数表中的内容覆盖，替换成子类的虚函数地址(& Cat::speak)。
5. 当父类指针或者引用指向子类对象时(Animal &animal_1 = cat;)，执行子类对象方法(cat.speak())。

优点：
- 提高了代码的可重用性。基类中的虚函数可以由派生类重写，从而使代码能够适应不同的情况。
- 提高了代码的可维护性。如果需要更改基类中的虚函数，则只需要更改基类中的定义，而无需修改派生类中的代码。
- 提高了程序的灵活性。虚函数允许程序根据对象的实际类型选择不同的行为。
缺点：
- 增加了代码的复杂性。虚函数表和虚函数指针的使用增加了代码的复杂性。
- 降低了程序的性能。由于需要查找虚函数表，因此调用虚函数比调用普通函数要慢一些。
总的来说，虚函数是C++语言中一种非常强大的机制，它可以提高代码的可重用性、可维护性和灵活性。但是，虚函数也有一些缺点，例如增加了代码的复杂性和降低了程序的性能。在使用虚函数时，需要权衡这些利弊。
# 多态案例1.计算器类
案例描述：
- 分别利用普通写法和多态技术，设计实现两个操作数进行运算的计算器类
多态的优点
- 代码组织结构清晰
- 可读性强
- 利于代码的扩展和维护
普通写法：
```cpp
#include<iostream>
#include<string>
using namespace std;
//计算器类

class Calculator{
public:
	int m_num1;
	int m_num2;

	int get_result(string oper) {
		if (oper == "+") {
			return m_num1 + m_num2;
		}
		else if (oper == "-") {
			return m_num1 - m_num2;
		}
		else if (oper == "*") {
			return m_num1 * m_num2;
		}
	}
};

//测试函数
void test01() {
	Calculator cal;
	cal.m_num1 = 10;
	cal.m_num2 = 20;
	cout << "num1 + num2 = " << cal.get_result("+") << endl;
	cout << "num1 - num2 = " << cal.get_result("-") << endl;
	cout << "num1 * num2 = " << cal.get_result("*") << endl;
}
//主函数
int main(){
	test01();

	system("pause");
	return 0;
}
```
多态写法：
```cpp
#include<iostream>
#include<string>
using namespace std;
//计算器类

//实现计算器抽象类
class AbstractCalculator {
public:
	int m_num1;
	int m_num2;

	virtual int get_result() {
		return 0;
	}
};
//加法计算器类
class AddCalculator :public AbstractCalculator {
public:
	int get_result() {
		return m_num1 + m_num2;
	}
};
//减法计算器类
class SubCalculator :public AbstractCalculator {
public:
	int get_result() {
		return m_num1 - m_num2;
	}
};
//乘法计算器类
class MulCalculator :public AbstractCalculator {
public:
	int get_result() {
		return m_num1 * m_num2;
	}
};

//测试函数
void test01() {
	//执行加法运算
	//多态使用条件：父类指针或引用指向子类对象
	AbstractCalculator* ac = new AddCalculator;
	ac->m_num1 = 10;
	ac->m_num2 = 20;
	//输出结果
	cout << "num1 + num2 = " << ac->get_result() << endl;
	//释放堆区数据
	delete ac;
	// 执行减法运算,
	// 堆区的数据被释放了，但是堆区数据的类型没有改变，还是AbstractCalculator类指针
	ac = new SubCalculator;
	ac->m_num1 = 10;
	ac->m_num2 = 20;
	//输出结果
	cout << "num1 - num2 = " << ac->get_result() << endl;
	//释放堆区数据
	delete ac;
	// 执行乘法运算,
	// 堆区的数据被释放了，但是堆区数据的类型没有改变，还是AbstractCalculator类指针
	ac = new MulCalculator;
	ac->m_num1 = 10;
	ac->m_num2 = 20;
	//输出结果
	cout << "num1 * num2 = " << ac->get_result() << endl;
	//释放堆区数据
	delete ac;
}
//主函数
int main(){
	test01();

	system("pause");
	return 0;
}
```
