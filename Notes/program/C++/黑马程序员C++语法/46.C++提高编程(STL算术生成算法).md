注意：
- 算术生成算法属于小型算法，要包含`#include <muneric>`头文件
算法简介：
- `accumulate();`//计算容器元素累计总和
- `fill();`//向容器中添加元素
## accumulate
### 功能描述
- 计算区间内容器元素累计总和
### 函数原型
- `accumulate(begin, end, val);`
	- 参数1，2：容器区间
	- 参数3：起始累加值
## 示例
```cpp
#include <iostream>
#include <vector>
#include <numeric>
using namespace std;

//STL算法 accumulate


//测试函数
void test01()
{
	vector<int> v = { 1,4,7,2,7,8 };//容器
	//累加容器内所有元素,参数1，2：容器区间；参数3：起始累加值
	int tatol = accumulate(v.begin(), v.end(), 0);
	cout << tatol << endl;
}

// 主函数
int main()
{
	test01();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
## fill
### 功能描述
- 向容器中填充指定元素
### 函数原型
- `fill(begin, end, val);`
	- 参数1，2：容器区间
	- 参数3：要填充的值
## 示例
```cpp
#include <iostream>
#include <vector>
#include <numeric>
using namespace std;

//STL算法 fill


//测试函数
void test01()
{
	vector<int> v = { 1,4,7,2,7,8 };//容器
	//容器内元素填充为999
	fill(v.begin(), v.end(), 999);
	//打印
	for (const int& elem : v)
	{
		cout << elem << endl;
	}
}

// 主函数
int main()
{
	test01();
	// 按任意键继续
	system("Pause");
	return 0;
}
```
