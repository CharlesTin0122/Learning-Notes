# 常用集合算法
## 算法简介
- `set_intersection(begin1, end1, begin2, end2, dest);`//求两个容器的交集，返回交集最后元素的下一位迭代器
- `set_union(begin1, end1, begin2, end2, dest);`//求两个容器的并集，返回并集最后元素的下一位迭代器
- `set_diffrence(begin1, end1, begin2, end2, dest);`//求两个容器的差集，返回差集最后元素的下一位迭代器
## 原理
- 交集：两个容器中重复的元素
- 并集：包含两个集合中所有元素的集合
- 差集：差集是一个集合中包含的元素但不在另一个集合中的元素的集合。
### 交集（Intersection）

交集是两个集合中共同包含的元素的集合。若 AAA 和 BBB 是两个集合，则它们的交集记作 A∩BA \cap BA∩B。

**定义**： A∩B={x∣x∈A 且 x∈B}A \cap B = \{ x \mid x \in A \text{ 且 } x \in B \}A∩B={x∣x∈A 且 x∈B}

**示例**： 若 A = \{1, 2, 3, 4\}，B = \{3, 4, 5, 6\}，则 A∩B={3,4}A \cap B = \{3, 4\}A∩B={3,4}。

### 并集（Union）

并集是包含两个集合中所有元素的集合（不包括重复元素）。若 AAA 和 BBB 是两个集合，则它们的并集记作 A∪BA \cup BA∪B。

**定义**： A∪B={x∣x∈A 或 x∈B}A \cup B = \{ x \mid x \in A \text{ 或 } x \in B \}A∪B={x∣x∈A 或 x∈B}

**示例**： 若 A = \{1, 2, 3, 4\}，B = \{3, 4, 5, 6\}，则 A∪B={1,2,3,4,5,6}A \cup B = \{1, 2, 3, 4, 5, 6\}A∪B={1,2,3,4,5,6}。

### 差集（Difference）

差集是一个集合中包含的元素但不在另一个集合中的元素的集合。若 AAA 和 BBB 是两个集合，则它们的差集记作 A−BA - BA−B 或 A∖BA \setminus BA∖B。

**定义**： A−B={x∣x∈A 且 x∉B}A - B = \{ x \mid x \in A \text{ 且 } x \notin B \}A−B={x∣x∈A 且 x∈/B}

**示例**： 若 A = \{1, 2, 3, 4\}，B = \{3, 4, 5, 6\}，则A - B = \{1, 2\}，而 B - A = \{5, 6\}。
## 示例
```cpp
#include <iostream>
#include <set>
#include <algorithm>
#include <iterator>

int main() {
    std::set<int> A = {1, 2, 3, 4};
    std::set<int> B = {3, 4, 5, 6};

    // 交集
    std::set<int> intersection;
    //std::inserter()用于在容器中插入元素的一个插入迭代器，向容器中插入元素。
    //参数1：要插入元素的容器；参数2：插入位置的迭代器。
    //返回一个 std::insert_iterator，这个迭代器包装了给定的容器和插入位置。
    //通过这个迭代器插入的所有元素都会被插入到容器中的指定位置。每次插入后，插入位置迭代器会自动递增。
    std::set_intersection(A.begin(), A.end(), B.begin(), B.end(),
                          std::inserter(intersection, intersection.begin()));

    std::cout << "Intersection: ";
    for (int elem : intersection) {
        std::cout << elem << " ";
    }
    std::cout << std::endl;

    // 并集
    std::set<int> union_set;
    std::set_union(A.begin(), A.end(), B.begin(), B.end(),
                   std::inserter(union_set, union_set.begin()));

    std::cout << "Union: ";
    for (int elem : union_set) {
        std::cout << elem << " ";
    }
    std::cout << std::endl;

    // 差集 A - B
    std::set<int> difference;
    std::set_difference(A.begin(), A.end(), B.begin(), B.end(),
                        std::inserter(difference, difference.begin()));

    std::cout << "Difference (A - B): ";
    for (int elem : difference) {
        std::cout << elem << " ";
    }
    std::cout << std::endl;

    return 0;
}

```
