# 概念
C++中的智能指针是用于自动管理动态分配内存的一种工具，旨在提高内存管理的安全性和效率。智能指针可以自动释放所指向的对象，防止内存泄漏和悬空指针。C++标准库提供了几种智能指针，主要包括：

1. **`std::unique_ptr`**：
   - 独占式智能指针，表示某个对象的唯一所有权。
   - 不可复制，只能移动，确保每个对象只能有一个`unique_ptr`指向。
   - 当`unique_ptr`超出作用域时，它会自动释放所管理的对象。

   ```cpp
   #include <memory>

   void example() {
       std::unique_ptr<int> ptr = std::make_unique<int>(10);
       // 使用ptr
   } // ptr超出作用域，自动释放
   ```

2. **`std::shared_ptr`**：
   - 共享式智能指针，允许多个`shared_ptr`指向同一个对象。
   - 使用引用计数来管理所有权，最后一个引用被销毁时，才会释放对象。
   - 适合多个对象共享同一个资源的情况。

   ```cpp
   #include <memory>

   void example() {
       std::shared_ptr<int> ptr1 = std::make_shared<int>(20);
       std::shared_ptr<int> ptr2 = ptr1; // 共享所有权
   } // ptr1和ptr2超出作用域，自动释放
   ```

3. **`std::weak_ptr`**：
   - 用于解决`shared_ptr`之间的循环引用问题。
   - 不增加引用计数，因此不会影响对象的生命周期。
   - 可用来观察`shared_ptr`所指向的对象，但不拥有它。

   ```cpp
   #include <memory>

   void example() {
       std::shared_ptr<int> ptr1 = std::make_shared<int>(30);
       std::weak_ptr<int> weakPtr = ptr1; // 观察ptr1

       if (auto sp = weakPtr.lock()) { // 检查是否还有效
           // 使用sp
       }
   } // ptr1超出作用域，自动释放
   ```

### 总结
- 智能指针通过 RAII（资源获取即初始化）原则简化了内存管理，减少了内存泄漏和指针错误的风险。
- 应根据具体需求选择合适的智能指针，`unique_ptr`用于独占所有权，`shared_ptr`用于共享所有权，`weak_ptr`用于避免循环引用。

# 实现简单的智能指针
```cpp
#include <iostream>

// 实现简单的智能指针，用面向对象包装裸指针，利用栈上的对象出作用域自动析构的特征，可以做到资源的自动释放
template <typename T>
class SmartPtr
{
public:
    // 构造函数
    SmartPtr(T *ptr = nullptr) : _ptr(ptr) { std::cout << "SmartPtr()" << std::endl; }
    // 析构函数
    ~SmartPtr()
    {
        std::cout << "~SmartPtr()" << std::endl;
        delete _ptr;
    }
    // 解引用*运算符重载，必须返回引用，因为要修改内存上指针指向的值
    T &operator*()
    {
        std::cout << "operator*()" << std::endl;
        return *_ptr;
    }
    // 指向符->重载，直接返回底层指针
    T *operator->()
    {
        std::cout << "operator->()" << std::endl;
        return _ptr;
    }

private:
    T *_ptr;
};

// Test 类
class Test
{
public:
    void func() { std::cout << "Test::func()" << std::endl; }
};
// 主函数
int main()
{
    // 裸指针,必须手动开辟，手动释放
    int *p = new int(10);
    *p = 30;
    delete p;
    // 智能指针,出作用域自动析构
    SmartPtr<int> p1(new int());
    // 解引用
    *p1 = 20;

    SmartPtr<Test> p2(new Test());
    // p2解引用并调用func()方法
    (*p2).func();
    // 指向符
    p2->func();

    return 0;
}
```
# 问题
- 上述自定义的智能指针能否定义在堆上，`SmartPtr<int> *p = new SmartPtr<int> (new int());`，用智能指针 指针指向堆上的智能指针。
	- 不能，因为
		- `SmartPtr<int> *p`实际上是一个智能指针类型的裸指针，必须使用`delete p`来释放。
		- 上述自定义的智能指针是利用栈上的对象出作用域自动析构的特征，不能放在堆上。
