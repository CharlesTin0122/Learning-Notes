# 分类
- shared_ptr：强智能指针，可以改变资源的引用计数
- weak_ptr：弱智能指针，不会改变资源的引用计数
- weak_ptr观察shared_ptr，shared_ptr观察堆内存资源
- weak_ptr用来解决shared_ptr循环引用的问题
# 强智能指针循环引用是什么？有何后果？
- 强智能指针（如 `std::shared_ptr`）循环引用是指两个或多个对象互相持有对方的智能指针引用，从而形成循环。这种情况通常会导致引用计数无法降到零，最终导致内存泄漏。
- **内存泄漏**：因为互相引用，引用计数不会降到零，导致内存无法被释放，最终造成内存泄漏。
- **资源浪费**：长时间占用内存可能导致资源的浪费，影响程序的性能，尤其在长时间运行的程序中。
```cpp
#include <iostream>
#include <memory>

// 循环引用问题
class B;
class A
{
public:
    A() { std::cout << "A()" << std::endl; }
    ~A() { std::cout << "~A()" << std::endl; }
    // A类型中指向B类型资源的智能指针
    std::shared_ptr<B> _ptrB;
};
class B
{
public:
    B() { std::cout << "B()" << std::endl; }
    ~B() { std::cout << "~B()" << std::endl; }
    // A类型中指向B类型资源的智能指针
    std::shared_ptr<A> _ptrA;
};
// 主函数
int main()
{
    std::shared_ptr<A> ptr_A(new A());//构造对象，引用计数加一
    std::shared_ptr<B> ptr_B(new B());//构造对象，引用计数加一
    // ptr_A对象的成员变量_ptrB指向ptr_B对象
    ptr_A->_ptrB = ptr_B;//调用运算符重载，引用计数加一
    // ptr_B对象的成员变量_ptrA指向ptr_A对象
    ptr_B->_ptrA = ptr_A;//调用运算符重载，引用计数加一
    /*
     * 此时ptr_A， ptr_B两个对象的引用计数均为2
     * 离开作用域时，引用计数均减一，为1。达不到析构对象的条件：引用计数为0.
     * 造成堆上的资源无法释放的问题。
     */
    std::cout << ptr_A.use_count() << std::endl;
    std::cout << ptr_B.use_count() << std::endl;
    /*结果：A(); B(); 2; 2 */
    return 0;
}

```
在这个例子中：

- 一个 `A` 对象持有一个指向 `B` 对象的 `shared_ptr`。
- 一个 `B` 对象持有一个指向 `A` 对象的 `shared_ptr`。

如果创建了 `A` 和 `B` 的实例并且互相引用，就会形成循环引用。

# 解决方案
- 使用 `std::weak_ptr` 来打破循环引用。`std::weak_ptr` 不增加引用计数，因此不会阻止对象的销毁。
- 定义对象的时候使用强智能指针`shared_ptr`；引用对象的时候使用弱智能指针`std::weak_ptr`。
```cpp
#include <iostream>
#include <memory>

// 循环引用问题
class B;
class A
{
public:
    A() { std::cout << "A()" << std::endl; }
    ~A() { std::cout << "~A()" << std::endl; }
    void testA() { std::cout << "A::testA()" << std::endl; }
    // A类型中指向B类型资源的智能指针,使用弱智能指针
    std::weak_ptr<B> _ptrB;
};
class B
{
public:
    B() { std::cout << "B()" << std::endl; }
    ~B() { std::cout << "~B()" << std::endl; }
    void func()
    {
        // 弱智能指针无法访问调用函数
        //_ptrA->testA();
        // 要使用弱智能指针，要将其提升成强智能指针，才能用来访问资源
        std::shared_ptr<A> ps = _ptrA.lock();
        if (ps) { ps->testA(); }
    }
    // A类型中指向B类型资源的智能指针,使用弱智能指针
    std::weak_ptr<A> _ptrA;
};
// 主函数
int main()
{
    std::shared_ptr<A> ptr_A(new A());
    std::shared_ptr<B> ptr_B(new B());
    // ptr_A对象的成员变量_ptrB指向ptr_B对象
    ptr_A->_ptrB = ptr_B;
    // ptr_B对象的成员变量_ptrA指向ptr_A对象
    ptr_B->_ptrA = ptr_A;
    /*
     * 此时ptr_A， ptr_B两个对象的引用计数均为2
     * 离开作用域时，引用计数均减一，为1。达不到析构对象的条件：引用计数为0.
     * 造成堆上的资源无法释放的问题。
     */
    std::cout << ptr_A.use_count() << std::endl;
    std::cout << ptr_B.use_count() << std::endl;
    /*结果：A(); B(); 2; 2 */

    ptr_B->func();

    return 0;
}
```

# 要点
- 弱智能指针只是一个观察者，智能观察资源，不能访问和调用资源。
-  弱智能指针没有赋值运算符重载`operator=()`和解引用运算符重载函数`operator=*()`
- 如果要使用弱智能指针调用方法和属性，需要将弱智能指针提升为强智能指针`std::shared_ptr<A> ps = _ptrA.lock();`
