# 概念
- 在智能指针 unique_ptr的底层析构函数中，都是调用了一个删除器函数对象`deletor()`
	- `~unique_ptr(){调用函数对象 deletor(ptr);}`
- 删除器函数对象`deletor()`，C++ 标准库默认删除器函数对象是这样的
```cpp
template<typename T>
class default_delete
{
public:
	void operator()(T *ptr)
	{
		delete ptr;
	}
};
```
- 他默认删除指针的方式是使用delete关键字。但是很多数据的删除不一定要使用delete。比如数组要使用`delete[]`，或者其他文件类型。因此我们要自定义删除器。
# 案例
```cpp
#include <cstdio>
#include <iostream>
#include <memory>

// 自定义数组删除器
template <typename T>
class MyArrayDeletor
{
public:
    void operator()(T *ptr) const
    {
        std::cout << " MyArrayDeletor()" << std::endl;
        delete[] ptr;
    }
};
// 自定义文件删除器
template <typename T>
class MyFileDeletor
{
public:
    void operator()(T *ptr) const
    {
        std::cout << " MyFileDeletor()" << std::endl;
        fclose(ptr);
    }
};
// 主函数
int main()
{
    // 定义强智能指针指向堆上的数组,添加删除器模板参数
    std::unique_ptr<int, MyArrayDeletor<int>> p1(new int[100]);
    // 定义强智能指针指向文件类型,添加删除器模板参数
    std::unique_ptr<FILE, MyFileDeletor<FILE>> p2(fopen("data.txt", "w"));

    return 0;
}
```
# 优化
- 可以使用`function`函数对象类型和`lambda`表达式来简化代码
```cpp
/* 定义强智能指针指向堆上的数组,添加lambda表达式删除器
 * std::function<void(int *)，函数对象类型，返回值是void,参数是int *
 */
std::unique_ptr<int, std::function<void(int *)>> p1(
	// 堆区创建数组，返回指针
	new int[100],
	// lambda表达式
	[](int *p) -> void
	{
		std::cout << " Call Lambda Release Array" << std::endl;
		delete[] p;
	});

std::unique_ptr<FILE, std::function<void(FILE *)>> p2(
	// 堆区打开文件，返回指针
	fopen("data.txt", "w"),
	// lambda表达式
	[](FILE *p) -> void
	{
		std::cout << " Call Lambda Release File" << std::endl;
		fclose(p);
	});
```
