在 C++11 中，`emplace` 方法是 STL 容器的一项新特性，旨在提高效率和简化代码。与传统的 `insert` 或 `push_back` 等方法不同，`emplace` 允许直接在容器内部构造元素，而无需先创建临时对象然后再复制或移动到容器中。

### 主要特性

1. **减少临时对象**：`emplace` 通过直接构造对象，避免了创建临时对象以及复制或移动操作，提升了性能。
2. **完美转发（Perfect Forwarding）**：`emplace` 使用模板和完美转发，可以接受一组参数来直接构造对象。

### 适用的容器

- **序列式容器**：如 `std::vector`, `std::deque`, `std::list`，提供 `emplace_back` 和 `emplace`。
- **关联容器**：如 `std::set`, `std::map`，提供 `emplace`。
- **无序容器**：如 `std::unordered_set`, `std::unordered_map`，提供 `emplace`。

### 使用方法

以下是 `emplace` 方法的用法及其相对于传统方法的优势。

#### 1. 在序列容器中的用法

- `emplace_back` 用于在容器尾部直接构造元素。
- `emplace` 可用于在指定位置构造元素。

**示例代码：**

```cpp
#include <iostream>
#include <vector>
#include <string>

struct Person {
    std::string name;
    int age;

    Person(const std::string& n, int a) : name(n), age(a) {
        std::cout << "Constructed: " << name << std::endl;
    }
};

int main() {
    std::vector<Person> people;

    // 使用 emplace_back 直接构造对象
    people.emplace_back("Alice", 30); // 在容器尾部构造 Person 对象
    people.emplace_back("Bob", 25);

    return 0;
}
```

**优势：**

- 避免了临时对象的创建和拷贝。

#### 2. 在关联容器中的用法

关联容器的 `emplace` 方法用于直接插入键值对或元素。

**示例代码：**

```cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, int> scores;

    // 使用 emplace 插入键值对
    scores.emplace("Alice", 95);
    scores.emplace("Bob", 88);

    // 遍历输出
    for (const auto& [name, score] : scores) {
        std::cout << name << ": " << score << std::endl;
    }

    return 0;
}
```

**优势：**

- 通过完美转发，避免创建临时 `std::pair` 对象。

#### 3. 在无序容器中的用法

类似于关联容器的 `emplace`。

**示例代码：**

```cpp
#include <iostream>
#include <unordered_map>
#include <string>

int main() {
    std::unordered_map<std::string, int> ages;

    // 使用 emplace 插入元素
    ages.emplace("Charlie", 22);
    ages.emplace("Diana", 28);

    for (const auto& [name, age] : ages) {
        std::cout << name << ": " << age << std::endl;
    }

    return 0;
}
```

### 对比 `insert` 和 `emplace`

|特性|`insert`|`emplace`|
|---|---|---|
|插入方式|需要现有对象或 `std::pair`|直接构造对象或键值对|
|性能|可能涉及拷贝或移动|无拷贝或移动，性能更高|
|参数转发|不支持完美转发|支持完美转发|

### 注意事项

1. **避免过度使用**：虽然 `emplace` 性能较高，但在不需要直接构造对象的情况下，`insert` 更加直观。
2. **构造失败的回滚**：`emplace` 在构造失败时，容器状态保持一致，但需要确保构造函数本身不会抛出异常。

### 总结

C++11 中的 `emplace` 方法是为了简化代码并提高性能。它在许多情况下避免了临时对象的创建，同时通过完美转发提供了更多的灵活性。建议在需要直接构造对象时优先使用 `emplace`，尤其是在性能敏感的场景下。
# 案例
```cpp
#include <iostream>
#include <map>
#include <utility>
#include <vector>

class Test
{
  public:
    Test(int a) { std::cout << "Test(int)" << std::endl; }                 // 构造函数
    Test(int a, int b) { std::cout << "Test(int, int)" << std::endl; }     // 构造函数
    Test(const Test &) { std::cout << "Test(const Test &)" << std::endl; } // 拷贝构造函数
    Test(Test &&) { std::cout << "Test(Test &&)" << std::endl; }           // 移动构造函数

    ~Test() { std::cout << "~Test()" << std::endl; } // 析构函数
};

int main()
{

    Test t1(10);

    std::vector<Test> vec;
    vec.reserve(100);

    std::cout << "----------------------------" << std::endl;
    // 直接插入对象，调用拷贝构造函数，两者没有区别
    vec.push_back(t1);
    vec.emplace_back(t1);
    // 插入临时对象，调用移动构造函数，两者也没有区别
    vec.push_back(Test(20));
    vec.emplace_back(Test(20));
    std::cout << "----------------------------" << std::endl;
    // 给emplace函数传入对象构造所需要的参数，直接在容器底层构造对象。
    vec.emplace_back(20);
    vec.emplace_back(30, 40);
    std::cout << "----------------------------" << std::endl;
    std::map<int, std::string> m;
    m.insert(std::make_pair(10, "hello")); // 创建临时对象pair，调用移动构造函数
    m.emplace(10, "hello");                // 直接在容器底层调用构造函数创建对象
}
```
