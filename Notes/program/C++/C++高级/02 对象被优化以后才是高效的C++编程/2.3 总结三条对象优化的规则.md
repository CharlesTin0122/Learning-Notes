# 对象优化的规则

- 函数参数传递过程中，对象优先按引用传递，不要用值传递。可以减少一次对象的拷贝构造和析构。
- 当函数返回对象的时候，应该优先返回一个临时对象，而不是返回一个定义过的对象。临时对象被拷贝构造时会被编译器优化，Test t = Test(other) -> Test t(other)，可以减少一次对象的拷贝构造和析构。
- 函数返回值被对象接受的时候，优先按照初始化的方式接收 `Test t2 = getObj(t1); `，不要按先定义，再赋值的方式接收。这样，临时对象被拷贝构造时会被编译器优化，可以减少一次对象的拷贝构造和析构。
# 示例
```cpp
#include <iostream>

// 测试类
class Test
{
public:
    Test(int val = 5) : ma(val) { std::cout << "Test(int)" << std::endl; }
    Test(const Test &other) : ma(other.ma) { std::cout << "Test(other)" << std::endl; }
    Test &operator=(const Test &other)
    {
        std::cout << "operator=" << std::endl;
        ma = other.ma;
        return *this;
    }
    ~Test() { std::cout << "~Test()" << std::endl; }

    int getData() const { return ma; }

private:
    int ma;
};

Test getObj(Test &t) // 参数按引用传递，减少一次对象的拷贝构造和析构
{
    int val = t.getData();

    /* 返回临时对象，在main函数栈帧拷贝构造一个新临时对象
     * 编译器会做优化，Test t = Test(other) -> Test t(other), return Test(val);这个临时对象不会产生,也不用析构。
     * 减少一次构造和析构
     */
    return Test(val);
}

// 主函数
int main()
{
    Test t1; // Test()
    // main栈帧上的临时对象被拷贝构造初始化新对象，编译器优化，Test t2(val),临时对象不再产生
    Test t2 = getObj(t1); // Test()

    return 0;
}

```
