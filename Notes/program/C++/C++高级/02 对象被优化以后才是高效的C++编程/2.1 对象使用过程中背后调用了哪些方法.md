# 对于临时对象的优化
- 在C++中，临时对象是指在表达式中创建的对象，没有名称，生存周期是所在的语句。
### 1. 定义

临时对象是在表达式中创建的对象，通常由如下情况产生：

- 通过函数返回值创建（特别是返回类型为对象的函数）。
- 通过类型转换（如隐式转换）生成。
- 在表达式中直接使用（如 `Test(50)`）。

### 2. 生命周期

- **创建与销毁**：临时对象的生命周期开始于它的创建，结束于包含它的完整表达式的结束。在这个过程中，临时对象会被自动析构。
- **延长生命周期**：如果临时对象绑定到`const`引用，临时对象的生命周期会延长至引用的作用域结束。
# 案例
案例1
```cpp
#include <iostream>

// 测试类
class Test
{
public:
    Test(int a = 10) : ma(a) { std::cout << "Test()" << std::endl; }
    Test(const Test &other) : ma(other.ma) { std::cout << "Test(other)" << std::endl; }
    Test &operator=(const Test &other)
    {
        std::cout << "operator=" << std::endl;
        ma = other.ma;
        return *this;
    }
    ~Test() { std::cout << "~Test()" << std::endl; }

private:
    int ma;
};

// 主函数
int main()
{
    Test t1; // 调用构造函数

    Test t2(t1);  // 调用拷贝构造函数
    Test t3 = t1; // 定义对象，仍然是调用拷贝构造函数

    Test t4;
    t4 = t1; // 调用=运算符重载

    /* 显示生成临时对象
     * 显示生成临时对象，先调用构造函数Test(30)生成临时对象，没有名称，生存周期是所在的语句。
     * 再调用运算符重载t4.operator=()，进行赋值。语句运行结束，临时对象析构。
     */
    t4 = Test(30);
    /* 显示生成临时对象
     * 将int类型数值30强转为Test类型，编译器要看Test类有没有带整形参数的构造函数，调用构造函数Test(int),生成临时对象
     * 再调用运算符重载t4.operator=()，进行赋值。语句运行结束，临时对象析构。
     */
    t4 = (Test)30;
    // 隐示生成临时对象，同上
    t4 = 30;

    /* 编译器对于对象构造的优化：用临时对象Test(20)生成新对象的时候，临时对象不再生成，而是直接构造新对象
     * 调用构造函数 等同于Test t5(20).
     */
    Test t5 = Test(20);
    std::cout << "-----------------------------------------------------" << std::endl;

    // 指针指向临时对象，临时对象语句运行完毕后析构，指针失效。是错误的。
    //Test *ptr = &Test(40);

    /* 常引用指向临时对象，这一句是合法的，因为它利用了“延长生存期”的特性。
     * 当你创建一个临时对象 Test(50)时，C++会将这个临时对象的生命周期延长到引用 ref 的生命周期结束。
     * 这意味着，在 ref 被使用期间，临时对象不会被析构。
     * 只有使用 const 关键字的引用（如 const Test &ref）才能合法地绑定到临时对象上，而非常量引用则不行。
     */
    const Test &ref = Test(50);

    return 0;
}
```

案例2
```cpp
#include <iostream>

// 测试类
class Test
{
public:
    Test(int a = 5, int b = 5) : ma(a), mb(b) { std::cout << "Test()" << std::endl; }
    Test(const Test &other) : ma(other.ma), mb(other.mb) { std::cout << "Test(other)" << std::endl; }
    Test &operator=(const Test &other)
    {
        std::cout << "operator=" << std::endl;
        ma = other.ma;
        mb = other.mb;
        return *this;
    }
    ~Test() { std::cout << "~Test()" << std::endl; }

private:
    int ma;
    int mb;
};

Test t1(10, 10); // 1. t1先构造Test(int,int)，全局变量在main()函数之前构造
// 主函数
int main()
{
    Test t2(20, 20);               // 3.Test(int,int)
    Test t3 = t2;                  // 4.Test(other)
    static Test t4 = Test(20, 30); // 5.static Test t4(20, 30),编译器优化，没有生成临时对象

    t2 = Test(40, 40); // 6.Test(int,int), operator=, ~Test()
    //","表达式，只记录最后一个参数。相当于(Test)50;将50参数传给ma,mb还是默认值5
    t2 = (Test)(30, 50); // 7.Test(50, 5),operator=, ~Test()
    t2 = 60;             // 8.Test(60, 5), , operator=, ~Test()

    // 在堆上的对象不是临时对象，delete的时候才析构
    Test *p1 = new Test(70, 70); // 9.Test(int,int)
    Test *p2 = new Test[2];      // 10.Test(int,int)，Test(int,int)
    // Test *p3 = &Test(80, 80);    // 指针指向临时对象。错误
    const Test &p4 = Test(90, 90); // 11.Test(int,int)

    delete p1;   // 12. ~~Test()
    delete[] p2; // 13. ~~Test(),~~Test()

    return 0;
}
Test t5(100, 100); // 2.构造t5,Test(int,int),全局变量在main()函数之前构造
```
