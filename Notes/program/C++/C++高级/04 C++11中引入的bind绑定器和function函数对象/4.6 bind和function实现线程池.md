# bind绑定器
在C++中，`std::bind` 是一个非常强大的工具，主要用于将函数或函数对象的参数进行绑定。它允许我们预先固定某些参数，从而生成一个新的可调用对象，这样可以在后续调用中更方便地使用。

### 基本概念

`std::bind` 是在 `<functional>` 头文件中定义的。它可以绑定普通函数、成员函数或函数对象。

### 使用方法

```cpp
#include <iostream>
#include <functional>

void printSum(int a, int b) {
    std::cout << "Sum: " << a + b << std::endl;
}

int main() {
    // 绑定第一个参数
    auto boundFunc = std::bind(printSum, 10, std::placeholders::_1);
    
    // 调用时只需要提供第二个参数
    boundFunc(5); // 输出: Sum: 15

    return 0;
}
```

### 关键要素

1. **占位符**：`std::placeholders::_1`, `std::placeholders::_2`, ... 用于指定绑定参数的位置。
2. **可调用对象**：`std::bind` 返回一个新的可调用对象，可以像普通函数一样被调用。
3. **灵活性**：你可以绑定部分或全部参数。

### 适用场景

- **回调函数**：在需要将函数作为参数传递的情况下，`std::bind` 可以用来预先设置某些参数。
- **事件处理**：在GUI编程或异步编程中，可以用于绑定事件处理函数。
- **算法和容器**：与STL算法结合，方便对容器中的元素进行操作。

### 示例

绑定成员函数：

```cpp
#include <iostream>
#include <functional>

class Multiplier {
public:
    void multiply(int a, int b) {
        std::cout << "Product: " << a * b << std::endl;
    }
};

int main() {
    Multiplier m;
    auto boundMemberFunc = std::bind(&Multiplier::multiply, &m, 3, std::placeholders::_1);
    
    boundMemberFunc(4); // 输出: Product: 12

    return 0;
}
```

### 小结

`std::bind` 是C++中处理函数参数绑定的利器，使得代码更加简洁和灵活。它的设计支持灵活的参数传递方式，使得可以在多种场景下使用。

# 案例
```cpp
#include <functional>
#include <iostream>

// bind绑定器

void hello(std::string str) { std::cout << str << std::endl; }
int sum(int a, int b) { return a + b; }
class Test
{
public:
    int sum(int a, int b) { return a + b; }
};
// 主函数
int main()
{
    // bind绑定器

    // bind是函数模板，将hello函数的参数绑定为"hello"，并执行。
    std::bind(&hello, "hello")();
    // bind绑定sum函数的参数a、b，参数1：函数地址，参数2，3：函数实参
    std::cout << std::bind(&sum, 10, 20)() << std::endl;
    // bind绑定成员方法：参数1：成员方法地址，参数2：类对象，参数3，4：函数实参
    std::cout << std::bind(&Test::sum, Test(), 30, 20)() << std::endl;

    // 参数占位符

    // std::placeholders::_1表示第一个参数被绑定
    std::bind(&hello, std::placeholders::_1)("Hello!");
    // 第1,2个参数绑定为200,300
    std::bind(&sum, std::placeholders::_1, std::placeholders::_2)(200, 320);

    // function和bind联用

    //利用function将bind返回的binder储存并复用
    std::function<void(std::string)> func1 = std::bind(&hello, std::placeholders::_1);
    func1("666");

    return 0;
}
```
