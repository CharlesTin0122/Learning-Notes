在C++中，**模板特例化**（Template Specialization）是一种允许开发者为特定的数据类型或情况提供自定义的模板实现的技术。模板特例化可以细分为**完全特例化**和**偏特例化**。

模板特例化主要用在需要对某些类型进行特殊处理的场景中。通过特例化，可以为不同类型提供特定的实现逻辑，而不是依赖通用模板。下面我来分别介绍完全特例化和偏特例化。

### 1. 完全特例化（Full Specialization）

**完全特例化**是指将模板针对某一特定类型完全定制，实现特定类型的完全自定义行为。这意味着模板不再通用，而是专门为这个特定类型定义的。

```cpp
#include <cstring>
#include <iostream>

// 比较函数模板
template <typename T>
bool compare(T a, T b)
{
    std::cout << "template compare" << std::endl;
    return a > b;
}
// 模板的特例化,完全特例化
template <>
bool compare<const char *>(const char *a, const char *b)
{
    std::cout << "compare<const char*> " << std::endl;

    return strcmp(a, b) > 0;
}

// 主函数
int main()
{
    compare(10, 20);
    // const char*类型，">" 比较的是内存地址，因此需要模板的特例化
    compare("aaa", "bbb");

    return 0;
}

```

在上述代码中：
- `Printer<int>` 使用通用模板，输出为 `"Generic print: 42"`。
- `Printer<std::string>` 则使用完全特例化的模板，输出为 `"String print: Hello"`。

**注意：** 完全特例化模板的语法是 `template<>` 后跟特定类型的模板声明。

### 2. 偏特例化（Partial Specialization）

**偏特例化**指的是部分地对模板参数进行特例化。偏特例化允许模板接受一部分特定类型的参数，而另一部分则保持通用性。C++ 中的偏特例化常见于**类模板**，而不是函数模板，因为函数模板的偏特例化并不直接支持。

例如，对于容器模板，偏特例化可以针对容器内的类型进行特例化：

```cpp
#include <iostream>
#include <type_traits>

// 泛化的模板类
template <typename T, typename U>
class Pair {
public:
    void print() {
        std::cout << "Generic Pair\n";
    }
};

// 偏特例化：当第二个类型参数为int时，提供特例化实现
template <typename T>
class Pair<T, int> {
public:
    void print() {
        std::cout << "Specialized Pair with int\n";
    }
};

int main() {
    Pair<double, double> genericPair;
    genericPair.print();  // 使用通用模板

    Pair<double, int> specializedPair;
    specializedPair.print();  // 使用偏特例化模板

    return 0;
}
```

在这个例子中：
- `Pair<double, double>` 调用了通用模板。
- `Pair<double, int>` 使用了偏特例化实现，这个实现专门处理第二个参数为 `int` 的情况。
### 3. 模板的实参推演
```cpp
#include <cstring>
#include <iostream>

// 模板的实参推演

// 相加函数
int sum(int a, int b) { return a + b; }

// 函数模板
template <typename T>
void func(T a)
{
    std::cout << typeid(T).name() << std::endl;
}
// 函数模板,将参数分拆，将参数分拆，返回值类型R，参数类型A、B
template <typename R, typename A, typename B>
void func2(R (*a)(A, B)) // 参数是一个函数指针
{
    std::cout << typeid(R).name() << std::endl;
    std::cout << typeid(A).name() << std::endl;
    std::cout << typeid(B).name() << std::endl;
}
// 类方法调用
class Test
{
public:
    int sum(int a, int b) { return a + b; }
};
// 函数模板,将参数分拆，返回值类型R，类名称C,参数类型A、B
template <typename R, typename C, typename A, typename B>
void func3(R (C::*a)(A, B)) // 参数是一个函数指针
{
    std::cout << typeid(R).name() << std::endl;
    std::cout << typeid(C).name() << std::endl;
    std::cout << typeid(A).name() << std::endl;
    std::cout << typeid(B).name() << std::endl;
}
// 主函数
int main()
{
    func(10);
    func(sum);
    func2(sum);        // 参数是函数
    func3(&Test::sum); // 参数是类方法

    return 0;
}

```
### 总结

- **完全特例化**适用于某个特定类型的完全自定义模板。
- **偏特例化**用于部分匹配的模板类型，适合处理某些参数为特定类型，其他参数保持通用的情况。
  
### 使用场景

模板特例化广泛用于需要根据类型特性来实现不同行为的场景，例如处理基础数据类型与复杂对象的差异、优化特定类型的性能、或者为特定类型定制格式化输出等。
# 案例
```cpp
#include <cstring>
#include <iostream>

// 类模板
template <typename T>
class Vector
{
public:
    Vector() { std::cout << "Call Vector Template init" << std::endl; }
};
// 针对char *类型，提供的完全特例化版本
template <>
class Vector<char *>
{
public:
    Vector() { std::cout << "Call Vector<char *> init" << std::endl; }
};
// 针对所有指针类型，提供部分特例化版本
template <typename Ty>
class Vector<Ty *>
{
public:
    Vector() { std::cout << "Call Vector<Ty *> init" << std::endl; }
};

// 针对函数指针类型，提供部分特例化版本(有返回值，有两个行参变量),返回值类型R，参数类型A1、A2
template <typename R, typename A1, typename A2>
class Vector<R (*)(A1, A2)>
{
public:
    Vector() { std::cout << "Call Vector<R (*)(A1, A2)> init" << std::endl; }
};

// 针对函数类型，提供部分特例化版本(有返回值，有两个行参变量),返回值类型R，参数类型A1、A2
template <typename R, typename A1, typename A2>
class Vector<R(A1, A2)>
{
public:
    Vector() { std::cout << "Call Vector<R(A1, A2)> init" << std::endl; }
};

int sum(int a, int b) { return a + b; }
// 主函数
int main()
{
    Vector<int> vec1;    // 从类模板实例化
    Vector<char *> vec2; // 从Vector<char *>实例化，调用完全特例化版本
    Vector<int *> vec3;  // 从VectorVector<Ty *>实例化，调用部分特例化版本

    /* int (*)(int, int) 是一种函数指针类型，它指向返回 int、且接受两个 int类型参数的函数。
     * vec4可以存储多个函数指针.这些指针指向的函数返回 int并接收两个 int 参数。
     */
    Vector<int (*)(int, int)> vec4; // 函数指针类型，从Vector<R (*)(A1, A2)>实例化，调用部分特例化版本

    int (*func1)(int, int);                  // 定义函数指针
    func1 = sum;                             // 函数指针指向sum()函数
    std::cout << func1(10, 20) << std::endl; // 调用函数

    // int(int, int)是一种函数类型，返回值为int类型、且接受两个 int类型参数的函数
    Vector<int(int, int)> vec5; // 函数类型,从Vector<R(A1, A2)>实例化，调用部分特例化版本

    typedef int FUNC2(int, int); // 这里定义了一个类型别名 FUNC2，它表示的是一个返回 int 且接受两个 int 参数的函数类型
    FUNC2 *func2 = sum; // FUNC2 * 表示一个指向 FUNC2 类型的指针，即指向一个返回 int 且接受两个 int 参数的函数的指针。
    std::cout << func2(10, 20) << std::endl; // 通过 func2(10, 20) 可以调用 sum 函数，并输出结果。

    return 0;
}

```
