# C++ STL 中的绑定器
- 绑定器 +  二元函数对象 = 一元函数对象
- bind1st ：把operator()的第一个参数绑定成确定的值
- bind2ed：把operator()的第二个参数绑定成确定的值
```cpp
#include <algorithm>
#include <cstdlib>
#include <ctime>
#include <functional>
#include <iostream>
#include <vector>

template <typename T>
void showContainer(const T &con)
{
    auto it = con.begin();
    while (it != con.end())
    {
        std::cout << *it << " ";
        ++it;
    }
    std::cout << std::endl;
}

// 主函数
int main()
{
    std::vector<int> vec;
    srand((unsigned int)time(nullptr)); // 随机数种子
    // 填充容器
    for (int i = 0; i < 20; ++i)
    {
        vec.push_back(rand() % 100 + 1);
    }

    // 利用二元函数对象greater，降序排列
    std::sort(vec.begin(), vec.end(), std::greater<int>());
    showContainer(vec);

    // 将70按序插入容器，在降序容器中找第一个小于70的数字，并插入该位置
    // 使用绑定器，将greater函数对象的第一个值绑定为70，使a > b 变为 70 > b
    auto it = std::find_if(vec.begin(), vec.end(),
                           std::bind1st(std::greater<int>(), 70));
    // 如果找到该位置，插入70元素
    if (it != vec.end()) { vec.insert(it, 70); }
    showContainer(vec);

    return 0;
}

```
