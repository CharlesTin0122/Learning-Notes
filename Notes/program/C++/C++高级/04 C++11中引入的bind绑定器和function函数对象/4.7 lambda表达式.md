C++ 中的 `lambda 表达式` 是一种可以定义匿名函数对象的方式，它允许你在代码中创建和使用函数，避免了定义额外的函数或者函数对象的需要。Lambda 表达式在 C++11 中被引入，提供了一种灵活、简洁的方式来定义回调函数、传递函数作为参数，或者进行简短的操作。

### 基本语法
```cpp
[捕获列表](参数列表) -> 返回类型 {
    // 函数体
}
```

- **捕获列表**：指定外部变量如何被捕获并传递给 lambda 表达式。可以按值捕获、按引用捕获或两者结合。
- **参数列表**：和普通函数一样，指定 lambda 接受的参数。
- **返回类型**：指定 lambda 的返回值类型，如果没有显式指定，可以通过推导（`auto`）或者直接返回类型推导。
- **函数体**：lambda 的具体实现，和普通函数的函数体一样。

### 捕获外部变量
- `[]`：表示不捕获任何外部变量
- `[=]`：以值传递的方式捕获所有外部变量
- `[&]`：以引用传递的方式捕获所有外部变量
- `[this]`：捕获外部的this指针
- `[=， &a]`：以值传递的方式捕获所有外部变量,但变量a以引用传递的方式捕获
- `[a， b]`：以值传递的方式捕获外部变量a、b
- `[a， &b]`：以值传递的方式捕获外部变量a，以引用传递的方式捕获变量b

- **按值捕获**：通过复制外部变量到 lambda 内部。使用 `=` 进行按值捕获。
  
  ```cpp
  int x = 10;
  auto lambda1 = [=]() { return x + 5; };
  std::cout << lambda1() << std::endl;  // 输出 15
  ```

- **按引用捕获**：通过引用捕获外部变量，允许修改外部变量。使用 `&` 进行按引用捕获。
  
  ```cpp
  int x = 10;
  auto lambda2 = [&]() { x += 5; };
  lambda2();
  std::cout << x << std::endl;  // 输出 15
  ```

- **捕获特定变量**：可以只捕获特定的变量。
  
  ```cpp
  int x = 10, y = 20;
  auto lambda3 = [x, &y]() { return x + y; };
  y = 30;
  std::cout << lambda3() << std::endl;  // 输出 40，x 捕获为值，y 捕获为引用
  ```

- **隐式捕获**：可以通过 `=` 或 `&` 来自动捕获所有外部变量，或通过 `this` 捕获成员变量。

  ```cpp
  int x = 10;
  auto lambda4 = [=]() { return x; };  // 自动按值捕获
  auto lambda5 = [&]() { x = 20; };   // 自动按引用捕获
  ```

### 返回类型
如果 lambda 的返回类型可以自动推导，则可以省略 `-> 返回类型` 部分；如果推导复杂或明确需要指定类型时，可以显式指定返回类型。

```cpp
auto lambda6 = [](int a, int b) -> int { return a + b; };
std::cout << lambda6(2, 3) << std::endl;  // 输出 5
```

### 例子：在 STL 算法中使用 Lambda

Lambda 表达式常常与 STL 算法配合使用，可以简化代码和避免创建额外的函数对象。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main()
{
    std::vector<int> vec = {7, 2, 4, 6, 9};

    // 使用 lambda 表达式进行降序排序
    std::sort(vec.begin(), vec.end(), [](int a, int b) { return a > b; });

    // 输出排序后的结果
    std::for_each(vec.begin(), vec.end(), [](int x) { std::cout << x << " "; });
    std::cout << std::endl;

    // 将数字5按序插入
    auto it = std::find_if(vec.begin(), vec.end(), [](int x) -> bool { return x < 5; });
    if (it != vec.end()) vec.insert(it, 5);
    // 输出排序后的结果
    std::for_each(vec.begin(), vec.end(), [](int x) { std::cout << x << " "; });
    std::cout << std::endl;

    return 0;
}
```

### 复杂示例：捕获成员变量

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

class MyClass {
public:
    MyClass() : data{1, 2, 3, 4, 5} {}

    void printData() {
        std::for_each(data.begin(), data.end(), [this](int val) {
            std::cout << val + this->increment << " "; // 捕获成员变量 increment
        });
        std::cout << std::endl;
    }

    void setIncrement(int value) { increment = value; }

private:
    std::vector<int> data;
    int increment = 0;
};

int main() {
    MyClass obj;
    obj.printData(); // 输出 1 2 3 4 5
    obj.setIncrement(10);
    obj.printData(); // 输出 11 12 13 14 15
    return 0;
}
```

### Lambda 表达式的用途

1. **函数对象替代**：避免创建一个单独的函数对象类，减少样板代码。
2. **回调函数**：适用于需要传递函数指针或者回调的情况。
3. **与 STL 配合**：与 STL 算法如 `std::for_each`, `std::transform`, `std::sort` 等紧密配合，能让代码更加简洁和表达性强。

### 总结

Lambda 表达式在 C++ 中是一项非常强大的特性，能够简化代码、提高代码的表达性和灵活性。它的捕获方式和用法可以根据具体的需求进行调整，使得 C++ 在函数式编程风格上更具优势。
