标准库模板类 `std::function`，它在 C++11 中引入，用于**通用的可调用对象封装**。`std::function` 可以存储、复制、调用各种**可调用对象**（如普通函数、函数指针、lambda 表达式、仿函数对象等）。

### 1. `std::function` 的作用

`std::function` 是一个模板类，提供了一种类型安全的方式来存储和调用符合特定签名的可调用对象。它的典型应用场景包括**回调函数**、**事件处理**、**策略模式**等，尤其在需要动态传递函数的地方非常有用。

### 2. `std::function` 的基本语法

`std::function` 的基本语法格式如下：

```cpp
#include <functional>

std::function<返回类型(参数类型列表)> 可调用对象名;
```

例如，要定义一个存储返回 `int` 且接受两个 `int` 参数的可调用对象，可以这样写：

```cpp
std::function<int(int, int)> func;
```

### 3. 使用示例

下面通过具体示例展示如何将不同的可调用对象类型存储到 `std::function` 中。

#### 示例 1：存储普通函数

```cpp
#include <iostream>
#include <functional>

int add(int a, int b) {
    return a + b;
}

int main() {
    std::function<int(int, int)> func = add;
    std::cout << "Result of add: " << func(3, 4) << std::endl; // 输出 7
    return 0;
}
```

#### 示例 2：存储 Lambda 表达式

```cpp
#include <iostream>
#include <functional>

int main() {
    std::function<int(int, int)> func = [](int a, int b) { return a * b; };
    std::cout << "Result of lambda: " << func(3, 4) << std::endl; // 输出 12
    return 0;
}
```

#### 示例 3：存储仿函数对象

```cpp
#include <iostream>
#include <functional>

struct Multiply {
    int operator()(int a, int b) const {
        return a * b;
    }
};

int main() {
    std::function<int(int, int)> func = Multiply();
    std::cout << "Result of functor: " << func(3, 4) << std::endl; // 输出 12
    return 0;
}
```

#### 示例 4：变更 `std::function` 对象内容

`std::function` 的优势在于可以动态替换内部存储的可调用对象。例如：

```cpp
#include <iostream>
#include <functional>

int add(int a, int b) {
    return a + b;
}

int main() {
    std::function<int(int, int)> func = add;
    std::cout << "Result of add: " << func(3, 4) << std::endl; // 输出 7

    func = [](int a, int b) { return a * b; }; // 重新赋值为 lambda 表达式
    std::cout << "Result of lambda: " << func(3, 4) << std::endl; // 输出 12

    return 0;
}
```

### 4. `std::function` 的优缺点

#### 优点
- **类型安全**：保证传递的可调用对象符合指定的签名。
- **灵活性**：可以存储不同类型的可调用对象（普通函数、函数指针、lambda、仿函数）。
- **动态分配**：允许在运行时决定使用的可调用对象，非常适合回调或事件系统。

#### 缺点
- **额外开销**：由于 `std::function` 会存储多种不同类型的可调用对象，并且包含一些额外的信息，可能会带来一些性能开销。
- **不可内联**：相比直接调用函数，`std::function` 的调用开销可能更大，因为它的调用不能被内联优化。

### 5. 常见应用场景

- **回调机制**：在异步任务完成时，通过 `std::function` 提供一个回调接口。
- **事件系统**：在图形界面或游戏开发中， `std::function` 可以用于注册事件响应函数。
- **策略模式**：在某些算法或策略设计中，可以通过 `std::function` 动态传递不同的算法逻辑。

### 6. `std::function` 与 `std::bind` 配合使用

`std::bind` 可以与 `std::function` 结合使用，将参数绑定到特定值或生成新的函数对象。例如：

```cpp
#include <iostream>
#include <functional>

int subtract(int a, int b) {
    return a - b;
}

int main() {
    std::function<int(int)> func = std::bind(subtract, std::placeholders::_1, 10);
    std::cout << "Result of bound function: " << func(20) << std::endl; // 输出 10 (20 - 10)
    return 0;
}
```

### 总结

- `std::function` 是一个强大的函数封装工具，适合动态函数调用场景。
- 它可以存储和调用多种不同类型的可调用对象，提供了高度的灵活性。
- `std::function` 可以与 `std::bind` 组合使用，进一步提升其使用场景的丰富性。
# 案例
```cpp
#include <functional>
#include <iostream>
#include <string>

void hello1() { std::cout << "Hello world!" << std::endl; }
void hello2(std::string str) { std::cout << str << std::endl; }
int sum(int a, int b) { return a + b; }
class Test
{
public:
    void hello(std::string str) { std::cout << str << std::endl; }
};
// 主函数
int main()
{
    // 用一个函数类型<void()>实例化function
    std::function<void()> func1(hello1);
    func1(); // 相当于func1.operator()调用hello1()函数

    // 用一个函数类型<void(string)>实例化function
    std::function<void(std::string)> func2 = hello2;
    func2("Hello world"); // 相当于func1.operator()(std::string str) 调用hello2(str) 函数

    std::function<int(int, int)> func3 = sum;
    std::cout << func3(3, 6) << std::endl;
    // 储存lambda表达式
    std::function<int(int, int)> func4 = [](int a, int b) -> int { return a + b; };
    std::cout << func4(6, 9) << std::endl;
    // 储存类方法,参数中要放Test类的指针相当于this指针，
    std::function<void(Test *, std::string)> func5 = &Test::hello;
    Test test;             // 创建对象
    func5(&test, "Hello"); // 调用函数，参数为1.对象指针，2.字符串

    return 0;
}

```
- function可以储存函数（普通函数、函数指针、lambda 表达式、函数对象）的类型
- 用函数类型实例化function
- 通过function调用operator()的时候需要根据函数类型传入相应的参数
- 通过function调用类方法的时候，参数中要写对象指针类型
