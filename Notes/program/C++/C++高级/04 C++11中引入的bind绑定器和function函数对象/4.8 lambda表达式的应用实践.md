# 引子
- 既然lambda表达式只能用在语句当中，如果想要跨语句使用之前定义好的lambda表达式，就是使用function函数类型。
```cpp
#include <functional>
#include <iostream>
#include <queue>
#include <vector>

class Data
{
public:
    int ma;
    int mb;
    Data(int a = 0, int b = 0) : ma(a), mb(b) {}
};

int main()
{
    // 优先级队列，模板参数：1，数据；2，底层数据结构；3，比较函数对象
    // 根据对象的ma属性大小进行降序排列
    // 结构为：priority_queue<data, vector, function> que(lambda)
    std::priority_queue<Data, std::vector<Data>, std::function<bool(Data &, Data &)>> 
	    que([](Data &d1, Data &d2) -> bool { return d1.ma > d2.ma; });

    que.push(Data(10, 20));
    que.push(Data(16, 32));
    que.push(Data(64, 17));
    que.push(Data(9, 3));

    // 遍历并打印元素
    while (!que.empty())
    {
        std::cout << que.top().ma << ", " << que.top().mb << std::endl;
        ;
        que.pop();
    }

    return 0;
}
```
