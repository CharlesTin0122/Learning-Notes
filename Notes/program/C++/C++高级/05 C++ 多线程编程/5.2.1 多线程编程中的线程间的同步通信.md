C++中的多线程编程涉及多个线程的并行执行，而线程间的同步和通信是确保线程安全和协调的重要部分。线程间的同步通信机制可以让线程间协调工作，避免数据竞态条件（race condition），确保数据一致性。

### 线程同步与通信的常用方式：

#### 1. **互斥锁 (Mutex)**
   - **作用**：互斥锁（Mutex）用于保证同一时刻只有一个线程可以访问共享资源。它通常用于保护临界区，即只能由一个线程执行的代码段，避免多个线程同时访问共享资源导致的竞态条件。
   - **实现**：C++11引入了`std::mutex`，它是最常用的互斥锁。线程可以通过调用`std::lock_guard`或`std::unique_lock`来自动管理锁的获取和释放。

   **示例代码**：
   ```cpp
   #include <iostream>
   #include <thread>
   #include <mutex>

   std::mutex mtx;  // 互斥锁

   void print_hello(int id) {
       std::lock_guard<std::mutex> lock(mtx);  // 自动加锁
       std::cout << "Hello from thread " << id << std::endl;
   }

   int main() {
       std::thread t1(print_hello, 1);
       std::thread t2(print_hello, 2);

       t1.join();
       t2.join();

       return 0;
   }
   ```

   **说明**：
   - `std::lock_guard`是RAII（资源获取即初始化）风格的锁管理工具，确保锁的自动释放。
   - 使用互斥锁保证在打印时不会有两个线程同时输出，从而避免了数据竞争。

#### 2. **条件变量 (Condition Variable)**
   - **作用**：条件变量是一种用于线程间通信的同步原语，它可以让一个线程等待某个条件成立，而其他线程可以通过通知来改变这个条件。
   - **实现**：C++11提供了`std::condition_variable`，通过与互斥锁结合使用，可以实现线程的等待和通知。

   **示例代码**：
   ```cpp
   #include <iostream>
   #include <thread>
   #include <mutex>
   #include <condition_variable>

   std::mutex mtx;
   std::condition_variable cv;
   bool ready = false;

   void print_id(int id) {
       std::unique_lock<std::mutex> lock(mtx);
       while (!ready) {  // 如果条件不满足，等待
           cv.wait(lock);
       }
       std::cout << "Thread " << id << '\n';
   }

   void go() {
       std::unique_lock<std::mutex> lock(mtx);
       ready = true;
       cv.notify_all();  // 通知所有线程条件已满足
   }

   int main() {
       std::thread threads[10];
       for (int i = 0; i < 10; ++i) {
           threads[i] = std::thread(print_id, i);
       }

       std::cout << "10 threads ready to race...\n";
       go();  // 通知所有线程开始

       for (auto& th : threads) {
           th.join();
       }

       return 0;
   }
   ```

   **说明**：
   - `cv.wait(lock)`会使线程在条件未满足时阻塞，并释放锁，直到`notify_all()`或`notify_one()`被调用。
   - `go()`函数在条件满足时唤醒所有等待的线程。

#### 3. **原子操作 (Atomic Operations)**
   - **作用**：原子操作是不可分割的操作，它们确保了在并发执行时不会被打断。通过原子操作可以在不使用锁的情况下实现线程同步。
   - **实现**：C++11引入了`std::atomic`，可以通过它来进行原子操作，如原子加法、原子比较和交换等。

   **示例代码**：
   ```cpp
   #include <iostream>
   #include <thread>
   #include <atomic>

   std::atomic<int> counter(0);  // 原子变量

   void increment() {
       for (int i = 0; i < 1000; ++i) {
           counter.fetch_add(1, std::memory_order_relaxed);  // 原子加1
       }
   }

   int main() {
       std::thread t1(increment);
       std::thread t2(increment);

       t1.join();
       t2.join();

       std::cout << "Counter: " << counter.load() << std::endl;  // 获取原子变量的值
       return 0;
   }
   ```

   **说明**：
   - `std::atomic`确保了对`counter`的所有操作是原子的，即多个线程在同时访问时不会出现数据不一致。
   - `fetch_add`是一个原子加操作，可以确保无论多少个线程同时执行该操作，`counter`的最终值都是正确的。

#### 4. **信号量 (Semaphore)**
   - **作用**：信号量是一种线程同步原语，用于控制访问共享资源的线程数量。它可以设定一个最大值，限制同时访问共享资源的线程数。
   - **实现**：C++20引入了`std::counting_semaphore`，支持计数信号量。`std::binary_semaphore`是一个特化的信号量，值只有0或1，通常用于控制互斥访问。

   **示例代码**：
   ```cpp
   #include <iostream>
   #include <thread>
   #include <semaphore>  // C++20

   std::counting_semaphore<3> sem(3);  // 最大允许3个线程同时访问

   void access_shared_resource(int id) {
       sem.acquire();  // 获取信号量
       std::cout << "Thread " << id << " is accessing shared resource\n";
       std::this_thread::sleep_for(std::chrono::seconds(1));
       sem.release();  // 释放信号量
   }

   int main() {
       std::thread threads[5];
       for (int i = 0; i < 5; ++i) {
           threads[i] = std::thread(access_shared_resource, i);
       }

       for (auto& th : threads) {
           th.join();
       }

       return 0;
   }
   ```

   **说明**：
   - `std::counting_semaphore`确保最多只有3个线程可以同时访问共享资源。
   - `acquire()`会在信号量可用时获得信号量，`release()`释放信号量。

#### 5. **读写锁 (Read-Write Lock)**
   - **作用**：读写锁允许多个线程同时读取资源，但写入资源时会阻塞所有读写操作。适用于资源大部分时间为读操作时。
   - **实现**：C++17引入了`std::shared_mutex`，它支持多个线程并发读取和单个线程写入。

   **示例代码**：
   ```cpp
   #include <iostream>
   #include <thread>
   #include <shared_mutex>

   std::shared_mutex rw_mutex;

   void read_data(int id) {
       std::shared_lock<std::shared_mutex> lock(rw_mutex);  // 共享锁，允许多个线程同时读取
       std::cout << "Thread " << id << " is reading data\n";
   }

   void write_data(int id) {
       std::unique_lock<std::shared_mutex> lock(rw_mutex);  // 独占锁，写操作需要独占资源
       std::cout << "Thread " << id << " is writing data\n";
   }

   int main() {
       std::thread threads[5];
       for (int i = 0; i < 3; ++i) {
           threads[i] = std::thread(read_data, i);
       }
       threads[3] = std::thread(write_data, 3);  // 写操作
       threads[4] = std::thread(read_data, 4);

       for (auto& th : threads) {
           th.join();
       }

       return 0;
   }
   ```

   **说明**：
   - `std::shared_lock`用于多个线程并发读取。
   - `std::unique_lock`用于独占访问（写操作）。

### 总结
C++提供了多种线程同步和通信机制，选择适当的同步方式可以有效避免数据竞态，确保多线程环境中的数据一致性和执行效率。最常用的机制包括互斥锁、条件变量、原子操作、信号量和读写锁，具体使用哪个同步机制，取决于具体的场景和需求。
