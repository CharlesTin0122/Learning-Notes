# **进程**、**线程**和**协程**

在C++编程中，**进程**、**线程**和**协程**是三种并发编程模型，它们各自有不同的特点、使用场景和执行方式。理解它们的区别和适用情况对于编写高效的多任务应用程序非常重要。下面是对这三个概念的详细介绍：

---

### 1. 进程（Process）

**进程**是操作系统中资源分配的基本单位，是程序执行的实例。每个进程都有独立的内存空间、数据、堆栈以及其他与进程执行相关的资源。

#### 特点：
- **独立性**：每个进程在操作系统中都有自己独立的内存空间、文件描述符等资源，因此一个进程崩溃不会直接影响到其他进程。
- **资源消耗大**：由于每个进程需要自己的内存和资源，创建和销毁进程的开销相对较大。
- **通信难度大**：进程之间的通信需要借助如**管道**、**消息队列**、**共享内存**等进程间通信（IPC）机制，通常较为复杂。

#### 示例：
操作系统通常提供系统调用来创建和管理进程。例如，在Unix/Linux下，创建进程可以使用`fork()`，在Windows下可以使用`CreateProcess()`。

```cpp
#include <iostream>
#include <unistd.h>

int main() {
    pid_t pid = fork();  // 创建新进程
    
    if (pid == 0) {
        std::cout << "This is the child process." << std::endl;
    } else if (pid > 0) {
        std::cout << "This is the parent process." << std::endl;
    } else {
        std::cerr << "Fork failed!" << std::endl;
    }
    
    return 0;
}
```

---

### 2. 线程（Thread）

**线程**是进程中的一个执行单元，通常称为轻量级进程。每个进程至少有一个线程（即主线程），并且可以创建多个线程来并行执行任务。线程共享进程的资源（如内存、文件描述符等），但每个线程有自己的堆栈和寄存器。

#### 特点：
- **资源共享**：同一个进程中的线程共享内存空间，因此它们之间的通信和数据交换较为方便（例如，直接访问共享内存）。
- **轻量级**：线程之间的创建和销毁开销相对较小，比起进程要高效得多。
- **同步问题**：由于多个线程共享同一内存空间，因此需要通过锁（如互斥锁、条件变量）等同步机制来避免竞态条件和数据不一致的问题。

#### 示例：
在C++中，可以使用`std::thread`类创建线程。

```cpp
#include <iostream>
#include <thread>

void print_hello() {
    std::cout << "Hello from thread!" << std::endl;
}

int main() {
    std::thread t(print_hello);  // 创建线程
    t.join();  // 等待线程完成
    return 0;
}
```

- `std::thread`是C++11标准引入的，用于方便地创建和管理线程。
- 通过`join()`等待线程结束，或者调用`detach()`让线程在后台执行。

---

### 3. 协程（Coroutine）

**协程**是一种比线程更加轻量级的并发模型，可以理解为在单线程中实现的"微线程"。协程通过**挂起（suspend）和恢复（resume）**的方式，能够在同一线程中交替执行多个任务。与线程不同，协程通常不需要操作系统的内核调度，而是由程序自身的调度器来管理。

#### 特点：
- **轻量级**：协程比线程更轻量，因为它们不需要操作系统的内核支持，创建和销毁协程的开销几乎为零。
- **高效**：协程通常用于I/O密集型任务，在执行过程中可以暂停等待I/O操作完成，然后恢复执行，避免了线程创建和上下文切换的高开销。
- **单线程内并发**：协程在单线程内模拟并发，它们之间的切换通过用户空间的调度器来完成，而不依赖操作系统调度。

#### 协程与线程的区别：
- **线程**：需要操作系统调度，拥有独立的栈和寄存器，能够并行执行（多核系统上）。线程之间通过内存共享进行通信，但需要处理同步问题。
- **协程**：协程在单线程中模拟并发，它们之间的切换是通过程序内部调度的，因此不需要操作系统调度，资源消耗更低，但也不具备真正的并行能力。适合I/O密集型任务。

#### 示例：
C++20引入了对协程的支持，使用`co_await`、`co_yield`等关键字来创建协程。

```cpp
#include <iostream>
#include <coroutine>
#include <thread>

struct task {
    struct promise_type;  // 协程的Promise类型
    using handle_type = std::coroutine_handle<promise_type>;

    task(handle_type h) : coro(h) {}
    ~task() { if (coro) coro.destroy(); }
    
    handle_type coro;
};

struct task::promise_type {
    task get_return_object() { return task{handle_type::from_promise(*this)}; }
    std::suspend_never initial_suspend() { return {}; }
    std::suspend_never final_suspend() noexcept { return {}; }
    void return_void() {}
    void unhandled_exception() { std::terminate(); }
};

task my_coroutine() {
    std::cout << "Hello from coroutine!" << std::endl;
    co_return;
}

int main() {
    auto t = my_coroutine();  // 创建并执行协程
    return 0;
}
```

- **`co_return`**：结束协程。
- **`std::suspend_never`**：表示协程不需要挂起或恢复。

---

### 进程、线程与协程的比较

| 特性            | 进程                       | 线程                       | 协程                        |
|-----------------|----------------------------|----------------------------|-----------------------------|
| **资源隔离**    | 独立的内存和资源            | 共享进程资源               | 共享调用协程的线程资源      |
| **调度**        | 操作系统调度                | 操作系统调度                | 用户空间调度                |
| **上下文切换**  | 操作系统管理，开销大        | 操作系统管理，开销小        | 轻量级，几乎没有开销        |
| **创建销毁开销**| 高                          | 低                          | 极低                        |
| **适用场景**    | 需要独立资源的任务          | CPU密集型任务并发执行       | I/O密集型任务，非阻塞并发  |

### 总结
- **进程**是操作系统的资源分配单位，每个进程有独立的内存空间，适用于需要高度隔离的任务。
- **线程**是进程内的执行单元，共享内存资源，适用于需要并行执行的任务。
- **协程**是一种轻量级的并发模型，通常在单线程中调度多个任务，适用于I/O密集型应用。

# C++多线程编程
C++中的多线程编程是利用多核CPU并发执行任务，以提高程序效率和响应性。多线程编程可以让程序同时运行多个线程，每个线程可以执行独立的任务。

C++标准库在C++11中引入了对多线程编程的支持，提供了`<thread>`头文件，用于创建和管理线程。此外，C++11还提供了用于同步线程的机制，如互斥锁（mutex）、条件变量等，以避免多线程之间的资源竞争。

### 1. 创建线程
C++11及以上版本通过`std::thread`类来创建和管理线程。`std::thread`构造函数接受一个可调用对象（如函数、函数指针、lambda表达式等）作为参数。

#### 示例：
```cpp
#include <iostream>
#include <thread>

void say_hello() {
    std::cout << "Hello from thread!" << std::endl;
}

int main() {
    // 创建一个线程，执行say_hello函数
    std::thread t(say_hello);
    
    // 等待线程结束
    t.join();

    return 0;
}
```
- `std::thread t(say_hello);`：创建一个新线程，线程执行`say_hello`函数。
- `t.join()`：主线程等待新线程执行完毕。`join()`会阻塞当前线程，直到子线程完成。

如果不调用`join()`，线程会成为“分离线程”（detached thread），这时线程会在后台运行，不会阻塞主线程。

### 2. 线程参数
可以通过传递参数给线程函数来使用线程。

#### 示例：
```cpp
#include <iostream>
#include <thread>

void print_number(int num) {
    std::cout << "Number: " << num << std::endl;
}

int main() {
    int value = 10;
    std::thread t(print_number, value);
    t.join();
    
    return 0;
}
```
- `std::thread t(print_number, value);`：这里传递了一个整数参数给线程函数`print_number`。

### 3. 多线程同步
在多线程编程中，多个线程可能会同时访问共享资源，从而导致数据竞争（race condition）。为了避免这种情况，需要使用同步机制。C++提供了多种同步方式。

#### 3.1 互斥锁（mutex）
互斥锁可以确保同一时刻只有一个线程可以访问共享资源。

```cpp
#include <iostream>
#include <thread>
#include <mutex>

std::mutex mtx; // 互斥锁

void print_number(int num) {
    std::lock_guard<std::mutex> lock(mtx);  // 自动加锁和解锁
    std::cout << "Number: " << num << std::endl;
}

int main() {
    std::thread t1(print_number, 1);
    std::thread t2(print_number, 2);
    
    t1.join();
    t2.join();
    
    return 0;
}
```
- `std::mutex mtx;`：定义一个互斥锁对象。
- `std::lock_guard<std::mutex> lock(mtx);`：在临界区内自动加锁，保证同一时刻只有一个线程可以访问共享资源。`lock_guard`会在作用域结束时自动解锁。

#### 3.2 条件变量（condition_variable）
条件变量用于在特定条件下让线程等待或通知其他线程。

```cpp
#include <iostream>
#include <thread>
#include <mutex>
#include <condition_variable>

std::mutex mtx;
std::condition_variable cv;
bool ready = false;

void print_number(int num) {
    std::unique_lock<std::mutex> lock(mtx); // 使用unique_lock，可以与条件变量一起使用
    while (!ready) {
        cv.wait(lock);  // 等待条件满足
    }
    std::cout << "Number: " << num << std::endl;
}

void go() {
    std::this_thread::sleep_for(std::chrono::seconds(1)); // 模拟一些工作
    std::unique_lock<std::mutex> lock(mtx);
    ready = true;
    cv.notify_all(); // 通知所有线程
}

int main() {
    std::thread t1(print_number, 1);
    std::thread t2(print_number, 2);
    
    go();
    
    t1.join();
    t2.join();
    
    return 0;
}
```
- `cv.wait(lock)`：使线程等待，直到条件为`true`。
- `cv.notify_all()`：通知所有等待的线程继续执行。

### 4. 线程池
C++标准库并没有提供线程池的直接支持，但可以通过自定义线程池来管理线程池中的多个线程，避免频繁地创建和销毁线程。

### 5. 异常处理
线程中的异常不能直接传播到主线程或其他线程，因此需要在每个线程内进行异常捕获。

#### 示例：
```cpp
#include <iostream>
#include <thread>
#include <stdexcept>

void throw_exception() {
    throw std::runtime_error("An error occurred in the thread!");
}

int main() {
    try {
        std::thread t(throw_exception);
        t.join();
    } catch (const std::exception& e) {
        std::cout << "Exception: " << e.what() << std::endl;
    }
    
    return 0;
}
```

### 总结
C++中的多线程编程使得开发者可以利用多核处理器，提高程序的执行效率。通过`std::thread`类可以轻松地创建和管理线程，互斥锁和条件变量等同步机制确保线程安全。通过合理使用这些工具，可以有效地处理并发任务。

### 常用功能：
- **线程创建与销毁**：`std::thread`
- **同步机制**：`std::mutex`, `std::lock_guard`, `std::condition_variable`
- **线程参数传递**：线程函数支持传递参数
