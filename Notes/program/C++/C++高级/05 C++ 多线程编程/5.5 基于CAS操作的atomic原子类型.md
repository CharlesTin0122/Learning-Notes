# atomic原子类型

在 C++ 中，**原子操作**（Atomic Operations）是指在多线程并发环境下，不可被中断的操作，保证了对共享变量的访问是安全的，而不需要使用传统的锁机制。`std::atomic` 是 C++ 标准库中的一个模板类，用来支持原子操作。通过原子类型，我们可以在多个线程中对同一变量进行操作，而不会引入竞态条件。

### 1. **CAS（Compare-and-Swap）操作：**
CAS 操作（也叫比较并交换）是一种常见的原子操作，通常用于实现无锁数据结构和算法。CAS 允许我们在单个操作中：
1. 比较一个内存位置的当前值。
2. 如果该值与预期值相同，则交换该内存位置的值为新值。
3. 如果当前值与预期值不匹配，则不进行交换，并返回当前值。

CAS 的优势在于，它不需要加锁，因此能大幅提升多线程程序的性能。

### 2. **C++ 中的原子类型：**

C++11 引入了 `std::atomic` 类模板，用于表示原子类型，并支持原子操作。原子类型支持的操作包括读取、写入、增减、加锁和解锁等。

#### `std::atomic` 基本操作：
`std::atomic` 提供了一些常见的原子操作，最常用的包括：

- **load**：读取原子变量的值。
- **store**：设置原子变量的值。
- **fetch_add**：执行原子加法操作，并返回旧值。
- **fetch_sub**：执行原子减法操作，并返回旧值。
- **compare_exchange_weak / compare_exchange_strong**：实现 CAS 操作。

#### `std::atomic` 的支持类型：
`std::atomic` 支持以下类型：
- **整型类型**：`std::atomic<int>`, `std::atomic<unsigned int>` 等。
- **指针类型**：`std::atomic<void*>`, `std::atomic<int*>` 等。
- **布尔类型**：`std::atomic<bool>`。

### 3. **CAS 操作示例：**

以下是一个基于 `std::atomic` 和 CAS 操作的例子，演示了如何使用 CAS 来实现无锁增量。

#### 示例代码：
```cpp
#include <iostream>
#include <atomic>
#include <thread>
#include <vector>

std::atomic<int> counter(0); // 原子变量

void increment(int id) {
    int old_value;
    do {
        old_value = counter.load(); // 获取当前值
    } while (!counter.compare_exchange_weak(old_value, old_value + 1)); // 比较并交换
    std::cout << "Thread " << id << " incremented counter to " << old_value + 1 << std::endl;
}

int main() {
    const int num_threads = 10;
    std::vector<std::thread> threads;

    // 启动多个线程进行增量操作
    for (int i = 0; i < num_threads; ++i) {
        threads.push_back(std::thread(increment, i));
    }

    // 等待所有线程完成
    for (auto& t : threads) {
        t.join();
    }

    std::cout << "Final counter value: " << counter.load() << std::endl;
    return 0;
}
```

#### 解释：
- **`std::atomic<int> counter(0);`**：定义了一个原子整数类型 `counter`，初始化为 0。
- **`counter.load()`**：读取原子变量 `counter` 的当前值。
- **`compare_exchange_weak(old_value, old_value + 1)`**：CAS 操作，比较 `counter` 当前值与 `old_value` 是否相等。如果相等，则将 `counter` 设置为 `old_value + 1`，否则返回当前值。若交换成功，返回 `true`，否则返回 `false`。

#### CAS 操作的流程：
1. 线程读取 `counter` 当前的值（`old_value`）。
2. 线程尝试将 `counter` 更新为 `old_value + 1`。
3. 如果 CAS 比较失败（意味着其他线程已经修改了 `counter`），那么线程会重新读取当前值并再次尝试 CAS 操作。
4. 一旦 CAS 成功，线程就完成了增量操作。

### 4. **C++ 中的 CAS 操作实现：**
在 C++ 中，`std::atomic` 类模板通常会利用底层硬件的原子指令来实现 CAS 操作。例如，现代的处理器通常支持 **原子比较和交换**（CAS）指令，像是 `cmpxchg` 或 `lock cmpxchg`，这些指令能够保证在多线程环境下执行原子比较和交换操作。

具体地：
- **`compare_exchange_weak`**：这是一个比较宽松的操作，执行时即使某些情况下 CAS 失败，也会继续尝试交换。
- **`compare_exchange_strong`**：该操作比 `weak` 更强一些，只有当所有的条件完全满足时才会交换。如果失败，操作会立即退出，不会继续尝试。

### 5. **CAS 和性能：**
- CAS 是一种非常有效的无锁机制，通常比传统的加锁（如 `std::mutex`）具有更低的开销。
- 然而，CAS 也存在 **ABA 问题**，即一个变量被改变了两次，但由于它的值回到了原来值，CAS 无法发现这种变化。为了解决这一问题，可以使用 **版本号** 或 **指针标记** 等技术。

### 6. **总结：**

- **CAS（Compare-and-Swap）操作** 是一种原子操作，能够确保多线程环境中对共享数据的安全访问，避免锁的开销。
- **C++ 中的 `std::atomic` 类型** 提供了对基本数据类型的原子操作支持，其中包括 CAS 操作的实现。
- CAS 操作通过 **`compare_exchange_weak`** 和 **`compare_exchange_strong`** 来实现，允许我们进行原子比较和交换。
- CAS 操作通常用于无锁算法和数据结构中，如无锁队列、栈、计数器等。
# 案例
```cpp
#include <atomic> //原子类型
#include <chrono>
#include <iostream>
#include <list>
#include <thread>

// 定义原子类型变量，volatile关键字，防止多线程对共享变量进行缓存
volatile std::atomic_bool isReady = false;
volatile std::atomic_int myCount = 0;
// 线程函数
void task()
{
    while (!isReady)
    {
        // 线程出让当前的CPU时间片，等待下次调动。线程并没有进入阻塞状态，只是在排队等待下次调度。
        std::this_thread::yield();
    }

    for (int i = 0; i < 100; ++i)
    {
        myCount++;
    }
}

// 主函数
int main()
{
    // 定义线程链表
    std::list<std::thread> thread_list;
    // 填充线程链表
    for (int i = 0; i < 10; ++i)
    {
        thread_list.push_back(std::thread(task));
    }
    // 主线程睡眠3s
    std::this_thread::sleep_for(std::chrono::seconds(3));
    isReady = true;

    // 主线程等待子线程结束
    for (std::thread &t : thread_list)
    {
        t.join();
    }
    std::cout << " count: " << myCount << std::endl;

    return 0;
}

```
