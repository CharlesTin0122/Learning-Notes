# 基本内容
C++语言级别的多线程，好处是可以跨平台。windows/linux/mac都可以编译运行。本质上还是调用系统的多线程API，Win系统下调用createThread；linux下调用pthread_create。主要学习内容如下：

- thread：多线程类
- mutex：互斥锁，用于线程间的互斥。
	- lock_guard
	- unique_lock
- condition_variable：条件变量，线程之间的通信
- atomic：基于CAS操作的原子类型，是线程安全的
- sleep_for：睡眠
# 线程操作
- 如何创建启动一个线程
	- `std::thread()`定义一个线程对象，传入线程所需的线程函数和参数，线程自动开启。
- 子线程如何结束
	- 子线程函数运行完成，线程就结束了
- 主线程如何处理子线程
	- 主线程运行完毕，如果当前进程还有未运行完毕的子线程，进程就会异常终止。因此子线程需要在主线程运行结束之前结束。有两种操作：
		- `t1.join()`： 主线程(main)阻塞，等待子线程 t1 结束,主线程继续运行。
		- `t1.detach()`：把子线程 t1 设置为分离线程，主线程运行完毕后不再查看子线程有没有运行完成。进程直接结束，所有子线程自动结束。
# 案例
```cpp
#include <chrono>
#include <iostream>
#include <thread>

void threadHandle1(int time)
{
    /*当子线程运行的时候，让子线程睡眠两秒
     * this_thread是一个名称空间，里面有关于此线程的操作方法，sleep_for表示睡眠
     * chrono：计时器。是一个名称空间，里面有关于线程时间的操作方法，seconds(2)表示两秒
     */
    std::this_thread::sleep_for(std::chrono::seconds(time));
    std::cout << "Hello Thread1!" << std::endl;
}
void threadHandle2(int time)
{
    std::this_thread::sleep_for(std::chrono::seconds(time));
    std::cout << "Hello Thread2!" << std::endl;
}

int main()
{
    // 创建一个线程对象，传入一个线程函数作为参数，新线程开始运行
    std::thread t1(threadHandle1, 2);
    std::thread t2(threadHandle2, 3);
    // 主线程(main)阻塞，等待子线程(threadHandle1)结束,主线程继续运行
    t1.join();
    t2.join();
    // 把子线程设置为分离线程，
    // t1.detach();
    std::cout << "main thread done!" << std::endl;

    return 0;
}
```
