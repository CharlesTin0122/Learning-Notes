代理模式（Proxy Pattern）是一种结构型设计模式，提供了对象的代理以控制对原对象的访问。代理模式通过一个代理类（Proxy）间接访问目标对象（RealSubject），可以在不改变目标对象的前提下添加额外的功能。

---
### **代理模式的结构**

在 C++ 中，代理模式通常包含以下角色：

1. **抽象主题（Subject）**：
    
    - 定义目标对象和代理对象的公共接口（通常是一个抽象类或接口）。
    - 客户端通过这一接口与目标对象交互。
2. **真实主题（RealSubject）**：
    
    - 实现了抽象主题的接口，是实际要处理业务逻辑的类。
3. **代理（Proxy）**：
    
    - 同样实现了抽象主题接口。
    - 持有对真实主题对象的引用，负责控制对真实主题的访问。
    - 在调用真实主题之前或之后，执行一些额外的操作。
4. **客户端（Client）**：
    
    - 通过代理对象与真实主题交互，而不直接访问真实主题。

### **代理模式的类型**

根据代理的功能，代理模式可以分为以下几种：

1. **保护代理（Protection Proxy）**：控制对真实对象的访问权限。
2. **虚拟代理（Virtual Proxy）**：延迟创建或优化对象的访问。
3. **远程代理（Remote Proxy）**：控制对远程对象的访问。
4. **缓存代理（Caching Proxy）**：为开销较大的操作提供缓存。
5. **智能引用代理（Smart Reference Proxy）**：对引用计数、日志记录等操作提供支持。

### **代理模式示例**

#### 示例：虚拟代理

**场景**：在某些情况下，目标对象的创建开销较大，我们可以使用代理对象延迟实例化目标对象。

```cpp
#include <iostream>
#include <memory>
using namespace std;

// 抽象主题
class Subject {
public:
    virtual void request() = 0; // 定义公共接口
    virtual ~Subject() = default;
};

// 真实主题
class RealSubject : public Subject {
public:
    RealSubject() {
        cout << "RealSubject: Expensive initialization." << endl;
    }
    void request() override {
        cout << "RealSubject: Handling request." << endl;
    }
};

// 代理
class Proxy : public Subject {
private:
    unique_ptr<RealSubject> realSubject; // 延迟初始化的真实主题
public:
    void request() override {
        if (!realSubject) {
            cout << "Proxy: Creating the RealSubject." << endl;
            realSubject = make_unique<RealSubject>();
        }
        realSubject->request();
    }
};

// 客户端代码
int main() {
    Proxy proxy;
    cout << "Client: Making the first request." << endl;
    proxy.request(); // 第一次调用，初始化真实主题
    cout << "Client: Making the second request." << endl;
    proxy.request(); // 第二次调用，直接使用已创建的真实主题
    return 0;
}
```

**输出**：

```
Client: Making the first request.
Proxy: Creating the RealSubject.
RealSubject: Expensive initialization.
RealSubject: Handling request.
Client: Making the second request.
RealSubject: Handling request.
```

#### 示例分析

1. **延迟初始化**：代理对象在第一次请求时才创建真实对象，避免了不必要的开销。
2. **真实主题的透明访问**：客户端不关心请求由代理还是真实对象处理，代理模式对客户端是透明的。

#### 示例：保护代理

**场景**：为目标对象提供访问权限控制。

```cpp
#include <iostream>
#include <string>
using namespace std;

// 抽象主题
class Subject {
public:
    virtual void request() = 0;
    virtual ~Subject() = default;
};

// 真实主题
class RealSubject : public Subject {
public:
    void request() override {
        cout << "RealSubject: Handling request." << endl;
    }
};

// 代理
class ProtectionProxy : public Subject {
private:
    RealSubject realSubject;
    string userRole;
public:
    ProtectionProxy(const string& role) : userRole(role) {}
    void request() override {
        if (userRole == "Admin") {
            cout << "ProtectionProxy: Access granted." << endl;
            realSubject.request();
        } else {
            cout << "ProtectionProxy: Access denied." << endl;
        }
    }
};

// 客户端代码
int main() {
    ProtectionProxy proxyAdmin("Admin");
    proxyAdmin.request(); // Admin 用户，允许访问

    ProtectionProxy proxyGuest("Guest");
    proxyGuest.request(); // Guest 用户，禁止访问
    return 0;
}
```

**输出**：

```
ProtectionProxy: Access granted.
RealSubject: Handling request.
ProtectionProxy: Access denied.
```

### **优点与缺点**

#### **优点**：

1. **控制访问**：通过代理类对目标对象的访问进行控制。
2. **减少开销**：可以通过延迟初始化或优化请求减少系统开销。
3. **增加灵活性**：在不修改目标对象的情况下添加额外功能。

#### **缺点**：

1. **增加复杂性**：引入了额外的类，可能使系统设计变得复杂。
2. **可能带来性能问题**：如果代理增加了额外的逻辑，可能会对性能产生影响。

---

### **代理模式的应用场景**

1. **远程访问**：访问远程服务器上的对象时，通过远程代理处理通信。
2. **安全控制**：对特定资源访问进行权限控制。
3. **缓存**：缓存开销较大的操作结果，避免重复计算。
4. **延迟加载**：在需要时才创建或初始化对象（如加载大文件或图像）。

代理模式在 C++ 中非常适合用来控制对象的访问，同时提升代码的灵活性和可维护性。

# 示例
```cpp
#include <iostream>
#include <memory>

// 代理模式

// 抽象类
class VideoSite
{
public:
    VideoSite() = default;
    virtual ~VideoSite() = default;

    virtual void freeMovie() = 0;
    virtual void vipMovie() = 0;
    virtual void ticketMovie() = 0;
};

// 委托类
class MyVideoSite : public VideoSite
{
public:
    virtual void freeMovie() override { std::cout << "观看免费电影" << std::endl; }
    virtual void vipMovie() override { std::cout << "观看VIP电影" << std::endl; }
    virtual void ticketMovie() override { std::cout << "观看用券电影" << std::endl; }
};

// 代理类
class FreeMovieProxy : public VideoSite
{
public:
    FreeMovieProxy() { p = new MyVideoSite(); }
    ~FreeMovieProxy() { delete p; }

    virtual void freeMovie() override { p->freeMovie(); }
    virtual void vipMovie() override { std::cout << "无法观看VIP电影" << std::endl; }
    virtual void ticketMovie() override { std::cout << "无法观看用券电影" << std::endl; }

private:
    VideoSite *p;
};

class VipMovieProxy : public VideoSite
{
public:
    VipMovieProxy() { p = new MyVideoSite(); }
    ~VipMovieProxy() { delete p; }

    virtual void freeMovie() override { p->freeMovie(); }
    virtual void vipMovie() override { p->vipMovie(); }
    virtual void ticketMovie() override { std::cout << "无法观看用券电影" << std::endl; }

private:
    VideoSite *p;
};

int main()
{
    std::unique_ptr<VideoSite> p1(new FreeMovieProxy());
    p1->freeMovie();
    p1->vipMovie();
    p1->ticketMovie();

    std::unique_ptr<VideoSite> p2(new VipMovieProxy());
    p2->freeMovie();
    p2->vipMovie();
    p2->ticketMovie();

    return 0;
}
```
