Python 中的**浅拷贝**（shallow copy）和**深拷贝**（deep copy）是处理对象复制时两种不同的方式，主要涉及可变对象（如列表、字典、嵌套结构）的复制行为。它们的核心区别在于：**是否复制嵌套对象本身**。

---

### 1. 浅拷贝（Shallow Copy）

**定义**：  
浅拷贝创建一个新对象，但**只复制对象的最外层元素**，嵌套对象（如列表中的列表）仍然指向原来的内存地址。

**特点**：
- 外层对象是新的（独立）
- 内层可变对象是共享的（修改会相互影响）

**实现方式**：
```python
import copy

# 方法1：copy.copy()
new_obj = copy.copy(original)

# 方法2：列表/字典的 .copy() 方法
new_list = original_list.copy()

# 方法3：切片（仅限序列）
new_list = original_list[:]
```

**示例**：
```python
import copy

original = [[1, 2, 3], [4, 5, 6]]
shallow = copy.copy(original)

# 修改外层
shallow[0] = [7, 8, 9]
print(original)  # [[1, 2, 3], [4, 5, 6]]  ← 未变
print(shallow)   # [[7, 8, 9], [4, 5, 6]]

# 修改内层
shallow[1][0] = 999
print(original)  # [[1, 2, 3], [999, 5, 6]] ← 被修改！
print(shallow)   # [[7, 8, 9], [999, 5, 6]]
```

> 注意：内层列表 `[4, 5, 6]` 是同一个对象，修改会同步。
#### 切片属于浅拷贝
```python
a = [11, 22]
b = [33, 44]
c = [a, b]
d = c[:] # 浅拷贝
```
#### 字典的copy()方法属于浅拷贝
```python
a = dict(name="LaoTian", age=18, cars = [120, 200, 300])
b = a.copy()
```
---

### 2. 深拷贝（Deep Copy）

**定义**：  
深拷贝创建一个**完全独立**的新对象，**递归复制所有嵌套对象**，新对象与原对象无任何共享引用。

**特点**：
- 外层和所有内层都是新的
- 修改新对象完全不影响原对象

**实现方式**：
```python
import copy

deep = copy.deepcopy(original)
```

**示例**：
```python
import copy

original = [[1, 2, 3], [4, 5, 6]]
deep = copy.deepcopy(original)

# 修改内层
deep[1][0] = 999
print(original)  # [[1, 2, 3], [4, 5, 6]]  ← 未变
print(deep)      # [[1, 2, 3], [999, 5, 6]]
```

> 完全独立，互不影响。

---

### 对比总结

| 特性               | 赋值 (`=`)       | 浅拷贝 (`copy.copy`)       | 深拷贝 (`copy.deepcopy`)       |
|--------------------|------------------|----------------------------|--------------------------------|
| 创建新对象         | ❌ 仅绑定引用     | ✅ 外层新                  | ✅ 全部新                      |
| 嵌套对象独立       | ❌ 共享           | ❌ 共享内层                 | ✅ 递归复制                    |
| 内存占用           | 最小             | 中等                       | 最大                          |
| 性能               | 最快             | 较快                       | 较慢（递归）                   |
| 适用场景           | 简单不可变对象   | 外层独立、内层共享         | 完全独立复制                  |

---

### 注意事项

1. **不可变对象（如 int、str、tuple）**  
   如果顶层数据类型为不可变类型，浅拷贝和深拷贝效果相同，都是拷贝引用。因为不可变对象无法被修改。
```python
import copy

a = [1, 2, 3]
b = (4, 5, 6)
c = copy.copy(a)
d = copy.copy(b)

print(c is a) # False
print(d is b) # True
```
   - 当使用copy()函数进行浅拷贝的时候。如果顶层数据类型为可变类型，则进行浅拷贝；如果顶层数据类型为不可变类型，则仅拷贝引用，相当于`d=b`。
   - 当使用deepcopy()函数进行深拷贝的时候。如果顶层数据类型为可变类型，则进行深拷贝；如果顶层数据类型为不可变类型，则仅拷贝引用，相当于`d=b`。

2. **循环引用问题**  
   `deepcopy` 能处理循环引用，`copy` 模块内部有缓存机制。

3. **自定义对象**  
   若类实现了 `__deepcopy__` 方法，`deepcopy` 会调用它。

---

### 快速判断是否为同一对象

```python
a is b          # 检查是否同一对象（内存地址）
id(a) == id(b)  # 同上
```

---

### 总结一句话

> **浅拷贝只复制“表层”，深拷贝复制“整个结构”**。  
> 用 `copy.copy()` 复制外壳，用 `copy.deepcopy()` 复制全部。
