Python 中的 `property` 是用于**管理类属性访问**的强大机制，它允许你将方法伪装成属性，使用户可以通过点号（`.`）访问属性时，实际上执行自定义的逻辑（如 getter、setter、deleter），同时保持代码的简洁和封装性。

---

### 1. 基本概念

`property` 是 Python 的内置类，通过 `@property` 装饰器语法糖实现。

它常用于：
- 控制属性的读取、设置、删除行为
- 实现**计算属性**（如 `full_name` 由 `first_name` 和 `last_name` 计算得出）
- 向后兼容：将方法改为属性而不改变接口
- 数据验证

---

### 2. 基本用法（推荐：装饰器语法）

```python
class Person:
    def __init__(self, first_name, last_name):
        self.first_name = first_name
        self._last_name = last_name  # 私有存储

    @property
    def last_name(self):
        """getter：通过对象读取 last_name 时调用"""
        return self._last_name.upper()

    @last_name.setter
    def last_name(self, value):
        """setter：通过对象设置 last_name 时调用"""
        if not value.isalpha():
            raise ValueError("Last name must contain only letters")
        self._last_name = value

    @last_name.deleter
    def last_name(self):
        """deleter：通过对象删除 last_name 时调用"""
        print("Deleting last_name...")
        del self._last_name
```
- `property`装饰的函数必须要在`xxx.setter`和`xxx.deleter`装饰器装饰的函数之前。
- `property`修饰的函数名为：xxx，那么`xxx.setter`和`xxx.deleter`装饰器装饰的函数名称要为xxx。
#### 使用示例：

```python
p = Person("Alice", "smith")

print(p.last_name)        # 输出: SMITH（调用 getter）
p.last_name = "jones"     # 调用 setter（自动转为小写存储）
# p.last_name = "123"     # 报错：ValueError
del p.last_name           # 调用 deleter
```

### 3. 使用 `property()` 函数（传统方式）

```python
class Circle:
    def __init__(self, radius):
        self._radius = radius

    def get_area(self):
        return 3.14159 * self._radius ** 2

    def set_radius(self, value):
        if value < 0:
            raise ValueError("Radius cannot be negative")
        self._radius = value

    def del_radius(self):
        print("Deleting radius...")
        del self._radius

    area = property(get_area)  # 只读属性
    radius = property(fset=set_radius, fget=None, fdel=del_radius, doc="Radius of circle")
```

> 注意：这种方式较老，不推荐日常使用，装饰器更清晰。

### 4. 常见应用场景

#### ① 计算属性（只读）

```python
class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height

    @property
    def area(self):
        return self.width * self.height

rect = Rectangle(5, 3)
print(rect.area)  # 15（无需加括号，像属性一样访问）
```

#### ② 延迟计算 / 缓存

```python
import math

class Circle:
    def __init__(self, radius):
        self.radius = radius
        self._area = None

    @property
    def area(self):
        if self._area is None:
            print("Calculating area...")
            self._area = math.pi * self.radius ** 2
        return self._area
```

---

### 5. 注意事项

- `@property` 方法名必须相同
- `setter` 和 `deleter` 是可选的
- 不能同时有 `@property` 和直接赋值同名属性（会冲突）
- `property` 是**描述符协议**的一部分（高级主题）

| deleter      | `@name.deleter`        |
