> 虽然 `reduce` **不是内置函数**（在 Python 3 中被移到 `functools` 模块），但它与 `map`、`filter` 常被一起提及，称为“函数式三剑客”。

---

## 一、`map(function, iterable, ...)`

### 作用
将 **一个可迭代对象** 的 **每个元素** 都传入 `function`，返回一个 **新的迭代器**（`map` 对象）。

### 语法
```python
map(function, iterable, *iterables)
```

### 示例

```python
numbers = [1, 2, 3, 4]

# 1. 平方
squared = map(lambda x: x**2, numbers)
print(list(squared))  # [1, 4, 9, 16]

# 2. 多个可迭代对象
a = [1, 2, 3]
b = [10, 20, 30]
added = map(lambda x, y: x + y, a, b)
print(list(added))  # [11, 22, 33]
```

### 性能提示
- `map` 是 **惰性求值**，只有在迭代时才计算。
- 比列表推导式略快（尤其在 C 实现函数如 `str.upper` 时）。

```python
# 推荐：list(map(str.upper, words))
# 替代： [w.upper() for w in words]
```

---

## 二、`filter(function, iterable)`

### 作用
筛选出 `function` 返回 **True** 的元素，返回一个 **过滤后的迭代器**。

### 语法
```python
filter(function, iterable)
```

### 示例

```python
numbers = [1, 2, 3, 4, 5, 6]

# 筛选偶数
evens = filter(lambda x: x % 2 == 0, numbers)
print(list(evens))  # [2, 4, 6]

# 筛选非空字符串
words = ["", "hello", " ", "world"]
non_empty = filter(None, words)  # None 表示用元素自身判断真假
print(list(non_empty))  # ['hello', ' ', 'world']
```

> `filter(None, ...)` 是常用技巧：自动过滤“假值”（`0`, `""`, `[]`, `None` 等）

---

## 三、`functools.reduce(function, iterable[, initializer])`

### 作用
**累积计算**：将 `iterable` 的前两个元素传入 `function` → 得到结果 → 与下一个元素再传入 → 重复直到结束。

### 必须导入
```python
from functools import reduce
```

### 语法
```python
reduce(function, iterable, initializer=None)
```

### 示例

```python
from functools import reduce

numbers = [1, 2, 3, 4]

# 1. 求和（等价于 sum）
total = reduce(lambda x, y: x + y, numbers)
print(total)  # 10

# 2. 带初始值
total_with_init = reduce(lambda x, y: x + y, numbers, 100)
print(total_with_init)  # 110

# 3. 求最大值
max_val = reduce(lambda x, y: x if x > y else y, numbers)
print(max_val)  # 4
```

> 注意：`reduce` **从左到右** 累积。

---

## 对比总结表

| 函数 | 输入 | 输出 | 是否惰性 | 是否需要导入 |
|------|------|------|----------|---------------|
| `map` | 函数 + N 个可迭代对象 | 每个元素变换后的迭代器 | 是 | 否 |
| `filter` | 函数 + 1 个可迭代对象 | 满足条件的迭代器 | 是 | 否 |
| `reduce` | 函数 + 1 个可迭代对象 + 可选初始值 | **单个值** | 否（立即计算） | 是 |

## 实际应用场景（代码示例）

### 1. 数据清洗：字符串处理
```python
texts = ["  hello  ", "WORLD", "python  ", ""]
cleaned = map(str.strip, filter(None, texts))
upper = map(str.upper, cleaned)
print(list(upper))  # ['HELLO', 'WORLD', 'PYTHON']
```

### 2. 统计词频（结合 reduce）
```python
from functools import reduce
words = ["apple", "apple", "banana", "apple"]

freq = reduce(
    lambda d, w: {**d, w: d.get(w, 0) + 1},
    words,
    {}
)
print(freq)  # {'apple': 3, 'banana': 1}
```

### 3. 链式操作（Pythonic 写法）
```python
numbers = range(1, 11)

result = list(
    map(lambda x: x * 2,
        filter(lambda x: x % 2 == 1, numbers)
    )
)
print(result)  # [2, 6, 10, 14, 18]  # 奇数 × 2
```

## 常见误区 & 最佳实践

| 误区 | 正确做法 |
|------|----------|
| `map` 直接打印 → `<map object>` | `list(map(...))` 或循环 |
| `reduce` 忘记导入 | `from functools import reduce` |
| 用 `map` 做复杂逻辑 | 优先用 **列表推导式** 更清晰 |
| `filter` 写 `lambda x: x != None` | 用 `filter(None, ...)` |

---

## 性能对比（Python 3.12）

```python
import timeit

setup = '''
nums = list(range(1000))
'''

print(timeit.timeit('list(map(lambda x: x**2, nums))', setup=setup, number=10000))
print(timeit.timeit('[x**2 for x in nums]', setup=setup, number=10000))
```

> 结果：`map` 通常 **略快**（尤其对内置函数如 `str`, `int`）

---

## 小结：什么时候用哪个？

| 场景 | 推荐 |
|------|------|
| 每个元素变换 | `map` |
| 筛选子集 | `filter` |
| 累积计算（求和、乘积、最大值） | `reduce` |
| 简单变换 + 清晰 | **列表/字典/生成器推导式** |
