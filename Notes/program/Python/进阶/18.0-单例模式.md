下面是几种常见的 Python 单例（Singleton）实现方式，每种都有简要说明和完整示例。你可以根据需求选择合适的一种。

---

## 1. 装饰器方式（最简洁）

```python
def singleton(cls):
    instances = {}
    def wrapper(*args, **kwargs):
        if cls not in instances:
            instances[cls] = cls(*args, **kwargs)
        return instances[cls]
    return wrapper

@singleton
class MySingleton:
    def __init__(self, value):
        self.value = value

# 使用
s1 = MySingleton(10)
s2 = MySingleton(20)
print(s1 is s2)          # True
print(s1.value, s2.value)  # 10 10
```

---

## 2. 元类方式（最灵活，支持继承）

```python
class SingletonMeta(type):
    _instances = {}
    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            cls._instances[cls] = super().__call__(*args, **kwargs)
        return cls._instances[cls]

class MySingleton(metaclass=SingletonMeta):
    def __init__(self, value):
        self.value = value

# 使用
s1 = MySingleton(10)
s2 = MySingleton(20)
print(s1 is s2)          # True
print(s1.value)          # 10
```

---

## 3. 模块级单例（Pythonic，最推荐）

Python 的模块本身天然就是单例，只需要创建一个模块文件即可。

**singleton.py**

```python
class _Singleton:
    def __init__(self, value):
        self.value = value

# 模块被导入时只实例化一次
instance = _Singleton(0)

def get_instance():
    return instance
```

**使用**

```python
from singleton import get_instance

s1 = get_instance()
s1.value = 42

from singleton import get_instance
s2 = get_instance()
print(s1 is s2)      # True
print(s2.value)      # 42
```

---

## 4. `__new__` 重写方式（经典）

```python
class MySingleton:
    _instance = None
    
    def __new__(cls, *args, **kwargs):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance
    
    def __init__(self, value):
        # __init__ 每次都会被调用，但实例是同一个
        self.value = value

# 使用
s1 = MySingleton(10)
s2 = MySingleton(20)
print(s1 is s2)          # True
print(s1.value, s2.value)  # 20 20  （后调用的 __init__ 会覆盖）
```

> **注意**：`__init__` 会在每次 `MySingleton(...)` 时被调用，如果想避免覆盖属性，可加判断：

```python
def __init__(self, value):
    if not hasattr(self, 'value'):
        self.value = value
```

---

## 5. 线程安全的 `__new__` 版本

```python
import threading

class ThreadSafeSingleton:
    _instance = None
    _lock = threading.Lock()
    
    def __new__(cls, *args, **kwargs):
        with cls._lock:
            if cls._instance is None:
                cls._instance = super().__new__(cls)
        return cls._instance
    
    def __init__(self, value):
        if not hasattr(self, '_initialized'):
            self.value = value
            self._initialized = True
```

---

### 总结

| 方式       | 优点                           | 缺点                         | 推荐场景                     |
|------------|--------------------------------|------------------------------|------------------------------|
| 装饰器     | 简洁、易读                     | 不能很好支持继承             | 简单类                       |
| 元类       | 支持继承、灵活                 | 稍复杂                       | 需要继承的单例               |
| 模块       | 最 Pythonic、天然线程安全      | 需要额外文件                 | 任何生产环境                 |
| `__new__`  | 经典、易懂                     | `__init__` 多次调用需处理    | 学习/快速原型                |
| 线程安全   | 多线程安全                     | 略冗余                       | 高并发环境                   |

**推荐在生产代码中使用「模块级单例」**，既简单又可靠。
