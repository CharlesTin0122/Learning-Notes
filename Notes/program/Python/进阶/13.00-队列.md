在 Python 中，`Queue` 是一个非常常用的线程安全队列模块，主要用于**多线程编程**中线程之间的安全数据交换。它位于 `queue` 模块（注意：模块名是小写的 `queue`，不是 `Queue`）。
- queue.Queue 本质上就是数据结构中的“队列”（queue），只不过是 Python 标准库给它加了一层线程安全锁的实现而已。
	- 数据结构中的队列：`collections.deque`,是一个双向链表，先进先出，仅两端操作时线程安全
	- 线程安全队列：`queue.Queue`，内部用 deque + 锁，先进先出，线程安全
	- 线程安全栈：queue.LifoQueue，后进先出栈，线程安全
	- 线程安全优先级队列：queue.PriorityQueue，内部用 heapq，优先级队列，线程安全

### 1. 为什么需要 Queue？
在多线程程序中，如果多个线程直接操作同一个列表、字典等容器，容易出现数据竞争（race condition），导致程序崩溃或数据错乱。  
`queue.Queue` 提供了线程安全的 `put()` 和 `get()` 操作，内部自动加锁，程序员无需自己处理锁。

### 2. 常用的三种 Queue

| 类型                      | 模块/位置                | 特点                     | 典型使用场景            |
| ----------------------- | -------------------- | ---------------------- | ----------------- |
| `queue.Queue`           | 内置 `queue` 模块        | 线程安全的 FIFO（先进先出）队列     | 多线程任务队列（最常用）      |
| `queue.LifoQueue`       | 内置 `queue` 模块        | 后进先出（栈）                | 某些需要回溯的场景         |
| `queue.PriorityQueue`   | 内置 `queue` 模块        | 优先级队列（最小堆），可按优先级取出数据   | 任务调度、Dijkstra 算法等 |
| `collections.deque`     | 内置 `collections` 模块  | 双端队列，线程安全（仅两端操作时），速度极快 | 单线程高性能场景、滑动窗口等    |
| `multiprocessing.Queue` | `multiprocessing` 模块 | 进程安全的队列，用于多进程通信        | 多进程间传递数据          |
####  核心特性

- **线程安全 (Thread-Safe):** 这是 `queue.Queue` 最重要的特性。所有对队列的操作（如放入、取出）都包含了必要的锁机制，因此可以在多个线程中并发地使用，而不需要用户显式地处理锁和同步问题。
    
- **同步 (Synchronization):** 队列提供了内置的同步机制，线程在尝试从空队列中取出元素时会被**阻塞**，直到有其他线程放入元素；同样，如果是有界队列（设置了最大容量），线程在尝试向满队列中放入元素时也会被**阻塞**，直到有其他线程取出元素。
    
- **FIFO (First-In, First-Out):** `queue.Queue` 默认实现的是先进先出原则，这是它最常见的用法。

### 3. queue.Queue 的基本用法

```python
import queue
import threading
import time
import random

# 创建一个最大长度为10的队列（可选，不写表示无大小限制）
q = queue.Queue(maxsize=10)

# 生产者线程
def producer(name):
    for i in range(5):
        item = f"{name}-商品{i}"
        q.put(item)                     # 把数据放入队列（会阻塞直到有空位）
        print(f"{name} 生产了 {item}")
        time.sleep(random.random())

# 消费者线程
def consumer(name):
    while True:
        item = q.get()                  # 从队列取数据（如果队列为空会阻塞）
        print(f"{name} 消费了 {item}")
        q.task_done()                   # 告诉队列这个任务已经处理完毕
        time.sleep(random.random() * 2)

# 创建线程
t1 = threading.Thread(target=producer, args=("厂家A",))
t2 = threading.Thread(target=producer, args=("厂家B",))
t3 = threading.Thread(target=consumer, args=("消费者1",), daemon=True)
t4 = threading.Thread(target=consumer, args=("消费者2",), daemon=True)

t1.start()
t2.start()
t3.start()
t4.start()

t1.join()
t2.join()

# 主线程等待所有任务被消费完（配合 task_done）
q.join()
print("所有任务已完成！")
```

### 4. Queue 主要方法一览

| 方法                                      | 说明                                                                     |
| --------------------------------------- | ---------------------------------------------------------------------- |
| `q.put(item, block=True, timeout=None)` | 把 item 放入队列。<br>• block=False → 队列满时抛出 `queue.Full`<br>• timeout 可设置超时 |
| `q.put_nowait(item)`                    | 等价于 put(item, block=False)                                             |
| `q.get(block=True, timeout=None)`       | 从队列取出并移除一个元素                                                           |
| `q.get_nowait()`                        | 等价于 get(block=False)，队列为空抛出 `queue.Empty`                              |
| `q.task_done()`                         | 消费者调用，表示已经处理完一个从队列取出的任务                                                |
| `q.join()`                              | 阻塞直到队列所有元素都被取出并调用了 task_done()                                         |
| `q.qsize()`                             | 返回当前队列大小（注意：多线程下可能不准确）                                                 |
| `q.empty()`                             | 队列是否为空（多线程下不一定可靠）                                                      |
| `q.full()`                              | 队列是否已满（多线程下不一定可靠）                                                      |
- queue.Queue 内部维护了一个**“未完成任务计数器”**（unfinished_tasks），它的作用就是专门给 join() 用的。
#### 工作原理（内部机制）

|操作|对“未完成任务计数器”的影响|
|---|---|
|每调用一次 q.put(item)|计数器 +1|
|每调用一次 q.task_done()|计数器 -1|
|q.join()|**阻塞当前线程**，直到计数器 == 0 为止|

也就是说： **q.join() 阻塞的不是“队列变空”**，而是**“所有曾经 put 进队列的任务，都已经被消费者正确处理完毕（调用了 task_done）”**。

这点非常重要！很多初学者以为 join() 等队列空就返回，其实不然——如果消费者取出了元素但**忘记调用 task_done()**，join() 会**永远阻塞**！
### 5. PriorityQueue 示例（优先级队列）

```python
import queue

pq = queue.PriorityQueue()

# (priority_number, data)  元组，优先级数字越小越先取出
pq.put((3, "低优先级任务"))
pq.put((1, "紧急任务"))
pq.put((2, "普通任务"))

while not pq.empty():
    priority, task = pq.get()
    print(f"处理优先级 {priority} 的任务: {task}")
    
# 输出：
# 处理优先级 1 的任务: 紧急任务
# 处理优先级 2 的任务: 普通任务
# 处理优先级 3 的任务: 低优先级任务
```

### 6. 总结

- 多线程间传递数据 → 首选 `queue.Queue`
- 需要优先级排序 → 用 `queue.PriorityQueue`
- 多进程间通信 → 用 `multiprocessing.Queue`
- 单线程追求极致性能的双端操作 → 用 `collections.deque`
- 记住：`import queue`（小写），而不是 `Queue`

这是 Python 并发编程中最基础也最实用的工具之一，掌握好 Queue 就能轻松写出稳定可靠的多线程程序！
