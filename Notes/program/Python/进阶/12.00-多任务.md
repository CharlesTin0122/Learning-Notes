# 多任务：
- 现代操作系统（如Windows、Linux、macOS）都是**抢占式多任务**系统。
- 即使你开了50个程序（进程），操作系统会把它们切成成百上千个线程，然后快速轮流给CPU执行。
- 人眼感觉是“同时运行”，实际上是CPU在极短时间内（毫秒级）来回切换线程，这种切换叫**上下文切换**（context switch）。
- 所以程序数量的上限根本不是核心数，而是内存+系统资源。
# 并发和并行
- 并发靠切换（1个核心也能并发），并行靠多核（必须多个核心）。
- 并发（Concurrency）：多个任务轮流干，宏观看起来是同时进行的。 
- 并行（Parallelism）：多个任务真同时干，在同一时刻真的在同时执行。



# python 中的多任务
在Python中，“多任务”通常指让程序同时处理多个任务的能力。主要有以下几种实现方式，从易到难、从假并行到真并行依次介绍：

### 1. 多线程（Threading）——最常用但有GIL限制
适合 I/O密集型任务（如网络请求、文件读写、爬虫），不适合CPU密集型任务。

```python
import threading
import time

def task(name):
    print(f"任务 {name} 开始")
    time.sleep(2)
    print(f"任务 {name} 结束")

# 创建线程
t1 = threading.Thread(target=task, args=("A",))
t2 = threading.Thread(target=task, args=("B",))

t1.start()
t2.start()

t1.join()  # 等待线程结束
t2.join()
print("所有线程结束")
```

特点：
- Python的CPython解释器有GIL（全局解释器锁），同一时刻只有一个线程执行Python字节码，所以多线程无法利用多核CPU做计算密集任务。
- 但在I/O等待时会释放GIL，所以I/O密集型任务能显著提速。

常用类：
- threading.Thread
- threading.Lock、RLock、Semaphore、Event、Condition（线程同步）
- queue.Queue（线程安全的队列，非常推荐用于生产者-消费者模型）

### 2. 多进程（Multiprocessing）——真正并行
适合 CPU密集型任务（科学计算、图像处理等），可以充分利用多核CPU。

```python
from multiprocessing import Process
import os

def worker(num):
    print(f"子进程 {num} PID: {os.getpid()}")

if __name__ == '__main__':  # Windows必须加这句
    processes = []
    for i in range(5):
        p = Process(target=worker, args=(i,))
        processes.append(p)
        p.start()
    
    for p in processes:
        p.join()
```

特点：
- 每个进程有独立的Python解释器和内存空间，绕过了GIL，实现真正并行。
- 进程间通信较复杂，常用工具：
  - multiprocessing.Queue
  - multiprocessing.Pipe
  - multiprocessing.Manager（共享list、dict等）
  - multiprocessing.Pool（进程池，非常实用）

进程池示例（推荐）：
```python
from multiprocessing import Pool

def square(x):
    return x * x

if __name__ == '__main__':
    with Pool(4) as p:  # 使用4个进程
        result = p.map(square, [1,2,3,4,5,6,7,8])
    print(result)  # [1, 4, 9, 16, 25, 36, 49, 64]
```

### 3. 异步编程（Asyncio）——单线程高并发（现代推荐方式）
适合高并发I/O任务（如Web服务器、爬虫、聊天服务），现在是主流趋势。

Python 3.5+ 引入 async/await 语法：

```python
import asyncio

async def say_hello(name, delay):
    await asyncio.sleep(delay)  # 非阻塞等待
    print(f"Hello {name}")

async def main():
    # 同时运行多个协程
    await asyncio.gather(
        say_hello("Alice", 3),
        say_hello("Bob", 1),
        say_hello("Cathy", 2),
    )

asyncio.run(main())
```

常用库：
- asyncio（内置）
- aiohttp（异步HTTP客户端/服务器）
- aiofiles（异步文件读写）
- aiomysql、asyncpg（异步数据库）

优点：
- 单线程，无线程安全问题
- 性能极高（几万并发很轻松）
- 代码更现代、更清晰

### 4. concurrent.futures（高级封装，推荐）
Python 3.2+ 提供的统一接口，既能用线程也能用进程，用起来最简单。

```python
from concurrent.futures import ThreadPoolExecutor, ProcessPoolExecutor, as_completed

def task(n):
    return n * n

# 用线程池（I/O密集型）
with ThreadPoolExecutor(max_workers=5) as executor:
    futures = [executor.submit(task, i) for i in range(10)]
    for future in as_completed(futures):
        print(future.result())

# 用进程池（CPU密集型）
with ProcessPoolExecutor() as executor:
    results = executor.map(task, range(10))
    print(list(results))
```

### 总结对比表

| 方式                  | 并行类型 | 是否利用多核 | 适合场景                | 启动开销 | 通信难度 |
|---------------------------------------|----------|--------------|-------------------------|----------|----------|
| threading             | 并发     | 否（有GIL）  | I/O密集型（爬虫、网络） | 小       | 中等     |
| multiprocessing       | 并行     | 是           | CPU密集型（计算、AI）   | 大       | 较高     |
| asyncio               | 并发     | 否           | 高并发I/O（Web、微服务）| 极小     | 简单     |
| concurrent.futures    | 并发/并行| 取决于选择   | 通用，代码最简洁        | 中等     | 简单     |

### 实际选择建议（2025年推荐）
1. 高并发网络服务 → asyncio（FastAPI、Starlette）
2. 爬虫 → asyncio + aiohttp，或线程池（requests + ThreadPoolExecutor）
3. 数据处理、机器学习训练 → multiprocessing 或 multiprocessing.Pool
4. 简单并行任务 → concurrent.futures（代码最少）
5. 混合任务 → 进程做计算 + asyncio做I/O

现在主流项目基本都是 asyncio + 多进程 的组合方式，比如用uvicorn（基于asyncio）启动多个worker进程来充分利用CPU。
