Python 语言是完全面向对象的，一切皆对象。在面向对象编程（OOP）中，类和实例都有一些**内建属性**（也称为**特殊属性**或**魔术属性**），它们以双下划线 `__` 开头和结尾，称为 **dunder 属性**（double underscore）。这些属性由 Python 解释器自动定义，用于实现对象的特定行为。

方法其实本质上来讲也是属性，他们是指向代码块的属性。

下面系统地介绍 Python 面向对象中常见的**内建属性**，按**类**和**实例**分类说明。

---

## 一、类的内建属性（在类定义中自动存在）

| 属性                 | 说明                              | 示例                             |
| ------------------ | ------------------------------- | ------------------------------ |
| `__name__`         | 类的名称（字符串）                       | `MyClass.__name__ → 'MyClass'` |
| `__module__`       | 定义该类的模块名                        | `'__main__'` 或模块路径             |
| `__bases__`        | 父类的元组（继承链）                      | `(object,)`                    |
| `__dict__`         | 类的属性字典（可读写）                     | 包含类变量、方法等                      |
| `__doc__`          | 类的文档字符串（docstring）              | `None` 或用户定义的说明                |
| `__annotations__`  | 类型注解字典（Python 3.6+）             | `{'x': int}`                   |
| `__qualname__`     | 类的限定名称（支持嵌套类）                   | `'Outer.Inner'`                |
| `__mro__`          | 方法解析顺序（Method Resolution Order） | `(MyClass, object)`            |
| `__subclasses__()` | 返回直接子类的列表（方法）                   | `[SubClass1, SubClass2]`       |

```python
class Person:
    """一个人的类"""
    species = "Homo sapiens"

    def __init__(self, name):
        self.name = name

print(Person.__name__)        # Person
print(Person.__module__)      # __main__
print(Person.__bases__)       # (<class 'object'>,)
print(Person.__doc__)         # 一个人的类的
print(Person.__dict__)        # {'__module__': ..., 'species': ..., ...}
```

## 二、实例的内建属性（对象实例化后自动存在）

| 属性           | 说明           | 示例                                          |
| ------------ | ------------ | ------------------------------------------- |
| `__class__`  | 实例所属的类       | `obj.__class__ → <class '__main__.Person'>` |
| `__dict__`   | 实例的属性字典（可读写） | `{'name': 'Alice'}`                         |
| `__doc__`    | 继承自类的文档字符串   | 同 `Class.__doc__`；help(class/instance)      |
| `__module__` | 获取该实例所属类的模块  | 同 `Class.__module__`                        |

```python
p = Person("Alice")
print(p.__class__)    # <class '__main__.Person'>
print(p.__dict__)     # {'name': 'Alice'}
```

## 三、与方法绑定的内建属性（函数/方法对象）

当方法绑定到实例时，会变成 **bound method**，具有以下属性：

| 属性             | 说明      |
| -------------- | ------- |
| `__self__`     | 绑定的实例对象 |
| `__func__`     | 原始函数对象  |
| `__qualname__` | 方法的限定名  |

```python
def say(self):
    print(f"Hello, {self.name}")

Person.say = say
p = Person("Bob")

bound_method = p.say
print(bound_method.__self__)   # <Person object ...>
print(bound_method.__func__)   # <function say ...>
```

## 四、其他重要内建属性（与对象生命周期相关）

| 属性                                | 说明                           | 触发时机                     |
| --------------------------------- | ---------------------------- | ------------------------ |
| `__new__`                         | 控制对象创建（静态方法）                 | 对象实例化前                   |
| `__init__`                        | 初始化实例                        | 对象创建后                    |
| `__del__`                         | 析构函数（对象销毁前调用）                | 在对象的引用计数为 0 且被垃圾回收器回收时调用 |
| `__str__`                         | `str(obj)` 或 `print(obj)` 调用 | 需要可读字符串表示                |
| `__repr__`                        | `repr(obj)`，开发者友好            | 调试时或终端执行                 |
| `__format__`                      | 自定义 `format()` 行为            | `f"{obj:spec}"`          |
| `__bytes__`                       | `bytes(obj)`                 | 转换为字节                    |
| `__hash__`                        | `hash(obj)`，支持哈希             | 用作 dict 键或 set 元素        |
| `__eq__`, `__ne__`, `__lt__`, ... | 比较运算符重载                      | `==`, `!=`, `<` 等        |
- `__new__`方法是一个静态方法，负责 分配内存并创建实例，必须 返回一个实例对象（通常是 cls 的实例），只有返回的实例是 cls 的实例时，__init__ 才会被自动调用。
- `__new__`方法需要不定长参数` *args, **kwargs`来匹配`__init__` 的参数签名
- `super().__new__(cls)`不需要不定长参数，因为`super().__new__` 是“魔法方法”，参数由 Python 解释器自动处理，因为 `object.__new__` 只用 `cls` 来分配内存，它根本不关心参数；只有在**继承**不可变类型（如 str, int, tuple）时，才需要传参数，否则无法构造不可变类型
```python
class Singleton:
	"""实现单例模式"""
    _instance = None

    def __new__(cls, *args, **kwargs):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

    def __init__(self):
        pass  # __init__ 每次都会调用，但实例是同一个

# 测试
s1 = Singleton()
s2 = Singleton()
print(s1 is s2)  # True
```

## 五、属性访问相关内建属性（描述符协议）

| 属性                                 | 说明                              |
| ---------------------------------- | ------------------------------- |
| `__get__`, `__set__`, `__delete__` | 实现描述符（property、classmethod 等底层） |
| `__getattribute__`                 | 自定义属性访问（所有属性），获取属性自动调用          |
| `__getattr__`                      | 当属性不存在时调用（兜底）                   |
| `__setattr__`                      | 自定义属性赋值                         |
| `__dir__`                          | 自定义 `dir(obj)` 输出               |
- 调用属性顺序`obj.attr`
	1. 调用 `obj.__getattribute__('attr')`
	2. 如果属性不存在，调用` __getattr__('attr')`（仅当 `__getattribute__` 未拦截）
	3. 如果仍未找到，抛出 `AttributeError`
- 注意：`__getattribute__` 覆盖一切，即使属性不存在也会被它拦截！

```python
class Logger:
    def __init__(self):
        self.name = "Alice"
        self.age = 25
        self.password = "123456"

    def __getattribute__(self, attr_name):
        """属性拦截器：参数:name为访问属性的名称str"""
        print(f"正在访问属性: {attr_name}")
        # 必须返回属性值，否则会抛出 AttributeError
        if attr_name == "name":
            # 属性拦截
            return "Tom"
        elif attr_name == "password":
            # 禁止访问
            return "密码不可访问！"
        else:
            # 必须调用父类方法，否则无限递归！
            # 如果`return self.age`则继续调用getattribute，进入死循环无限递归
            return super().__getattribute__(attr_name)

    def __getattr__(self, name):
        return f"属性 {name} 不存在！"


obj = Logger()
print(obj.name)  # Tom
print(obj.age)  # 25
print(obj.password)  # 密码不可访问！
print(obj.username)  # 属性 username 不存在！
```

## 六、特殊容器协议内建属性

| 属性                                          | 说明         |
| ------------------------------------------- | ---------- |
| `__len__`                                   | `len(obj)` |
| `__getitem__`, `__setitem__`, `__delitem__` | `obj[key]` |
| `__iter__`, `__next__`                      | 可迭代协议      |
| `__contains__`                              | `in` 操作符   |
- __getitem__、__setitem__、__delitem__ 是 Python 中实现 容器协议（Container Protocol） 的三个核心魔法方法，用于让你的对象支持 索引访问（像列表、字典一样），获取键值，支持切片。
```python
obj[key]         # → obj.__getitem__(key)
obj[key] = value # → obj.__setitem__(key, value)
del obj[key]     # → obj.__delitem__(key)
```
- 案例
```python
class MyDict:
    def __init__(self):
        self.data = {}

    def __getitem__(self, key):
        print(f"获取: {key}")
        return self.data[key]  # 抛 KeyError 由 Python 自动处理

    def __setitem__(self, key, value):
        print(f"设置: {key} = {value}")
        self.data[key] = value

    def __delitem__(self, key):
        print(f"删除: {key}")
        del self.data[key]

    def __len__(self):
        return len(self.data)  # 支持 len()

    def __contains__(self, key):
        return key in self.data  # 支持 in

# 使用
d = MyDict()
d['name'] = 'Alice'     # → 设置: name = Alice
print(d['name'])        # → 获取: name → Alice
print("name" in d)      # True
del d['name']           # → 删除: name
```

## 总结：常用内建属性速查表

| 类别 | 属性 |
|------|------|
| **基本信息** | `__name__`, `__module__`, `__doc__`, `__qualname__` |
| **继承相关** | `__bases__`, `__mro__`, `__subclasses__()` |
| **属性存储** | `__dict__`, `__annotations__` |
| **实例绑定** | `__class__`, `__self__`, `__func__` |
| **对象协议** | `__str__`, `__repr__`, `__hash__`, `__eq__` |
| **生命周期** | `__new__`, `__init__`, `__del__` |
| **属性控制** | `__getattribute__`, `__getattr__`, `__setattr__` |

---

## 小贴士

- 这些属性是**只读或系统管理**的，不要手动修改（如 `__name__` 可改但不推荐）。
- 使用 `dir(obj)` 可以查看对象所有属性（包括内建的）。
- 使用 `vars(obj)` 或 `obj.__dict__` 查看可变属性字典。

```python
dir(Person)     # 列出所有属性
vars(Person)    # 等价于 Person.__dict__
```
