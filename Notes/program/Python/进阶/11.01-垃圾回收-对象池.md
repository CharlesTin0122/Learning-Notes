### Python 中的“对象池”（Object Pool）其实有好几种不同的概念，很多人一说“对象池”就容易混淆。下面把 Python 中真正存在的几种对象池一一说清楚：

| 类型                  | 负责的对象                        | 池的大小限制                  | 主要目的                     | 是否可以手动干预 |
|-----------------------|-----------------------------------|-------------------------------|------------------------------|------------------|
| 1. 小整数池（-5 ~ 256）| int（小整数）                     | 固定 -5 到 256                | 避免重复创建相同小整数       | 不可改           |
| 2. 字符串驻留池（intern）| 某些短字符串、标识符              | 动态，可达几万条              | 节省内存、加快比较           | 可手动 intern    |
| 3. 空元组/空容器单例   | (), [], {}, set() 等              | 永远只有 1 个实例             | 节省内存                     | 不可改           |
| 4. pymalloc 内存池     | 小对象（≤512 字节）               | 每个 arena 64KB，系统可有几百个 | 减少 malloc/free 开销、防碎片 | 不可直接控制     |
| 5. 自定义对象池        | 你自己写的类（如数据库连接、线程）| 自己决定                      | 复用昂贵资源                 | 完全可控         |

下面详细介绍每一种：

#### 1. 小整数池（最经典的池），无法被回收
```python
>>> a = 256
>>> b = 256
>>> a is b
True

>>> a = 257
>>> b = 257
>>> a is b
False        # 257 不在池中，每次都是新对象
```
- Python 启动时就预创建了 -5 到 256 这 262 个 int 对象
- 所有代码、所有模块、交互式环境都共用这 262 个实例
- 这是 CPython 的硬编码行为，其他实现（如 PyPy）不一定有

#### 2. 字符串驻留（intern）机制，引用计数为0自动回收
```python
# 看起来像标识符的字符串会自动 intern
>>> a = "hello_world"
>>> b = "hello_world"
>>> a is b
True

# 包含特殊字符的通常不会自动 intern
>>> a = "hello-world"
>>> b = "hello-world"
>>> a is b
False

# 可以手动强制加入池
>>> from sys import intern
>>> a = intern("hello-world" * 10)
>>> b = intern("hello-world" * 10)
>>> a is b
True
```
- 默认是自动对普通字符串开启intern驻留机制的，但是如果字符串中包含特殊字符（包含空格）的话是不会自动开启字符串驻留的。
#### 3. 空容器单例
```python
>>> a = []
>>> b = []
>>> a is b
False   # 空列表不是单例！引用计数为0自动回收

# 但是空元组是单例，不能回收
>>> a = ()
>>> b = ()
>>> a is b
True
```

#### 4. pymalloc 小对象内存池（真正干活的池）
这是 Python 自己实现的专属内存分配器，只管 ≤512 字节的对象。

结构如下：
- 1 arena = 256 KB（Linux 上）或 1 MB（Windows 上）
- 每个 arena 再切成很多小块（按 8 字节对齐，从 8 字节到 512 字节）
- 同一个 size 的空闲块用单向链表串起来 → 这就是“池”

当你 del 一个 list、dict、自定义对象（体积小）时：
1. 对象 __del__（如果有）执行
2. 引用计数归零
3. 内存块被放回对应 size 的空闲链表（池子）
4. 下次再创建同样大小的对象，直接从池子拿，速度飞快

这个池是 Python 内存不下降的主要原因（内存被 Python 自己缓存了，不是还给操作系统）。

#### 5. 自定义对象池（最实用）
常用于连接池、线程池、数据库游标等创建成本高的对象：

```python
# 简单连接池示例
from queue import Queue

class ConnectionPool:
    def __init__(self, factory, max_size=10):
        self._pool = Queue(max_size)
        self._factory = factory
        self._size = 0
        self.max_size = max_size

    def get(self):
        if self._pool.empty() and self._size < self.max_size:
            self._size += 1
            return self._factory()
        return self._pool.get()

    def put(self, conn):
        if not conn.is_closed():
            self._pool.put(conn)

# 使用
pool = ConnectionPool(lambda: mysql.connect(...), 20)
conn = pool.get()
# 用完
pool.put(conn)
```

### 总结：Python 里到底有哪些对象池？

| 池的名称              | 复用对象类型           | 是否全局共享 | 是否自动 | 能否关闭/修改 |
|-----------------------|------------------------|--------------|----------|---------------|
| 小整数池 (-5~256)     | int                    | 是           | 是       | 不能          |
| 字符串 intern 池      | 合法标识符短字符串     | 是           | 部分自动 | 可手动 intern |
| pymalloc 小对象池     | ≤512 字节的所有对象    | 是           | 是       | 不能（可禁用 pymalloc）|
| 自定义对象池          | 你想复用的任何对象     | 否           | 否       | 完全可控      |
