Python 语言是完全面向对象（OOP）的编程语言，支持面向对象的三大核心特性：**封装（Encapsulation）**、**继承（Inheritance）** 和 **多态（Polymorphism）**。下面分别介绍这三大特性及其在 Python 中的体现。

---

### 1. **封装（Encapsulation）**
**定义**：将数据（属性）和操作数据的方法绑定在一起，隐藏对象的内部实现细节，只暴露必要的接口。

**目的**：提高代码的安全性和可维护性，防止外部直接修改内部状态。

**Python 实现方式**：
- 使用类（`class`）将属性和方法封装在一个对象中。
- 通过命名约定控制访问权限：
  - **公有**：`self.name`（默认）
  - **保护**：`self._name`（单下划线，约定为受保护）
  - **私有**：`self.__name`（双下划线，名称改写机制，实际可通过 `_ClassName__name` 访问）

**示例**：
```python
class Person:
    def __init__(self, name, age):
        self.name = name          # 公有
        self._age = age           # 受保护
        self.__id = "12345"       # 私有

    def get_id(self):
        return self.__id

p = Person("Alice", 25)
print(p.name)      # Alice
print(p._age)      # 25（不推荐直接访问）
# print(p.__id)    # 报错：AttributeError
print(p.get_id())  # 12345
print(p._Person__id)  # 12345（名称改写后可访问）
```

---

### 2. **继承（Inheritance）**
**定义**：子类继承父类的属性和方法，实现代码复用。

**目的**：提高代码复用性，支持层次化设计。

**Python 特点**：
- 支持**单继承**和**多继承**
- 子类可以重写（override）父类方法
- 使用 `super()` 调用父类方法

**示例**：
```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        print("动物叫声")

class Dog(Animal):
    def speak(self):  # 方法重写
        print("汪汪！")

class Cat(Animal):
    def speak(self):
        print("喵喵！")

dog = Dog("旺财")
cat = Cat("咪咪")
dog.speak()  # 汪汪！
cat.speak()  # 喵喵！
```

**多继承示例**：
```python
class A:
    def method(self):
        print("A")

class B:
    def method(self):
        print("B")

class C(A, B):  # 多继承，方法解析顺序（MRO）
    pass

c = C()
c.method()  # 输出 A（遵循 C3 线性化算法）
```

---

### 3. **多态（Polymorphism）**
**定义**：同一接口（方法名）在不同对象上表现出不同的行为。

**目的**：增强代码灵活性和可扩展性。

**Python 实现**：
- Python 是**动态类型语言**，天然支持多态（鸭子类型：不关心对象类型，只关心是否有对应方法）
- 不需要显式声明接口

**示例**：
```python
class Dog:
    def speak(self):
        return "汪汪"

class Cat:
    def speak(self):
        return "喵喵"

def animal_sound(animal):
    print(animal.speak())  # 多态调用

animal_sound(Dog())  # 汪汪
animal_sound(Cat())  # 喵喵
```

---

### 总结表格

| 特性   | 核心思想                     | Python 实现方式                     |
|--------|------------------------------|-------------------------------------|
| 封装   | 隐藏内部细节，只暴露接口     | `class`、单/双下划线命名约定、`getter/setter` |
| 继承   | 复用父类代码                 | `class 子类(父类)`、`super()`、`多继承` |
| 多态   | 同一方法不同行为             | 动态类型 + 方法重写 + 鸭子类型       |

---

Python 的面向对象设计简洁灵活，尤其是**多态天然支持**，让代码更加“Pythonic”。掌握这三大特性，是写出优雅、可维护 Python 代码的关键！
