# Python 中的生成器（Generator）详解

**生成器** 是 Python 中一种特殊的**迭代器**，它允许你**惋惜地（lazily）生成值**，而不是一次性将所有结果存储在内存中。  
它使用 `yield` 关键字定义，极大提升了内存效率和代码可读性。

---

## 一、什么是生成器？

> **生成器 = 迭代器 + 惰性求值（Lazy Evaluation）**
- 生成器是一种特殊的**迭代器**，它利用迭代器的惰性求值特性，每次只生成一个数值，按需生成。
- 自动实现 `__iter__()` 和 `__next__()` 方法。
- 状态自动保存，适合处理大数据、流式数据、无限序列等。

---

## 二、两种创建生成器的方式

### 1. **生成器函数（Generator Function）** —— 使用 `yield`


```python
def count_down(n):
    while n > 0:
        yield n    # 暂停函数，返回值
        n -= 1

# 调用后返回一个生成器对象（不是立即执行）
gen = count_down(5)

print(gen)  # <generator object count_down at 0x...>
```

#### 使用方式：

```python
for x in count_down(5):
    print(x)
# 输出: 5 4 3 2 1
```

```python
gen = count_down(3)
print(next(gen))  # 3
print(next(gen))  # 2
print(next(gen))  # 1
# print(next(gen))  # StopIteration
```
- yield 是用来暂停函数并产出值的关键字， 让普通函数变成 “可逐个返回值的生成器”。
	- 如果是第一次执行，则从 def 代码块的开始部分执行，直到遇到 yield 为止,并且把,yield 关键字后的数值返回,当做 next()的返回值
	- 如果不是第一次执行,则从上一次暂停的位置执行(即从上一次 yield 关键字的下一个语句开始执行)，直到遇到下一次 yield 为止，并且把 yiel键字后的数值返回，当做 next()的返回值
### 2. **生成器表达式（Generator Expression）** —— 类似列表推导式

```python
# 列表推导式（一次性生成所有值）
squares_list = [x**2 for x in range(5)]  # [0, 1, 4, 9, 16]

# 生成器表达式（惋惜生成）
squares_gen = (x**2 for x in range(5))   # <generator object ...>

print(squares_gen)
```

#### 使用：

```python
for sq in squares_gen:
    print(sq)
# 输出: 0 1 4 9 16
```

> **区别**：
> - `[]` → 列表（占内存）
> - `()` → 生成器（惋惜，省内存）

## 三、生成器 vs 普通函数 vs 列表

| 特性               | 普通函数             | 生成器函数                  | 列表推导式             |
|--------------------|----------------------|-----------------------------|------------------------|
| 返回值             | 单个值 / 列表         | 生成器对象（迭代器）         | 完整列表               |
| 内存占用           | 可能很大              | 极小（只存状态）             | 全部元素               |
| 执行时机           | 立即执行              | 惋惜执行（调用 `next` 时）   | 立即执行               |
| 是否可迭代         | 否（除非返回可迭代）  | 是                          | 是                     |
| 是否可多次遍历     | 否                    | 否（一次性消耗）             | 是                     |

```python
# 内存对比示例：生成 1000 万个数字
def make_list():
    return list(range(10_000_000))  # 占用 ~800MB 内存

def make_gen():
    for i in range(10_000_000):
        yield i                     # 几乎不占内存
```

## 四、生成器的执行流程（关键！）

```python
def echo():
    print("开始")
    yield 1
    print("中间")
    yield 2
    print("结束")
    yield 3
```

```python
g = echo()
next(g)  # 开始 → 输出: 开始 → 返回 1
next(g)  # 中间 → 输出: 中间 → 返回 2
next(g)  # 结束 → 输出: 结束 → 返回 3
# next(g)  # StopIteration
```

> `yield` = **暂停 + 返回**，下次 `next()` 从暂停处继续。

## 五、经典应用场景

### 1. **处理大文件（逐行读取）**

```python
def read_lines(filename):
    with open(filename, encoding='utf-8') as f:
        for line in f:    # f 本身就是生成器
            yield line.strip()

for line in read_lines('large.log'):
    print(line)
```

### 2. **无限序列**

```python
def infinite_nums():
    n = 0
    while True:
        yield n
        n += 1

for x in infinite_nums():
    if x > 10:
        break
    print(x)
```

### 3. **管道式数据处理（类似 Linux `|`）**

```python
def numbers():
    for i in range(10):
        yield i

def even(gen):
    for x in gen:
        if x % 2 == 0:
            yield x

def square(gen):
    for x in gen:
        yield x * x

pipeline = square(even(numbers()))
print(list(pipeline))  # [0, 4, 16, 36, 64]
```

## 六、发送值给生成器：`send()`、`yield from`

### `generator.send(value)`

```python
def accumulator():
    total = 0
    while True:
        value = yield total      # 接收 send 进来的值
        if value is None:
            break
        total += value

g = accumulator()
print(next(g))      # 启动 → 0
print(g.send(10))   # 10
print(g.send(20))   # 30
g.close()
```

### `yield from`（Python 3.3+）

```python
def sub_generator():
    yield 1
    yield 2

def main_generator():
    yield 0
    yield from sub_generator()  # 委托给子生成器
    yield 3

list(main_generator())  # [0, 1, 2, 3]
```

## 七、生成器方法一览

| 方法           | 作用 |
|----------------|------|
| `next(g)`      | 获取下一个值 |
| `g.send(value)`| 向生成器发送值 |
| `g.throw(exc)` | 向生成器抛出异常 |
| `g.close()`    | 关闭生成器（触发 `GeneratorExit`） |

## 八、常见面试题

1. **生成器和迭代器的区别？**  
   → 生成器是迭代器的一种**实现方式**，更易用。

2. **`return` 在生成器中会怎样？**  
   ```python
   def gen():
       yield 1
       return "结束"
   ```
   → `return` 会抛出 `StopIteration("结束")`，提前终止。

3. **如何捕获生成器的 `StopIteration`？**

   ```python
   g = count_down(2)
   try:
       while True:
           print(next(g))
   except StopIteration:
       print("迭代结束")
   ```

## 九、总结：为什么用生成器？

| 优点 | 说明 |
|------|------|
| **节省内存** | 不存储所有数据 |
| **惋惜计算** | 需要时才计算 |
| **表示无限序列** | 如斐波那契、实时数据流 |
| **简化代码** | 替代复杂的状态机 |
| **支持管道处理** | 函数式编程风格 |

# 案例
```python
class FibonacciIter:
    """迭代器：斐波那契数列"""

    def __init__(self) -> None:
        self.num1, self.num2 = 0, 1

    def __iter__(self):
        return self

    def __next__(self):
        value = self.num1
        self.num1, self.num2 = self.num2, self.num1 + self.num2
        return value


def fibonacci_gener():
    """生成器：斐波那契数列"""
    a, b = 0, 1
    while True:
        yield a  # 产出当前值
        a, b = b, a + b  # 更新下一对


def my_generator(x, k=2, b=1):
    """生成器：y = kx +b"""
    while True:
        y = k * x + b
        yield y
        x = y


# 验证
if __name__ == "__main__":

    print(next(fib_iter))
    print(next(fib_iter))
    print(next(fib_iter))

    print("_" * 20)

    print(next(fib_gener))
    print(next(fib_gener))
```
