# Python 中的生成器（Generator）详解

**生成器** 是 Python 中一种特殊的**迭代器**，它允许你**惋惜地（lazily）生成值**，而不是一次性将所有结果存储在内存中。  
它使用 `yield` 关键字定义，极大提升了内存效率和代码可读性。

---

## 一、什么是生成器？

> **生成器 = 迭代器 + 惰性求值（Lazy Evaluation）**
- 生成器是一种特殊的**迭代器**，它利用迭代器的惰性求值特性，每次只生成一个数值，按需生成。
- 自动实现 `__iter__()` 和 `__next__()` 方法。
- 状态自动保存，适合处理大数据、流式数据、无限序列等。

---

## 二、两种创建生成器的方式
### 0. 迭代器实现斐波那契数列
```python
class FibonacciIter:
    """迭代器：斐波那契数列"""

    def __init__(self) -> None:
        self.num1, self.num2 = 0, 1

    def __iter__(self):
        return self

    def __next__(self):
        value = self.num1
        self.num1, self.num2 = self.num2, self.num1 + self.num2
        return value
if __name__ == "__main__":

    fib_iter = FibonacciIter()

    print(next(fib_iter))
    print(next(fib_iter))
    print(next(fib_iter))
    print(next(fib_iter))
    print(next(fib_iter))
```

### 1. 生成器函数实现斐波那契数列

```python
def fibonacci_gener():
    """生成器：斐波那契数列"""
    a, b = 0, 1
    while True:
        yield a  # 产出当前值
        a, b = b, a + b  # 更新下一对

if __name__ == "__main__":
	fib_gener = fibonacci_gener()
	
	print(next(fib_gener))
	print(next(fib_gener))
	print(next(fib_gener))
	print(next(fib_gener))
	print(next(fib_gener))
```

- yield 是用来暂停函数并产出值的关键字， 让普通函数变成 “可逐个返回值的生成器”。
	- 如果是第一次执行，则从 def 代码块的开始部分执行，直到遇到 yield 为止,并且把,yield 关键字后的数值返回,当做 next()的返回值
	- 如果不是第一次执行,则从上一次暂停的位置执行(即从上一次 yield 关键字的下一个语句开始执行)，直到遇到下一次 yield 为止，并且把 yiel键字后的数值返回，当做 next()的返回值
### 1.1 生成器中的`return`
```python
def generator_return():
    a, b = 0, 1
    t = a
    a, b = b, a + b
    yield t  # 1

    t = a
    a, b = b, a + b
    yield t  # 1

    t = a
    a, b = b, a + b
    yield t  # 2

    # 如果在调用next函数的时候，从上次yield暂停的位置向下运行，遇不到下一个yield，就会抛出StopIteration异常
    # 如果在调用next函数的时候，从上次yield暂停的位置向下运行，遇到return，会将return值存储于抛出的StopIteration异常,可用try来捕获异常
    return "已经生成了3个斐波那契数..."  # StopIteration: "已经生成了3个斐波那契数..."
```

- 执行
```python
gener = generator_return()
print(next(gener)) # 1
print(next(gener)) # 1
print(next(gener)) # 2
try:
	print(next(gener))
except StopIteration as res: # StopIteration
	print(res.value) # "已经生成了3个斐波那契数..."
	
```
### 2. **生成器表达式（Generator Expression）** —— 类似列表推导式

```python
# 列表推导式（一次性生成所有值）
squares_list = [x**2 for x in range(5)]  # [0, 1, 4, 9, 16]

# 生成器表达式（惋惜生成）
squares_gen = (x**2 for x in range(5))   # <generator object ...>

print(squares_gen)
```

#### 使用：

```python
for sq in squares_gen:
    print(sq)
# 输出: 0 1 4 9 16
```

> **区别**：
> - `[]` → 列表（占内存）
> - `()` → 生成器（惋惜，省内存）

## 三、生成器 vs 普通函数 vs 列表

| 特性               | 普通函数             | 生成器函数                  | 列表推导式             |
|--------------------|----------------------|-----------------------------|------------------------|
| 返回值             | 单个值 / 列表         | 生成器对象（迭代器）         | 完整列表               |
| 内存占用           | 可能很大              | 极小（只存状态）             | 全部元素               |
| 执行时机           | 立即执行              | 惋惜执行（调用 `next` 时）   | 立即执行               |
| 是否可迭代         | 否（除非返回可迭代）  | 是                          | 是                     |
| 是否可多次遍历     | 否                    | 否（一次性消耗）             | 是                     |

```python
# 内存对比示例：生成 1000 万个数字
def make_list():
    return list(range(10_000_000))  # 占用 ~800MB 内存

def make_gen():
    for i in range(10_000_000):
        yield i                     # 几乎不占内存
```

## 四、生成器的执行流程（关键！）

```python
def echo():
    print("开始")
    yield 1
    print("中间")
    yield 2
    print("结束")
    yield 3
```

```python
g = echo()
next(g)  # 开始 → 输出: 开始 → 返回 1
next(g)  # 中间 → 输出: 中间 → 返回 2
next(g)  # 结束 → 输出: 结束 → 返回 3
# next(g)  # StopIteration
```

> `yield` = **暂停 + 返回**，下次 `next()` 从暂停处继续。

## 五、经典应用场景

### 1. **处理大文件（逐行读取）**

```python
def read_lines(filename):
    with open(filename, encoding='utf-8') as f:
        for line in f:    # f 本身就是生成器
            yield line.strip()

for line in read_lines('large.log'):
    print(line)
```

### 2. **无限序列**

```python
def infinite_nums():
    n = 0
    while True:
        yield n
        n += 1

for x in infinite_nums():
    if x > 10:
        break
    print(x)
```

### 3. **管道式数据处理（类似 Linux `|`）**

```python
def numbers():
    for i in range(10):
        yield i

def even(gen):
    for x in gen:
        if x % 2 == 0:
            yield x

def square(gen):
    for x in gen:
        yield x * x

pipeline = square(even(numbers()))
print(list(pipeline))  # [0, 4, 16, 36, 64]
```

## 六、发送值给生成器：`send()`、`yield from`

### `generator.send(value)`
- 我们除了可以调用`next()`函数来唤醒生成器之外还可以使用`send()`函数来唤醒执行。
- 使用`send()`函数有一个好处：可以在唤醒的同时传入一个附加数据

```python
def generator_test():
    while True:
        print("--1--")
        num = yield 100
        print("--2--", "num= ", num)


gener = generator_test()
print(next(gener))
# 把 10 作为 yield 100 表达式的 返回值 赋值给 num → num = 10
print(gener.send(10))
print(gener.send(20))
```
- `yield` 表达式的返回值 = 调用者通过` .send(value)` 传入的值 ，如果使用 `next()`，则等价于` .send(None)`，所以返回 `None`
- **必须先调用一次 next(gener) 才能使用 send(value)**，否则会抛出 `TypeError`。因为生成器必须在 `yield` 表达式处暂停，才能调用`send()`，可以使用`send(None)`来替代`next()`.
#### 可以使用装饰器自动预启动
```python
def auto_start(gen_func):
    def wrapper(*args, **kwargs):
        g = gen_func(*args, **kwargs)
        next(g)      # 自动启动
        return g
    return wrapper

@auto_start
def my_gen():
    x = yield 100
    print("收到:", x)

g = my_gen()
g.send(999)  # 直接 send 成功！
```
### `yield from`（Python 3.3+）

```python
def sub_generator():
    yield 1
    yield 2

def main_generator():
    yield 0
    yield from sub_generator()  # 委托给子生成器
    yield 3

list(main_generator())  # [0, 1, 2, 3]
```

## 七、生成器方法一览

| 方法           | 作用 |
|----------------|------|
| `next(g)`      | 获取下一个值 |
| `g.send(value)`| 向生成器发送值 |
| `g.throw(exc)` | 向生成器抛出异常 |
| `g.close()`    | 关闭生成器（触发 `GeneratorExit`） |

## 八、常见面试题

1. **生成器和迭代器的区别？**  
   → 生成器是迭代器的一种**实现方式**，更易用。

2. **`return` 在生成器中会怎样？**  
   ```python
   def gen():
       yield 1
       return "结束"
   ```
   → `return` 会抛出 `StopIteration("结束")`，提前终止。

3. **如何捕获生成器的 `StopIteration`？**

   ```python
   g = count_down(2)
   try:
       while True:
           print(next(g))
   except StopIteration:
       print("迭代结束")
   ```

## 九、总结：为什么用生成器？

| 优点 | 说明 |
|------|------|
| **节省内存** | 不存储所有数据 |
| **惋惜计算** | 需要时才计算 |
| **表示无限序列** | 如斐波那契、实时数据流 |
| **简化代码** | 替代复杂的状态机 |
| **支持管道处理** | 函数式编程风格 |

# 案例
```python
def my_generator():
    """生成器：y = kx +b,每次的计算结果y赋值给x,返回点坐标（x,y）"""
    x = 0
    k = 2
    b = 1
    while True:
        y = k * x + b
        temp = yield (x, y)
        # 用于send()函数传入k，b的值
        if temp:
            k, b = temp
        # 计算结果y赋值给x
        x = y


if __name__ == "__main__":
    gener = my_generator()

    print(next(gener))
    print(gener.send((3, 2)))  # k=3,b=2
    print(next(gener))

```
