在Python中，“进程”（Process）是指操作系统中正在运行的一个程序实例，它拥有独立的内存空间、资源和执行环境。多进程是Python实现真正并行（parallelism）的核心手段，尤其适合CPU密集型任务（因为能绕过GIL全局解释器锁的限制）。

### 0. 当创建一个子进程时发生了什么

- 父进程启动一个新的 Python 解释器进程（相当于执行 python -c "..." 或 python.exe 新实例）
- 将要执行的函数（target）、参数（args）、全局变量等通过 pickle 序列化
- 通过管道（pipe）或套接字把序列化数据传给子进程
- 子进程启动后，反序列化代码和数据，重新导入模块（__main__ 模块会被重新执行！）
- 执行目标函数

>==这就是为什么在 multiprocessing 中必须把子进程代码写在：`if __name__ == '__main__':`里，因为 Windows 和 spawn 模式下，子进程会重新导入主模块，如果没有这个保护，会无限创建子进程。==
### 1. 最常用的 `multiprocessing` 模块（推荐）

这是Python标准库中最强大、最常用的多进程模块。

#### 基本用法示例：

```python
from multiprocessing import Process
import os
import time

def worker(num):
    print(f"进程 {num} 开始运行，PID: {os.getpid()}")
    time.sleep(2)
    print(f"进程 {num} 结束")

if __name__ == '__main__':  # Windows系统必须写这行保护入口
    processes = []
    for i in range(5):
        p = Process(target=worker, args=(i,))
        processes.append(p)
        p.start()  # 启动进程

    for p in processes:
        p.join()   # 等待所有子进程结束

    print("所有进程已完成")
```
#### 类用法示例：
```python
from multiprocessing import Process
import os
import time


class MyProcess(Process):
    def __init__(self, name, delay):
        super().__init__()
        self.name = name
        self.delay = delay

    def run(self):
        print(f"Process {self.name} starting with PID: {os.getpid()}")
        for i in range(5):
            time.sleep(self.delay)
            print(f"Process {self.name} (PID: {os.getpid()}) - Count: {i + 1}")
        print(f"Process {self.name} ending with PID: {os.getpid()}")


if __name__ == "__main__":
    processes = []
    for i in range(5):
        p = MyProcess(f"tarsk{i}", 1)
        processes.append(p)
        p.start()  # 启动进程

    for p in processes:
        p.join()  # 等待所有子进程结束

    print("所有进程已完成")

```

从 Python 3.8 开始，Process.join() 会自动调用底层的 os.waitpid() 回收子进程，所以现在大多数情况下你只需要写 p.join() 就既等待又回收了，不会留下僵尸进程。
#### 常用类和函数

| 类/函数                  | 作用                                   |
|--------------------------|----------------------------------------|
| `Process`                | 创建单个进程                           |
| `Pool`                   | 进程池（最常用，自动管理多个进程）      |
| `Queue`                  | 进程安全的队列，用于进程间通信          |
| `Pipe`                   | 进程间管道通信（父子进程间更快）        |
| `Value` / `Array`        | 共享内存（共享基本数据类型或数组）      |
| `Manager`                | 共享复杂数据结构（如dict、list）        |

#### 进程池 Pool 最常见用法（推荐用于大量任务）

```python
from multiprocessing import Pool
import time

def task(x):
    time.sleep(1)
    return x * x

if __name__ == '__main__':
    with Pool(processes=4) as pool:  # 使用4个进程
        results = pool.map(task, range(10))  # 自动分配任务
    print(results)  # [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
```


### 2. `concurrent.futures` 模块（更现代的接口）

Python 3.2+ 提供的统一接口，同时支持线程和进程：

```python
from concurrent.futures import ProcessPoolExecutor
import math

def compute(n):
    return math.factorial(n)

with ProcessPoolExecutor(max_workers=4) as executor:
    results = list(executor.map(compute, [10, 15, 20, 25]))
print(results)
```

### 进程 vs 线程 的关键区别（面试常问）

| 特性               | 多进程 (multiprocessing)         | 多线程 (threading)              |
|--------------------|-----------------------------------|---------------------------------|
| 是否真正并行       | 是（多核CPU可充分利用）           | 否（受GIL限制，同一时间只一个线程执行Python代码） |
| 内存空间           | 独立（各自有独立Python解释器和内存） | 共享                           |
| 数据共享难度       | 较难（需要Queue、Pipe、Manager等） | 容易（共享全局变量）            |
| 稳定性             | 一个进程崩溃不影响其他             | 一个线程崩溃可能导致整个进程崩溃 |
| 启动开销           | 大                               | 小                              |
| 适合场景           | CPU密集型（计算、科学计算、爬虫限速绕过） | IO密集型（网络、文件读写）      |

### 进程间通信常见方式总结

- 注意：进程之间不共享全局变量

1. `Queue`（最推荐，进程安全）
2. `Pipe()`（父子进程间高速通信）
3. `Manager()`（共享list、dict等复杂对象）
4. `multiprocessing.Value` 和 `Array`（共享简单数值和数组）
5. 文件、数据库、socket（通用但较慢）

### 小结：什么时候用多进程？

- 需要真正利用多核CPU（CPU密集型任务）
- 需要更高的稳定性（子进程崩溃不影响主进程）
- 需要绕过GIL限制
- 爬虫中需要突破网站并发限制（每个进程独立IP行为）

典型应用场景：数据处理、科学计算、机器学习特征工程、视频转码、高并发爬虫等。

推荐优先使用 `multiprocessing.Pool` 或 `concurrent.futures.ProcessPoolExecutor`，代码简洁且高效。
