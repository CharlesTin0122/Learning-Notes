## 类中嵌套类的基本语法

```python
class MyList:
    def __init__(self, data):
        self.data = data

    def __iter__(self):
        return self.ListIterator(self)  # 返回内部迭代器

    # 嵌套类：迭代器
    class ListIterator:
        def __init__(self, my_list):
            self.my_list = my_list
            self.index = 0

        def __iter__(self):
            return self

        def __next__(self):
            if self.index >= len(self.my_list.data):
                raise StopIteration
            value = self.my_list.data[self.index]
            self.index += 1
            return value
```

## 使用示例

```python
# 创建自定义列表
my_lst = MyList([10, 20, 30])

# 支持 for 循环！
for item in my_lst:
    print(item)
# 输出：
# 10
# 20
# 30
```

## 为什么要在类中嵌套类？—— 三大优势

| 优势 | 说明 |
|------|------|
| **封装性强** | `ListIterator` 只服务于 `MyList`，不污染全局命名空间 |
| **访问外部类数据** | 内部类可以直接访问外部类的属性（如 `self.my_list.data`） |
| **逻辑清晰** | 迭代器是“附属品”，嵌套更符合语义 |

## 进阶技巧

### 1. 嵌套类访问外部类（Outer Class）

```python
class Outer:
    value = "我是外部类"

    class Inner:
        def show(self):
            print(Outer.value)  # 直接访问外部类的类变量
```

### 2. 多个嵌套类（状态模式）

```python
class TrafficLight:
    class Red:
        def next(self): return TrafficLight.Green()
        def action(self): print("Stop!")

    class Green:
        def next(self): return TrafficLight.Yellow()
        def action(self): print("Go!")

    class Yellow:
        def next(self): return TrafficLight.Red()
        def action(self): print("Caution!")

    def __init__(self):
        self.state = self.Red()

    def change(self):
        self.state = self.state.next()
        self.state.action()
```

---

### 3. 嵌套类 + 闭包 = 更灵活

```python
def create_counter(start=0):
    class Counter:
        def __init__(self):
            self.count = start
        def inc(self):
            self.count += 1
            return self.count
    return Counter()

c = create_counter(10)
print(c.inc())  # 11
```

## 注意事项

| 注意点 | 说明 |
|--------|------|
| 嵌套类是**静态的** | 不自动绑定外部实例，除非手动传 `self` |
| 不能直接写 `self.value` | 除非在 `__init__` 中传入外部实例 |
| 命名空间隔离 | `MyList.ListIterator` 不会和全局 `ListIterator` 冲突 |

## 最佳实践总结

```python
class Container:
    def __iter__(self):
        return self.Iterator(self)  # 传入 self

    class Iterator:                 # 嵌套在 Container 内
        def __init__(outer_self, container):
            outer_self.container = container
            outer_self.index = 0

        def __next__(outer_self):
            if outer_self.index >= len(outer_self.container.data):
                raise StopIteration
            ...
```

> 推荐：**迭代器、生成器、状态类、配置类** 都嵌套在主类中
