### Python 中的匿名函数（Lambda 函数）

Python 中的**匿名函数**（也称为 **lambda 函数**）是一种**无需命名**的**小型函数**，用于定义**简单的、单表达式**的函数逻辑。它通常在需要**函数作为参数传递**的场景中使用，例如 `map()`、`filter()`、`sorted()` 等高阶函数。

---

#### 基本语法

```python
lambda 参数列表: 表达式
```

- `lambda`：关键字
- `参数列表`：可以有 0 个或多个参数，用逗号分隔
- `:` 后面必须是一个**表达式**（不能是语句，如 `print`、`if` 块等）
- 返回值：表达式的计算结果（自动 `return`）

---

#### 示例

##### 1. 简单加法
```python
add = lambda x, y: x + y
print(add(3, 5))  # 输出: 8
```

##### 2. 无参数
```python
greet = lambda: "Hello!"
print(greet())  # 输出: Hello!
```

##### 3. 配合 `map()` 使用
```python
numbers = [1, 2, 3, 4]
squared = list(map(lambda x: x**2, numbers))
print(squared)  # 输出: [1, 4, 9, 16]
```

##### 4. 配合 `filter()` 使用
```python
nums = [1, 2, 3, 4, 5, 6]
evens = list(filter(lambda x: x % 2 == 0, nums))
print(evens)  # 输出: [2, 4, 6]
```

##### 5. 配合 `sorted()` 排序（自定义键）
```python
pairs = [(1, 'one'), (3, 'three'), (2, 'two')]
sorted_pairs = sorted(pairs, key=lambda x: x[1])
print(sorted_pairs)
# 输出: [(1, 'one'), (3, 'three'), (2, 'two')] 按第二个元素字母排序
```

---

#### 优点

- 简洁：适合一次性、简单的函数逻辑
- 就地定义：不需要单独用 `def` 定义函数
- 常用于函数式编程风格

---

#### 局限性

- **只能包含一个表达式**（不能写多行代码、循环、复杂条件）
- **不可包含语句**（如 `print`、`return`、`if` 语句块等）
- **调试困难**：没有函数名，报错时难以定位
- **不建议用于复杂逻辑**（此时应使用 `def` 定义普通函数）

 不推荐：
 ```python
 lambda x: if x > 0: x else -x  # 语法错误！
 ```

推荐（复杂逻辑用 `def`）：
```python
def abs_value(x):    
	return x if x >= 0 else -x
```

---

#### 小技巧：立即调用（IIFE）

```python
result = (lambda x, y: x * y)(3, 4)
print(result)  # 输出: 12
```

---

### 总结

| 特性         | lambda 函数         | 普通函数（def）       |
|--------------|---------------------|-----------------------|
| 是否命名     | 否（匿名）          | 是                    |
| 表达式数量   | 仅 1 个             | 任意                  |
| 适合场景     | 简单、临时函数      | 复杂、复用逻辑        |
| 调试友好性   | 差                  | 好                    |

**推荐使用场景**：`map`、`filter`、`sorted`、`key` 参数、GUI 回调等。
