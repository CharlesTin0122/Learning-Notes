**描述器（Descriptor）** 是 Python 中一个**强大而底层**的协议，它是 `@property`、`@classmethod`、`@staticmethod` 等装饰器的**实现基石**，也是 Python 数据模型的核心机制之一。

---

## 一、定义（官方一句话）

> **描述器是一个实现了描述器协议（`__get__`、`__set__`、`__delete__` 任意一个）的对象**，当它被用作**类的属性**时，Python 会自动调用它的这些方法来控制属性的访问。

```python
class Descriptor:
    def __get__(self, instance, owner): ...
    def __set__(self, instance, value): ...
    def __delete__(self, instance): ...
```

---

## 二、三大协议方法

| 方法 | 触发时机 | 参数说明 |
|------|---------|--------|
| `__get__(self, instance, owner)` | 读取属性：`obj.attr` 或 `Cls.attr` | `instance` 是实例，`owner` 是类 |
| `__set__(self, instance, value)` | 赋值：`obj.attr = value` | |
| `__delete__(self, instance)` | 删除：`del obj.attr` | |

> 只要类中定义了以上任一方法，它就是**描述器**。

---

## 三、描述器只有在**类属性**中才生效！

```python
class MyDescriptor:
    def __get__(self, instance, owner):
        print("触发 __get__")
        return "描述器返回值"

class MyClass:
    attr = MyDescriptor()  # 必须是类属性！

obj = MyClass()
print(obj.attr)  # 触发 __get__ → 输出 "描述器返回值"
```

**反例（不生效）**：
```python
class MyClass:
    def __init__(self):
        self.attr = MyDescriptor()  # 实例属性 → 不是描述器！

obj = MyClass()
print(obj.attr)  # 直接返回 MyDescriptor 对象，不会触发 __get__
```

---

## 四、描述器类型分类

| 类型 | 必须实现 | 特点 |
|------|----------|------|
| **数据描述器（Data Descriptor）** | `__get__` + `__set__` | **优先级最高**，覆盖实例属性 |
| **非数据描述器（Non-data Descriptor）** | 仅 `__get__` | 实例属性可覆盖 |

### 示例对比

```python
class DataDesc:
    def __get__(self, instance, owner): return "data"
    def __set__(self, instance, value): pass

class NonDataDesc:
    def __get__(self, instance, owner): return "non-data"

class Test:
    data = DataDesc()
    nondata = NonDataDesc()

t = Test()
t.nondata = "我覆盖了"  # 成功！非数据描述器可被实例属性覆盖
# t.data = "我不能覆盖"  # 报错或被 __set__ 拦截

print(t.data)      # "data"
print(t.nondata)   # "我覆盖了"
```

## 五、经典应用：`@property` 就是描述器！

```python
class Property:
    def __init__(self, fget): self.fget = fget
    def __get__(self, instance, owner):
        if instance is None: return self
        return self.fget(instance)

# @property 装饰器等价于：
def property(fget):
    return Property(fget)
```

所以：
```python
class C:
    @property
    def x(self):
        return self._x
```
等价于：
```python
class C:
    def _get_x(self): return self._x
    x = property(_get_x)
```

## 六、`@classmethod` 和 `@staticmethod` 也是描述器！

| 装饰器 | 实际返回 | 关键方法 |
|--------|---------|---------|
| `@classmethod` | `classmethod` 对象 | `__get__` 绑定 `cls` |
| `@staticmethod` | `staticmethod` 对象 | `__get__` 返回原始函数 |

```python
class classmethod:
    def __get__(self, instance, owner):
        return self.func.__get__(owner, owner)  # 绑定类

class staticmethod:
    def __get__(self, instance, owner):
        return self.func  # 原样返回
```

## 七、手写一个完整描述器：温度转换

```python
class Celsius:
    def __init__(self):
        self._c = 0

    def __get__(self, instance, owner):
        return self._c

    def __set__(self, instance, value):
        if value < -273.15:
            raise ValueError("温度不能低于绝对零度")
        self._c = value

class Fahrenheit:
    def __get__(self, instance, owner):
        return instance.celsius * 1.8 + 32

    def __set__(self, instance, value):
        instance.celsius = (value - 32) / 1.8

class Temperature:
    celsius = Celsius()
    fahrenheit = Fahrenheit()

# 使用
t = Temperature()
t.celsius = 25
print(t.fahrenheit)  # 77.0

t.fahrenheit = 98.6
print(t.celsius)     # 37.0
```

## 八、描述器查找顺序（重要！）

```text
1. 数据描述器（有 __set__）
2. 实例的 __dict__
3. 非数据描述器（只有 __get__）
4. 类的 __dict__（从 MRO 查找）
5. 父类
```

> **数据描述器 > 实例属性 > 非数据描述器**

## 九、常见面试题

**Q1：描述器和属性查找顺序？**  
A：数据描述器优先于实例属性。

**Q2：`@property` 为什么能控制读写？**  
A：因为它返回一个**数据描述器**，`__get__`/`__set__` 拦截访问。

**Q3：手写一个 `@cached_property`？**

```python
from functools import wraps

class cached_property:
    def __init__(self, func):
        self.func = func
        self.name = func.__name__

    def __get__(self, instance, owner):
        if instance is None:
            return self
        value = self.func(instance)
        instance.__dict__[self.name] = value  # 缓存到实例
        return value

# 使用
class Circle:
    def __init__(self, r): self.r = r

    @cached_property
    def area(self):
        print("计算中...")
        return 3.14 * self.r ** 2

c = Circle(5)
print(c.area)  # 计算中... → 78.5
print(c.area)  # 直接返回 78.5（不再计算）
```

## 十、总结：一句话定义

> **描述器是“属性访问的钩子”**，通过实现 `__get__`/`__set__`/`__delete__`，控制类属性的读取、赋值、删除行为，是 Python 面向对象最底层的魔法。

---

## 描述器家族一览

| 功能 | 实现方式 |
|------|--------|
| `@property` | 内置数据描述器 |
| `@classmethod` | 绑定 `cls` 的描述器 |
| `@staticmethod` | 返回原函数的描述器 |
| ORM 字段 | 自定义描述器（如 Django `Field`） |
| 验证、缓存、日志 | 自定义描述器 |
