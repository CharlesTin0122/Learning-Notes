## Python 中的多继承与 MRO（方法解析顺序）

Python 是支持**多继承**的语言，即一个类可以同时继承多个父类。多继承带来了灵活性，但也可能导致**菱形继承（Diamond Problem）**等歧义问题。为解决这些问题，Python 引入了 **C3 线性化算法** 来确定 **MRO（Method Resolution Order，方法解析顺序）**。

---

### 1. 多继承基本语法

```python
class A:
    def hello(self):
        print("A")

class B(A):
    pass

class C(A):
    def hello(self):
        print("C")

class D(B, C):   # 多继承：D 继承 B 和 C
    pass

d = D()
d.hello()        # 输出什么？C
```


---

### 2. MRO 的作用

当调用 `d.hello()` 时，Python 按 **MRO 顺序** 在类的继承链中查找 `hello` 方法，直到找到第一个实现。

查看 MRO：

```python
print(D.mro())  
# 或
print(D.__mro__)
```

输出（Python 3）：

```
[<class '__main__.D'>, <class '__main__.B'>, <class '__main__.C'>, <class '__main__.A'>, <class 'object'>]
```

所以 `d.hello()` → 查找顺序：`D → B → C → A → object`，找到 `C.hello` → 输出 **C**

---

### 3. C3 线性化算法（Python 使用的 MRO 算法）

C3 算法确保：

1. **子类优先于父类**
2. **父类保持它们在继承列表中的相对顺序**
3. **单调性**：如果 A 在 B 的 MRO 中排在 C 前面，那么在所有继承 A 的子类中，A 也必须排在 C 前面

#### 计算公式（简化理解）

对于类 `D(B, C)`，其 MRO 为：

```
D + merge(MRO(B), MRO(C), [B, C])
```

其中 `merge` 按顺序取第一个“合法”的头元素（即不在其他列表尾部的元素）。

---

### 4. 菱形继承示例（经典问题）

```python
class A:
    def hello(self):
        print("A")

class B(A):
    pass

class C(A):
    pass

class D(B, C):   # 菱形：D -> B -> A, D -> C -> A
    pass
```

MRO：

```python
print(D.mro())
# [<class 'D'>, <class 'B'>, <class 'C'>, <class 'A'>, <class 'object'>]
```

- `B` 和 `C` 都继承 `A`，但 `A` 只出现**一次**（在最后）
- 解决了“调用哪个 `A`”的歧义

---

### 5. 使用 `super()` 在多继承中

`super()` 按 **MRO 顺序** 调用下一个类的方法，非常适合协作式多继承（Cooperative Inheritance）。

```python
class A:
    def __init__(self):
        print("A init")
        super().__init__()

class B(A):
    def __init__(self):
        print("B init")
        super().__init__()

class C(A):
    def __init__(self):
        print("C init")
        super().__init__()

class D(B, C):
    def __init__(self):
        print("D init")
        super().__init__()

d = D()
```

输出：

```
D init
B init
C init
A init
```

> 注意：所有类都必须正确使用 `super()`，否则可能跳过某些初始化！

---

### 6. 常见错误与注意事项

| 问题 | 说明 |
|------|------|
| 不一致的 `super()` | 某些类没调用 `super()` → 跳过后续初始化 |
| MRO 不一致 | `class D(C, B)` 会改变顺序 |
| 循环继承 | Python 会报错：`TypeError: Cannot create a consistent method resolution order` |

```python
class X: pass
class Y(X): pass
class Z(Y, X):  # 合法
    pass

# class P(X, Y):  # 非法：X 在 Y 之后，但 Y 继承 X → 矛盾
```

---

### 7. 实用工具

```python
# 查看 MRO
D.mro()
D.__mro__

# 检查继承关系
issubclass(D, B)      # True
isinstance(d, A)      # True

# 动态创建类并查看 MRO
type('E', (B, C), {}).mro()
```

---

### 总结

| 特性 | 说明 |
|------|------|
| 多继承 | 支持，语法 `class D(B, C):` |
| MRO | 方法解析顺序，由 C3 算法决定 |
| 查看 MRO | `Class.mro()` 或 `Class.__mro__` |
| `super()` | 按 MRO 调用下一个类，需所有类配合 |
| 菱形问题 | C3 保证基类只出现一次 |
| 最佳实践 | 所有相关类都使用 `super()`，保持继承顺序清晰 |

---

**建议**：设计多继承时，尽量保持**线性化、可预测**的继承图，避免复杂耦合。推荐使用 **Mixin 模式** 来实现功能组合。

```python
class LogMixin:
    def log(self, msg):
        print(f"[{self.__class__.__name__}] {msg}")

class MyClass(Base, LogMixin):
    pass
```

这样既清晰又安全。
