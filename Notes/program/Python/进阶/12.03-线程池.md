Python 中的线程池主要用来解决频繁创建和销毁线程带来的性能开销，尤其适合大量短时任务的并发执行场景。

Python 提供了两个主要的线程池实现方式：

### 1. concurrent.futures.ThreadPoolExecutor（推荐，Python 3.2+）
这是最常用、最现代的方式，属于 `concurrent.futures` 模块，接口简洁，易于使用。

```python
from concurrent.futures import ThreadPoolExecutor, as_completed
import time

def task(name, delay):
    print(f"任务 {name} 开始")
    time.sleep(delay)
    return f"任务 {name} 完成"

# 创建线程池
with ThreadPoolExecutor(max_workers=5) as executor:
    # 方法1：submit 提交任务
    futures = [executor.submit(task, f"task-{i}", 2) for i in range(10)]

    # 获取结果（按提交顺序）
    for future in futures:
        print(future.result())

    # 方法2：map（保持返回顺序）
    results = executor.map(task, [f"task-{i}" for i in range(5)], [1, 2, 3, 4, 5])
    for r in results:
        print(r)

    # 方法3：as_completed（谁先完成先返回）
    futures = [executor.submit(task, f"async-{i}", i%3) for i in range(8)]
    for future in as_completed(futures):
        print(future.result())
```

**优点**：
- 使用 `with` 语句自动关闭线程池
- 支持 `submit`、`map`、`as_completed` 三种灵活方式
- 自动处理异常（future.result() 会抛出任务中的异常）

### 2. threading + queue 手动实现线程池（旧方式）
早期常用的方式，虽然灵活但代码较多。

```python
import threading
import queue
import time

class ThreadPool:
    def __init__(self, num_threads=5):
        self.task_queue = queue.Queue()
        self.threads = []
        self.stop_flag = False
        
        for _ in range(num_threads):
            t = threading.Thread(target=self._worker)
            t.daemon = True
            t.start()
            self.threads.append(t)
    
    def _worker(self):
        while not self.stop_flag:
            try:
                func, args, kwargs = self.task_queue.get(timeout=1)
                func(*args, **kwargs)
            except queue.Empty:
                continue
            except Exception as e:
                print(f"任务执行出错: {e}")
            finally:
                self.task_queue.task_done()
    
    def submit(self, func, *args, **kwargs):
        self.task_queue.put((func, args, kwargs))
    
    def shutdown(self):
        self.stop_flag = True
        for t in self.threads:
            t.join()

# 使用示例
def worker(x):
    time.sleep(1)
    print(f"处理 {x}")

pool = ThreadPool(10)
for i in range(50):
    pool.submit(worker, i)

pool.shutdown()
```

### 3. 第三方库（更高级功能）
- `threadpool`（较老）
- `multiprocessing.dummy.Pool`（实际上就是线程池，接口和 multiprocessing.Pool 一样）

```python
from multiprocessing.dummy import Pool as ThreadPool

def task(x):
    time.sleep(1)
    return x * x

pool = ThreadPool(8)
results = pool.map(task, range(20))
pool.close()
pool.join()
print(results[:10])
```

### 线程池关键参数说明

| 参数              | 说明                                                                 |
|-------------------|----------------------------------------------------------------------|
| max_workers       | 最大线程数，默认是 `min(32, os.cpu_count() + 4)`                     |
| thread_name_prefix | 线程名称前缀，便于调试                                               |

### 注意事项（非常重要！）

1. **GIL 的影响**  
   Python 的 CPython 解释器有全局解释器锁（GIL），同一时刻只有一个线程执行 Python 字节码。  
   所以线程池适合 **I/O 密集型任务**（网络请求、文件读写、数据库操作），不适合 CPU 密集型任务（用进程池 `ProcessPoolExecutor`）。

2. **不要在子线程中再次创建线程池**（容易导致死锁或资源耗尽）

3. **推荐始终使用 with 语句**，自动调用 shutdown()

4. **共享数据的注意线程安全**（使用 `queue.Queue` 或 `threading.Lock`）

### 总结推荐用法（2025年最佳实践）

```python
from concurrent.futures import ThreadPoolExecutor
import requests

def download(url):
    return requests.get(url).status_code

urls = ["https://httpbin.org/delay/1"] * 20

with ThreadPoolExecutor(max_workers=10) as executor:
    results = list(executor.map(download, urls))

print(f"成功: {results.count(200)}, 失败: {results.count(404)}")
```

这就是 Python 中线程池的完整介绍，日常开发中 99% 的场景使用 `ThreadPoolExecutor` 就够了，简单、高效、安全。
