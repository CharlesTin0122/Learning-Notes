## Python `with` 语句与**上下文管理器**（Context Manager）详解

`with` 是 Python 中最优雅的语法之一，它的核心是 **“自动管理资源”** —— 无论代码块是否异常，都能**正确地打开、关闭、清理资源**。

---

### 一句话总结：
> **`with` = 自动调用 `__enter__` 和 `__exit__`，确保资源安全释放**

---

## 一、`with` 语句的基本语法

```python
with 表达式 [as 变量]:
    代码块
```

- `表达式`：必须返回一个**上下文管理器对象**
- `as 变量`：接收 `__enter__()` 的返回值（可选）

```python
with open('data.txt', 'r', encoding='utf-8') as f:
    content = f.read()
# 自动关闭文件 f
```

---

## 二、上下文管理器协议（Context Manager Protocol）

一个对象要支持 `with`，必须实现以下两个**魔法方法**：

| 方法 | 作用 |
|------|------|
| `__enter__(self)` | 进入 `with` 块时调用，返回值可被 `as` 绑定 |
| `__exit__(self, exc_type, exc_value, traceback)` | 退出 `with` 块时调用（无论正常还是异常） |

```python
class MyContext:
    def __enter__(self):
        print("进入上下文")
        return "我是要被 as 绑定的值"

    def __exit__(self, exc_type, exc_value, traceback):
        print("退出上下文")
        if exc_type:
            print(f"发生异常: {exc_type}")
        return False  # 不吞异常；返回 True 可吞异常

with MyContext() as value:
    print("在 with 块中:", value)
    # raise ValueError("测试异常")
```

输出：
```
进入上下文
在 with 块中: 我是要被 as 绑定的值
退出上下文
```

## 三、常见内置上下文管理器

| 场景 | 上下文管理器 | 说明 |
|------|-------------|------|
| 文件操作 | `open()` | 自动 `close()` |
| 线程锁 | `threading.Lock()` | 自动 `acquire/release` |
| 数据库 | `sqlite3.connect()` | 自动 `commit/rollback` |
| 临时目录 | `tempfile.TemporaryDirectory()` | 自动删除 |
| 忽略异常 | `contextlib.suppress()` | 吞掉指定异常 |

```python
import threading
import sqlite3
from tempfile import TemporaryDirectory
from contextlib import suppress

lock = threading.Lock()
with lock:
    # 自动上锁/解锁
    pass

with sqlite3.connect(':memory:') as conn:
    conn.execute('CREATE TABLE t(x)')

with TemporaryDirectory() as tmp:
    print(tmp)  # 自动删除目录

with suppress(FileNotFoundError):
    open('no_such_file.txt').read()
```

## 四、`contextlib` 模块 —— 简化上下文管理器

位于 `contextlib` 的工具让写上下文管理器**像写生成器一样简单**。

### 1. `@contextmanager` 装饰器（最常用）

```python
from contextlib import contextmanager

@contextmanager
def timer(name):
    import time
    start = time.time()
    try:
        yield  # ← yield 前：__enter__，yield 后：__exit__
    finally:
        print(f"{name} 耗时: {time.time() - start:.2f}s")

# 使用
with timer("下载"):
    time.sleep(1)
```

> `yield` 前的代码 → `__enter__`  
> `yield` 后的代码 → `__exit__`（即使异常也执行）

---

### 2. `contextlib.suppress(*exceptions)`

```python
from contextlib import suppress

with suppress(KeyError, IndexError):
    value = d[missing_key][0]  # 即使出错也不抛异常
```

---

### 3. `contextlib.redirect_stdout` / `redirect_stderr`

```python
from contextlib import redirect_stdout
import io

f = io.StringIO()
with redirect_stdout(f):
    print("这不会显示在终端")
output = f.getvalue()
print("捕获输出:", output)
```

---

### 4. `contextlib.ExitStack` —— 动态管理多个上下文

```python
from contextlib import ExitStack

with ExitStack() as stack:
    files = [stack.enter_context(open(fname)) for fname in ['a.txt', 'b.txt']]
    # 所有文件自动关闭，即使中途异常
```

## 五、手写上下文管理器 vs `@contextmanager`

| 方式 | 适用场景 |
|------|---------|
| **类 + `__enter__/__exit__`** | 需要复杂状态管理 |
| **`@contextmanager` + `yield`** | 简单、清晰、推荐 |

```python
# 类方式
class Database:
    def __enter__(self):
        self.conn = connect_db()
        return self.conn
    def __exit__(self, *args):
        self.conn.close()

# 生成器方式（推荐）
@contextmanager
def database():
    conn = connect_db()
    try:
        yield conn
    finally:
        conn.close()
```

## 六、异常处理机制详解

`__exit__` 接收三个参数：

```python
def __exit__(self, exc_type, exc_value, traceback):
```

| 参数 | 含义 |
|------|------|
| `exc_type` | 异常类型（如 `ValueError`） |
| `exc_value` | 异常实例 |
| `traceback` | 堆栈信息 |
| **返回 `True`** | **吞掉异常**（不向外抛） |
| **返回 `False` 或不返回** | 异常继续向外传播 |

```python
@contextmanager
def ignore_error():
    try:
        yield
    except ZeroDivisionError:
        print("忽略除零错误")
        return True  # 吞异常

with ignore_error():
    print(1 / 0)  # 不崩溃
```

## 七、实战案例：数据库事务管理

```python
@contextmanager
def transaction(db):
    try:
        yield db
        db.commit()
        print("事务提交")
    except:
        db.rollback()
        print("事务回滚")
        raise  # 重新抛出异常

# 使用
with get_db() as db, transaction(db):
    db.execute("INSERT INTO users ...")
    # 1 / 0  # 触发回滚
```

## 十、总结：`with` 的三大价值

| 价值 | 说明 |
|------|------|
| **资源安全** | 自动关闭文件、锁、连接 |
| **代码简洁** | 省去 `try...finally` |
| **异常安全** | 无论如何都执行清理 |

## 彩蛋：一行代码实现“临时切换目录”

```python
from contextlib import contextmanager
import os

@contextmanager
def cd(path):
    old = os.getcwd()
    os.chdir(path)
    try:
        yield
    finally:
        os.chdir(old)

with cd('/tmp'):
    print(os.getcwd())  # /tmp
print(os.getcwd())      # 回到原目录
```
