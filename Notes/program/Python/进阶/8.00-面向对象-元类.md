### Python 中的元类（Metaclass）介绍

Python 是一门“万物皆对象”的语言，包括**类本身也是对象**。而**元类（metaclass）**就是**创建类对象的类**。简单来说：

> **类是对象的实例，元类是类的“类”**。
- ...元类 （type）-->元类（type） --> 类(class) -->实例(instance)

所有对象（包括类）都是 object 的实例；所有类都是 type 的实例；type 本身也是 object 的子类，同时又是自己的实例——这构成了 Python 的 元对象模型（metaclass model）。object 是父类（决定实例行为），type 是元类（决定类如何创建）。
```
type  → 继承自 object
type  → 是自己的 metaclass（metaclass=type）
type  → 创建所有普通类
普通类 → 继承自 object（默认）
普通类 → 实例化得到实例对象
```

```
                +------------------+
                |     object       |   ← 所有对象的基类
                +--------+---------+
                         ↑
            (继承)       |
                         |
                +--------+---------+
                |       type        |   ← 所有类的默认元类
                +--------+---------+
                         ↑
            (metaclass)  |
                         |
          +--------------+--------------+
          |                             |
   自定义类（如 MyClass）          内置类（如 int、list）
          |                             |
   metaclass=type               metaclass=type
          |                             |
   实例化 ↓                     实例化 ↓
   实例对象                     实例对象
```
- 创建流程：从无到有
```python
# 1. type 创建 object（Python 启动时已完成）
object = type('object', (), {...})

# 2. type 创建 type 本身（自举）
type = type('type', (object,), {...})

# 3. type 创建用户自定义类
MyClass = type('MyClass', (object,), {'x': 1})

# 4. MyClass 创建实例
obj = MyClass()
```
- 等价于
```python
class MyClass:
    x = 1
obj = MyClass()
```

## 1. 基本概念

- 普通类（如 `class MyClass:`）的实例是对象。
- 但 `MyClass` 本身也是一个对象，这个对象是由**元类**创建的。
- Python 默认的元类是 **`type`**。

```python
class MyClass:
    pass

# MyClass 是 type 的实例
print(type(MyClass))  # <class 'type'>
```

所以：

```python
MyClass = type('MyClass', (), {})  # 动态创建类，等价于上面的 class 定义
```

## 2. 自定义元类

你可以通过继承 `type` 来自定义元类。
- `type`类有三个参数：
	- name （str）：类名
	- bases（tuple）：父类
	- dict（dict）：属性字典
- 运行`type()`时返回类对象本身
### 示例：快速创建类
```python
class Bird:
    num = 100

def print_instance(self):
    """实例方法"""
    print(f"name: {self.name},age: {self.age}")

@classmethod
def print_num(cls):
    """类方法"""
    print(cls.num)

@staticmethod
def print_speak():
    """静态方法"""
    print("JiJiJi")

# 创建类：类名字符串，父类元组，属性字典
Eagle = type(
    "Eagle",
    (Bird,),
    {
        "name": "Eagle",
        "age": 3,
        "print_instance": print_instance,
        "print_num": print_num,
        "print_speak": print_speak,
    },
)

if __name__ == "__main__":
    eagle = Eagle()
    eagle.print_instance()  # name: Eagle,age: 3
    eagle.print_num()  # 100
    eagle.print_speak()  # JiJiJi
    print(type(eagle))  # <class '__main__.Eagle'>
```
### 示例：一个属性名改为大写的元类

```python
class UpperAttrMeta(type):
    """元类"""

    def __new__(cls, class_name: str, class_bases: tuple, class_dict: dict):
        """将自定义属性名称改为大写，再生成类对象
        Args:
            class_name (str): 类名
            class_bases (tuple): 父类
            class_dict (dict):属性
        Returns:
            _type_: 类对象
        """
        new_dict = dict()
        for name, value in class_dict.items():
            if not name.startswith("__"):
                new_dict[name.upper()] = value
        # 也可以使用:
        # return type(class_name, class_bases, new_dict)
        return super().__new__(cls, class_name, class_bases, new_dict)


# 使用 UpperAttrMeta 作为元类创建 MyClass 类
class MyClass(metaclass=UpperAttrMeta):
    x = 10
    y = "bipo"

    def print_info(self):
        print(f"X:{self.X}, Y:{self.Y}")


if __name__ == "__main__":
    my_class = MyClass()
    # 使用大写来调用函数
    print(my_class.X) # 10
    print(my_class.Y) # bipo
    my_class.PRINT_INFO() # X:10, Y:bipo
```

输出：

```
10
bipo

```

## 3. 元类的关键魔术方法

元类主要通过重写以下方法控制类的创建：

| 方法 | 作用 |
|------|------|
| `__new__(cls, name, bases, namespace)` | 实际创建类对象（分配内存） |
| `__init__(cls, name, bases, namespace)` | 类创建后初始化（类似 `__init__`） |
| `__call__(cls, *args, **kwargs)` | 控制实例化过程（如 `MyClass()` 调用） |

### 示例：单例元类

```python
class SingletonMeta(type):
    _instances = {}
    
    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            cls._instances[cls] = super().__call__(*args, **kwargs)
        return cls._instances[cls]

class Database(metaclass=SingletonMeta):
    def __init__(self):
        self.connection = "Connected!"

db1 = Database()
db2 = Database()
print(db1 is db2)  # True
```

## 4. 常见使用场景

| 场景 | 说明 |
|------|------|
| **单例模式** | 确保全局只有一个实例 |
| **ORM 框架（如 Django models）** | 自动注册模型、添加字段验证 |
| **API 框架** | 自动注册路由、参数检查 |
| **插件系统** | 动态发现和加载类 |
| **代码检查/日志** | 在类创建时记录或验证 |

---

## 5. 类创建过程总结

```text
用户定义 class A(metaclass=M):
     ↓
调用 M.__new__() 创建类对象
     ↓
调用 M.__init__() 初始化类
     ↓
返回类对象 A
     ↓
A() → 调用 M.__call__() → 创建实例
```

---

## 6. 注意事项

- 元类是**高级特性**，滥用会让代码难以理解。
- 优先考虑：**继承、装饰器、描述器**，再考虑元类。
- 元类影响**所有子类**，要谨慎设计。
- 调试元类问题较难，建议加日志。

## 小结

| 概念 | 说明 |
|------|------|
| 默认元类 | `type` |
| 自定义元类 | `class MyMeta(type):` |
| 指定元类 | `class A(metaclass=MyMeta):` |
| 核心方法 | `__new__`, `__init__`, `__call__` |
| 典型用途 | 单例、ORM、注册机制 |

---

**一句话总结**：

> **元类是类的类，用于控制类的创建行为，是 Python 元编程的终极武器。**
