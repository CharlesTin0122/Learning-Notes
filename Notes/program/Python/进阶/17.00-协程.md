### Python中的协程（Coroutines）详解

协程是Python中实现**异步并发**的核心机制之一，它允许我们在单线程中“暂停”和“恢复”函数的执行，从而实现高效率的I/O并发（比如网络请求、文件读写等）而不阻塞线程。

#### 1. 协程的发展历史
- Python 3.4：引入`asyncio`模块和`yield from`语法，支持原始协程
- Python 3.5：引入`async def`和`await`关键字（PEP 492），正式称为**原生协程（native coroutine）**
- Python 3.6：引入`async for`和`async with`（异步迭代器和异步上下文管理器）
- Python 3.7：`asyncio`成为正式标准库的一部分
- Python 3.11+：性能大幅提升，引入Task Group、异常组等新特性

#### 2. 基本语法（Python 3.5+ 推荐写法）

```python
import asyncio

# 定义一个异步函数（协程函数）
async def hello():
    print("Hello")
    await asyncio.sleep(1)   # 模拟I/O操作，暂停协程，切换到其他协程
    print("World!")

async def main():
    await hello()            # 等待hello协程完成
    await hello()

# 运行协程
asyncio.run(main())
```

输出：
```
Hello
World!
Hello
World!
```

关键关键字：
- `async def`：定义一个协程函数，调用后返回一个**协程对象（coroutine object）**
- `await`：只能在`async def`函数内部使用，暂停当前协程，等待另一个可等待对象（awaitable）完成

#### 3. 三种主要的可等待对象（Awaitables）
1. **协程（coroutine）**：`async def`定义的函数调用返回的对象
2. **Task（任务）**：对协程的封装，交给事件循环后台运行
3. **Future**：底层低级对象，类似JS中的Promise

#### 4. 并发执行多个协程（重点）

```python
async def task(name, delay):
    print(f"{name} 开始")
    await asyncio.sleep(delay)
    print(f"{name} 结束")

async def main():
    # 方法1：逐个await（串行）
    # await task("A", 2)
    # await task("B", 1)

    # 方法2：并发执行（推荐）
    await asyncio.gather(
        task("A", 2),
        task("B", 1),
        task("C", 3)
    )

    # 方法3：创建Task后台运行
    # t1 = asyncio.create_task(task("A", 2))
    # t2 = asyncio.create_task(task("B", 1))
    # await t1
    # await t2

asyncio.run(main())
```

输出（大约3秒完成，而不是6秒）：
```
A 开始
B 开始
C 开始
B 结束
A 结束
C 结束
```

#### 5. 常见的异步库生态（都基于协程）
- `aiohttp`：异步HTTP客户端/服务器
- `aiomysql`、`asyncpg`：异步数据库
- `aiofiles`：异步文件读写
- `quart`、`fastapi`、`starlette`：异步Web框架

#### 6. 协程 vs 线程 vs 多进程 对比

| 特性               | 协程（asyncio）       | 线程（threading）     | 多进程             |
|--------------------|-----------------------|-----------------------|--------------------|
| 并发模型           | 协作式（主动让出）     | 抢占式                | 抢占式             |
| 切换开销           | 极小（微秒级）         | 中等（毫秒级）         | 很大               |
| 适合场景           | I/O密集型             | I/O密集 + 轻量CPU     | CPU密集型          |
| GIL影响            | 不受影响（单线程）     | 受GIL限制             | 不受影响           |
| 调试难度           | 较高                  | 中等                  | 较低               |

#### 7. 常见错误写法（坑）

```python
# 错误：忘记await，直接调用协程函数
hello()  # 只创建了协程对象，什么都不执行！

# 错误：在普通函数里使用await
def normal():
    await asyncio.sleep(1)  # SyntaxError!

# 错误：阻塞调用（如time.sleep、requests.get）会卡死整个事件循环
async def bad():
    time.sleep(5)           # 千万不要这样！
    requests.get("http://") # 也千万不要！
```

#### 8. 小结

- 协程是Python实现**高并发I/O**的最优雅方式
- 使用`async def` + `await` + `asyncio.run()`是现代写法
- 配合`asyncio.gather()`或`create_task()`实现真正并发
- 永远不要在异步代码中调用阻塞函数，否则会阻塞整个事件循环

**协程让Python在单线程里也能轻松实现成千上万的并发网络连接，性能接近Go/Node.js，是现代Python后端开发的标配。**
