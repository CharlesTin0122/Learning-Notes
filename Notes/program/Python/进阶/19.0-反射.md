Python 中的反射（Reflection）是指**程序在运行时能够检查、访问、甚至修改自身结构和行为的能力**。Python 作为一门动态语言，天生支持非常强大的反射机制，主要通过以下四个内置函数实现：

### 反射四大核心函数

| 函数         | 作用说明                                   | 常见用法场景                              |
|--------------|--------------------------------------------|-------------------------------------------|
| `getattr(obj, name[, default])`   | 获取对象 `obj` 上名为 `name` 的属性/方法     | 动态调用方法、访问属性                     |
| `setattr(obj, name, value)`       | 给对象 `obj` 设置名为 `name` 的属性为 `value` | 动态添加/修改属性                         |
| `hasattr(obj, name)`              | 判断对象 `obj` 是否有名为 `name` 的属性/方法 | 安全地检查属性是否存在                    |
| `delattr(obj, name)`              | 删除对象 `obj` 上名为 `name` 的属性         | 动态删除属性                              |

### 经典示例

```python
class Person:
    def __init__(self, name):
        self.name = name
    
    def say_hello(self):
        print(f"Hello, 我是 {self.name}")

# 正常调用
p = Person("张三")
p.say_hello()                 # Hello, 我是 张三

# 使用反射动态调用
method_name = "say_hello"
if hasattr(p, method_name):
    func = getattr(p, method_name)
    func()                    # Hello, 我是 张三（反射调用）

# 动态添加属性
setattr(p, "age", 18)
print(p.age)                  # 18

# 动态修改属性
setattr(p, "name", "李四")
getattr(p, "say_hello")()     # Hello, 我是 李四

# 删除属性
delattr(p, "age")
print(hasattr(p, "age"))      # False
```

### 结合 `__dict__` 和 `type()` 更强大的反射

```python
# 查看对象所有可访问的属性和方法
print(p.__dict__)             
# {'name': '李四'}

# 动态创建类（元编程）
def constructor(self, name):
    self.name = name

def say_hi(self):
    print("Hi,", self.name)

# 动态创建一个类
DynamicClass = type("DynamicClass", (object,), {
    "__init__": constructor,
    "say_hi": say_hi,
    "country": "China"   # 甚至可以动态添加类属性
})

obj = DynamicClass("王五")
obj.say_hi()                     # Hi, 王五
print(obj.country)               # China
```

### 常见实际应用场景

1. **框架/插件系统**（最典型）
   - Flask、Django 的路由装饰器本质上就是利用反射把 URL 映射到函数
   - 实现插件热加载：根据配置文件动态 import 模块并调用指定函数

2. **序列化/反序列化**
   ```python
   # 根据字段列表自动把对象转成 dict
   def to_dict(obj, fields):
       return {field: getattr(obj, field) for field in fields}
   ```

3. **通用工具函数**
   ```python
   # 通用调用器（比如 RPC、命令分发）
   def call_command(obj, command_name, *args, **kwargs):
       if hasattr(obj, command_name):
           return getattr(obj, command_name)(*args, **kwargs)
       else:
           raise AttributeError(f"No such command: {command_name}")
   ```

4. **ORM 框架**
   - 根据模型类名动态创建表、根据字段名动态生成 SQL 等

### 注意事项 & 最佳实践

- 反射很强大，但**滥用会让代码难以阅读和调试**，能用显式方式就不要用反射
- 性能略低于直接访问（有一次字典查找）
- 使用 `hasattr` 防止 `AttributeError`
- 配合 `try-except` 更安全

```python
try:
    func = getattr(obj, method_name)
    result = func(*args)
except AttributeError:
    print("方法不存在")
```

总结一句话：
**Python 的反射就是“让程序在运行时能像看镜子一样看到自己，并能摸到、改掉镜子里的东西”**，是实现框架、插件系统、动态配置等高级功能的核心机制之一。掌握好这四个函数（`getattr/setattr/hasattr/delattr`），你就掌握了 Python 反射的 90%。
