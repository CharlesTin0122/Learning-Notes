在 Python 中，`__slots__` 是一个特殊的类属性，用于**优化对象的内存使用**并**限制实例可以拥有的属性**。它主要用于性能敏感的场景，比如创建大量实例时。

---

### 一、默认情况下 Python 对象的属性存储方式

默认情况下，Python 的实例属性存储在一个名为 `__dict__` 的字典中：

```python
class Person:
    pass

p = Person()
p.name = "Alice"
p.age = 25

print(p.__dict__)  # {'name': 'Alice', 'age': 25}
```

这种方式灵活，但每个实例都会有一个 `__dict__` 字典，**占用额外内存**（尤其是创建成千上万个对象时）。

---

### 二、使用 `__slots__` 优化内存

通过声明 `__slots__`，你可以告诉 Python：**这个类的实例只允许拥有指定的属性，并且不使用 `__dict__`**。

```python
class Person:
    __slots__ = ('name', 'age')  # 只允许 name 和 age 属性

    def __init__(self, name, age):
        self.name = name
        self.age = age
```

#### 效果：
- 实例**没有 `__dict__`** 和 `__weakref__`（除非显式声明）
- 属性存储在固定大小的结构中，**节省内存**
- **不能动态添加未在 `__slots__` 中声明的属性**

```python
p = Person("Alice", 25)
print(p.name)  # Alice

# 尝试添加未声明的属性 → 报错
p.height = 170  # AttributeError: 'Person' object has no attribute 'height'
```

---

### 三、内存节省示例

```python
import sys

class A:  # 普通类
    pass

class B:  # 使用 __slots__
    __slots__ = ('x', 'y')

a = A()
b = B()

a.x = a.y = 1
b.x = b.y = 1

print(sys.getsizeof(a))  # 通常更大（包含 __dict__）
print(sys.getsizeof(b))  # 更小（固定结构）
```

> 实际测试中，`B` 的实例通常比 `A` 小 50% 以上（尤其在大量实例时明显）。

---

### 四、注意事项与限制

| 特性 | 说明 |
|------|------|
| 无 `__dict__` | 不能动态添加属性 |
| 无 `__weakref__` | 默认不支持弱引用（除非在 `__slots__` 中加入 `'__weakref__'`） |
| 继承问题 | 子类若未声明 `__slots__`，会恢复使用 `__dict__` |
| 多继承复杂 | 所有父类都用 `__slots__` 时需小心属性冲突 |

#### 示例：支持弱引用

```python
class Person:
    __slots__ = ('name', '__weakref__')  # 允许弱引用
```

---

### 五、继承中的 `__slots__`

```python
class Animal:
    __slots__ = ('species',)

class Dog(Animal):
    __slots__ = ('name',)  # 子类也声明 __slots__

d = Dog()
d.species = "Canis"
d.name = "Buddy"
```

如果子类**不声明 `__slots__`**，则会自动获得 `__dict__`，失去内存优化。

---

### 六、适用场景

| 适合使用 `__slots__` | 不适合使用 |
|---------------------|------------|
| 创建**大量实例**（如游戏中的粒子、数据记录等） | 需要**动态属性**的类（如 ORM 模型） |
| 内存敏感型应用 | 频繁添加/删除属性的场景 |
| 高性能数据结构 | 通用类、配置类 |

---

### 七、总结

| 功能 | 说明 |
|------|------|
| `__slots__ = ('attr1', 'attr2', ...)` | 声明允许的实例属性 |
| 节省内存 | 避免为每个实例创建 `__dict__` |
| 限制属性 | 防止意外添加属性（更安全） |
| 提高访问速度 | 属性查找更快（略） |

---

### 示例：完整对比

```python
# 普通类
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

# 优化版
class PointSlots:
    __slots__ = ('x', 'y')
    def __init__(self, x, y):
        self.x = x
        self.y = y

p1 = Point(1, 2)
p2 = PointSlots(1, 2)

print(hasattr(p1, '__dict__'))     # True
print(hasattr(p2, '__dict__'))     # False
```

---

**结论：`__slots__` 是 Python 中一个强大的内存优化工具，适合在性能关键、实例数量巨大的场景中使用。**
