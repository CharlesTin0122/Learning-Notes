要让 Python 代码更“Pythonic”，本质就是遵循 Python 社区的惯例、哲学（Zen of Python）和最佳实践，让代码更简洁、可读、优雅、高效。下面是一套实战中最有效的“Pythonic 改造清单”，按重要性排序：

### 1. 牢记 Zen of Python（导入这句就行）
```python
import this
```
核心原则：**Beautiful is better than ugly. Simple is better than complex. Readability counts.**

### 2. 核心 Pythonic 习惯（必掌握）

| 反模式                          | Pythonic 写法                                      | 说明 |
|-------------------------------|--------------------------------------------------|------|
| 用 for 循环手动建列表              | 列表推导式 `[x*2 for x in lst]`                   | 最经典的 Pythonic |
| 用 for 循环手动建字典/集合          | 字典/集合推导式 `{k: v for k, v in items}`        | 同上 |
| 用 for 循环 + if 过滤               | 生成器表达式 `(x for x in lst if x > 0)`          | 配合 sum、max、any、all 等内置函数 |
| 手动交换变量 a, b = b, a            | `a, b = b, a`                                    | Python 最优雅特性之一 |
| 手动遍历索引 `for i in range(len(lst))` | `for idx, val in enumerate(lst)`                | 同时需要索引时 |
| 手动遍历键值 `for k in d.keys(): if k in d:` | `for k, v in d.items()`                         | 直接解包 |
| 手动拼接字符串                     | `', '.join(list)`                                | 永远用 join |
| 手动检查列表是否为空 `if len(lst) == 0` | `if not lst:`                                   | Python 的“真值测试”哲学 |
| 复杂的 if/elif/elif                | 字典映射 `{1: 'one', 2: 'two'}.get(x, 'default')` | 常用于策略模式 |

### 3. 进阶 Pythonic 技巧（用了立马高大上）

```python
# 1. 链式比较（数学家写法）
if 0 < x < 100:      # 而不是 0 < x and x < 100

# 2. 多变量赋值与解构
a, b, c = 1, 2, 3
x, *rest, y = lst    # Python 3.0+ 星号解包
first, *_, last = lst  # _ 表示不在意的变量（惯例）

# 3. 用 any/all 替代手写循环
if any(x > 100 for x in lst):   # 比写 for+flag 优雅百倍
if all(isinstance(x, int) for x in lst):

# 4. 默认值神器：defaultdict、setdefault
from collections import defaultdict
d = defaultdict(list)           # 访问不存在的键自动创建 []
d[key].append(value)            # 再也不用 if key not in d:

# 5. 用 itertools 取代手写循环（极度 Pythonic）
from itertools import chain, combinations, groupby, permutations

# 6. 上下文管理器（with）用于资源管理
with open('file.txt') as f:
    data = f.read()

# 甚至自定义：
with timer():   # 自己写的计时上下文管理器
    do_something()

# 7. 函数式编程三件套：map、filter、sorted(key=)
sorted(students, key=lambda s: s.grade, reverse=True)
# 更好：用 operator.attrgetter 或 key 函数
from operator import attrgetter, itemgetter
sorted(students, key=attrgetter('grade'))

# 8. 用 if 表达式代替简单三目
status = "even" if x % 2 == 0 else "odd"

# 9. 条件式导入（高级技巧）
if TYPE_CHECKING:
    from typing import Literal   # 只用于类型检查，不影响运行时性能
```

### 4. 最常见的“反 Pythonic”恶习（一定要改掉）

```python
# 坏味道
lst = []
for i in range(10):
    if i % 2 == 0:
        lst.append(i*2)

# 改成一行（极致 Pythonic）
lst = [i*2 for i in range(10) if i % 2 == 0]

# 坏味道：可变默认参数
def func(a, b=[]): ...

# 正确写法
def func(a, b=None):
    if b is None:
        b = []
```
