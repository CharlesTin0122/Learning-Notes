在 Python 中，**类的方法装饰器**是面向对象编程中非常重要的工具，它们可以**改变方法的行为、控制访问权限、优化性能**等。以下是 **类中方法最常用的 6 大装饰器**，按使用频率和重要性排序，**带完整示例 + 原理说明 + 实际应用场景**。

---

## 一、`@property` —— 属性化方法（最常用！）

### 作用
将**方法伪装成属性**，实现**读取控制**、**计算属性**、**延迟计算**。

### 三大子装饰器
```python
@property          # 读
.setter            # 写
.deleter           # 删除
```

### 示例
```python
class Circle:
    def __init__(self, radius):
        self._radius = radius

    @property
    def radius(self):
        return self._radius

    @radius.setter
    def radius(self, value):
        if value < 0:
            raise ValueError("半径不能为负")
        self._radius = value

    @property
    def area(self):  # 只读计算属性
        return 3.14159 * self._radius ** 2

c = Circle(5)
print(c.radius)   # 5（像属性一样访问）
print(c.area)     # 78.53975
c.radius = 10     # 触发 setter
# c.area = 100    # 报错！只读
```

> **场景**：表单验证、延迟加载、缓存计算结果

## 二、`@classmethod` —— 类方法

### 作用
- 方法的第一个参数是 **类本身（cls）**
- **不依赖实例**，可通过类或实例调用
- 常用于**工厂方法、替代构造函数**
### 原理
- @classmethod 是一个描述器，在 __get__ 时无论实例是否存在，都将原函数绑定到类（owner），返回一个可调用对象，第一个参数接收 cls。

### 示例
```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    @classmethod
    def from_birth_year(cls, name, birth_year):
        return cls(name, 2025 - birth_year)

    @classmethod
    def validate_age(cls, age):
        return 0 <= age <= 150

p = Person.from_birth_year("Alice", 1995)
print(p.age)  # 30
```

> **场景**：`from_json()`、`from_dict()` 等替代构造函数

## 三、`@staticmethod` —— 静态方法

### 作用
- **既不接收 `self` 也不接收 `cls`**
- 就是一个**放在类里的普通函数**，但逻辑上属于该类
- **不能访问类或实例属性**

### 示例
```python
class MathUtils:
    @staticmethod
    def is_even(n):
        return n % 2 == 0

    @staticmethod
    def add(a, b):
        return a + b

print(MathUtils.is_even(4))  # True
print(MathUtils.add(3, 5))   # 8
```

> **场景**：工具函数、与类功能相关但不依赖状态的函数
## 总结
- 实例方法，类方法，静态方法都可以使用实例对象来调用，因为装饰器已经对方法进行了包装完善。
- 类对象可以调用：类方法 和 静态方法，类对象不能调用实例方法，除非手动传实例
```python
class Person:
    def say_hello(self):
        print(f"Hello, I'm {self.name}")

# 实例调用
p = Person()
p.name = "Alice"
p.say_hello()  # Hello, I'm Alice

# 类调用 → 报错！缺少 self
# Person.say_hello()  # TypeError: say_hello() missing 1 required positional argument: 'self'

# 但可以手动传实例
Person.say_hello(p)  # Hello, I'm Alice
```
- “类属性、类方法、静态方法、实例方法 都定义并存储在 类对象的 `__dict__` 中； 实例属性 存储在 实例对象的` __dict__` 中。 当实例访问类属性或类/静态方法时，Python 会通过 实例的 `__class__ `属性定位到类对象，再从类的 `__dict__` 中查找。”

## 四、`@dataclass`（Python 3.7+）—— 自动生成 boilerplate 代码

### 作用
自动为类生成：
- `__init__`
- `__repr__`
- `__eq__`
- `__hash__`（如需）

### 示例
```python
from dataclasses import dataclass
from typing import List

@dataclass(frozen=True)  # 不可变
class Point:
    x: float
    y: float

    def distance_to(self, other):
        return ((self.x - other.x)**2 + (self.y - other.y)**2)**0.5

p1 = Point(1, 2)
p2 = Point(4, 6)
print(p1)  # Point(x=1, y=2)
```

> **场景**：DTO（数据传输对象）、配置类、简单模型

## 五、`@abstractmethod` + `@abc.abstractmethod` —— 抽象方法（接口）

### 作用
定义**必须被子类实现**的方法，强制接口规范。

### 示例
```python
from abc import ABC, abstractmethod

class Animal(ABC):
    @abstractmethod
    def speak(self):
        pass

    def sleep(self):
        print("Zzz...")

class Dog(Animal):
    def speak(self):
        return "汪汪！"

# a = Animal()  # 报错！不能实例化抽象类
d = Dog()
print(d.speak())  # 汪汪！
```

> **场景**：框架设计、插件系统、强制 API 规范

## 六、`@cache` / `@lru_cache` —— 方法结果缓存（性能优化）

### 作用
**记忆化（Memoization）**：相同参数只计算一次。

### 示例
```python
from functools import cache
import time

class Fib:
    @cache
    def fib(self, n):
        print(f"计算 fib({n})")
        if n <= 1:
            return n
        return self.fib(n-1) + self.fib(n-2)

f = Fib()
print(f.fib(10))  # 只打印前几次计算
print(f.fib(10))  # 直接返回缓存，不打印
```

> **场景**：递归、动态规划、昂贵计算

## 装饰器对比总结表

| 装饰器 | 第一个参数 | 能否访问实例 | 能否访问类 | 常见用途 |
|--------|-----------|-------------|-----------|---------|
| `@property` | 无（伪装属性） | 是（通过 self） | 是 | 控制属性访问 |
| `@classmethod` | `cls` | 否 | 是 | 工厂方法 |
| `@staticmethod` | 无 | 否 | 否 | 工具函数 |
| `@dataclass` | — | — | — | 自动生成方法 |
| `@abstractmethod` | `self` | 是 | 是 | 接口规范 |
| `@cache` | `self` + 参数 | 是 | 是 | 缓存优化 |

## 进阶技巧：自定义方法装饰器

```python
def log_method(func):
    def wrapper(self, *args, **kwargs):
        print(f"[LOG] 调用 {func.__name__}{args}")
        result = func(self, *args, **kwargs)
        print(f"[LOG] 返回 {result}")
        return result
    return wrapper

class Calculator:
    @log_method
    def add(self, a, b):
        return a + b

calc = Calculator()
calc.add(3, 5)
# [LOG] 调用 add(3, 5)
# [LOG] 返回 8
```

> **场景**：日志、权限、事务、性能监控
