# Python 中的**装饰器（Decorator）** 详解

**装饰器** 是 Python 中一种优雅的**高阶函数**，用于**在不修改原函数代码的前提下，动态地为函数（或方法、类）添加额外功能**。

> 核心思想：**函数也是一等公民（First-class Citizen）** —— 可以作为参数传递、返回值、赋值给变量。

---

## 一、什么是装饰器？

```python
@decorator
def my_function():
    pass
```

等价于：

```python
def my_function():
    pass
my_function = decorator(my_function)
```

> `@decorator` 就是**语法糖**，自动把下面的函数传入装饰器并重新赋值。

---

## 二、从零开始：手把手实现一个装饰器

### 1. 函数作为参数和返回值

```python
def hello(name):
    return f"Hello, {name}!"

def make_upper(func):           # 接收一个函数
    def wrapper(name):          # 内部包装函数
        result = func(name)     # 调用原函数
        return result.upper()   # 增强功能
    return wrapper              # 返回新函数

# 使用
hello = make_upper(hello)       # 装饰
print(hello("Alice"))           # HELLO, ALICE!
```

### 2. 使用 `@` 语法糖

```python
def make_upper(func):
    def wrapper(name):
        return func(name).upper()
    return wrapper

@make_upper                     # 等价于 hello = make_upper(hello)
def hello(name):
    return f"Hello, {name}!"

print(hello("Bob"))             # HELLO, BOB!
```

## 三、装饰器通用模板

```python
def decorator(func):
    def wrapper(*args, **kwargs):   # 接收任意参数
        # —— 前置逻辑 ——
        print(f"调用 {func.__name__} 前")
        
        result = func(*args, **kwargs)  # 执行原函数
        
        # —— 后置逻辑 ——
        print(f"调用 {func.__name__} 后")
        
        return result
    return wrapper
```

### 示例：计时装饰器

```python
import time
from functools import wraps

def timer(func):
    @wraps(func)  # 保留原函数的元信息（name, docstring）
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        end = time.time()
        print(f"{func.__name__} 执行耗时: {end - start:.4f} 秒")
        return result
    return wrapper

@timer
def slow_function(n):
    time.sleep(n)
    return n * 2

slow_function(1)
# 输出：
# slow_function 执行耗时: 1.0012 秒
```

> 使用 `@wraps(func)` 是最佳实践，避免丢失原函数的 `__name__`、`__doc__` 等信息。

## 四、带参数的装饰器（进阶）

有时需要**配置装饰器行为**，比如设置日志级别、缓存时间等。

```python
def repeat(times):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            for _ in range(times):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(3)
def say_hello():
    print("Hello!")

say_hello()
# 输出：
# Hello!
# Hello!
# Hello!
```

> 结构：`@repeat(3)` → 返回一个装饰器 → 再装饰 `say_hello`

## 五、类装饰器（用类实现）

```python
class Logger:
    def __init__(self, level="INFO"):
        self.level = level

    def __call__(self, func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            print(f"[{self.level}] 调用 {func.__name__}")
            return func(*args, **kwargs)
        return wrapper

@Logger(level="DEBUG")
def add(a, b):
    return a + b

add(2, 3)
# [DEBUG] 调用 add
```

## 六、多个装饰器叠加

```python
@timer
@repeat(2)
def greet(name):
    print(f"Hi, {name}!")

greet("Charlie")
# 输出：
# Hi, Charlie!
# Hi, Charlie!
# greet 执行耗时: 0.0001 秒
```

> **执行顺序**：从下到上（先 `@repeat` → 再 `@timer`）

## 七、常见内置装饰器

| 装饰器 | 作用 |
|--------|------|
| `@staticmethod` | 静态方法，不接收 `self` |
| `@classmethod` | 类方法，接收 `cls` |
| `@property` | 将方法变成属性 |
| `@cache` / `@lru_cache` | 缓存函数结果（记忆化） |
| `@dataclass` | 自动生成 `__init__`、`__repr__` 等 |

```python
from functools import lru_cache
import time

@lru_cache(maxsize=3)
def fib(n):
    if n <= 1:
        return n
    return fib(n-1) + fib(n-2)

print(fib(100))  # 瞬间返回（缓存加速）
```

## 八、装饰器应用场景（实战）

| 场景 | 示例 |
|------|------|
| **日志记录** | 记录函数调用时间、参数、返回值 |
| **权限控制** | `@login_required` |

```python

from flask import Flask
app = Flask(__name__)

@app.route('/')

```

## 九、调试技巧：查看装饰后函数信息

```python
@timer
def test():
    """这是一个测试函数"""
    pass

print(test.__name__)   # wrapper（无 @wraps）
# 使用 @wraps 后 → test
print(test.__doc__)    # 这是一个测试函数
```

## 十、常见面试题

1. **装饰器会改变原函数吗？**  
   → 不会，但会“包装”它。原函数仍在内存中。

2. **如何保留原函数？**

   ```python
   original_func = my_func
   @decorator
   def my_func():
       pass
   ```

3. **装饰器能用于类方法吗？**

   ```python
   class MyClass:
       @timer
       def method(self):
           time.sleep(1)
   ```

4. **如何装饰已经装饰过的函数？**  
   → 直接再加 `@another_decorator` 即可（多层装饰）。

---

## 总结：装饰器核心模型

```python
@decorator        →     func = decorator(func)
```

| 要素 | 说明 |
|------|------|
| `func` | 被装饰的原函数 |
| `wrapper` | 包装函数，添加增强逻辑 |
| `*args, **kwargs` | 通用参数传递 |
| `@wraps(func)` | 保留元信息 |
| 返回 `wrapper` | 必须返回可调用对象 |

## 小彩蛋：一行实现“函数调用计数”装饰器

```python
from functools import wraps

def count_calls(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        wrapper.calls += 1
        print(f"第 {wrapper.calls} 次调用 {func.__name__}")
        return func(*args, **kwargs)
    wrapper.calls = 0
    return wrapper

@count_calls
def hello():
    print("Hi!")

hello()  # 第 1 次调用 hello
hello()  # 第 2 次调用 hello
```
