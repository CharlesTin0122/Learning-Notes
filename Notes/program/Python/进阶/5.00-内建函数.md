Python 的**内置函数**（built-in functions）是 Python 解释器自带、无需导入模块即可直接使用的函数。它们是 Python 语言的核心工具，涵盖类型转换、数学运算、迭代、输入输出、对象操作等多个方面。

截至 Python 3.12（当前主流版本），Python 共有 **71 个内置函数**。以下按功能分类系统性介绍，并附常用示例。

---

## 一、类型转换与创建（13 个）

| 函数 | 功能 | 示例 |
|------|------|------|
| `int(x)` | 转为整数 | `int("123") → 123` |
| `float(x)` | 转为浮点数 | `float("3.14") → 3.14` |
| `str(obj)` | 转为字符串 | `str(100) → "100"` |
| `bool(x)` | 转为布尔值 | `bool(0) → False` |
| `list(iter)` | 转为列表 | `list("abc") → ['a','b','c']` |
| `tuple(iter)` | 转为元组 | `tuple([1,2]) → (1,2)` |
| `set(iter)` | 转为集合 | `set([1,1,2]) → {1,2}` |
| `dict(**kwargs)` | 创建字典 | `dict(a=1, b=2)` |
| `frozenset(iter)` | 不可变集合 | `frozenset([1,2])` |
| `bytes()`, `bytearray()` | 字节序列 | `bytes([65]) → b'A'` |
| `complex()` | 复数 | `complex(1,2) → 1+2j` |
| `memoryview(obj)` | 内存视图 | 用于二进制数据操作 |

## 三、迭代与序列操作（12 个）

| 函数 | 功能 | 示例 |
|------|------|------|
| `range(start, stop, step)` | 生成整数序列 | `list(range(3)) → [0,1,2]` |
| `len(s)` | 长度 | `len("hello") → 5` |
| `sorted(iter, key=None, reverse=False)` | 排序 | `sorted([3,1,2]) → [1,2,3]` |
| `reversed(seq)` | 反向迭代器 | `list(reversed([1,2])) → [2,1]` |
| `enumerate(iter, start=0)` | 带索引迭代 | `list(enumerate(['a','b'])) → [(0,'a'), (1,'b')]` |
| `zip(*iters)` | 并行迭代 | `list(zip([1,2], ['a','b'])) → [(1,'a'), (2,'b')]` |
| `iter(obj)` | 获取迭代器 | `iter([1,2,3])` |
| `next(iter, default)` | 获取下一个元素 | `next(iter([1,2])) → 1` |
| `any(iter)` | 任一为真 | `any([0, False, 1]) → True` |

| `map(func, iter)` | 映射 | `list(map(str, [1,2])) → ['1','2']` |
| `filter(func, iter)` | 过滤 | `list(filter(lambda x:x>0, [-1,0,1])) → [1]` |

## 如何查看所有内置函数？

```python
print(dir(__builtins__))
```

这会列出当前命名空间中所有内置名称（包括函数和异常）。

# Tips
## range()
- 在 python3 中 `range()`函数返回的是可迭代对象`range object`；在 python2 中返回的是列表，此时如果数据量非常大，会导致占用大量内存。
