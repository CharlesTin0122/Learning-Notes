### Python 中的迭代器（Iterator）介绍

在 Python 中，**迭代器**是一种实现**迭代协议**（Iteration Protocol）的对象，用于逐一访问容器（如列表、元组、字典等）中的元素。它是 Python 可迭代对象（Iterable）的核心机制之一，广泛用于 `for` 循环、`list()`、`tuple()`、`sum()` 等函数中。

---

## 一、核心概念

### 1. 可迭代对象（Iterable）
- 任何可以被 `for` 循环遍历的对象。
- 必须实现 `__iter__()` 方法，返回一个迭代器。
- 示例：`list`, `tuple`, `dict`, `set`, `str`, `range()`, 文件对象等。

```python
for item in [1, 2, 3]:  # [1, 2, 3] 是可迭代对象
    print(item)
```
- 验证是否可迭代
```python
from collections.abc import Iterable

print(isinstance([1, 2, 3], Iterable))
```
- `list`, `tuple`构建
```python
list(Iterable)
tuple(Iterable)
```
### 2. 迭代器（Iterator）
- 是一个用于记录迭代进度的对象，他内部实现了 `__iter__()` 和 `__next__()` 两个方法。
- `__iter__()`：返回迭代器自身（`return self`）。
- `__next__()`：返回下一个元素，当没有元素时抛出 `StopIteration` 异常。

```python
it = iter([1, 2, 3])  # 获取迭代器
print(next(it))  # 1
print(next(it))  # 2
print(next(it))  # 3
# print(next(it))  # StopIteration 错误
```

---

## 二、迭代器的工作原理

```python
# 1. 调用 iter() 获取迭代器
it = iter(my_iterable)

# 2. 反复调用 next() 获取下一个值
value = next(it)

# 3. 直到抛出 StopIteration，循环结束
```

`for` 循环内部就是这么做的：

```python
for x in obj:
    print(x)
```
1. 先调用iter()方法，获取可迭代对象obj的迭代器
2. 调用next()方法，将迭代器进行取值并赋值给x变量
3. 执行for循环体的代码
4. 循环往复，直到最后一个元素迭代完毕，抛出StopIteration异常，迭代完毕。

等价于：

```python
it = iter(obj)
while True:
    try:
        x = next(it)
        print(x)
    except StopIteration:
        break
```

## 三、如何判断一个对象是迭代器？

```python
from collections.abc import Iterator, Iterable

lst = [1, 2, 3]
it = iter(lst)

print(isinstance(lst, Iterable))   # True
print(isinstance(lst, Iterator))   # False

print(isinstance(it, Iterable))    # True
print(isinstance(it, Iterator))    # True
```

> **注意**：所有迭代器都是可迭代的，但可迭代对象不一定是迭代器。

## 四、自定义迭代器（示例）
### 示例一：嵌套类
```python
from collections.abc import Iterable, Iterator

class MyList:
    """列表类"""
    def __init__(self, data):
        """构造函数，传入一个可迭代数据"""
        self.data = data
    def add(self, item):
        """添加元素函数"""
        self.data.append(item)
    def __iter__(self):
        """返回迭代器"""
        return self.MyIter(self.data)
    class MyIter:
        """迭代器类"""
        def __init__(self, iter_data):
            """构造函数：数据和索引"""
            self.my_data = iter_data
            self.index = 0
        def __iter__(self):
            """iter函数，返回迭代器自身"""
            return self
        def __next__(self):
            """next函数,返回索引值，索引自增，超出索引后抛出异常"""
            if self.index >= len(self.my_data):
                raise StopIteration
            value = self.my_data[self.index]
            self.index += 1
            return value
# 验证
if __name__ == "__main__":
    my_list = [1, 2, 3]
    obj = MyList(my_list)
    obj.add(4)
    obj.add(5)
    my_iter = iter(obj)

    print(isinstance(obj, Iterable))
    print(isinstance(my_iter, Iterator))

    print(next(my_iter))
    print(next(my_iter))
    print(next(my_iter))
    print(next(my_iter))
    print(next(my_iter))

```
### 示例二：一个类(不推荐)
- 也可以将__iter__和__next__函数写入类中，这个类即当容器类又当迭代器类
```python
class MyList:
    """列表类"""

    def __init__(self, data):
        """构造函数，传入一个可迭代数据"""
        self.data = data
        self.index = 0

    def add(self, item):
        """添加元素函数"""
        self.data.append(item)

    def __iter__(self):
        """iter函数，返回迭代器自身"""
        # 每次迭代都从0索引开始
        self.index = 0
        return self

    def __next__(self):
        """next函数,返回索引值，索引自增，超出索引后抛出异常"""
        if self.index >= len(self.data):
            raise StopIteration
        value = self.data[self.index]
        self.index += 1
        return value

```

## 五、生成器（Generator）是特殊的迭代器

```python
def countdown(n):
    while n > 0:
        yield n
        n -= 1

# countdown(5) 返回一个生成器（也是迭代器）
for x in countdown(5):
    print(x)
```

> 生成器自动实现了 `__iter__()` 和 `__next__()`，是创建迭代器的简便方式。

## 六、常见内置迭代器工具（`itertools`）

```python
import itertools

# 无限计数器
for i in itertools.count(10):
    print(i)
    if i >= 15:
        break

# 循环迭代
for item in itertools.cycle(['A', 'B', 'C']):
    print(item)
    # 无限循环，除非 break

# 组合、排列
list(itertools.permutations('ABC', 2))  # [('A', 'B'), ('A', 'C'), ...]
```

## 七、总结对比

| 特性               | 可迭代对象 (Iterable)       | 迭代器 (Iterator)              |
|--------------------|-----------------------------|--------------------------------|
| 实现 `__iter__()`  | ✅ 必须                      | ✅ 必须（返回 self）            |
| 实现 `__next__()`  | ❌ 不需要                    | ✅ 必须                        |
| 可用于 `for` 循环  | ✅ 是                       | ✅ 是                          |
| 可多次遍历         | ✅ 是（每次调用 iter()）     | ❌ 否（一次性消耗）             |
| 示例               | `list`, `str`, `range()`    | `iter(list)`, 生成器           |

## 小技巧

- 使用 `iter()` 和 `next()` 手动控制迭代。
- 迭代器只能前进，不能倒退或重置。
- 文件对象本身就是迭代器：

```python
with open('file.txt') as f:
    for line in f:  # f 是迭代器
        print(line)
```
