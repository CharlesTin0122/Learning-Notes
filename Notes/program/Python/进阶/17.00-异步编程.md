### Python 中的异步编程简介

Python 从 3.5 版本开始正式引入了原生的异步编程支持，主要通过以下关键字和标准库实现：

- `async def`：定义异步函数（协程函数）
- `await`：在异步函数内部等待一个可等待对象（awaitable）
- `asyncio`：标准库中的异步 I/O 框架，是目前最主流的异步编程库
- `async with`、`async for`：异步上下文管理器和异步迭代器

#### 核心概念

| 概念              | 说明                                                                 |
|-------------------|----------------------------------------------------------------------|
| 协程（Coroutine） | 用 `async def` 定义的函数，调用后返回一个协程对象，不会立即执行          |
| 可等待对象（Awaitable） | 可以被 `await` 的对象，主要有：协程、Task、Future                   |
| 事件循环（Event Loop） | asyncio 的核心，负责调度和管理所有协程的执行                         |
| Task              | 对协程的封装，相当于把协程提交给事件循环执行                          |
| Future            | 低层对象，表示一个还未完成的结果，Task 是 Future 的子类               |

#### 基本写法对比

```python
# 普通同步函数
def sync_func():
    time.sleep(3)
    return "done"

# 异步函数
async def async_func():
    await asyncio.sleep(3)   # 不会阻塞事件循环
    return "done"
```

#### 简单示例：并发下载多个网站

```python
import asyncio
import aiohttp

async def download(url):
    async with aiohttp.ClientSession() as session:
        async with session.get(url) as resp:
            text = await resp.text()
            print(f"{url} 下载完成，大小: {len(text)} 字节")

async def main():
    tasks = [
        download("https://httpbin.org/delay/2"),
        download("https://httpbin.org/delay/3"),
        download("https://httpbin.org/delay/1"),
    ]
    # 并发执行所有任务
    await asyncio.gather(*tasks)

# 运行方式（Python 3.7+）
asyncio.run(main())
```

运行结果大概在 3 秒左右就全部完成（最大延迟决定总时间），而同步方式要 2+3+1=6 秒。

#### 常见的启动异步代码方式

```python
# 推荐方式（Python 3.7+）
asyncio.run(main())

# 老方式（兼容性更好）
loop = asyncio.get_event_loop()
loop.run_until_complete(main())
```

#### 异步上下文管理器和异步迭代器

```python
# 异步上下文管理器（比如异步数据库连接）
async with async_engine.acquire() as conn:
    await conn.execute(...)

# 异步生成器
async for item in async_generator():
    print(item)
```

#### 什么时候该用异步？

适合的场景（收益巨大）：
- 高并发 I/O 操作（网络请求、数据库、文件读写）
- Web 服务（FastAPI + Uvicorn）
- 爬虫、微服务、聊天机器人、WebSocket 服务

不适合或收益很小的场景：
- CPU 密集型任务（需要 multiprocessing 或 threading）
- 代码主要是计算、数据处理
- 第三方库没有提供异步版本（会阻塞事件循环）

#### 常见坑

1. 永远不要在异步代码里调用阻塞函数（如 `time.sleep()`, `requests.get()`）
2. 第三方库没异步版时，可以用 `asyncio.to_thread()`（Python 3.9+）放到线程里运行
   ```python
   result = await asyncio.to_thread(blocking_function, arg1, arg2)
   ```
3. 调试异步代码比同步难，推荐使用 `asyncio.run()` + 好的日志

#### 总结一句话

Python 的异步编程 = asyncio 事件循环 + async/await 语法糖 + 丰富的异步生态库，让你在单线程里就能实现高并发 I/O，特别适合现代 Web 服务和网络密集型应用。
