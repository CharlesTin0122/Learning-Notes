### Python 中的闭包（Closure）

**闭包**是 Python 中一个非常重要且强大的特性，它允许函数“记住”并访问其定义时所在的**词法作用域**中的变量，即使该作用域已经执行完毕。

---

#### 1. 什么是闭包？

简单来说：

> **闭包 = 函数 + 该函数定义时的环境（外部变量）**

当一个**内部函数**引用了其**外部函数作用域**中的变量，并且这个内部函数被返回或传递出去时，就形成了一个闭包。

---

#### 2. 闭包的三个必要条件

1. 必须有一个**内嵌函数**（nested function）。
2. 内嵌函数必须**引用**外部函数局部作用域中的变量。
3. 外部函数必须**返回**这个内嵌函数。

---

#### 3. 基本示例

```python
def outer_function(msg):
    # 外部函数的局部变量
    message = msg

    def inner_function():
        # 引用了外部的 message 变量
        print(message)

    # 返回内部函数（不是调用！）
    return inner_function

# 创建闭包
closure1 = outer_function("Hello")
closure2 = outer_function("World")

# 调用闭包
closure1()  # 输出: Hello
closure2()  # 输出: World
```

> 即使 `outer_function` 执行完毕，`message` 变量本该被销毁，但由于闭包的存在，它被“捕获”并保留了下来。

---

#### 4. 闭包“记住”了变量的值

```python
def make_multiplier(x):
    def multiplier(n):
        return x * n
    return multiplier

times3 = make_multiplier(3)
times5 = make_multiplier(5)

print(times3(10))  # 30
print(times5(10))  # 50
```

每个闭包都独立地记住了自己创建时 `x` 的值。

---

#### 5. 闭包中的变量是延迟绑定（Late Binding）

注意这个常见陷阱：

```python
def create_functions():
    functions = []
    for i in range(3):
        def func():
            print(i)
        functions.append(func)
    return functions

funcs = create_functions()
for f in funcs:
    f()  # 输出: 2, 2, 2  （不是 0,1,2！）
```

**原因**：`i` 是自由变量，闭包绑定的是**变量本身**，而不是值。循环结束后 `i` 变为 2。

**解决方法**：使用默认参数“捕获”当前值：

```python
def create_functions():
    functions = []
    for i in range(3):
        def func(x=i):  # 默认参数在定义时绑定
            print(x)
        functions.append(func)
    return functions

funcs = create_functions()
for f in funcs:
    f()  # 输出: 0, 1, 2
```

---

#### 6. 查看闭包中的变量

```python
closure = outer_function("Python")
print(closure.__closure__)           # 返回 cell 对象元组
print(closure.__closure__[0].cell_contents)  # 'Python'
```

#### 7. 闭包的典型应用场景

| 场景 | 说明 |
|------|------|
| 数据隐藏 / 封装 | 类似私有变量 |
| 装饰器 | `@decorator` 底层就是闭包 |
| 回调函数 | 携带上下文的回调 |
| 工厂函数 | `make_adder(5)` 返回加 5 的函数 |

```python
# 工厂函数示例
def make_adder(n):
    def adder(x):
        return x + n
    return adder

add5 = make_adder(5)
print(add5(10))  # 15
```

---

#### 8. 闭包 vs 类（可替代性）

闭包和类可以实现类似功能：

```python
# 用闭包
def counter():
    count = 0
    def inc():
        nonlocal count
        count += 1
        return count
    return inc

c1 = counter()
print(c1())  # 1
print(c1())  # 2

# 用类
class Counter:
    def __init__(self):
        self.count = 0
    def __call__(self):
        self.count += 1
        return self.count

c2 = Counter()
print(c2())  # 1
```

> **闭包更轻量**，适合简单状态；**类更灵活**，适合复杂逻辑。

### 总结

| 特性 | 说明 |
|------|------|
| 动态创建 | 运行时生成函数 |
| 状态保持 | 记住外部变量 |
| 轻量封装 | 无需定义类 |
| 注意事项 | 延迟绑定、`nonlocal` 关键字 |

---

**关键语句**：
```python
nonlocal var  # 在 Python 3 中用于修改外部函数的变量
```
