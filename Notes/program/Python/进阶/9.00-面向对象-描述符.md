Python 中的**描述符（Descriptor）**是 Python 面向对象编程中一个非常强大但又容易被忽视的高级特性。它是属性访问（获取、设置、删除）的“幕后控制者”，让你可以自定义某个类在访问属性时的行为。

### 一、什么是描述符？

描述符就是实现了**描述符协议**的类实例。这个协议包含以下三个方法（至少实现一个）：

| 方法                                | 作用                          | 触发时机                    |
| --------------------------------- | --------------------------- | ----------------------- |
| `__get__(self, instance, owner)`  | 获取属性值                       | `obj.attr` 或 `Cls.attr` |
| `__set__(self, instance, value)`  | 设置属性值                       | `obj.attr = value`      |
| `__delete__(self, instance)`      | 删除属性                        | `del obj.attr`          |
| `__set_name__(self, owner, name)` | Python 3.6+ 自动调用，告诉描述符它的属性名 | 类定义时自动调用                |
|                                   |                             |                         |

如果一个类的实例被用作另一个类的**类属性**，那它就会变成描述符。描述器只有在**类属性**中才生效！
- 其中的参数意义
	- self：描述符实例本身，就是那个被用作类属性的描述符对象
	- instance：当前正在操作的实例， 你写 obj.attr 时，obj 就是这里。类访问时为 None
	- owner：实例所属的类，就是定义这个属性的类（可能是子类）
	- value：要设置的新值
	- name：类中的描述符实例变量名
### 二、描述符的两种类型

1. **数据描述符（Data Descriptor）**  
   同时实现了 `__get__` 和 `__set__`，优先级最高，连实例的同名属性都会被覆盖。

2. **非数据描述符（Non-Data Descriptor）**  
   只实现了 `__get__`，优先级较低，如果实例字典中有同名属性，会覆盖描述符。

优先级顺序（从高到低）：
```
数据描述符 > 实例属性 > 非数据描述符 > 类属性
```

### 三、最常见的实际例子
#### 0.简单案例
```python
class Info:
    """
    一个记录属性读写删除历史的描述符
    每次操作都会打印日志，适合初学者看清楚每一步发生了什么
    """

    def __init__(self):
        self._value = None  # 真正存放数据的变量
        self.name = None  # 属性名字（稍后由 __set_name__ 自动设置）

    def __set_name__(self, owner, name):
        """类创建时自动调用，告诉我们这个描述符叫什么名字"""
        self.name = name
        print(f"【初始化】描述符被绑定到属性名：{name}")

    def __get__(self, instance, owner):
        """读取属性时调用： obj.name"""
        if instance is None:
            return self  # 类访问时返回描述符本身
        print(f"【读取】正在读取 {self.name}，当前值是：{self._value}")
        return self._value

    def __set__(self, instance, value):
        """设置属性时调用： obj.name = xxx"""
        print(f"【设置】正在把 {self.name} 设置为：{value}")
        self._value = value

    def __delete__(self, instance):
        """删除属性时调用： del obj.name"""
        print(f"【删除】正在删除 {self.name}，原来值是：{self._value}")
        self._value = None


# ──────────────────────────────
# 使用这个描述符的类
# ──────────────────────────────
class Student:
    name = Info()  # 描述符实例作为类属性
    age = Info()  # 再来一个

    def __init__(self, name, age):
        self.name = name  # → 触发 __set__
        self.age = age  # → 触发 __set__


if __name__ == "__main__":
    s = Student("小明", 18)

    print(s.name)  # → 触发 __get__
    print(s.age)

    s.name = "小红"  # → 触发 __set__
    print(s.name)

    del s.age  # → 触发 __delete__
    print(s.age)  # 现在是 None

```
#### 1. `@property` 其实就是描述符
```python
class Person:
    def __init__(self, name):
        self._name = name
    
    @property
    def name(self):
        return self._name
    
    @name.setter
    def name(self, value):
        if not value:
            raise ValueError("名字不能为空")
        self._name = value

# 实际上等价于：
class Person:
    def __init__(self, name):
        self._name = name
    
    class NameDescriptor:
        def __get__(self, instance, owner):
            return instance._name
        
        def __set__(self, instance, value):
            if not value:
                raise ValueError("名字不能为空")
            instance._name = value
    
    name = NameDescriptor()
```

#### 2. 自定义一个带缓存的描述符（非常实用）
```python
import functools
import time

class CachedProperty:
    def __init__(self, func):
        self.func = func
        self.name = None
        self.__doc__ = func.__doc__
    
    def __set_name__(self, owner, name):
        self.name = name
    
    def __get__(self, instance, owner):
        if instance is None:
            return self
        
        value = self.func(instance)  # 计算一次
        instance.__dict__[self.name] = value  # 缓存到实例字典
        return value

# 使用
class Circle:
    def __init__(self, radius):
        self.radius = radius
    
    @CachedProperty
    def area(self):
        print("正在计算面积...")
        time.sleep(2)  # 模拟耗时计算
        return 3.14 * self.radius ** 2

c = Circle(5)
print(c.area)   # 会打印“正在计算面积...”，等2秒
print(c.area)   # 立即返回，不再计算
```

#### 3. 经典的类型检查描述符
```python
class Typed:
    def __init__(self, name, expected_type):
        self.name = name
        self.expected_type = expected_type
    
    def __set_name__(self, owner, name):
        self.private_name = '_' + name
    
    def __get__(self, instance, owner):
        if instance is None:
            return self
        return getattr(instance, self.private_name)
    
    def __set__(self, instance, value):
        if not isinstance(value, self.expected_type):
            raise TypeError(f"{self.name} 必须是 {self.expected_type}")
        setattr(instance, self.private_name, value)

# 使用方式（类似 Django 模型字段）
class Person:
    name = Typed('name', str)
    age = Typed('age', int)
    
    def __init__(self, name, age):
        self.name = name   # 会自动检查类型
        self.age = age

p = Person("Alice", 25)   # OK
p = Person("Alice", "25") # TypeError
```

### 四、描述符常见应用场景

- `@property、@classmethod、@staticmethod`（底层都是描述符）
- 数据验证（类型、范围、正则等）
- 延迟计算/缓存（`@cached_property`）
- ORM 模型字段（如 Django）
- 只读属性、日志记录、权限控制
- 实现类似 Vue/React 的响应式属性

### 五、总结

| 特性                 | 说明                                           |
|----------------------|------------------------------------------------|
| 本质                 | 实现了描述符协议的类，被用作类属性时生效      |
| 必须放在类属性上     | 实例属性不会触发描述符机制                     |
| 数据描述符优先级最高 | 可以完全接管属性的读写                         |
| Python 3.6+ 有 `__set_name__` | 不用再手动传属性名，更优雅                   |

# 案例-电影评分
- 属性值要为为非负值
```python
class NoNegativeDescriptor:
    """非负值描述符类"""
    def __init__(self, default):
        self.default = default
        self.data = dict()

    def __get__(self, instance, owner):
        if instance is None:
            return self  # 类调用返回自身
        # 如果键在字典中，则返回该键的值，否则返回默认值
        return self.data.get(instance, self.default)

    def __set__(self, instance, value):
        if value < 0:
            raise ValueError("赋值不得小于0")
        else:
            self.data[instance] = value

    def __set_name__(self, owner, name):
        self.name = name  # 可选：方便调试或报错信息


class Movie:
    rating = NoNegativeDescriptor(0)  # 评分
    budget = NoNegativeDescriptor(0)  # 成本
    gross = NoNegativeDescriptor(0)  # 票房

    def __init__(self, title, rating, budget, gross):
        self.title = title  # 直接用参数赋值
        self.rating = rating  # 将参数rating赋值给描述符对象，调用__set__方法
        self.budget = budget  # 将参数budget赋值给描述符对象，调用__set__方法
        self.gross = gross  # 将参数gross赋值给描述符对象，调用__set__方法

    def profit(self):
        return self.gross - self.budget


if __name__ == "__main__":
    movie = Movie("Kill Bill", 8, 1000, 2000)
    print("rating", movie.rating)

    try:
        movie.rating = -3
    except ValueError as e:
        print(e)

```
