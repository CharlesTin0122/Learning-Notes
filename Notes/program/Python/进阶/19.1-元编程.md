Python 的元编程（Metaprogramming）就是“**写程序的程序**”，也就是让代码在运行时能够**动态生成、修改、包装其他代码**的能力。  
简单说：普通编程是写“做什么”，元编程是写“怎么自动生成要做的代码”。

Python 因为天生极度动态，几乎是元编程的乐园。下面把 Python 最常用、最强大的元编程手段从易到难完整介绍一遍。

### 1. 基础级：函数 + 装饰器（最常用）
```python
def timer(func):
    import time
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"{func.__name__} 运行耗时 {time.time()-start:.3f}s")
        return result
    return wrapper

@timer
def slow_add(a, b):
    time.sleep(1)
    return a + b
```
装饰器本质就是：在运行时把一个函数替换成另一个函数 → 典型的元编程。

### 2. 类装饰器 & 类级元编程
```python
def singleton(cls):
    instances = {}
    def get_instance(*args, **kwargs):
        if cls not in instances:
            instances[cls] = cls(*args, **kwargs)
        return instances[cls]
    return get_instance

@singleton
class Database:
    pass

a = Database()
b = Database()
print(a is b)  # True
```

### 3. `__new__` 和 `__init_subclass__`（Python 3.6+ 黑魔法）
```python
# 自动注册所有子类（插件系统、ORM 模型注册常用）
class PluginBase:
    subclasses = {}
    
    def __init_subclass__(cls, **kwargs):
        super().__init_subclass__(**kwargs)
        cls.subclasses[cls.__name__] = cls
        print(f"自动注册插件：{cls.__name__}")

class Calculator(PluginBase):
    pass

class Weather(PluginBase):
    pass

print(PluginBase.subclasses)
# {'Calculator': <class '__main__.Calculator'>, 'Weather': <class '__main__.Weather'>}
```

### 4. 描述器（Descriptor）—— property 的底层原理
```python
class Positive:
    def __init__(self, name):
        self.name = name
    
    def __get__(self, obj, objtype=None):
        return obj.__dict__[self.name]
    
    def __set__(self, obj, value):
        if value <= 0:
            raise ValueError("必须是正数")
        obj.__dict__[self.name] = value

class Product:
    price = Positive("price")
    quantity = Positive("quantity")

    def __init__(self, price, quantity):
        self.price = price
        self.quantity = quantity
```

### 5. 元类（Metaclass）—— 终极武器
元类是“创建类的类”。所有类默认的元类是 type。

```python
# 最经典的元类：自动给类加字段/方法、单例、自动注册等
class AutoMeta(type):
    def __new__(cls, name, bases, attrs):
        # 自动给每个类加 created_at 时间
        attrs["created_at"] = __import__("time").time()
        # 自动把所有方法加上日志
        for key, value in attrs.items():
            if callable(value) and not key.startswith("__"):
                attrs[key] = AutoMeta.log_decorator(value)
        return super().__new__(cls, name, bases, attrs)
    
    @staticmethod
    def log_decorator(func):
        def wrapper(*args, **kwargs):
            print(f"[LOG] 调用 {func.__name__}")
            return func(*args, **kwargs)
        return wrapper

class User(metaclass=AutoMeta):
    def say_hi(self):
        print("Hello")

u = User()
u.say_hi()
# [LOG] 调用 say_hi
# Hello
print(u.created_at)   # 自动添加的属性
```

### 6. `type()` 动态创建类（结合反射的超级能力）
```python
def __init__(self, name):
    self.name = name

def speak(self):
    print(f"I'm {self.name}")

# 动态创建类
Animal = type("Animal", (object,), {
    "__init__": __init__,
    "speak": speak,
    "legs": 4
})

dog = Animal("旺财")
dog.speak()      # I'm 旺财
print(dog.legs)  # 4
```

### 7. exec() + eval()（危险但强大）
```python
code = """
def dynamic_func(x):
    return x ** 2 + 3*x + 3
"""

exec(code)  # 动态创建函数
print(dynamic_func(5))  # 43
```

### 8. `__getattr__` / `__getattribute__` 终极拦截
```python
class LazyAPI:
    def __getattr__(self, name):
        # 当访问不存在的属性时自动创建
        def method(*args):
            print(f"动态调用 API: {name}{args}")
        return method

api = LazyAPI()
api.login("user123")      # 动态调用 API: login('user123',)
api.upload(file="a.jpg")  # 动态调用 API: upload('a.jpg',)
```

### 真实世界中元编程的经典应用

| 场景              | 使用的元编程技术                              | 代表框架/库                     |
|-------------------|-----------------------------------------------|---------------------------------|
| ORM 模型          | 元类 + `__init_subclass__` + 描述器           | Django ORM、SQLAlchemy          |
| Web 路由          | 类装饰器 + 反射 + `__init_subclass__`         | Flask、FastAPI                  |
| 插件系统          | 元类自动注册 + 反射 + importlib               | NoneBot、Airflow、Jupyter       |
| 序列化            | `__getattr__` + 描述器 + 元类                 | dataclasses、pydantic           |
| 异步框架          | `__await__` + `__aiter__` + 元类              | asyncio、Trio                   |
| 配置管理系统      | 动态创建类 + 描述器                           | Hydra、OmegaConf                |

### 一句话总结各级元编程

| 级别     | 手段                     | 难度 | 使用频率 | 典型场景                |
|----------|--------------------------|------|----------|-------------------------|
| 初级     | 装饰器                   | ★☆☆☆ | ★★★★★   | 缓存、日志、权限        |
| 中级     | 类装饰器、描述器         | ★★☆☆ | ★★★★☆   | property、pydantic      |
| 高级     | `__init_subclass__`      | ★★★☆ | ★★★★☆   | 插件注册、Django Model  |
| 骨灰级   | 元类（metaclass）        | ★★★★★ | ★★★☆☆   | Django ORM、pydantic    |
| 魔王级   | `type()` + `exec()`      | ★★★★★ | ★☆☆☆☆   | 代码生成器、DSL         |
