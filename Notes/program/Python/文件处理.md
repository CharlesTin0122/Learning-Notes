## Python 语言中的文件处理

Python 提供了强大的内置文件操作功能，主要通过 `open()` 函数实现。以下从基础到进阶，系统化地介绍文件处理的核心概念、常用模式及最佳实践。

---

### 1. 基本打开与关闭文件

```python
f = open('file.txt', 'r', encoding='utf-8')   # 打开文件
data = f.read()                               # 读取内容
f.close()                                     # 手动关闭
```

**注意**：手动 `close()` 容易忘记，导致资源泄漏。推荐使用 **上下文管理器**（`with` 语句）：

```python
with open('file.txt', 'r', encoding='utf-8') as f:
    data = f.read()
# 自动关闭文件
```

---

### 2. 文件打开模式

| 模式    | 含义                      |
| ----- | ----------------------- |
| `'r'` | 读取（默认）                  |
| `'w'` | 写入（**覆盖**原有内容）          |
| `'a'` | 追加（写入到文件末尾）             |
| `'x'` | 独占写入（文件已存在则报错）          |
| `'b'` | 二进制模式（如 `'rb'`, `'wb'`） |
| `'t'` | 文本模式（默认）                |
| `'+'` | 读写模式（如 `'r+'`, `'w+'`）  |

示例：
```python
with open('data.bin', 'wb') as f:
    f.write(b'\x00\xff')
```

---

### 3. 常用读取方法

| 方法 | 功能 |
|------|------|
| `f.read(size=-1)` | 读取全部或指定字节/字符 |
| `f.readline()` | 读取一行（含换行符） |
| `f.readlines()` | 读取所有行，返回列表 |

**推荐迭代文件对象**（逐行读取，内存友好）：

```python
with open('large.txt', 'r', encoding='utf-8') as f:
    for line in f:           # 自动按行迭代
        print(line.strip())
```

---

### 4. 写入文件

```python
with open('output.txt', 'w', encoding='utf-8') as f:
    f.write('第一行\n')
    f.writelines(['第二行\n', '第三行\n'])
```

> `write()` 不自动加换行符，需手动添加 `\n`。

---

### 5. 文件指针操作（`seek` / `tell`）

```python
with open('file.txt', 'rb') as f:
    print(f.tell())        # 当前位置：0
    f.seek(10)             # 移动到第10字节
    data = f.read(5)       # 读取5字节
    print(f.tell())        # 当前位置：15
```

常用 `seek` 偏移方式：
- `0`: 从文件开头
- `1`: 从当前位置
- `2`: 从文件末尾（常用于追加前定位）

---

### 6. 路径处理：`pathlib`（推荐，Python 3.4+）

代替字符串拼接，使用面向对象的路径操作：

```python
from pathlib import Path

p = Path('data/logs/app.log')
p.parent.mkdir(parents=True, exist_ok=True)  # 自动创建目录

with p.open('w', encoding='utf-8') as f:
    f.write('日志内容')

# 常用方法
print(p.exists())      # 是否存在
print(p.read_text())   # 直接读取文本
p.write_text('新内容') # 直接写入文本
```

### 7. 常见文件类型处理

#### CSV 文件
```python
import csv

# 写
with open('data.csv', 'w', newline='', encoding='utf-8') as f:
    writer = csv.writer(f)
    writer.writerow(['name', 'age'])
    writer.writerows([['张三', 25], ['李四', 30]])

# 读
with open('data.csv', 'r', encoding='utf-8') as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)
```

#### JSON 文件
```python
import json

data = {'name': '王五', 'skills': ['Python', 'AI']}
with open('config.json', 'w', encoding='utf-8') as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

with open('config.json', 'r', encoding='utf-8') as f:
    loaded = json.load(f)
```

### 8. 异常处理

```python
try:
    with open('not_exist.txt') as f:
        print(f.read())
except FileNotFoundError:
    print("文件未找到")
except PermissionError:
    print("权限不足")
except IOError as e:
    print(f"IO错误: {e}")
```

---

### 9. 临时文件与内存文件

```python
from tempfile import NamedTemporaryFile
import io

# 临时文件（自动删除）
with NamedTemporaryFile('w+', suffix='.txt', delete=True) as tmp:
    tmp.write('临时内容')
    tmp.seek(0)
    print(tmp.read())

# 内存中模拟文件
f = io.StringIO()
f.write('字符串作为文件\n')
f.seek(0)
print(f.read())
```

---

### 10. 最佳实践总结

| 建议 | 说明 |
|------|------|
| 始终使用 `with open()` | 自动管理资源 |
| 指定 `encoding='utf-8'` | 避免中文乱码 |
| 大文件用迭代读取 | 节省内存 |
| 使用 `pathlib` 管理路径 | 跨平台、更安全 |
| 二进制文件加 `'b'` 模式 | 防止编码问题 |

---

### 示例：完整文件复制

```python
from pathlib import Path

def copy_file(src: str, dst: str):
    src_path = Path(src)
    dst_path = Path(dst)
    dst_path.parent.mkdir(parents=True, exist_ok=True)
    
    with src_path.open('rb') as fsrc, dst_path.open('wb') as fdst:
        for chunk in iter(lambda: fsrc.read(8192), b''):
            fdst.write(chunk)

copy_file('source.bin', 'backup/copy.bin')
```
