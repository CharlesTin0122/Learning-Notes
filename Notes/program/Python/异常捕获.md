在 Python 中，异常捕获是一种处理程序运行时可能出现的错误或异常情况的机制，以避免程序崩溃并提高代码的健壮性。Python 使用 `try`、`except`、`else` 和 `finally` 关键字来实现异常捕获。以下是对 Python 异常捕获的详细介绍：

---
# try except
### 1. **基本语法**
```python
try:
    # 可能引发异常的代码块
    ...
except 异常类型1 as e:
    # 处理异常类型1的代码
    ...
except 异常类型2 as e:
    # 处理异常类型2的代码
    ...
else:
    # 如果 try 块中没有异常，则执行此块
    ...
finally:
    # 无论是否有异常，都会执行此块
    ...
```

- **`try`**: 放置可能抛出异常的代码。
- **`except`**: 捕获并处理特定类型的异常，可以有多个 `except` 分支来处理不同类型的异常。
- **`else`**: 如果 `try` 块中的代码没有抛出异常，则执行 `else` 块（可选）。
- **`finally`**: 无论是否发生异常，`finally` 块中的代码都会执行（常用于清理资源，如关闭文件或释放连接，可选）。

---

### 2. **异常的层次结构**
Python 的异常是基于类的，所有的内置异常都继承自 `BaseException`，常用的异常继承自 `Exception`。以下是一些常见的内置异常类型：
- `ZeroDivisionError`: 除以零时引发。
- `TypeError`: 类型错误，如对不支持的操作应用到对象上。
- `ValueError`: 值无效，如将字符串转换为整数时格式错误。
- `FileNotFoundError`: 文件或目录不存在。
- `IndexError`: 列表索引超出范围。
- `KeyError`: 字典中键不存在。

可以通过 `except Exception as e` 捕获大多数常见异常，但不建议过于宽泛地捕获所有异常，因为这可能隐藏意料之外的错误。

---

### 3. **异常捕获的示例**
以下是一些实际代码示例，展示不同场景下的异常捕获：

#### 示例 1：基本异常捕获
```python
try:
    num = int(input("请输入一个数字："))
    result = 10 / num
except ValueError:
    print("输入的不是有效数字！")
except ZeroDivisionError:
    print("不能除以零！")
else:
    print(f"结果是：{result}")
finally:
    print("执行完毕！")
```

**输出示例**：
- 输入 `5`：  
  ```
  结果是：2.0
  执行完毕！
  ```
- 输入 `0`：  
  ```
  不能除以零！
  执行完毕！
  ```
- 输入 `abc`：  
  ```
  输入的不是有效数字！
  执行完毕！
  ```

#### 示例 2：捕获多个异常
可以同时处理多种异常类型：
```python
try:
    lst = [1, 2, 3]
    index = int(input("请输入索引："))
    print(lst[index])
except (IndexError, ValueError) as e:
    print(f"发生错误：{e}")
```

**输出示例**：
- 输入 `5`：  
  ```
  发生错误：list index out of range
  ```
- 输入 `abc`：  
  ```
  发生错误：invalid literal for int() with base 10: 'abc'
  ```

#### 示例 3：自定义异常
可以通过继承 `Exception` 类来定义自定义异常：
```python
class MyCustomError(Exception):
    pass

try:
    age = int(input("请输入年龄："))
    if age < 0:
        raise MyCustomError("年龄不能为负数！")
    print(f"您的年龄是：{age}")
except MyCustomError as e:
    print(f"错误：{e}")
except ValueError:
    print("请输入有效数字！")
```

**输出示例**：
- 输入 `-5`：  
  ```
  错误：年龄不能为负数！
  ```
- 输入 `abc`：  
  ```
  请输入有效数字！
  ```

---

### 4. **异常捕获的最佳实践**
1. **具体捕获异常**：尽量捕获具体的异常类型，而不是用 `except Exception` 捕获所有异常，以避免隐藏潜在的错误。
2. **使用 `else` 和 `finally`**：
   - 使用 `else` 块来放置仅在无异常时执行的逻辑，保持代码清晰。
   - 使用 `finally` 块来确保资源（如文件或网络连接）被正确释放。
3. **记录异常信息**：在生产环境中，使用日志记录异常信息（例如使用 `logging` 模块）以便调试。
4. **避免空 `except` 块**：空的 `except` 块（如 `except: pass`）可能导致错误被无声忽略，难以排查问题。
5. **抛出异常**：在必要时使用 `raise` 抛出异常，或重新抛出捕获的异常（如 `raise`）以传递给上层调用者。

---

### 5. **with 语句与异常捕获**
对于文件操作或资源管理，`with` 语句可以简化 `finally` 的使用，因为它会自动处理资源的释放，即使发生异常：
```python
try:
    with open("example.txt", "r") as file:
        content = file.read()
        print(content)
except FileNotFoundError:
    print("文件不存在！")
```

---

### 6. **异常的传播**
如果一个异常在当前的 `try-except` 块中没有被捕获，它会向上传播到调用栈中的上层 `try-except` 块。如果没有任何地方捕获异常，程序将终止并显示错误信息。

---

### 7. **总结**
Python 的异常捕获机制通过 `try`、`except`、`else` 和 `finally` 提供了一种强大的方式来处理运行时错误。合理使用异常捕获可以让程序更健壮，防止意外崩溃，同时通过自定义异常和日志记录可以更好地调试和维护代码。

# raise
在 Python 中，`raise` 关键字用于主动抛出异常，允许程序员在特定条件下触发错误或异常情况，从而中断程序的正常执行流程。它是异常处理机制的重要组成部分，常用于自定义异常或将捕获的异常重新抛出。以下是对 `raise` 关键字的详细介绍：

---

### 1. **基本语法**
```python
raise [异常类型[(异常信息)]]
```

- **异常类型**：必须是 `BaseException` 的子类（如 `Exception` 或其子类，例如 `ValueError`、`TypeError` 或自定义异常类）。
- **异常信息**（可选）：附加的描述信息，通常是字符串，用于说明异常原因。
- 如果不指定异常类型或信息，`raise` 可以单独使用，用于重新抛出当前捕获的异常。
- BaseException及其子类：

	BaseException
	├── SystemExit
	├── KeyboardInterrupt
	├── GeneratorExit
	└── Exception
	     ├── ArithmeticError
	     │   ├── ZeroDivisionError
	     │   ├── OverflowError
	     │   └── FloatingPointError
	     ├── TypeError
	     ├── ValueError
	     ├── IndexError
	     ├── KeyError
	     ├── FileNotFoundError
	     ├── AttributeError
	     ├── ImportError
	     │   └── ModuleNotFoundError
	     ├── RuntimeError
	     ├── OSError
	     ├── MemoryError
	     ├── StopIteration
	     └── NotImplementedError
	     ...
---

### 2. **使用场景**
`raise` 关键字主要用于以下几种情况：
1. **主动抛出异常**：在代码中检测到不符合预期的情况时，手动抛出异常。
2. **重新抛出异常**：在 `except` 块中捕获异常后，重新抛出以供上层代码处理。
3. **自定义异常**：结合自定义异常类，提供更具体的错误信息。

---

### 3. **具体示例**

#### 示例 1：主动抛出内置异常
```python
def divide(a, b):
    if b == 0:
        raise ZeroDivisionError("除数不能为零！")
    return a / b

try:
    result = divide(10, 0)
except ZeroDivisionError as e:
    print(f"错误：{e}")
```

**输出**：
```
错误：除数不能为零！
```

说明：当 `b == 0` 时，程序抛出 `ZeroDivisionError` 异常，并附带自定义错误信息。

---

#### 示例 2：自定义异常
可以通过继承 `Exception` 创建自定义异常类，并使用 `raise` 抛出：
```python
class NegativeNumberError(Exception):
    pass

def check_positive(number):
    if number < 0:
        raise NegativeNumberError("输入的数字不能为负数！")
    return number

try:
    check_positive(-5)
except NegativeNumberError as e:
    print(f"错误：{e}")
```

**输出**：
```
错误：输入的数字不能为负数！
```

说明：定义了一个自定义异常类 `NegativeNumberError`，并在检测到负数时使用 `raise` 抛出。

---

#### 示例 3：重新抛出异常
在 `except` 块中捕获异常后，可以使用 `raise` 重新抛出原始异常：
```python
try:
    num = int(input("请输入一个数字："))
    if num == 0:
        raise ValueError("输入不能为零！")
except ValueError as e:
    print(f"捕获到错误：{e}")
    raise  # 重新抛出捕获的异常
```

**输出示例**：
- 输入 `abc`：
  ```
  捕获到错误：invalid literal for int() with base 10: 'abc'
  Traceback (most recent call last):
    ...
  ValueError: invalid literal for int() with base 10: 'abc'
  ```
- 输入 `0`：
  ```
  捕获到错误：输入不能为零！
  Traceback (most recent call last):
    ...
  ValueError: 输入不能为零！
  ```

说明：`except` 捕获异常后，打印错误信息，然后使用 `raise` 将异常重新抛出，导致程序终止并显示完整 traceback。

---

#### 示例 4：抛出异常但不指定信息
可以只抛出异常类型而不附加信息：
```python
try:
    raise RuntimeError
except RuntimeError:
    print("捕获到一个 RuntimeError！")
```

**输出**：
```
捕获到一个 RuntimeError！
```

---

### 4. **注意事项**
1. **异常类型必须有效**：`raise` 后必须跟一个 `BaseException` 的子类实例或类。如果传入其他类型（如字符串），会引发 `TypeError`。
   ```python
   raise "这会报错"  # TypeError: exceptions must derive from BaseException
   ```

2. **异常传播**：如果抛出的异常没有被捕获，它会向上传播到调用栈，直到被处理或导致程序终止。

3. **结合 `try-except`**：通常与 `try-except` 配合使用，确保抛出的异常能被捕获和处理。

4. **调试与日志**：抛出异常时，提供清晰的错误信息有助于调试。可以使用 `logging` 模块记录异常，而不是仅依靠 `print`。

---

### 5. **高级用法：异常链**
Python 支持异常链，当一个异常在处理另一个异常时触发，可以通过 `raise ... from ...` 显式指定异常的因果关系：
```python
try:
    num = int("abc")  # 触发 ValueError
except ValueError as e:
    raise RuntimeError("转换失败！") from e
```

**输出**：
```
Traceback (most recent call last):
  ...
ValueError: invalid literal for int() with base 10: 'abc'

The above exception was the direct cause of the following exception:

Traceback (most recent call last):
  ...
RuntimeError: 转换失败！
```

说明：`from e` 将原始异常 (`ValueError`) 链接到新抛出的异常 (`RuntimeError`)，便于追溯错误原因。

---

### 6. **总结**
- `raise` 关键字用于主动抛出异常或重新抛出捕获的异常。
- 它支持内置异常和自定义异常，允许附加详细的错误信息。
- 通过结合 `try-except` 和 `raise`，可以实现灵活的异常处理逻辑。
- 使用 `raise ... from ...` 可以构建异常链，增强错误信息的可追溯性。
