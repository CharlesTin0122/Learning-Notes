### 1. 基础经验与 Pipeline 理解（初筛，5-8分钟）
1. 请完整描述您目前/之前工作中使用的角色制作 pipeline（从绑定到引擎），重点说明 MotionBuilder、Maya、Unreal Engine 之间的数据流转方式。
2. 您在 Maya 中绑定过的最复杂角色是什么类型？（人型/四足/道具/车辆等）主要挑战是什么？如何解决？
3. 您对 MetaHuman 工作流有多熟悉？是否实际在项目中使用过 MetaHumanForMaya 插件将 MetaHuman 导入 Maya 进行绑定/动画调整？
4. 您使用 Python 在 Maya 和 MotionBuilder 中开发过哪些插件或自动化工具？请举 2-3 个实际案例及解决的问题。
5. 您对线性代数在绑定中的核心应用有哪些理解？（至少举出 3 个实际场景）

### 2. Maya 角色 & 道具绑定（技术面）
6. 请详细说明您在 Maya 中搭建一套完整 HumanIK + 自定义骨骼绑定（包括 FK/IK 切换、Stretch、Squash & Stretch、Corrective Blendshape）的流程。
7. 如何为一个高面数 MetaHuman 角色做高效的 Skinning？您会使用哪些工具/脚本来优化权重（Heat Map、Delta Mush、Volume Skin 等）？
8. 道具绑定中，您如何处理多层级 Rigid Body + 约束（Constraint）系统？例如一把可拆卸的武器或带物理链条的道具。
9. 描述您处理“面部绑定”的完整方案（包括 Jaw、Eye、Tongue、Lip 等）。您是否使用过 Advanced Skeleton、mGear 或自定义 Face Rig？
10. 如何在 Maya 中实现“次级动画”（Secondary Motion）？例如头发、衣服、软组织等（Dynamic Chain、Jiggle Deformer、nCloth 等）。

### 3. Python 脚本与插件编程（深度面，必考）
11. 请现场/口头编写一段 Maya Python 代码：创建一个自定义节点（MPxNode），实现一个简单的“距离驱动 Blendshape”功能。

14. 如何使用 Python + OpenMaya API 读取/修改顶点权重（SkinCluster）并实现“权重镜像”功能？请说明核心类和方法。
15. 如何处理 Maya 与 MotionBuilder 之间的 Python 脚本互通？（例如 MotionBuilder 导出数据后，Maya 自动加载并应用绑定）

### 4. 线性代数（深度面，必考，结合绑定场景）

17. 在 Skinning 中，线性混合蒙皮（Linear Blend Skinning）会导致哪些问题？您如何用 Dual Quaternion Skinning 解决？请写出核心数学公式。
18. 如何用向量叉乘和点乘实现“LookAt 约束”？请现场推导或写出伪代码。
19. 解释**变换矩阵（Transformation Matrix）**在 Maya 中的 4x4 矩阵表示，以及如何通过矩阵运算实现“父子空间切换”。

### 5. Unreal Engine 布料 & 次级动画（深度面）

### 6. MetaHuman、DNA 格式 & MetaHumanForMaya 插件（深度面，必考）
